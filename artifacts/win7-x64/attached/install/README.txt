KexSetup - VxKex NEXT介绍和使用
https://github.com/YuZhouRen86/VxKex-NEXT

1、介绍
VxKex NEXT 是一套适用于 Windows 7 的 API 扩展，可让一些 Windows 8、8.1 和 10 独占应用程序在 Windows 7 上运行。

2、使用
安装后，以下是启用 VxKex NEXT 的方法：
右键单击bin\opencode.exe程序，打开属性对话框，选择“VxKex”选项卡。然后，选中“为此程序启用 VxKex NEXT”和“为子进程禁用 VxKex NEXT”复选框，并尝试运行程序。
