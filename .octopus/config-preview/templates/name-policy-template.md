# Name Policy Table

> Issue: #<id> `<title>`
> 类型：品牌重构 / 命名迁移
> 日期：`<YYYY-MM-DD>`

## 策略定义

| 策略              | 含义                                 |
| ----------------- | ------------------------------------ |
| **Hard Rename**   | 全局替换，不保留旧名                 |
| **Soft Fallback** | 新名优先，旧名保留兼容，过渡期后删除 |
| **Reserved**      | 明确不替换（CHANGELOG、历史记录）    |
| **Forbidden**     | 不可替换（第三方包名、.git/ 对象）   |
