## 去重说明

交叉比对 9 个候选 Issue 的影响范围（包/文件清单），进行语义去重：

| 对比        | 结论       | 理由                                                                                                |
| ----------- | ---------- | --------------------------------------------------------------------------------------------------- |
| #1 vs #2-#9 | **不重复** | #1 处理 npm scope 字符串 + import 语句，其他 Issue 处理具体标识符/路径/资产，语义不同               |
| #2 vs #5    | **不重复** | #2 重命名 `packages/octopus/`（包目录），#5 重命名 `.opencode/`（配置目录），不同文件系统对象       |
| #3 vs #1    | **不重复** | #1 是 `from "@opencode-ai/*"` 作用域替换，#3 是 `createOpencode()` 等 JS 标识符重命名，互不覆盖     |
| #4 vs #5    | **不重复** | #4 处理环境变量名 (`OPENCODE_*`) + Flag 常量，#5 处理配置文件名 + 目录路径，语义不同                |
| #6 vs #7    | **不重复** | #6 处理主题/图标/CSS，#7 处理 VS Code/Zed 扩展元数据，虽同属"品牌展示"但变更类型不同                |
| #8 vs #2    | **不重复** | #2 重命名包目录及其引用，#8 更新 GitHub Actions URL + 脚本中的外部路径，仅在 `sst.config.ts` 有交集 |
| #9 vs #1-#7 | **不重复** | #9 是文档层面更新，内容依赖 #1-#7 的代码变更结果，语义独立                                          |

**判定：0 个语义重复，无需合并。** 9 个 Issue 覆盖 9 个互不重叠的变更维度。

## 风险与缓解

### 高风险

| 风险                    | 影响                                                                                           | 概率 | 缓解                                                                              |
| ----------------------- | ---------------------------------------------------------------------------------------------- | :--: | --------------------------------------------------------------------------------- |
| **#1 scope 替换遗漏**   | 部分 import 指向不存在的 `@opencode-ai/*`，导致 typecheck 失败                                 |  中  | 使用自动化脚本 (`sed` + `rg` 验证)，在 #1 门控处强制 `grep '@opencode-ai'` 零结果 |
| **#9 文档与代码不一致** | 用户按文档操作失败，损害品牌体验                                                               |  中  | #9 必须在 #1-#7 全部完成且 CI 绿后执行；对 MDX 代码块使用脚本提取+验证            |
| **保留引用误杀**        | 外部模型 ID (`opencode/claude-opus-4-7`)、第三方包 (`@gitlab/opencode-gitlab-auth`) 被错误替换 |  高  | 在 #1 和 #9 的自动化脚本中加入排除列表，所有替换后人工抽查                        |
| **bun.lock 不一致**     | workspace 依赖名变化后 4 个锁文件过期                                                          |  高  | #1 完成后立即 `bun install`，生成新锁文件作为 #1 的一部分提交                     |
| **#2 目录 rename 遗漏** | 脚本/CI/文档中的 `packages/octopus/` 路径部分残留                                              |  低  | `git mv` 后全仓 `rg 'packages/octopus/'` 检查                                     |

### 中风险

| 风险                                | 影响                                                                                   | 概率 | 缓解                                                                                |
| ----------------------------------- | -------------------------------------------------------------------------------------- | :--: | ----------------------------------------------------------------------------------- |
| **GitHub Secrets/App 凭证名未同步** | CI 流水线因环境变量名不匹配而失败                                                      |  中  | #8 的验收标准包含 CI 配置清单；在版本发布前由人工完成 GitHub Settings 同步          |
| **i18n key 重命名遗漏**             | 前端页面显示 fallback 或空白                                                           |  低  | #9 对 i18n key 进行脚本化匹配 (regex: `opencode` → `octopus`)，然后对翻译值人工审查 |
| **`.opencode/` 配置目录迁移**       | 用户本地 `.opencode/` 目录在新版本中不被识别                                           |  高  | compat Agent 需在 P5 设计迁移逻辑：启动时检测 `.opencode/` 并提示迁移到 `.octopus/` |
| **外部 URL 替换过度**               | `https://opencode.ai/install`、`https://discord.gg/opencode` 等外部服务 URL 被错误替换 |  中  | 建立保留列表；#8 替换前用 `rg` 列出所有 URL 匹配，人工标注"修改/保留"               |
