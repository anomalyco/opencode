# Test Screenshots

This directory contains screenshots captured during VS Code extension integration tests.

## Structure

- `01-extension/` - Extension activation and registration screenshots
- `02-chat/` - Chat participant interaction screenshots
- `03-failures/` - Screenshots captured on test failures

## Naming Convention

Files follow the pattern: `{sequence}-{scenario}.png`

Example: `01-activation.png`, `02-participant.png`

## Retention

Screenshots are stored in CI artifacts for 90 days and attached to PR comments for verification.
