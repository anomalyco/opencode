# lacymorrow/lash

A FORK OF sst/opencode

AI-powered terminal assistant for software developers.

## Installation

### One-line install (Recommended)
```bash
curl -fsSL https://raw.githubusercontent.com/lacymorrow/lash/main/install | bash
```

### Homebrew
```bash
brew install lacymorrow/tap/lash
```

### npm
```bash
npm install -g lash-cli
```

### From Source
```bash
git clone https://github.com/lacymorrow/lash
cd lash/packages/opencode
bun install
bun run dev
```

### Pre-built Binaries
Download the latest release for your platform from the [GitHub Releases](https://github.com/lacymorrow/lash/releases) page.

## Usage

```bash
lash --help
```

## Features

- 🤖 AI-powered coding assistance
- 🖥️ Terminal-based interface
