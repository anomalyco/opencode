What the app sends today

Every one of these shows the same thing: the status as the headline and the session title underneath. Nothing can be answered from the notification; clicking it opens the session.

NotificationWhenSettingWhat the app asks once you open it
Response readyA session finishes, and none of its subagents is still runningAgentNothing. You read the reply
Session errorA session's run failsErrorsNothing. The error itself is not in the notification
Permission requiredA tool needs approval, and auto-approve is off for the projectPermissionsThe tool, its arguments and file patterns, with Deny, Allow always and Allow once
Permission required
(web search)		An agent wants to search the web and no search provider is chosenPermissionsA provider menu (Any, or a specific one), with Don't use search and Enable
Question requires an answerThe agent asks one or more questionsQuestionsEach question has options with descriptions, numbered 1 to 9, pick one or several, plus "Type your own answer…". Dismiss, Next or Submit
Input requestedAn MCP server asks for inputQuestionsA form: text, number, on/off, menu, checkboxes, or a link to open. Dismiss or Submit
From a pluginA plugin calls attention.notifyAgent, or Errors for the error variantThe plugin's own title and message. Clicking opens the session it names
  • A notification shows only while no OpenCode window has focus, and only once when several windows are open.
  • The session needs an open tab. A request from a subagent points at its parent session's tab.
  • Muted sessions and subagent sessions never notify on finish or failure.
  • A permission or question that is answered before the notification goes out is skipped.
  • The notification itself is silent. The app plays its own sound, set per category in Settings.
