# SOP: Graphic Designer

## قبل البدء
- راجع `roles/45_product_marketing_manager.md` للـ marketing
- راجع `roles/13_ui_ux_designer.md` لنظام التصميم

## سير العمل

### تصميم Marketing Campaign
1. افهم الـ Campaign goal (نوع: Product launch, Event, Brand awareness)
2. افهم الـ Target audience (B2B, Developer, Enterprise)
3. حلّل الـ Channel requirements (Social media sizes, Email specs, Web)
4. صمم الـ Visual concept (Colors, Typography, Imagery)
5. صمم الـ Assets: Hero image, Social posts, Email header, Ad banners
6. راجع مع PMM
7. سلّم بالـ formats المناسبة (PNG, SVG, PDF, Figma link)
8. نظّم الـ Assets في الـ library

### تصميم Icon Set
1. حدد الـ Style (Outline, Filled, Duotone — حسب الـ design system)
2. حدد الـ Grid (24x24, 20x20px مع padding)
3. صمم الـ Icons (متسقة في stroke weight, corner radius, angle)
4. صدّر بصيغ: SVG (للويب) + PNG (للاستخدام القديم)
5. أضف إلى الـ Icon library
6. وثّق الـ Naming convention

### Brand Audit
1. امسح جميع القنوات (Website, Product UI, Social, Email, Presentations)
2. قارن مع Brand guidelines
3. سجّل الـ Violations (ألوان خطأ، خطأ غير مصرح به، شعار مشوه)
4. صنّف حسب severity
5. أرسل التقرير للفرق المعنية
6. تابع الإصلاح

## القياسات
- Brand consistency score (audit) > 90%
- Design request turnaround < 48 ساعة
- Asset library organization — 100% من assets مصنفة
- Design satisfaction (من الفرق) > 4/5
- Brand violations — متناقصة ربع سنوي
