# SOP: Financial Analyst / FP&A

## قبل البدء
- راجع `7-ops/finops.md` لتحسين تكلفة السحابة
- راجع `config/cost/history.csv` لسجل التكلفة
- راجع `8-quality/cost_optimization.md` لتحسين التكلفة

## سير العمل

### إعداد الـ Budget السنوي
1. اجمع المدخلات من جميع الأقسام (Headcount, SaaS, Infra, Professional services)
2. حلّل الـ Actuals من السنة الماضية
3. بني الـ Financial model (Revenue, COGS, OPEX, Headcount)
4. راجع مع كل قسم lead
5. وحّد في نموذج واحد
6. اعرض على الـ CTO + CEO للموافقة
7. انشر الـ Budget المعتمد

### التحليل الشهري
1. جهز الـ Actuals (من الـ accounting system)
2. قارن مع الـ Budget (Variance analysis)
3. حلّل الـ Drivers (لماذا الفروقات؟)
4. حدّث الـ Forecast
5. اكتب الـ Commentary (ما حدث، لماذا، ماذا نتوقع)
6. اعرض في الـ Monthly business review

### بناء Financial Model لـ Product Pricing
1. احسب الـ Unit economics (CAC, LTV, Gross margin)
2. حلّل الـ Cost to serve لكل منتج
3. اعمل الـ Scenario analysis (3 سيناريوهات: متفائل، متوقع، متشائم)
4. قدّم التوصيات للـ PM + CTO
5. حدّث الـ model بعد الـ launch بالبيانات الحقيقية

## القياسات
- Budget accuracy (Actual vs Budget) < 5% variance
- Forecast accuracy > 85%
- Board deck delivery — 3 أيام قبل الـ board
- Financial model updates — شهري
- Cost savings identified — $X سنوياً
