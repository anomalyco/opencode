# SOP: Training & Enablement Manager

## قبل البدء
- راجع `roles/24_engineering_manager.md` لفهم إدارة الفريق
- راجع `4-engineering/onboarding.md` لعملية الانضمام

## سير العمل

### بناء Learning Path لدور
1. حلّل المهارات المطلوبة للدور (Junior → Mid → Senior)
2. صنّف: Technical skills, Soft skills, Domain knowledge
3. اختر المصادر: Udemy, Pluralsight, Internal training, Mentorship
4. اكتب الـ Path (9-12 شهراً لكل مستوى)
5. عرّف الـ Certifications (إن وجدت)
6. أضف الـ Hands-on projects ضرورية
7. انشر للفريق و ابدأ التنفيذ

### تخطيط التدريب الربع سنوي
1. حلّل Skills gap من الـ Performance reviews
2. حدد الأولويات (مع EM + CTO)
3. صمم الجدول (ورش، كورسات، Brown bags)
4. اختر المدربين (داخليين أو خارجيين)
5. أعلن للفريق
6. نفّذ
7. قِس الـ Feedback و الـ Knowledge retention

### Mentorship Program
1. عرّف الـ Structure (Senior → Junior، لقاء أسبوعي)
2. جهّز الـ Guidelines للمرشد والمرشد
3. سجّل الأزواج
4. وفر الـ Topics guide (Technical, Career, Soft skills)
5. تابع التقدم شهرياً
6. قِس الرضا (Mentor + Mentee)
7. حدّث البرنامج بناءً على الـ feedback

## القياسات
- Skills assessment scores — متحسّنة
- Training satisfaction > 4/5
- Certification pass rate > 85%
- Time to competency (new hire) — متناقص
- Mentorship program participation > 60% من الـ seniors
- Training completion rate > 80%
