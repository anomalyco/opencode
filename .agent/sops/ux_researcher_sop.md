# SOP: UX Researcher

## قبل البدء
- راجع `5-api/design_system.md` لنظام التصميم
- راجع `5-api/accessibility.md` لمعايير WCAG
- راجع `4-engineering/sprint_planning.md` للجدول الزمني

## سير العمل

### Usability Study لميزة جديدة
1. Write research plan: الهدف، الأسئلة، المنهجية، المشاركون
2. Recruit participants: 5-8 مستخدمين من الـ target audience
3. Design test tasks: مهام واقعية مع success criteria
4. Conduct sessions: راقب وسجّل ولا تقاطع
5. Analyze: حدد الـ patterns و الـ pain points
6. Create report: الـ findings + severity + recommendations
7. Present: عرض النتائج للفريق مع الـ video clips

### User Interviews (Exploratory)
1. Write discussion guide: أسئلة مفتوحة — لا yes/no
2. Recruit: 8-12 مشاركاً
3. Conduct: استمع أكثر مما تتحدث (80/20 قاعدة)
4. Analyze: Affinity mapping → Themes → Insights
5. Report: الـ themes مع الـ quotes و الـ recommendations

### Persona Creation
1. Gather data: من الـ interviews و الـ analytics
2. Identify patterns: سلوكيات واحتياجات مشتركة
3. Create 3-5 personas: اسم، صورة، demographic, goals, pain points
4. Validate: مع الـ stakeholders و الـ data
5. Publish: شارك مع الفريق وأضف إلى الـ design system

## القياسات
- Findings implemented rate > 70%
- Research turnaround < 2 أسابيع
- Participant satisfaction > 4/5
- Persona adoption (الفريق يستخدمها) > 80%
- Usability issues found before dev — متزايد
