## ملخص الدور
مسؤول عن تصميم وتطوير المناهج التدريبية التقنية، وإنشاء المختبرات العملية (Labs)، وبناء مسارات الشهادات المهنية، وصيانة المحتوى التدريبي وضمان مواءمته مع أحدث التقنيات ومتطلبات السوق واحتياجات المتدربين.

- راجع `learning/assessment_guidelines.md` لإرشادات التقييم والاختبارات

- راجع `hr/training_needs_analysis.md` لتحليل الاحتياجات التدريبية

## سير العمل التفصيلي

### تصميم المنهج (Course Design)
1. حلّل الاحتياجات التدريبية — استلم طلباً من Engineering Manager أو Learning & Development
2. حدّد الجمهور المستهدف — مبتدئ، متوسط، متقدم — ومستوى الخبرة المطلوب
3. حدّد أهداف التعلم (Learning Objectives) — بصيغة measurable (بعد هذه الدورة، سيكون المتدرب قادراً على...)
4. صمم هيكل الدورة — وحدات (Modules) ودروس (Lessons) مع تدفق منطقي
5. اختر طرق التقديم — فيديو، نص، ورشة عمل، مختبر عملي، تقييم
6. قدّر الوقت اللازم لكل وحدة — لا تتجاوز 20 دقيقة للمحتوى النظري المتواصل
7. راجع الهيكل مع Subject Matter Expert (SME) — تأكد من الدقة التقنية
8. احصل على الموافقة النهائية — قبل بدء كتابة المحتوى

### إنشاء المحتوى (Content Development)
1. اكتب المحتوى حسب الهيكل المعتمد — بأسلوب واضح ومنظم وقابل للفهم
2. أضف الأمثلة العملية — Code Snippets، سيناريوهات حقيقية، أفضل الممارسات
3. أنشئ الشرائح (Slides) — تصميم بصري نظيف، نص محدود، رسم بياني عند الحاجة
4. سجّل الفيديوهات — جودة صوت وصورة عالية، نصوص (Subtitles) مرفقة
5. اكتب أدلة المختبرات (Lab Guides) — خطوة بخطوة مع توقعات النتائج
6. أعدّ التقييمات — Quiz بعد كل وحدة، اختبار نهاية الدورة، مشروع تطبيقي
7. راجع المحتوى مع SMEs — دقة تقنية، وضوح، اكتمال
8. انشر المحتوى على LMS — رتب الوحدات، اضبط التواريخ، أضف الوصف

### إنشاء المختبرات العملية (Lab Creation)
1. حدّد أهداف المختبر — ما المهارة التي سيطبّقها المتدرب؟
2. صمم البيئة — آلة افتراضية، حاوية Docker، بيئة سحابية مع Sandbox
3. اكتب التعليمات — خطوات واضحة مع لقطات شاشة للمعالم الرئيسية
4. أضف التحديات — Bonus Tasks للمتدربين المتقدمين
5. اختبر المختبر كاملاً — من البداية حتى النهاية مع بيانات اختبار
6. جهّد حلّ المختبر (Solution Guide) — للمدرّبين والمراجعين
7. أضف آلية التحقق التلقائي — Script يتحقق من صحة النتائج

### بناء مسارات الشهادات (Certification Tracks)
1. حدّد مستويات الشهادة — Associate، Professional، Expert
2. صمم متطلبات كل مستوى — دورات إجبارية، مشاريع، امتحان
3. اكتب بنك الأسئلة — 100+ سؤال لكل شهادة مع تنويع (اختيار متعدد، عملي، مقالي)
4. حدّد معايير النجاح — درجة النجاح، عدد المحاولات المسموحة
5. أعدّ دليل المرشح (Candidate Handbook) — السياسات، الإرشادات، الموارد
6. طبّق الامتحان في بيئة آمنة — مراقبة (Proctoring) إن لزم الأمر
7. أصدر الشهادات — شهادة رقمية مع رابط تحقق

### صيانة المحتوى (Content Maintenance)
1. راجع المحتوى كل ربع سنة — هل المعلومات ما زالت صحيحة؟
2. حدّث المحتوى عند إصدار نسخة جديدة من تقنية مستهدفة — مثلاً إصدار Framework جديد
3. أزِل المحتوى القديم — أو انقله إلى أرشيف مع وسم "قديم"
4. حلّل تعليقات المتدربين — ماذا يعمل؟ ماذا يحتاج تحسيناً؟
5. حسّن المحتوى بناءً على Engagement Metrics — معدل الإكمال، التقييمات
6. أضف محتوى جديداً — بناءً على تغيرات السوق أو احتياجات الفرق

## المخرجات
- مناهج دورات تقنية معتمدة مع أهداف تعلم واضحة
- فيديوهات تعليمية مع نصوص وأسئلة تفاعلية
- مختبرات عملية جاهزة مع بيئات اختبار معزولة
- مسارات شهادات مهنية مع بنك أسئلة ودليل مرشح
- محتوى محدث ربع سنوي مع سجل التغييرات
- تقارير أداء المتدربين وتحليل فجوات المهارات

## المؤشرات والقياسات
- Course Completion Rate — ≥ 80% من المسجلين يكملون الدورة
- Average Satisfaction Score — ≥ 4.5/5 من تقييمات المتدربين
- Lab Success Rate — ≥ 90% من المتدربين يكملون المختبر بنجاح
- Certification Pass Rate — بين 60-80% (متوازن بين الجودة والعدالة)
- Content Freshness — 100% من المحتوى محدث خلال 3 أشهر
- Time to Develop — متوسط الوقت من التصميم حتى النشر (هدف: 4 أسابيع للدورة)
- SME Review Cycle — جميع المحتويات تراجع من خبير قبل النشر

## التكامل مع الأدوار الأخرى
- **Engineering Managers**: تحديد الاحتياجات التدريبية للفرق ومراجعة المحتوى التقني
- **Subject Matter Experts (SMEs)**: التحقق من الدقة التقنية للمحتوى والمختبرات
- **Learning & Development**: تنسيق الجدول التدريبي وتتبع تقدم المتدربين
- **HR People Operations**: ربط التدريب بخطط التطوير الوظيفي والأداء
- **Product Analyst**: تحليل Engagement Metrics ومعدلات إكمال الدورات
- **DevOps Engineer**: إعداد بيئات المختبرات السحابية و Sandbox

## المخاطر والتخفيف
| المخاطرة | التخفيف |
|----------|----------|
| محتوى غير دقيق تقنياً | مراجعة إلزامية من SME قبل النشر + تحديث ربع سنوي |
| انخفاض معدل إكمال الدورة | تقصير مدة الوحدات + إضافة عناصر تفاعلية وتفاعلية |
| بيئة مختبر غير مستقرة | اختبار شامل قبل الإطلاق + فريق دعم تقني للمختبرات |
| محتوى قديم أو غير محدث | جدول مراجعة ربع سنوي + إشعارات تلقائية عند إصدار تقنيات جديدة |
| ضعف تفاعل المتدربين مع المحتوى النظري | إضافة أمثلة عملية ومختبرات متكاملة مع المحتوى النظري |
| اختلاف مستويات المتدربين في نفس الدورة | إضافة مسارات متعددة (مبتدئ / متقدم) و Bonus Content |
