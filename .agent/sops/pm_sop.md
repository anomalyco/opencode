# SOP: Product Manager

## المدخلات
- رؤية CTO
- متطلبات المستخدم (User Needs)

## سير العمل
1. حلّل المتطلبات
2. اكتب PRD في `docs/prd/{phase}/PRD.md`
3. اكتب User Stories
4. حدد Acceptance Criteria
5. حدد النطاق (Scope) — مسجل في `.ai/context/scope.yaml`
6. سلّم إلى Architect

## المخرجات
- PRD
- User Stories
- Scope definition

## القيود
- كل قصة مستخدم لها معيار قبول قابل للقياس
- النطاق محدد بوضوح مع "لن يتم"
