# SOP: Technical Recruiter

## قبل البدء
- راجع `roles/24_engineering_manager.md` لإدارة الفريق
- راجع `4-engineering/onboarding.md` لعملية الانضمام

## سير العمل

### فتح Position جديد
1. اجتمع مع الـ EM لفهم: الـ Role، الـ Skills، الـ Culture fit
2. اكتب الـ Job description (واضح، شامل، غير متحيز)
3. نشر في القنوات: LinkedIn, Indeed, Twitter/X, المنصات التقنية
4. ابدأ الـ Sourcing (LinkedIn, GitHub, Personal network)
5. حدد الـ Interview process (Phone screen → Technical → System design → Cultural)
6. درّب الـ Interviewers على الـ Unbiased interviewing

### إدارة Pipeline
1. راجع المتقدمين يومياً
2. Phone screen (30 دقيقة): مهارات أساسية، دوافع، توقعات راتب
3. جدول الـ Technical interviews
4. اجمع الـ Feedback (نظام تقييم موحد — ليس عاطفي)
5. اتخذ القرار مع الـ EM
6. أرسل الـ Offer
7. أبلغ الـ Unsuccessful candidates (مع feedback مفيد)

### تحسين الـ Employer Brand
1. اكتب Blog posts (Developer stories, Tech challenges)
2. نظّم Open house / Tech talk events
3. شارك في conferences (booth, talks)
4. شجّع الفريق على المشاركة في المنصات (Stack Overflow, GitHub)
5. قِس الـ Brand awareness (Unsolicited applications, Referral rate)

## القياسات
- Time to hire < 30 يوماً
- Offer acceptance rate > 85%
- Source quality (أي قناة تجلب أفضل المرشحين)
- Diversity of pipeline > 30%
- Candidate satisfaction (NPS) > 50
- Referral rate > 40%
