# SOP: Agile Coach

## قبل البدء
- راجع `4-engineering/sprint_planning.md` لعملية الـ Sprint
- راجع `roles/16_scrum_master.md` لدور الـ SM
- راجع `4-engineering/devex.md` لتجربة المطور

## سير العمل

### تقييم نضج Agile لفريق
1. اختَر نموذج التقييم (Agile Fluency, Scrum maturity, Spotify model)
2. حلّل: Sprint reviews, Retro outcomes, Velocity trends, Team satisfaction
3. قابِل: Scrum Master, PM, Engineering Manager
4. حدد: نقاط القوة، الفجوات، الأولويات
5. اكتب: تقرير مع خطة التحسين (3 أشهر)
6. اعرض: على الفريق والـ CTO

### تدريب Scrum Master
1. لاحظ: احضر الـ ceremonies كمراقب
2. Feed back: ناقش الـ facilitation, الـ conflict resolution, الـ time management
3. Teach: تقنيات الـ Agile engineering (TDD, pair programming, CI)
4. Shadow: دع الـ SM يقود وأنت تراقب
5. Repeat: مرة كل أسبوعين لمدة 3 أشهر

### تحسين Flow للفريق
1. قِس الـ current flow: Cycle time, WIP, Throughput
2. حلّل الـ bottlenecks (أين تتراكم المهام؟)
3. أعطِ توصيات: WIP limits, Batch size reduction, Policy definitions
4. طبّق: Kanban board مع explicit policies
5. قِس: الفرق بعد 4 أسابيع

## القياسات
- Agile maturity score — متزايد ربع سنوي
- Team satisfaction — متزايد
- Cycle time — متناقص
- Scrum Master skills — متحسّن (تقييم 360)
- Agile transformation progress — على الخطة
