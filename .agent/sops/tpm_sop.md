# SOP: Technical Program Manager (TPM)

## قبل البدء
- راجع `1-core/phases.md` لجميع الـ 18 مرحلة
- راجع `1-core/integration_plan.md` لخطة الدمج
- راجع `1-core/rollback_and_cost.md` لإدارة التكلفة
- راجع `1-core/wave_parallel.md` للمسارات المتوازية

## سير العمل

### تخطيط البرنامج
1. عرّف الـ Program Goal (جملة واحدة)
2. عرّف الـ Phases ومدة كل مرحلة
3. حدد الـ Dependencies بين الفرق والمراحل
4. ارسم الـ Critical Path
5. حدد الـ Milestones (GO/NO-GO points)
6. أنشئ الـ Risk Register
7. اعرض على CTO للموافقة
8. انشر البرنامج لجميع الفرق

### تحديث الحالة الأسبوعي
1. اجمع status من جميع الـ Leads
2. حلّل الـ progress vs plan
3. حدد الـ new risks و blockers
4. حدّث الـ milestone dates إن لزم
5. اكتب التقرير التنفيذي (صفحة واحدة)
6. اعرض في الـ Steering Committee
7. انشر للـ stakeholders

### إدارة الـ Dependencies
1. حدد الـ dependencies في بداية البرنامج
2. صنّف حسب النوع (Technical, Team, External)
3. حدد الـ owner لكل dependency
4. تابع الـ status أسبوعياً
5. للأخطار: اسأل "ماذا تحتاج لحل هذه الـ dependency؟"
6. صعّد للـ CTO إن لم تُحل خلال أسبوع

## القياسات
- Program completion on time > 85%
- Milestone achievement rate > 90%
- Dependency resolved on time > 85%
- Risk mitigation effectiveness > 80%
- Stakeholder satisfaction > 4/5
