# Русская терминология (V2 docs)

Решения для переводов `src/docs/content/ru/`. Английский столбец — исходный термин; ниже — принятый русский вариант и примечания.

| English | Русский | Примечания |
| --- | --- | --- |
| agent / subagent | агент / субагент | В том числе в составе «агент для программирования»; `child agent` → дочерний агент |
| open source coding agent | агент для программирования с открытым исходным кодом | Никогда не добавлять «AI» к этой фразе |
| Console (product) | Console | Не переводить; «в Console», «из Console». Не «консоль», чтобы не путать с терминалом |
| workspace (Console object) | рабочее пространство | Рабочее пространство Console: участники, кредиты, бюджеты |
| workspace (текущий каталог/Location) | рабочий каталог / проект | Например, в инструкциях и разрешениях; не путать с рабочим пространством Console |
| team | команда | Go Teams остаётся по-английски |
| account | аккаунт | Не «учётная запись» |
| authentication / authenticate | аутентификация / аутентифицировать | sign in → войти, вход |
| token | токен | И токен доступа, и токены модели |
| provider | провайдер | |
| identity provider (IdP) | поставщик удостоверений | Не «провайдер идентичности»; отличать от провайдера моделей |
| model / variant | модель / вариант | |
| session | сессия | |
| prompt | промпт | prompt cache → кэш промптов |
| context | контекст | |
| tool | инструмент | tool call → вызов инструмента |
| skill | навык | `SKILL.md` не переводится |
| plugin | плагин | |
| harness | harness | Не склоняется: «в harness», «для harness» |
| command / slash command | команда / слеш-команда | |
| permission | разрешение | |
| policy / policies | политика / политики | |
| budget | бюджет | |
| credits | кредиты | credit balance → баланс кредитов |
| billing / invoice | оплата и счета / счёт | |
| usage | использование | usage limits → лимиты использования |
| request / response | запрос / ответ | |
| inference | инференс | |

| endpoint | эндпоинт | |

| service account | сервисный аккаунт | |

| single sign-on | единый вход | SSO остаётся |
| directory sync | синхронизация каталога | |

| warming | прогрев | |
