# Українська (uk) — глосарій перекладу документації

Терміни й правила для перекладу V2-документації в `src/docs/content/uk/`. Загальні терміни — з `../glossary.md`; цей файл фіксує українські рішення.

## Правила письма

- Звертання до читача — «ви» з малої літери, дієслова в наказовому способі: «Встановіть», «Запустіть», «Дивіться».
- Природна українська технічна мова, без кальок з російської та без буквального перекладу англійських конструкцій. Короткі речення, активний стан.
- Лапки — « », апостроф — прямий `'` (`обов'язково`, `п'ять`), тире — довге з пробілами (` — `), три крапки — `…`, якщо так у англійському тексті.
- Числа, ціни, версії, ідентифікатори моделей і дати — точно як в англійському тексті.
- Код, команди, прапорці, ключі конфігурації, змінні середовища, шляхи, URL, MDX-компоненти та їхні пропси — без змін; вміст блоків коду — побайтово той самий (разом з info string на кшталт `title="opencode.jsonc"`).
- Внутрішні посилання лишаються коренево-відносними (`/config`); перекладається лише текст посилання.
- Структура заголовків — та сама кількість, порядок і рівень, що в англійському тексті (якорі беруться з англійських заголовків).
- Кількість пунктів списків, рядків таблиць і застережень — як в англійському тексті; нічого не додавати й не вилучати.
- Назви продуктів, моделей, компаній і застосунків — англійською.
- Англійські UI-підписи в жирному (**Settings › Billing**, **Add credits**, **Personal**) — англійською.
- OpenCode — це «відкритий агент для кодування»; не додавати «AI» до цієї фрази.

## Уникати (росіянізми й кальки)

- «являється» → «є», «це»;
- «в якості» → «як»;
- «на протязі» → «протягом»;
- «слідуючий» → «наступний»;
- «приймати участь» → «брати участь»;
- «відноситися» → «стосуватися»;
- «в залежності від» → «залежно від»;
- «так як» → «оскільки»;
- «при допомозі» → «за допомогою»;
- «співпадати» → «збігатися»;
- «направлений» → «спрямований»;
- «по» на позначення засобу → «за», «з», «через»;
- «данний» → «цей»;
- «до тих пір, поки» → «доки»;
- «відповідно до» — доречно лише з документами/правилами, не як універсальна зв'язка;
- «функціонал» → «можливості», «функції»;
- «юзер» → «користувач»;
- «дефолтний» → «типовий», «стандартний»;
- «контент» → «вміст»;
- «апдейт» → «оновлення».
