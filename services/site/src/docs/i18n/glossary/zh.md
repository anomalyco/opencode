# 简体中文 (zh) 文档术语表

`src/docs/content/zh/` 的 V2 文档翻译用词。共用的产品、代码和格式规则见 [`../glossary.md`](../glossary.md)；本文件记录简体中文的选择。

## 保留英文

- 产品名称：OpenCode、Zen、Go、Go Plus、Go Teams、Desktop。
- 角色词 `agent`、`subagent`，包括 `coding agent` 等组合词。
- 供应商、模型、公司、应用和工具名称。
- 缩写：MCP、LSP、SDK、CLI、API、TUI、JSON。
- 命令、旗标、配置键和值、环境变量、路径、代码、URL 和密钥。
- 从产品引用的粗体英文界面标签，例如 **Settings › Billing**、**Add credits**。
