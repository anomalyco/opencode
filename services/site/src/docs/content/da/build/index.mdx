title: "Byg på OpenCode"
description: "Byg på OpenCode med plugins, TypeScript-klienten til dets HTTP-API eller SDK'et, der indlejrer det i din applikation."

OpenCode bruges af millioner hver dag. Byg videre på OpenCode, når du vil skabe dine egne apps, integrationer og brugeroplevelser med agenter uden at starte fra bunden.

Vi tilbyder også Effect-API'er til [plugins](/build/plugins/effect),
[klienter](/build/client/effect) og [indlejrede apps](/build/sdk/effect).

    forbliver intakt.
  </Card>
