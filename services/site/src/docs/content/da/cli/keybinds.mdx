---
title: "Tastebindinger"
description: "Tilpas OpenCode CLI-tastebindinger i cli.json, og slå hver kommandos ID og standardbinding op."
---

Tilpas tastebindinger i `cli.json`:

```json title="cli.json"
{
  "keybinds": {
    "leader": "ctrl+space",
    "command.palette.show": "ctrl+k",
    "app.exit": ["ctrl+c", "ctrl+d"],
    "app.debug": false
  },
  "leader": {
    "timeout": 1500
  }
}
```

Brug en streng til én tast:

```json
{
  "keybinds": {
    "command.palette.show": "ctrl+k"
  }
}
```

Adskil alternativer med kommaer:

```json
{
  "keybinds": {
    "app.exit": "ctrl+c,ctrl+d"
  }
}
```

Deaktivér en binding med `"none"` eller `false`:

```json
{
  "keybinds": {
    "app.debug": "none",
    "help.show": false
  }
}
```

Brug et objekt til hændelsesadfærd:

```json
{
  "keybinds": {
    "prompt.paste": {
      "key": "ctrl+v",
      "preventDefault": false
    }
  }
}
```

`leader` er som standard `ctrl+x`. `<leader>` i en anden binding refererer til den tast.

```json
{
  "keybinds": {
    "leader": "ctrl+space",
    "model.list": "<leader>m"
  },
  "leader": {
    "timeout": 2000
  }
}
```

Ukendte kommando-ID'er ignoreres.

## Mini

Kommandoen `app.clear` virker kun i [`opencode mini`](/cli). Tryk på `ctrl+l` for at rydde den synlige skærm og tegne prompten igen. Terminalen beholder scrollback.

```json title="cli.json"
{
  "keybinds": {
    "app.clear": "ctrl+l"
  }
}
```

| ID          | Standard  | Beskrivelse      |
| ----------- | -------- | ---------------- |
| `app.clear` | `ctrl+l` | Ryd skærmen |

## Diff-fremviser

Tryk på `d` (`diff.switch_source`) for at vælge **All**, **Committed**, **Uncommitted** eller **Last turn** (inde i en session), eller vælg **Base** for at ændre sammenligningsbranchen. Valgene huskes, indtil TUI'en afsluttes. Angiv startomfanget med [`diffs.source` i `cli.json`](/cli/config#diffs).

Rulning, bladring og genveje til start/slut styrer altid diffen. Der er ingen tastaturfokusskift: klik på filer for at åbne dem, klik på mapper for at udvide eller skjule dem, og brug mushjulet til at rulle filtræet.

Brug `n` / `p` eller `alt+down` / `alt+up` (Option på macOS) til at flytte mellem filer. Inde i diff-fremviseren navigerer Alt-genvejene mellem filer i stedet for sessionfaner.

Tryk på `m` for at markere en fil som gennemgået og skjule dens patchtekst. I visningen med alle filer skal du trykke på `m` igen for at fjerne markeringen og åbne patchen igen. Enkeltfilvisningen går automatisk videre til næste fil, når du markerer som gennemgået, men bliver på den sidste fil i stedet for at gå rundt. Fjernelse af en markering går aldrig videre.

Højreklik på en fil i sidebaren eller på dens diff-overskrift for at vælge **Mark complete** (eller **Mark incomplete**). Det ændrer markeringen på samme måde som `m`. Hvis du bruger menuen til at markere en anden fil som gennemgået, ændres den fil, du har åben, ikke.

De alternative tastebindinger med Shift til `diff.help` understøtter terminaler, der registrerer Shift som en del af tastetrykket, når du trykker på `?`.
