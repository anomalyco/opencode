OpenCode Console tilbyder en liste over modeller, der er testet og verificeret af OpenCode-teamet. Log ind, tilføj kredit, og hent en
API-nøgle for at bruge dem med OpenCode eller en anden kodningsagent.

Console fungerer som enhver anden udbyder i OpenCode. Det er **helt valgfrit**, og du kan bruge enhver anden udbyder
i stedet. For et abonnement med inkluderet forbrug, se [OpenCode Go](/console/go).

## How it works

1. Log ind på [Console](https://opencode.ai/console), angiv dine faktureringsoplysninger, tilføj kredit, og kopiér din API-nøgle.
2. Kør `/connect` i TUI'en, vælg OpenCode-udbyderen med betaling efter forbrug, og indsæt din API-nøgle.

   ```text
   /connect
   ```

3. Kør `/models` for at se de tilgængelige modeller og vælge en.

   ```text
   /models
   ```

Du betaler pr. anmodning og kan tilføje kredit til din konto.

## Endpoints

Du kan også få adgang til modellerne direkte gennem følgende API-endpoints. Chatmodeller på gratisniveauet kræver OpenCode;
brug betalte modeller eller [Go](/console/go) fra andre klienter.

For hver model vises det API, den selv understøtter, men alle tekstmodeller virker også via de andre API'er, fordi Console oversætter anmodningerne. Se [Base URL'er](/console/harnesses#base-urls) for den fulde oversigt.

### Jev

Jev er en System One-model fra TypeSafe AI til hurtige, strukturerede beslutninger. I stedet for at generere tekst vurderer den en `state` ud fra spørgsmål med definerede typer og returnerer værdier og sandsynligheder, som din kode kan bruge direkte. Den understøtter ja/nej-spørgsmål (`noul`), spørgsmål med svarmuligheder (`choice`) og spørgsmål med faste bedømmelseskriterier (`score`).

Brug din OpenCode Console-API-nøgle med endpointet `https://opencode.ai/inference/systemone/v1/systemone`. Dette eksempel kontrollerer, om en supportanmodning haster:

```bash
curl https://opencode.ai/inference/systemone/v1/systemone \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jev-1.14",
    "state": "My payments have failed for three days and I am losing sales. Please help now.",
    "questions": {
      "is_urgent": {
        "type": "noul",
        "instructions": "Does this request require urgent attention?"
      }
    }
  }'
```

Du kan stille flere spørgsmål i én anmodning. Jev evaluerer dem parallelt og returnerer hvert svar under det matchende spørgsmåls-ID:

```bash
curl https://opencode.ai/inference/systemone/v1/systemone \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jev-1.14",
    "state": "My order arrived late and the item is damaged. I want a refund.",
    "questions": {
      "department": {
        "type": "choice",
        "instructions": "Which team should handle this request?",
        "criteria": {
          "returns": "Refunds, exchanges, or damaged items",
          "shipping": "Delivery delays or lost packages",
          "billing": "Charges, invoices, or payment problems"
        }
      },
      "frustration": {
        "type": "score",
        "instructions": "How frustrated is the customer?",
        "criteria": ["Calm", "Frustrated", "Very angry"]
      }
    }
  }'
```

Brug `jev-1.13-free` for at bruge den tidsbegrænsede gratis model, som kører Jev 1.13. Se [TypeSafe AI-dokumentationen](https://docs.typesafe.ai/) for detaljer om spørgsmålstyper og svarfelter.

### GPT 6 Luna Decision and Gemini Decision 1

`gpt-6-luna-decision` og `gemini-decision-1` tager den samme System One-anmodning som Jev på det samme endpoint. Send billeder, lyd, video og PDF'er i `state` som chatdele (`image_url`, `input_audio`, `video_url`, `file`). GPT 6 Luna Decision accepterer tekst og billeder; Gemini Decision 1 accepterer også lyd, video og PDF'er.

```bash
curl https://opencode.ai/inference/systemone/v1/systemone \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gemini-decision-1",
    "state": "I was charged twice for my order.",
    "questions": {
      "refund": {
        "type": "noul",
        "instructions": "Is this a refund request?"
      }
    }
  }'
```

### Billedmodeller

`gpt-image-2.5-sunburst`, `gemini-nano-banana-2.1` og `grok-imagine-image-2.0` genererer og redigerer billeder. De er ikke chatmodeller, så de vises aldrig i `/models` eller model-endpointet,
og `opencode/<model-id>` vælger dem ikke. Kald dem på deres native API med en Console-nøgle, eller lad OpenCodes
[`generate_image`](/tools#image-generate)-værktøj bruge en billedmodel ved at angive
`experimental.image_generate.model`, f.eks. `opencode/gpt-image-2.5-sunburst`.

```bash
curl https://opencode.ai/inference/openai/v1/images/generations \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2.5-sunburst",
    "prompt": "A mountain at sunrise",
    "size": "1024x1024"
  }'
```

Google tager sine native `contents` og `generationConfig`, og xAI sine native valgmuligheder som `resolution` og
`quality`. OpenAI Images og xAI Images accepterer også redigeringer på `/images/edits`.

### Embedding-modeller

`text-embedding-3-small`, `qwen3-embedding-8b` og de øvrige embedding-modeller i tabellen ovenfor omdanner tekst til
vektorer. OpenCode bruger dem ikke til chat, så de vises aldrig i `/models`, og gratisniveauet omfatter dem ikke.
[Go](/console/go#embedding-models) omfatter nogle af dem. Kald dem på OpenAIs Embeddings-API med en Console-nøgle.

```bash
curl https://opencode.ai/inference/openai/v1/embeddings \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "text-embedding-3-small",
    "input": ["hello world", "goodbye"]
  }'
```

- `input` tager en streng eller et array af strenge. `data` returnerer én vektor pr. input i samme rækkefølge.
- `dimensions` forkorter vektorerne på modeller, der understøtter det, f.eks. `text-embedding-3-small`.
- `encoding_format: "base64"` returnerer vektorerne base64-kodede i stedet for som floats.
- Hvert input skal passe i modellens kontekstvindue.
- Svaret angiver `usage.cost` som enhver inferensanmodning. Se [Omkostning](/console/api/inference#cost).

Vektorer fra forskellige modeller kan ikke sammenlignes, så brug samme model til at danne embeddings for dine dokumenter og forespørgsler. En [tilsluttet udbyder](/console/api/providers#endpoints) stiller sine egne embeddingmodeller til rådighed på `/embeddings`.

## Baggrund

Der findes mange modeller, men kun få fungerer godt som kodningsagenter. Udbydere varierer også i konfiguration,
ydeevne og kvalitet, så en model, der tilgås gennem en gateway som OpenRouter, kan yde anderledes.

<Callout type="tip">Vi testede en udvalgt gruppe modeller og udbydere, der fungerer godt med OpenCode.</Callout>

Sådan sammensatte vi kataloget:

1. Vi testede en række udvalgte modeller og talte med teamene bag dem om, hvordan modellerne bedst køres.
2. Vi samarbejdede med udbyderne om at sikre, at modellerne blev leveret korrekt.
3. Vi benchmarkede hver kombination af model og udbyder for at sammensætte en liste, vi trygt kan anbefale.

Console er en AI-gateway, der giver dig adgang til disse modeller.

## Mål

Vi byggede Console for at:

1. **Benchmarke** de bedste modeller og udbydere til kodningsagenter.
2. Tilbyde **den højeste kvalitet** uden at nedgradere ydeevnen eller route til billigere udbydere.
3. Videregive **prisfald** ved at sælge til kostpris med avance kun til at dække behandlingsgebyrer.
