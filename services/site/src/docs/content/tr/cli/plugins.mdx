---
title: "CLI eklentileri"
description: "TUI eklentilerini OpenCode yapılandırmanızdan CLI'ya yükleyin. CLI'ya özel eklentileri ve seçeneklerini cli.json dosyasında tanımlayın."
---

`opencode.json(c)` içinde yapılandırılan ve bir TUI bileşeni sunan eklentiler CLI tarafından otomatik olarak yüklenir. Eklenti geliştirmeyi öğrenmek için
[Eklenti geliştirme](/build/plugins) sayfasına bakın. Aynı paketi `cli.json` dosyasına eklemeniz gerekmez. CLI,
etkin eklenti listesini bağlı olduğu OpenCode sunucusundan alır; bu nedenle sunucu uzakta olsa da çalışır.

Yalnızca CLI'ya özel eklentiler için `cli.json` kullanın. Bu eklentiler terminalde yerel olarak çalışır ve CLI uzak bir sunucuya bağlandığında da etkin kalır:

```json title="cli.json"
{
  "plugins": [
    "opencode.example",
    "opencode.example@1.0.0",
    "@example/opencode-tui",
    "@example/opencode-tui@1.0.0",
    "./plugins/status",
    "../plugins/status",
    "/home/user/plugins/status",
    "file:///home/user/plugins/status"
  ]
}
```

Girdiler sırayla işlenir. Eşleşen eklentileri devre dışı bırakmak için bir kimliğin veya joker karakterin başına `-` ekleyin:

```json title="cli.json"
{
  "plugins": ["*", "-opencode.notifications", "-team.*"]
}
```

Eklenti seçeneklerini nesne biçimiyle iletin:

```json title="cli.json"
{
  "plugins": [
    {
      "package": "@example/opencode-tui",
      "options": {
        "compact": true
      }
    }
  ]
}
```

OpenCode ayrıca genel yapılandırma dizinindeki ve projedeki `.opencode` dizinlerindeki eklentileri de keşfeder. Her eklenti, yayımlanmış bir paketle aynı düzeni kullanır; sunucu ve TUI giriş noktaları bir arada tutulur.

```text title="Plugin discovery paths"
<global-config>/plugins/status/index.ts
<global-config>/plugins/status/tui.ts
<project>/.opencode/plugins/status/index.ts
<project>/.opencode/plugins/status/tui.ts
```

Keşfedilen eklentiler `@opencode/plugin/tui` paketini doğrudan içe aktarabilir; OpenCode paketi çalışma zamanında çözer. Örnekler için
[TUI eklentileri geliştirme](/build/plugins/cli) sayfasına bakın.
