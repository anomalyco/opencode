Her komut, tüm bayrak listesi için `--help` kabul eder, örneğin `opencode run --help`. Sunucuya dayanan bazı komutlar özel bir sunucu çalıştırmak için `--standalone` veya belirli bir sunucuyu hedeflemek için `--server <url>` kabul eder; desteklenen bayraklar için komutun yardımına bakın.

## run

Etkileşimli arayüzü açmadan bir mesaj gönderir ve yanıtı yazdırır.

```bash
$ opencode run "Explain this repository"
```

### CI

CI'da sağlayıcı API anahtarını gizli değer olarak verin. Anahtarın özel sunucuya ulaşması için bağımsız modu kullanın.
Örneğin bu GitHub Actions işi, çalışma dizinine alınan depoyu inceler:

```yaml
name: OpenCode review
on: [pull_request]

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm install --global @opencode/cli
      - run: opencode run --standalone --model anthropic/claude-sonnet-5-5 "Review this repository for correctness and summarize any issues."
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
```

Bir model seçin.

```bash
$ opencode run --model anthropic/claude-sonnet-5-5 "Refactor parseToken"
```

Son oturumu sürdürün.

```bash
$ opencode run --continue "Now handle the expired case"
```

Betikler için satır sonuyla ayrılmış JSON üretin.

```bash
$ opencode run --format json "List the TODO comments"
```

Mesaja dosya ekleyin.

```bash
$ opencode run --file src/server.ts --file src/client.ts "Review these for bugs"
```

Belirli bir agent ile çalıştırın.

```bash
$ opencode run --agent build "Fix the failing test"
```

Belirli bir oturumu sürdürün.

```bash
$ opencode run --session ses_4f2a1c "Check edge cases"
```

Açıkça reddedilmeyen izinleri otomatik onaylayın.

```bash
$ opencode run --auto "Fix the failing test"
```

Oturumu arşivlenmiş olarak oluşturun; böylece betik veya CI çalışmaları oturum listelerinin ve gelen kutusunun dışında kalır. Oturum yine de vardır: `opencode session list` onu içerir ve kimliğiyle açabilirsiniz.

```bash
$ opencode run --archived "Review this diff"
```

Tüm alt komutları ve bayrakları görüntüleyin.

```bash
$ opencode run --help
```

```bash
$ opencode mini --session ses_4f2a1c
```

Tüm alt komutları ve bayrakları görüntüleyin.

```bash
$ opencode mini --help
```

## session

Oturumları yönetir.

```bash
$ opencode session list
```

Listeyi sınırlayın ve JSON yazdırın.

```bash
$ opencode session list --max-count 20 --format json
```

Bir oturumu ve alt oturumlarını silin.

```bash
$ opencode session delete ses_9c1b08
```

Oturum verilerini JSON olarak dışa aktarın.

```bash
$ opencode session export ses_4f2a1c
```

Dışa aktarırken hassas konuşma dökümü ve dosya verilerini gizleyin.

```bash
$ opencode session export ses_4f2a1c --sanitize
```

Oturum verilerini bir JSON dosyasından veya URL'den içe aktarın.

```bash
$ opencode session import session.json
```

Belirli bir dizine içe aktarın.

```bash
$ opencode session import session.json --directory ~/code/project
```

Tüm alt komutları ve bayrakları görüntüleyin.

```bash
$ opencode session --help
```

## auth

AI sağlayıcılarını ve kimlik bilgilerini yönetir.

```bash
$ opencode auth list
```

Bunları JSON olarak listeleyin.

```bash
$ opencode auth list --format json
```

Bir sağlayıcıda oturum açın.

```bash
$ opencode auth login anthropic
```

Belirli bir kimlik doğrulama yöntemiyle oturum açın.

```bash
$ opencode auth login anthropic --method key
```

Kaydedilmiş bir hesabın oturumunu kapatın.

```bash
$ opencode auth logout anthropic work
```

Bir entegrasyon için etkin hesabı değiştirin.

```bash
$ opencode auth switch anthropic work
```

Kaydedilmiş kimlik bilgilerini dışa aktarın ve başka bir makinede içe aktarın. Dosya gizli değerler içerir.

```bash
$ opencode auth export anthropic > credentials.json
$ opencode auth import credentials.json
```

Tüm alt komutları ve bayrakları görüntüleyin.

```bash
$ opencode auth --help
```

## mcp

MCP (Model Context Protocol) sunucularını yönetir.

```bash
$ opencode mcp list
```

Uzak bir sunucu ekleyin.

```bash
$ opencode mcp add context7 --url https://mcp.context7.com/mcp
```

Genel yapılandırmaya yerel bir sunucu ekleyin.

```bash
$ opencode mcp add everything --global -- npx -y @modelcontextprotocol/server-everything
```

Bir ortam değişkeniyle yerel bir sunucu ekleyin.

```bash
$ opencode mcp add everything --env LOG_LEVEL=debug -- npx -y @modelcontextprotocol/server-everything
```

Bir başlıkla uzak bir sunucu ekleyin.

```bash
$ opencode mcp add context7 --url https://mcp.context7.com/mcp --header CONTEXT7_API_KEY=secret
```

OAuth destekli uzak bir sunucuda kimlik doğrulayın.

```bash
$ opencode mcp auth sentry
```

Bir sunucu için saklanan OAuth kimlik bilgilerini kaldırın.

```bash
$ opencode mcp logout sentry
```

Tüm alt komutları ve bayrakları görüntüleyin.

```bash
$ opencode mcp --help
```

## plugin

Eklentileri yönetir.

```bash
$ opencode plugin list
```

Yerleşik sunucu eklentilerini dahil edin.

```bash
$ opencode plugin list --builtin
```

Bir eklenti kurun ve genel yapılandırmaya ekleyin.

```bash
$ opencode plugin add @example/opencode-tui
```

Paket eklentilerini güncellemeler için denetleyin.

```bash
$ opencode plugin check
```

Paket eklentilerini güncelleyin.

```bash
$ opencode plugin update
```

Genel yapılandırmadan bir eklenti kaldırın.

```bash
$ opencode plugin remove @example/opencode-tui
```

Tüm alt komutları ve bayrakları görüntüleyin.

```bash
$ opencode plugin --help
```

## serve

API ve web sunucusunu başlatır. Bkz. [Web](/cli/web).

```bash
$ opencode serve
```

Sunucuyu tüm ağ arayüzlerinde sabit bir portta dinleyecek şekilde başlatın.

```bash
$ opencode serve --hostname 0.0.0.0 --port 4096
```

Başka bir kaynaktaki tarayıcı istemcisine izin verin.

```bash
$ opencode serve --cors https://app.example.com
```

Tüm alt komutları ve bayrakları görüntüleyin.

```bash
$ opencode serve --help
```

## pair

Bir tarayıcıyı veya uygulamayı sunucuda oturum açtıran tek kullanımlık bağlantıları ve ilkinin bir QR kodunu yazdırır.
Bağlantılar 5 dakika sonra sona erer ve bir kez çalışır.

```bash
$ opencode pair
```

Bağlantılarda harici bir URL kullanın.

```bash
$ opencode pair --url https://dev.example.com
```

Bir OpenTunnel uzak adresi üzerinden her yerden eşleştirin. Bu, sunucuyu internete açar; bu nedenle uzak erişimi ilk
etkinleştirdiğinde bunu açıklar ve kabul etmenizi ister. Bkz. [Uzak erişim](/cli/web#remote-access).

```bash
$ opencode pair --remote
```

İstem göstermeden kabul edin; örneğin terminali olmayan bir betikte.

```bash
$ opencode pair --remote --yes
```

Tüm alt komutları ve bayrakları görüntüleyin.

```bash
$ opencode pair --help
```

## service

Arka plan sunucusunu yönetir. Bkz. [Web](/cli/web).

```bash
$ opencode service start
```

Yeniden başlatın.

```bash
$ opencode service restart
```

Durumunu gösterin.

```bash
$ opencode service status
```

Durdurun.

```bash
$ opencode service stop
```

Bir ayarı okuyun.

```bash
$ opencode service get hostname
```

Bir ayar belirleyin.

```bash
$ opencode service set hostname 0.0.0.0
```

Ek bir CORS kaynağına izin verin.

```bash
$ opencode service set cors https://app.example.com
```

Sunucu sürecine bir ortam değişkeni iletin.

```bash
$ opencode service set env OPENCODE_LOG_LEVEL DEBUG
```

Bir ayarı varsayılanına sıfırlayın.

```bash
$ opencode service unset hostname
```

Tüm alt komutları ve bayrakları görüntüleyin.

```bash
$ opencode service --help
```

## reload

Sunucuyu yeniden başlatmadan yapılandırmayı yeniden yükler. Çalışan oturumlar bir sonraki adımdan itibaren yeniden yüklenen hizmetleri kullanır.

```bash
$ opencode reload
```

## api

Çalışan sunucuya bir istek yapar.

```bash
$ opencode api GET /api/session
```

Bir sorgu parametresiyle bir işlem kimliği çağırın.

```bash
$ opencode api session.list --param limit=10
```

Bir JSON gövdesi gönderin.

```bash
$ opencode api session.create --data '{"title": "New session"}'
```

Bir istek başlığı ekleyin.

```bash
$ opencode api GET /api/session -H "accept: application/json"
```

Tüm alt komutları ve bayrakları görüntüleyin.

```bash
$ opencode api --help
```

```bash
$ opencode acp
```

Tüm alt komutları ve bayrakları görüntüleyin.

```bash
$ opencode acp --help
```

## debug

Hata ayıklama ve sorun giderme araçları sunar.

```bash
$ opencode debug agents
```

Yapılandırma kaynaklarını listeleyin.

```bash
$ opencode debug config
```

Çalışan arka plan sunucusunun bir heap anlık görüntüsünü yazın ve yolunu yazdırın.

```bash
$ opencode debug heap-dump
```

Anlık görüntüyü seçtiğiniz bir dizine yazın.

```bash
$ opencode debug heap-dump --directory ./snapshots
```

Genel yolları gösterin.

```bash
$ opencode debug paths
```

Tek bir yolu yazdırın.

```bash
$ opencode debug paths db
```

Tüm alt komutları ve bayrakları görüntüleyin.

```bash
$ opencode debug --help
```

## upgrade

OpenCode'u en son veya belirli bir sürüme yükseltir. Takma ad: `update`.

```bash
$ opencode upgrade
```

Belirli bir paket yöneticisiyle belirli bir sürüme yükseltin.

```bash
$ opencode upgrade 2.0.21 --method bun
```

Tüm alt komutları ve bayrakları görüntüleyin.

```bash
$ opencode upgrade --help
```

## uninstall

Arka plan hizmetlerini durdurur, genel önbelleği kaldırır ve OpenCode'u kaldırır. Oturum verileri, yapılandırma ve
durum kaldırılmaz.

```bash
$ opencode uninstall
```

Nelerin kaldırılacağını önizleyin.

```bash
$ opencode uninstall --dry-run
```

Tüm alt komutları ve bayrakları görüntüleyin.

```bash
$ opencode uninstall --help
```
