---
title: "Tuş atamaları"
description: "OpenCode CLI tuş atamalarını cli.json içinde özelleştirin ve her komutun kimliğine ve varsayılan atamasına bakın."
---

Atamaları `cli.json` içinde özelleştirin:

```json title="cli.json"
{
  "keybinds": {
    "leader": "ctrl+space",
    "command.palette.show": "ctrl+k",
    "app.exit": ["ctrl+c", "ctrl+d"],
    "app.debug": false
  },
  "leader": {
    "timeout": 1500
  }
}
```

Tek bir tuş için dize kullanın:

```json
{
  "keybinds": {
    "command.palette.show": "ctrl+k"
  }
}
```

Alternatifleri virgülle ayırın:

```json
{
  "keybinds": {
    "app.exit": "ctrl+c,ctrl+d"
  }
}
```

Bir atamayı `"none"` veya `false` ile devre dışı bırakın:

```json
{
  "keybinds": {
    "app.debug": "none",
    "help.show": false
  }
}
```

Olay davranışı için nesne kullanın:

```json
{
  "keybinds": {
    "prompt.paste": {
      "key": "ctrl+v",
      "preventDefault": false
    }
  }
}
```

`leader` varsayılan olarak `ctrl+x` olur. Başka bir atamadaki `<leader>` o tuşa başvurur.

```json
{
  "keybinds": {
    "leader": "ctrl+space",
    "model.list": "<leader>m"
  },
  "leader": {
    "timeout": 2000
  }
}
```

Bilinmeyen komut kimlikleri yok sayılır.

## Mini

`app.clear` komutu yalnızca [`opencode mini`](/cli) içinde çalışır. Görünür ekranı temizlemek ve promptu yeniden çizmek için `ctrl+l` tuşlarına basın. Terminal kaydırma geçmişini korur.

```json title="cli.json"
{
  "keybinds": {
    "app.clear": "ctrl+l"
  }
}
```

| Kimlik      | Varsayılan | Açıklama       |
| ----------- | ---------- | -------------- |
| `app.clear` | `ctrl+l`   | Ekranı temizle |

## Diff görüntüleyici

**All**, **Committed**, **Uncommitted** veya (bir oturum içinde) **Last turn** seçmek için `d` (`diff.switch_source`) tuşuna basın veya karşılaştırma dalını değiştirmek için **Base** seçeneğini seçin. Seçimler TUI çıkana kadar hatırlanır. Başlangıç kapsamını [`cli.json` içindeki `diffs.source`](/cli/config#diffs) ile ayarlayın.

Kaydırma, sayfalama ve başlangıç/son kısayolları her zaman diff'i denetler. Klavye odağı değiştirme yoktur: dosyaları açmak için tıklayın, klasörleri genişletmek veya daraltmak için tıklayın ve dosya ağacında kaydırmak için fare tekerleğini kullanın.

Dosyalar arasında geçmek için `n` / `p` veya `alt+down` / `alt+up` (macOS'ta Option) kullanın. Diff görüntüleyici içinde Alt kısayolları oturum sekmeleri yerine dosyalar arasında gezinir.

Bir dosyayı incelendi olarak işaretlemek ve yama gövdesini daraltmak için `m` tuşuna basın. Tüm dosyalar görünümünde işareti kaldırmak ve yamayı yeniden açmak için `m` tuşuna tekrar basın. Tek dosya görünümü, incelendi olarak işaretlerken otomatik olarak sonraki dosyaya geçer, ancak başa dönmek yerine son dosyada kalır. Bir dosyanın işaretini kaldırmak asla ilerlemez.

**Mark complete** (veya **Mark incomplete**) için kenar çubuğundaki bir dosyaya veya onun diff başlığına sağ tıklayın. Bu, `m` ile aynı incelendi durumunu değiştirir. Menüsünden farklı bir dosyayı tamamlamak o dosyayı seçmez ve okunmakta olan dosyada ilerlemez.

`diff.help` için Shift içeren alternatifler, `?` tuşuna bastığınızda Shift'i de bildiren terminalleri destekler.

| ----------------------------- | ---------- | ------------------- |
| `composer.subagent.up`        | `up`       | Önceki subagent     |
| `composer.subagent.down`      | `down`     | Sonraki subagent    |
| `composer.subagent.select`    | `return`   | Subagent'a git      |
| `composer.subagent.interrupt` | `ctrl+d`   | Subagent'ı kes      |
| `composer.shell.up`           | `up`       | Önceki kabuk        |
| `composer.shell.down`         | `down`     | Sonraki kabuk       |
| `composer.shell.select`       | `return`   | Kabuk çıktısını görüntüle |
| `composer.shell.kill`         | `ctrl+d`   | Kabuk komutunu sonlandır |
| `composer.terminal.up`        | `up,k`     | Önceki terminal     |
| `composer.terminal.down`      | `down,j`   | Sonraki terminal    |
| `composer.terminal.select`    | `return`   | Terminal seç        |

**Shell** sekmesinde çalışan bir komutu seçip yakalanan stdout ve stderr'i görüntülemek için **Enter** tuşuna basın veya komuta tıklayın.
Kaydırmak için **↑/↓**, **Page Up/Down** veya **Home**, yeni çıktıyı izlemek için **End**, komutu durdurmadan dönmek için **Esc** kullanın.
Görüntüleyici son çıktıyı gösterir ve çıkıştan sonra açık kalır; bir dosyaya yönlendirilen çıktı dahil edilmez.
