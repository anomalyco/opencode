---

OpenCode, `write`, `edit` veya `patch` araçları dosyaları değiştirdikten sonra onları biçimlendirebilir. Biçimlendiriciler
varsayılan olarak kapalıdır; bu nedenle onları yapılandırmanızda etkinleştirin:

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "formatter": true,
}
```

## Etkinleştirme

Tüm yerleşik biçimlendiricileri etkinleştirmek için `formatter` değerini `true` yapın. OpenCode bir yerleşik biçimlendiriciyi
yalnızca çalıştırılabilir dosyası ve projeye özgü gereksinimleri varsa çalıştırır.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "formatter": true,
}
```

Nesne biçimi de yerleşik biçimlendiricileri etkinleştirir; ayrıca bunların ayarlarını değiştirmenize veya özel
biçimlendiriciler eklemenize olanak tanır. Boş nesne devralınan ayarları korur; `true` ise ayarları yerleşik değerlere döndürür.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "formatter": {},
}
```

ve çalıştırmasını sağlar:

```jsonc title="opencode.jsonc"
{
  "formatter": true,
}
```

## Özelleştirme

Yerleşik bir biçimlendiriciyi değiştirmek veya özel bir biçimlendirici tanımlamak için adlandırılmış bir girdi ekleyin. Özel
bir biçimlendiricinin çalışması için hem `command` hem de `extensions` gerekir.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "formatter": {
    "prettier": {
      "environment": {
        "NODE_ENV": "development",
      },
      "extensions": [".js", ".ts"],
    },
    "deno-markdown": {
      "command": ["deno", "fmt", "$FILE"],
      "extensions": [".md"],
    },
  },
}
```

| Alan | Tür | Davranış |
| --- | --- | --- |
| `disabled` | `boolean` | `true` olduğunda adlandırılmış biçimlendiriciyi kaldırır. |
| `command` | `string[]` | Yerleşik komutun yerini alır veya özel bir komut tanımlar. |
| `environment` | `Record<string, string>` | Üst ortamı koruyarak ortam değişkenleri ekler. |
| `extensions` | `string[]` | Yerleşik uzantı listesinin yerini alır veya özel listeyi tanımlar. Baştaki noktayı dahil edin. |

Tüm alanlar isteğe bağlıdır. Yerleşik bir girdi belirtilmeyen değerleri devralır; komutu veya uzantısı olmayan yeni bir
girdi ise çalışamaz.

```jsonc title="opencode.jsonc"
{
  "formatter": {
    "prettier": {
      "extensions": [".md", ".mdx"],
    },
  },
}
```

## Komutlar

`command` bir kabuk komut dizesi değil, argüman dizisidir. OpenCode `$FILE` yerine dosyanın mutlak yolunu koyar ve komutu
etkin proje dizininden çalıştırır.

```jsonc title="opencode.jsonc"
{
  "formatter": {
    "custom": {
      "command": ["custom-fmt", "--write", "$FILE"],
      "extensions": [".custom"],
    },
  },
}
```

## Eşleştirme

OpenCode dosyanın son uzantısını `extensions` ile karşılaştırır. Eşleştirme büyük/küçük harfe duyarlıdır ve `.part.md`
gibi bileşik girdiler `notes.part.md` ile eşleşmez; çünkü onun son uzantısı `.md`dir.

```jsonc title="opencode.jsonc"
{
  "formatter": {
    "markdown": {
      "command": ["deno", "fmt", "$FILE"],
      "extensions": [".md"],
    },
  },
}
```

Birden fazla biçimlendirici eşleştiğinde OpenCode onları kayıt sırasına göre dener ve ilk başarılı komuttan sonra durur.
Yerleşikler kendi yerleşik sıralarını korur; özel girdiler nesne sırasına göre gelir. Biri başarısız olursa OpenCode hatayı
günlüğe yazar ve bir sonraki eşleşmeyi dener.

```jsonc title="opencode.jsonc"
{
  "formatter": {
    "preferred": {
      "command": ["preferred-fmt", "$FILE"],
      "extensions": [".foo"],
    },
    "fallback": {
      "command": ["fallback-fmt", "$FILE"],
      "extensions": [".foo"],
    },
  },
}
```

## Devre dışı bırakma

Hiçbir yapılandırma dosyası `formatter` ayarlamıyorsa biçimlendirme kapalıdır. Daha düşük öncelikli bir dosyanın
etkinleştirdiği biçimlendirmeyi kapatmak için değeri `false` yapın.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "formatter": false,
}
```

Diğerlerini açık tutup tek bir yerleşik biçimlendiriciyi kapatmak için o biçimlendiricinin girdisini devre dışı olarak işaretleyin.

```jsonc title="opencode.jsonc"
{
  "formatter": {
    "prettier": {
      "disabled": true,
    },
  },
}
```
