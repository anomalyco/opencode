title: "Effect eklentileri"
description: "Sunucu eklentilerini Effect'e özgü eklenti API'siyle yazın."
---

`@opencode/plugin/effect`, OpenCode eklenti API'sinin Effect'e özgü sürümüdür. Bağlam işlemleri Effect'ler veya Stream'ler
döndürür, geri çağırmalar Effect döndürür ve eklenti ömrü `Scope` ile temsil edilir.

OpenCode, eklentileri ve `node_modules` bağımlılıklarını yüklerken `effect` (dışa aktarılan `effect/*` alt yolları dahil)
ve `@opencode/plugin` paketlerini çalışma zamanında sağlar. Eklentinize paketlemek yerine yerel tür denetimi ve test için
bunları eş/geleştirme bağımlılığı olarak kurun.

```sh
bun add --peer @opencode/plugin effect@4.0.1
```

Otomatik yüklemek için `.opencode/plugins/` içinden bir Effect eklentisi dışa aktarın.

```ts title=".opencode/plugins/concise/index.ts"
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "example",
  effect: (ctx) =>
    Effect.gen(function* () {
      const storage = ctx.storage
      yield* storage.set("loaded", true)
    }),
})
```

Yayımlanmış paketler ve `.opencode/plugins/` dışındaki eklenti dizinleri diğer sunucu eklentileriyle aynı `plugins`
yapılandırmasını kullanır.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": [
    "opencode-acme-effect-plugin",
    "opencode-acme-effect-plugin@1.2.0",
    "@acme/opencode-effect-plugin",
    "./plugins/local-effect",
    {
      "package": "@acme/opencode-effect-plugin",
      "options": { "agent": "reviewer", "strict": true },
    },
  ],
}
```

Etkinleştirme, paket çözümleme ve yapılandırma önceliği için [Eklentileri yapılandırma](/plugins) sayfasına bakın.

```ts title="plugins/local-effect/index.ts"
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "local-effect",
  effect: (ctx) =>
    Effect.gen(function* () {
      yield* Effect.logInfo("Effect plugin loaded", { version: ctx.app.version })
    }),
})
```

## Yaşam döngüsü

`effect`, eklenti yüklendiğinde çalışır. Eklenti yeniden yüklendiğinde veya devreden çıkarıldığında kapsamı kapanır; kayıtlar, kapsama bağlı fiber'lar ve sonlandırıcılar birlikte serbest bırakılır.

```ts
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "lifecycle",
  effect: (ctx) =>
    Effect.gen(function* () {
      yield* Effect.logInfo("loaded", { version: ctx.app.version })
      yield* Effect.addFinalizer(() => Effect.logInfo("unloaded"))
    }),
})
```

Arka plan işleri için kapsama bağlı fiber'lar kullanın. Eklenti kapsamı kapatılıp kaynaklar temizlenirken fiber durdurulur.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const storage = ctx.storage
    yield* Effect.repeat(
      storage.set("heartbeat", { time: Date.now() }),
      { schedule: Schedule.spaced("1 minute") },
    ).pipe(Effect.forkScoped)
  }),
```

### Bağlam

Bağlam, bağlı OpenCode sunucusu için Effect istemcisini ve eklentiye özgü dönüşümleri, kancaları, depolamayı, yeniden
yüklemeleri ve seçenekleri sunar. OpenCode'un özel Core hizmetlerini sunmaz.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const plugins = ctx.plugin
    const active = yield* plugins.list().pipe(Effect.orDie)
    yield* Effect.logInfo("active plugins", { count: active.data.length })
  }),
```

Eklenti tanımı ve eksiksiz bağlam şu şekilde bildirilir.

```ts
interface Context {
  readonly app: App
  readonly location: Location.Info
  readonly options: PluginOptions
  readonly agent: AgentDomain
  readonly aisdk: AISDKDomain
  readonly command: CommandDomain
  readonly event: EventDomain
  readonly experimental: {
    readonly terminal: Pick<ExperimentalApi<unknown>["persistentPty"], "read">
    readonly generate: GenerateApi<unknown>
  }
  readonly integration: IntegrationDomain
  readonly mcp: MCPDomain
  readonly model: ModelDomain
  /** @deprecated Use `experimental.generate.text`. */
  readonly generate: Pick<ExperimentalGenerateApi<unknown>, "text">
  readonly permission: PermissionDomain
  readonly plugin: Pick<PluginApi<unknown>, "list">
  readonly provider: ProviderDomain
  readonly reference: ReferenceDomain
  readonly rpc: RpcDomain
  readonly session: SessionDomain
  readonly shell: ShellDomain
  readonly skill: SkillDomain
  readonly storage: StorageDomain
  readonly tool: ToolDomain
  readonly vcs: VcsDomain
  readonly websearch: WebSearchDomain
  readonly worktree: WorktreeDomain
}

interface Plugin<R = Scope.Scope> {
  readonly id: string
  readonly effect: (context: Context) => Effect.Effect<void, never, R>
}
```

### Seçenekler

Seçenekleri `opencode.json(c)` içinde nesne biçimiyle iletin.

```jsonc title="opencode.jsonc"
{
  "plugins": [
    {
      "package": "./plugins/company-effect",
      "options": { "strict": true },
    },
  ],
}
```

Seçenekleri `ctx.options` üzerinden okuyun. Bilinmeyen değerleri kullanmadan önce daraltın.

```ts title="plugins/company-effect/index.ts"
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "company",
  effect: (ctx) =>
    Effect.gen(function* () {
      const strict = ctx.options.strict === true
      yield* Effect.logInfo("company plugin configured", { strict })
    }),
})
```

## Dönüşümler

Dönüşümler durumu bir düzenleyici üzerinden eşzamanlı düzenler. OpenCode dönüşümleri her alanda kayıt sırasına göre
uygular. Kaynaklar önce sağlayıcıları ve değişmez model tanımlarını katkı olarak verir; ardından model dönüşümleri etkin
sağlayıcıların adaylarını düzenler. Kaydı yield etmek onu eklenti kapsamında tutar.

```ts title="plugins/models-effect/index.ts"
import { Model, Plugin, Provider } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "company.models",
  effect: (ctx) =>
    Effect.gen(function* () {
      const providerID = Provider.ID.make("acme")
      const models = [{ ...Model.Info.default(providerID, Model.ID.make("reasoner")), name: "Acme Reasoner" }]
      yield* ctx.provider.transform((editor) => {
        editor.add({
          info: {
            ...Provider.Info.empty(providerID),
            name: "Acme",
            activation: "enabled",
            package: "@opencode/ai/providers/openai-compatible",
            settings: { baseURL: "http://127.0.0.1:8000/v1" },
          },
          models,
        })
      })
    }),
})
```

Bir model dönüşümü, etkin sağlayıcının eksiksiz aday koleksiyonu genelinde politika uygulayabilir.

```ts title="plugins/model-budget-effect/index.ts"
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.model.transform((editor) => {
      editor
        .list()
        .filter((model) => model.cost.some((tier) => tier.output > 20))
        .forEach((model) => {
          editor.remove(model.providerID, model.id)
        })
    })
  }),
```

Bir dönüşümün kullandığı harici durum değiştiğinde `reload` çağırın. Burada `loadFromSource()`
`{ info: Provider.Info, models: readonly Model.Info[] }` girdileri döndürür; sağlayıcı yeniden yüklemeleri ayrıca tüm
model sonucunu geçersiz kılar.

```ts title="plugins/models-effect/index.ts"
effect: (ctx) =>
  Effect.gen(function* () {
    const provider = ctx.provider
    const source = { providers: yield* loadFromSource() }

    yield* provider.transform((editor) => {
      source.providers.forEach((provider) => editor.add(provider))
    })

    yield* Effect.repeat(
      Effect.gen(function* () {
        source.providers = yield* loadFromSource()
        yield* provider.reload()
      }),
      { schedule: Schedule.spaced("1 minute") },
    ).pipe(Effect.forkScoped)
  }),
```

## API

### Agent

Tüm agent'ları okuyun veya kimliğiyle bir tane getirin. İstemci yanıtları çözümlenmiş konumu ve şema verilerini içerir.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const agent = ctx.agent
    const agents = yield* agent.list().pipe(Effect.orDie)
    const build = yield* agent.get({ agentID: Agent.ID.make("build") }).pipe(Effect.orDie)
    yield* Effect.logInfo("agents", { count: agents.data.length, build: build.data.name })
  }),
```

Agent'ları dönüştürün veya yeniden yükleyin.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const agent = ctx.agent
    yield* agent.transform((editor) => {
      editor.default("build")
      editor.update("build", (item) => (item.description = "Builds features and fixes bugs"))
      editor.remove("legacy")
    })
    yield* agent.reload()
  }),
```

Şema: [`Agent.Info`](/api#schema-Agent.Info).

```ts
interface AgentEditor {
  list(): readonly Types.DeepMutable<Agent.Info>[]
  get(id: string): Types.DeepMutable<Agent.Info> | undefined
  default(id: string | undefined): void
  update(id: string, update: (agent: Types.DeepMutable<Agent.Info>) => void): void
  remove(id: string): void
}

interface AgentDomain extends AgentApi<unknown> {
  readonly transform: Transform<AgentEditor>
  readonly reload: () => Effect.Effect<void>
}
```

### Sağlayıcılar

Kullanılabilir sağlayıcıları okuyun veya bir sağlayıcının üst verisini kimliğiyle inceleyin.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const provider = ctx.provider
    const providers = yield* provider.list().pipe(Effect.orDie)
    const anthropic = yield* provider.get({ providerID: Provider.ID.make("anthropic") }).pipe(Effect.orDie)
    yield* Effect.logInfo("providers", {
      providers: providers.data.length,
      anthropic: anthropic.data.name,
    })
  }),
```

Sağlayıcı dönüşümleri sağlayıcı ayarlarını ve kaynak tanımlarını düzenler. Düzenleyici okumaları etkin olmayan
sağlayıcıları içerir ve değişmez tanımları sunar; `models.update` bir kaynak modelin sahiplenilmiş kopyasını düzenler.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.provider.transform((editor) => {
      editor.update("anthropic", (provider) => {
        provider.headers = { ...provider.headers, "x-company": "engineering" }
      })
      editor.models.update("anthropic", "claude-sonnet-5-5", (model) => (model.name = "Team Sonnet"))
      editor.models.remove("anthropic", "legacy-model")
      editor.remove("legacy-provider")
    })
  }),
```

Bir kaynak envanterini `models.set` ile değiştirin, ardından yakalanan tanımları değiştikten sonra yeniden yükleyin.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const provider = ctx.provider
    const source = { models: yield* loadModels() }
    yield* provider.transform((editor) => editor.models.set("acme", source.models))
    source.models = yield* loadModels()
    yield* provider.reload()
  }),
```

Hesaba özgü keşif için envanteri yüklemek üzere kullanılan bağlantıyı `sourceConnection` olarak iletin. Eklentiniz
yenilenmiş envanterini yayımlayana kadar başka bir bağlantı seçiliyken OpenCode o sağlayıcıyı dışlar.

{/* prettier-ignore */}
```ts
const connection = yield* ctx.integration.connection.active("acme")
if (!connection) return
const inventory = yield* loadInventory(connection)
yield* ctx.provider.transform((editor) => {
  editor.add({ info: inventory.provider, models: inventory.models, sourceConnection: connection })
})
```

Şemalar: [`Provider.Info`](/api#schema-Provider.Info), [`Model.Info`](/api#schema-Model.Info).

```ts
interface ProviderRecord {
  readonly provider: Provider.Info
  readonly models: ReadonlyMap<string, Model.Info>
  readonly sourceConnection?: ConnectionInfo
}

interface ProviderEditor {
  list(): readonly ProviderRecord[]
  get(providerID: string): ProviderRecord | undefined
  add(input: { info: Provider.Info; models: readonly Model.Info[]; sourceConnection?: ConnectionInfo }): void
  update(providerID: string, update: (provider: Types.DeepMutable<Provider.Info>) => void): void
  remove(providerID: string): void
  readonly models: {
    set(providerID: string, models: readonly Model.Info[]): void
    update(providerID: string, modelID: string, update: (model: Types.DeepMutable<Model.Info>) => void): void
    remove(providerID: string, modelID: string): void
  }
}

interface ProviderDomain extends ProviderApi<unknown> {
  readonly transform: Transform<ProviderEditor>
  readonly reload: () => Effect.Effect<void>
}
```

### Modeller

Kullanılabilir modelleri ve varsayılan seçimi okuyun.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const model = ctx.model
    const models = yield* model.list().pipe(Effect.orDie)
    const selected = yield* model.default().pipe(Effect.orDie)
    yield* Effect.logInfo("models", { count: models.data.length, selected: selected.data?.name })
  }),
```

Model dönüşümleri etkin sağlayıcının eksiksiz aday koleksiyonunu düzenler. Devre dışı adaylar tüm dönüşümler bitene kadar
düzenlenebilir kalır; `update` bir modeli yalnızca kullanılabilir bir sağlayıcı altında ekleyebilir.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.model.transform((editor) => {
      editor.list("anthropic").forEach((model) => {
        editor.update(model.providerID, model.id, (draft) => {
          draft.enabled = draft.capabilities.tools
        })
      })
      editor.default.set("anthropic", "claude-sonnet-5-5")
      editor.remove("anthropic", "legacy-model")
    })
  }),
```

Geri çağırmalar ham model geçersiz kılmalarını düzenler. OpenCode sonucu işlerken sağlayıcı varsayılanları bir kez
birleştirilir; değişmemiş okumalar o sonucu yeniden kullanır. `editor.provider`, model dönüşümü çıktısı yerine etkin
olmayan şablonlar dahil değişmez kaynak tanımlarını okur.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const model = ctx.model
    yield* model.transform((editor) => {
      const source = editor.provider.get("anthropic")?.models.get("claude-sonnet-5-5")
      if (!source) return
      editor.update("anthropic", source.id, (draft) => {
        draft.limit.context = Math.min(draft.limit.context, source.limit.context)
      })
    })
    yield* model.reload()
  }),
```

Şema: [`Model.Info`](/api#schema-Model.Info).

```ts
interface ModelEditor {
  list(providerID?: string): readonly Types.DeepMutable<Model.Info>[]
  get(providerID: string, modelID: string): Types.DeepMutable<Model.Info> | undefined
  update(providerID: string, modelID: string, update: (model: Types.DeepMutable<Model.Info>) => void): void
  remove(providerID: string, modelID: string): void
  readonly default: {
    get(): { providerID: string; modelID: string } | undefined
    set(providerID: string, modelID: string): void
  }
  readonly provider: {
    list(): readonly ProviderRecord[]
    get(providerID: string): ProviderRecord | undefined
  }
}

interface ModelDomain extends ModelApi<unknown> {
  readonly transform: Transform<ModelEditor>
  readonly reload: () => Effect.Effect<void>
}
```

### Komutlar

Geçerli konumda kullanılabilir komutları okuyun.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const command = ctx.command
    const commands = yield* command.list().pipe(Effect.orDie)
    yield* Effect.logInfo("commands", { names: commands.data.map((item) => item.name) })
  }),
```

Geçerli komut dönüşümü yalnızca ekleme yapar. Bir yürütücü oturumu, prompt eklerini ve teslim modunu alır.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const command = ctx.command
    const session = ctx.session
    yield* command.transform((editor) => {
      editor.add({
        name: "security-review",
        description: "Review changes for security issues",
        execute: (input) =>
          session.prompt({
            ...input.prompt,
            sessionID: input.sessionID,
            text: `Review these changes for security issues.\n\n${input.prompt.text}`,
            delivery: input.delivery,
          }).pipe(Effect.asVoid),
      })
    })
    yield* command.reload()
  }),
```

Şemalar: [`Command.Info`](/api#schema-Command.Info),
[`Session.Inbox.Delivery`](/api#schema-Session.Inbox.Delivery).

```ts
interface CommandInvocation {
  readonly sessionID: Session.ID

  readonly delivery: SessionInbox.Delivery
}

interface CommandDefinition {
  readonly name: string
  readonly description?: string

}

interface CommandEditor {
  add(definition: CommandDefinition): void
}

interface CommandDomain extends Pick<CommandApi<unknown>, "list"> {
  readonly transform: Transform<CommandEditor>
  readonly reload: () => Effect.Effect<void>

```

### Entegrasyonlar

Entegrasyonları okuyun ve varsa etkin kimlik bilgisini çözümleyin.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const integration = ctx.integration
    const integrations = yield* integration.list().pipe(Effect.orDie)
    const github = yield* integration.get({ integrationID: Integration.ID.make("github") }).pipe(Effect.orDie)
    const connection = yield* integration.connection.active("github")
    const credential = connection ? yield* integration.connection.resolve(connection).pipe(Effect.orDie) : undefined
    yield* Effect.logInfo("integration", {
      count: integrations.data.length,
      github: github.data.name,
      credential: credential?.type,
    })
  }),
```

Bir anahtarla bağlanın veya bağlı API üzerinden bir OAuth denemesini yürütün.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const integration = ctx.integration
    const token = yield* Config.Redacted("GITHUB_TOKEN").pipe(Effect.orDie)
    yield* integration.connect
      .key({ integrationID: Integration.ID.make("github"), key: Redacted.value(token) })
      .pipe(Effect.orDie)

    const attempt = yield* integration.oauth
      .connect({
        integrationID: Integration.ID.make("acme"),
        methodID: Integration.MethodID.make("oauth"),
      })
      .pipe(Effect.orDie)
    const status = yield* integration.oauth
      .status({
        integrationID: Integration.ID.make("acme"),
        attemptID: attempt.data.attemptID,
      })
      .pipe(Effect.orDie)
    yield* Effect.logInfo("OAuth status", { status: status.data })
  }),
```

Entegrasyonları ve kimlik doğrulama yöntemlerini dönüştürün. OAuth yöntemi geri çağırmaları Effect'tir ve kapsamlı
kaynaklar edinebilir.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const integration = ctx.integration
    yield* integration.transform((editor) => {
      editor.update("acme", (item) => (item.name = "Acme"))
      editor.method.update({
        integrationID: "acme",
        method: { id: "device", type: "oauth", label: "Sign in with Acme" },
        authorize: () =>
          Effect.succeed({
            mode: "code",
            url: "https://acme.example/device",
            instructions: "Enter the displayed code",
            callback: (code) => exchangeCode(code),
          }),
      })
    })
    yield* integration.reload()
  }),
```

Şemalar: [`Integration.Info`](/api#schema-Integration.Info), [`Integration.Method`](/api#schema-Integration.Method),
[`Connection.Info`](/api#schema-Connection.Info), [`Form.Answer`](/api#schema-Form.Answer).

```ts
type IntegrationOAuthAuthorization = {
  readonly url: string
  readonly instructions: string
  readonly expiresAt?: number
} & (
  | { readonly mode: "auto"; readonly callback: Effect.Effect<Credential.OAuth, unknown> }
  | { readonly mode: "code"; readonly callback: (code: string) => Effect.Effect<Credential.OAuth, unknown> }
)

type IntegrationOAuthMethodRegistration = {
  readonly integrationID: string
  readonly method: IntegrationOAuthMethod
  readonly authorize: (answer: Form.Answer) => Effect.Effect<IntegrationOAuthAuthorization, unknown, Scope.Scope>
  readonly refresh?: (credential: Credential.OAuth) => Effect.Effect<Credential.OAuth, unknown>
  readonly label?: (credential: Credential.OAuth) => string | undefined
}

interface IntegrationEditor {
  list(): readonly IntegrationRef[]
  get(id: string): IntegrationRef | undefined
  update(id: string, update: (integration: IntegrationRef) => void): void
  remove(id: string): void
  readonly method: {
    list(integrationID: string): readonly IntegrationMethod[]
    update(input: IntegrationMethodRegistration): void
    remove(integrationID: string, method: IntegrationMethod): void
  }
}

interface IntegrationDomain extends Omit<IntegrationApi<unknown>, "wellknown"> {
  readonly transform: Transform<IntegrationEditor>
  readonly reload: () => Effect.Effect<void>
  readonly connection: {
    readonly active: (integrationID: string) => Effect.Effect<ConnectionInfo | undefined>
    readonly resolve: (connection: ConnectionInfo) => Effect.Effect<Credential.Value | undefined, unknown>
  }
}
```

### MCP

MCP sunucularını ve güncel bağlantı durumlarını listeleyin.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const mcp = ctx.mcp
    const servers = yield* mcp.list().pipe(Effect.orDie)
    yield* Effect.logInfo("MCP servers", { count: servers.data.length })
  }),
```

Eklentiler MCP sunucularını yalnızca dönüşümler üzerinden yönetir. Bir sunucu eklemek veya değiştirmek için `editor.set`,
yapılandırmasını değiştirmek için `editor.update`, kaldırmak için `editor.remove` kullanın. Yapılandırmayı `editor.list` ve
`editor.get` ile inceleyin.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const mcp = ctx.mcp
    yield* mcp.transform((editor) => {
      const servers = editor.list()
      const docs = editor.get("docs")
      editor.set("docs", { type: "remote", url: "https://mcp.example.com" })
      editor.update("docs", (server) => (server.disabled = false))
      editor.remove("legacy")
    })
  }),
```

Bir sunucuyu devre dışı bırakmak ve bağlantısını kesmek için dönüşümde `disabled: true`, etkinleştirmek ve OpenCode'un
bağlanmasına izin vermek için `disabled: false` ayarlayın. OpenCode sunucu yaşam döngüsünü dönüştürülmüş
yapılandırmadan uzlaştırır.

Bir dönüşümün kullandığı harici durum değiştiğinde dönüşümleri yeniden uygulamak ve sunucuları uzlaştırmak için
`reload()` çağırın.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const mcp = ctx.mcp
    yield* mcp.reload()
  }),
```

Şemalar: [`Mcp.Server`](/api#schema-Mcp.Server), [`Mcp.LocalConfigEncoded`](/api#schema-Mcp.LocalConfigEncoded),
[`Mcp.RemoteConfigEncoded`](/api#schema-Mcp.RemoteConfigEncoded).

```ts
interface MCPEditor {
  list(): readonly [string, Types.DeepMutable<Mcp.ServerConfig>][]
  get(name: string): Types.DeepMutable<Mcp.ServerConfig> | undefined
  set(name: string, config: Mcp.ServerConfig): void
  update(name: string, update: (config: Types.DeepMutable<Mcp.ServerConfig>) => void): void
  remove(name: string): void
}

interface MCPDomain extends Pick<McpApi<unknown>, "list"> {
  readonly transform: Transform<MCPEditor>
  readonly reload: () => Effect.Effect<void>
}
```

### Eklentiler

Geçerli konumdaki etkin, başarısız ve çözümlenmiş eklentileri listeleyin.

```ts
effect: (ctx) =>
```

### Araçlar

Effect `Schema` ile tipli araçlar kaydedin. Yürütücü çözülmüş girdiyi alır ve tipli çıktı, görüntüleme içeriği veya üst
veri içeren bir Effect döndürür.

Düzenleyici `add`, `update` ve `remove` destekler. Dönüşüm geri çağırması eşzamanlıdır: bir Effect veya Promise
döndürmemelidir. Harici verileri kaydetmeden veya yeniden yüklemeden önce yükleyin. OpenCode etkin dönüşümleri yeni bir
düzenleyicide kayıt sırasına göre yeniden oynatır; aynı etkin araç adı için sonraki geçerli kayıt öncekinin yerini alır.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const tool = ctx.tool
    yield* tool.transform((editor) => {
      editor.namespace({
        name: "acme",
        description: "Customer account tools",
      })
      editor.add({
        name: "greeting",
        description: "Create a greeting",
        input: Schema.Struct({ name: Schema.String }),
        output: Schema.Struct({ greeting: Schema.String }),
        options: { namespace: "acme", codemode: true },
        execute: ({ name }, context) =>
          Effect.gen(function* () {
            yield* context.progress({ status: "greeting" })
            return { output: { greeting: `Hello ${name}!` } }
          }),
      })
    })
  }),
```

Geri çağırmanın yakaladığı kaynak verileri değiştirdikten sonra `yield* ctx.tool.reload()` çağırın. Yeniden yükleme
etkin dönüşümleri sıralarını değiştirmeden yeniden oynatır; eklenti effect'ini yeniden çalıştırmaz.

Effect araçları Promise araçlarıyla aynı [serbest biçimli girdi bildirimini](/build/plugins/server#freeform-tool-input)
kabul eder. Model o biçimi duyurmuyorsa araç normal nesne girdisini korur.

Araçların etkin adlarını içeren bir `id` değeri vardır ve o kimlik yoksa `get()` `undefined` döndürür. `update` ve
`remove` işlemlerini etkin araç adıyla, ad alanı dahil (yukarıdaki `acme_greeting`) kullanın. Ad alanlarındaki noktalar
`_` ile değiştirilir. Araç adlarında harfler, rakamlar, `_` ve `-` dışındaki karakterler `_` ile değiştirilir.
Var olmayan adlar yok sayılır; bir araç oluşturmak için `add` yöntemini eksiksiz bir tanımla çağırın.
Güncellemeler adı ve ad alanını korur. Yeni şemaları veya seçenekleri atayarak onları değiştirin,
iç içe değerleri değiştirmeyin. Geçersiz güncellemeler günlüğe yazılır ve önceki tanım bozulmadan kalır.

{/* prettier-ignore */}
```ts
yield* ctx.tool.transform((editor) => {
  editor.update("acme_greeting", (tool) => {
    tool.description = "Greet the user by name"
  })
  editor.remove("acme_obsolete")
})
```

Güncellemeler ve kaldırmalar, MCP katalog yenilemelerinden sonra da dahil, eklemelerle sırayla yeniden oynatılır.

`transform` kapsama bağlı bir kayıt döndürür. Bu dönüşümü kaldırıp sonucu kalan dönüşümlerden yeniden oluşturmak için `yield* registration.dispose` çalıştırın. Böylece kaldırılan dönüşümün geçersiz kıldığı önceki tanım yeniden geçerli olur. Aynı kaydı tekrar kaldırmanın ek bir etkisi yoktur. Eklenti kapsamı kapandığında kayıtları da kaldırılır.

Her model isteği bir araç anlık görüntüsü yakalar. Yeniden yükleme ve elden çıkarma, mevcut bir isteğin zaten yakaladığı
tanımları veya yürütücüleri değil gelecekteki anlık görüntüleri etkiler. Değiştirilebilir eklenti verilerini kapatarak
kullanan yürütücüler o verileri yine görür; bir tanıma bağlı kalması gerektiğinde dönüşüm içinde bir değer yakalayın.

Şemalar: [`Tool.Content`](/api#schema-Tool.Content), [`Tool.TextContent`](/api#schema-Tool.TextContent),
[`Tool.FileContent`](/api#schema-Tool.FileContent).

```ts

  list(): readonly (Tool.Info & { readonly id: string })[]
  get(id: string): (Tool.Info & { readonly id: string }) | undefined
  namespace(namespace: { name: string; description: string }): void
  add<Input extends Tool.ValueSchema<any>, Output extends Tool.ValueSchema<any> | undefined>(
```

### VCS

Depo bilgilerini, çalışma kopyası durumunu veya dosya diff'lerini okuyun.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const vcs = ctx.vcs
    const info = yield* vcs.get().pipe(Effect.orDie)
    const branches = yield* vcs.branch.list({ search: "feature", limit: 10 }).pipe(Effect.orDie)
    const changes = yield* vcs.status().pipe(Effect.orDie)
    const diff = yield* vcs.diff({ mode: "working", context: 3 }).pipe(Effect.orDie)
    yield* Effect.logInfo("vcs", { branch: info.data.branch.current, files: changes.data.length })
  }),
```

Kapsamlı bir dönüşümle konum kapsamlı bir sağlayıcı kaydedin. Algılanan depo türüyle eşleşen sağlayıcılar otomatik olarak
seçilir; farklı bir sağlayıcı seçmek için `editor.default.set` kullanın.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const vcs = ctx.vcs
    yield* vcs.transform((editor) => {
      editor.add({
        id: "custom",
        name: "Custom VCS",
        info: () => Effect.succeed({ branch: { current: "feature", default: "main" } }),
        branches: (input) => readBranches(input),
        status: (scope) => readStatus(scope.worktree),
        diff: (input) => readDiff(input),
      })
      editor.default.set("custom")
    })
  }),
```

Sağlayıcı geri çağırmaları geçerli konumu, çalışma kopyası kökünü, asıl proje kökünü ve isteğe bağlı depo deposunu alır.
Diff geri çağırmaları ayrıca seçilen modu, istenen bağlamı ve çıktı bayt bütçesini alır. Depo keşfi OpenCode'un yerleşik
Git ve Mercurial algılayıcılarını kullanmaya devam eder.

Sağlayıcılar isteğe bağlı olarak `scope.worktree` içinde bir depo oluşturmak için `init(scope)` uygulayabilir. Başlatma
sağlayıcıyı algılanan depo türüne göre değil kimliğine göre (varsayılan Git) seçer. Konumda henüz depo olmasa bile `init`
içeren bir sağlayıcı kaydedin; OpenCode onu çağırmadan önce dizinin var olduğunu ve depo içermediğini denetler, ardından
projeyi yeniden keşfeder. Yeni depo biçimleri yine de bu geri çağırmanın ötesinde keşif desteği gerektirir.

Şemalar: [`Vcs.Info`](/api#schema-Vcs.Info), [`Vcs.FileStatus`](/api#schema-Vcs.FileStatus),
[`FileDiff.Info`](/api#schema-FileDiff.Info).

Kancalar, işlemler yürütülürken devreye girer. Aynı kancayı birden fazla eklenti kaydedebilir. OpenCode kancaları eklenti sırasıyla çalıştırır; böylece sonraki kancalar önceki değişiklikleri görür. Kayıtlar eklenti kapsamı boyunca etkin kalır.

```ts
effect: (ctx) =>

```

### Oturumlar

Model gönderiminden hemen önce birleştirilmiş sistem talimatlarını, mesajları veya araçları değiştirin. `context` agent
döngüsü için, `compaction`, `generate` ve `title` ise o yardımcı istekler için çalışır. `compaction` ve `title`, model
çağrısını atlayan bir `result` kabul eder.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const session = ctx.session
    yield* session.hook("context", (event) =>
      Effect.sync(() => {
        event.system.push({ type: "text", text: "Keep the review focused on correctness." })
        delete event.tools.write
      }),
    )
    yield* session.hook("compaction", (event) =>
      Effect.map(summarize(event.messages), (summary) => {
        event.result = { summary }
      }),
    )
  }),
```

`context`, `compaction` ve `generate` kancalarındaki mesajlar, saklanan mesajlarının `metadata` değerini salt okunur
olarak taşır (örneğin bir `prompt` kancasının ayarladığı değer). Bu, modele gönderilmez.

OpenCode'un talimatlarını tutan `system` parçası ayrıca her kaynağı `metadata.experimental.instructions` içinde
`{ key, text }` olarak listeler, örneğin `core/date` veya `core/environment`; böylece bir kanca kaynakları ayırt
edebilir. Liste bir kopyadır: parçanın `text` değerini düzenlemek onu güncellemez. Bu deneyseldir ve değişebilir.

Model istek ayarlarını değiştirin ve isteğe bağlı olarak kancayı tek bir sağlayıcıyla sınırlayın. Olay, aşağıdaki HTTP
kancalarıyla aynı `kind` değerini taşır.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const session = ctx.session
    yield* session.hook(
      "model.request",
      (event) => Effect.sync(() => (event.headers["x-plugin"] = "review")),
      { providerID: "anthropic" },
    )
  }),
```

Yerel sağlayıcı isteklerini veya yanıtlarını değiştirin. Gövdeleri tek kullanımlık akışlardır; okumadan önce bir gövdeyi
klonlayın veya değiştirin. İki kanca da bir oturumun yaptığı her istek için çalışır; `event.kind`, isteği hangi akışın
yaptığına göre `"primary"`, `"compaction"`, `"title"` veya `"generate"` olur.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const session = ctx.session
    yield* session.hook("http.request", (event) =>
      Effect.sync(() => {
        event.request.headers.set("x-session-id", event.sessionID)
        if (event.kind === "title") event.request.headers.set("x-priority", "background")
      }),
    )
    yield* session.hook("http.response", (event) =>
      Effect.sync(() => {
        event.response = new Response(event.response.body, {
          status: event.response.status,
          headers: { ...Object.fromEntries(event.response.headers), "x-plugin": "review" },
        })
      }),
    )
  }),
```

WebSocket üzerinden akış yapan sağlayıcılar oturum başına tek bir bağlantıyı yeniden kullanır; bu nedenle HTTP kancaları o
trafiği hiç görmez. Deneysel `experimental.ws.handshake` kancası model çağrısı başına bir kez, bağlantı seçilmeden önce
çalışır ve bağlantının `url` ve `headers` değerlerini sunar; ikisinden birini değiştirmek soketi yeniden açar. Bir WebSocket
rotasının geri döndüğü her istek için HTTP kancaları yine çalışır.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.session.hook(
      "experimental.ws.handshake",
      (event) =>
        Effect.gen(function* () {
          event.headers.authorization = `Bearer ${yield* mintToken(event.url)}`
          delete event.headers["api-key"]
        }),
      { providerID: "azure" },
    )
  }),
```

`experimental.ws.send` ve `experimental.ws.receive` çerçevelerin kendisini sunar: `send`, sağlayıcı sürücüsü giden bir
çerçeve oluşturduktan sonra; `receive` ise her gelen çerçevede sürücü onu görmeden önce çalışır. Kanca döndüğünde
`frame` ne tutuyorsa telden geçen veya sürücüye ulaşan odur; OpenCode bunu doğrulamaz.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.session.hook(
      "experimental.ws.send",
      (event) =>
        Effect.sync(() => {
          const body = JSON.parse(event.frame)
          if (body.type === "response.create") body.metadata = { ...body.metadata, session: event.sessionID }
          event.frame = JSON.stringify(body)
        }),
      { providerID: "openai" },
    )
  }),
```

Bir sağlayıcı hatası için yeniden deneme kararını geçersiz kılın veya gecikmesini milisaniye olarak değiştirin. Kanca,
OpenCode hatayı sınıflandırıp politikasını önerdikten sonra ama herhangi bir yeniden deneme planlanmadan önce çalışır.
OpenCode'un sonraki denemeyi dahili olarak nasıl yaptığını sunmaz.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.session.hook("retry", (event) =>
      Effect.sync(() => {
        if (event.error.status === 429) {
          event.decision = { retry: true, delay: 10_000 }
          return
        }
        if (event.error.type === "provider.invalid-request" && event.attempt === 2) {
          event.decision = { retry: true, delay: 0 }
          return
        }
        if (event.attempt >= 3) event.decision = { retry: false }
      }),
    )
  }),
```

Başlangıçtaki `decision` OpenCode'un politikasıdır; bu nedenle kancalar normalde sonlandırıcı olan bir sağlayıcı hatasını
yeniden denenebilir yapabilir veya önerilen bir yeniden denemeyi veto edebilir. Birden fazla kanca kayıt sırasına göre
çalışır ve sonraki kancalar geçerli kararı görür. Yerleşik azami deneme sayısı kesin bir sınır olarak kalır. `attempt`,
önerilen fiziksel denemedir; ilk istek `1`. denemedir, bu nedenle ilk yeniden deneme `2`. denemedir. Geçersiz gecikmeler
(`NaN`, sonsuz veya negatif değerler) hesaplanan gecikmeye geri döner. Bağlam taşması kurtarması ayrı kalır; çünkü aynı
isteği yeniden denemek yerine konuşmayı sıkıştırır.

### Kabuk

Kabuk komutlarını, çalışma dizinlerini, zaman aşımlarını, çalıştırılabilir dosyaları veya ortam değişkenlerini yürütmeden
önce değiştirin.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const shell = ctx.shell
    yield* shell.hook("create.before", (event) =>
      Effect.sync(() => {
        if (event.command === "npm") event.command = "bun"
        event.timeout = Math.min(event.timeout, 60_000)
        event.env.COMPANY_ENV = "development"
      }),
    )
  }),
```

### Araçlar

Önce kancaları girdiyi değiştirebilir veya `Tool.Error` ile başarısız olabilir.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const tool = ctx.tool
    yield* tool.hook("execute.before", (event) =>
      event.tool === "write"
        ? Effect.fail(new Tool.Error({ message: "Writes are disabled" }))
        : Effect.logDebug("tool input", { tool: event.tool, input: event.input }),
    )
  }),
```

Sonra kancaları başarılı sonuçları ve hataları inceleyebilir veya değiştirebilir.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const tool = ctx.tool
    yield* tool.hook("execute.after", (event) => {
      if (event.status === "error") return Effect.logWarning("tool failed", { message: event.error.message })
      return Effect.sync(() => {
        event.result = { ...event.result, metadata: { observed: true } }
      })
    })
  }),
```

```ts
interface ToolHooks {
  readonly "execute.before": ToolExecuteBefore
  readonly "execute.after": ToolExecuteAfter
```

Paylaşılan kayıt türleri hangi işlemlerin eklenti kapsamı gerektirdiğini gösterir.

```ts
interface Registration {
  readonly dispose: Effect.Effect<void>
}

type Hooks<Spec, Failures extends Record<keyof Spec, unknown> = Record<keyof Spec, never>> = <Name extends keyof Spec>(
  name: Name,
  callback: (input: Spec[Name]) => Effect.Effect<void, Failures[Name]>,
) => Effect.Effect<Registration, never, Scope.Scope>

type Transform<Input> = (callback: (input: Input) => void) => Effect.Effect<Registration, never, Scope.Scope>
```

## Yayımlama

Bir paket eklentisi yerel bir Effect eklentisiyle aynı varsayılan dışa aktarımı kullanır. Effect uygulamasını ana giriş
noktasından dışa aktarın ve `effect` paketini `peerDependency` olarak bildirin. `devDependencies` altında
`@opencode/plugin` paketinin kullandığı sürümü sabitleyin; böylece geliştirme kurulumları tek bir kopya kurar.

```json title="package.json"
{
  "name": "opencode-acme-effect-plugin",
  "version": "1.0.0",
  "type": "module",
  "exports": {
    ".": "./src/index.ts"
  },
  "dependencies": {
    "@opencode/plugin": "latest"
  },
  "peerDependencies": {
    "effect": "^4.0.1"
  },
  "devDependencies": {
    "effect": "4.0.1"
  }
}
```

OpenCode, `effect`, dışa aktarılan `effect/*` alt yolları ve `@opencode/plugin` (eklentinin `node_modules` içindeki
bağımlılıklardan gelen içe aktarmalar dahil) içe aktarmalarını ana bilgisayarın çalışma zamanı örneklerine yönlendirir;
böylece fiber'lar, günlükleyiciler ve `Schema` ayrıştırıcıları tek bir çalışma zamanı kopyasını paylaşır.

- `effect` paketini yayımlanan eklenti çıktısına paketlemeyin. Bir paketleyiciyle derliyorsanız `effect` ve `effect/*`
  paketlerini external olarak işaretleyin.
- Eklentiler ve `node_modules` bağımlılıkları her zaman ana bilgisayar OpenCode sürümünün `effect` örneğine karşı
  yürütülür. Hedeflediğiniz OpenCode sürümüyle uyumlu `effect` API'lerini ve modül yollarını kullanın; başka bir `effect`
  ana sürümü üzerine kurulmuş bağımlılıklar (örneğin Effect 3) de ana bilgisayarın `effect` paketini alır ve desteklenmez.
- Yalnızca genel `effect` alt yolları sağlanır. Effect'in özel `internal` modüllerinden birini içe aktaran bir eklenti,
  yolu adlandıran bir hatayla yüklenemez.
- Derlenmiş OpenCode ikili dosyası, Effect'in HTTP API belge sayfalarının kullandığı Scalar ve Swagger UI varlıklarını
  içermez; bu sayfaları bir eklentiden sunmak bunun yerine bir bildirim gösterir.

Paket giriş noktası, bir `effect` işleviyle `Plugin.define` dışa aktarır.

```ts title="src/index.ts"
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "acme.published",
  effect: (ctx) =>
    Effect.gen(function* () {
      const storage = ctx.storage
      yield* storage.set("installed", true)
    }),
})
```

Hedeflediğiniz OpenCode sürümüyle uyumlu sürümler kullanın ve yalnızca çalışma alanına bağlanmış bir kopyayı değil kurulu
paketi test edin.

```sh
bun pm pack
bun add ./opencode-acme-effect-plugin-1.0.0.tgz
```
