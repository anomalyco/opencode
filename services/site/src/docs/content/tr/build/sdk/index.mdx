`@opencode/sdk`, OpenCode'u doğrudan uygulamanızın içinde barındırır. [Ağ istemcisinden](/build/client) farklı olarak
OpenCode sunucusunu uygulama içinde kurar ve API çağrılarını bellekteki HTTP yönlendiricisi üzerinden işler. HTTP bağlantılarını dinleyen bir port açmaz; istemci ile sunucu arasında ağ iletişimi gerekmez.

Cloudflare Durable Objects için [Cloudflare rehberine](/build/sdk/cloudflare) bakın.

SDK'yı kurun:

```sh
bun add @opencode/sdk
```

## Gömülü sunucu oluşturma

`OpenCode.create()`, yaşam döngüsünden çağıran kodun sorumlu olduğu bir gömülü sunucu döndürür. Yönlendiriciyi, Location hizmetlerini, fiber'ları ve kapsama bağlı eklenti kayıtlarını serbest bırakmak için `await using` kullanın:

```ts
import { OpenCode } from "@opencode/sdk"

await using opencode = await OpenCode.create()
const session = await opencode.sessions.create({
  location: { directory: "/workspace" },
})

await opencode.sessions.prompt({
  sessionID: session.id,
  text: "Review the current changes",
})
```

Kaynakları açıkça yönetme özelliği kullanılamıyorsa `await opencode.close()` çağrısını doğrudan yapın.

Gömülü sunucu, `@opencode/client` ile aynı Promise değerlerini, tanımlı hataları, istek seçeneklerini ve `AsyncIterable` akışlarını kullanır. Üretilen istemcinin tamamını sunar ve oturum ile olay gruplarına kolayca erişmek için `sessions` ve `events` takma adlarını ekler.

## Worktree'ler

Worktree işlemleri bir `projectID` gerektirir. Oluşturma ve yenileme, yapılandırmayı ve eklentileri projenin kayıtlı asıl
checkout'undan yükler. Listeleme yalnızca kayıtlı envanteri okur; kaldırma asıl eklentileri etkinleştirir ve kaydedilmiş
stratejiyi kullanır; o strateji kullanılamıyorsa başarısız olur.

```ts
const projectID = session.projectID
const worktree = await opencode.worktree.create({ projectID, name: "task" })
await opencode.worktree.refresh({ projectID })
await opencode.worktree.remove({ projectID, directory: worktree.directory, force: false })
```

Yenileme, bilinen checkout köklerinde mevcut tüm stratejileri kullanarak worktree'leri keşfeder. Özel bir stratejiyi
[bir eklentinin worktree dönüşümü](/build/plugins/server#worktrees) ile kaydedin.

## Olay akışı

```ts
for await (const event of opencode.events.subscribe()) {
  console.log(event.type)
}
```

Oluşturulan istek seçenekleri aracılığıyla bir `AbortSignal` iletin veya yanıt gövdesini iptal etmek için yinelenmeyi
bırakın.

## Özelleştirme

OpenCode örneğinizi eklenti kaydederek özelleştirin. Gömülü sunucu başlatılırken agent'ları, modelleri, araçları ve diğer davranışları özelleştirmek için eklentileri `OpenCode.create()` çağrısına iletin:

```ts
import { Plugin } from "@opencode/plugin"
import { OpenCode } from "@opencode/sdk"

const plugin = Plugin.define({
  id: "customize-agent",
  async setup(ctx) {
    await ctx.agent.transform((agents) => {
      agents.update("build", (agent) => {
        agent.description = "Builds features and fixes bugs for our team"
      })
    })
  },
})

await using opencode = await OpenCode.create({ plugins: [plugin] })
```

Başlangıçtan sonra başka bir eklenti kaydetmek için `await opencode.plugin(plugin)` çağırın.

Eklenti kancaları, dönüşümler, araçlar ve eksiksiz eklenti bağlamı için
[eklentiler belgelerinin tamamına](/build/plugins/server) bakın.
