npm paketi, platformunuz için yerel `opencode` ikili dosyasını seçmek üzere bir postinstall betiği kullanır. Bun ve pnpm komutları
gerekli betiğe açıkça izin verir; Vite+ ek bir bayrak gerektirmez. mise komutu mise 2026.10.9 veya üstünü gerektirir;
eski sürümler OpenCode 1'i kurar.

Windows paket yöneticileri desteklenmez.


Platformunuz için bağımsız bir CLI ikili dosyası indirin.

- **macOS:** [Apple silicon](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-arm64.zip) · [Intel](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-x64.zip) · [Intel (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-x64-baseline.zip)
- **Windows:** [ARM64](https://opencode.ai/update/api/latest/cli/opencode/opencode-windows-arm64.zip) · [x64](https://opencode.ai/update/api/latest/cli/opencode/opencode-windows-x64.zip) · [x64 (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-windows-x64-baseline.zip)
- **Linux (glibc):** [ARM64](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-arm64.tar.gz) · [x64](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-x64.tar.gz) · [x64 (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-x64-baseline.tar.gz)

## Web

OpenCode web arayüzüne `opencode pair` komutuyla erişin.

```bash
$ opencode pair

  Open a link to connect. Links work once and expire in 5 minutes.

  http://127.0.0.1:49374/auth/connect/...
```

## Docker

Docker imajları `ghcr.io/anomalyco/opencode:2.0.0` gibi sürüm içeren etiketler kullanır. Sunucuyu bir kapsayıcıda
çalıştırmak için [Docker](/cli/web#docker) bölümüne bakın.

## Bağlanma

OpenCode birçok LLM sağlayıcısını yerleşik olarak destekler. Bunlara `/connect` ile doğrudan
[TUI içinden](/cli/providers) bağlanabilirsiniz.

Özel sağlayıcıları yapılandırmak için [Sağlayıcılar](/providers) sayfasına bakın.

En iyi kodlama modellerine kolayca erişmek isterseniz
[OpenCode Console](/console) ürününü deneyebilirsiniz.

En iyi kodlama modellerine erişim sağlayan aylık 10 dolarlık [OpenCode Go](/console/go) aboneliğini de deneyebilirsiniz.
