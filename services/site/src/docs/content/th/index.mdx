OpenCode คือเอเจนต์เขียนโค้ดแบบโอเพนซอร์ส ใช้งานได้ทั้งผ่านเทอร์มินัล แอปเดสก์ท็อป และเว็บแอป

แพ็กเกจ npm ใช้สคริปต์ postinstall เพื่อเลือกไบนารี `opencode` ที่ตรงกับแพลตฟอร์มของคุณ คำสั่งสำหรับ Bun และ pnpm
ด้านบนระบุให้รันสคริปต์ที่จำเป็นไว้แล้ว ส่วน Vite+ ไม่ต้องใช้แฟล็กเพิ่มเติม คำสั่ง mise ต้องใช้ mise 2026.10.9 ขึ้นไป
เพราะเวอร์ชันก่อนหน้านั้นจะติดตั้ง OpenCode 1

ไม่รองรับตัวจัดการแพ็กเกจของ Windows


ดาวน์โหลดไบนารี CLI แบบสแตนด์อโลนสำหรับแพลตฟอร์มของคุณ

## เว็บ

เข้าถึงอินเทอร์เฟซเว็บของ OpenCode ด้วยคำสั่ง `opencode pair`

```bash
$ opencode pair

  Open a link to connect. Links work once and expire in 5 minutes.

  http://127.0.0.1:49374/auth/connect/...
```

## Docker

อิมเมจ Docker ใช้แท็กที่ระบุเวอร์ชัน เช่น `ghcr.io/anomalyco/opencode:2.0.0` ดูวิธีรันเซิร์ฟเวอร์ในคอนเทนเนอร์ในหัวข้อ [Docker](/cli/web#docker)

---

## การเชื่อมต่อ

OpenCode รองรับผู้ให้บริการ LLM หลายรายในตัว คุณเชื่อมต่อได้โดยตรง [ใน TUI](/cli/providers) ด้วย `/connect`

ดูวิธีตั้งค่าผู้ให้บริการแบบกำหนดเองในหน้า [ผู้ให้บริการ](/providers)

หากต้องการเริ่มใช้โมเดลเขียนโค้ดชั้นนำได้ง่าย ๆ ลองใช้
[OpenCode Console](/console)

อีกทางเลือกคือ [OpenCode Go](/console/go) แพ็กเกจราคา $10/เดือน สำหรับใช้โมเดลเขียนโค้ดชั้นนำ

[เชื่อมต่อเซิร์ฟเวอร์ MCP](/mcp-servers) หรือ [สร้างคำสั่ง](/commands) สำหรับธีมและคีย์ลัดในเทอร์มินัล ดู [การตั้งค่า CLI](/cli/config)
