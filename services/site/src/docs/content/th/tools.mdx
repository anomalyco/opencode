ขอผลลัพธ์ที่คุณต้องการ OpenCode จะเลือกเครื่องมือที่ใช้ได้ ขออนุมัติเมื่อจำเป็น
และคืนผลลัพธ์

```text
Find where request timeouts are configured, change the default to 30 seconds,
and run the relevant existing tests.
```

งานนี้มักใช้ `grep` หรือ `glob`, `read`, เครื่องมือแก้ไข และ `shell`
คุณยังระบุชื่อเครื่องมือได้เมื่อต้องการวิธีเฉพาะ

```text
Use grep to find every reference to DEFAULT_TIMEOUT, then read the matching files.
```

## ไฟล์

### Read

`read` คืนไฟล์หรือรายการไดเรกทอรีแบบไม่เรียกซ้ำ ระบุ `path`;
ใช้ `offset` และ `limit` เพื่อแบ่งหน้าผลลัพธ์ขนาดใหญ่

```text
Read src/server.ts starting at line 120 and return at most 80 lines.
```

ข้อความที่อ่านได้มีเลขบรรทัด แต่ละหน้าอ่านได้ไม่เกิน 2,000 บรรทัดและ 50 KiB และตัดแต่ละบรรทัดหลังอักขระที่ 2,000
เครื่องมือนี้ส่งไฟล์ PNG, JPEG, GIF, WebP และ PDF ให้โมเดลได้ด้วย โดยรองรับข้อมูลต้นฉบับไม่เกิน 20 MiB หากเป็นไฟล์ไบนารีประเภทอื่น ระบบจะแจ้งข้อผิดพลาด ดู [ไฟล์แนบ](/attachments) สำหรับประเภทสื่อที่รองรับและการประมวลผลภาพ

สิทธิ์: `read` โดยใช้พาธที่ปรับมาตรฐานแล้วเป็นทรัพยากร

### Glob

`glob` ค้นหาพาธไฟล์จากรูปแบบเช่น `**/*.ts` จะค้นหาใน
ไดเรกทอรีปัจจุบันเว้นแต่ `path` เลือกไดเรกทอรีสัมพัทธ์อื่น `hidden`
รวมรายการที่ซ่อนอยู่ และ `limit` จำกัดผลลัพธ์

```text
Use glob with **/*.test.ts under packages/core and return at most 50 files.
```

ขีดจำกัดเริ่มต้นคือ 100 ไฟล์ และเวลาหมดอายุการค้นหาคือ 30 วินาที
สิทธิ์: `glob` โดยใช้รูปแบบที่ขอเป็นทรัพยากร

### Grep

`grep` ค้นหาในเนื้อหาไฟล์และส่งพาธ เลขบรรทัด และตัวอย่างข้อความกลับมา
`pattern` ใช้ไวยากรณ์ regular expression เว้นแต่ `literal` เป็น true จำกัดขอบเขตการค้นหาได้ด้วย `path`, `include`, `caseSensitive` หรือ `limit`

```text
Use grep for the literal text "request timed out" in src, including only *.ts files.
```

ขีดจำกัดเริ่มต้นคือ 100 บรรทัดที่ตรง และเวลาหมดอายุการค้นหาคือ 30 วินาที
สิทธิ์: `grep` โดยใช้รูปแบบที่ขอ ไม่ใช่พาธค้นหา เป็น
ทรัพยากร

### Edit

`edit` แทนที่ข้อความในไฟล์ที่มีอยู่ ระบุ `path`, `oldString` และ
`newString` ที่ต่างกัน ข้อความเดิมต้องตรงหนึ่งครั้งพอดีเว้นแต่ `replaceAll`
เป็น true

```text
In src/config.ts, replace the unique text "timeout: 60" with "timeout: 30".
```

ใช้ `edit` สำหรับการเปลี่ยนแปลงเฉพาะจุด OpenCode อาจจัดรูปแบบไฟล์หลังเขียน
สิทธิ์: `edit` โดยใช้พาธเป้าหมายเป็นทรัพยากร

### Write

`write` สร้างหรือแทนที่ไฟล์ข้อความทั้งหมดจาก `path` และ `content`
จะสร้างไดเรกทอรีแม่ที่ขาดและอาจรันฟอร์แมตเตอร์ที่กำหนด

```text
Create docs/example.md with a heading and one setup command.
```

ใช้ `edit` แทนเมื่อต้องการเปลี่ยนเพียงบางส่วนของไฟล์ที่มีอยู่
สิทธิ์: `edit` โดยใช้พาธเป้าหมายเป็นทรัพยากร

### Patch

`patch` ใช้แพตช์เดียวที่เพิ่ม อัปเดต ย้าย หรือลบหลายไฟล์ได้
`patchText` ใช้ส่วน `*** Add File`, `*** Update File` และ `*** Delete File`

```text
Use patch to rename src/old.ts to src/new.ts and update its exported name.
```

OpenCode เปิด `patch` สำหรับโมเดล GPT ที่รองรับ โมเดลอื่นจะได้ `edit`
และ `write` แทน สิทธิ์: `edit` โดยใช้ทุกพาธที่ได้รับผลกระทบเป็นทรัพยากร

พาธนอก Location ที่ใช้งานหรือเวิร์กทรีโปรเจกต์จะถูกตรวจ
กับ `external_directory` ด้วย ซึ่งอนุญาตโดยค่าเริ่มต้น ดู
[สิทธิ์](/permissions)สำหรับการปรับพาธให้เป็นมาตรฐาน ลำดับกฎ และการอนุมัติ
ที่บันทึกไว้ หากต้องการให้เนื้อหาภายนอกใช้ได้ตามชื่อ ให้กำหนดค่า[การอ้างอิง](/references)

## คำสั่ง

### Shell

`shell` รันคำสั่งใน shell ของผู้ใช้โฮสต์ ตั้ง `workdir` แทนการใส่
`cd` ในคำสั่ง และตั้ง `timeout` เป็นมิลลิวินาทีเมื่อเวลาหมดอายุโฟร์กราวด์
เริ่มต้นสองนาทีไม่เหมาะ

```text
Run bun test from packages/core with a five-minute timeout.
```

ตั้ง `background` เป็น true สำหรับเดฟเซิร์ฟเวอร์หรือโปรเซสที่ทำงานนานอื่น
การเรียกแบบเบื้องหลังจะคืนทันทีและแจ้งเซสชันเมื่อเสร็จ
ไม่มีเวลาหมดอายุเว้นแต่ระบุ ผลลัพธ์ขนาดใหญ่จะถูกย่อและ
เก็บผลลัพธ์ทั้งหมดไว้ในไฟล์ที่จัดการ

สิทธิ์: `shell` โดยใช้แต่ละคำสั่งที่ตัวสแกนสร้างเป็นทรัพยากร ตัวสแกน
ยังตรวจไดเรกทอรีทำงานภายนอกและไดเรกทอรีที่อนุมานได้จากคำสั่ง Shell มี
สิทธิ์ระบบไฟล์ โปรเซส และเครือข่ายของผู้ใช้โฮสต์ จึงควรใช้กฎแคบๆ ใน[สิทธิ์](/permissions)

## เว็บ

### Webfetch

`webfetch` ดึง URL HTTP หรือ HTTPS หนึ่งรายการเป็น `markdown`, `text` หรือ `html`
ค่าเริ่มต้นคือ Markdown `timeout` รับได้สูงสุด 120 วินาที

```text
Fetch https://example.com/docs as markdown.
```

รับการตอบกลับแบบข้อความเช่น HTML, ข้อความล้วน, JSON และ XML แต่ไม่รับ
ภาพหรือไบนารีอื่น ผลลัพธ์ขนาดใหญ่อาจถูกย่อขณะเก็บข้อความเต็มไว้ในที่เก็บ
ที่จัดการ สิทธิ์: `webfetch` โดยใช้ URL ที่ขอเป็นทรัพยากร

### Websearch

`websearch` ค้นหาการเชื่อมต่อที่เลือกเพื่อข้อมูลล่าสุด อินพุตคือ `query`
การค้นหา

```text
Search the web for the latest Bun release notes.
```

สิทธิ์: `websearch` โดยใช้คำค้นเป็นทรัพยากร ดู[การค้นหาเว็บ](/websearch)
สำหรับผู้ให้บริการ การเลือก ขีดจำกัดอัตรา และการปิดเครื่องมือ

## ภาพ

### การสร้างภาพ

`generate_image` สร้างภาพใหม่จากพรอมต์ หรือแก้ไข
ภาพที่มีอยู่ เป็นฟีเจอร์ทดลองและปรากฏเมื่อผู้ให้บริการที่เชื่อมต่อมี
โมเดลสร้างภาพ หากต้องการเลือกโมเดลเริ่มต้น ดู
[`experimental.image_generate`](/config#image-generation)

```text
Generate a flat app icon of a paper plane on a blue background and save it to assets/icon.png.
```

ระบุ `prompt` และไม่บังคับ `images` เพื่อแก้ไขหรือใช้อ้างอิง
`model` ที่ระบุ หรือ `path` เพื่อบันทึก ทำงานในเบื้องหลังและ
แจ้งเซสชันพร้อมพาธที่บันทึกเมื่อภาพพร้อม

สิทธิ์: `generate_image` โดยใช้โมเดลที่เลือกเป็นทรัพยากร

## การโต้ตอบ

### การถามคำถาม

`question` หยุดการทำงานชั่วคราวและแสดงคำถามหนึ่งข้อขึ้นไปแก่ผู้ใช้
แต่ละคำถามมีส่วนหัวสั้นๆ พรอมต์ และตัวเลือก `multiple` อนุญาตมากกว่า
หนึ่งตัวเลือก มีคำตอบแบบอิสระเสมอ

```text
Before changing the API, ask me to choose between a breaking change and a compatibility layer.
```

สิทธิ์: `question` โดยใช้ `*` เป็นทรัพยากร ไคลเอนต์ต้องรองรับ
แบบฟอร์มแบบอินเทอร์แอกทีฟ และการปิดจะยกเลิกคำถาม

### การโหลดสกิล

`skill` โหลดคำแนะนำและทรัพยากรที่รวมไว้สำหรับ ID สกิลที่ใช้ได้หนึ่งรายการ
ลงในบทสนทนา

```text
Load the effect skill before changing this Effect code.
```

ID ต้องอยู่ในรายการสกิลที่ประกาศหรือผู้ใช้ระบุอย่างชัดเจน
สิทธิ์: `skill` โดยใช้ ID สกิลเป็นทรัพยากร ดู[สกิล](/skills)สำหรับ
การสร้าง การค้นพบ และกฎการโหลด

## ระบบอัตโนมัติ

### ซับเอเจนต์

`subagent` เริ่มเซสชันลูกด้วยซับเอเจนต์ที่กำหนด ระบุ ID เอเจนต์
`description` สั้นๆ และ `prompt` ที่สมบูรณ์

```text
Ask the explore subagent to map the authentication flow and return the key files.
```

ซับเอเจนต์ทำงานในเบื้องหลังเสมอ การเรียกจะคืน
`sessionID` ทันที และเซสชันแม่จะได้รับข้อความ `<subagent>` เมื่อเซสชันลูก
ว่าง และอีกครั้งหลังงานรอบถัดไปแต่ละรอบ เพื่อให้ทำงานต่อหรือจบ
เทิร์นได้โดยไม่ต้องรอ ส่ง `sessionID` ที่คืนมากลับเพื่อคุยต่อในเซสชันลูกเดิม
การส่งข้อความต่อถึงเซสชันลูกที่กำลังทำงานจะเข้าร่วมการรันปัจจุบัน ใช้ได้เฉพาะ
เอเจนต์โหมด subagent และความลึกการซ้อนเริ่มต้นคือหนึ่ง

สิทธิ์: `subagent` โดยใช้ ID เอเจนต์ที่เลือกเป็นทรัพยากร

### Execute

`execute` รัน JavaScript ใน Code Mode เพื่อให้เอเจนต์เรียกและรวมเครื่องมือ
จากแคตตาล็อกได้ มีประโยชน์สำหรับการเรียกอิสระแบบขนานและสำหรับประมวลผล
ผลลัพธ์โดยไม่เพิ่มทุกค่ากลางลงในบริบทของโมเดล

```text
Read package.json and README.md in parallel, then return their relevant setup details.
```

รันไทม์ไม่มีการเข้าถึงระบบไฟล์โดยตรง การนำเข้า หรือตัวจับเวลา
มี `fetch` สำหรับคำขอ HTTP ส่วนอย่างอื่นผ่านเครื่องมือในแคตตาล็อก
การปฏิเสธ `execute` ด้วยทรัพยากร `*` จะเอา Code Mode ออก เครื่องมือที่มันจะเข้าถึง
รวมถึงเครื่องมือ MCP จากเซิร์ฟเวอร์ที่ไม่ได้ตั้ง `codemode: false` จะถูก
แสดงเป็นเครื่องมือโดยตรง แต่ละตัวพร้อมคำจำกัดความเต็มในทุกคำขอ ปฏิเสธ
เครื่องมือเหล่านั้นด้วยหากเอเจนต์ไม่ควรมี
เครื่องมือในตัวและ MCP ที่ซ้อนกันยังบังคับใช้สิทธิ์ของตัวเอง และเครื่องมือ
ปลั๊กอินบังคับใช้สิทธิ์ที่มันประกาศ

### เซสชัน

เนมสเปซ `opencode.session` ใน Code Mode มียูทิลิตีเซสชัน หากไม่มี Code
Mode จะแสดงเป็น `opencode_session_rename` และ `opencode_session_move`

- `rename` เปลี่ยนชื่อเซสชันปัจจุบันหรือเซสชันอื่น
  ที่เลือกด้วย `sessionID`
- `move` ย้ายเซสชันปัจจุบันหรือเซสชันอื่นที่เลือกไปยัง
  `directory` แบบสัมพัทธ์หรือสัมบูรณ์ การย้ายมีผลที่จุดปลอดภัย
  งานที่ขึ้นกับปลายทางจึงควรอยู่ในการเรียกถัดไป

```text
Rename this session to "Timeout cleanup", then move it to the new worktree.
```

### เวิร์กทรี

เนมสเปซ `opencode` จัดการเวิร์กทรีของโปรเจกต์ของเซสชัน

- `worktree_create` สร้างเวิร์กทรีจาก `name` และคืน
  `directory` การกำหนดค่าเวิร์กทรีของโปรเจกต์เลือกปลายทางและ
  กลยุทธ์
- `worktree_list` แสดงรายการเวิร์กทรีของโปรเจกต์
- `worktree_remove` ลบเวิร์กทรีที่ OpenCode บันทึกไว้สำหรับโปรเจกต์ ตั้ง
  `force` เพื่อทิ้งการเปลี่ยนแปลงที่ยังไม่คอมมิต

```text
Create a worktree named "login" and move this session into it.
```

`worktree_remove` ใช้สิทธิ์ `edit` โดยมีไดเรกทอรีเวิร์กทรีเป็น
ทรัพยากร ยูทิลิตีเวิร์กทรีอื่นไม่ขอดำเนินการสิทธิ์ในตัว

## เบราว์เซอร์

เนมสเปซ `browser` ใน Code Mode ควบคุมเบราว์เซอร์ที่แอปเดสก์ท็อป OpenCode
เชื่อมต่อ เปิดแท็บ เก็บ `tabID` ที่คืนมา แล้วส่ง ID นั้นอย่างชัดเจนให้
ทุกการดำเนินการบนหน้า

```text
Open https://example.com, take a snapshot of that tab, and report the main heading.
```

เนมสเปซรวมคำสั่งแท็บและการนำทาง สแนปช็อตหน้าและการค้นหา
การคลิกและการป้อนฟอร์ม ภาพหน้าจอ การถ่ายโอนไฟล์ การตรวจคอนโซลและเครือข่าย
เทรซประสิทธิภาพ การตรวจฮีป และการตรวจ Lighthouse
ภาพหน้าจอต้องมีแท็บที่โฟกัสและมองเห็น พาธอัปโหลดเป็นพาธในเครื่องเซิร์ฟเวอร์
การจับภาพคืนพาธในเครื่องเซิร์ฟเวอร์ และการถ่ายโอนไฟล์แต่ละครั้งจำกัด 5 MiB

เนื้อหาหน้า บันทึก เฮดเดอร์ และบอดีการตอบกลับเป็นข้อมูลที่ไม่น่าเชื่อถือ ไม่ใช่คำแนะนำของเอเจนต์
กฎ deny ของ `browser` ด้วยทรัพยากร `*` จะเอาแคตตาล็อกเบราว์เซอร์ออก
การดำเนินการเบราว์เซอร์ไม่มีการถามสิทธิ์รายรายการ

## ส่วนขยาย

[เซิร์ฟเวอร์ MCP](/mcp-servers) เพิ่มเครื่องมือที่ชื่อและอินพุตมาจากแต่ละ
เซิร์ฟเวอร์ที่เชื่อมต่อ การกระทำสิทธิ์คือ `<server>_<tool>` โดยมีทรัพยากร
`*` ไม่ใช่ส่วนคงที่ของแคตตาล็อกในตัว โดยค่าเริ่มต้น เอเจนต์เข้าถึง
ผ่าน `execute` ภายใต้เนมสเปซของเซิร์ฟเวอร์ ตั้ง `codemode: false` ใน
เซิร์ฟเวอร์เพื่อแสดงเครื่องมือโดยตรง

[สกิล](/skills) เพิ่มคำแนะนำงานแทนเครื่องมือเรียกใช้ใหม่
[ไฟล์แนบ](/attachments) ใส่เนื้อหาที่ผู้ใช้เลือกในพรอมต์ ส่วน
[การอ้างอิง](/references) ให้ไดเรกทอรีภายนอกที่มีชื่อ ฟีเจอร์เหล่านี้
เสริมเครื่องมือโดยไม่ข้ามการตรวจสิทธิ์ของเครื่องมือ
