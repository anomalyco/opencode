---

การอ้างอิงช่วยให้ OpenCode เข้าถึงไดเรกทอรีนอกโปรเจกต์ปัจจุบันผ่านชื่อที่คุณตั้งไว้ เพิ่มการอ้างอิงใน `opencode.json` หรือ `opencode.jsonc` แล้วแนบ alias ในไคลเอนต์เมื่อต้องการใช้

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "references": {
    "docs": {
      "path": "../product-docs",
      "description": "Use for product behavior and terminology",
    },
  },
}
```

หลังจากแนบ `docs` ให้ขอให้เอเจนต์ตรวจพาธที่เกี่ยวข้อง

```text
Read the attached docs reference and summarize api/authentication.md.
```

ใช้การอ้างอิงสำหรับเอกสาร ไลบรารีที่ใช้ร่วมกัน ตัวอย่าง หรือซอร์สจาก
รีโพอื่น

## ในเครื่อง

ใช้ `path` สำหรับไดเรกทอรีในเครื่อง

```jsonc
{
  "references": {
    "design-system": {
      "path": "../design-system",
      "description": "Use when working with components or design tokens",
    },
  },
}
```

พาธมีพฤติกรรมดังนี้

- พาธสัมพัทธ์อ้างอิงจากไดเรกทอรีที่มีไฟล์กำหนดค่า
- รองรับพาธแบบสัมบูรณ์
- รองรับพาธเทียบไดเรกทอรีบ้านเช่น `~/docs`

ใช้รูปแบบสตริงย่อเมื่อไม่ต้องใช้ฟิลด์อื่น

```jsonc
{
  "references": {
    "docs": "../docs",
    "shared": "~/work/shared",
  },
}
```

<Callout type="note">
  สตริงย่อเป็นพาธในเครื่องเฉพาะเมื่อขึ้นต้นด้วย `.`, `/` หรือ `~` ใช้ `./docs` ไม่ใช่ `docs`; ค่า `docs`
  เปล่าๆ จะถูกตีความเป็นรีโพ Git
</Callout>

## Git

ใช้ `repository` สำหรับรีโพ Git ระยะไกล

```jsonc
{
  "references": {
    "effect": {
      "repository": "Effect-TS/effect",
      "branch": "main",
    },
    "internal-sdk": {
      "repository": "git@gitlab.example.com:platform/sdk.git",
      "branch": "release/v2",
    },
  },
}
```

รูปแบบระยะไกลที่รองรับรวมถึง

- ทางลัด `owner/repo` ของ GitHub
- URL Git
- รูปแบบโฮสต์/พาธ
- รีโมทแบบ SCP

ไม่รองรับรีโพ `file:` ในเครื่อง

ใช้สตริงย่อเพื่อตามสาขาเริ่มต้นของรีโมท

```jsonc
{
  "references": {
    "effect": "Effect-TS/effect",
    "sdk": "gitlab.com/platform/sdk",
  },
}
```

หากไม่มี `branch` OpenCode จะเช็กเอาต์และรีเฟรชสาขาเริ่มต้นของรีโมท
ชื่อสาขาอาจมีตัวอักษร ตัวเลข `/`, `_`, `.` และ `-` แต่ต้องไม่
ขึ้นต้นด้วย `-` หรือมี `..`

```jsonc
{
  "references": {
    "sdk": {
      "repository": "example/sdk",
      "branch": "release/v2.1",
    },
  },
}
```

## ที่เก็บข้อมูล

OpenCode ปรับแต่ละรีโมทให้เป็นมาตรฐานและเก็บเช็กเอาต์หนึ่งรายการต่อรีโมทและสาขา
ภายใต้ไดเรกทอรีข้อมูลส่วนกลาง หากไม่มีสาขาอย่างชัดเจน พาธจะใช้
รูปแบบนี้

```text
opencode/repos/<host>/<repository-path>
```

ในการติดตั้ง Linux ทั่วไป `Effect-TS/effect` จะถูกเก็บที่

```text
~/.local/share/opencode/repos/github.com/Effect-TS/effect
```

สาขาที่ระบุชัดเจนจะเพิ่มส่วนต่อท้าย `@<branch>` ที่เข้ารหัส

```text
~/.local/share/opencode/repos/github.com/Effect-TS/effect@main
```

## การรีเฟรช

รีโพที่ขาดจะถูกโคลนแบบอะซิงโครนัส เช็กเอาต์ที่มีอยู่จะถูกตรวจ
ในเบื้องหลังเมื่อการอ้างอิงโหลดหรือโหลดใหม่ และหลังรับพรอมต์ผู้ใช้ใหม่ใน
Location ของมัน

```text
Prompt admitted → refresh check starts in background → agent continues
```

เช็กเอาต์จะเข้าเกณฑ์เมื่อความพยายามรีเฟรชครั้งล่าสุดผ่านไปอย่างน้อย 24 ชั่วโมง
หรือยังไม่มีการบันทึกความพยายาม การรีเฟรชจะดึงและรีเซ็ตไปยัง
สาขาที่กำหนดหรือสาขาเริ่มต้นของรีโมท

```text
Last attempt: 25 hours ago → eligible
Last attempt: 2 hours ago  → skipped
```

การรีเฟรชเป็นไปตามกฎเหล่านี้

- การประทับเวลาคงอยู่ข้ามการรีสตาร์ตบริการ
- Location ที่ใช้เช็กเอาต์เดียวกันจะใช้การประทับเวลาเดียวกัน
- ความพยายามที่ล้มเหลวจะถูกบันทึกและยังอยู่ภายใต้ขีดจำกัด 24 ชั่วโมง
- ไม่มีการโพลเป็นระยะขณะ Location ไม่ได้ใช้งาน
- ความล้มเหลวในการโคลนหรือรีเฟรชไม่หยุดการอ้างอิงอื่นโหลด

พรอมต์ไม่รอการโคลนหรือรีเฟรช ไฟล์แนบอาจมีเนื้อหาเก่า
แม้การอ่านด้วยเครื่องมือภายหลังจะเห็นเช็กเอาต์ที่อัปเดตแล้ว และการอ้างอิงใหม่
อาจปรากฏก่อนเช็กเอาต์พร้อม

```text
Attachment created → cached content
Background refresh completes → later tool read sees newer content
```

<Callout type="warning">
  เช็กเอาต์ที่แคชไว้ใช้ร่วมกันและอาจอัปเดตขณะเอเจนต์ใช้งาน หลีกเลี่ยงการแก้ไขเช็กเอาต์ที่แคชไว้เพราะ
  การรีเฟรชจะรีเซ็ต
</Callout>

## คำแนะนำ

`description` บอกเอเจนต์ว่าควรใช้การอ้างอิงนี้เมื่อใด หากระบุคำอธิบาย การอ้างอิงจะปรากฏในคำแนะนำของเอเจนต์พร้อม alias และพาธที่ระบบหาได้

```jsonc
{
  "references": {
    "docs": {
      "path": "../docs",
      "description": "Use for product behavior and terminology",
    },
  },
}
```

การอ้างอิงที่ไม่มีคำอธิบายยังใช้ได้จากไคลเอนต์แต่ไม่ถูก
ประกาศโดยอัตโนมัติ

```jsonc
{
  "references": {
    "archive": {
      "path": "../archive",
    },
  },
}
```

## การมองเห็น

ตั้ง `hidden` เป็น `true` เพื่อนำการอ้างอิงออกจากตัวเลือกของไคลเอนต์แบบอินเทอร์แอกทีฟ

```jsonc
{
  "references": {
    "internal": {
      "path": "../internal",
      "description": "Use for internal service behavior",
      "hidden": true,
    },
  },
}
```

`hidden` มีผลเฉพาะกับการแสดงผลในส่วนที่ผู้ใช้โต้ตอบได้ การอ้างอิงยังคงอยู่ใน API การอ้างอิง และถ้ามีคำอธิบายก็ยังอยู่ในคำแนะนำของเอเจนต์ด้วย

## การใช้งาน

ไคลเอนต์แนบการอ้างอิงด้วย alias ราก ไฟล์แนบมี
รายการไฟล์และไดเรกทอรีทันทีของรากแบบไม่เรียกซ้ำ

```text
Attached alias: docs
Ask: Inspect docs/guides/deployment.md and explain the deployment steps.
```

ขอให้เอเจนต์ตรวจพาธที่ระบุเมื่อต้องการเนื้อหาใต้ราก

## สิทธิ์

การอ้างอิงไม่ได้ให้สิทธิ์เครื่องมือเพิ่มเติม การเข้าถึงนอก
Location ที่ใช้งานยังเป็นไปตามกฎเครื่องมือปกติและสิทธิ์ `external_directory`
การแก้ไขยังต้องมีสิทธิ์แก้ไขที่บังคับใช้

```text
Read ../product-docs/api.md
```

คำขอจะสำเร็จเฉพาะเมื่อสิทธิ์ที่ใช้งานอยู่อนุญาตการอ่านภายนอกนั้น

## ฟิลด์

| ฟิลด์         | ในเครื่อง    | Git      | คำอธิบาย                                   |
| ------------- | -------- | -------- | --------------------------------------------- |
| `path`        | จำเป็น | ไม่       | พาธไดเรกทอรีในเครื่อง                          |
| `repository`  | ไม่       | จำเป็น | รีโพ Git ระยะไกล                         |
| `branch`      | ไม่       | ไม่บังคับ | สาขาที่จะดึงและเช็กเอาต์                 |
| `description` | ไม่บังคับ | ไม่บังคับ | คำแนะนำว่าควรใช้เมื่อใด |
| `hidden`      | ไม่บังคับ | ไม่บังคับ | ซ่อนจากตัวเลือกของไคลเอนต์แบบอินเทอร์แอกทีฟ     |

รายการ Git ที่สมบูรณ์ใช้ทุกฟิลด์ที่เข้ากันได้กับ Git ได้

```jsonc
{
  "references": {
    "sdk": {
      "repository": "example/sdk",
      "branch": "main",
      "description": "Use for SDK implementation details",
      "hidden": false,
    },
  },
}
```

## Alias

alias ต้องไม่ว่างและต้องไม่มี `/`, `\`, ช่องว่าง แบคทิก หรือ
จุลภาค

```text
Valid:   docs
Invalid: product docs
Invalid: docs/api
```
