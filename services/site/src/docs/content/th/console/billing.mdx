ไม่ว่าทีมจะมีขนาดเท่าใดก็ใช้ Console ได้ฟรีโดยไม่มีค่าบริการรายสมาชิก คุณจ่ายตามการใช้งานจริงจากเครดิตที่เติมล่วงหน้าไว้ใช้ร่วมกันทั้งเวิร์กสเปซ
เจ้าของและผู้ดูแลจัดการการเรียกเก็บเงินได้ใน **Settings › Billing**

หากใช้ [ผู้ให้บริการของคุณเอง](/console/providers) ผู้ให้บริการรายนั้นจะเรียกเก็บค่าใช้งาน ไม่ใช่ Console

## เพิ่มวิธีชำระเงิน

1. เปิด **Settings › Billing**
2. ในส่วน **Payment methods** คลิก **Add**
3. เลือกวิธีชำระเงินแล้วทำตามขั้นตอนของ Stripe ให้ครบ

วิธีชำระเงินที่รองรับ

- บัตร
- Link
- Alipay
- UPI
- WeChat Pay

ใช้ **⋯ › Make default** เพื่อเลือกวิธีชำระเงินที่จะใช้เมื่อเรียกเก็บเงินอัตโนมัติ หากลบวิธีชำระเงิน
การเติมเงินอัตโนมัติหรือการต่ออายุ Go ที่ใช้วิธีนั้นอาจหยุดทำงาน

## เพิ่มเครดิต

1. ในส่วน **Credits** คลิก **Add credits**
2. เลือก $10, $50 หรือ $100 หรือเลือก **Other** แล้วป้อนจำนวนเงิน
3. เลือกวิธีชำระเงินแล้วคลิก **Confirm and pay**

ระบบคิดค่าธรรมเนียมการชำระเงินเพิ่ม 4.6% + $0.31 ดังนั้น เมื่อเติมเครดิต $50 ยอดที่ต้องชำระคือ $52.61 และคุณจะได้รับเครดิตเต็ม $50

## การเติมเงินอัตโนมัติ

ระบบจะเติมเครดิตโดยอัตโนมัติเมื่อยอดคงเหลือต่ำ

1. ในส่วน **Auto-recharge** คลิก **Add rule**
2. ตั้งยอดคงเหลือที่ให้ระบบเริ่มเติมเงิน และระบุจำนวนเงินที่จะเติม
3. คลิก **Save**

ระบบเติมเงินอัตโนมัติจะเรียกเก็บผ่านวิธีชำระเงินเริ่มต้น โดยรวมค่าธรรมเนียมการชำระเงินแล้ว หากเรียกเก็บไม่สำเร็จ
การเติมเงินอัตโนมัติจะปิดจนกว่าคุณจะตั้งค่าใหม่

## ตรวจสอบยอดคงเหลือ

เจ้าของและผู้ดูแลดูยอดคงเหลือได้จากการ์ด **Billing** ในหน้า **Activity** และคลิกการ์ดเพื่อเปิด **Settings › Billing**

ปุ่ม **Billing** ในส่วนหัวของเวิร์กสเปซ หรือปุ่ม `B` เปิดแผงที่แสดงขีดจำกัด Go เครดิต และการใช้งาน
แบบเรียลไทม์ เจ้าของและผู้ดูแลเห็นยอดคงเหลือ การใช้งาน และการเติมเงินอัตโนมัติของเวิร์กสเปซ ส่วนสมาชิกเห็นเฉพาะการใช้งาน
และขีดจำกัดของตัวเอง

## เมื่อเครดิตหมด

คำขอแบบเสียค่าใช้จ่ายจะล้มเหลวด้วย HTTP `402` เมื่อยอดคงเหลือถึงศูนย์ ยอดคงเหลือไม่มีทางติดลบ

```text
Upstream request failed: Insufficient account funds
```

## ใบแจ้งหนี้

การชำระเงินทุกครั้งจะแสดงในส่วน **Invoices** พร้อมสถานะและลิงก์ **Download invoice** หรือ **View receipt**

| รายการ            | สร้างโดย                               |
| ---------------- | ---------------------------------------- |
| การเติมเครดิต   | การเพิ่มเครดิต                           |
| การเติมเครดิตอัตโนมัติ | การเติมเงินอัตโนมัติ                            |
| การสมัครสมาชิก Go  | การสมัคร Go, Go Plus หรือ Go Teams  |
| การต่ออายุ Go       | การต่ออายุ Go รายเดือน                       |
| การอัปเกรดเป็น Go Plus  | การอัปเกรด Go เป็น Go Plus                  |
| การอัปเกรดเป็น Go Teams | การอัปเกรด Go หรือ Go Plus เป็น Go Teams      |
| สมาชิก Go Teams  | สมาชิกที่เข้าร่วมเวิร์กสเปซบน Go Teams |
| การใช้งานรายเดือน    | การเรียกเก็บเงินแบบออกใบแจ้งหนี้                         |

## การเรียกเก็บเงินแบบออกใบแจ้งหนี้

เวิร์กสเปซที่มีข้อตกลงวงเงินเครดิตสามารถรับใบแจ้งหนี้รายเดือนแทนการเติมเครดิตล่วงหน้าได้ ติดต่อฝ่ายสนับสนุนเพื่อเปิดใช้

- ค่าใช้งานจะนับรวมในวงเงินเครดิต ไม่ได้หักจากยอดที่เติมไว้ล่วงหน้า
- ใบแจ้งหนี้ของแต่ละเดือนจะออกในวันที่ 1 (UTC) และครบกำหนด 14 วันหลังออก
- ใบแจ้งหนี้ที่ยังไม่ได้ชำระจะมีปุ่ม **Pay now**
- คำขอจะล้มเหลวด้วย HTTP `402` เมื่อถึงวงเงินเครดิตหรือมีใบแจ้งหนี้ค้างชำระ

## Go

การสมัคร [OpenCode Go](/console/go) ใช้วิธีชำระเงินเดียวกันและแสดงในรายการใบแจ้งหนี้เดียวกัน คุณยัง
[จ่ายค่า Go ด้วยเครดิต](/console/go#pay-with-credit) ได้ เปิด **Extra Usage** ในหน้า **Go** เพื่อให้ระบบหักเครดิต
แทนเมื่อใช้งานถึงขีดจำกัดของ Go
