[OpenCode Console](https://opencode.ai/console) เป็นบริการเสริมที่มอบสิทธิประโยชน์เพิ่มเติมให้กับการใช้
OpenCode ทั้งแบบส่วนตัวและแบบทีม

- [เวิร์กสเปซ](/console/workspaces) สำหรับแชร์การเข้าถึงกับ[ทีม](/console/members)ของคุณ
- [Inference](/console/models) สำหรับทั้งโมเดลแบบกรรมสิทธิ์และโมเดลโอเพนซอร์ส
- [ผู้ให้บริการ](/console/providers) สำหรับเชื่อมต่อบัญชีผู้ให้บริการของคุณเองผ่านเกตเวย์ของ Console
- การติดตามการใช้งานและตัวควบคุม[งบประมาณ](/console/budgets)
- เผยแพร่นโยบายระดับทีมเพื่อควบคุมพฤติกรรมของ OpenCode
- [การค้นหาเว็บ](/console/websearch)
- [Harness](/console/harnesses) สำหรับใช้โมเดลของ Console จาก Claude Code, Codex และเอเจนต์อื่นๆ
- [OpenCode Go, Go Plus และ Go Teams](/console/go) การสมัครสมาชิกรายเดือนราคา $10, $40 และ $20/สมาชิก สำหรับการเข้าถึงโมเดลโอเพนซอร์ส

## เริ่มต้นใช้งาน

คุณไม่จำเป็นต้องมีทีมเพื่อใช้ Console ทุกบัญชีเริ่มต้นด้วยเวิร์กสเปซ **Personal** ที่คุณเป็นสมาชิกเพียง
คนเดียว

1. เข้าสู่ระบบ [Console](https://opencode.ai/console)
2. สมัครสมาชิก [Go](/console/go) เพิ่ม[เครดิต](/console/billing#add-credits) หรือเชื่อมต่อ[ผู้ให้บริการ](/console/providers)
3. รัน `/connect` ใน OpenCode แล้วเลือกเวิร์กสเปซ
4. หากต้องการ ให้[เชิญ](/console/members#invite-members)สมาชิกในทีม

```text
/connect
```

## นโยบาย

กฎ Providers และ Tools จากหน้า Policies มีผลกับไคลเอนต์ OpenCode ทุกตัว
ที่เชื่อมต่อกับเวิร์กสเปซ กฎเหล่านี้ถูกส่งเป็น[ข้อกำหนดนโยบาย](/policies#console)
ที่มีลำดับความสำคัญสูงกว่าการกำหนดค่าระดับผู้ใช้และระดับโปรเจกต์ของสมาชิก และจะมีผลภายในประมาณหนึ่งนาที
ทั้งนี้ การตั้งค่าที่จัดการจากส่วนกลางและไฟล์กำหนดค่าระบบยังมีลำดับความสำคัญสูงกว่านโยบายของเวิร์กสเปซ ดู[ลำดับความสำคัญ](/policies#precedence)
