`GET https://opencode.ai/console/api/v2/usage/export` คืนการใช้งานของเวิร์กสเปซเป็น CSV หนึ่งแถวต่อวัน UTC
ต่อสมาชิกหรือบัญชีบริการ ต่อผู้ให้บริการ และต่อโมเดล เป็นไฟล์เดียวกับที่ปุ่ม **Export usage** ดาวน์โหลดจาก
**Activity › Usage**

```bash
curl --fail-with-body "https://opencode.ai/console/api/v2/usage/export?range=30d" \
  --header "Authorization: Bearer oc_sk_..." \
  --output usage-30d.csv
```

## การตรวจสอบสิทธิ์

ส่ง[คีย์ API](/console/api#api-keys)เป็น bearer token เพื่อส่งออกข้อมูลการใช้งานของเวิร์กสเปซที่สร้างคีย์นั้น

```text
Authorization: Bearer oc_sk_...
```

คีย์ต้องมี **Usage › Read** คีย์ที่มี **All** หรือ **Read only** มีสิทธินี้ คีย์แบบกำหนดขอบเขตต้องมี

```text
Permissions: Restricted
Usage:       Read
```

ใช้[คีย์บัญชีบริการ](/console/api#service-accounts)สำหรับการส่งออกตามกำหนดเวลา หรือ
[คีย์ API ส่วนตัว](/console/api#personal-api-keys)ของเจ้าของ/ผู้ดูแล สมาชิกอ่านการใช้งานของเวิร์กสเปซไม่ได้
คีย์ของสมาชิกจึงคืน `403`

## คำขอ

| พารามิเตอร์ | จำเป็น | ค่า                                                                                                                 |
| --------- | -------- | --------------------------------------------------------------------------------------------------------------------- |
| `range`   | ใช่      | `7d`, `30d` หรือ `90d`                                                                                                |
| `user_id` | ไม่      | ID สมาชิก (`user_...`) หรือ ID บัญชีบริการ (`svcacct_...`) คืนเฉพาะแถวของสมาชิกหรือบัญชีบริการนั้น |

`range` นับวันตาม UTC และรวมวันนี้ด้วย `7d` จึงครอบคลุมวันนี้และหกวันก่อนหน้า ข้อมูลในแถวของวันนี้จะสะสมเพิ่มจนถึงเที่ยงคืน UTC

หากต้องการส่งออกการใช้งานของบัญชีบริการเดียว ให้ส่ง ID จากคอลัมน์ `user_id` ของการส่งออกครั้งก่อน

```bash
curl --fail-with-body "https://opencode.ai/console/api/v2/usage/export?range=7d&user_id=svcacct_01JD8Z4Q2W7N3K5M6P9R0S1T2V" \
  --header "Authorization: Bearer oc_sk_..."
```

ID ที่ไม่อยู่ในเวิร์กสเปซจะคืนเฉพาะแถวหัวตาราง

## การตอบกลับ

คำขอที่สำเร็จจะคืน `200` พร้อม `Content-Type: text/csv; charset=utf-8` บรรทัดแรกคือหัวตาราง ตามด้วยแถวข้อมูล
โดยวันใหม่สุดมาก่อน

```csv
day,user_type,user_id,user_name,provider,model,requests,input_tokens,output_tokens,cache_read_tokens,cache_write_5m_tokens,cache_write_1h_tokens,cost_micro_cents,cost_usd
2026-11-24,service_account,svcacct_01JD8Z4Q2W7N3K5M6P9R0S1T2V,CI Pipeline,opencode,claude-sonnet-5-5,412,1830211,96402,5120330,210044,0,1512334800,15.123348
2026-11-24,member,user_01JC2X7Y8Z9A0B1C2D3E4F5G6H,ada@example.com,opencode,claude-haiku-5-5,57,402118,31877,880012,0,0,214500000,2.145
2026-11-23,member,user_01JC2X7Y8Z9A0B1C2D3E4F5G6H,ada@example.com,opencode,claude-sonnet-5-5,96,711560,48210,2204118,61022,0,587000000,5.87
```

- บรรทัดลงท้ายด้วย `\r\n`
- วันที่ไม่มีการใช้งานจะไม่มีแถว
- การตอบกลับเป็นการดาวน์โหลด (`Content-Disposition: attachment; filename="usage-30d.csv"`) และไม่ถูกแคช
  (`Cache-Control: private, no-store`)
- เซลล์ข้อความที่ขึ้นต้นด้วย `=`, `+`, `-` หรือ `@` จะได้ `'` นำหน้า เพื่อไม่ให้สเปรดชีตรันเป็นสูตร

### คอลัมน์

| คอลัมน์                  | ความหมาย                                                                                                       |
| ----------------------- | ------------------------------------------------------------------------------------------------------------- |
| `day`                   | วันที่ UTC ในรูปแบบ `YYYY-MM-DD`                                                                                |
| `user_type`             | `member` หรือ `service_account`                                                                                |
| `user_id`               | ID ของสมาชิกหรือบัญชีบริการ                                                                         |
| `user_name`             | อีเมลของสมาชิก หรือชื่อของบัญชีบริการ อาจว่างได้                                              |
| `provider`              | ผู้ให้บริการที่ให้บริการคำขอ เช่น `opencode` สำหรับ [OpenCode Models](/console/models)             |
| `model`                 | ID โมเดล                                                                                                 |
| `requests`              | จำนวนคำขอ                                                                                           |
| `input_tokens`          | โทเคนอินพุต |
| `output_tokens`         | โทเคนเอาต์พุต |
| `cache_read_tokens`     | โทเคนที่อ่านจากพรอมต์แคช |
| `cache_write_5m_tokens` | โทเคนที่เขียนลงพรอมต์แคชที่มีอายุ 5 นาที |
| `cache_write_1h_tokens` | โทเคนที่เขียนลงพรอมต์แคชที่มีอายุ 1 ชั่วโมง |
| `cost_micro_cents`      | ค่าใช้จ่ายเป็นจำนวนเต็มหน่วยไมโครเซนต์ หนึ่งดอลลาร์สหรัฐคือ `100000000`                                          |
| `cost_usd`              | ค่าใช้จ่ายเดียวกันเป็นดอลลาร์สหรัฐ เป็นทศนิยมแม่นยำอย่างน้อยสองตำแหน่ง เช่น `2.145` หรือ `0.00` |

### สิ่งที่รวมอยู่

- คำขอโมเดลทุกครั้งที่สมาชิกและบัญชีบริการของเวิร์กสเปซทำ
- คำขอไปยังโมเดลฟรี และคำขอที่สมาชิกทำผ่านการสมัครสมาชิก Claude Code, Codex หรือ OpenCode ของตัวเอง
  จะรวมอยู่ในไฟล์พร้อมจำนวนโทเคน โดยระบุค่าใช้จ่ายเป็นศูนย์
- ไม่รวม[การค้นหาเว็บ](/console/websearch)และบริการแบบโฮสต์อื่นๆ
- ยอดรวมอาจตามหลังคำขอใหม่ประมาณหนึ่งนาที

## ขีดจำกัด

- การส่งออกครอบคลุมได้สูงสุด 90 วัน หากต้องการเก็บประวัติยาวนานขึ้น ให้บันทึกไฟล์ตามกำหนดเวลา
- คำขอนับเข้าในขีดจำกัดของ Console API ที่ 300 คำขอต่อนาทีต่อบัญชี ซึ่งใช้ร่วมกับเอนด์พอยต์อื่น
  คีย์ API ส่วนตัวนับกับสมาชิกเจ้าของคีย์

## ข้อผิดพลาด

| สถานะ | ความหมาย                                                                                               |
| ------ | ----------------------------------------------------------------------------------------------------- |
| `400`  | `range` หายไปหรือไม่ใช่ `7d`, `30d` หรือ `90d` หรือ `user_id` ไม่ใช่ ID สมาชิกหรือบัญชีบริการ |
| `401`  | ไม่มีข้อมูลรับรอง หรือคีย์หมดอายุหรือถูกเพิกถอน                                                         |
| `403`  | คีย์ไม่มี **Usage › Read** หรือเป็นของสมาชิกที่ไม่ใช่เจ้าของหรือผู้ดูแล         |
| `429`  | เกินขีดจำกัดอัตรา ลองใหม่หลังจำนวนวินาทีในเฮดเดอร์ `Retry-After`                   |
| `503`  | ยอดรวมรายวันยังไม่พร้อม ลองคำขอใหม่ภายหลัง                                           |
