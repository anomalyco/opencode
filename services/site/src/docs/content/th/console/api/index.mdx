Console API ให้สคริปต์และการเชื่อมต่อของคุณเรียกใช้โมเดลและส่งออกการใช้งาน ทุกคำขอตรวจสอบสิทธิ์ด้วยคีย์
API

```bash
curl --fail-with-body "https://opencode.ai/inference/v1/models" \
  --header "Authorization: Bearer oc_sk_..."
```

| API                                       | เอนด์พอยต์                                         |
| ----------------------------------------- | ------------------------------------------------- |
| [Models](/console/api/models)             | `https://opencode.ai/console/api/v1/models`       |
| [Inference](/console/api/inference)       | `https://opencode.ai/inference/...`               |
| [Providers](/console/api/providers)       | `https://opencode.ai/inference/custom/...`        |
| [Usage export](/console/api/usage-export) | `https://opencode.ai/console/api/v2/usage/export` |

## คีย์ API

ทั้งสมาชิกเวิร์กสเปซและบัญชีบริการมีคีย์ API ได้ ให้ส่งคีย์เป็นโทเคน Bearer

```text
Authorization: Bearer oc_sk_...
```

|                  | คีย์ API ส่วนตัว                                       | คีย์บัญชีบริการ                                                      |
| ---------------- | ------------------------------------------------------ | ------------------------------------------------------------------------ |
| สร้างโดย       | สมาชิกคนใดก็ได้ สำหรับตัวเอง                             | เจ้าของและผู้ดูแล                                                        |
| สร้างที่       | **Account › Personal API keys**                        | **Settings › Service accounts**                                          |
| ทำหน้าที่เป็น          | สมาชิกที่สร้างคีย์                              | บัญชีบริการ                                                      |
| นับการใช้งานไปที่ | [งบประมาณ](/console/budgets#member-budgets)ของสมาชิก | [งบประมาณ](/console/budgets#service-account-budgets)ของบัญชีบริการ |
| เหมาะสำหรับ         | สคริปต์และ[harness](/console/harnesses)ของคุณเอง   | CI เครื่องที่ใช้ร่วมกัน และการเชื่อมต่อ                                    |

- แต่ละคีย์ใช้ได้ในเวิร์กสเปซเดียว ซึ่งเลือกตอนสร้าง ไม่ต้องมีเฮดเดอร์เวิร์กสเปซ
- คีย์เต็มจะแสดงเพียงครั้งเดียวทันทีหลังสร้าง หลังจากนั้น Console จะแสดงเฉพาะคำนำหน้า
- **Expiration** เป็นทางเลือก: **Never**, **1 day**, **7 days**, **30 days** หรือ **Custom** (1 ถึง 365 วัน) คีย์ที่หมดอายุ
  แล้วต่ออายุไม่ได้ ให้สร้างใหม่

## คีย์ API ส่วนตัว

คีย์ส่วนตัวทำหน้าที่ในนามของคุณ บทบาท [งบประมาณ](/console/budgets#member-budgets) และกฎของโมเดลของคุณมีผลกับคีย์นี้

1. เปิด **Account** จากเมนูบัญชี แล้วหา **Personal API keys**
2. คลิก **Add API key**
3. เลือก **Workspace**, **Key name** และ **Expiration** ที่ไม่บังคับ เจ้าของและผู้ดูแลเลือก
   **Permissions** ได้ด้วย
4. คลิก **Create** แล้วคัดลอกคีย์

```text
oc_sk_1a2b3c4d5e6f_...
```

คีย์จะเป็นไปตามสิทธิ์การเข้าถึงเวิร์กสเปซปัจจุบันของคุณ หากบทบาทเปลี่ยน สิ่งที่คีย์ทำได้ก็เปลี่ยนตาม หาก
เวิร์กสเปซบังคับใช้ [SSO](/console/sso#sso-enforcement) คีย์จะทำงานเฉพาะขณะที่คุณมีเซสชัน SSO ที่ใช้งานอยู่ เว้นแต่
คุณเป็นเจ้าของ

## บัญชีบริการ

บัญชีบริการคือสมาชิกที่ไม่ใช่บุคคลของเวิร์กสเปซ มีคีย์ API การใช้งาน และ
[งบประมาณ](/console/budgets#service-account-budgets)ของตัวเอง ใช้สำหรับระบบอัตโนมัติ การใช้งานจึงไม่ผูกกับบุคคล เจ้าของและ
ผู้ดูแลจัดการบัญชีเหล่านี้

1. เปิด **Settings › Service accounts** แล้วคลิก **Add Service Account** จากนั้นตั้งชื่อ เช่น `CI Pipeline`
2. เปิดบัญชีบริการแล้วคลิก **Add API Key**
3. เลือก **Key name**, **Expiration** ที่ไม่บังคับ และ **Permissions** แล้วคลิก **Create**
4. คัดลอกคีย์

```bash
export SERVICE_API_KEY="oc_sk_..."
```

เจ้าของและผู้ดูแลเปลี่ยนชื่อคีย์บัญชีบริการหรือเปลี่ยนสิทธิ์ภายหลังได้ด้วย **Edit…** ในเมนูการดำเนินการของคีย์

## สิทธิ์

แต่ละคีย์มีระดับสิทธิ์ ซึ่งเลือกได้ภายใต้ **Permissions** ตอนสร้าง

| สิทธิ์    | อนุญาต                                                                               |
| -------------- | ------------------------------------------------------------------------------------ |
| **All**        | ทุกอย่างที่สมาชิกหรือบัญชีบริการทำได้ ยกเว้น **This account's API keys** |
| **Restricted** | เฉพาะทรัพยากรที่คุณเลือก                                                       |
| **Read only**  | สิทธิ์อ่านทุกทรัพยากร คีย์แสดงรายการโมเดลได้แต่เรียกใช้ไม่ได้            |

คีย์ไม่สามารถทำงานเกินสิทธิ์ของผู้ที่คีย์ใช้แทนได้ คีย์ส่วนตัวใช้สิทธิ์ได้ไม่เกินบทบาทปัจจุบันของสมาชิก ส่วนคีย์บัญชีบริการใช้ได้ไม่เกิน[ขอบเขตสิทธิ์ของบัญชีบริการ](#limitations)

### คีย์แบบกำหนดขอบเขต

กำหนดแต่ละทรัพยากรเป็น **None**, **Read** หรือ **Write** **Write** รวม **Read**

| ทรัพยากร                    | ระดับ                |
| --------------------------- | --------------------- |
| **Models**                  | **Read**, **Request** |
| **Usage**                   | **Read**              |
| **Budgets**                 | **Read**, **Write**   |
| **Members**                 | **Read**, **Write**   |
| **Providers**               | **Read**, **Write**   |
| **Billing**                 | **Read**, **Write**   |
| **Workspace settings**      | **Read**, **Write**   |
| **SSO**                     | **Read**              |
| **Service accounts**        | **Read**              |
| **This account's API keys** | **Write**             |

**Models › Read** แสดงรายการโมเดล และ **Models › Request** เรียกใช้โมเดลผ่าน [Inference](/console/api/inference)
และ [Providers](/console/api/providers) API ด้วย ตัวอย่างเช่น คีย์ที่เรียกใช้โมเดลอย่างเดียวต้องมี

```text
Permissions: Restricted
Models:      Request
```

คีย์ที่สร้างเป็น **Inference only** ก่อนมีสิทธิ์แบบกำหนดขอบเขตจะแสดงเป็น **Restricted** โดย **Models** ตั้งเป็น **Request**

### ใครให้สิทธิ์อะไรได้บ้าง

- **สมาชิก** สร้างได้เฉพาะคีย์ส่วนตัวที่แสดงรายการและเรียกใช้โมเดล Console จะแสดงข้อความ “This key can list and call
  models as you.” แทนตัวเลือกสิทธิ์
- **เจ้าของและผู้ดูแล** ให้ **All**, **Restricted** หรือ **Read only** กับคีย์ส่วนตัวได้ไม่เกินบทบาทของตัวเอง
  ค่าเริ่มต้นคือ **Restricted** โดย **Models** ตั้งเป็น **Request** หากภายหลังถูกลดบทบาท คีย์ก็จะถูกลดตาม
- **คีย์บัญชีบริการ** ค่าเริ่มต้นคือ **All** เจ้าของและผู้ดูแลเลือกสิทธิ์ได้

### ข้อจำกัด

บางการกระทำต้องมีบุคคลลงชื่อเข้าใช้ Console เสมอ และการสร้างคีย์ด้วยคีย์มีข้อจำกัดเข้มงวด

- ไม่มีคีย์ API ใดเปลี่ยนการตั้งค่า SSO หรือลบเวิร์กสเปซได้
- คีย์บัญชีบริการเชิญสมาชิก เปลี่ยนบทบาท นำสมาชิกออก จัดการการเรียกเก็บเงิน เปลี่ยนการตั้งค่าเวิร์กสเปซ
  จัดการโมเดล หรือสร้าง/ลบบัญชีบริการไม่ได้ แม้จะมี **All**
- **This account's API keys** ใช้ได้เฉพาะกับคีย์บัญชีบริการ และ **All** ไม่รวมถึงสิ่งนี้ คีย์ที่มีสิทธินี้
  สร้างและเพิกถอนคีย์ได้เฉพาะบัญชีบริการของตัวเอง คีย์ใหม่ต้องเป็น **Restricted** อยู่ในขอบเขต
  สิทธิ์ของคีย์ที่สร้าง และรวม **This account's API keys** ไม่ได้
- คีย์ส่วนตัวไม่เคยได้รับ **This account's API keys** และไม่มีคีย์ API ใดสร้างหรือเพิกถอนคีย์ API ส่วนตัวได้

คำขอนอกเหนือสิทธิ์ของคีย์จะคืน HTTP `403`

## การเพิกถอน

| คีย์                 | ใครเพิกถอนได้      | ที่ไหน                                                                             |
| ------------------- | ---------------------- | --------------------------------------------------------------------------------- |
| คีย์ API ส่วนตัว    | สมาชิกเจ้าของคีย์ | **Account › Personal API keys** แล้ว **Revoke**                                  |
| คีย์ API ส่วนตัว    | เจ้าของและผู้ดูแล      | หน้าของสมาชิกใน **Settings › Members** ภายใต้ **API Keys**                   |
| คีย์บัญชีบริการ | เจ้าของและผู้ดูแล      | หน้าของบัญชีบริการใน **Settings › Service accounts** ภายใต้ **API Keys** |

คีย์ยังถูกเพิกถอนโดยอัตโนมัติเมื่อ

- การออกหรือถูกนำออกจากเวิร์กสเปซ หรือถูกถอดผ่าน [SCIM](/console/scim) จะเพิกถอนทุกคีย์
  ที่บุคคลนั้นสร้างในเวิร์กสเปซ รวมถึงคีย์บัญชีบริการ คีย์อื่นบนบัญชีบริการเดียวกันยังใช้งานได้
- การลบบัญชีบริการจะเพิกถอนคีย์ทั้งหมด

เมื่อคีย์ถูกเพิกถอนหรือหมดอายุ คีย์นั้นจะใช้ไม่ได้ทันที และคำขอที่ใช้คีย์นั้นจะได้รับ HTTP `401`
