OpenCode Go ให้คุณใช้โมเดลเขียนโค้ดแบบเปิดยอดนิยมได้อย่างเสถียร โดยมีแพ็กเกจรายเดือนให้เลือกสามแบบ

| แพ็กเกจ         | ราคา                                  | ปริมาณการใช้งานที่รวมอยู่                                                             |
| ------------ | -------------------------------------- | -------------------------------------------------------------------------- |
| **Go**       | **$10/เดือน**                          | การเข้าถึงโมเดลด้านล่างในราคาประหยัด                                      |
| **Go Plus**  | **$40/เดือน**                          | ขีดจำกัดการใช้งานที่สูงขึ้นสำหรับโมเดลด้านล่าง                                |
| **Go Teams** | **$20/สมาชิก/เดือน** ขั้นต่ำ 2 สมาชิก | สมาชิกแต่ละคนมีขีดจำกัดของตัวเอง สูงกว่า Go $5/เดือนในทุกโมเดล |

Go ทำงานเหมือนผู้ให้บริการรายอื่นใน OpenCode เมื่อสมัคร OpenCode Go คุณจะได้รับคีย์ API บริการนี้เป็น **ทางเลือก** คุณใช้ OpenCode ได้โดยไม่ต้องสมัคร

บริการนี้ออกแบบสำหรับผู้ใช้ต่างประเทศเป็นหลักและให้การเข้าถึงทั่วโลกที่เสถียร

## วิธีการทำงาน

1. ลงชื่อเข้าใช้ [OpenCode Console](https://opencode.ai/console) สมัคร Go, Go Plus หรือ Go Teams เพิ่มรายละเอียดการเรียกเก็บเงิน แล้วคัดลอกคีย์ API
2. รัน `/connect` ใน TUI เลือก **OpenCode Go** แล้ววางคีย์ API

   ```text
   /connect
   ```

3. รัน `/models` เพื่อเลือกโมเดลที่ใช้ได้ผ่าน Go

   ```text
   /models
   ```

<Callout>
  Go และ Go Plus ครอบคลุมสมาชิกที่สมัครและคีย์ API ของเวิร์กสเปซ สมาชิกคนอื่นที่คุณเชิญจะใช้โมเดลฟรี
  หรือยอดคงเหลือของเวิร์กสเปซ ทั้งสองแบบอัปเกรดเป็น Go Teams ได้ทุกเมื่อ โดยได้เครดิตส่วนที่ยังไม่ได้ใช้ของวงเงินเดือนนั้นคืน
  Go Teams ให้สมาชิกทุกคนในเวิร์กสเปซใช้แพ็กเกจได้ในราคา $20 ต่อสมาชิกต่อเดือน ขั้นต่ำ 2 คน
  ($40/เดือน) ขั้นต่ำนี้รวมสิทธิ์ของสมาชิกคนที่สองไว้แล้ว จึงไม่คิดเงินเพิ่มเมื่อสมาชิกคนนั้นเข้าร่วม หลังจากนั้น หากมีสมาชิกเข้าร่วมกลางรอบ ระบบจะเรียกเก็บ $20 และให้วงเงินรายเดือนเต็มจำนวน บัญชีบริการไม่ได้รับสิทธิ์ใช้งาน Go Teams
</Callout>

ดู[รายการโมเดลปัจจุบัน](https://opencode.ai/console/go#models) รายการอาจเปลี่ยนเมื่อเราทดสอบและเพิ่มโมเดลใหม่

### เปิดใช้งานโมเดลที่จำกัด

Go ใช้การตั้งค่าความเป็นส่วนตัวของเวิร์กสเปซ โดยค่าเริ่มต้น ระบบจะบล็อกเอนด์พอยต์แบบเสียค่าใช้จ่ายที่นำข้อมูลคำขอไปใช้ฝึกโมเดล
และอนุญาตเฉพาะภูมิภาค **Europe & United States** หากเวิร์กสเปซยังไม่ได้บันทึกการตั้งค่าความเป็นส่วนตัว
ระบบจะอนุญาต **Global** สำหรับคำขอจากจีนด้วย

ใน **Settings › Privacy** เจ้าของหรือผู้ดูแลเปิดใช้งานได้

- **DeepSeek V4.1 Flash และ V4 Pro:** เลือก **Global** ภายใต้ **Regions**
- **LongCat 2.5:** เลือก **Global** ภายใต้ **Regions**
- **Muse Spark 1.3 Contributor และ Muse Spark 1.2 Contributor:** เปิด **Allow paid endpoints that train on request data**

ดู[ความเป็นส่วนตัว](#privacy)สำหรับเงื่อนไขการฝึกและการเก็บรักษาข้อมูลของแต่ละโมเดล

## จ่ายด้วยเครดิต

เจ้าของและผู้ดูแลใช้เครดิตของเวิร์กสเปซจ่ายค่า Go รวมถึงค่าต่ออายุและค่าอัปเกรดได้ เลือก **Credit** เป็น
วิธีชำระเงินตอนสมัคร หรือเปลี่ยนภายหลังใน **Manage subscription** วิธีนี้แยกจาก
[Extra Usage](#usage-beyond-limits) ซึ่งใช้จ่ายเฉพาะค่าใช้งานที่เกินขีดจำกัด

- ราคาเต็มจะหักจากยอดเครดิตของคุณ หากยอดไม่พอ คุณเติมเครดิตก่อนได้
- ระบบจะหักค่าต่ออายุจากเครดิตเมื่อสิ้นรอบ หากเครดิตไม่พอ คุณยังใช้ Go ได้ระหว่างที่ระบบลองต่ออายุอีกครั้ง
  เมื่อผ่านไป 1, 3 และ 7 วันหลังสิ้นรอบ และจะลองอีกครั้งทันทีเมื่อเติมเครดิตจนพอ หากครั้งสุดท้ายยังไม่สำเร็จ การสมัคร Go จะสิ้นสุด
- เวิร์กสเปซที่ใช้[การเรียกเก็บเงินแบบออกใบแจ้งหนี้](/console/billing#invoiced-billing)จ่ายค่า Go ด้วยเครดิตไม่ได้
- เมื่อมีการคืนค่า Go ที่จ่ายด้วยเครดิต ระบบจะคืนเงินเข้ายอดเครดิตและสิ้นสุดรอบ Go นั้น

## ไคลเอนต์ที่ใช้ Go ได้

OpenCode Go ออกแบบมาสำหรับ [OpenCode](https://opencode.ai) และเอเจนต์เขียนโค้ดอื่น
ที่ส่งคำขอลักษณะคล้ายกัน เราตรวจสอบทราฟฟิกเพื่อป้องกันการใช้งานในทางที่ผิดซึ่งส่งผลกระทบต่อผู้ใช้รายอื่น

ไคลเอนต์ของคุณควร

1. ส่งทราฟฟิกแบบเอเจนต์เขียนโค้ดทั่วไป
2. ระบุชื่อไคลเอนต์ในค่า user agent เช่น `my-coding-agent/1.0` แทน
   ชื่อ SDK หรือไลบรารี HTTP ทั่วไป
3. ส่ง ID เซสชันเดิมใน `x-opencode-session` ตลอดแต่ละบทสนทนา เพื่อให้เราปรับการกำหนดเส้นทางและ
   การแคชพรอมต์ให้มีประสิทธิภาพขึ้น

คำขอ[การตัดสินใจ](#decision-models)และ [embedding](#embedding-models) ไม่ต้องใช้ `x-opencode-session` ไคลเอนต์ใดก็ได้
เช่น ไลบรารี RAG ผู้ให้บริการหน่วยความจำ หรือสคริปต์ จึงเรียกได้ด้วยคีย์ Go ของคุณ

ดู [Harnesses](/console/harnesses) เพื่อตั้งค่า Go ใน Claude Code, Codex, Hermes, OpenClaw, Pi และ Raycast

## ขีดจำกัดการใช้งาน

โมเดลแบบเสียค่าใช้จ่ายทั้งหมดใน Go ใช้วงเงินเดียวกัน ส่วนใน Go Teams สมาชิกแต่ละคนมีวงเงินของตัวเองสำหรับใช้กับทุกโมเดล

- **ขีดจำกัด 5 ชั่วโมง** คือ 20% ของวงเงินรายเดือน รอบนี้เริ่มเมื่อคุณใช้วงเงินครั้งแรกและสิ้นสุดหลังผ่านไป 5 ชั่วโมง
- **ขีดจำกัดรายสัปดาห์** คือ 50% ของวงเงินรายเดือน รีเซ็ตวันจันทร์เวลา 00:00 UTC
- **วงเงินรายเดือน** รีเซ็ตเมื่อเริ่มรอบที่ชำระเงินแล้วรอบใหม่

การสลับโมเดลใช้จากวงเงินเดียวกัน หากถึงขีดจำกัด คุณใช้โมเดลฟรีหรือเปิด
[Extra Usage](#usage-beyond-limits) เพื่อใช้เครดิต Console จนกว่าจะมีวงเงินเหลืออีกครั้ง

ขีดจำกัด[รายเดือน](https://opencode.ai/console/go#limits)ของแต่ละโมเดลแสดงปริมาณการใช้งานที่แพ็กเกจของคุณครอบคลุมหากคุณใช้เฉพาะโมเดลนั้นตลอดเดือน
ตัวอย่างเช่น การใช้งาน $1.50 บนโมเดลที่มีขีดจำกัด $15 ใช้วงเงินรายเดือน 10% และ $6 บนโมเดล
ที่มีขีดจำกัด $60 ก็เช่นกัน การตอบกลับของ Go รายงานว่าคำขอแต่ละครั้งนับไปเท่าใดใน [`opencode.allowance`](/console/api/inference#cost)

[ราคาโทเคน](https://opencode.ai/console/go#pricing)คิดต่อ 1M โทเคน และใช้อัตราเดียวกันสำหรับ Go, Go Plus และ Go Teams

โมเดล[การตัดสินใจ](#decision-models)และ [embedding](#embedding-models) คิดในราคาปลีก ไม่มีส่วนลด Go
ขีดจำกัดรายเดือนจึงเท่ากับที่คุณจ่าย คือ $10 บน Go และ $40 บน Go Plus บน Go Teams คือ $15 สูงกว่า Go $5 เช่นเดียวกับทุก
โมเดล

**Beam Free:** ฟรีในระยะเวลาจำกัด ไม่มีให้ใช้ในแองโกลา เบลารุส กัมพูชา จีน (รวมฮ่องกงและมาเก๊า) คิวบา สาธารณรัฐประชาธิปไตยคองโก อิเควทอเรียลกินี อิหร่าน อิรัก ลาว ลิเบีย ไนจีเรีย เกาหลีเหนือ รัสเซีย ซีเรีย เติร์กเมนิสถาน อุซเบกิสถาน เวเนซุเอลา หรือไครเมีย โดเนตสค์ และลูฮันสค์ของยูเครน

**Gemini 4 Argon:** ส่วนลด 50% ใช้ถึง 30 พฤศจิกายน 2026

**HungerG Free:** ฟรีในระยะเวลาจำกัด

### คำขอโดยประมาณ

หน้า Go ของ Console [ประเมินคำขอต่อ 5 ชั่วโมง](https://opencode.ai/console/go#limits)สำหรับแต่ละโมเดล จาก
รูปแบบการใช้ Go ทั่วไป การใช้งานจริงแตกต่างกัน

คุณติดตามการใช้งานปัจจุบันได้ใน [console](https://opencode.ai/console) หรือด้วย[เอนด์พอยต์การใช้งาน](#usage)

<Callout type="tip">หากถึงขีดจำกัดการใช้งาน คุณใช้โมเดลฟรีต่อไปได้</Callout>

ขีดจำกัดการใช้งานอาจเปลี่ยนเมื่อเราเรียนรู้จากการใช้งานช่วงแรกและความคิดเห็น

### การใช้งานเกินขีดจำกัด

หากมีเครดิตคงเหลือใน Console คุณเปิด **Extra Usage** ในหน้า
**Go** ได้ เมื่อใช้ถึงขีดจำกัด Go จะหักค่าใช้งานจาก [ยอดคงเหลือแบบจ่ายตามการใช้งาน](/console/models#pricing)
แทนการบล็อกคำขอ

Go Teams เปิด **Extra Usage** ไว้โดยค่าเริ่มต้น คุณปิดหรือเปิดใหม่ได้ในหน้า **Go**

### สาเหตุที่บางโมเดลมีวงเงินการใช้งานน้อยกว่า

วงเงินรายเดือนที่รวมอยู่ใน Go แตกต่างกันไปตามโมเดล

สำหรับโมเดลส่วนใหญ่ เราได้รับส่วนลดจากการซื้อในปริมาณมากและจองกำลังประมวลผล GPU ไว้ล่วงหน้า เราจึงนำต้นทุนที่ประหยัดได้มาเพิ่มวงเงินการใช้งานรายเดือนให้คุณ

สำหรับบางโมเดล เราไม่มีโอกาสเจรจาส่วนลดหรือโฮสต์ในต้นทุนที่ต่ำลง ไม่ว่าจะเพราะโมเดลใหม่หรือเพราะราคาสาธารณะมีส่วนลดอยู่แล้ว

สำหรับโมเดลเหล่านี้ คุณยังได้มากกว่าการจ่ายให้ผู้ให้บริการโมเดลโดยตรงเล็กน้อย นี่คือเหตุผลที่ปริมาณการใช้งานรายเดือนที่รวมอยู่ต่ำกว่า

## เอนด์พอยต์

คุณยังเข้าถึงโมเดล Go ผ่าน API ที่ `https://opencode.ai/inference/go` ได้ ดู
[ID, พาธ และแพ็กเกจ AI SDK](https://opencode.ai/console/go#api) ของแต่ละโมเดล แต่ละโมเดลแสดงพร้อม API เนทีฟ แต่โมเดล
ข้อความทุกตัวยังใช้ผ่าน API อื่นได้ ซึ่ง Console จะแปลรูปแบบให้ ดู
[Base URL](/console/harnesses#base-urls) สำหรับชุดทั้งหมด

แพ็กเกจ AI SDK เหล่านี้สำหรับแอปที่เรียก Go โดยตรง หากต้องการใช้ Go ใน OpenCode ให้เชื่อมต่อด้วย `/connect` และตั้ง
[โมเดล](/models)ในรูปแบบ `opencode-go/<model-id>`

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "model": "opencode-go/kimi-k3",
}
```

### โมเดล

ดึงรายการโมเดลที่ใช้ได้ทั้งหมดและข้อมูลเมตาจากเอนด์พอยต์ models

```bash
curl https://opencode.ai/inference/go/v1/models
```

ดู[API รายการโมเดล](/console/api/models)สำหรับทุกฟิลด์ในการตอบกลับ รวมถึงขีดจำกัดการใช้งานรายเดือนของ Go

### โมเดลตัดสินใจ

โมเดลตัดสินใจตอบคำถามที่ระบุชนิดไว้เกี่ยวกับ `state` แทนการสร้างข้อความ ส่งคำขอ System One
แบบเดียวกับบน[โมเดลของ Console](/console/models#jev) ไปยัง `https://opencode.ai/inference/go/systemone/v1/systemone` ด้วยคีย์ Go
ของคุณ

```bash
curl https://opencode.ai/inference/go/systemone/v1/systemone \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jev-1.14",
    "state": "My payments have failed for three days and I am losing sales.",
    "questions": {
      "is_urgent": {
        "type": "noul",
        "instructions": "Does this request require urgent attention?"
      }
    }
  }'
```

| โมเดล                               | ID โมเดล            | อินพุต  | เอาต์พุต | อ่านแคช | เขียนแคช |
| ----------------------------------- | ------------------- | ------ | ------ | ----------- | ------------ |
| Jev 1.14                            | jev-1.14            | $0.042 | ฟรี   | -           | -            |
| Gemini Decision 1                   | gemini-decision-1   | $0.10  | ฟรี   | -           | -            |
| GPT 6 Luna Decision (≤ 272K tokens) | gpt-6-luna-decision | $0.10  | ฟรี   | $0.01       | $0.125       |
| GPT 6 Luna Decision (> 272K tokens) | gpt-6-luna-decision | $0.20  | ฟรี   | $0.02       | $0.25        |

- ราคาคิดต่อ 1M โทเคน
- คำขอในรูปแบบ Decisions ของ OpenAI ใช้ได้ที่ `https://opencode.ai/inference/go/openai/v1/decisions`
- ดู [Jev](/console/models#jev) สำหรับชนิดคำถาม และ
  [GPT 6 Luna Decision และ Gemini Decision 1](/console/models#gpt-6-luna-decision-and-gemini-decision-1) สำหรับภาพ
  เสียง วิดีโอ และ PDF ใน `state`

### โมเดล embedding

โมเดล embedding เปลี่ยนข้อความเป็นเวกเตอร์ เรียกผ่าน Embeddings API ของ OpenAI ที่
`https://opencode.ai/inference/go/openai/v1/embeddings` ด้วยคีย์ Go ของคุณ

```bash
curl https://opencode.ai/inference/go/openai/v1/embeddings \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "text-embedding-3-small",
    "input": ["hello world", "goodbye"]
  }'
```

| โมเดล                  | ID โมเดล               | อินพุต |
| ---------------------- | ---------------------- | ----- |
| text-embedding-3-small | text-embedding-3-small | $0.02 |
| Qwen3 Embedding 8B     | qwen3-embedding-8b     | $0.01 |

### การใช้งาน

ตรวจสอบว่าใช้งานไปแล้วเท่าใดเมื่อเทียบกับ [ขีดจำกัดการใช้งาน](#usage-limits) เช่น เพื่อนำไปแสดงในไคลเอนต์ของคุณเอง

```bash
curl https://opencode.ai/inference/go/v1/usage \
  -H "Authorization: Bearer <token>"
```

ใช้คีย์เดียวกับที่ใช้กับ Go บน Go และ Go Plus คือ
[คีย์ API ส่วนตัว](/console/api#personal-api-keys)ของสมาชิกที่สมัครหรือ[คีย์บัญชีบริการ](/console/api#service-accounts) บน Go
Teams คือคีย์ API ส่วนตัวของสมาชิกคนใดก็ได้

การตอบกลับแสดงการใช้งานแยกตามขีดจำกัด ได้แก่ `rolling` สำหรับรอบ 5 ชั่วโมง, `weekly` สำหรับรอบสัปดาห์ และ `monthly` สำหรับรอบเดือน

```json
{
  "usage": {
    "rolling": { "status": "ok", "percent": 30, "resetsAt": "2026-11-21T15:00:00.000Z" },
    "weekly": { "status": "rate-limited", "percent": 100, "resetsAt": "2026-11-23T00:00:00.000Z" },
    "monthly": { "status": "ok", "percent": 50, "resetsAt": "2026-12-01T00:00:00.000Z" }
  }
}
```

| ฟิลด์      | ความหมาย                                                                                                    |
| ---------- | ---------------------------------------------------------------------------------------------------------- |
| `status`   | `ok` หรือ `rate-limited` เมื่อใช้ขีดจำกัดหมดแล้ว                                                         |
| `percent`  | สัดส่วนของขีดจำกัดที่ใช้ไป เป็นจำนวนเต็มตั้งแต่ `0` ถึง `100`                                        |
| `resetsAt` | เวลาที่วงเงินรีเซ็ตในรูปแบบ ISO 8601 หากยังไม่เริ่มรอบ 5 ชั่วโมง `rolling` จะแสดงเวลาอีก 5 ชั่วโมงนับจากตอนนี้ |

คำขอที่ไม่มีคีย์ที่ถูกต้องจะได้รับ HTTP `401` ส่วนคำขอที่ใช้คีย์ที่ไม่มีสิทธิ์ใช้ Go จะได้รับ HTTP `403` พร้อมข้อความอธิบาย
เหตุผล เช่น เมื่อเวิร์กสเปซไม่มีการสมัครสมาชิก Go ที่ใช้งานอยู่

```json
{ "type": "error", "error": { "type": "EntitlementError", "message": "OpenCode Go subscription required." } }
```

## ที่มา

โมเดลแบบเปิดพัฒนาไปมาก ตอนนี้ทำงานเขียนโค้ดได้ใกล้เคียงโมเดลแบบปิด และมีผู้ให้บริการหลายรายที่แข่งขันกันให้บริการได้ในราคาที่มักถูกกว่ามาก

แต่การหาแหล่งที่ให้บริการได้เสถียรและตอบสนองเร็วอาจไม่ง่าย เพราะผู้ให้บริการแต่ละรายมีคุณภาพและความพร้อมใช้งานต่างกัน

<Callout type="tip">เราคัดเลือกและทดสอบโมเดลกับผู้ให้บริการที่ทำงานร่วมกับ OpenCode ได้ดี</Callout>

เพื่อแก้ปัญหานี้ เราทำหลายอย่าง

1. เราคัดเลือกโมเดลแบบเปิดมาทดสอบ แล้วปรึกษาทีมผู้พัฒนาโมเดลแต่ละตัวเพื่อหาวิธีรันที่เหมาะที่สุด
2. เราทำงานร่วมกับผู้ให้บริการบางรายเพื่อให้แน่ใจว่าระบบให้บริการโมเดลได้อย่างถูกต้อง
3. เราวัดประสิทธิภาพของโมเดลแต่ละตัวเมื่อใช้กับผู้ให้บริการแต่ละราย แล้วคัดเป็นรายการที่เราแนะนำได้อย่างมั่นใจ

Go, Go Plus และ Go Teams ให้การเข้าถึงโมเดลเหล่านี้ทั้งหมด เลือกแพ็กเกจที่เหมาะกับปริมาณการใช้ของคุณ หรือ Go
Teams เพื่อครอบคลุมทั้งทีม

## เป้าหมาย

เราสร้าง OpenCode Go เพื่อ

1. ทำให้การเขียนโค้ดด้วย AI **เข้าถึงได้**สำหรับผู้คนมากขึ้น ด้วยการสมัครสมาชิกราคาต่ำ
2. ให้ใช้โมเดลเขียนโค้ดแบบเปิดที่ดีที่สุดได้อย่าง**เสถียร**
3. คัดสรรโมเดลที่**ผ่านการทดสอบและทำเบนช์มาร์ก**สำหรับการใช้งานเอเจนต์เขียนโค้ด
4. **ไม่ผูกมัด** ด้วยการให้คุณใช้ผู้ให้บริการรายอื่นกับ OpenCode ได้เช่นกัน
