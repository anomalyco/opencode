title: "การค้นหาเว็บของ Console"

---

Console ให้บริการค้นหาเว็บแบบโฮสต์แก่ผู้ใช้ OpenCode ที่เชื่อมต่ออยู่ เจ้าของหรือผู้ดูแลเวิร์กสเปซเปิดใช้งานครั้งเดียวสำหรับเวิร์กสเปซ โดยไม่ต้องมอบคีย์ผู้ให้บริการค้นหาแยกให้สมาชิก

การค้นหาที่สำเร็จแต่ละครั้งมีค่าใช้จ่าย **$0.01** ระบบจะหักจากยอดคงเหลือของเวิร์กสเปซและนับรวมในวงเงินการใช้จ่ายของสมาชิก

## เปิดใช้งาน

1. เข้าสู่ระบบ [Console](https://opencode.ai/console) ในฐานะเจ้าของหรือผู้ดูแลเวิร์กสเปซ
2. เปิด **Integrations** แล้วคลิก **Set up** ที่ **Hosted Web Search**
3. คลิก **Enable**

จากนั้นสมาชิกแต่ละคนเชื่อมต่อ OpenCode กับเวิร์กสเปซด้วย `/connect`

```text
/connect
```

การกำหนดค่าของเวิร์กสเปซจะเลือก **OpenCode Web Search** เป็นผู้ให้บริการเริ่มต้น สมาชิกไม่จำเป็นต้องตั้งค่า `websearch.provider` หรือเพิ่มคีย์ API ของผู้ให้บริการ สมาชิกที่ตั้งค่า `websearch.provider` ของตัวเองจะยังคงใช้ตัวเลือกนั้นแทน

## การค้นหา

ถาม OpenCode เพื่อขอข้อมูลล่าสุดในพรอมต์ การค้นหาจะทำงานจาก OpenCode ไม่ใช่จากหน้าแบบอินเทอร์แอกทีฟใน Console

```text
Find the latest Bun release and summarize the changes with source links.
```

ผู้ให้บริการแบบโฮสต์จะค้นหาเว็บสาธารณะและคืนผลลัพธ์สูงสุดแปดรายการ OpenCode ใช้ผลลัพธ์เหล่านั้นเพื่อตอบพรอมต์และอ้างอิงแหล่งที่มา

ดู[คู่มือการค้นหาเว็บ](/websearch) สำหรับการกำหนดค่าสิทธิ์หรือปิดใช้งานเครื่องมือนี้

## การเรียกเก็บเงิน

Console จะเรียกเก็บ **$0.01** เมื่อการค้นหาคืนชุดผลลัพธ์ที่ถูกต้อง การค้นหาที่ล้มเหลวหรือถูกจำกัดอัตราจะไม่ถูกเรียกเก็บเงิน

การค้นหาเว็บจะแสดงแยกจากการใช้งานโมเดลใน **Activity › Usage**, **Activity › Overview**, กิจกรรมของสมาชิก, ใบแจ้งหนี้ และไฟล์ CSV ที่ส่งออก นโยบายงบประมาณแบบครอบคลุมการใช้จ่ายทั้งหมดจะรวมค่าใช้จ่ายการค้นหาเว็บด้วย

## ความเป็นส่วนตัว

การค้นหาเว็บแบบโฮสต์ไม่มีการเก็บรักษาข้อมูล (zero data retention) Console และผู้ให้บริการค้นหาแบบโฮสต์จะประมวลผลแต่ละคำค้นและผลลัพธ์โดยไม่จัดเก็บเนื้อหา
