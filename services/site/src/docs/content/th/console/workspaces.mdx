เวิร์กสเปซเก็บทุกอย่างใน [Console](https://opencode.ai/console): สมาชิก เครดิต งบประมาณ ผู้ให้บริการ
นโยบาย และบัญชีบริการ การใช้งานและการเรียกเก็บเงินติดตามแยกตามเวิร์กสเปซ

เวิร์กสเปซมีสมาชิกเพียงคนเดียวได้ คุณใช้เครดิต [ผู้ให้บริการของคุณเอง](/console/providers) งบประมาณ และ [Go](/console/go) ได้ด้วยตัวเอง
และ[เชิญสมาชิก](/console/members)เฉพาะเมื่อจำเป็น

## เวิร์กสเปซแรกของคุณ

Console สร้างเวิร์กสเปซชื่อ **Personal** เมื่อคุณสมัคร โดยคุณเป็นเจ้าของและสมาชิกเพียงคนเดียว หากคุณสมัคร
จากคำเชิญ คุณจะเข้าร่วมเวิร์กสเปซที่เชิญแทน และจะไม่มีการสร้างเวิร์กสเปซ Personal

## สร้างเวิร์กสเปซ

1. เปิดเมนูเวิร์กสเปซในแถบด้านบน
2. คลิก **Create Workspace**
3. ป้อน **Workspace name** แล้วคลิก **Create**

คุณจะเป็นเจ้าของเวิร์กสเปซใหม่

## สลับเวิร์กสเปซ

เลือกเวิร์กสเปซอื่นจากเมนูเวิร์กสเปซ Console จะพาคุณอยู่ที่หน้าเดิม การสลับจาก
`/acme/settings/members` จึงเปิดหน้าสมาชิกของเวิร์กสเปซอื่น

คำเชิญที่รอดำเนินการจะอยู่ด้านบนของเมนูเดียวกัน ดู[สมาชิก](/console/members#accept-an-invitation)

## เชื่อมต่อ OpenCode

รัน `/connect` ใน OpenCode แล้วเลือกเวิร์กสเปซในเบราว์เซอร์ OpenCode จะใช้โมเดล
นโยบาย และงบประมาณของเวิร์กสเปซนั้น

```text
/connect
```

รัน `/connect` อีกครั้งเพื่อสลับ OpenCode ไปยังเวิร์กสเปซอื่น [นโยบาย](/policies#console) ของเวิร์กสเปซจะถูกแทนที่
ด้วยของเวิร์กสเปซใหม่ และถูกล้างเมื่อคุณยกเลิกการเชื่อมต่อ

## บทบาท

ทุกสมาชิกมีหนึ่งบทบาท สมาชิกใหม่เข้าร่วมเป็น **Member** เสมอ

| บทบาท   | ทำได้                                                                                                               |
| ------ | -------------------------------------------------------------------------------------------------------------------- |
| Member | ใช้ OpenCode ดูการใช้งาน บันทึก และงบประมาณของตัวเอง                                                                 |
| Admin  | ทุกอย่างที่สมาชิกทำได้ บวกการจัดการสมาชิก การเรียกเก็บเงิน งบประมาณ ผู้ให้บริการ นโยบาย บัญชีบริการ และการตั้งค่า |
| Owner  | ทุกอย่างที่ผู้ดูแลทำได้ บวกการจัดการ SSO และการซิงค์ไดเรกทอรี การให้บทบาท Owner และการลบเวิร์กสเปซ         |

สมาชิกเห็นการใช้งานและบันทึกของตัวเองใน **Activity** พร้อมลีดเดอร์บอร์ดเมื่อเปิดให้สมาชิกเห็น
เมื่อเวิร์กสเปซมีการสมัครสมาชิก [Go Teams](/console/go) พวกเขาจะเห็น **Go** พร้อมขีดจำกัดของตัวเองด้วย
เปิด **Account** ได้จากเมนูบัญชี

### กฎของบทบาท

- เวิร์กสเปซมีเจ้าของได้หลายคน และจะมีอย่างน้อยหนึ่งคนเสมอ
- คุณกำหนดบทบาทที่สูงกว่าของตัวเองไม่ได้ เฉพาะเจ้าของเท่านั้นที่ตั้งใครเป็นเจ้าของได้
- คุณเปลี่ยนบทบาทของตัวเองไม่ได้

### โอนความเป็นเจ้าของ

1. ในฐานะเจ้าของ เปิด **Settings › Members** แล้วตั้งบทบาทของเจ้าของใหม่เป็น **Owner**
2. ขอให้เจ้าของใหม่เปลี่ยนบทบาทของคุณเป็น **Admin** หรือ **Member**

## ลบเวิร์กสเปซ

เฉพาะเจ้าของเท่านั้นที่ลบเวิร์กสเปซได้ และเฉพาะเมื่อเป็นสมาชิกของเวิร์กสเปซอื่นอย่างน้อยหนึ่งแห่ง

1. เปิด **Settings › General** แล้วคลิก **Delete workspace**
2. ทำเครื่องหมายยืนยันทุกข้อ
3. คลิก **Delete workspace** เพื่อยืนยัน

การลบมีผลทันทีและย้อนกลับไม่ได้

- สมาชิกสูญเสียการเข้าถึงทันที
- คีย์ API ของบัญชีบริการทั้งหมดและคำเชิญที่รอดำเนินการจะถูกเพิกถอน
- การเติมเงินอัตโนมัติหยุด
- การสมัครสมาชิก Go ที่ใช้งานอยู่สิ้นสุด
- เครดิตที่เหลือทั้งหมดจะหมดสิทธิ์ใช้งาน

<Callout type="warning">คุณจะลบเวิร์กสเปซไม่ได้ระหว่างที่ระบบประมวลผลการชำระเงิน โปรดลองใหม่ในอีกไม่กี่นาที</Callout>

## ออกจากเวิร์กสเปซ

1. เปิด **Account** จากเมนูบัญชี
2. ภายใต้ **Connected workspaces** คลิก **Leave** ข้างเวิร์กสเปซ
3. ยืนยันด้วย **Leave workspace**

เจ้าของคนสุดท้ายออกไม่ได้ ให้ตั้งสมาชิกคนอื่นเป็นเจ้าของก่อน ในเวิร์กสเปซที่ใช้ SSO หรือการซิงค์ไดเรกทอรี
ผู้ให้บริการระบุตัวตนของคุณเป็นผู้จัดการสมาชิก คุณจึงออกจากเวิร์กสเปซผ่าน Console ไม่ได้ หากออกแล้วต้องการกลับเข้าร่วม ให้ขอคำเชิญใหม่
