งบประมาณจำกัดการใช้จ่ายรายเดือนผ่านนโยบาย เจ้าของและผู้ดูแลจัดการได้ใน **Controls**

## ระดับงบประมาณ

| กลุ่มเป้าหมายของนโยบาย | มีผลกับ                                           |
| ---------------------- | ---------------------------------------------------- |
| ทั้งเวิร์กสเปซ          | การใช้จ่ายรวมของสมาชิกและบัญชีบริการทั้งหมด   |
| สมาชิกทั้งหมด          | สมาชิกแต่ละคน หรือวงเงินร่วมหนึ่งวงเงินสำหรับสมาชิกทั้งหมด |
| สมาชิกที่มีแท็ก        | สมาชิกที่มีแท็กที่เลือก                         |
| สมาชิกเหล่านี้         | สมาชิกที่ระบุ                                     |
| บัญชีบริการทั้งหมด     | บัญชีบริการแต่ละบัญชี หรือวงเงินร่วมหนึ่งวงเงิน        |
| บัญชีบริการเหล่านี้    | บัญชีบริการที่ระบุ                                |

คำขอต้องไม่เกินวงเงินของงบประมาณทุกข้อที่ใช้กับคำขอนั้น วงเงินที่สูงกว่าไม่ได้ลบล้างวงเงินที่ต่ำกว่า หากไม่ได้ตั้งงบประมาณไว้เลย จะไม่มีการจำกัดการใช้จ่ายด้วยงบประมาณ

## งบประมาณของเวิร์กสเปซ

งบประมาณของเวิร์กสเปซบล็อกคำขอของทุกคนเมื่อเวิร์กสเปซใช้ถึงงบ

1. เปิด **Controls** แล้วคลิก **Add policy**
2. เลือก **Entire workspace** แล้วเพิ่มกฎ **Budget**
3. ป้อนขีดจำกัดรายเดือนเป็น USD แล้วคลิก **Save**

## งบประมาณของสมาชิก

เลือก **All members** ในนโยบายเพื่อให้สมาชิกแต่ละคนมีวงเงินรายเดือน หรือแบ่งจำนวนเดียวให้ทั้งกลุ่ม
เลือกสมาชิกหรือแท็กที่ระบุเพื่อครอบคลุมกลุ่มที่เล็กกว่า

การตั้งงบประมาณให้คนเดียว

1. เปิดสมาชิกใน **Settings › Members**
2. คลิก **Create budget policy** เพื่อเปิดตัวสร้างนโยบายโดยเลือกบุคคลนั้นไว้แล้ว
3. ป้อนจำนวนเงินแล้วคลิก **Save**

หน้าของสมาชิกจะแสดงนโยบายที่บังคับใช้ หากงบประมาณสำหรับสมาชิกทั้งหมดครอบคลุมเขาด้วย
ขีดจำกัดทั้งสองจะบังคับใช้

## งบประมาณของบัญชีบริการ

ใน **Controls** เลือก **All service accounts** หรือ **These service accounts** เพิ่มกฎ **Budget** แล้วตั้ง
วงเงินรายเดือนแบบรายบัญชีหรือร่วมกัน นโยบายจะมีผลกับทุกคีย์ของบัญชีเหล่านั้น

## จำนวนเงินและการรีเซ็ต

- จำนวนเงินเป็นดอลลาร์สหรัฐ ทศนิยมไม่เกินสองตำแหน่ง
- งบประมาณรีเซ็ตในวันที่ 1 ของทุกเดือนเวลา 00:00 UTC
- งบประมาณ `$0` บล็อกการใช้จ่ายทั้งหมดที่นับเข้างบประมาณ
- การเพิ่มหรือเปลี่ยนงบประมาณจะรวมการใช้จ่ายที่บันทึกไว้แล้วในเดือนนั้นด้วย และไม่รีเซ็ตวงเงิน

## สิ่งที่นับเข้างบประมาณ

โดยค่าเริ่มต้น งบประมาณครอบคลุม **All spend** คุณสามารถจำกัดให้เหลือเฉพาะโมเดลที่เลือกได้ จากนั้นจะนับ
เฉพาะโมเดลเหล่านั้น โดยใช้วงเงินเดียวสำหรับทั้งชุด หรือวงเงินแยกสำหรับแต่ละโมเดล

| การใช้จ่าย                                                               | นับเข้างบประมาณ        |
| ------------------------------------------------------------------- | ---------------------------- |
| โมเดลของ Console แบบเสียค่าใช้จ่าย                                                 | ได้                          |
| โมเดลบน[ผู้ให้บริการของคุณเอง](/console/providers)ที่กำหนดราคาไว้ | ได้ ตามราคาที่กำหนด |
| [การค้นหาเว็บ](/console/websearch)                            | ได้ สำหรับงบประมาณแบบ All spend   |
| โมเดลฟรี                                                         | ไม่                           |
| การใช้งาน [Go](/console/go) ภายในแพ็กเกจ                             | ไม่                           |
| การใช้งาน Go เพิ่มเติมที่จ่ายจากเครดิต                                    | ได้                          |

## เมื่องบประมาณถูกใช้ครบ

คำขอใหม่จะล้มเหลวด้วย HTTP `429` จนกว่างบประมาณจะรีเซ็ตหรือเจ้าของ/ผู้ดูแลเพิ่มให้ การตอบกลับระบุ
ว่าล้มเหลวเพราะงบประมาณของนโยบาย แต่ไม่ระบุชื่องบประมาณ เปิดคำขอใน **Activity › Logs** เพื่อดูนโยบาย
ที่บล็อกคำขอนั้น

```text
Upstream request failed: Policy budget exceeded
```

ระบบตรวจสอบงบประมาณตอนเริ่มประมวลผลคำขอ คำขอที่เริ่มไปแล้วจะทำงานจนเสร็จ ยอดใช้จ่ายรวมจึงอาจสูงกว่าวงเงินเล็กน้อย

## ติดตามการใช้จ่าย

สมาชิกแต่ละคนเห็นการใช้จ่ายและขีดจำกัดของตัวเองใน **Activity** เปิด **My usage** สำหรับ **Activity › Overview**
ซึ่งรวมรายละเอียดงบประมาณและวันที่รีเซ็ต

เจ้าของและผู้ดูแลเปิด **Activity › Usage** จากกราฟการใช้จ่ายได้ โดยแยกต้นทุนตามวัน โมเดล และ
บุคคล และปุ่ม **Export usage** ดาวน์โหลดยอดรวมรายวันของ 7, 30 หรือ 90 วันล่าสุดเป็น CSV หากต้องการดาวน์โหลด
ไฟล์เดียวกันจากสคริปต์ ให้ใช้ [Usage export API](/console/api/usage-export)
