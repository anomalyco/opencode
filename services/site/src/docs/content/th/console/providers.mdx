เชื่อมต่อบัญชีผู้ให้บริการที่คุณจ่ายอยู่แล้ว เช่น Anthropic, OpenAI หรือ AWS Bedrock แล้วแชร์โมเดลให้ทุกคนในเวิร์กสเปซ
Console เก็บข้อมูลรับรองและให้บริการแต่ละผู้ให้บริการผ่านเกตเวย์ สมาชิกจึงใช้โมเดลได้โดยไม่เห็นคีย์ของผู้ให้บริการ
เกตเวย์เดียวกันใช้ได้จากเครื่องมือของคุณเองผ่าน [Providers API](/console/api/providers)

เจ้าของและผู้ดูแลจัดการผู้ให้บริการจากแท็บ **Providers** สมาชิกจะได้รับโมเดลที่เปิดใช้งานใน OpenCode หลังจาก
รัน `/connect`

## เชื่อมต่อผู้ให้บริการ

1. เปิด **Providers** แล้วคลิก **Connect Provider**
2. เลือกผู้ให้บริการจากแคตตาล็อกแล้วป้อนคีย์ API
3. หากต้องการทดสอบ ให้คลิก **Test connection** จากนั้นคลิก **Save**

แคตตาล็อกรวม Anthropic, OpenAI, Google, xAI, DeepSeek, Mistral, Groq, OpenRouter และอีกมากมาย ผู้ให้บริการ
ในแคตตาล็อกมีโมเดลกำหนดค่าไว้ล่วงหน้า

### ผู้ให้บริการแบบคลาวด์

ผู้ให้บริการแบบคลาวด์ต้องใช้รายละเอียดเพิ่มเติมเล็กน้อย

| ผู้ให้บริการ              | รายละเอียด                               |
| --------------------- | ------------------------------------- |
| Azure                 | ชื่อทรัพยากรและคีย์ API             |
| AWS Bedrock           | รีเจียนและคีย์ API                    |
| Google Vertex AI      | รีเจียนและ JSON ของบัญชีบริการ       |
| Cloudflare AI Gateway | ID บัญชี, ID เกตเวย์ และโทเคน API |
| Databricks            | URL ของเวิร์กสเปซและโทเคน |

### ผู้ให้บริการแบบกำหนดเอง

คลิก **Add Custom Provider** เพื่อเชื่อมต่อเอนด์พอยต์อื่น แล้วเพิ่มโมเดลด้วย **Add Model**

| ฟิลด์      | คำอธิบาย                                                                     |
| ---------- | ------------------------------------------------------------------------------- |
| Base URL   | ที่ Console ส่งต่อคำขอ เช่น `https://api.deepseek.com/v1`     |
| Format     | Chat Completions, Responses API, Anthropic Compatible หรือ Google Generative AI |
| Auth mode  | โทเคน Bearer, เฮดเดอร์คีย์ API หรือเฮดเดอร์ที่กำหนดเอง                           |
| Credential | คีย์ที่ Console ส่งให้ผู้ให้บริการ                                          |

## เลือกโมเดล

เปิดผู้ให้บริการเพื่อดูโมเดล เฉพาะโมเดลที่เปิดใช้งานเท่านั้นที่สมาชิกใช้ได้

- ใช้สวิตช์ **Enabled** เพื่อเปิดหรือปิดโมเดล
- เปิด **New models** เพื่อเปิดใช้งานโมเดลที่ผู้ให้บริการเพิ่มในอนาคต

## แก้ไขโมเดล

คลิกโมเดลเพื่อแก้ไข การเปลี่ยนแปลงจะถูกบันทึกเมื่อคุณปิดแผง

| ส่วน       | สิ่งที่เปลี่ยนได้                                             |
| ------------- | --------------------------------------------------------------- |
| General       | ชื่อที่แสดง, API ID, การรองรับเครื่องมือ, ชนิดอินพุตและเอาต์พุต     |
| Variants      | ตัวเลือกย่อยของโมเดลที่มีเฮดเดอร์หรือบอดีของตัวเอง |
| Configuration | ตัวเลือกย่อยเริ่มต้นของโมเดล เฮดเดอร์และบอดีของคำขอ และขีดจำกัดโทเคน |
| Cost Tiers    | ราคาอินพุต เอาต์พุต การอ่านแคช และการเขียนแคชต่อ 1M โทเคน |

### ราคากำหนดเอง

โมเดลในแคตตาล็อกเริ่มต้นด้วยราคาปลีกของผู้ให้บริการ หากคุณมีราคาที่เจรจาไว้ เช่น ส่วนลดในสัญญา
OpenAI ให้แทนที่ราคาภายใต้ **Cost Tiers** เพื่อให้รายงานการใช้งานและ[งบประมาณ](/console/budgets)ตรงกับที่
คุณจ่ายจริง

| ฟิลด์            | ราคาปลีก | ราคาของคุณ |
| ---------------- | ---------- | ---------- |
| ราคาอินพุต      | $2.50      | $2.00      |
| ราคาเอาต์พุต     | $15.00     | $12.00     |
| ราคาการอ่านแคช | $0.25 | $0.20 |

ราคาที่คุณเปลี่ยนจะถูกไฮไลต์ในหน้าผู้ให้บริการ ใช้ **Restore default value** ที่ฟิลด์ หรือ **⋯ › Restore...**
ที่โมเดล เพื่อกลับไปใช้ราคาปลีก

เพิ่มระดับราคา **Context** หากโมเดลคิดราคาสูงขึ้นเมื่อบริบทเกินขนาดที่กำหนด เช่น พรอมต์ที่เกิน 200K โทเคน

### โมเดลกำหนดเอง

คลิก **Add Model** เพื่อเพิ่มโมเดลที่ไม่มีในแคตตาล็อก พร้อม **Display name** และ **Model ID** ใช้
**⋯ › Duplicate...** ที่โมเดลที่มีอยู่เพื่อเริ่มจากค่าตั้งของโมเดลนั้น

## โมเดลของ OpenCode

แท็บ **Models** จัดการ[โมเดล](/console/models)ที่ Console ให้บริการ ซึ่งจ่ายจากเครดิตของเวิร์กสเปซ ทำงาน
เหมือนหน้าผู้ให้บริการ

- เปิดหรือปิดโมเดลแต่ละตัว
- ปิด **Free models** เพื่อบล็อกโมเดลฟรีสำหรับเวิร์กสเปซ
- เปิด **New models** เพื่อเปิดใช้งานโมเดลใหม่ของ Console โดยอัตโนมัติ

หากต้องการใช้เฉพาะผู้ให้บริการของคุณเอง ให้เลือก **⋯ › Disable** เพื่อปิดผู้ให้บริการโมเดลของ Console ทั้งราย

## ใช้ใน OpenCode

สมาชิกรัน `/connect` แล้วเลือกเวิร์กสเปซ ผู้ให้บริการที่เปิดใช้งานแต่ละรายจะปรากฏเป็นชื่อเวิร์กสเปซตามด้วย
ชื่อผู้ให้บริการ และ `/models` แสดงโมเดลที่เปิดใช้งาน

```text
Acme Inc. / Anthropic
```

เปิด **Managed providers only** ใน **Settings › General** เพื่อจำกัด OpenCode ให้ใช้เฉพาะผู้ให้บริการของเวิร์กสเปซ
สำหรับทุกคน

## ส่งข้อมูลระบุตัวตน

เมื่อผู้ให้บริการเป็นเกตเวย์ที่คุณรันเอง ให้เปิด **Send identity** ในหน้าของผู้ให้บริการ Console จะเพิ่ม
เฮดเดอร์ `x-opencode-actor` ในทุกคำขอโมเดลที่ส่งไปที่นั่น เฮดเดอร์ระบุสมาชิกหรือบัญชีบริการที่อยู่เบื้องหลังคำขอ
เกตเวย์ของคุณจึงบันทึกหรือจำกัดคำขอตามผู้ส่งได้

```text
x-opencode-actor: eyJhbGciOiJFUzI1NiIsInR5cCI6Im9wZW5jb2RlLWFjdG9yK2p3dCIsImtpZCI6Ii4uLiJ9...
```

- ปิดโดยค่าเริ่มต้น และการเปลี่ยน base URL จะปิดให้
- ผู้ให้บริการที่ยังใช้ API ของผู้ขายเอง เช่น `https://api.openai.com/v1` จะไม่แสดงการตั้งค่านี้ เพราะ
  ผู้ขายไม่สนใจเฮดเดอร์นี้
- Console จะลบเฮดเดอร์ `x-opencode-*` ใดก็ตามที่ไคลเอนต์ส่งมา `x-opencode-actor` ที่เกตเวย์ของคุณได้รับ
  จึงเป็นตัวที่ Console ลงนามเท่านั้น
- **Test connection** และการแสดงรายการโมเดลเรียก `GET <base URL>/models` ด้วยข้อมูลรับรองอย่างเดียว
  จึงไม่ควรกำหนดให้เส้นทางนั้นต้องมีเฮดเดอร์

### โทเคน

เฮดเดอร์เป็น JWT ที่ Console ลงนามสำหรับแต่ละคำขอ

| ฟิลด์        | ค่า                                            |
| ------------ | ------------------------------------------------ |
| `alg`        | `ES256`                                          |
| `typ`        | `opencode-actor+jwt`                             |
| `iss`        | `https://opencode.ai/inference`                  |
| `aud`        | base URL ของผู้ให้บริการโดยไม่มีเครื่องหมายทับปิดท้าย |
| `iat`, `exp` | `exp` คือ 120 วินาทีหลัง `iat`                 |

| Claim                | ค่า                                                                  |
| -------------------- | ---------------------------------------------------------------------- |
| `sub`                | `user_id` สำหรับสมาชิก หรือ `service_account_id` ในกรณีอื่น                 |
| `workspace_id`       | เวิร์กสเปซที่คำขอทำงานอยู่                                       |
| `user_id`, `email`   | สมาชิก เมื่อสมาชิกเป็นผู้ส่งคำขอ                             |
| `service_account_id` | บัญชีบริการ เมื่อบัญชีบริการเป็นผู้ส่ง (รวมถึงเอเจนต์)  |
| `session_id`         | ID เซสชันของไคลเอนต์ เมื่อไคลเอนต์ส่งมา                              |
| `request_id`         | ID ที่ไคลเอนต์ได้รับกลับในเฮดเดอร์ตอบกลับ `x-opencode-log-id` |

คำขอของสมาชิกมีเพย์โหลดเช่นนี้

```json
{
  "iss": "https://opencode.ai/inference",
  "aud": "https://llm.example.com/v1",
  "sub": "user_...",
  "workspace_id": "org_...",
  "user_id": "user_...",
  "email": "ada@example.com",
  "session_id": "ses_...",
  "request_id": "019a6e8f-24a0-7b12-9c3d-4e5f6a7b8c9d",
  "iat": 1794500000,
  "exp": 1794500120
}
```

### ตรวจสอบโทเคน

Console เผยแพร่คีย์สาธารณะที่ `https://opencode.ai/inference/.well-known/jwks.json` พร้อม
`Cache-Control: public, max-age=300` ตรวจสอบลายเซ็น ผู้ออก ผู้รับ ชนิดและอายุ แล้วจึงตรวจเวิร์กสเปซ ตัวอย่างนี้
ใช้ [jose](https://github.com/panva/jose)

```ts
import { createRemoteJWKSet, jwtVerify } from "jose"

const keys = createRemoteJWKSet(new URL("https://opencode.ai/inference/.well-known/jwks.json"))

export async function sender(request: Request) {
  const token = request.headers.get("x-opencode-actor")
  if (!token) throw new Error("Missing x-opencode-actor")
  const { payload } = await jwtVerify(token, keys, {
    issuer: "https://opencode.ai/inference",
    audience: "https://llm.example.com/v1",
    algorithms: ["ES256"],
    typ: "opencode-actor+jwt",
    maxTokenAge: "120s",
    clockTolerance: "5s",
  })
  if (payload.workspace_id !== "org_...") throw new Error("Another workspace")
  return payload
}
```

ตั้ง `audience` เป็น base URL ของผู้ให้บริการที่บันทึกใน Console โดยไม่มีเครื่องหมายทับปิดท้าย และแทน `org_...` ด้วย
ID เวิร์กสเปซจาก Console URL ของคุณ Console จะเผยแพร่คีย์ลงนามใหม่ก่อนใช้ลงนาม ตัวตรวจสอบที่ค้นคีย์ด้วย `kid`
อย่าง `createRemoteJWKSet` จึงทำงานต่อได้ตลอดการหมุนเวียนคีย์

## ปิดหรือนำออก

เปิดเมนู **⋯** ของผู้ให้บริการ

- **Disable** ซ่อนผู้ให้บริการและโมเดลจากสมาชิกแต่เก็บค่าตั้งไว้
- **Remove...** ลบผู้ให้บริการและโมเดล กล่องโต้ตอบจะแสดงว่าใครใช้ล่าสุด และเสนอ
  **Disable instead**

หากต้องการหมุนเวียนคีย์ ให้คลิกข้อมูลรับรองในหน้าผู้ให้บริการแล้วป้อนคีย์ใหม่

## การเรียกเก็บเงิน

ผู้ให้บริการเรียกเก็บค่าโทเคนจากคุณโดยตรง Console จะไม่หักเครดิตสำหรับค่าโทเคน แต่ยังบันทึกทุกคำขอและ
ค่าใช้จ่ายตามราคาของโมเดล รายงานการใช้งานและ[งบประมาณ](/console/budgets)จึงรวมไว้ด้วย

หากต้องการเรียกผู้ให้บริการจากเครื่องมือของคุณเองแทน OpenCode ให้ใช้ [Providers API](/console/api/providers)
