ทุกวันมีผู้ใช้ OpenCode หลายล้านคน ต่อยอดบน OpenCode เพื่อสร้างแอป
การเชื่อมต่อ และประสบการณ์เอเจนต์ของคุณเองโดยไม่ต้องเริ่มจาก
ศูนย์

นอกจากนี้เรายังมี Effect API สำหรับ[ปลั๊กอิน](/build/plugins/effect),
[ไคลเอนต์](/build/client/effect) และ[แอปแบบฝัง](/build/sdk/effect)
