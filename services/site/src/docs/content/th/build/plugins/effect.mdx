description: "เขียนปลั๊กอินเซิร์ฟเวอร์ด้วย API ปลั๊กอินที่ใช้ Effect โดยตรง"
---

`@opencode/plugin/effect` เป็น API ปลั๊กอิน OpenCode เวอร์ชันที่ใช้ Effect โดยตรง การดำเนินการในบริบทคืน
Effect หรือ Stream คอลแบ็กคืน Effect และอายุปลั๊กอินแสดงด้วย `Scope`

OpenCode ให้ `effect` (รวมพาธย่อย `effect/*` ที่ส่งออก) และ `@opencode/plugin` ขณะรันเมื่อโหลด
ปลั๊กอินและ Dependency ใน `node_modules` ให้ติดตั้งเป็น peer/dev dependency สำหรับการตรวจชนิดและการทดสอบในเครื่อง
แทนการรวมเข้าในปลั๊กอิน

```sh
bun add --peer @opencode/plugin effect@4.0.1
```

ส่งออกปลั๊กอิน Effect จาก `.opencode/plugins/` เพื่อโหลดอัตโนมัติ

```ts title=".opencode/plugins/concise/index.ts"
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "example",
  effect: (ctx) =>
    Effect.gen(function* () {
      const storage = ctx.storage
      yield* storage.set("loaded", true)
    }),
})
```

แพ็กเกจที่เผยแพร่และไดเรกทอรีปลั๊กอินนอก `.opencode/plugins/` ใช้การกำหนดค่า `plugins` เดียวกับปลั๊กอินเซิร์ฟเวอร์
อื่น

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": [
    "opencode-acme-effect-plugin",
    "opencode-acme-effect-plugin@1.2.0",
    "@acme/opencode-effect-plugin",
    "./plugins/local-effect",
    {
      "package": "@acme/opencode-effect-plugin",
      "options": { "agent": "reviewer", "strict": true },
    },
  ],
}
```

ดู[การกำหนดค่าปลั๊กอิน](/plugins)สำหรับวิธีเปิดใช้งาน วิธีค้นหาแพ็กเกจ และลำดับความสำคัญของการกำหนดค่า

```ts title="plugins/local-effect/index.ts"
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "local-effect",
  effect: (ctx) =>
    Effect.gen(function* () {
      yield* Effect.logInfo("Effect plugin loaded", { version: ctx.app.version })
    }),
})
```

## วงจรชีวิต

`effect` ทำงานเมื่อโหลดปลั๊กอิน Scope จะปิดเมื่อโหลดปลั๊กอินใหม่หรือเลิกโหลด การลงทะเบียน Fiber
แบบมีขอบเขต และ finalizer จึงถูกปล่อยพร้อมกัน

```ts
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "lifecycle",
  effect: (ctx) =>
    Effect.gen(function* () {
      yield* Effect.logInfo("loaded", { version: ctx.app.version })
      yield* Effect.addFinalizer(() => Effect.logInfo("unloaded"))
    }),
})
```

ใช้ Fiber ที่ผูกกับ Scope สำหรับงานเบื้องหลัง เมื่อคืนทรัพยากร Scope ของปลั๊กอินจะหยุด Fiber นั้น

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const storage = ctx.storage
    yield* Effect.repeat(
      storage.set("heartbeat", { time: Date.now() }),
      { schedule: Schedule.spaced("1 minute") },
    ).pipe(Effect.forkScoped)
  }),
```

### บริบท

บริบทเปิดไคลเอนต์ Effect สำหรับเซิร์ฟเวอร์ OpenCode ที่เชื่อมต่อ พร้อมการแปลง ฮุก ที่เก็บข้อมูล
การโหลดใหม่ และตัวเลือกเฉพาะปลั๊กอิน ไม่เปิดบริการ Core ภายในของ OpenCode

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const plugins = ctx.plugin
    const active = yield* plugins.list().pipe(Effect.orDie)
    yield* Effect.logInfo("active plugins", { count: active.data.length })
  }),
```

คำจำกัดความปลั๊กอินและบริบททั้งหมดประกาศดังนี้

```ts

```

ส่งตัวเลือกด้วยรูปแบบออบเจกต์ใน `opencode.json(c)`

```jsonc title="opencode.jsonc"
  "plugins": [
    {
      "package": "./plugins/company-effect",
      "options": { "strict": true },
    },
  ],
}
```

อ่านตัวเลือกจาก `ctx.options` จำกัดชนิดค่าที่ไม่รู้จักก่อนใช้

```ts title="plugins/company-effect/index.ts"
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "company",

    Effect.gen(function* () {
      const strict = ctx.options.strict === true

    }),
})
```

## การแปลง

การแปลงแก้ไขสถานะแบบซิงโครนัสผ่านตัวแก้ไข OpenCode ใช้การแปลงตามลำดับการลงทะเบียนภายในแต่ละ
โดเมน แหล่งให้ผู้ให้บริการและคำจำกัดความโมเดลที่ไม่เปลี่ยนรูปก่อน จากนั้นการแปลงโมเดลจึงแก้ไข
ตัวเลือกของผู้ให้บริการที่ใช้งาน การ yield การลงทะเบียนจะเก็บไว้ใน Scope ของปลั๊กอิน

```ts title="plugins/models-effect/index.ts"
import { Model, Plugin, Provider } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "company.models",
  effect: (ctx) =>
    Effect.gen(function* () {
      const providerID = Provider.ID.make("acme")
      const models = [{ ...Model.Info.default(providerID, Model.ID.make("reasoner")), name: "Acme Reasoner" }]
      yield* ctx.provider.transform((editor) => {
        editor.add({
          info: {
            ...Provider.Info.empty(providerID),
            name: "Acme",
            activation: "enabled",
            package: "@opencode/ai/providers/openai-compatible",
            settings: { baseURL: "http://127.0.0.1:8000/v1" },
          },
          models,
        })
      })
    }),
})
```

การแปลงโมเดลบังคับนโยบายกับคอลเลกชันตัวเลือกของผู้ให้บริการที่ใช้งานทั้งหมดได้

```ts title="plugins/model-budget-effect/index.ts"
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.model.transform((editor) => {
      editor
        .list()
        .filter((model) => model.cost.some((tier) => tier.output > 20))
        .forEach((model) => {
          editor.remove(model.providerID, model.id)
        })
    })
  }),
```

เรียก `reload` เมื่อสถานะภายนอกที่การแปลงใช้อ้างอิงเปลี่ยนไป ในตัวอย่างนี้ `loadFromSource()` คืนรายการ `{ info: Provider.Info, models: readonly Model.Info[] }` เมื่อโหลดผู้ให้บริการใหม่ ระบบจะถือว่าผลลัพธ์ของโมเดลทั้งหมดไม่เป็นปัจจุบันด้วย

```ts title="plugins/models-effect/index.ts"
effect: (ctx) =>
  Effect.gen(function* () {
    const provider = ctx.provider
    const source = { providers: yield* loadFromSource() }

    yield* provider.transform((editor) => {
      source.providers.forEach((provider) => editor.add(provider))
    })

    yield* Effect.repeat(
      Effect.gen(function* () {
        source.providers = yield* loadFromSource()
        yield* provider.reload()
      }),
      { schedule: Schedule.spaced("1 minute") },
    ).pipe(Effect.forkScoped)
  }),
```

## API

### Agent

อ่านข้อมูลเอเจนต์ทั้งหมดหรือดึงข้อมูลเอเจนต์ตาม ID การตอบกลับของไคลเอนต์มี location ที่ระบบระบุแล้วและข้อมูล schema

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const agent = ctx.agent
    const agents = yield* agent.list().pipe(Effect.orDie)
    const build = yield* agent.get({ agentID: Agent.ID.make("build") }).pipe(Effect.orDie)
    yield* Effect.logInfo("agents", { count: agents.data.length, build: build.data.name })
  }),
```

แปลงหรือโหลดเอเจนต์ใหม่

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const agent = ctx.agent
    yield* agent.transform((editor) => {
      editor.default("build")
      editor.update("build", (item) => (item.description = "Builds features and fixes bugs"))
      editor.remove("legacy")
    })
    yield* agent.reload()
  }),
```

Schema: [`Agent.Info`](/api#schema-Agent.Info)

```ts
interface AgentEditor {
  list(): readonly Types.DeepMutable<Agent.Info>[]
  get(id: string): Types.DeepMutable<Agent.Info> | undefined
  default(id: string | undefined): void
  update(id: string, update: (agent: Types.DeepMutable<Agent.Info>) => void): void
  remove(id: string): void
}

interface AgentDomain extends AgentApi<unknown> {
  readonly transform: Transform<AgentEditor>
  readonly reload: () => Effect.Effect<void>
}
```

### Providers

อ่านผู้ให้บริการที่ใช้ได้หรือดูข้อมูลเมตาของผู้ให้บริการหนึ่งตาม ID

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const provider = ctx.provider
    const providers = yield* provider.list().pipe(Effect.orDie)
    const anthropic = yield* provider.get({ providerID: Provider.ID.make("anthropic") }).pipe(Effect.orDie)
    yield* Effect.logInfo("providers", {
      providers: providers.data.length,
      anthropic: anthropic.data.name,
    })
  }),
```

การแปลงผู้ให้บริการแก้ไขการตั้งค่าผู้ให้บริการและคำจำกัดความแหล่ง การอ่านของตัวแก้ไขรวมผู้ให้บริการที่ไม่ใช้งาน
และเปิดคำจำกัดความที่ไม่เปลี่ยนรูป `models.update` แก้ไขสำเนาของโมเดลแหล่งที่ตัวแก้ไขเป็นเจ้าของ

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.provider.transform((editor) => {
      editor.update("anthropic", (provider) => {
        provider.headers = { ...provider.headers, "x-company": "engineering" }
      })
      editor.models.update("anthropic", "claude-sonnet-5-5", (model) => (model.name = "Team Sonnet"))
      editor.models.remove("anthropic", "legacy-model")
      editor.remove("legacy-provider")
    })
  }),
```

แทนที่รายการแหล่งด้วย `models.set` แล้วโหลดใหม่หลังคำจำกัดความที่จับไว้เปลี่ยน

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const provider = ctx.provider
    const source = { models: yield* loadModels() }
    yield* provider.transform((editor) => editor.models.set("acme", source.models))
    source.models = yield* loadModels()
    yield* provider.reload()
  }),
```

สำหรับการค้นพบเฉพาะบัญชี ให้ส่งการเชื่อมต่อที่ใช้โหลดรายการเป็น `sourceConnection` OpenCode จะตัด
ผู้ให้บริการนั้นออกขณะเลือกการเชื่อมต่ออื่น จนกว่าปลั๊กอินของคุณจะเผยแพร่รายการที่รีเฟรชแล้ว

{/* prettier-ignore */}
```ts
const connection = yield* ctx.integration.connection.active("acme")
if (!connection) return
const inventory = yield* loadInventory(connection)
yield* ctx.provider.transform((editor) => {
  editor.add({ info: inventory.provider, models: inventory.models, sourceConnection: connection })
})
```

Schemas: [`Provider.Info`](/api#schema-Provider.Info), [`Model.Info`](/api#schema-Model.Info)

```ts
interface ProviderRecord {
  readonly provider: Provider.Info
  readonly models: ReadonlyMap<string, Model.Info>
  readonly sourceConnection?: ConnectionInfo
}

interface ProviderEditor {
  list(): readonly ProviderRecord[]
  get(providerID: string): ProviderRecord | undefined
  add(input: { info: Provider.Info; models: readonly Model.Info[]; sourceConnection?: ConnectionInfo }): void
  update(providerID: string, update: (provider: Types.DeepMutable<Provider.Info>) => void): void
  remove(providerID: string): void
  readonly models: {
    set(providerID: string, models: readonly Model.Info[]): void
    update(providerID: string, modelID: string, update: (model: Types.DeepMutable<Model.Info>) => void): void
    remove(providerID: string, modelID: string): void
  }
}

interface ProviderDomain extends ProviderApi<unknown> {
  readonly transform: Transform<ProviderEditor>
  readonly reload: () => Effect.Effect<void>
}
```

### Models

อ่านโมเดลที่ใช้ได้และการเลือกเริ่มต้น

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const model = ctx.model
    const models = yield* model.list().pipe(Effect.orDie)
    const selected = yield* model.default().pipe(Effect.orDie)
    yield* Effect.logInfo("models", { count: models.data.length, selected: selected.data?.name })
  }),
```

การแปลงโมเดลแก้ไขคอลเลกชันตัวเลือกของผู้ให้บริการที่ใช้งานทั้งหมด ตัวเลือกที่ปิดใช้งานยังแก้ไขได้จนกว่า
การแปลงทั้งหมดจะเสร็จ `update` เพิ่มโมเดลได้เฉพาะภายใต้ผู้ให้บริการที่พร้อมใช้

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.model.transform((editor) => {
      editor.list("anthropic").forEach((model) => {
        editor.update(model.providerID, model.id, (draft) => {
          draft.enabled = draft.capabilities.tools
        })
      })
      editor.default.set("anthropic", "claude-sonnet-5-5")
      editor.remove("anthropic", "legacy-model")
    })
  }),
```

คอลแบ็กแก้ไขการแทนที่โมเดลดิบ ค่าเริ่มต้นของผู้ให้บริการถูกรวมครั้งเดียวเมื่อ OpenCode ยืนยันผล การอ่านที่ไม่เปลี่ยน
ใช้ผลนั้นซ้ำ `editor.provider` อ่านคำจำกัดความแหล่งที่ไม่เปลี่ยนรูป รวมถึงเทมเพลตที่ไม่ใช้งาน แทน
ผลของการแปลงโมเดล

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const model = ctx.model
    yield* model.transform((editor) => {
      const source = editor.provider.get("anthropic")?.models.get("claude-sonnet-5-5")
      if (!source) return
      editor.update("anthropic", source.id, (draft) => {
        draft.limit.context = Math.min(draft.limit.context, source.limit.context)
      })
    })
    yield* model.reload()
  }),
```

Schema: [`Model.Info`](/api#schema-Model.Info)

```ts
interface ModelEditor {
  list(providerID?: string): readonly Types.DeepMutable<Model.Info>[]
  get(providerID: string, modelID: string): Types.DeepMutable<Model.Info> | undefined
  update(providerID: string, modelID: string, update: (model: Types.DeepMutable<Model.Info>) => void): void
  remove(providerID: string, modelID: string): void
  readonly default: {
    get(): { providerID: string; modelID: string } | undefined
    set(providerID: string, modelID: string): void
  }
  readonly provider: {
    list(): readonly ProviderRecord[]
    get(providerID: string): ProviderRecord | undefined
  }
}

interface ModelDomain extends ModelApi<unknown> {
  readonly transform: Transform<ModelEditor>
  readonly reload: () => Effect.Effect<void>
}
```

### Commands

อ่านคำสั่งที่ใช้ได้ที่ location ปัจจุบัน

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const command = ctx.command
    const commands = yield* command.list().pipe(Effect.orDie)
    yield* Effect.logInfo("commands", { names: commands.data.map((item) => item.name) })
  }),
```

การแปลงคำสั่งปัจจุบันเป็นการเพิ่มเท่านั้น ตัวเรียกใช้ได้รับเซสชัน ไฟล์แนบพรอมต์ และโหมดการส่ง

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const command = ctx.command
    const session = ctx.session
    yield* command.transform((editor) => {
      editor.add({
        name: "security-review",
        description: "Review changes for security issues",
        execute: (input) =>
          session.prompt({
            ...input.prompt,
            sessionID: input.sessionID,
            text: `Review these changes for security issues.\n\n${input.prompt.text}`,
            delivery: input.delivery,
          }).pipe(Effect.asVoid),
      })
    })
    yield* command.reload()
  }),
```

Schemas: [`Command.Info`](/api#schema-Command.Info),
[`Session.Inbox.Delivery`](/api#schema-Session.Inbox.Delivery)

```ts
interface CommandInvocation {
  readonly sessionID: Session.ID
  readonly prompt: PromptInput.Prompt
  readonly delivery: SessionInbox.Delivery
}

interface CommandDefinition {
  readonly name: string
  readonly description?: string
  readonly execute: (input: CommandInvocation) => Effect.Effect<void, unknown>
}

interface CommandEditor {
  add(definition: CommandDefinition): void
}

interface CommandDomain extends Pick<CommandApi<unknown>, "list"> {
  readonly transform: Transform<CommandEditor>
  readonly reload: () => Effect.Effect<void>
}
```

### Integrations

อ่านข้อมูลการเชื่อมต่อและดึงข้อมูลรับรองที่ใช้งานอยู่ หากมี

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const integration = ctx.integration
    const integrations = yield* integration.list().pipe(Effect.orDie)
    const github = yield* integration.get({ integrationID: Integration.ID.make("github") }).pipe(Effect.orDie)
    const connection = yield* integration.connection.active("github")
    const credential = connection ? yield* integration.connection.resolve(connection).pipe(Effect.orDie) : undefined
    yield* Effect.logInfo("integration", {
      count: integrations.data.length,
      github: github.data.name,
      credential: credential?.type,
    })
  }),
```

เชื่อมต่อด้วยคีย์หรือดำเนินการ OAuth ผ่าน API ที่เชื่อมต่อ

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const integration = ctx.integration
    const token = yield* Config.Redacted("GITHUB_TOKEN").pipe(Effect.orDie)
    yield* integration.connect
      .key({ integrationID: Integration.ID.make("github"), key: Redacted.value(token) })
      .pipe(Effect.orDie)

    const attempt = yield* integration.oauth
      .connect({
        integrationID: Integration.ID.make("acme"),
        methodID: Integration.MethodID.make("oauth"),
      })
      .pipe(Effect.orDie)
    const status = yield* integration.oauth
      .status({
        integrationID: Integration.ID.make("acme"),
        attemptID: attempt.data.attemptID,
      })
      .pipe(Effect.orDie)
    yield* Effect.logInfo("OAuth status", { status: status.data })
  }),
```

แปลงการเชื่อมต่อและวิธีตรวจสอบสิทธิ์ คอลแบ็กวิธี OAuth เป็น Effect และอาจได้ทรัพยากร
แบบมีขอบเขต

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const integration = ctx.integration
    yield* integration.transform((editor) => {
      editor.update("acme", (item) => (item.name = "Acme"))
      editor.method.update({
        integrationID: "acme",
        method: { id: "device", type: "oauth", label: "Sign in with Acme" },
        authorize: () =>
          Effect.succeed({
            mode: "code",
```

### Tools

ใช้ `Schema` ของ Effect เพื่อลงทะเบียนเครื่องมือที่ระบุชนิดข้อมูล ตัวเรียกใช้จะได้รับอินพุตที่ถอดรหัสแล้วและคืน Effect ที่มีเอาต์พุตที่ระบุชนิดข้อมูล เนื้อหาสำหรับแสดงผล หรือข้อมูลเมตา

ตัวแก้ไขรองรับ `add`, `update` และ `remove` คอลแบ็กการแปลงเป็นซิงโครนัส: ต้องไม่คืน Effect หรือ Promise โหลด
ข้อมูลภายนอกก่อนลงทะเบียนหรือโหลดใหม่ OpenCode เล่นการแปลงที่ใช้งานตามลำดับการลงทะเบียนบน
ตัวแก้ไขใหม่ สำหรับชื่อเครื่องมือที่มีผลเดียวกัน การลงทะเบียนที่ถูกต้องภายหลังจะแทนที่ก่อนหน้า

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const tool = ctx.tool
    yield* tool.transform((editor) => {
      editor.namespace({
        name: "acme",
        description: "Customer account tools",
      })
      editor.add({
        name: "greeting",
        description: "Create a greeting",
        input: Schema.Struct({ name: Schema.String }),
        output: Schema.Struct({ greeting: Schema.String }),
        options: { namespace: "acme", codemode: true },
        execute: ({ name }, context) =>
          Effect.gen(function* () {
            yield* context.progress({ status: "greeting" })
            return { output: { greeting: `Hello ${name}!` } }
          }),
      })
    })
  }),
```

เรียก `yield* ctx.tool.reload()` หลังเปลี่ยนข้อมูลแหล่งที่คอลแบ็กจับไว้ การโหลดใหม่เล่นการแปลงที่ใช้งาน
โดยไม่เปลี่ยนลำดับ ไม่ได้รัน effect ของปลั๊กอินใหม่

เครื่องมือ Effect รับ[การประกาศอินพุต freeform](/build/plugins/server#freeform-tool-input)เดียวกับเครื่องมือ Promise หากโมเดลไม่ประกาศรูปแบบนั้น เครื่องมือจะคงอินพุตออบเจกต์ปกติ

ค่า `id` ของเครื่องมือคือชื่อที่ระบบใช้จริง และ `get()` จะคืน `undefined` หากไม่พบ ID นั้น เมื่อเรียก
`update` หรือ `remove` ให้ใช้ชื่อที่ระบบใช้จริงซึ่งรวมเนมสเปซด้วย (เช่น `acme_greeting` ข้างต้น) ระบบจะแทนจุดในเนมสเปซด้วย `_`
และแทนอักขระในชื่อเครื่องมือด้วย `_` หากไม่ใช่ตัวอักษร ตัวเลข `_` หรือ `-` ระบบจะข้ามชื่อที่ไม่พบ หากต้องการสร้างเครื่องมือ ให้ใช้
`add` พร้อมคำจำกัดความที่สมบูรณ์ การอัปเดตจะคงชื่อและเนมสเปซไว้ ให้แทนที่ด้วย schema หรือตัวเลือกใหม่
แทนการแก้ไขค่าที่ซ้อน การอัปเดตที่ไม่ถูกต้องจะถูกบันทึกและคงคำจำกัดความก่อนหน้าไว้

{/* prettier-ignore */}
```ts
yield* ctx.tool.transform((editor) => {
  editor.update("acme_greeting", (tool) => {
    tool.description = "Greet the user by name"
  })
  editor.remove("acme_obsolete")
})
```

การอัปเดตและการนำออกเล่นตามลำดับพร้อมการเพิ่ม รวมถึงหลังการรีเฟรชแคตตาล็อก MCP

`transform` คืนการลงทะเบียนที่มีขอบเขตกำกับ เรียก `yield* registration.dispose` เพื่อนำการแปลงนั้นออกและสร้างผลลัพธ์ใหม่จากการแปลงที่เหลือ คำจำกัดความเดิมที่เคยถูกแทนที่จึงกลับมาใช้ได้ การยกเลิกซ้ำไม่เปลี่ยนผล และการปิด Scope ของปลั๊กอินจะยกเลิกการลงทะเบียนของปลั๊กอินด้วย

คำขอโมเดลแต่ละรายการจะบันทึกสแนปช็อตของเครื่องมือไว้ การโหลดใหม่และการยกเลิกการลงทะเบียนมีผลกับสแนปช็อตในอนาคตเท่านั้น ไม่เปลี่ยนคำจำกัดความหรือตัวเรียกใช้ที่คำขอเดิมบันทึกไว้แล้ว

### VCS

อ่านข้อมูลรีโพ สถานะสำเนาทำงาน หรือ diff ของไฟล์

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const vcs = ctx.vcs
    const info = yield* vcs.get().pipe(Effect.orDie)
    const branches = yield* vcs.branch.list({ search: "feature", limit: 10 }).pipe(Effect.orDie)
    const changes = yield* vcs.status().pipe(Effect.orDie)
    const diff = yield* vcs.diff({ mode: "working", context: 3 }).pipe(Effect.orDie)
    yield* Effect.logInfo("vcs", { branch: info.data.branch.current, files: changes.data.length })
  }),
```

ลงทะเบียนผู้ให้บริการ VCS ตามขอบเขต location ผ่านการแปลงแบบมีขอบเขต ผู้ให้บริการที่ตรงกับชนิดรีโพที่ตรวจพบจะ
ถูกเลือกอัตโนมัติ ใช้ `editor.default.set` เพื่อเลือกผู้ให้บริการอื่น

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const vcs = ctx.vcs
    yield* vcs.transform((editor) => {
      editor.add({
        id: "custom",
        name: "Custom VCS",
        info: () => Effect.succeed({ branch: { current: "feature", default: "main" } }),
        branches: (input) => readBranches(input),
        status: (scope) => readStatus(scope.worktree),
        diff: (input) => readDiff(input),
      })
      editor.default.set("custom")
    })
  }),
```

คอลแบ็กผู้ให้บริการได้รับ location ปัจจุบัน รากสำเนาทำงาน รากโปรเจกต์มาตรฐาน และที่เก็บรีโพ
ที่ไม่บังคับ คอลแบ็ก diff ยังได้รับโหมดที่เลือก บริบทที่ขอ และงบไบต์เอาต์พุต การค้นพบรีโพ
ยังใช้ตัวตรวจ Git และ Mercurial ในตัวของ OpenCode

ผู้ให้บริการเลือกใช้ `init(scope)` เพื่อสร้างรีโพใน `scope.worktree` ได้ การเริ่มต้นเลือก
ผู้ให้บริการตาม ID (Git โดยค่าเริ่มต้น) ไม่ใช่ตามชนิดรีโพที่ตรวจพบ ลงทะเบียนผู้ให้บริการที่มี `init` แม้
location ยังไม่มีรีโพ OpenCode จะตรวจว่าไดเรกทอรีมีอยู่และไม่มีรีโพก่อนเรียก
แล้วจึงค้นพบโปรเจกต์ใหม่ รูปแบบรีโพใหม่ยังต้องมีการรองรับการค้นพบนอกเหนือจากคอลแบ็กนี้

### Events

การสมัครรับอีเวนต์สาธารณะของเซิร์ฟเวอร์จะได้ `Stream` ของ Effect ให้แยกงานที่อ่านสตรีมไปทำงานใน Fiber ภายใน Scope ของปลั๊กอิน เพื่อให้ระบบหยุดงานนั้นโดยอัตโนมัติเมื่อปิด Scope

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const event = ctx.event
    yield* event.subscribe().pipe(
      Stream.tap((item) => Effect.logDebug("OpenCode event", { type: item.type })),
      Stream.runDrain,
      Effect.forkScoped,
    )
  }),
```

ส่ง `types` เพื่อรับเฉพาะชนิดอีเวนต์ที่ต้องการ สตรีมมีชนิดให้ตรง จึงไม่ต้องใช้ type guard

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const event = ctx.event
    yield* event.subscribe({ types: ["config.updated"] }).pipe(
      Stream.runForEach(() => Effect.logInfo("configuration changed")),
      Effect.forkScoped,
    )
  }),
```

### Sessions

แก้ไขคำแนะนำระบบ ข้อความ หรือเครื่องมือที่ประกอบแล้วทันทีก่อนส่งถึงโมเดล `context` ทำงานสำหรับ
ลูปเอเจนต์ ส่วน `compaction`, `generate` และ `title` ทำงานสำหรับคำขอเสริมเหล่านั้น `compaction` และ `title` รับ
`result` ที่ข้ามการเรียกโมเดล

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const session = ctx.session
    yield* session.hook("context", (event) =>
      Effect.sync(() => {
        event.system.push({ type: "text", text: "Keep the review focused on correctness." })
        delete event.tools.write
      }),
    )
    yield* session.hook("compaction", (event) =>
      Effect.map(summarize(event.messages), (summary) => {
        event.result = { summary }
      }),
    )
  }),
```

ข้อความในฮุก `context`, `compaction` และ `generate` มี `metadata` ของข้อความที่จัดเก็บไว้อ่านอย่างเดียว
(เช่นสิ่งที่ฮุก `prompt` ตั้งไว้) ไม่ได้ส่งถึงโมเดล

ส่วน `system` ที่เก็บคำแนะนำของ OpenCode ยังแสดงแต่ละแหล่งใน `metadata.experimental.instructions` เป็น
`{ key, text }` เช่น `core/date` หรือ `core/environment` ฮุกจึงแยกแหล่งได้ รายการเป็นสำเนา:
การแก้ `text` ของส่วนนั้นไม่อัปเดตรายการ นี่เป็นฟีเจอร์ทดลองและอาจเปลี่ยน

แก้ไขการตั้งค่าคำขอโมเดลและจำกัดฮุกให้ผู้ให้บริการเดียวได้ อีเวนต์มี `kind` เดียวกับ
ฮุก HTTP ด้านล่าง

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const session = ctx.session
    yield* session.hook(
      "model.request",
      (event) => Effect.sync(() => (event.headers["x-plugin"] = "review")),
      { providerID: "anthropic" },
    )
  }),
```

แก้ไขคำขอหรือการตอบกลับของผู้ให้บริการเนทีฟ บอดีเป็นสตรีมใช้ครั้งเดียว ให้โคลนหรือแทนที่บอดีก่อนอ่าน
ฮุกทั้งสองทำงานทุกคำขอที่เซสชันส่ง `event.kind` เป็น `"primary"`, `"compaction"`, `"title"` หรือ
`"generate"` ขึ้นกับโฟลว์ที่ส่ง

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const session = ctx.session
    yield* session.hook("http.request", (event) =>
      Effect.sync(() => {
        event.request.headers.set("x-session-id", event.sessionID)
        if (event.kind === "title") event.request.headers.set("x-priority", "background")
      }),
    )
    yield* session.hook("http.response", (event) =>
      Effect.sync(() => {
        event.response = new Response(event.response.body, {
          status: event.response.status,
          headers: { ...Object.fromEntries(event.response.headers), "x-plugin": "review" },
        })
      }),
    )
  }),
```

ผู้ให้บริการที่สตรีมผ่าน WebSocket ใช้การเชื่อมต่อเดียวต่อเซสชัน ฮุก HTTP จึงไม่เห็นทราฟฟิกนั้น ฮุกทดลอง
`experimental.ws.handshake` ทำงานครั้งเดียวต่อการเรียกโมเดลก่อนเลือกการเชื่อมต่อ และเปิดเผย `url`
กับ `headers` ของการเชื่อมต่อ การเปลี่ยนอย่างใดอย่างหนึ่งจะเปิดซ็อกเก็ตใหม่ ฮุก HTTP ยังทำงานสำหรับคำขอใดๆ
ที่เส้นทาง WebSocket ถอยกลับไปใช้

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.session.hook(
      "experimental.ws.handshake",
      (event) =>
        Effect.gen(function* () {
          event.headers.authorization = `Bearer ${yield* mintToken(event.url)}`
          delete event.headers["api-key"]
        }),
      { providerID: "azure" },
    )
  }),
```

`experimental.ws.send` และ `experimental.ws.receive` เปิดเฟรมเอง: `send` ทำงานหลังไดรเวอร์ผู้ให้บริการ
สร้างเฟรมขาออก ส่วน `receive` ทำงานทุกเฟรมขาเข้าก่อนไดรเวอร์เห็น สิ่งที่ `frame` เก็บเมื่อฮุกคืนคือสิ่งที่ส่งผ่านสายหรือถึงไดรเวอร์
OpenCode ไม่ตรวจสอบ

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.session.hook(
      "experimental.ws.send",
      (event) =>
        Effect.sync(() => {
          const body = JSON.parse(event.frame)
          if (body.type === "response.create") body.metadata = { ...body.metadata, session: event.sessionID }
          event.frame = JSON.stringify(body)
        }),
      { providerID: "openai" },
    )
  }),
```

แทนที่การตัดสินใจลองใหม่สำหรับความล้มเหลวของผู้ให้บริการหรือแทนที่เวลาหน่วงเป็นมิลลิวินาที ฮุกทำงานหลัง OpenCode
จำแนกความล้มเหลวและเสนอ นโยบาย แต่ก่อนกำหนดเวลาลองใหม่ ไม่เปิดเผยว่า OpenCode
ดำเนินการพยายามครั้งถัดไปภายในอย่างไร

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.session.hook("retry", (event) =>
      Effect.sync(() => {
        if (event.error.status === 429) {
          event.decision = { retry: true, delay: 10_000 }
          return
        }
        if (event.error.type === "provider.invalid-request" && event.attempt === 2) {
          event.decision = { retry: true, delay: 0 }
          return
        }
        if (event.attempt >= 3) event.decision = { retry: false }
      }),
    )
  }),
```

ค่า `decision` เริ่มต้นมาจากนโยบายของ OpenCode ฮุกจึงเลือกให้ลองใหม่แม้ปกติจะหยุดเมื่อพบข้อผิดพลาดแบบนั้น หรือยกเลิกการลองใหม่ที่ระบบเสนอได้ ฮุกทำงานตามลำดับการลงทะเบียน โดยฮุกถัดไปจะเห็นผลการตัดสินใจล่าสุด และยังเกินจำนวนครั้งสูงสุดที่ระบบกำหนดไม่ได้
`attempt` คือลำดับการส่งคำขอจริงที่ระบบกำลังเสนอ คำขอแรกคือครั้งที่ `1` การลองใหม่ครั้งแรกจึงเป็นครั้งที่ `2` หากเวลาหน่วงไม่ถูกต้อง (`NaN`, ค่าอนันต์ หรือค่าลบ) ระบบจะใช้เวลาหน่วงที่คำนวณไว้
การกู้คืนเมื่อบริบทล้นใช้กลไกแยกต่างหาก เพราะเป็นการบีบอัดบทสนทนาแทนการส่งคำขอเดิมซ้ำ

### Tools

ฮุกก่อนอาจแทนที่อินพุตหรือล้มเหลวด้วย `Tool.Error`

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const tool = ctx.tool
    yield* tool.hook("execute.before", (event) =>
```

ฮุกหลังอาจตรวจหรือแทนที่ผลลัพธ์ที่สำเร็จและความล้มเหลว

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const tool = ctx.tool
    yield* tool.hook("execute.after", (event) => {
      if (event.status === "error") return Effect.logWarning("tool failed", { message: event.error.message })
      return Effect.sync(() => {
        event.result = { ...event.result, metadata: { observed: true } }
      })
    })
  }),
```

## การเผยแพร่

ปลั๊กอินแพ็กเกจใช้ default export เดียวกับปลั๊กอิน Effect ในเครื่อง ส่งออกการใช้งาน Effect จากจุดเข้า
หลักและประกาศ `effect` เป็น `peerDependency` ภายใต้ `devDependencies` ให้ปักหมุดเวอร์ชันที่ `@opencode/plugin` ใช้
เพื่อให้การติดตั้งสำหรับพัฒนามีเพียงสำเนาเดียว

```json title="package.json"
{
  "name": "opencode-acme-effect-plugin",
  "version": "1.0.0",
  "type": "module",
  "exports": {
    ".": "./src/index.ts"
  },
  "dependencies": {
    "@opencode/plugin": "latest"
  },
  "peerDependencies": {
    "effect": "^4.0.1"
  },
  "devDependencies": {
    "effect": "4.0.1"
  }
}
```

OpenCode เปลี่ยนเส้นทางการนำเข้า `effect` พาธย่อย `effect/*` ที่ส่งออก และ `@opencode/plugin` (รวมการนำเข้าจาก
แพ็กเกจที่ปลั๊กอินใช้ใน `node_modules`) ไปยังอินสแตนซ์รันไทม์ของโฮสต์ เพื่อให้ Fiber ตัวเขียนบันทึก และตัวแยกวิเคราะห์ `Schema`
ใช้สำเนารันไทม์เดียว

- อย่าใส่ `effect` ไว้ในบันเดิลปลั๊กอินที่เผยแพร่ หากใช้บันเดิลเลอร์ ให้ตั้งค่า `effect` และ `effect/*`
  เป็น external
- ปลั๊กอินและ Dependency ใน `node_modules` รันกับอินสแตนซ์ `effect` ของรุ่น OpenCode โฮสต์เสมอ
  ใช้ API และพาธโมดูลของ `effect` ที่เข้ากันได้กับรุ่น OpenCode ที่กำหนดเป้าหมาย Dependency ที่สร้างบน
  `effect` เมเจอร์อื่น (เช่น Effect 3) ก็ได้รับ `effect` ของโฮสต์และไม่รองรับ
- ให้เฉพาะพาธย่อย `effect` สาธารณะ ปลั๊กอินที่นำเข้าโมดูล `internal` ส่วนตัวของ Effect จะโหลดไม่สำเร็จ
  พร้อมข้อผิดพลาดที่ระบุพาธ
- ไบนารี OpenCode ที่คอมไพล์แล้วไม่รวมแอสเซท Scalar และ Swagger UI ที่หน้าเอกสาร HTTP API ของ Effect ใช้
  การให้บริการหน้าเหล่านั้นจากปลั๊กอินจะแสดงประกาศแทน

จุดเข้าแพ็กเกจส่งออก `Plugin.define` พร้อมฟังก์ชัน `effect`

```ts title="src/index.ts"
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "acme.published",
  effect: (ctx) =>
    Effect.gen(function* () {
      const storage = ctx.storage
      yield* storage.set("installed", true)
    }),
})
```

ใช้เวอร์ชันที่เข้ากันได้กับรุ่น OpenCode ที่กำหนดเป้าหมาย และทดสอบแพ็กเกจที่ติดตั้ง ไม่ใช่เฉพาะ
