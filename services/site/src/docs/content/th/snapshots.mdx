สแนปช็อตให้คุณเลิกทำการเปลี่ยนแปลงบทสนทนาและไฟล์ล่าสุดพร้อมกัน ใช้เพื่อแก้ไขงานล่าสุด แต่ให้เก็บคอมมิต Git
หรือแบ็กอัปสำหรับสิ่งสำคัญ

## เวิร์กโฟลว์

รัน `/undo` หลังการตอบกลับที่คุณต้องการแก้ไข OpenCode จะเตรียมการย้อนกลับ คืนไฟล์ที่ได้รับผลกระทบ และใส่
พรอมต์ที่ถูกลบกลับในช่องพิมพ์เพื่อให้คุณแก้ไข

```text
/undo

# Edit the restored prompt, then submit it again.
Add validation without changing the public API.
```

การส่งพรอมต์ที่แก้ไขจะยืนยันการย้อนกลับที่เตรียมไว้ ก่อนส่ง ให้รัน `/redo` เพื่อยกเลิกและคืน
บทสนทนาและไฟล์ที่คุณมีก่อน `/undo`

```text
/redo
```

เทอร์มินัลยังมีทางลัดเริ่มต้น

| การกระทำ | คำสั่ง | ทางลัด |
| --- | --- | --- |
| เตรียมการย้อนข้อความก่อนหน้า | `/undo` | `<leader>u` |
| ยกเลิกการย้อนกลับที่เตรียมไว้ | `/redo` | `<leader>r` |

คุณยังเลือกข้อความก่อนหน้าแล้วเลือก **Revert** เพื่อเตรียมการย้อนกลับไปยังจุดนั้นได้

## การบันทึก

ในแต่ละขั้น OpenCode จะพยายามสร้างสแนปช็อตทันทีก่อนเรียกโมเดล และสร้างอีกครั้งเมื่อบันทึกว่าขั้นนั้นสำเร็จหรือล้มเหลว ข้อความของผู้ช่วยจะระบุว่าพาธใดเปลี่ยนไประหว่างสแนปช็อตทั้งสอง

```text
before model step ── snapshot A
model edits src/api.ts
step finishes ────── snapshot B ── changed: src/api.ts
```

ระบบจะบันทึกสแนปช็อตเมื่อทำได้ หากขาดสแนปช็อตตัวใดตัวหนึ่ง บทสนทนายังดำเนินต่อได้ แต่อาจกู้คืนการเปลี่ยนแปลงไฟล์ของขั้นนั้นไม่ได้

## ขอบเขต

สแนปช็อตครอบคลุมไดเรกทอรีที่ใช้งานของเซสชันภายในเวิร์กทรี Git ตัวอย่างเช่น เซสชันที่เปิดใน `packages/app`
จะบันทึกไฟล์ที่เข้าเกณฑ์ใต้ `packages/app` ไม่ใช่การเปลี่ยนแปลงอื่นในรีโพ

| เนื้อหา | บันทึก | ตัวอย่าง |
| --- | --- | --- |
| ไฟล์ที่ติดตามในไดเรกทอรีที่ใช้งาน | ได้ | `packages/app/src/app.tsx` |
| ไฟล์ที่ยังไม่ติดตามและไม่ถูกเพิกเฉย ขนาดไม่เกิน 2 MiB ต่อไฟล์ | ได้ | `packages/app/notes.txt` |
| ไฟล์ที่ Git เพิกเฉย | ไม่ | `packages/app/dist/app.js` |
| ไฟล์ที่ยังไม่ติดตามขนาดเกิน 2 MiB แต่ละไฟล์ | ไม่ | `packages/app/debug.log` |
| ไฟล์นอกไดเรกทอรีที่ใช้งาน | ไม่ | `packages/server/src/index.ts` |
| ข้อมูลเมตาของ Git และผลข้างเคียงอื่นๆ | ไม่ | คอมมิต สาขา ฐานข้อมูล หรือโปรเซส |

สแนปช็อตของระบบไฟล์ต้องมีรีโพ Git นอกรีโพ `/undo` ยังย้อนประวัติบทสนทนาได้ แต่
คืนไฟล์ไม่ได้

## การคืนค่า

การย้อนกลับคืนเฉพาะพาธที่เชื่อมโยงกับขั้นของผู้ช่วยหลังขอบเขตบทสนทนาที่เลือก แต่ละพาธกลับ
ไปยังสถานะก่อนขั้นที่ถูกย้อนขั้นแรก ไฟล์ที่สร้างโดยขั้นเหล่านั้นจะถูกลบหากไม่มีอยู่ในตอนนั้น

| ไทม์ไลน์ | `src/api.ts` | `src/new.ts` |
| --- | --- | --- |
| ขอบเขตที่เลือก | เวอร์ชัน A | ไม่มี |
| ขั้นของผู้ช่วยภายหลัง | เวอร์ชัน B | สร้างแล้ว |
| หลังการย้อนกลับ | เวอร์ชัน A | ลบแล้ว |

พาธที่ไม่ได้เชื่อมโยงกับขั้นเหล่านั้นจะไม่ถูกแตะ การแก้ไขปัจจุบันในพาธที่ได้รับผลกระทบอาจถูกเขียนทับ
จึงควรตรวจสอบสรุปที่คืนค่าและ `git diff` ก่อนดำเนินการต่อ

```sh
git diff --stat
git diff
```

## ที่เก็บข้อมูล

OpenCode เก็บสแนปช็อตในเครื่องในฐานข้อมูลออบเจกต์ Git ภายในแยกต่างหากภายใต้ไดเรกทอรีข้อมูล การบันทึกสแนปช็อต
ไม่สร้างคอมมิต ไม่ย้ายสาขา และไม่ตั้งใจเปลี่ยน index ของรีโพคุณ

```sh
# Your repository remains an ordinary dirty worktree after capture.
git status --short
```

ออบเจกต์สแนปช็อตอาจมีเนื้อหาทั้งหมดของไฟล์ที่ติดตามและไฟล์ที่ยังไม่ติดตามที่เข้าเกณฑ์ ให้ถือว่าไดเรกทอรีข้อมูล
ของ OpenCode เป็นข้อมูลในเครื่องที่ละเอียดอ่อน

## การตั้งค่า

สแนปช็อตเปิดโดยค่าเริ่มต้น ตั้ง `snapshots` เป็น `false` ใน[การกำหนดค่า](/config#snapshots)ของคุณเพื่อหยุด
การบันทึกระบบไฟล์ในอนาคต

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "snapshots": false,
}
```

การปิดสแนปช็อตไม่ลบสแนปช็อตที่เก็บไว้แล้ว การย้อนบทสนทนายังใช้ได้ แต่ไม่มีการบันทึก
สถานะระบบไฟล์จึงคืนการเปลี่ยนแปลงไฟล์ที่เกี่ยวข้องไม่ได้

## ความปลอดภัย

สแนปช็อตช่วยให้ย้อนงานได้สะดวก ไม่ใช่ทรานแซกชันหรือการสำรองข้อมูล

- คำสั่ง shell เปลี่ยนบริการ โปรเซส ทรัพยากรเครือข่าย ฐานข้อมูล สถานะ Git เอาต์พุตที่ถูกเพิกเฉย หรือไฟล์นอก
  ไดเรกทอรีที่ใช้งานได้ การคืนสแนปช็อตไม่ย้อนผลเหล่านั้น
- งานที่ถูกขัดจังหวะหรือล้มเหลวอาจทิ้งการเปลี่ยนแปลงไว้เมื่อการบันทึกล้มเหลวหรือไม่มีคู่สแนปช็อตที่ใช้ได้
- การคืนพาธที่ได้รับผลกระทบจะเขียนทับเนื้อหาปัจจุบัน การยกเลิกการย้อนกลับที่เตรียมไว้อาจเขียนทับการแก้ไขภายหลังด้วย
- OpenCode ปฏิเสธการย้อนกลับขณะเซสชันทำงาน แต่อีดิเตอร์และคำสั่งภายนอกยังเปลี่ยน
  เวิร์กทรีระหว่างการบันทึกและการคืนค่าได้
- การคอมมิตการย้อนกลับลบข้อความออกจากมุมมองบทสนทนาที่ใช้งาน ไม่ใช่จากประวัติเซสชันถาวรหรือ
  ที่เก็บสแนปช็อตที่มีอยู่ ไม่ใช่การลบข้อมูลอย่างปลอดภัย

คอมมิตหรือแบ็กอัปงานสำคัญก่อนใช้ `/undo` บนเวิร์กทรีที่มีการเปลี่ยนแปลง
