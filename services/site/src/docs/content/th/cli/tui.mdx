รัน OpenCode ในไดเรกทอรีของโปรเจกต์ พิมพ์คำขอ แล้วกด **Enter**

```bash
cd ~/code/my-project
opencode
```

```text
Explain how authentication works in this project
```

กด **Shift+Enter**, **Ctrl+Enter**, **Alt+Enter** หรือ **Ctrl+J** เพื่อขึ้นบรรทัดใหม่ ขณะ OpenCode กำลังทำงาน ให้กด **Enter** เพื่อส่งพรอมต์ไปปรับทิศทางงานในเซสชันนั้น หรือกด **Ctrl+X** ตามด้วย **Enter** เพื่อเก็บพรอมต์ไว้ในคิว

## โปรเจกต์และไดเรกทอรี

OpenCode จะค้นหาไฟล์และรันคำสั่ง shell ในไดเรกทอรีที่คุณใช้เริ่มโปรแกรม ไดเรกทอรีในที่เก็บ Git เดียวกัน
รวมถึงเวิร์กทรีของที่เก็บนั้น จะอยู่ในโปรเจกต์เดียวกัน ส่วนไดเรกทอรีที่ไม่ได้ใช้ระบบควบคุมเวอร์ชันจะเป็นโปรเจกต์แยกต่างหาก

ระบุไดเรกทอรีเพื่อเริ่มทำงานในโปรเจกต์อื่น

```bash
opencode ~/code/another-project
```

กด **Ctrl+O** เพื่อเปิดรายการเซสชันและโปรเจกต์ล่าสุด เลือกโปรเจกต์แล้วกด **Right** เพื่อดูรายการเวิร์กทรีของโปรเจกต์
จากนั้นกด **Ctrl+N** ในรายการนั้นเพื่อสร้างเวิร์กทรีใหม่

## บริบท

พิมพ์ `@` เพื่อค้นหาไฟล์ แล้วเลือกไฟล์ที่จะแนบกับพรอมต์ พิมพ์ต่อหลัง `@` เพื่อกรองผลลัพธ์

```text
Review @src/auth.ts for error handling problems
```

คุณระบุบรรทัดหรือช่วงบรรทัดหลังพาธได้

```text
Explain @src/auth.ts#20-45
```

## Shell

พิมพ์ `!` ในช่องพิมพ์ที่ยังว่างเพื่อเข้าโหมด shell ป้อนคำสั่งแล้วกด **Enter** หรือกด **Esc** เพื่อออกจากโหมด shell โดยไม่รันคำสั่ง

```text
!git status
```

ระบบรันคำสั่ง shell ในไดเรกทอรีทำงานของเซสชันและเก็บผลลัพธ์ไว้ในเซสชันนั้น

## คำสั่ง

พิมพ์ `/` เพื่อแสดงคำสั่ง slash พิมพ์ต่อเพื่อกรองรายการ แล้วกด **Enter** เพื่อรันคำสั่งที่เลือก

```text
/models
```

คำสั่งที่ใช้บ่อยได้แก่ `/new`, `/sessions`, `/models`, `/agents`, `/undo`, `/redo` และ `/editor` กด **Ctrl+P** เพื่อเปิดพาเลตต์คำสั่ง ซึ่งรวมทุกคำสั่งที่เรียกใช้ได้ในมุมมองปัจจุบัน

หลังอัปเดต OpenCode จะแสดงสิ่งใหม่ในรุ่นนั้นครั้งเดียวบนหน้าหลัก รัน `/highlights` เพื่อดูอีกครั้ง หรือตั้ง `"highlights": false` ใน [`cli.json`](/cli/config#alerts) เพื่อหยุดการเปิดอัตโนมัติ

## คำถามแยกจากบทสนทนาหลัก

รัน `/btw <question>` เพื่อถามคำถามสั้น ๆ เกี่ยวกับสิ่งที่คุยกันในเซสชัน ระบบใช้บริบทของเซสชันและโมเดลปัจจุบันในการตอบ แต่ไม่เพิ่มคำตอบลงในบทสนทนา จึงไม่ส่งผลต่อพรอมต์ถัดไป ระหว่างรอคำตอบจะมีสถานะ `/btw` แสดงใต้ช่องพิมพ์ เมื่อคำตอบเปิดในกล่องโต้ตอบ ให้กด **C** เพื่อคัดลอก

```text
/btw why did the test in step 2 fail?
```

## โมเดล

กด **Ctrl+X** แล้ว **M** เพื่อเลือกโมเดล หรือรัน `/models` กด **F2** เพื่อสลับวนระหว่างโมเดลที่ใช้ล่าสุด

กด **Ctrl+X** แล้ว **A** เพื่อเลือกเอเจนต์ หรือรัน `/agents` กด **Shift+Tab** เพื่อสลับวนระหว่างเอเจนต์

## เซสชัน

แต่ละเซสชันเป็นบทสนทนาแยกกัน โดยมีประวัติและไดเรกทอรีของตัวเอง หากต้องการเริ่มเซสชันสำหรับงานอื่น ให้รัน `/new` หรือกด **Ctrl+X** ตามด้วย **N** คุณยังกลับไปใช้เซสชันเดิมได้ เซสชันใหม่จะเริ่มในไดเรกทอรีที่คุณใช้เปิด OpenCode หรือใช้ไดเรกทอรีของเซสชันปัจจุบันหากตั้ง [`session.new_location`](/cli/config#sessions) เป็น `inherit`

กด **Ctrl+X** ตามด้วย **L** หรือรัน `/sessions` เพื่อกลับไปที่เซสชันเดิม ในรายการนั้น กด **Ctrl+A** เพื่อสลับระหว่างเซสชันในไดเรกทอรีปัจจุบันกับเซสชันจากทุกโปรเจกต์ กด **Ctrl+O** เพื่อเปิดรายการเซสชันและโปรเจกต์ล่าสุดพร้อมกัน

แท็บเปิดใช้งานโดยค่าเริ่มต้น ใช้ **Ctrl+Tab** และ **Ctrl+Shift+Tab** เพื่อสลับแท็บ **Ctrl+X** แล้ว **W** เพื่อปิดแท็บ และ **Ctrl+Shift+T** เพื่อเปิดแท็บที่ปิดล่าสุดอีกครั้ง

## ประวัติ

กด **Ctrl+X** แล้ว **U** หรือรัน `/undo` เพื่อย้อนข้อความล่าสุดของผู้ใช้และงานที่เกิดขึ้นหลังข้อความนั้น พรอมต์จะกลับมาอยู่ในช่องพิมพ์ให้แก้ไขได้

กด **Ctrl+X** แล้ว **R** หรือรัน `/redo` เพื่อคืนงานที่ถูกย้อน หากส่งพรอมต์ใหม่แทน จะถือว่ายอมรับการย้อนและทำงานต่อจากจุดนั้น

## อีดิเตอร์

ตั้งค่า `VISUAL` หรือ `EDITOR` แล้วกด **Ctrl+X** ตามด้วย **E** หรือรัน `/editor` เพื่อแก้ไขพรอมต์ในอีดิเตอร์ที่เลือก บันทึกแล้วออกจากอีดิเตอร์เพื่อนำข้อความกลับมาใส่ในช่องพิมพ์ จากนั้นกด **Enter** เพื่อส่ง

```bash
export EDITOR="nvim"
opencode
```

คีย์นำ (leader key) คือ **Ctrl+X** โดยค่าเริ่มต้น ดูวิธีเปลี่ยนคีย์ลัดเหล่านี้ได้ที่ [คีย์ลัด](/cli/keybinds)
