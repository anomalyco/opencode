การตั้งค่า CLI ควบคุมเฉพาะไคลเอนต์เทอร์มินัล แยกจาก การตั้งค่าเซิร์ฟเวอร์และโปรเจกต์ใน
`opencode.json(c)`

กด `Ctrl+P` แล้วเลือก **Open settings** เพื่อเปลี่ยนการตั้งค่าทั่วไปจาก TUI

<img src={`${import.meta.env.BASE_URL}assets/cli/settings.png`} alt="OpenCode TUI settings dialog" />

## ไฟล์กำหนดค่า

OpenCode เก็บการตั้งค่า CLI ในไฟล์ส่วนกลางหนึ่งไฟล์

```text
~/.config/opencode/cli.json
```

เมื่อตั้ง `$XDG_CONFIG_HOME` OpenCode จะใช้

```text
$XDG_CONFIG_HOME/opencode/cli.json
```

ไม่มีไฟล์การตั้งค่า CLI ระดับโปรเจกต์ ให้เพิ่ม JSON Schema ที่เผยแพร่เพื่อการตรวจสอบและเติมอัตโนมัติ

```json title="cli.json"
{
  "$schema": "https://opencode.ai/v2/cli.json"
}
```

OpenCode เพิ่ม `$schema` เมื่อสร้างหรือย้ายไฟล์นี้ การแก้ไขที่ถูกต้องจะโหลดใหม่ขณะ TUI ทำงาน

การตั้งค่าที่ไม่รู้จักจะถูกเพิกเฉย เก็บ `$schema` ไว้เพื่อให้อีดิเตอร์ของคุณเตือนค่าที่ไม่ถูกต้อง

### `tui.json` จาก V1

V1 เก็บการตั้งค่าไคลเอนต์เทอร์มินัลไว้ใน `tui.json` ส่วน V2 อ่านไฟล์นี้ครั้งเดียวเพื่อย้ายการตั้งค่าเท่านั้น
และไม่ใช้ไฟล์นี้เป็นชั้นการกำหนดค่าที่มีลำดับต่ำกว่า `cli.json`

- หากไม่มี `cli.json` ทาง CLI จะสร้างไฟล์นี้จากการตั้งค่าที่รองรับในไฟล์ `tui.json` ส่วนกลางที่อยู่ในไดเรกทอรีเดียวกัน
  และจากค่ากำหนดที่บันทึกไว้ใน `kv.json` ในไดเรกทอรีเก็บสถานะ
- เมื่อมี `cli.json` แล้ว ระบบจะไม่อ่าน `tui.json` อีก การแก้ไขไฟล์นี้หลังจากนั้นจะไม่มีผล คุณจะเก็บหรือลบไฟล์นี้ก็ได้
- หากลบ `cli.json` ระบบจะย้ายการตั้งค่าอีกครั้งเมื่อเริ่มทำงานครั้งถัดไป
- ระบบจะไม่แก้ไขหรือลบไฟล์เดิม
- ระบบจะอ่านเฉพาะ `tui.json` ส่วนกลาง ไม่ย้ายการตั้งค่าจาก `tui.json` ระดับโปรเจกต์หรือจาก `tui.jsonc`

## การกำหนดค่าแบบอินไลน์

ตั้ง `OPENCODE_CLI_CONFIG_CONTENT` เพื่อใช้การตั้งค่า CLI จาก JSON แบบอินไลน์

```sh
OPENCODE_CLI_CONFIG_CONTENT='{"tabs":{"mode":"off"}}' opencode
```

OpenCode นำการตั้งค่าอินไลน์มารวมกับ `cli.json` ส่วนกลาง โดยรวมออบเจกต์ที่ซ้อนกัน แต่อาร์เรย์และค่าสเกลาร์จากตัวแปรสภาพแวดล้อมจะแทนที่ค่าส่วนกลาง ตราบใดที่ตั้งตัวแปรนี้ไว้ การตั้งค่าอินไลน์ยังมีลำดับสูงกว่า

## รูปลักษณ์
เลือกธีม ควบคุมแอนิเมชันของอินเทอร์เฟซ และแทนที่เคอร์เซอร์ของเทอร์มินัล

```json title="cli.json"
{
  "theme": {
    "name": "tokyonight",
    "mode": "system"
  },
  "animations": true,
  "cursor": {
    "style": "block",
    "blinking": true
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="Appearance settings" tabIndex={0}>

| การตั้งค่า           | ค่า                                  | คำอธิบาย                                                              |
| ----------------- | --------------------------------------- | ------------------------------------------------------------------------ |
| `theme.name`      | สตริง                                  | เลือกธีมในตัว กำหนดเอง หรือที่มาจากเทอร์มินัล                   |
| `theme.mode`      | `system`, `dark` หรือ `light`            | ตามรูปลักษณ์ของเทอร์มินัลหรือล็อกธีมเป็นโหมดสีเดียว    |
| `animations`      | บูลีน                                 | เปิดแอนิเมชันของอินเทอร์เฟซ                                           |
| `cursor.style`    | `block`, `underline`, `line`, `default` | กำหนดรูปร่างเคอร์เซอร์ `default` คงรูปร่างเคอร์เซอร์ของเทอร์มินัล  |
| `cursor.blinking` | บูลีน                                 | ควบคุมการกะพริบของเคอร์เซอร์ ไม่มีผลเมื่อสไตล์เป็น `default` |

</div>

ดู[ธีม](/cli/theme)สำหรับการเลือกและสร้างธีม

## อินพุต

กำหนดการจับเมาส์ การเลื่อน บริบทอีดิเตอร์ การวาง และตัวอย่างภาพในพรอมต์

```json title="cli.json"
{
  "mouse": true,
  "scroll": {
    "speed": 3,
    "acceleration": false
  },
  "prompt": {
    "editor": true,
    "paste": "compact",
    "image_preview": false
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="Input settings" tabIndex={0}>

| การตั้งค่า                    | ค่า                          | คำอธิบาย                                                                 |
| -------------------------- | ------------------------------- | --------------------------------------------------------------------------- |
| `mouse`                    | บูลีน                         | เปิดการจับเมาส์ของเทอร์มินัล                                             |
| `scroll.speed`             | ตัวเลข อย่างน้อย `0.001`        | กำหนดระยะคงที่ต่อการเลื่อนหนึ่งครั้ง                               |
| `scroll.acceleration`      | บูลีน                         | เร่งการเลื่อนซ้ำ เมื่อเปิด จะมีลำดับเหนือกว่าความเร็ว |
| `prompt.editor`            | บูลีน                         | รวมไฟล์หรือส่วนที่เลือกในอีดิเตอร์ที่ใช้งานเป็นบริบทพรอมต์             |
| `prompt.paste`             | `compact` หรือ `full`             | แสดงการวางขนาดใหญ่เป็นตัวแทนย่อหรือข้อความเต็ม                  |
| `prompt.image_preview`     | บูลีน                         | แสดงตัวอย่างไฟล์แนบภาพเหนือช่องพรอมต์                     |

</div>

## เซสชัน

กำหนดวิธีแสดงเซสชัน TUI เต็มหน้าจอและตำแหน่งเริ่มเซสชันใหม่

```json title="cli.json"
{
  "session": {
    "sidebar": "auto",
    "scrollbar": false,
    "submit_scroll": "bottom",
    "thinking": "hide",
    "grouping": "auto",
    "image_preview": false,
    "tps": true,
    "markdown": "rendered",
    "new_location": "launch",
    "permissions": "prompt"
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="Session settings" tabIndex={0}>

| การตั้งค่า                 | ค่า                      | คำอธิบาย                                                                  |
| ----------------------- | --------------------------- | ---------------------------------------------------------------------------- |
| `session.sidebar`       | `auto` หรือ `hide`            | แสดงแถบข้างเมื่อมีพื้นที่หรือซ่อนเสมอ                     |
| `session.scrollbar`     | บูลีน                     | แสดงแถบเลื่อนของบทสนทนา                                              |
| `session.submit_scroll` | `bottom` หรือ `keep`          | กระโดดไปข้อความล่าสุดเมื่อส่งพรอมต์ หรือคงตำแหน่งเดิม  |
| `session.thinking`      | `show` หรือ `hide`            | แสดงหรือซ่อนการให้เหตุผลของโมเดลโดยค่าเริ่มต้น                                   |
| `session.grouping`      | `auto` หรือ `none`            | จัดกลุ่มรายการบทสนทนาที่เกี่ยวข้องหรือแสดงแต่ละรายการแยก             |
| `session.image_preview` | บูลีน                     | แสดงภาพไฟล์แนบผู้ใช้และผลเครื่องมือในบทสนทนา              |
| `session.tps`           | บูลีน                     | แสดงจำนวนโทเคนเอาต์พุตต่อวินาทีในส่วนท้ายของข้อความผู้ช่วย                         |
| `session.markdown`      | `source` หรือ `rendered`      | แสดงเครื่องหมายไวยากรณ์ Markdown หรือซ่อนในเนื้อหาที่แสดงผล          |
| `session.new_location`  | `launch` หรือ `inherit`       | เริ่มในไดเรกทอรีที่เปิด TUI หรือสืบทอดตำแหน่งเซสชันที่ใช้งาน  |
| `session.permissions`   | `prompt` หรือ `autoaccept`    | ถามสำหรับคำขอสิทธิ์หรือยอมรับทุกคำขออัตโนมัติ      |

</div>

## แท็บ

กำหนดแถบแท็บเซสชันแบบถาวร

```json title="cli.json"
{
  "tabs": {
    "mode": "auto",
    "scope": "cwd",
    "layout": "horizontal",
    "indicators": "status"
  }
}
```

การตั้งค่า `tabs.enabled` แบบบูลีนเดิมยังรองรับ: `true` คือ `on` และ `false` คือ `off` OpenCode อ่านโดยไม่เขียนไฟล์กำหนดค่าใหม่

<div class="docs-table-scroll" role="region" aria-label="Tab settings" tabIndex={0}>

| การตั้งค่า           | ค่า                      | คำอธิบาย                                                                   |
| ----------------- | --------------------------- | ----------------------------------------------------------------------------- |
| `tabs.mode`       | `auto`, `on` หรือ `off`      | ใช้แท็บอัตโนมัติ ใช้เสมอ หรือไม่ใช้เลย โหมดอัตโนมัติซ่อนแท็บใน Herdr       |
| `tabs.scope`      | `cwd` หรือ `global`           | เก็บแท็บแยกตามไดเรกทอรีทำงานหรือแชร์ทั่วโลก            |
| `tabs.layout`     | `horizontal` หรือ `vertical`  | วางแท็บในแถบแนวนอนหรือแถบข้างแนวตั้ง                      |
| `tabs.indicators` | `status` หรือ `numbers`       | แสดงไอคอนสถานะหรือแสดงหมายเลขแท็บเสมอ                               |

</div>

ตัวบ่งชี้หมายเลขยังคงสีสถานะและแอนิเมชันพื้นหลัง ทางลัด Ctrl+number สลับแท็บได้ในทั้งสองโหมด

## Diff

กำหนดขอบเขตและรูปแบบ diff เริ่มต้น

```json title="cli.json"
{
  "diffs": {
    "source": "branch",
    "wrap": "word",
    "tree": true,
    "single": false,
    "view": "auto"
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="Diff settings" tabIndex={0}>

| การตั้งค่า        | ค่า                                      | คำอธิบาย                                               |
| -------------- | ------------------------------------------- | --------------------------------------------------------- |
| `diffs.source` | `branch`, `committed`, `working` หรือ `turn` | กำหนดขอบเขตการรีวิวเริ่มต้น                            |
| `diffs.wrap`   | `word` หรือ `none`                            | ตัดบรรทัดยาวที่คำหรือปล่อยไม่ตัด       |
| `diffs.tree`   | บูลีน                                     | แสดงต้นไม้ไฟล์ diff                                 |
| `diffs.single` | บูลีน                                     | แสดงเฉพาะแพตช์ไฟล์ที่เลือก                       |
| `diffs.view`   | `auto`, `split` หรือ `unified`               | กำหนดเลย์เอาต์ `auto` เลือกจากความกว้างที่มี |

</div>

`branch` แสดง **All** ซึ่งรวมการเปลี่ยนแปลงทั้งหมดในสาขาและในเครื่อง ส่วน `committed` แสดงเฉพาะคอมมิตในสาขา และ `working` แสดงการเปลี่ยนแปลงที่ stage แล้ว ที่ยังไม่ stage และไฟล์ที่ Git ยังไม่ได้ติดตาม
`turn` แสดง **Last turn** ซึ่งเป็นไฟล์ที่เซสชันแก้ไขในเทิร์นล่าสุด รายการนี้จะอัปเดตเมื่อเซสชันจบแต่ละเทิร์น และใช้ `branch` แทนหากเปิด `/diff` จากนอกเซสชัน

ใน `/diff` กด `d` เพื่อเปลี่ยนขอบเขตหรือเลือกสาขาเปรียบเทียบจาก **Base** ตัวเลือกในมุมมองเหล่านี้คงจน
TUI ออกและไม่เปลี่ยน `cli.json`

## การแจ้งเตือน

เปิดการแจ้งเตือนของระบบและเสียงเรียกความสนใจแยกกัน

```json title="cli.json"
{
  "attention": {
    "notifications": true,
    "sound": true,
    "volume": 0.4,
    "sound_pack": "opencode.default",
    "sounds": {
      "permission": "/home/me/sounds/permission.wav"
    }
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="Alert settings" tabIndex={0}>

| การตั้งค่า                  | ค่า                 | คำอธิบาย                                                                                              |
| ------------------------ | ---------------------- | -------------------------------------------------------------------------------------------------------- |
| `attention.notifications` | บูลีน               | แสดงการแจ้งเตือนของระบบ ปกติเมื่อเทอร์มินัลไม่โฟกัส                                  |
| `attention.sound`        | บูลีน               | เล่นเสียงเรียกความสนใจ                                                                                  |
| `attention.volume`       | ตัวเลขจาก `0` ถึง `1` | กำหนดระดับเสียง                                                                                       |
| `attention.sound_pack`   | สตริง                 | เลือก ID ชุดเสียงที่ใช้งาน                                                                        |
| `attention.sounds`       | ออบเจกต์                 | แทนที่ไฟล์เสียงสำหรับ `default`, `question`, `permission`, `error`, `done` หรือ `subagent_done`    |

</div>

การแทนที่ที่ไม่ถูกต้องหรืออ่านไม่ได้จะถอยไปใช้เสียงในตัวสำหรับอีเวนต์นั้น

หลังอัปเดต TUI จะแสดงไฮไลต์ของรุ่นใหม่ครั้งเดียวบนหน้าหลัก รัน `/highlights` เพื่อดูอีกครั้ง
หรือปิดกล่องโต้ตอบ

```json title="cli.json"
{
  "highlights": false
}
```

## เทอร์มินัล

กำหนดการเชื่อมต่อเทอร์มินัล

```json title="cli.json"
{
  "terminal": {
    "title": true,
    "copy": "select"
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="Terminal settings" tabIndex={0}>

| การตั้งค่า          | ค่า               | คำอธิบาย                                                                                              |
| ---------------- | -------------------- | -------------------------------------------------------------------------------------------------------- |
| `terminal.title` | บูลีน              | อัปเดตชื่อหน้าต่างเทอร์มินัล                                                                       |
| `terminal.copy`  | `manual` หรือ `select` | คัดลอกด้วยตัวเองหรือทันทีหลังเลือก ค่าเริ่มต้นของแพลตฟอร์มคือ `manual` บน Windows และ `select` ที่อื่น |

</div>

## Mini

กลุ่ม `mini` ควบคุม [`opencode mini`](/cli#mini) ซึ่งเป็นอินเทอร์เฟซแบบอินเทอร์แอกทีฟขั้นต่ำ

```json title="cli.json"
{
  "mini": {
    "thinking": "show",
    "tools": "hide",
    "shell_output": "hide",
    "turn_summary": "show",
    "footer": "show",
    "splash": "show",
    "work_spinner": "block-soft-slide",
    "mono": false,
    "replay": true,
    "replay_limit": 200
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="Mini settings" tabIndex={0}>

| การตั้งค่า             | ค่า                         | คำอธิบาย                                                                        |
| ------------------- | ------------------------------ | ---------------------------------------------------------------------------------- |
| `mini.thinking`     | `show` หรือ `hide`               | แสดงหรือซ่อนการให้เหตุผลของโมเดล                                                    |
| `mini.tools`        | `show` หรือ `hide`               | แสดงหรือซ่อนการเรียกเครื่องมือและข้อความผู้ช่วยที่นำหน้า               |
| `mini.shell_output` | `show` หรือ `hide`               | แสดงหรือซ่อนเอาต์พุตดิบของเครื่องมือ shell                                              |
| `mini.turn_summary` | `show` หรือ `hide`               | แสดงหรือซ่อนสรุปเอเจนต์ โมเดล และระยะเวลาในประวัติการเลื่อน               |
| `mini.footer`       | `show` หรือ `hide`               | แสดงหรือซ่อนรายละเอียดกิจกรรม โมเดล การใช้งาน และบริบทแบบถาวร             |
| `mini.splash`       | `show` หรือ `hide`               | แสดงหรือซ่อนแบนเนอร์ต้อนรับและอำลาตอนเข้า/ออก                                      |
| `mini.work_spinner` | ID สปินเนอร์                     | เลือกแอนิเมชันการทำงานในส่วนท้าย                                          |
| `mini.mono`         | บูลีน                        | ใช้เอาต์พุต ASCII ขาวดำ                                                      |
| `mini.replay`       | บูลีน                        | คืนประวัติเซสชันเมื่อกลับมาและเมื่อปรับขนาดเทอร์มินัล                            |
| `mini.replay_limit` | จำนวนเต็มบวก               | จำกัดการเล่นซ้ำเฉพาะข้อความใหม่สุด ขีดจำกัดเริ่มต้นคือ `200`                  |

</div>

ID สปินเนอร์ที่ใช้ได้คือ

```text
block-soft-slide  block-soft-sweep  block-low-comet  block-low-duet
block-shuttle     block-bridge      block-squeeze    small-toggle
square-toggle     grow-shrink       quadrant-orbit   crosshatch
density-wave      seed
```

แฟล็กการเล่นซ้ำของ `mini` ในบรรทัดคำสั่งแทนที่การตั้งค่าเหล่านี้สำหรับการเรียกครั้งนั้น

## คีย์ลัด

แทนที่การผูกคำสั่งและเวลาหมดอายุของปุ่ม leader

```json title="cli.json"
{
  "keybinds": {
    "leader": "ctrl+x",
    "app.exit": ["ctrl+c", "ctrl+d", "<leader>q"],
    "prompt.paste": {
      "key": "ctrl+v",
      "event": "press",
      "preventDefault": false,
      "fallthrough": false
    },
    "help.show": false
  },
  "leader": {
    "timeout": 2000
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="Keybind settings" tabIndex={0}>

| การตั้งค่า                 | ค่า                                           | คำอธิบาย                                                          |
| ----------------------- | ------------------------------------------------ | -------------------------------------------------------------------- |
| `keybinds.leader`       | ค่าการผูก                                    | กำหนดคีย์ที่ `<leader>` อ้างถึงในการผูกอื่น             |
| `keybinds.<command>`    | ค่าการผูก                                    | แทนที่การผูกสำหรับ ID คำสั่งหนึ่ง                            |
| `keybinds.*.key`        | สตริงคีย์หรือตัวระบุ                         | เลือกคีย์สำหรับการผูกแบบออบเจกต์                               |
| `keybinds.*.event`      | `press` หรือ `release`                             | จำกัดการผูกแบบออบเจกต์ให้หนึ่งอีเวนต์คีย์                           |
| `keybinds.*.preventDefault` | บูลีน                                      | ควบคุมว่าจะป้องกันพฤติกรรมคีย์เริ่มต้นของเทอร์มินัลหรือไม่  |
| `keybinds.*.fallthrough` | บูลีน                                         | อนุญาตให้ตัวจัดการลำดับต่ำกว่าได้รับอีเวนต์เดียวกัน            |
| `leader.timeout`        | จำนวนเต็มบวก                                 | กำหนดจำนวนมิลลิวินาทีที่รอหลังปุ่ม leader             |

</div>

ค่าของคีย์ลัดเป็นได้ทั้งสตริง อาร์เรย์ของคีย์ลัดทางเลือก หรือออบเจกต์ ใช้ `"none"` หรือ `false` เพื่อปิดคีย์ลัด
ดู [คีย์ลัด](/cli/keybinds) สำหรับรูปแบบการระบุคีย์ที่รองรับ รวมถึง ID คำสั่งและคีย์ลัดเริ่มต้นทั้งหมด

## ปลั๊กอิน

โหลดปลั๊กอินเฉพาะเทอร์มินัลตามลำดับ

```json title="cli.json"
{
  "plugins": [
    "-opencode.notifications",
    {
      "package": "./plugins/status",
      "options": {
        "compact": true
      }
    }
  ]
}
```

<div class="docs-table-scroll" role="region" aria-label="Plugin settings" tabIndex={0}>

| การตั้งค่า              | ค่า          | คำอธิบาย                                                     |
| -------------------- | --------------- | --------------------------------------------------------------- |
| `plugins`            | อาร์เรย์           | ระบุรายการเปิดหรือปิดปลั๊กอินตามลำดับ รวมถึงปลั๊กอินภายนอก    |
| `plugins[].package`  | สตริง          | กำหนดชื่อแพ็กเกจ พาธในเครื่อง หรือ URL ไฟล์                    |
| `plugins[].options`  | ออบเจกต์          | ส่งตัวเลือกเฉพาะปลั๊กอินให้ปลั๊กอินนั้น                   |

</div>

ดู[ปลั๊กอิน](/cli/plugins)สำหรับรูปแบบแพ็กเกจ การค้นพบในเครื่อง ไวลด์การ์ด และคำสั่งปิดใช้งาน

## ดีบักและการทดลอง

เปิดการวินิจฉัยหรือเลือกใช้การทดลองที่ใช้ได้ในปัจจุบัน

```json title="cli.json"
{
  "debug": {
    "devtools": false,
    "timing": false,
    "turn_tokens": "verbose"
  },
  "experimental": {}
}
```

<div class="docs-table-scroll" role="region" aria-label="Debug and experimental settings" tabIndex={0}>

| การตั้งค่า             | ค่า                          | คำอธิบาย                                                                         |
| ------------------- | ------------------------------- | ----------------------------------------------------------------------------------- |
| `debug.devtools`    | บูลีน                         | แสดงแถบดีบัก DevTools                                                       |
| `debug.timing`      | บูลีน                         | แสดงการวินิจฉัยเวลาถึงการวาดครั้งแรกในแถบดีบัก                              |
| `debug.turn_tokens` | บูลีนหรือ `verbose`            | แสดงจำนวนโทเคนที่ใช้ต่อเทิร์น `verbose` จะแสดงอินพุตที่ใช้เรียกเครื่องมือด้วย               |
| `experimental`      | ออบเจกต์ของ ID ฟีเจอร์เป็นบูลีน | เปิดหรือปิดการทดลองที่อาจเปลี่ยนหรือถูกนำออกโดยไม่แจ้ง     |

</div>

ใช้เฉพาะ ID ฟีเจอร์ที่แสดงในกล่องโต้ตอบ **Experiments** ของ TUI ปัจจุบัน ID ที่ไม่รู้จักไม่มีผล
