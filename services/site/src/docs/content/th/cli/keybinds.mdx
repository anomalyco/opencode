ปรับแต่งคีย์ลัดใน `cli.json`

```json title="cli.json"
{
  "keybinds": {
    "leader": "ctrl+space",
    "command.palette.show": "ctrl+k",
    "app.exit": ["ctrl+c", "ctrl+d"],
    "app.debug": false
  },
  "leader": {
    "timeout": 1500
  }
}
```

ใช้สตริงสำหรับคีย์เดียว

```json
{
  "keybinds": {
    "command.palette.show": "ctrl+k"
  }
}
```

คั่นทางเลือกด้วยจุลภาค

```json
{
  "keybinds": {
    "app.exit": "ctrl+c,ctrl+d"
  }
}
```

ปิดการผูกด้วย `"none"` หรือ `false`

```json
{
  "keybinds": {
    "app.debug": "none",
    "help.show": false
  }
}
```

ใช้ออบเจกต์สำหรับพฤติกรรมอีเวนต์

```json
{
  "keybinds": {
    "prompt.paste": {
      "key": "ctrl+v",
      "preventDefault": false
    }
  }
}
```

`leader` มีค่าเริ่มต้น `ctrl+x` `<leader>` ในการผูกอื่นหมายถึงคีย์นั้น

```json
{
  "keybinds": {
    "leader": "ctrl+space",
    "model.list": "<leader>m"
  },
  "leader": {
    "timeout": 2000
  }
}
```

ID คำสั่งที่ไม่รู้จักจะถูกเพิกเฉย

## Mini

คำสั่ง `app.clear` ทำงานเฉพาะใน [`opencode mini`](/cli) กด `ctrl+l` เพื่อล้างหน้าจอที่มองเห็นและวาดพรอมต์ใหม่ เทอร์มินัลยังเก็บประวัติการเลื่อน

```json title="cli.json"
{
  "keybinds": {
    "app.clear": "ctrl+l"
  }
}
```

## ตัวแสดง Diff

กด `d` (`diff.switch_source`) เพื่อเลือก **All**, **Committed**, **Uncommitted** หรือ **Last turn** (ในเซสชัน) หรือเลือก **Base** เพื่อเปลี่ยนสาขาที่เปรียบเทียบ ตัวเลือกจะถูกจำไว้จน TUI ออก ตั้งขอบเขตเริ่มต้นด้วย [`diffs.source` ใน `cli.json`](/cli/config#diffs)

คีย์ลัดสำหรับเลื่อน เลื่อนทีละหน้า หรือไปยังจุดเริ่มต้นหรือจุดสิ้นสุด จะควบคุมตัวแสดง Diff เสมอ สลับโฟกัสด้วยแป้นพิมพ์ไม่ได้ ให้คลิกไฟล์เพื่อเปิด คลิกโฟลเดอร์เพื่อขยายหรือยุบ และใช้ล้อเมาส์เลื่อนรายการไฟล์แบบต้นไม้

ใช้ `n` / `p` หรือ `alt+down` / `alt+up` (Option บน macOS) เพื่อสลับไฟล์ ในตัวแสดง Diff คีย์ลัด Alt จะสลับไฟล์แทนการสลับแท็บเซสชัน

กด `m` เพื่อทำเครื่องหมายไฟล์ว่ารีวิวแล้วและยุบเนื้อหาแพตช์ ในมุมมองทุกไฟล์ กด `m` อีกครั้งเพื่อยกเลิกเครื่องหมายและเปิดแพตช์อีกครั้ง มุมมองไฟล์เดียวจะเลื่อนไปไฟล์ถัดไปอัตโนมัติเมื่อทำเครื่องหมายรีวิวแล้ว แต่จะอยู่ที่ไฟล์สุดท้ายแทนการวนกลับ การยกเลิกเครื่องหมายไม่เคยเลื่อน

คลิกขวาที่ไฟล์ในแถบข้างหรือหัวข้อ diff เพื่อ **Mark complete** (หรือ **Mark incomplete**) ซึ่งเปลี่ยนสถานะรีวิวเดียวกันกับ `m` การทำเครื่องหมายไฟล์อื่นจากเมนูไม่เลือกไฟล์นั้นหรือเลื่อนไฟล์ที่กำลังอ่านอยู่

ทางเลือก `diff.help` แบบ shift รองรับเทอร์มินัลที่รายงานตัวปรับ Shift เมื่อคุณกด `?`
