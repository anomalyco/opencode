プロジェクトで OpenCode を実行し、リクエストを入力して **Enter** を押します。

```bash
cd ~/code/my-project
opencode
```

```text
Explain how authentication works in this project
```

改行するには **Shift+Enter**、**Ctrl+Enter**、**Alt+Enter**、または **Ctrl+J** を押します。OpenCode の作業中に **Enter** を押すと、入力したプロンプトで進行中の作業の方向を変えられます。後で実行するためにプロンプトをキューに入れるには、**Ctrl+X** を押してから **Enter** を押します。

## コンテキスト

`@` を入力してファイルを検索し、選択するとそのファイルがプロンプトに添付されます。`@` の後に続けて入力すると、結果を絞り込めます。

```text
Review @src/auth.ts for error handling problems
```

パスの後に行情報や範囲を指定できます。

```text
Explain @src/auth.ts#20-45
```

## シェル

空のプロンプトの先頭で `!` を入力すると、シェルモードに入ります。コマンドを入力して **Enter** を押します。実行せずにシェルモードを抜けるには **Esc** を押します。

```text
!git status
```

シェルコマンドはセッションの作業ディレクトリで実行され、その出力はセッション内に残ります。

## コマンド

`/` を入力するとスラッシュコマンドが一覧表示されます。続けて入力するとリストが絞り込まれ、**Enter** を押すと選択中のコマンドが実行されます。

```text
/models
```

よく使うコマンドには `/new`、`/sessions`、`/models`、`/agents`、`/undo`、`/redo`、`/editor` があります。**Ctrl+P** を押すと、現在のビューで利用可能なすべての操作を含むコマンドパレットが開きます。

更新後、OpenCode はホーム画面でリリースの新機能を一度表示します。もう一度見るには `/highlights` を実行するか、[`cli.json`](/cli/config#alerts) で `"highlights": false` を設定すると自動的に開かなくなります。

## 補足の質問

`/btw <question>` を実行すると、ここまでの会話について手早く質問できます。回答はセッションのコンテキストと現在のモデルを使用しますが、会話には追加されないため、以降のプロンプトに影響しません。実行中はプロンプトのフッターに `/btw` のインジケーターが表示され、回答はダイアログで開きます。**C** を押すとコピーできます。

```text
/btw why did the test in step 2 fail?
```

## モデル

モデルを選ぶには **Ctrl+X** を押してから **M**、または `/models` を実行します。**F2** を押すと、最近使用したモデルを順に切り替えられます。

エージェントを選ぶには **Ctrl+X** を押してから **A**、または `/agents` を実行します。**Shift+Tab** を押すと、エージェントを順に切り替えられます。

## セッション

新しいセッションを始めるには **Ctrl+X** に続けて **N** を押します。既存のセッションに戻るには **Ctrl+X** に続けて **L** を押すか、`/sessions` を実行します。**Ctrl+O** を押すと、最近のセッションとプロジェクトをまとめた一覧が開きます。

タブはデフォルトで有効です。タブ間の移動には **Ctrl+Tab** と **Ctrl+Shift+Tab**、タブを閉じるには **Ctrl+X** の後に **W**、最後に閉じたタブを開き直すには **Ctrl+Shift+T** を使用します。

## 履歴

最新のユーザーメッセージとその後の作業を元に戻すには、**Ctrl+X** を押してから **U**、または `/undo` を実行します。元に戻したプロンプトは入力欄に戻り、編集できます。

元に戻した作業を復元するには、**Ctrl+X** を押してから **R**、または `/redo` を実行します。代わりに新しいプロンプトを送信すると、元に戻す操作が確定し、その時点から続行されます。

## エディタ

`VISUAL` または `EDITOR` を設定し、**Ctrl+X** を押してから **E**、または `/editor` を実行すると、そのエディタで現在のプロンプトを編集できます。保存して終了するとテキストが入力欄に戻るので、**Enter** を押して送信します。

```bash
export EDITOR="nvim"
opencode
```

リーダーキーはデフォルトで **Ctrl+X** です。これらのショートカットの変更については[キーバインド](/cli/keybinds)を参照してください。
