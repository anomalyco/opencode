プロジェクトのディレクトリで OpenCode を起動し、依頼したい内容を入力して **Enter** を押します。

```bash
cd ~/code/my-project
opencode
```

```text
Explain how authentication works in this project
```

改行するには **Shift+Enter**、**Ctrl+Enter**、**Alt+Enter**、または **Ctrl+J** を押します。OpenCode の作業中に **Enter** を押すと、入力したプロンプトで進行中の作業の方向を変えられます。後で実行するためにプロンプトをキューに入れるには、**Ctrl+X** を押してから **Enter** を押します。

## プロジェクトとディレクトリ

OpenCode は起動したディレクトリを基準にファイルを探し、シェルコマンドを実行します。同じ Git リポジトリ内のディレクトリは、ワークツリーも含めて 1 つのプロジェクトに属します。バージョン管理されていないディレクトリは、それ自体が 1 つのプロジェクトになります。

別のプロジェクトで始めるには、ディレクトリを指定して起動します。

```bash
opencode ~/code/another-project
```

最近のセッションとプロジェクトを開くには **Ctrl+O** を押します。プロジェクトを選んで **Right** を押すとワークツリーが一覧表示され、そこで **Ctrl+N** を押すと新しいワークツリーを作成できます。

## コンテキスト

`@` を入力してファイルを検索します。ファイルを選ぶと、プロンプトに添付されます。`@` に続けて文字を入力すると、検索結果を絞り込めます。

```text
Review @src/auth.ts for error handling problems
```

パスの後ろに行番号や行の範囲を指定できます。

```text
Explain @src/auth.ts#20-45
```

## シェル

空のプロンプトの先頭で `!` を入力すると、シェルモードに入ります。コマンドを入力して **Enter** を押します。実行せずにシェルモードを抜けるには **Esc** を押します。

```text
!git status
```

シェルコマンドはセッションの作業ディレクトリで実行され、その出力はセッション内に残ります。

## コマンド

`/` を入力するとスラッシュコマンドが一覧表示されます。続けて入力するとリストが絞り込まれ、**Enter** を押すと選択中のコマンドが実行されます。

```text
/models
```

よく使うコマンドには `/new`、`/sessions`、`/models`、`/agents`、`/undo`、`/redo`、`/editor` があります。**Ctrl+P** を押すとコマンドパレットが開き、現在の画面で実行できるすべての操作が表示されます。

更新後は、リリースの主な変更点がホーム画面に一度だけ表示されます。もう一度見るには `/highlights` を実行します。自動表示を無効にするには、[`cli.json`](/cli/config#alerts) で `"highlights": false` を設定してください。

## 補足の質問

`/btw <question>` を実行すると、ここまでの会話について気になることをその場で質問できます。現在のモデルがセッションのコンテキストを使って答えますが、回答は会話に追加されないため、以降のプロンプトに影響しません。処理中は入力欄の下に `/btw` のインジケーターが表示され、回答はダイアログに表示されます。**C** を押すと回答をコピーできます。

```text
/btw why did the test in step 2 fail?
```

## モデル

モデルを選ぶには、**Ctrl+X** に続けて **M** を押すか、`/models` を実行します。**F2** を押すと、最近使ったモデルを順に切り替えられます。

エージェントを選ぶには、**Ctrl+X** に続けて **A** を押すか、`/agents` を実行します。**Shift+Tab** を押すと、エージェントを順に切り替えられます。

## セッション

セッションごとに会話が分かれ、それぞれに履歴とディレクトリがあります。別の作業を始めるには、`/new` を実行するか、**Ctrl+X** に続けて **N** を押します。それまでのセッションは引き続き利用できます。新しいセッションは OpenCode を起動したディレクトリで始まります。[`session.new_location`](/cli/config#sessions) を `inherit` に設定すると、現在のセッションのディレクトリを引き継ぎます。

既存のセッションに戻るには、**Ctrl+X** に続けて **L** を押すか、`/sessions` を実行します。その一覧で **Ctrl+A** を押すと、現在のディレクトリのセッションと、全プロジェクトのセッションを切り替えられます。**Ctrl+O** を押すと、最近のセッションとプロジェクトをまとめた一覧が開きます。

タブはデフォルトで有効です。タブ間の移動には **Ctrl+Tab** と **Ctrl+Shift+Tab**、タブを閉じるには **Ctrl+X** の後に **W**、最後に閉じたタブを開き直すには **Ctrl+Shift+T** を使用します。

## 履歴

直前のユーザーメッセージとそれ以降の作業を元に戻すには、**Ctrl+X** に続けて **U** を押すか、`/undo` を実行します。送信したプロンプトは入力欄に戻るため、編集できます。

取り消した作業を復元するには、**Ctrl+X** に続けて **R** を押すか、`/redo` を実行します。復元せずに新しいプロンプトを送ると、取り消しが確定し、その時点から作業を続けます。

## エディタ

`VISUAL` または `EDITOR` を設定しておくと、**Ctrl+X** に続けて **E** を押すか `/editor` を実行して、指定したエディタでプロンプトを編集できます。保存してエディタを閉じるとテキストが入力欄に戻るので、**Enter** を押して送信します。

```bash
export EDITOR="nvim"
opencode
```

リーダーキーはデフォルトで **Ctrl+X** です。これらのショートカットの変更については[キーバインド](/cli/keybinds)を参照してください。
