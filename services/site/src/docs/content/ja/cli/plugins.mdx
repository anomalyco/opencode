---
title: "CLI プラグイン"
description: "OpenCode の設定から TUI プラグインを CLI で読み込み、CLI 専用のプラグインとそのオプションを cli.json に追加します。"
---

`opencode.json(c)` で設定され、TUI コンポーネントを公開するプラグインは、CLI によって自動的に読み込まれます。プラグインの作成方法については[プラグインの作成](/build/plugins)を参照してください。同じパッケージを `cli.json` に追加する必要はありません。CLI は接続している OpenCode サーバーからアクティブなプラグインの一覧を取得するため、サーバーがリモートの場合も機能します。

CLI 専用のプラグインには `cli.json` を使用します。これらのプラグインはターミナルでローカルに実行され、CLI がリモートサーバーに接続しても有効なままです。

```json title="cli.json"
{
  "plugins": [
    "opencode.example",
    "opencode.example@1.0.0",
    "@example/opencode-tui",
    "@example/opencode-tui@1.0.0",
    "./plugins/status",
    "../plugins/status",
    "/home/user/plugins/status",
    "file:///home/user/plugins/status"
  ]
}
```

エントリは順に処理されます。ID またはワイルドカードの前に `-` を付けると、一致するプラグインが無効になります。

```json title="cli.json"
{
  "plugins": ["*", "-opencode.notifications", "-team.*"]
}
```

プラグインのオプションはオブジェクト形式で渡します。

```json title="cli.json"
{
  "plugins": [
    {
      "package": "@example/opencode-tui",
      "options": {
        "compact": true
      }
    }
  ]
}
```

OpenCode は、グローバル設定ディレクトリとプロジェクトの `.opencode` ディレクトリ配下からもプラグインを検出します。各プラグインは公開パッケージと同じ構成にし、サーバーと TUI のエントリポイントを同じパッケージに置きます。

```text title="Plugin discovery paths"
<global-config>/plugins/status/index.ts
<global-config>/plugins/status/tui.ts
<project>/.opencode/plugins/status/index.ts
<project>/.opencode/plugins/status/tui.ts
```

検出されたプラグインは `@opencode/plugin/tui` を直接インポートできます。OpenCode は実行時にパッケージの場所を特定します。例については [TUI プラグインの作成](/build/plugins/cli)を参照してください。
