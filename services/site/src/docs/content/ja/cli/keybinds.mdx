title: "キーバインド"
description: "cli.json で OpenCode CLI のキーバインドをカスタマイズし、各コマンドの ID とデフォルトのバインドを確認します。"
---

バインドは `cli.json` でカスタマイズします。

```json title="cli.json"
{
  "keybinds": {
    "leader": "ctrl+space",
    "command.palette.show": "ctrl+k",
    "app.exit": ["ctrl+c", "ctrl+d"],
    "app.debug": false
  },
  "leader": {
    "timeout": 1500
  }
}
```

1 つのキーには文字列を使用します。

```json
{
  "keybinds": {
    "command.palette.show": "ctrl+k"
  }
}
```

代替のキーはカンマで区切ります。

```json
{
  "keybinds": {
    "app.exit": "ctrl+c,ctrl+d"
  }
}
```

バインドを無効にするには `"none"` または `false` を使用します。

```json
{
  "keybinds": {
    "app.debug": "none",
    "help.show": false
  }
}
```

イベントの動作にはオブジェクトを使用します。

```json
{
  "keybinds": {
    "prompt.paste": {
      "key": "ctrl+v",
      "preventDefault": false
    }
  }
}
```

`leader` のデフォルトは `ctrl+x` です。他のバインドの `<leader>` はそのキーを参照します。

```json
{
  "keybinds": {
    "leader": "ctrl+space",
    "model.list": "<leader>m"
  },
  "leader": {
    "timeout": 2000
  }
}
```

不明なコマンド ID は無視されます。

## Mini

`app.clear` コマンドは [`opencode mini`](/cli) でのみ機能します。`ctrl+l` を押すと、表示中の画面をクリアしてプロンプトを描き直します。ターミナルはスクロールバックを保持します。

```json title="cli.json"
{
  "keybinds": {
    "app.clear": "ctrl+l"
  }
}
```

| ID          | デフォルト | 説明           |
| ----------- | ---------- | -------------- |
| `app.clear` | `ctrl+l`   | 画面をクリア   |

## Diff ビューア

`d`（`diff.switch_source`）を押すと、**All**、**Committed**、**Uncommitted**、**Last turn**（セッション内）から選ぶか、**Base** を選択して比較するブランチを変更できます。選択は TUI を終了するまで記憶されます。初期のスコープは [`cli.json` の `diffs.source`](/cli/config#diffs) で設定します。

スクロール、ページ送り、先頭 / 末尾のショートカットは常に Diff を操作します。キーボードフォーカスの切り替えはありません。ファイルをクリックして開き、フォルダをクリックして展開または折りたたみ、マウスホイールでファイルツリーをスクロールします。

ファイル間の移動には `n` / `p` または `alt+down` / `alt+up`（macOS では Option）を使用します。Diff ビューア内では、Alt のショートカットはセッションタブではなくファイルを移動します。

`m` を押すとファイルをレビュー済みとしてマークし、そのパッチ本体を折りたたみます。すべてのファイルのビューでは、もう一度 `m` を押すとマークを解除してパッチを開きます。単一ファイルのビューでは、レビュー済みにすると自動的に次のファイルへ進みますが、最後のファイルでは折り返さずそのまま留まります。マークの解除では進みません。

サイドバーまたは Diff の見出しでファイルを右クリックすると、**Mark complete**（または **Mark incomplete**）を選べます。これは `m` と同じレビュー状態を変更します。別のファイルをそのメニューから完了しても、そのファイルが選択されたり、現在読んでいるファイルが進んだりすることはありません。

`diff.help` に Shift 付きのキーバインドもあるのは、`?` を入力したときに Shift 修飾キーも通知するターミナルに対応するためです。

**Shell** タブで実行中のコマンドを選択して **Enter** を押すか、クリックすると、キャプチャされた stdout と stderr を表示できます。
スクロールには **↑/↓**、**Page Up/Down**、**Home**、新しい出力への追従には **End**、コマンドを止めずに戻るには **Esc** を使用します。
ビューアは最近の出力を表示し、終了後も開いたままです。ファイルにリダイレクトされた出力は含まれません。
