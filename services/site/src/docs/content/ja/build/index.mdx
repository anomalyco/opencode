---
title: "OpenCode で作る"
description: "プラグイン、HTTP API 用の TypeScript クライアント、またはアプリケーションに組み込む SDK を使って OpenCode の上に構築します。"
---

OpenCode は毎日何百万人もの人に使われています。OpenCode を土台にすれば、ゼロから作ることなく、独自のアプリケーションや連携機能、エージェントの利用体験を実現できます。

[プラグイン](/build/plugins/effect)、[クライアント](/build/client/effect)、[組み込みアプリ](/build/sdk/effect)向けの Effect API も提供しています。

<CardGroup cols={1}>
  <Card title="Extend OpenCode" href="/build/plugins">
    OpenCode 本体に手を加えずに、ツール、連携機能、コマンド、エージェント、独自の動作を追加するプラグインを作れます。
  </Card>
  <Card title="Run it as a server" href="/build/client">
    TUI やデスクトップアプリと同じクライアントで OpenCode に接続し、独自のインターフェース、ワークフロー、エージェントの利用体験を作れます。
  </Card>
  <Card title="Embed it" href="/build/sdk">
    OpenCode をアプリケーションに直接組み込み、完全に独自のエージェント、インターフェース、開発者向け製品を作れます。
  </Card>
</CardGroup>
