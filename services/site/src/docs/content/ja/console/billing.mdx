Console はチームの規模を問わず無料で、メンバーごとの利用料はかかりません。使用した分の料金だけが、ワークスペース全体で共有する前払いのクレジットから差し引かれます。オーナーと管理者は **Settings › Billing** で請求を管理します。

[独自に接続したプロバイダー](/console/providers)を利用した分は、Console ではなく、そのプロバイダーから請求されます。

## 支払い方法を追加

1. **Settings › Billing** を開きます。
2. **Payment methods** セクションで **Add** をクリックします。
3. 支払い方法を選択し、Stripe の設定を完了します。

対応している支払い方法は次のとおりです。

- カード
- Link
- Alipay
- UPI
- WeChat Pay

自動支払いに使う支払い方法は **⋯ › Make default** で指定します。支払い方法を削除すると、その方法を使っている自動チャージや Go の契約更新が止まる場合があります。

## クレジットを追加

1. **Credits** セクションで **Add credits** をクリックします。
2. $10、$50、$100 から選ぶか、**Other** を選んで金額を入力します。
3. 支払い方法を選択し、**Confirm and pay** をクリックします。

購入金額には 4.6% + $0.31 の決済手数料が加算されます。たとえば $50 分を購入する場合、支払額は $52.61 で、残高には $50 がそのまま加算されます。

## 自動チャージ

自動チャージを設定すると、残高が少なくなったときにクレジットが自動で購入されます。

1. **Auto-recharge** セクションで **Add rule** をクリックします。
2. 自動チャージが発動する残高のしきい値と、チャージする金額を設定します。
3. **Save** をクリックします。

自動チャージでは、手数料を含めてデフォルトの支払い方法に課金されます。チャージに失敗すると、再度設定するまで自動チャージはオフになります。

## 残高を確認する

オーナーと管理者は **Activity** の **Billing** カードで残高を確認できます。カードをクリックすると **Settings › Billing** が開きます。

ワークスペースのヘッダーにある **Billing** ボタンをクリックするか、`B` キーを押すと、Go の現在の上限、クレジット、使用量を確認できるパネルが開きます。オーナーと管理者にはワークスペースの残高、使用量、自動チャージの設定が表示され、メンバーには自分の使用量と上限だけが表示されます。

## クレジットがなくなったとき

残高がゼロになると、有料のリクエストは HTTP `402` で失敗します。残高がマイナスになることはありません。

```text
Upstream request failed: Insufficient account funds
```

## 請求書

**Invoices** には、すべての支払いについて、ステータスと **Download invoice** または **View receipt** のリンクが表示されます。

| 項目                     | 作成のきっかけ                                 |
| ------------------------ | ---------------------------------------------- |
| 残高のチャージ           | クレジットの追加                               |
| 自動チャージ             | 自動チャージ                                   |
| Go サブスクリプション    | Go、Go Plus、Go Teams の契約                   |
| Go の更新                | Go の月次更新                                  |
| Go Plus へのアップグレード | Go から Go Plus へのアップグレード            |
| Go Teams へのアップグレード | Go または Go Plus から Go Teams へのアップグレード |
| Go Teams のメンバー      | Go Teams のワークスペースへのメンバー参加      |
| 月次使用量               | 請求書払い                                     |

## 請求書払い

与信契約を締結しているワークスペースでは、クレジットの前払いに代えて、月ごとの請求書払いを利用できます。ご希望の場合はサポートにお問い合わせください。

- 前払いの残高ではなく、クレジット上限の範囲内で利用できます。
- 毎月の請求書は 1 日（UTC）に発行され、14 日後が支払期限です。
- 未払いの請求書には **Pay now** ボタンがあります。
- クレジット上限に達した場合、または支払期限を過ぎた未払いの請求書がある場合は、リクエストに対して HTTP `402` が返ります。

## Go

[OpenCode Go](/console/go) のサブスクリプションにも同じ支払い方法を利用でき、支払いは同じ請求書一覧に表示されます。[Go の料金をクレジットで支払う](/console/go#pay-with-credit)こともできます。**Go** ページで **Extra Usage** をオンにすると、Go の上限を超えた分の料金がクレジットから差し引かれます。
