Console はチームの規模を問わず無料で、メンバーごとの利用料はかかりません。料金が発生するのは使用分のみで、ワークスペースで共有する前払いのクレジットから差し引かれます。オーナーと管理者は **Settings › Billing** で請求を管理します。

[自分のプロバイダー](/console/providers)経由の使用量は、Console ではなくプロバイダーから請求されます。

## 支払い方法を追加

1. **Settings › Billing** を開きます。
2. **Payment methods** の下で **Add** をクリックします。
3. 支払い方法を選択し、Stripe の設定を完了します。

対応している支払い方法は次のとおりです。

- カード
- Link
- Alipay
- UPI
- WeChat Pay

自動課金に使う支払い方法は **⋯ › Make default** で選択します。支払い方法を削除すると、それを使っている自動チャージや Go の更新が停止する場合があります。

## クレジットを追加

1. **Credits** の下で **Add credits** をクリックします。
2. $10、$50、$100 から選ぶか、**Other** を選んで金額を入力します。
3. 支払い方法を選択し、**Confirm and pay** をクリックします。

これに手数料 4.6% + $0.31 が加算されるため、$50 の購入には $52.61 がかかり、残高には $50 全額が追加されます。

## 自動チャージ

自動チャージを設定すると、残高が少なくなったときにクレジットが自動で購入されます。

1. **Auto-recharge** の下で **Add rule** をクリックします。
2. チャージを実行する残高と、追加する金額を設定します。
3. **Save** をクリックします。

自動チャージでは、手数料を含めてデフォルトの支払い方法に課金されます。チャージに失敗すると、再度設定するまで自動チャージはオフになります。

## 残高を確認する

オーナーと管理者は **Activity** の **Billing** カードで残高を確認できます。カードを開くと **Settings › Billing** に移動します。

ワークスペースのヘッダーにある **Billing** ボタン、または `B` キーを押すと、Go の現在の上限、クレジット、使用量を含むドロワーが開きます。オーナーと管理者にはワークスペースの残高、使用量、自動チャージが表示され、メンバーには自分の使用量と上限だけが表示されます。

## クレジットがなくなったとき

残高がゼロになると、有料のリクエストは HTTP `402` で失敗します。残高がマイナスになることはありません。

```text
Upstream request failed: Insufficient account funds
```

## 請求書

すべての支払いは **Invoices** に、ステータスと **Download invoice** または **View receipt** へのリンク付きで表示されます。

| 項目                     | 作成のきっかけ                                 |
| ------------------------ | ---------------------------------------------- |
| 残高のチャージ           | クレジットの追加                               |
| 自動チャージ             | 自動チャージ                                   |
| Go サブスクリプション    | Go、Go Plus、Go Teams の契約                   |
| Go の更新                | Go の月次更新                                  |
| Go Plus へのアップグレード | Go から Go Plus へのアップグレード            |
| Go Teams へのアップグレード | Go または Go Plus から Go Teams へのアップグレード |
| Go Teams のメンバー      | Go Teams のワークスペースへのメンバー参加      |
| 月次使用量               | 請求書払い                                     |

## 税務フォーム

米国のお客様は [Anomaly Innovations Inc. の W-9](/assets/anomaly-w9.pdf) をダウンロードできます。

## 請求書払い

与信契約を締結しているワークスペースでは、クレジットの前払いに代えて、月ごとの請求書払いを利用できます。ご希望の場合はサポートにお問い合わせください。

- 前払いの残高ではなく、クレジット上限の範囲内で利用できます。
- 毎月の請求書は 1 日（UTC）に発行され、14 日後が支払期限です。
- 未払いの請求書には **Pay now** ボタンがあります。
- クレジット上限に達した場合、または支払期限を過ぎた未払いの請求書がある場合は、リクエストに対して HTTP `402` が返ります。

## Go

[OpenCode Go](/console/go) のサブスクリプションは同じ支払い方法を使い、同じ請求書一覧に表示されます。[Go をクレジットで支払う](/console/go#pay-with-credit)こともできます。**Go** ページで **Extra Usage** をオンにすると、Go の上限に達した後にクレジットから支払われます。
