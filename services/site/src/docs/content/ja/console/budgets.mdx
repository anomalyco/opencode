---
title: "予算"
description: "ワークスペース、そのメンバー、サービスアカウントの月間支出に上限を設定します。"
---

予算ポリシーで月間支出の上限を設定できます。オーナーと管理者は **Controls** で予算を管理します。

## 予算のレベル

| ポリシーの対象             | 適用範囲                                               |
| -------------------------- | ------------------------------------------------------ |
| ワークスペース全体         | すべてのメンバーとサービスアカウントの合計支出         |
| すべてのメンバー           | 各メンバー、またはすべてのメンバーで 1 つの利用枠を共有 |
| タグ付けされたメンバー     | 選択したタグを持つメンバー                             |
| 指定したメンバー           | 特定のメンバー                                         |
| すべてのサービスアカウント | 各サービスアカウント、または 1 つの利用枠を共有        |
| 指定したサービスアカウント | 特定のサービスアカウント                               |

リクエストは、適用されるすべての予算の範囲内に収まる必要があります。利用枠が大きい予算があっても、小さい方の上限は引き続き適用されます。予算を設定しない場合、支出に上限はありません。

## ワークスペースの予算

ワークスペースの予算に達すると、そのワークスペースの全員のリクエストがブロックされます。

1. **Controls** を開き、**Add policy** をクリックします。
2. **Entire workspace** を選択し、**Budget** ルールを追加します。
3. 月間の上限を米ドルで入力し、**Save** をクリックします。

## メンバーの予算

ポリシーで **All members** を選ぶと、各メンバーに月間の利用枠を付与するか、グループ全体で 1 つの金額を共有できます。対象を絞る場合は、特定のメンバーまたはタグを選びます。

1 人だけに予算を設定するには、次のようにします。

1. **Settings › Members** でそのメンバーを開きます。
2. **Create budget policy** をクリックすると、そのメンバーが選択された状態でビルダーが開きます。
3. 金額を入力し、**Save** をクリックします。

メンバーのページには、適用されるポリシーが一覧表示されます。全メンバー向けの予算もそのメンバーに適用される場合、両方の上限が適用されます。

## サービスアカウントの予算

**Controls** で **All service accounts** または **These service accounts** を選び、**Budget** ルールを追加して、個別または共有の月間利用枠を設定します。ポリシーは、それらのアカウントに属するすべてのキーを対象にします。

## 金額とリセット

- 金額は米ドルで、小数点以下 2 桁まで指定できます。
- 予算は毎月 1 日 00:00 UTC にリセットされます。
- `$0` の予算は、予算の対象となるすべての支出をブロックします。
- 予算を追加または変更しても、その月にすでに記録された支出が含まれ、利用枠はリセットされません。

## 対象となる支出

デフォルトでは、予算は **All spend** を対象にします。対象を選択したモデルに絞ることもでき、その場合はそれらのモデルだけが対象となり、セット全体で 1 つの利用枠を使うか、モデルごとに別々の利用枠を設定できます。

| 支出                                                                 | 予算の対象                     |
| -------------------------------------------------------------------- | ------------------------------ |
| 有料の Console モデル                                                | 対象                           |
| 価格を設定した[自分のプロバイダー](/console/providers)のモデル      | 対象（設定した価格で）         |
| [Web 検索](/console/websearch)                                       | 対象（全支出の予算の場合）     |
| 無料モデル                                                           | 対象外                         |
| プラン内の [Go](/console/go) の使用量                                | 対象外                         |
| クレジットから支払う Go の追加使用量                                 | 対象                           |

## 予算に達したとき

予算がリセットされるか、オーナーまたは管理者が上限を引き上げるまで、新しいリクエストは HTTP `429` で失敗します。レスポンスはポリシーによる予算超過を示しますが、どの予算かは示しません。ブロックしたポリシーを確認するには、**Activity › Logs** で該当のリクエストを開きます。

```text
Upstream request failed: Policy budget exceeded
```

予算はリクエストの開始時に確認されます。すでに進行中のリクエストは最後まで実行されるため、支出が上限をわずかに超えることがあります。

## 支出を確認する

各メンバーは **Activity** で自分の支出と上限を確認できます。**My usage** を開くと **Activity › Overview** が表示され、予算の詳細とリセット日も確認できます。

オーナーと管理者は、支出チャートから **Activity › Usage** を開けます。ここではコストが日別、モデル別、メンバー別に分類され、**Export usage** ボタンで過去 7 日、30 日、90 日の日次合計を CSV としてダウンロードできます。スクリプトから同じファイルをダウンロードするには、[使用量エクスポート API](/console/api/usage-export) を使用します。
