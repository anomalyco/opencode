ワークスペースは、[Console](https://opencode.ai/console) のすべてをまとめる単位です。メンバー、クレジット、予算、プロバイダー、ポリシー、サービスアカウントが含まれます。使用量と請求はワークスペースごとに記録されます。

ワークスペースのメンバーは 1 人だけでもかまいません。クレジット、[自分のプロバイダー](/console/providers)、予算、[Go](/console/go) を自分だけで使い、必要になったときだけ[メンバーを招待](/console/members)できます。

## 最初のワークスペース

Console はサインアップ時に **Personal** という名前のワークスペースを作成し、あなたをオーナーかつ唯一のメンバーにします。招待からサインアップした場合は、招待元のワークスペースに参加するため、Personal ワークスペースは作成されません。

## ワークスペースを作成する

1. 上部バーのワークスペースメニューを開きます。
2. **Create Workspace** をクリックします。
3. **Workspace name** を入力し、**Create** をクリックします。

新しいワークスペースのオーナーになります。

## ワークスペースを切り替える

ワークスペースメニューから別のワークスペースを選びます。Console は同じページを維持するため、`/acme/settings/members` から切り替えると、もう一方のワークスペースの Members ページが開きます。

保留中の招待は同じメニューの上部に表示されます。[メンバー](/console/members#accept-an-invitation)を参照してください。

## OpenCode を接続する

OpenCode で `/connect` を実行し、ブラウザでワークスペースを選択します。以降、OpenCode はそのワークスペースのモデル、ポリシー、予算を使用します。

```text
/connect
```

再度 `/connect` を実行すると、OpenCode を別のワークスペースに切り替えられます。ワークスペースの[ポリシー](/policies#console)は新しいワークスペースのものに置き換わり、接続を解除するとクリアされます。

## ロール

各メンバーは 1 つのロールを持ちます。新しいメンバーは常に **Member** として参加します。

| ロール   | できること                                                                                                             |
| -------- | ---------------------------------------------------------------------------------------------------------------------- |
| メンバー | OpenCode を使用し、自分の使用量、ログ、予算を確認できる。                                                               |
| 管理者   | メンバーができることに加え、メンバー、請求、予算、プロバイダー、ポリシー、サービスアカウント、設定を管理できる。         |
| オーナー | 管理者ができることに加え、SSO とディレクトリ同期を管理し、オーナーロールを付与し、ワークスペースを削除できる。           |

メンバーは **Activity** で自分の使用量とログを確認でき、メンバーに表示される場合はリーダーボードも確認できます。ワークスペースに [Go Teams](/console/go) のサブスクリプションがある場合は、自分の上限を含む **Go** も表示されます。**Account** はアカウントメニューから開きます。

### ロールのルール

- ワークスペースには複数のオーナーを設定でき、常に少なくとも 1 人のオーナーが残ります。
- 自分より上位のロールは付与できないため、オーナーだけが他のメンバーをオーナーにできます。
- 自分のロールは変更できません。

### オーナー権限を移譲する

1. オーナーとして **Settings › Members** を開き、新しいオーナーのロールを **Owner** に設定します。
2. 新しいオーナーに依頼して、自分のロールを **Admin** または **Member** に変更してもらいます。

## ワークスペースを削除する

ワークスペースを削除できるのはオーナーだけであり、かつ他のワークスペースに少なくとも 1 つ所属している必要があります。

1. **Settings › General** を開き、**Delete workspace** をクリックします。
2. すべての確認項目にチェックを入れます。
3. **Delete workspace** をクリックして確定します。

削除はすぐに実行され、元に戻すことはできません。

- メンバーはその場でアクセスできなくなります。
- すべてのサービスアカウントの API キーと保留中の招待が無効になります。
- 自動チャージは停止します。
- 有効な Go サブスクリプションは終了します。
- 未使用のクレジットは失効します。

<Callout type="warning">支払いの処理中は削除できません。数分後にもう一度お試しください。</Callout>

## ワークスペースを退出する

1. アカウントメニューから **Account** を開きます。
2. **Connected workspaces** の下で、ワークスペースの横にある **Leave** をクリックします。
3. **Leave workspace** で確定します。

最後のオーナーは退出できません。先に別のメンバーをオーナーにしてください。SSO またはディレクトリ同期を使用するワークスペースでは、ID プロバイダーがメンバーシップを管理するため、Console から退出することはできません。退出後に再参加するには、新しい招待を依頼してください。
