---
title: Plugins du CLI
description: Chargez les plugins TUI depuis votre configuration OpenCode dans le CLI, et ajoutez des plugins réservés au CLI et leurs options dans cli.json.
---

Les plugins configurés dans `opencode.json(c)` qui exposent un composant TUI sont chargés automatiquement par le CLI. Pour apprendre à créer des plugins, consultez [Créer des plugins](/build/plugins). Vous n’avez pas besoin d’ajouter le même paquet à `cli.json`. Le CLI obtient la liste des plugins actifs depuis le serveur OpenCode connecté, ce qui fonctionne donc aussi lorsque le serveur est distant.

Utilisez `cli.json` pour les plugins réservés au CLI. Ces plugins s’exécutent localement dans le terminal et restent actifs lorsque le CLI se connecte à un serveur distant :

```json title="cli.json"
{
  "plugins": [
    "opencode.example",
    "opencode.example@1.0.0",
    "@example/opencode-tui",
    "@example/opencode-tui@1.0.0",
    "./plugins/status",
    "../plugins/status",
    "/home/user/plugins/status",
    "file:///home/user/plugins/status"
  ]
}
```

Les entrées sont traitées dans l’ordre. Préfixez un ID ou un joker par `-` pour désactiver les plugins correspondants :

```json title="cli.json"
{
  "plugins": ["*", "-opencode.notifications", "-team.*"]
}
```

Pour définir les options d’un plugin, utilisez la forme objet :

```json title="cli.json"
{
  "plugins": [
    {
      "package": "@example/opencode-tui",
      "options": {
        "compact": true
      }
    }
  ]
}
```

OpenCode recherche aussi des plugins dans le répertoire de configuration global et dans les répertoires `.opencode` des projets. Chaque plugin suit la structure d’un paquet publié et regroupe les points d’entrée du serveur et du TUI.

```text title="Plugin discovery paths"
<global-config>/plugins/status/index.ts
<global-config>/plugins/status/tui.ts
<project>/.opencode/plugins/status/index.ts
<project>/.opencode/plugins/status/tui.ts
```

Les plugins découverts peuvent importer `@opencode/plugin/tui` directement ; OpenCode résout le paquet à l’exécution. Consultez [Créer des plugins TUI](/build/plugins/cli) pour des exemples.
