---
title: Raccourcis clavier
description: Personnalisez les raccourcis clavier du CLI OpenCode dans cli.json et retrouvez l’ID de chaque commande ainsi que son raccourci par défaut.
---

Personnalisez les raccourcis dans `cli.json` :

```json title="cli.json"
{
  "keybinds": {
    "leader": "ctrl+space",
    "command.palette.show": "ctrl+k",
    "app.exit": ["ctrl+c", "ctrl+d"],
    "app.debug": false
  },
  "leader": {
    "timeout": 1500
  }
}
```

Utilisez une chaîne pour une seule touche :

```json
{
  "keybinds": {
    "command.palette.show": "ctrl+k"
  }
}
```

Séparez les alternatives par des virgules :

```json
{
  "keybinds": {
    "app.exit": "ctrl+c,ctrl+d"
  }
}
```

Désactivez une liaison avec `"none"` ou `false` :

```json
{
  "keybinds": {
    "app.debug": "none",
    "help.show": false
  }
}
```

Utilisez un objet pour le comportement des événements :

```json
{
  "keybinds": {
    "prompt.paste": {
      "key": "ctrl+v",
      "preventDefault": false
    }
  }
}
```

`leader` vaut `ctrl+x` par défaut. `<leader>` dans une autre liaison fait référence à cette touche.

```json
{
  "keybinds": {
    "leader": "ctrl+space",
    "model.list": "<leader>m"
  },
  "leader": {
    "timeout": 2000
  }
}
```

Les ID de commande inconnus sont ignorés.

## Mini

La commande `app.clear` ne fonctionne que dans [`opencode mini`](/cli). Appuyez sur `ctrl+l` pour effacer l’écran visible et redessiner le prompt. Le terminal conserve l’historique de défilement.

```json title="cli.json"
{
  "keybinds": {
    "app.clear": "ctrl+l"
  }
}
```

| ID | Par défaut | Description |
| --- | --- | --- |
| `app.clear` | `ctrl+l` | Effacer l’écran |

## Visionneuse Diff

Appuyez sur `d` (`diff.switch_source`) pour choisir **All**, **Committed**, **Uncommitted** ou **Last turn** (dans une session), ou sélectionnez **Base** pour changer la branche de comparaison. Les choix sont mémorisés jusqu’à la fermeture du TUI. Définissez le périmètre initial avec [`diffs.source` dans `cli.json`](/cli/config#diffs).

Le défilement, la pagination et les raccourcis de début/fin contrôlent toujours le diff. Il n’y a pas de bascule de focus au clavier : cliquez sur les fichiers pour les ouvrir, sur les dossiers pour les déplier ou les replier, et utilisez la molette pour faire défiler l’arborescence.

Utilisez `n` / `p` ou `alt+down` / `alt+up` (Option sur macOS) pour passer d’un fichier à l’autre. Dans la visionneuse de diff, les raccourcis Alt naviguent entre les fichiers plutôt qu’entre les onglets de session.

Appuyez sur `m` pour marquer un fichier comme relu et replier son patch. Dans la vue tous les fichiers, appuyez à nouveau sur `m` pour le démarquer et rouvrir le patch. La vue d’un seul fichier passe automatiquement au fichier suivant lorsque vous marquez comme relu, mais reste sur le dernier fichier au lieu de boucler. Démarquer un fichier ne fait jamais avancer.

Faites un clic droit sur un fichier dans la barre latérale ou sur son en-tête de diff pour **Mark complete** (ou **Mark incomplete**). Cela modifie le même état de relecture que `m`. Terminer un autre fichier depuis son menu ne le sélectionne pas et ne fait pas avancer le fichier en cours de lecture.

Les alternatives `diff.help` avec Maj prennent en charge les terminaux qui signalent le modificateur Shift lorsque vous appuyez sur `?`.
