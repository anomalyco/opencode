---
title: Développer avec OpenCode
description: Développez vos propres solutions avec OpenCode grâce aux plugins, le client TypeScript de son API HTTP ou le SDK qui l’intègre à votre application.
---

OpenCode est utilisé par des millions de personnes chaque jour. Appuyez-vous sur OpenCode pour créer vos propres applications, intégrations et interfaces pour agents sans repartir de zéro.

Nous proposons aussi des API Effect pour les [plugins](/build/plugins/effect), les [clients](/build/client/effect) et les [applications embarquées](/build/sdk/effect).

<CardGroup cols={1}>
  <Card title="Extend OpenCode" href="/build/plugins">
    Créez des plugins qui ajoutent des outils, des intégrations, des commandes, des agents et des comportements personnalisés
    tout en laissant le reste d’OpenCode intact.
  </Card>
  <Card title="Run it as a server" href="/build/client">
    Connectez-vous à OpenCode avec le même client que le TUI et l’application Desktop, puis créez l’interface, le flux de travail ou l’expérience d’utilisation d’un agent qui vous convient.
  </Card>
  <Card title="Embed it" href="/build/sdk">
    Intégrez OpenCode directement dans votre application et créez un agent, une interface ou un produit destiné aux développeurs, entièrement sur mesure.
  </Card>
</CardGroup>
