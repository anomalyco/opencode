---
title: API d’export des données d’utilisation
description: Téléchargez les données d’utilisation quotidiennes d’un espace de travail au format CSV, avec les requêtes, les tokens et le coût pour chaque jour, personne, fournisseur et modèle.
---

`GET https://opencode.ai/console/api/v2/usage/export` renvoie l’utilisation d’un espace de travail au format CSV, avec une ligne par jour UTC, membre ou compte de service, fournisseur et modèle. C’est le même fichier que celui téléchargé par le bouton **Export usage** depuis **Activity › Usage**.

```bash
curl --fail-with-body "https://opencode.ai/console/api/v2/usage/export?range=30d" \
  --header "Authorization: Bearer oc_sk_..." \
  --output usage-30d.csv
```

## Authentification

Envoyez une [clé d’API](/console/api#api-keys) sous forme de token Bearer. L’export porte sur l’espace de travail dans lequel la clé a été créée.

```text
Authorization: Bearer oc_sk_...
```

La clé a besoin de **Usage › Read**. Les clés avec **All** ou **Read only** en disposent. Une clé restreinte a besoin de :

```text
Permissions: Restricted
Usage:       Read
```

Utilisez une [clé de compte de service](/console/api#service-accounts) pour les exports planifiés, ou la [clé d’API personnelle](/console/api#personal-api-keys) d’un propriétaire ou administrateur. Les membres ne peuvent pas consulter les données d’utilisation de tout l’espace de travail : leurs clés renvoient donc `403`.

## Requête

| Paramètre | Requis | Valeur |
| --- | --- | --- |
| `range` | Oui | `7d`, `30d` ou `90d`. |
| `user_id` | Non | Un ID de membre (`user_...`) ou de compte de service (`svcacct_...`). Renvoie uniquement les lignes de ce membre ou de ce compte de service. |

`range` compte des jours UTC et inclut aujourd’hui : `7d` correspond donc à aujourd’hui et aux six jours précédents. Les chiffres du jour continuent d’évoluer jusqu’à minuit UTC.

Pour exporter l’utilisation d’un compte de service, passez son ID indiqué dans la colonne `user_id` d’un export antérieur :

```bash
curl --fail-with-body "https://opencode.ai/console/api/v2/usage/export?range=7d&user_id=svcacct_01JD8Z4Q2W7N3K5M6P9R0S1T2V" \
  --header "Authorization: Bearer oc_sk_..."
```

Un ID absent de l’espace de travail ne renvoie que la ligne d’en-tête.

## Réponse

Une requête réussie renvoie `200` avec `Content-Type: text/csv; charset=utf-8`. La première ligne est l’en-tête. Les lignes suivent, du jour le plus récent au plus ancien.

```csv
day,user_type,user_id,user_name,provider,model,requests,input_tokens,output_tokens,cache_read_tokens,cache_write_5m_tokens,cache_write_1h_tokens,cost_micro_cents,cost_usd
2026-11-24,service_account,svcacct_01JD8Z4Q2W7N3K5M6P9R0S1T2V,CI Pipeline,opencode,claude-sonnet-5-5,412,1830211,96402,5120330,210044,0,1512334800,15.123348
2026-11-24,member,user_01JC2X7Y8Z9A0B1C2D3E4F5G6H,ada@example.com,opencode,claude-haiku-5-5,57,402118,31877,880012,0,0,214500000,2.145
2026-11-23,member,user_01JC2X7Y8Z9A0B1C2D3E4F5G6H,ada@example.com,opencode,claude-sonnet-5-5,96,711560,48210,2204118,61022,0,587000000,5.87
```

- Les lignes se terminent par `\r\n`.
- Les jours sans utilisation n’ont aucune ligne.
- La réponse est fournie sous forme de fichier à télécharger (`Content-Disposition: attachment; filename="usage-30d.csv"`) et n’est jamais mise en cache (`Cache-Control: private, no-store`).
- Une cellule texte qui commence par `=`, `+`, `-` ou `@` reçoit un `'` initial, afin que les tableurs ne l’exécutent pas comme une formule.

### Colonnes

| Colonne | Signification |
| --- | --- |
| `day` | La date UTC, au format `YYYY-MM-DD`. |
| `user_type` | `member` ou `service_account`. |
| `user_id` | L’ID du membre ou du compte de service. |
| `user_name` | L’adresse e-mail du membre, ou le nom du compte de service. Peut être vide. |
| `provider` | Le fournisseur qui a servi les requêtes, par exemple `opencode` pour [OpenCode Models](/console/models). |
| `model` | L’ID du modèle. |
| `requests` | Nombre de requêtes. |
| `input_tokens` | Tokens d’entrée. |
| `output_tokens` | Tokens de sortie. |
| `cache_read_tokens` | Tokens lus depuis le cache des prompts. |
| `cache_write_5m_tokens` | Tokens écrits dans le cache des prompts avec une durée de vie de 5 minutes. |
| `cache_write_1h_tokens` | Tokens écrits dans le cache des prompts avec une durée de vie d’une heure. |
| `cost_micro_cents` | Coût sous forme d’entier de micro-cents. Un dollar américain vaut `100000000`. |
| `cost_usd` | Le même coût en dollars américains, sous forme de décimal exact avec au moins deux décimales, comme `2.145` ou `0.00`. |

### Ce qui est inclus

- Chaque requête de modèle effectuée par les membres et comptes de service de l’espace de travail.
- Les requêtes vers des modèles gratuits, et celles que les membres font via leurs propres abonnements Claude Code, Codex ou OpenCode, figurent dans l’export avec leur nombre de tokens et un coût nul.
- [La recherche web](/console/websearch) et les autres services hébergés ne sont pas inclus.
- Les totaux peuvent accuser environ une minute de retard sur les nouvelles requêtes.

## Limites

- Un export couvre au plus 90 jours. Pour conserver un historique plus long, planifiez des exports réguliers.
- Les requêtes comptent dans la limite de l’API Console de 300 requêtes par minute et par compte, partagée avec ses autres endpoints. Les clés d’API personnelles comptent pour le membre qui les possède.

## Erreurs

| Statut | Signification |
| --- | --- |
| `400` | `range` manque ou n’est pas `7d`, `30d` ou `90d`, ou `user_id` n’est pas un ID de membre ou de compte de service. |
| `401` | Aucun identifiant, ou une clé expirée ou révoquée. |
| `403` | La clé n’a pas **Usage › Read**, ou appartient à un membre qui n’est ni propriétaire ni administrateur. |
| `429` | Limite de débit dépassée. Réessayez après le nombre de secondes indiqué dans l’en-tête `Retry-After`. |
| `503` | Les totaux quotidiens ne sont pas encore disponibles. Réessayez plus tard. |
