Claude 요금제나 다른 Claude Code 계정을 사용할 수 있습니다. Claude Agent는 사용자의 컴퓨터에서 Claude Code를 실행하므로,
Claude Code 2.1.248 이상을 설치하고 먼저 로그인하세요.

```bash
claude auth login
```

그다음 **Claude Agent**를 연결하고 모델을 선택하세요. 모델 목록은 Claude Code에서 가져옵니다. 추론 강도는
`claude-agent/opus#high`처럼 변형으로 지정합니다.

```text
/connect
# Select Claude Agent.
/models
```

CLI에서 `auth login claude-agent`로 연결할 수도 있습니다.

OpenCode는 `claude` 실행 파일을 `PATH`에서 찾습니다. 다른 위치에 설치한 실행 파일을 사용하려면 서버에 `OPENCODE_CLAUDE_PATH`를 설정하세요.

```bash
opencode service set env OPENCODE_CLAUDE_PATH /opt/claude/bin/claude
```

## 작동 방식

모델 호출은 Claude Code가 하고 나머지는 OpenCode가 처리합니다.

- Claude는 Claude Code의 시스템 프롬프트와 함께 에이전트 프롬프트, `AGENTS.md` 파일, 스킬, MCP 지침을 받습니다.
- Claude는 Claude Code의 내장 도구 대신 OpenCode의 도구와 권한을 사용합니다.
- Claude Code 설정, `CLAUDE.md` 파일, 훅, MCP 서버, 스킬, 메모리는 로드되지 않습니다.
- 압축과 서브에이전트는 OpenCode가 실행합니다.
- 같은 세션에서 Claude Agent와 다른 모델을 오갈 수 있습니다.

## 비용

비용은 Claude Code 로그인 방식에 따라 다릅니다.

| 로그인 | 표시되는 비용 |
| --- | --- |
| Claude 구독 | 없음, 요금제에 포함 |
| Anthropic API 키 또는 AWS나 Google Cloud의 Claude Platform | Anthropic 가격 |
| Amazon Bedrock | Bedrock 가격, Bedrock Mantle에서는 Anthropic 가격 |
| Google Vertex | Vertex 가격 |
| Microsoft Foundry | Azure 가격 |
| 커스텀 기본 URL | 없음 |

## 구성

`claude-agent` 제공자의 연결 설정은 Claude Code로 전달됩니다. 셸에 설정된 같은 변수보다 우선합니다.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "providers": {
    "claude-agent": {
      "settings": {
        "baseURL": "https://llm-proxy.example.com/anthropic",
      },
      "headers": {
        "X-Gateway-Tenant": "engineering",
      },
    },
  },
}
```

| 구성 | Claude Code 변수 |
| --- | --- |
| `settings.baseURL` | `ANTHROPIC_BASE_URL` |
| `settings.apiKey` | `ANTHROPIC_API_KEY` |
| `settings.authToken` | `ANTHROPIC_AUTH_TOKEN` |
| `settings.headerTimeout` | `API_TIMEOUT_MS` |
| `settings.chunkTimeout` | `CLAUDE_STREAM_IDLE_TIMEOUT_MS` |
| `settings.configDir` | `CLAUDE_CONFIG_DIR` |
| `headers` | `ANTHROPIC_CUSTOM_HEADERS` |
| `body` | `CLAUDE_CODE_EXTRA_BODY` |

모델에 설정하면 해당 모델에서 제공자의 값을 재정의합니다.

## 두 번째 Claude 계정 사용

두 번째 계정은 별도 폴더에서 로그인합니다. 기존 로그인은 그대로 유지됩니다.

```bash
CLAUDE_CONFIG_DIR="$HOME/.claude-2" claude auth login
```

PowerShell에서는 다음과 같습니다.

```powershell
$env:CLAUDE_CONFIG_DIR = "$HOME\.claude-2"; claude auth login
```

그다음 해당 폴더를 사용하는 모델을 추가합니다.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "providers": {
    "claude-agent": {
      "models": {
        "sonnet-2": {
          "modelID": "sonnet",
          "name": "Sonnet (Claude 2)",
          "settings": { "configDir": "~/.claude-2" },
        },
      },
    },
  },
}
```

프로젝트의 모든 모델에 하나의 계정을 사용하려면 대신 해당 프로젝트 구성의 제공자에 `settings.configDir`을
설정하세요.

## 계정 순환

서로 바꿔 쓸 수 있는 계정이 여러 개라면, 한 계정이 사용 한도에 도달했을 때 OpenCode가 다음 계정으로 넘어가게 할 수
있습니다. 추가 계정은 각자 별도 폴더에서 로그인하세요. `~/.claude`의 기존 로그인은 그대로 두어도 됩니다.

```bash
CLAUDE_CONFIG_DIR="$HOME/.claude-1" claude auth login
```

그다음 폴더를 나열합니다.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "providers": {
    "claude-agent": {
      "settings": { "configDir": ["~/.claude", "~/.claude-1"] },
    },
  },
}
```

기존 대화에서는 그 대화에 마지막으로 응답한 계정을 계속 사용합니다. 새 대화는 가장 최근에 정상적으로 응답한 계정으로 시작합니다. 순환은 Claude 구독
로그인에만 적용되며 `apiKey`나 `authToken`에는 적용되지 않습니다.

## 웹 검색

Claude Agent는 Claude Code의 WebSearch로 OpenCode의 웹 검색을 처리할 수도 있어, 검색 API 키 없이 Claude 요금제로
검색합니다. 모든 모델이 이를 사용할 수 있습니다. `opencode.jsonc`에서 선택하세요.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "websearch": {
    "provider": "claude-agent",
  },
}
```

자세한 내용은 [웹 검색](/websearch#claude-agent)을 참고하세요.

## 제한 사항

- Claude Code는 OpenCode 서버와 같은 머신에 설치되어 있어야 합니다. Claude Agent는 원격 워크스페이스에서 사용할 수
  없습니다.
- Claude Code의 시스템 프롬프트가 OpenCode의 내장 프롬프트를 대체합니다. 커스텀 에이전트 프롬프트는 계속 적용됩니다.
- temperature, top-p, top-k, seed, stop 시퀀스는 지원하지 않습니다.
- API 호출을 Claude Code가 하므로 플러그인의 `http.request`와 `http.response` 훅은 실행되지 않습니다.
- `/usage`, `/loop`, 자동 모드, 에이전트 팀 같은 Claude Code 기능은 사용할 수 없습니다.

## 오류

| 오류 또는 증상 | 확인할 사항 |
| --- | --- |
| `Claude Code is not installed` | Claude Code를 설치하거나 `OPENCODE_CLAUDE_PATH`를 해당 경로로 설정하세요. |
| `Claude Code is not logged in` | `claude auth login`을 실행한 뒤 Claude Agent를 다시 연결하세요. `configDir`을 사용한다면 오류에 표시된 해당 폴더용 명령을 실행하세요. |
| `Claude Code ... is too old` | `claude update`를 실행하세요. |
