Console은 팀 규모와 관계없이 무료이며 시트 요금이 없습니다. 워크스페이스가 공유하는 선불 크레딧에서 사용한 만큼만
차감됩니다. 소유자와 관리자는 **Settings › Billing**에서 결제를 관리합니다.

[자체 제공자](/console/providers)를 사용한 요금은 Console이 아닌 해당 제공자가 청구합니다.

## 결제 수단 추가

1. **Settings › Billing**을 여세요.
2. **Payment methods**에서 **Add**를 클릭하세요.
3. 결제 수단을 선택하고 Stripe에서 설정을 완료하세요.

지원되는 결제 수단은 다음과 같습니다.

- 카드
- Link
- Alipay
- UPI
- WeChat Pay

자동 청구에 사용할 결제 수단은 **⋯ › Make default**로 선택하세요. 결제 수단을 제거하면 이를 사용하는 자동 충전과 Go
갱신이 중단될 수 있습니다.

## 크레딧 충전

1. **Credits**에서 **Add credits**를 클릭하세요.
2. $10, $50, $100 중 하나를 고르거나 **Other**를 선택해 금액을 입력하세요.
3. 결제 수단을 선택하고 **Confirm and pay**를 클릭하세요.

결제 처리 수수료 4.6% + $0.31이 별도로 붙습니다. $50을 충전하면 $52.61이 결제되며, 잔액에는 $50 전액이
반영됩니다.

## 자동 충전

자동 충전을 설정하면 잔액이 부족할 때 크레딧을 자동으로 구매합니다.

1. **Auto-recharge**에서 **Add rule**을 클릭하세요.
2. 자동 충전이 시작되는 기준 잔액과 충전 금액을 설정하세요.
3. **Save**를 클릭하세요.

자동 충전 시 결제 처리 수수료를 포함한 금액이 기본 결제 수단으로 청구됩니다. 결제에 실패하면 자동 충전이
꺼지며 다시 설정해야 합니다.

## 잔액 확인

소유자와 관리자는 **Activity**의 **Billing** 카드에서 잔액을 확인할 수 있습니다. 카드를 클릭하면 **Settings › Billing**이 열립니다.

워크스페이스 헤더의 **Billing** 버튼이나 `B` 키를 누르면 결제 패널이 열립니다. 이 패널에서 Go 사용 한도, 크레딧,
사용량을 실시간으로 확인할 수 있습니다. 소유자와 관리자는 워크스페이스의 잔액, 사용량, 자동 충전 설정을 볼 수
있으며, 멤버에게는 본인의 사용량과 한도만 표시됩니다.

## 크레딧이 소진되면

잔액이 0이 되면 유료 요청은 HTTP `402`로 실패합니다. 잔액은 음수가 되지 않습니다.

```text
Upstream request failed: Insufficient account funds
```

## 청구서

**Invoices**에는 모든 결제의 상태와 **Download invoice** 또는 **View receipt** 링크가 표시됩니다.

| 항목               | 생성 시점                                  |
| ------------------ | ------------------------------------------ |
| 잔액 충전          | 크레딧 충전 시                             |
| 자동 충전          | 자동 충전 시                               |
| Go 구독            | Go, Go Plus, Go Teams 구독 시              |
| Go 갱신            | 매월 Go 갱신 시                            |
| Go Plus 업그레이드 | Go에서 Go Plus로 업그레이드 시             |
| Go Teams 업그레이드 | Go 또는 Go Plus에서 Go Teams로 업그레이드 시 |
| Go Teams 멤버      | Go Teams 워크스페이스에 멤버가 합류할 때   |
| 월간 사용량        | 월별 청구서 발행 시                        |

## 세금 양식

미국 고객은 [Anomaly Innovations Inc.의 W-9](/assets/anomaly-w9.pdf)를 내려받을 수 있습니다.

## 청구서 결제

신용 거래 계약을 맺은 워크스페이스는 크레딧을 미리 충전하는 대신 월별 청구서로 결제할 수 있습니다. 신청하려면 지원팀에 문의하세요.

- 사용 요금은 선불 잔액이 아닌 신용 한도에서 차감됩니다.
- 청구서는 매월 1일(UTC)에 발행되며 결제 기한은 발행일로부터 14일입니다.
- 미결제 청구서에는 **Pay now** 버튼이 있습니다.
- 신용 한도에 도달하거나 청구서가 연체되면 요청이 HTTP `402`로 실패합니다.

## Go

[OpenCode Go](/console/go) 구독은 같은 결제 수단을 사용하고 같은 청구서 목록에 표시됩니다. [크레딧으로 Go를
결제](/console/go#pay-with-credit)할 수도 있습니다. Go 사용 한도에 도달한 뒤에도 크레딧으로 계속 이용하려면 **Go** 페이지에서
**Extra Usage**를 켜세요.
