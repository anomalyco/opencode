소유자와 관리자는 **Settings › Members**에서 멤버를 관리합니다. 멤버의 페이지를 열면 사용량과 예산 정책을 볼 수 있습니다.

## 멤버 초대

1. **Settings › Members**를 열고 **Invite Members**를 클릭하세요.
2. 이메일 주소를 하나 이상 추가하세요. 공백, 쉼표, 세미콜론으로 구분하거나 목록을 붙여 넣으세요.
3. **Send invitations**를 클릭하세요.

초대받은 사람에게 **Join Acme Inc. on OpenCode**라는 제목의 이메일이 발송됩니다. 이메일에는 **Join workspace** 버튼이 있습니다.

초대는 7일 후 만료됩니다. 모든 사람은 **Member**로 합류하며, 합류한 뒤 [역할을 변경](#change-a-role)할 수 있습니다.

<Callout>
  [OpenCode Go](/console/go)와 Go Plus에서는 초대한 사람이 무료 모델이나 워크스페이스 잔액을 사용합니다. 모든
  사람에게 개별 Go 한도를 제공하려면 Go Teams(멤버당 월 $20, 최소 2명)로 업그레이드하세요. 세 번째부터는 각 멤버가
  합류한 시점부터 멤버당 월 $20이 청구됩니다.
</Callout>

멤버는 자동으로 합류할 수도 있습니다.

- [SSO](/console/sso#automatic-membership)는 확인된 이메일 도메인의 사람을 처음 로그인할 때 추가합니다.
- [디렉터리 동기화](/console/scim)는 ID 공급자에서 할당한 대로 사람을 추가하고 제거합니다.

## 초대 수락

초대받은 사람은 초대를 받은 이메일 주소로 로그인해야 합니다. 수락 방법은 두 가지입니다.

- 초대 이메일에서 **Join workspace**를 클릭한 뒤 로그인하거나 계정을 만듭니다.
- Console에 로그인해 워크스페이스 메뉴를 열고 **Pending invitations** 아래의 **Join**을 클릭합니다.

다른 계정으로 로그인한 상태라면 Console에서 **Sign out and continue**를 선택해 초대받은 이메일 주소로 계속하라는 안내가 표시됩니다.

## 대기 중인 초대 관리

대기 중인 초대는 멤버 표에 **Pending · Expires**와 날짜, 또는 **Expired**로 표시됩니다.

| 작업       | 방법                                                                                      |
| ---------- | ----------------------------------------------------------------------------------------- |
| 다시 보내기 | **⋯ › Resend invitation**. 7일 동안 유효한 새 링크를 보내며 기존 링크는 동작하지 않습니다. |
| 취소       | **⋯ › Remove...**. 링크가 즉시 동작을 멈춥니다.                                           |

## 역할 변경

멤버 행의 역할 메뉴를 열고 **Member**, **Admin**, **Owner** 중 하나를 고르세요.

자신의 역할보다 높은 역할은 부여할 수 없고, 워크스페이스에는 항상 소유자가 한 명 이상 있어야 합니다.
[역할](/console/workspaces#roles)을 참고하세요.

## 멤버 제거

1. 멤버 행에서 **⋯ › Remove...**를 클릭하세요.
2. **Remove member**를 클릭해 제거를 확정하세요.

접근 권한은 즉시 회수되며 나중에 다시 초대할 수 있습니다. 이전 사용량은 워크스페이스 보고서에 남습니다.

멤버를 제거하면 그 사람이 워크스페이스에서 만든 API 키(서비스 계정 키 포함)도 폐기됩니다. 서비스 계정 자체는 남고,
다른 사람이 만든 키는 계속 동작합니다. [폐기](/console/api#revocation)를 참고하세요.

## 멤버 세부 정보

멤버를 클릭하면 월 예산, 사용하는 모델과 클라이언트, 사용량 차트, 요청 로그를 볼 수 있습니다. 여기에서
[예산](/console/budgets#member-budgets)을 설정하고 사용량을 CSV로 내보낼 수 있습니다.
