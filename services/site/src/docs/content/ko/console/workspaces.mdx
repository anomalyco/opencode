[Console](https://opencode.ai/console)의 멤버, 크레딧, 예산, 제공자, 정책, 서비스 계정은 모두 워크스페이스 단위로
관리합니다. 사용량과 결제 내역도 워크스페이스별로 집계됩니다.

워크스페이스에는 멤버가 한 명만 있어도 됩니다. 혼자서 크레딧, [자체 제공자](/console/providers), 예산,
[Go](/console/go)를 사용하고, 필요할 때만 [멤버를 초대](/console/members)할 수 있습니다.

## 첫 워크스페이스

가입하면 Console이 **Personal**이라는 워크스페이스를 만들고, 본인이 소유자이자 유일한 멤버가 됩니다. 초대를 통해
가입하면 초대한 워크스페이스에 합류하며 Personal 워크스페이스는 만들어지지 않습니다.

## 워크스페이스 만들기

1. 상단 바의 워크스페이스 메뉴를 여세요.
2. **Create Workspace**를 클릭하세요.
3. **Workspace name**을 입력하고 **Create**를 클릭하세요.

새 워크스페이스의 소유자가 됩니다.

## 워크스페이스 전환

워크스페이스 메뉴에서 다른 워크스페이스를 선택하세요. Console은 전환한 워크스페이스의 동일한 페이지를 열므로
`/acme/settings/members`에서 전환하면 다른 워크스페이스의 멤버 페이지가 열립니다.

대기 중인 초대는 같은 메뉴 상단에 표시됩니다. [멤버](/console/members#accept-an-invitation)를 참고하세요.

## OpenCode 연결

OpenCode에서 `/connect`를 실행하고 브라우저에서 워크스페이스를 선택하세요. 그러면 OpenCode가 해당 워크스페이스의
모델, 정책, 예산을 사용합니다.

```text
/connect
```

`/connect`를 다시 실행하면 OpenCode를 다른 워크스페이스로 전환합니다. 워크스페이스 [정책](/policies#console)은
새 워크스페이스의 것으로 교체되고, 연결을 해제하면 지워집니다.

## 역할

모든 멤버는 역할을 하나 가집니다. 새 멤버는 항상 **Member**로 합류합니다.

| 역할   | 할 수 있는 일                                                                                                        |
| ------ | -------------------------------------------------------------------------------------------------------------------- |
| Member | OpenCode를 사용하고 자신의 사용량, 로그, 예산을 봅니다.                                                              |
| Admin  | 멤버가 할 수 있는 모든 것에 더해 멤버, 결제, 예산, 제공자, 정책, 서비스 계정, 설정을 관리합니다.                      |
| Owner  | 관리자가 할 수 있는 모든 것에 더해 SSO와 디렉터리 동기화를 관리하고, Owner 역할을 부여하고, 워크스페이스를 삭제합니다. |

멤버는 **Activity**에서 자신의 사용량과 로그를 보고, 멤버에게 공개된 경우 리더보드도 봅니다.
워크스페이스에 [Go Teams](/console/go) 구독이 있으면 자신의 한도가 있는 **Go**도 볼 수 있습니다.
**Account**는 계정 메뉴에서 엽니다.

### 역할 규칙

- 워크스페이스에는 여러 소유자가 있을 수 있으며 항상 최소 한 명이 유지됩니다.
- 자신의 역할보다 높은 역할은 부여할 수 없으므로 소유자만 다른 사람을 소유자로 만들 수 있습니다.
- 자신의 역할은 변경할 수 없습니다.

### 소유권 이전

1. 소유자 계정으로 **Settings › Members**를 열고 새 소유자의 역할을 **Owner**로 설정하세요.
2. 새 소유자에게 자신의 역할을 **Admin** 또는 **Member**로 변경해 달라고 요청하세요.

## 워크스페이스 삭제

소유자만 워크스페이스를 삭제할 수 있으며, 다른 워크스페이스에 하나 이상 속해 있어야 합니다.

1. **Settings › General**을 열고 **Delete workspace**를 클릭하세요.
2. 모든 확인란을 선택하세요.
3. **Delete workspace**를 클릭해 삭제를 확정하세요.

삭제는 즉시 이루어지며 되돌릴 수 없습니다.

- 멤버는 즉시 접근 권한을 잃습니다.
- 모든 서비스 계정 API 키가 폐기되며 대기 중인 초대는 취소됩니다.
- 자동 충전이 중지됩니다.
- 활성 Go 구독이 종료됩니다.
- 남은 크레딧 잔액은 소멸됩니다.

<Callout type="warning">결제가 처리 중인 동안에는 삭제가 차단됩니다. 몇 분 후에 다시 시도하세요.</Callout>

## 워크스페이스 떠나기

1. 계정 메뉴에서 **Account**를 여세요.
2. **Connected workspaces**에서 해당 워크스페이스 옆의 **Leave**를 클릭하세요.
3. **Leave workspace**를 클릭해 나가기를 확정하세요.

마지막 소유자는 떠날 수 없으므로 먼저 다른 멤버를 소유자로 만드세요. SSO나 디렉터리 동기화를 사용하는
워크스페이스에서는 ID 공급자가 멤버십을 관리하므로 Console에서 떠날 수 없습니다. 떠난 뒤 다시 합류하려면 새 초대를
요청하세요.
