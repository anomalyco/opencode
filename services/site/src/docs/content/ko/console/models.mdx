OpenCode Console은 OpenCode 팀이 테스트하고 검증한 모델 목록을 제공합니다. 로그인하고 크레딧을 충전한 뒤 API 키를
발급받으면 OpenCode나 다른 코딩 에이전트에서 사용할 수 있습니다.

Console은 OpenCode의 다른 제공자와 똑같이 동작합니다. **완전히 선택 사항**이며 다른 제공자를 대신 사용해도 됩니다.
사용량이 포함된 구독은 [OpenCode Go](/console/go)를 참고하세요.

## 작동 방식

1. [Console](https://opencode.ai/console)에 로그인하세요. 결제 정보를 등록하고 크레딧을 충전한 뒤 API 키를 복사하세요.
2. TUI에서 `/connect`를 실행하고 OpenCode 종량제 제공자를 선택한 다음 API 키를 붙여 넣으세요.

   ```text
   /connect
   ```

3. `/models`를 실행해 사용 가능한 모델을 확인하고 하나를 선택하세요.

   ```text
   /models
   ```

요청당 요금이 청구되며 계정에 크레딧을 충전할 수 있습니다.

## 엔드포인트

다음 API 엔드포인트로 모델에 직접 접근할 수도 있습니다. 무료 등급 채팅 모델은 OpenCode가 필요하며, 다른
클라이언트에서는 유료 모델이나 [Go](/console/go)를 사용하세요.

각 모델은 자체 API와 함께 표시되지만, 모든 텍스트 모델은 Console이 변환하는 다른 API로도 동작합니다. 전체

### 모델 목록

모델 엔드포인트에서 사용 가능한 모델의 전체 목록과 메타데이터를 가져오세요.

```bash
curl https://opencode.ai/inference/v1/models
```

응답의 모든 필드와 워크스페이스가 연결한 제공자까지 포함하는 Console 목록은 [모델 목록
API](/console/api/models)를 참고하세요.

### Jev

Jev는 빠르게 구조화된 결정을 내리는 TypeSafe AI의 System One 모델입니다. 텍스트를 생성하는 대신 유형이 지정된 질문에 따라 `state`를 평가하고, 코드에서 바로 쓸 수 있는 값과 확률을 반환합니다. 예/아니요(`noul`), 객관식(`choice`), 평가 기준에 따른 점수(`score`) 질문을 지원합니다.

OpenCode Console API 키를 `https://opencode.ai/inference/systemone/v1/systemone` 엔드포인트에 사용하세요. 다음 예제는 지원 요청이 긴급한지 확인합니다.

```bash
curl https://opencode.ai/inference/systemone/v1/systemone \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jev-1.14",
    "state": "My payments have failed for three days and I am losing sales. Please help now.",
    "questions": {
      "is_urgent": {
        "type": "noul",
        "instructions": "Does this request require urgent attention?"
      }
    }
  }'
```

한 요청에서 여러 질문을 할 수 있습니다. Jev는 이를 병렬로 평가하고 일치하는 질문 ID 아래에 각 답변을 반환합니다.

```bash
curl https://opencode.ai/inference/systemone/v1/systemone \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jev-1.14",
    "state": "My order arrived late and the item is damaged. I want a refund.",
    "questions": {
      "department": {
        "type": "choice",
        "instructions": "Which team should handle this request?",
        "criteria": {
          "returns": "Refunds, exchanges, or damaged items",
          "shipping": "Delivery delays or lost packages",
          "billing": "Charges, invoices, or payment problems"
        }
      },
      "frustration": {
        "type": "score",
        "instructions": "How frustrated is the customer?",
        "criteria": ["Calm", "Frustrated", "Very angry"]
      }
    }
  }'
```

기간 한정 무료 모델인 `jev-1.13-free`를 사용하면 Jev 1.13이 실행됩니다. 질문 유형과 응답 필드에 대한 자세한 내용은 [TypeSafe AI 문서](https://docs.typesafe.ai/)를 참고하세요.

### GPT 6 Luna Decision 및 Gemini Decision 1

### 이미지 모델

`gpt-image-2.5-sunburst`, `gemini-nano-banana-2.1`, `grok-imagine-image-2.0`은 이미지를 생성하고 편집합니다.
채팅 모델이 아니므로 `/models`나 모델 엔드포인트에 절대 나타나지 않고, `opencode/<model-id>`로도 선택할 수
없습니다. Console 키로 자체 API에서 호출하거나, OpenCode의 [`generate_image`](/tools#image-generate) 도구가
이미지 모델을 사용하게 하려면 `experimental.image_generate.model`을 설정하세요. 예를 들어
`opencode/gpt-image-2.5-sunburst`입니다.

```bash
curl https://opencode.ai/inference/openai/v1/images/generations \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2.5-sunburst",
    "prompt": "A mountain at sunrise",
    "size": "1024x1024"
  }'
```

Google은 자체 `contents`와 `generationConfig`를, xAI는 `resolution`, `quality` 같은 자체 옵션을 받습니다.
OpenAI Images와 xAI Images는 `/images/edits`에서 편집 요청도 받습니다.

### 임베딩 모델

`text-embedding-3-small`, `qwen3-embedding-8b`와 위 표의 다른 임베딩 모델은 텍스트를 벡터로 바꿉니다.
OpenCode는 채팅에 이들을 쓰지 않으므로 `/models`에 표시되지 않고, 무료 등급에도 포함되지 않습니다.
[Go](/console/go#embedding-models)에는 일부가 포함됩니다. Console 키로 OpenAI의 Embeddings API에서 호출하세요.

```bash
curl https://opencode.ai/inference/openai/v1/embeddings \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "text-embedding-3-small",
    "input": ["hello world", "goodbye"]
  }'
```

- `input`은 문자열 또는 문자열 배열을 받습니다. `data`는 입력마다 하나의 벡터를 같은 순서로 반환합니다.
- `dimensions`는 지원하는 모델에서 벡터를 줄입니다(예: `text-embedding-3-small`).
- `encoding_format: "base64"`는 벡터를 부동소수 대신 base64로 인코딩해 반환합니다.
- 각 입력은 모델의 컨텍스트 윈도에 맞아야 합니다.
- 응답은 다른 추론 요청처럼 `usage.cost`를 보고합니다. [비용](/console/api/inference#cost)을 참고하세요.

서로 다른 모델의 벡터는 비교할 수 없으므로 문서와 쿼리를 같은 모델로 임베딩하세요. [연결한
제공자](/console/api/providers#endpoints)는 `/embeddings`에서 자체 임베딩 모델을 제공합니다.

## 배경

사용 가능한 모델은 많지만 코딩 에이전트로 잘 동작하는 모델은 소수입니다. 제공자마다 구성, 성능, 품질도
다르므로 OpenRouter 같은 게이트웨이를 통해 접근한 모델은 다르게 동작할 수 있습니다.

<Callout type="tip">OpenCode와 잘 동작하는 엄선된 모델과 제공자를 테스트했습니다.</Callout>

이 카탈로그를 만들기 위해 다음을 했습니다.

1. 엄선된 모델 그룹을 테스트하고 각 팀과 최적의 실행 방법을 논의했습니다.
2. 제공자와 협력해 모델이 올바르게 제공되는지 확인했습니다.
3. 각 모델-제공자 조합을 벤치마크해 자신 있게 추천할 수 있는 목록을 만들었습니다.

Console은 이 모델에 접근할 수 있게 해 주는 AI 게이트웨이입니다.

## 목표

Console은 다음을 위해 만들었습니다.

1. 코딩 에이전트에 가장 좋은 모델과 제공자를 **벤치마크**합니다.
2. 성능을 낮추거나 더 저렴한 제공자로 라우팅하지 않고 **최고 품질**의 옵션을 제공합니다.
3. 원가에 결제 처리 수수료만 더해 제공하므로 **가격 인하** 혜택을 그대로 돌려드립니다.
4. **특정 서비스에 종속되지 않습니다.** Console은 어떤 코딩 에이전트와도 쓸 수 있고, OpenCode에서는 다른 제공자도 사용할 수 있습니다.
