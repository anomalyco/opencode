---
title: "예산"
description: "워크스페이스, 멤버, 서비스 계정의 월 지출을 제한하세요."
---

예산은 정책으로 월 지출을 제한합니다. 소유자와 관리자는 **Controls**에서 관리합니다.

## 예산 수준

| 정책 대상             | 적용 범위                                            |
| --------------------- | ---------------------------------------------------- |
| 전체 워크스페이스     | 모든 멤버와 서비스 계정의 합산 지출                  |
| 모든 멤버             | 멤버별 지출 한도 또는 모든 멤버가 공유하는 지출 한도 |
| 태그가 지정된 멤버    | 선택한 태그가 있는 멤버                              |
| 특정 멤버             | 지정한 멤버                                          |
| 모든 서비스 계정      | 서비스 계정별 지출 한도 또는 공유 지출 한도          |
| 특정 서비스 계정      | 지정한 서비스 계정                                   |

요청은 적용되는 모든 예산 한도를 충족해야 합니다. 예산이 더 큰 정책이 적용되더라도 더 작은 한도는 그대로 적용됩니다. 예산이 없으면
지출에 제한이 없습니다.

## 워크스페이스 예산

워크스페이스 예산에 도달하면 모든 사용자의 요청이 차단됩니다.

1. **Controls**를 열고 **Add policy**를 클릭하세요.
2. **Entire workspace**를 선택하고 **Budget** 규칙을 추가하세요.
3. 월 한도를 USD로 입력하고 **Save**를 클릭하세요.

## 멤버 예산

정책에서 **All members**를 선택하면 멤버별로 월 지출 한도를 설정하거나 모든 멤버에게 공유 한도 하나를 적용할 수
있습니다. 일부 멤버에게만 적용하려면 멤버나 태그를 지정하세요.

한 사람의 예산을 설정하려면 다음과 같이 합니다.

1. **Settings › Members**에서 해당 멤버의 페이지를 여세요.
2. **Create budget policy**를 클릭하세요. 해당 멤버가 선택된 상태로 정책 편집 화면이 열립니다.
3. 금액을 입력하고 **Save**를 클릭하세요.

멤버 페이지에 적용되는 정책이 나열됩니다. 모든 멤버 예산도 해당 멤버를 포함하면 두 한도가 모두 적용됩니다.

## 서비스 계정 예산

**Controls**에서 **All service accounts** 또는 **These service accounts**를 선택하고 **Budget** 규칙을 추가한 뒤
계정별 또는 공유 월 지출 한도를 설정하세요. 정책은 해당 계정의 모든 키에 적용됩니다.

## 금액과 초기화

- 금액은 소수점 아래 두 자리까지의 미국 달러입니다.
- 예산은 매월 1일 00:00 UTC에 초기화됩니다.
- `$0` 예산은 예산에 반영되는 모든 지출을 차단합니다.
- 예산을 추가하거나 변경해도 이번 달에 이미 기록된 지출은 계속 예산에 반영됩니다. 남은 한도가 초기화되지는 않습니다.

## 반영되는 지출

기본적으로 예산은 **All spend**를 대상으로 합니다. 선택한 모델로 범위를 좁힐 수 있으며, 그러면 해당 모델만
예산에 반영됩니다. 선택한 모델에 공유 한도를 적용하거나 모델마다 별도의 한도를 설정할 수 있습니다.

| 지출                                                        | 예산 반영                    |
| ----------------------------------------------------------- | ---------------------------- |
| 유료 Console 모델                                           | 예                           |
| 가격이 설정된 [자체 제공자](/console/providers)의 모델      | 예, 설정된 가격 기준         |
| [웹 검색](/console/websearch)                               | 예, 전체 지출 예산에 반영    |
| 무료 모델                                                   | 아니요                       |
| 요금제 내 [Go](/console/go) 사용량                          | 아니요                       |
| 크레딧으로 결제한 Go 추가 사용량                            | 예                           |

## 예산에 도달하면

예산이 초기화되거나 소유자나 관리자가 예산을 올릴 때까지 새 요청은 HTTP `429`로 실패합니다. 응답은 정책 예산
실패임을 알려 주지만 어느 예산인지는 밝히지 않습니다. **Activity › Logs**에서 해당 요청을 열면 차단한 정책을
확인할 수 있습니다.

```text
Upstream request failed: Policy budget exceeded
```

예산은 요청이 시작될 때 확인합니다. 이미 진행 중인 요청은 끝까지 처리되므로 지출이 한도를 약간 넘을 수 있습니다.

## 지출 추적

각 멤버는 **Activity**에서 자신의 지출과 한도를 봅니다. **My usage**를 열면 예산 세부 정보와 초기화 날짜를 포함한
**Activity › Overview**로 이동합니다.

소유자와 관리자는 지출 차트에서 **Activity › Usage**를 열 수 있습니다. 날짜, 모델, 사용자별 비용을 보여 주며,
**Export usage** 버튼으로 최근 7일, 30일, 90일의 일별 합계를 CSV로 내려받습니다. 스크립트에서 같은 파일을
받으려면 [사용량 내보내기 API](/console/api/usage-export)를 사용하세요.
