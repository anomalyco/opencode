description: "cli.json에서 OpenCode CLI 키바인드를 커스터마이즈하고 각 명령어의 ID와 기본 바인딩을 확인하세요."
---

`cli.json`에서 바인딩을 커스터마이즈하세요.

```json title="cli.json"
{
  "keybinds": {
    "leader": "ctrl+space",
    "command.palette.show": "ctrl+k",
    "app.exit": ["ctrl+c", "ctrl+d"],
    "app.debug": false
  },
  "leader": {
    "timeout": 1500
  }
}
```

키 하나에는 문자열을 사용하세요.

```json
{
  "keybinds": {
    "command.palette.show": "ctrl+k"
  }
}
```

대안은 쉼표로 구분하세요.

```json
{
  "keybinds": {
    "app.exit": "ctrl+c,ctrl+d"
  }
}
```

바인딩은 `"none"`이나 `false`로 비활성화하세요.

```json
{
  "keybinds": {
    "app.debug": "none",
    "help.show": false
  }
}
```

이벤트 동작에는 객체를 사용하세요.

```json
{
  "keybinds": {
    "prompt.paste": {
      "key": "ctrl+v",
      "preventDefault": false
    }
  }
}
```

`leader`의 기본값은 `ctrl+x`입니다. 다른 바인딩의 `<leader>`는 그 키를 가리킵니다.

```json
{
  "keybinds": {
    "leader": "ctrl+space",
    "model.list": "<leader>m"
  },
  "leader": {
    "timeout": 2000
  }
}
```

알 수 없는 명령 ID는 무시됩니다.

## Mini

`app.clear` 명령은 [`opencode mini`](/cli)에서만 동작합니다. `ctrl+l`을 누르면 화면을 지우고 프롬프트를 다시 그립니다. 스크롤백은 터미널에 남습니다.

```json title="cli.json"
{
  "keybinds": {
    "app.clear": "ctrl+l"
  }
}
```

| ID          | 기본값  | 설명      |
| ----------- | -------- | ---------------- |
| `app.clear` | `ctrl+l` | 화면 지우기 |

## Diff 뷰어

`d`(`diff.switch_source`)를 눌러 **All**, **Committed**, **Uncommitted**, **Last turn**(세션 안)을 고르거나 **Base**를 선택해 비교 브랜치를 바꾸세요. 선택은 TUI를 종료할 때까지 기억됩니다. 초기 범위는 [`diffs.source` 설정(`cli.json`)](/cli/config#diffs)으로 지정하세요.

스크롤, 페이징, 시작/끝 단축키는 항상 diff를 제어합니다. 키보드 포커스 전환은 없으며, 파일을 클릭해 열고 폴더를 클릭해 펼치거나 접고 마우스 휠로 파일 트리를 스크롤하세요.

`n` / `p` 또는 `alt+down` / `alt+up`(macOS에서는 Option)으로 파일 사이를 이동하세요. diff 뷰어 안에서는 Alt 단축키가 세션 탭이 아니라 파일을 이동합니다.

`m`을 누르면 파일을 리뷰 완료로 표시하고 패치 본문을 접습니다. 전체 파일 보기에서 `m`을 다시 누르면 표시를 해제하고 패치를 다시 엽니다. 단일 파일 보기에서는 리뷰 완료로 표시하면 자동으로 다음 파일로 넘어가지만 마지막 파일에서는 순환하지 않고 머뭅니다. 표시 해제는 절대 이동하지 않습니다.

사이드바의 파일이나 diff 제목을 마우스 오른쪽 버튼으로 클릭하고 **Mark complete**(또는 **Mark incomplete**)를 선택하세요. 이는 `m`과 같은 리뷰 상태를 바꿉니다. 다른 파일을 그 메뉴에서 완료해도 그 파일이 선택되거나 현재 읽는 파일이 넘어가지 않습니다.
