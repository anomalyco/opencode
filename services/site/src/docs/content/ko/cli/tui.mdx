프로젝트에서 OpenCode를 실행하고 요청을 입력한 뒤 **Enter**를 누르세요.

```bash
cd ~/code/my-project
opencode
```

```text
Explain how authentication works in this project
```

새 줄을 입력하려면 **Shift+Enter**, **Ctrl+Enter**, **Alt+Enter**, **Ctrl+J** 중 하나를 누르세요. OpenCode가 작업하는 동안 **Enter**를 누르면 진행 중인 작업의 방향을 조정하는 프롬프트를 보냅니다. **Ctrl+X**를 누른 뒤 **Enter**를 누르면 프롬프트를 나중에 처리하도록 대기열에 넣습니다.

## 컨텍스트

`@`를 입력해 파일을 검색한 다음 선택하면 해당 파일이 프롬프트에 첨부됩니다. `@` 뒤에 계속 입력하면 결과를 좁힐 수 있습니다.

```text
Review @src/auth.ts for error handling problems
```

경로 뒤에 줄 번호나 범위를 붙일 수 있습니다.

```text
Explain @src/auth.ts#20-45
```

## 셸

빈 프롬프트 처음에 `!`를 입력하면 셸 모드로 들어갑니다. 명령을 입력하고 **Enter**를 누르세요. 명령어를 실행하지 않고 셸 모드를 종료하려면 **Esc**를 누르세요.

```text
!git status
```

셸 명령은 세션의 작업 디렉터리에서 실행되며, 출력은 세션에 남습니다.

## 명령어

`/`를 입력하면 슬래시 명령어 목록이 표시됩니다. 계속 입력해 목록을 걸러 낸 뒤 **Enter**를 눌러 선택한 명령어를 실행하세요.

```text
/models
```

자주 쓰는 명령어로 `/new`, `/sessions`, `/models`, `/agents`, `/undo`, `/redo`, `/editor`가 있습니다. **Ctrl+P**를 누르면 현재 화면에서 사용할 수 있는 모든 작업이 담긴 명령어 팔레트가 열립니다.

업데이트 후 OpenCode는 홈 화면에서 새 버전의 변경 사항을 한 번 보여 줍니다. 다시 보려면 `/highlights`를 실행하고, 자동으로 열리지 않게 하려면 `"highlights": false`를 [`cli.json`](/cli/config#alerts)에 설정하세요.

## 곁가지 질문

`/btw <question>`을 실행하면 지금까지의 대화에 대해 짧은 질문을 할 수 있습니다. 답변은 세션의 컨텍스트와 현재 모델을 사용하지만 대화에 추가되지 않으므로 이후 프롬프트에 영향을 주지 않습니다. 실행 중에는 입력창 하단에 `/btw` 표시가 나타나고, 답변은 대화 상자로 열립니다. **C**를 누르면 답변을 복사합니다.

```text
/btw why did the test in step 2 fail?
```

## 모델

모델을 고르려면 **Ctrl+X**를 누른 뒤 **M**을 누르거나 `/models`를 실행하세요. **F2**를 누르면 최근 사용한 모델을 차례로 전환합니다.

에이전트를 고르려면 **Ctrl+X**를 누른 뒤 **A**를 누르거나 `/agents`를 실행하세요. **Shift+Tab**을 누르면 에이전트를 차례로 전환합니다.

## 세션

새 세션을 시작하려면 **Ctrl+X**를 누른 뒤 **N**을 누르세요. 기존 세션으로 돌아가려면 **Ctrl+X**를 누른 뒤 **L**을 누르거나 `/sessions`를 실행하세요. **Ctrl+O**를 누르면 최근 세션과 프로젝트를 한곳에서 볼 수 있습니다.

탭은 기본으로 활성화되어 있습니다. **Ctrl+Tab**과 **Ctrl+Shift+Tab**으로 탭 사이를 이동하고, **Ctrl+X**를 누른 뒤 **W**를 눌러 탭을 닫고, **Ctrl+Shift+T**로 마지막으로 닫은 탭을 다시 여세요.

## 기록

**Ctrl+X**를 누른 뒤 **U**를 누르거나 `/undo`를 실행하면 마지막 사용자 메시지와 그 뒤에 이어진 작업을 되돌립니다. 되돌린 프롬프트는 입력창으로 돌아오므로 수정할 수 있습니다.

**Ctrl+X**를 누른 뒤 **R**을 누르거나 `/redo`를 실행하면 되돌린 작업을 복원합니다. 대신 새 프롬프트를 보내면 되돌리기를 확정하고 그 지점부터 이어 갑니다.

## 편집기

`VISUAL` 또는 `EDITOR`를 설정한 뒤 **Ctrl+X**를 누르고 **E**를 누르거나 `/editor`를 실행하면 해당 편집기에서 현재 프롬프트를 편집합니다. 저장하고 종료하면 텍스트가 입력창으로 돌아오며, **Enter**를 눌러 전송하세요.

```bash
export EDITOR="nvim"
opencode
```

리더 키는 기본적으로 **Ctrl+X**입니다. 단축키를 바꾸려면 [키바인드](/cli/keybinds)를 참고하세요.
