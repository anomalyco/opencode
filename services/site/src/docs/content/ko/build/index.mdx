매일 수백만 명이 OpenCode를 사용합니다. OpenCode를 기반으로 자체 애플리케이션, 통합 기능, 에이전트 사용 환경을
개발하면 처음부터 만들 필요가 없습니다.

[플러그인](/build/plugins/effect), [클라이언트](/build/client/effect), [내장 앱](/build/sdk/effect)용 Effect API도
제공합니다.
