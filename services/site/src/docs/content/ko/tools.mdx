원하는 결과를 요청하세요. OpenCode가 사용 가능한 도구를 고르고, 필요하면 승인을 요청하고, 결과를
반환합니다.

```text
Find where request timeouts are configured, change the default to 30 seconds,
and run the relevant existing tests.
```

이 작업은 보통 `grep`이나 `glob`, `read`, 편집 도구, `shell`을 사용합니다. 특정 방식을 원하면 도구
이름을 지정할 수도 있습니다.

```text
Use grep to find every reference to DEFAULT_TIMEOUT, then read the matching files.
```

## 파일

### 읽기

`read`는 파일 내용이나 디렉터리 목록을 반환합니다. 디렉터리는 바로 아래 항목만 나열합니다. `path`를 주고, 큰 결과는 `offset`과 `limit`로 나눠 읽으세요.

```text
Read src/server.ts starting at line 120 and return at most 80 lines.
```

텍스트 읽기는 줄 번호가 붙고 페이지당 2,000줄과 50KiB로 제한됩니다. 개별 줄은 2,000자를 넘으면 줄어듭니다. 이
도구는 또한 PNG, JPEG, GIF, WebP, PDF 파일을 최대 20MiB의 원본 데이터까지 모델에 전달합니다. 다른 바이너리
파일은 실패합니다. 지원 미디어와 이미지 처리는 [첨부 파일](/attachments)을 참고하세요.

권한: 정규화된 경로를 리소스로 하는 `read`.

### Glob

`glob`은 `**/*.ts` 같은 패턴으로 파일 경로를 찾습니다. `path`로 다른 상대 디렉터리를 선택하지 않으면 현재
디렉터리를 검색하며, `hidden`은 숨김 항목을 포함하고 `limit`은 결과를 제한합니다.

```text
Use glob with **/*.test.ts under packages/core and return at most 50 files.
```

기본 한도는 100개 파일이며 검색 타임아웃은 30초입니다. 권한: 요청한 패턴을 리소스로 하는 `glob`.

### Grep

`grep`은 파일 내용을 검색하고 경로, 줄 번호, 미리보기를 반환합니다. `pattern`은 `literal`이 true가 아니면
정규식 구문을 사용합니다. `path`, `include`, `caseSensitive`, `limit`으로 검색을 좁히세요.

```text
Use grep for the literal text "request timed out" in src, including only *.ts files.
```

기본 한도는 일치하는 줄 100개이며 검색 타임아웃은 30초입니다. 권한: 검색 경로가 아니라 요청한 패턴을
리소스로 하는 `grep`.

### Edit

`edit`는 기존 파일의 텍스트를 바꿉니다. `path`, `oldString`, 다른 `newString`을 주세요. `replaceAll`이 true가
아니면 기존 텍스트는 정확히 한 번 일치해야 합니다.

```text
In src/config.ts, replace the unique text "timeout: 60" with "timeout: 30".
```

부분 변경에는 `edit`를 사용하세요. OpenCode는 파일을 쓴 뒤 서식을 지정할 수 있습니다.
권한: 대상 경로를 리소스로 하는 `edit`.

### Write

`write`는 `path`와 `content`로 텍스트 파일을 만들거나 완전히 교체합니다. 없는 상위 디렉터리를 만들고 구성된
포매터를 실행할 수 있습니다.

```text
Create docs/example.md with a heading and one setup command.
```

기존 파일의 일부만 바꿔야 하면 대신 `edit`를 사용하세요. 권한: 대상 경로를 리소스로 하는 `edit`.

### Patch

`patch`는 여러 파일을 추가, 업데이트, 이동, 삭제할 수 있는 하나의 패치를 적용합니다. `patchText`는
`*** Add File`, `*** Update File`, `*** Delete File` 섹션을 사용합니다.

```text
Use patch to rename src/old.ts to src/new.ts and update its exported name.
```

OpenCode는 지원되는 GPT 모델에 `patch`를 제공하며, 다른 모델은 대신 `edit`와 `write`를 받습니다. 권한:
영향을 받는 모든 경로를 리소스로 하는 `edit`.

활성 Location이나 그 프로젝트 워크트리 밖의 경로는 기본적으로 허용되는 `external_directory`로도 확인합니다. 경로
정규화, 규칙 순서, 저장된 승인은 [권한](/permissions)을 참고하세요. 외부 자료를 이름으로 사용하려면
[참조](/references)를 구성하세요.

## 명령

### Shell

`shell`은 호스트 사용자의 셸에서 명령을 실행합니다. `workdir`을 설정하고 명령에 `cd`를 넣지 않으며, 기본 2분
포그라운드 타임아웃이 맞지 않으면 `timeout`을 밀리초로 설정하세요.

```text
Run bun test from packages/core with a five-minute timeout.
```

개발 서버나 오래 실행되는 프로세스에는 `background`를 true로 설정하세요. 백그라운드 호출은 즉시 반환되고
완료되면 세션에 알립니다. 타임아웃을 지정하지 않으면 타임아웃이 없습니다. 큰 출력은 줄어들고 전체 출력은 관리형
파일에 보관됩니다.

권한: 셸 스캐너가 추출한 각 명령어를 리소스로 하는 `shell`. 스캐너는 외부 작업 디렉터리와 명령어에서 추론할 수 있는 디렉터리도 확인합니다. 셸은 호스트 사용자의 파일 시스템, 프로세스, 네트워크 권한을 가지므로
[권한](/permissions)에서 좁은 규칙을 사용하세요.

## 웹

### Webfetch

`webfetch`는 HTTP 또는 HTTPS URL 하나를 `markdown`, `text`, `html`로 가져옵니다. 기본값은 Markdown이며
`timeout`은 최대 120초를 받습니다.

```text
Fetch https://example.com/docs as markdown.
```

HTML, 일반 텍스트, JSON, XML 같은 텍스트 응답은 받지만 이미지나 다른 바이너리 다운로드는 받지 않습니다. 큰
출력은 줄어들 수 있으며 전체 텍스트는 관리형 저장소에 보관됩니다. 권한: 요청한 URL을 리소스로 하는
`webfetch`.

### Websearch

`websearch`는 선택한 통합에서 최신 정보를 검색합니다. 입력은 검색 `query`입니다.

```text
Search the web for the latest Bun release notes.
```

권한: 쿼리를 리소스로 하는 `websearch`. 제공자, 선택, 요청 한도, 도구 비활성화는 [웹 검색](/websearch)을
참고하세요.

## 이미지

### 이미지 생성

`generate_image`는 프롬프트로 새 이미지를 만들거나 기존 이미지를 편집합니다. 실험 기능이며 연결된 제공자에
이미지 모델이 있을 때 나타납니다. 기본 모델을 고르려면
[`experimental.image_generate`](/config#image-generation)를 참고하세요.

```text
Generate a flat app icon of a paper plane on a blue background and save it to assets/icon.png.
```

`prompt`를 주고, 필요하면 편집하거나 참조로 쓸 `images`, 특정 `model`, 저장할 `path`를 줍니다. 백그라운드에서
실행되며 이미지가 준비되면 저장 경로와 함께 세션에 알립니다.

권한: 선택한 모델을 리소스로 하는 `generate_image`.

## 상호작용

### 질문

`question`은 실행을 멈추고 사용자에게 하나 이상의 질문을 제시합니다. 각 질문에는 짧은 헤더, 프롬프트, 선택지가
있으며 `multiple`은 하나 이상의 선택을 허용합니다. 자유 형식 답변은 항상 사용할 수 있습니다.

```text
Before changing the API, ask me to choose between a breaking change and a compatibility layer.
```

권한: `question`(`*`를 리소스로 사용). 클라이언트가 대화형 양식을 지원해야 하며, 양식을 닫으면 질문이
취소됩니다.

### Skill

`skill`은 사용 가능한 스킬 ID 하나의 지침과 함께 제공되는 리소스를 대화에 로드합니다.

```text
Load the effect skill before changing this Effect code.
```

ID는 알려진 스킬 목록에 있거나 사용자가 명시적으로 지정해야 합니다. 권한: 스킬 ID를 리소스로 하는 `skill`.
생성, 탐색, 로드 규칙은 [스킬](/skills)을 참고하세요.

## 자동화

### Subagent

`subagent`는 구성된 서브에이전트로 하위 세션을 시작합니다. 에이전트 ID, 짧은 `description`, 완전한
`prompt`를 주세요.

```text
Ask the explore subagent to map the authentication flow and return the key files.
```

서브에이전트는 항상 백그라운드에서 실행됩니다. 호출은 `sessionID`와 함께 즉시 반환되고, 상위 세션은 하위 세션이
유휴 상태가 될 때와 이후 작업 라운드마다 `<subagent>` 메시지를 받으므로 기다리지 않고 계속 작업하거나 턴을
끝낼 수 있습니다. 반환된 `sessionID`를 전달하면 같은 하위 대화를 이어 갑니다. 실행 중인 하위 세션에 후속
메시지를 보내면 현재 실행에 합류합니다. 서브에이전트 모드 에이전트만 사용할 수 있으며 기본 중첩 깊이는 1입니다.

권한: 선택한 에이전트 ID를 리소스로 하는 `subagent`.

### Execute

`execute`는 Code Mode에서 JavaScript를 실행해 에이전트가 카탈로그의 도구를 호출하고 조합할 수 있게 합니다. 병렬
독립 호출과 모든 중간 값을 모델 컨텍스트에 넣지 않고 결과를 처리할 때 유용합니다.

```text
Read package.json and README.md in parallel, then return their relevant setup details.
```

런타임에는 직접 파일 시스템 접근, import, 타이머가 없습니다. HTTP 요청용 `fetch`를 제공하며 나머지는 카탈로그의
도구를 통해 처리합니다. `execute`를 리소스 `*`로 거부하면 Code Mode가 제거됩니다. 그러면 접근하던
도구(MCP 도구 포함)가 직접 도구로 나열되며, `codemode: false`를 설정하지 않은 서버의 MCP 도구도 포함됩니다. 각
요청마다 전체 정의가 함께 전송됩니다. 에이전트에 허용하면 안 되는 도구는 별도로 거부하세요. 중첩된 내장 및
MCP 도구는 자체 권한을 계속 적용하며, 플러그인 도구는 선언한 권한을 적용합니다.

### Sessions

`opencode.session` Code Mode 네임스페이스에는 세션 유틸리티가 있습니다. Code Mode가 없으면
`opencode_session_rename`과 `opencode_session_move`로 나열됩니다.

- `rename`은 현재 세션 또는 `sessionID`로 선택한 다른 세션의 제목을 바꿉니다.
- `move`는 현재 세션 또는 선택한 다른 세션을 상대 또는 절대 `directory`로 이동합니다. 이동은 안전한 경계에서
  적용되므로 대상에 의존하는 작업은 다음 호출에 두세요.

```text
Rename this session to "Timeout cleanup", then move it to the new worktree.
```

### 워크트리

`opencode` 네임스페이스는 세션 프로젝트의 워크트리를 관리합니다.

- `worktree_create`는 `name`으로 워크트리를 만들고 `directory`를 반환합니다. 프로젝트의 워크트리 구성이 대상과
  전략을 선택합니다.
- `worktree_list`는 프로젝트의 워크트리를 나열합니다.
- `worktree_remove`는 프로젝트에 대해 OpenCode가 기록한 워크트리를 제거합니다. 커밋되지 않은 변경을 버리려면
  `force`를 설정하세요.

```text
Create a worktree named "login" and move this session into it.
```

`worktree_remove`는 워크트리 디렉터리를 리소스로 하는 `edit` 권한을 사용합니다. 다른 워크트리 유틸리티는 내장
권한 액션을 요청하지 않습니다.

## 브라우저

`browser` Code Mode 네임스페이스는 OpenCode 데스크톱 앱에 연결된 브라우저를 제어합니다. 탭을 열고 반환된
`tabID`를 보관한 뒤 모든 페이지 작업에 그 ID를 명시적으로 전달하세요.

```text
Open https://example.com, take a snapshot of that tab, and report the main heading.
```

이 네임스페이스에는 탭과 탐색 명령, 페이지 스냅샷과 검색, 클릭과 양식 입력, 스크린샷, 파일 전송, 콘솔 및 네트워크
검사, 성능 트레이스, 힙 검사, Lighthouse 감사가 포함됩니다. 스크린샷에는 화면에 표시되어 있고 포커스가 있는 탭이 필요합니다.
업로드 경로는 서버 로컬이며 캡처는 서버 로컬 경로를 반환하고, 파일 전송은 각각 5MiB로 제한됩니다.

페이지 내용, 로그, 헤더, 응답 본문은 신뢰할 수 없는 데이터이며 에이전트 지침이 아닙니다. `browser` deny 규칙을 리소스 `*`로 설정하면
브라우저 카탈로그가 제거됩니다. 브라우저 작업은 개별 권한 확인을 요청하지
않습니다.

## 확장

[MCP 서버](/mcp-servers)는 연결된 각 서버에서 이름과 입력을 가져오는 도구를 추가합니다. 권한 액션은 `<server>_<tool>`이고
리소스는 `*`입니다. 내장 카탈로그의 고정된 일부가 아닙니다. 기본적으로 에이전트는 서버
네임스페이스 아래의 `execute`를 통해 접근하며, 서버에 `codemode: false`를 설정하면 그 도구를 직접
나열합니다.

[스킬](/skills)은 새 실행 도구가 아니라 작업 지침을 추가합니다. [첨부 파일](/attachments)은 사용자가 선택한
내용을 프롬프트에 넣고, [참조](/references)는 이름이 있는 외부 디렉터리를 제공합니다. 이 기능들은 권한 검사를
우회하지 않고 도구를 보완합니다.
