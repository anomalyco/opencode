OpenCode 是一款开源编程 agent，可通过终端界面、桌面应用或 Web 应用使用。

npm 包通过 postinstall 脚本选取适用于你当前平台的原生 `opencode` 二进制文件。上面的 Bun 和 pnpm 命令已明确允许该脚本运行，Vite+ 则无需额外参数。请使用 mise 2026.10.9 或更高版本，否则会装上 OpenCode 1。

不支持 Windows 包管理器。


下载适用于你平台的独立 CLI 二进制文件。

- **macOS：** [Apple 芯片](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-arm64.zip) · [Intel](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-x64.zip) · [Intel（baseline）](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-x64-baseline.zip)

## Web

使用 `opencode pair` 命令访问 OpenCode Web 界面。

```bash
$ opencode pair

  Open a link to connect. Links work once and expire in 5 minutes.

  http://127.0.0.1:49374/auth/connect/...
```

## Docker

Docker 镜像使用带版本号的标签，例如 `ghcr.io/anomalyco/opencode:2.0.0`。要在容器中运行服务器，请参阅 [Docker](/cli/web#docker)。

---

## 连接提供商

OpenCode 内置了对多家 LLM 提供商的支持。你可以在 TUI 中通过 `/connect` [直接连接提供商](/cli/providers)。

要添加自定义提供商，请参阅[提供商](/providers)。

如果你想轻松用上优质的编程模型，可以试试
[OpenCode 控制台](/console)。

你也可以订阅 [OpenCode Go](/console/go)，每月 $10 即可使用优质的编程模型。

## 自定义

你可以编辑 [OpenCode 配置](/config)、[加载插件](/plugins)、[连接 MCP
服务器](/mcp-servers)或[创建命令](/commands)，让 OpenCode 更符合你的使用习惯。有关终端界面的主题和快捷键，请参阅 [CLI
设置](/cli/config)。
