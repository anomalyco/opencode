无论团队多大，使用控制台都不收席位费。你只需按实际用量付费，费用从工作区共用的预付余额中扣除。所有者和管理员可以在 **Settings › Billing** 中管理账单。

如果使用[你自己的提供商](/console/providers)，相应用量由提供商收费，控制台不会再收费。

## 添加付款方式

1. 打开 **Settings › Billing**。
2. 在 **Payment methods** 下点击 **Add**。
3. 选择一种付款方式，并完成 Stripe 设置。

支持的付款方式：

- 银行卡
- Link
- Alipay
- UPI
- WeChat Pay

通过 **⋯ › Make default** 可以指定自动扣款使用的付款方式。删除某种付款方式后，依赖它的自动充值和 Go 续费可能会中断。

## 充值额度

1. 在 **Credits** 下点击 **Add credits**。
2. 选择 $10、$50 或 $100，或者选择 **Other** 并输入金额。
3. 选择付款方式，然后点击 **Confirm and pay**。

手续费为 4.6% + $0.31，另行收取。比如充值 $50 时，实际扣款 $52.61，余额增加 $50。

## 自动充值

余额低于指定金额时，系统会自动充值。

1. 在 **Auto-recharge** 下点击 **Add rule**。
2. 设置触发扣款的余额阈值和充值金额。
3. 点击 **Save**。

自动充值使用默认付款方式扣款，扣款金额包含手续费。如果扣款失败，自动充值会关闭，需重新设置才能恢复。

## 查看余额

所有者和管理员可以在 **Activity** 的 **Billing** 卡片中查看余额，点击该卡片会打开 **Settings › Billing**。

点击工作区顶部的 **Billing** 按钮或按 `B` 键，即可打开账单面板，查看最新的 Go 限额、额度和用量。所有者和管理员可以查看工作区余额、用量和自动充值设置；成员只能查看自己的用量和限额。

## 额度用完后

余额降到零后，付费请求会失败并返回 HTTP `402`。余额不会变成负数。

```text
Upstream request failed: Insufficient account funds
```

## 发票

每笔付款都会显示在 **Invoices** 中，包含状态以及 **Download invoice** 或 **View receipt** 链接。

| 条目             | 来源                                   |
| ---------------- | -------------------------------------- |
| 余额充值 | 手动充值额度 |
| 自动充值 | 触发自动充值 |
| OpenCode Go 订阅 | 订阅 Go、Go Plus 或 Go Teams |
| OpenCode Go 续费 | Go 每月续费 |
| 升级到 Go Plus | 从 Go 升级到 Go Plus |
| 升级到 Go Teams | 从 Go 或 Go Plus 升级到 Go Teams |
| Go Teams 成员 | 成员加入已开通 Go Teams 的工作区 |
| 月度用量 | 按发票结算 |

## 按发票结算

签订授信协议的工作区可以按月开票结算，无需预先购买额度。如需开通，请联系支持。

- 用量费用占用的是授信额度，而不是预付余额。
- 发票于每月 1 日（UTC）开具，开具后 14 天到期。
- 未支付的发票上会显示 **Pay now** 按钮。
- 达到授信额度上限或发票逾期时，请求会失败并返回 HTTP `402`。

## Go

[OpenCode Go](/console/go) 订阅使用同样的付款方式，相关款项也在同一个发票列表中。你也可以[用额度支付 Go](/console/go#pay-with-credit)。在 **Go** 页面开启 **Extra Usage** 后，超出 Go 限额的用量会从余额中扣费。
