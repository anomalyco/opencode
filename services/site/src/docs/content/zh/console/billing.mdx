无论团队规模大小，控制台都免费，不收席位费。你只需为用量付费，费用从覆盖整个工作区的预付额度中扣除。所有者和管理员在 **Settings › Billing** 中管理账单。

通过[自有提供商](/console/providers)产生的用量由提供商计费，控制台不计费。

## 添加付款方式

1. 打开 **Settings › Billing**。
2. 在 **Payment methods** 下点击 **Add**。
3. 选择一种付款方式，并完成 Stripe 设置。

支持的付款方式：

- 银行卡
- Link
- Alipay
- UPI
- WeChat Pay

通过 **⋯ › Make default** 可以指定自动扣款使用的付款方式。删除某种付款方式后，依赖它的自动充值和 Go 续费可能会中断。

## 充值额度

1. 在 **Credits** 下点击 **Add credits**。
2. 选择 $10、$50 或 $100，或者选择 **Other** 并输入金额。
3. 选择付款方式，然后点击 **Confirm and pay**。

另外会加收 4.6% + $0.31 的手续费，因此购买 $50 实际扣款 $52.61，$50 会全额计入余额。

## 自动充值

自动充值会在余额不足时自动购买额度。

1. 在 **Auto-recharge** 下点击 **Add rule**。
2. 设置触发扣款的余额阈值和充值金额。
3. 点击 **Save**。

自动充值会从默认付款方式扣款，并包含手续费。如果扣款失败，自动充值会关闭，直到你重新设置。

## 查看余额

所有者和管理员可以在 **Activity** 的 **Billing** 卡片中查看余额，点击该卡片会打开 **Settings › Billing**。

点击工作区页面顶部的 **Billing** 按钮或按 `B` 键，会打开一个抽屉，显示实时的 Go 限额、额度和用量。所有者和管理员可以看到工作区的余额、用量和自动充值；成员只能看到自己的用量和限额。

## 额度用完后

余额降到零后，付费请求会失败并返回 HTTP `402`。余额不会变成负数。

```text
Upstream request failed: Insufficient account funds
```

## 发票

每笔付款都会显示在 **Invoices** 中，包含状态以及 **Download invoice** 或 **View receipt** 链接。

| 条目             | 来源                                   |
| ---------------- | -------------------------------------- |
| Balance top-up   | 充值额度                               |
| Automatic top-up | 自动充值                               |
| Go subscription  | 订阅 Go、Go Plus 或 Go Teams           |
| Go renewal       | Go 每月续费                            |
| Go Plus upgrade  | 从 Go 升级到 Go Plus                   |
| Go Teams upgrade | 从 Go 或 Go Plus 升级到 Go Teams       |
| Go Teams member  | 成员加入开通了 Go Teams 的工作区       |
| Monthly Usage    | 按发票结算                             |

## 按发票结算

签订授信协议的工作区可以按月开票结算，无需预先购买额度。如需开通，请联系支持。

- 用量从授信额度中扣除，而不是从预付余额中扣除。
- 每月发票在当月 1 日（UTC）开具，14 天后到期。
- 未支付的发票上会显示 **Pay now** 按钮。
- 达到授信额度上限或发票逾期时，请求会失败并返回 HTTP `402`。

## Go

[OpenCode Go](/console/go) 订阅使用相同的付款方式，并显示在同一个发票列表中。你也可以[用额度支付 Go](/console/go#pay-with-credit)。在 **Go** 页面上开启 **Extra Usage**，即可在达到 Go 限额后改用额度付费。
