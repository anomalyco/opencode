title: "Codex"
description: "在 Codex 中使用 Console 和 Go 模型。"
---

Codex 使用 OpenAI Responses API。将它指向 Console，即可使用任何付费或 Go 模型，包括 Claude、Gemini 和开源模型。对于不接受 Responses 的模型，Console 会转换请求。

<Callout>
  [Console CLI](/console/harnesses#console-cli) 可以用一条命令设置好 Codex，包括团队的策略、MCP 服务器、技能和指令。运行 `npx @opencode/console setup codex`。以下步骤介绍如何手动设置。
</Callout>

## 配置

在 `~/.codex/config.toml` 中将 Console 添加为模型提供商，并将其设为默认。

```toml title="~/.codex/config.toml"
model = "gpt-6.1-sol"
model_provider = "opencode"

[model_providers.opencode]
name = "OpenCode Console"
base_url = "https://opencode.ai/inference/openai/v1"
env_key = "OPENCODE_API_KEY"
wire_api = "responses"
```

Codex 会在基础 URL 后追加 `/responses`，并从 `env_key` 读取密钥。请创建[个人 API 密钥](/console/harnesses#get-an-api-key)，然后将其导出。

```bash
export OPENCODE_API_KEY="oc_sk_..."
codex
```

<Callout>
  Codex 只从 `~/.codex/config.toml` 读取模型提供商。项目的 `.codex/config.toml` 无法设置它们。
</Callout>

## Go

使用 Go 的基础 URL，以及来自已订阅 [Go](/console/go) 的团队的密钥。

```toml title="~/.codex/config.toml"
model = "kimi-k3"
model_provider = "opencode-go"

[model_providers.opencode-go]
name = "OpenCode Go"
base_url = "https://opencode.ai/inference/go/openai/v1"
env_key = "OPENCODE_API_KEY"
wire_api = "responses"
```

## 模型

将 `model` 设为 [Console](/console/models#endpoints) 或 [Go](/console/go#endpoints) 表格中的任何模型 ID。使用 `--model` 可以为单次运行覆盖它。

```bash
codex --model claude-sonnet-5-5
```

Codex 不知道其自有目录之外模型的上下文窗口或推理设置。它会为这些模型使用通用默认值并输出警告，你可以忽略。

## 配置文件

使用 profile 同时保留按量付费和 Go。在 `~/.codex/config.toml` 中定义两个提供商，然后添加一个切换到 Go 的 profile 文件。

```toml title="~/.codex/go.config.toml"
model = "kimi-k3"
model_provider = "opencode-go"
```

```bash
codex --profile go
```

## Console MCP

添加 [Console MCP](/console/harnesses#console-mcp) 服务器，并在浏览器中登录。

```bash
codex mcp add opencode-console --url https://opencode.ai/console/mcp
```

如果登录没有自动开始，请自行运行。

```bash
codex mcp login opencode-console
```
