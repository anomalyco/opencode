[Pi](https://pi.dev) 内置了按量付费和 Go 的 OpenCode 提供商。它会为每个付费或 Go 模型选择正确的 API。免费层级对话模型只能在 OpenCode 中使用，从 Pi 调用会返回 HTTP `403`。

<Callout>
  [Console CLI](/console/harnesses#console-cli) 可以用一条命令设置好 Pi，包括团队的策略、MCP 服务器、技能和指令。运行 `npx @opencode/console setup pi`。以下步骤介绍如何手动设置。
</Callout>

| 提供商      | 套餐          |
| ------------- | ------------- |
| `opencode`    | 按量付费 |
| `opencode-go` | Go            |

## 配置

两个提供商都会从 `OPENCODE_API_KEY` 读取密钥。请创建[个人 API 密钥](/console/harnesses#get-an-api-key)。

```bash
export OPENCODE_API_KEY="oc_sk_..."
pi --model opencode/claude-sonnet-5-5
```

你也可以在 Pi 中运行 `/login` 并选择提供商。Pi 会把密钥保存到 `~/.pi/agent/auth.json`。

```text
/login opencode
```

## Go

使用 `opencode-go` 提供商，以及来自已订阅 [Go](/console/go) 的团队的密钥。

```bash
pi --model opencode-go/kimi-k3
```

## 模型

以 `<provider>/<model-id>` 的形式选择模型，使用 [Console](/console/models#endpoints) 或 [Go](/console/go#endpoints) 表格中的 ID。使用 `--list-models` 列出 Pi 已知的模型。

```bash
pi --list-models opencode-go
```

在 `~/.pi/agent/settings.json` 中设置默认值，或在 `/model` 选择器中按 `Ctrl+S`。

```json title="~/.pi/agent/settings.json"
{
  "defaultProvider": "opencode-go",
  "defaultModel": "kimi-k3"
}
```

当新的 Console 模型尚未出现时，运行 `pi update --models`。

## Console MCP

Pi v0.99.0 及更高版本支持 MCP。添加 [Console MCP](/console/harnesses#console-mcp) 服务器，然后在浏览器中登录。

```bash
pi mcp add opencode-console --url https://opencode.ai/console/mcp
pi mcp login opencode-console
```
