---
title: "预算"
description: "为工作区、成员和服务账号设置每月支出上限。"
---

预算通过策略限制每月支出。所有者和管理员在 **Controls** 中管理预算。

## 预算层级

| 策略范围 | 适用对象 |
| ---------------------- | ---------------------------------------------------- |
| 整个工作区 | 所有成员和服务账号的合计支出 |
| 所有成员 | 每位成员，或所有成员共用一个额度 |
| 带有以下标签的成员 | 带有所选标签的成员 |
| 这些成员 | 指定成员 |
| 所有服务账号 | 每个服务账号，或所有服务账号共用一个额度 |
| 这些服务账号 | 指定服务账号 |

每个请求都必须满足所有适用的预算。较大的额度不会覆盖较小的额度。没有任何预算时，支出不受限制。

## 工作区预算

工作区支出达到预算后，所有人的请求都会被阻止。

1. 打开 **Controls**，点击 **Add policy**。
2. 选择 **Entire workspace**，并添加一条 **Budget** 规则。
3. 输入每月限额（美元），然后点击 **Save**。

## 成员预算

在策略中选择 **All members**，可以为每位成员设置每月额度，也可以让整个组共用一个金额。选择特定成员或标签，可以把范围缩小到更小的一组。

要为某个人设置预算：

1. 在 **Settings › Members** 中打开该成员。
2. 点击 **Create budget policy**，打开已选中该成员的策略构建器。
3. 输入金额并点击 **Save**。

该成员的页面会列出适用的策略。如果所有成员预算也覆盖该成员，两个限额都会生效。

## 服务账号预算

在 **Controls** 中，选择 **All service accounts** 或 **These service accounts**，添加一条 **Budget** 规则，并设置单独或共享的每月额度。该策略涵盖这些账号名下的所有密钥。

## 金额与重置

- 金额以美元为单位，最多保留两位小数。
- 预算会在每月 1 日 00:00 UTC 重置。
- `$0` 预算会阻止所有计入预算的支出。
- 添加或更改预算时，当月已记录的支出也会计算在内，但不会重置额度。

## 计入范围

默认情况下，预算覆盖 **All spend**。你也可以将范围缩小到指定模型，此时只有这些模型计入，既可以为一组模型设一个额度，也可以为每个模型分别设额度。

| 支出                                                               | 计入预算        |
| ------------------------------------------------------------------- | ---------------------------- |
| 控制台的付费模型                                                 | 是                          |
| [自有提供商](/console/providers)上已设置价格的模型 | 是，按配置的价格计算 |
| [网页搜索](/console/websearch)                                    | 是，仅限全部支出的预算   |
| 免费模型                                                         | 否                           |
| 套餐内的 [Go](/console/go) 用量                            | 否                           |
| 用额度支付的 Go 额外用量                                        | 是                          |

## 达到预算后

在预算重置或所有者、管理员提高预算之前，新请求会失败并返回 HTTP `429`。响应会说明是策略预算超限，但不会指出具体是哪个预算。在 **Activity › Logs** 中打开该请求，即可查看阻止它的策略。

```text
Upstream request failed: Policy budget exceeded
```

预算在请求开始时检查。已经开始处理的请求会照常完成，因此支出可能略微超出限额。

## 跟踪支出

每位成员都可以在 **Activity** 中查看自己的支出和限额。打开 **My usage** 即可进入 **Activity › Overview**，其中包含预算详情和重置日期。

所有者和管理员可以从支出图表打开 **Activity › Usage**。它会按天、模型和人员拆分费用，**Export usage** 按钮可以下载最近 7、30 或 90 天的每日汇总 CSV。若要从脚本下载同一文件，请使用[用量导出 API](/console/api/usage-export)。
