---
title: "预算"
description: "通过策略限制团队、成员和服务账号的每月支出。"
---

预算通过策略限制每月支出。所有者和管理员在 **Controls** 中管理预算。

## 预算层级

| 策略受众 | 适用对象 |
| ---------------------- | ---------------------------------------------------- |
| 整个团队 | 所有成员和服务账号的合计支出 |
| 所有成员 | 每位成员，或所有成员共用一个额度 |
| 带有以下标签的成员 | 带有所选标签的成员 |
| 这些成员 | 指定成员 |
| 所有服务账号 | 每个服务账号，或所有服务账号共用一个额度 |
| 这些服务账号 | 指定服务账号 |

每个请求都必须满足所有适用的预算。较大的额度永远不会覆盖较小的额度。没有任何预算时，支出不受限制。

## 团队预算

团队达到预算后，团队预算会阻止所有人的请求。

1. 打开 **Controls**，点击 **Add policy**。
2. 选择 **Entire workspace**，并添加一条 **Budget** 规则。
3. 输入每月限额（美元），然后点击 **Save**。

## 成员预算

在策略中选择 **All members**，可以为每位成员设置每月额度，也可以在组内共用一个金额。选择特定成员或标签可以覆盖更小的组。

要为某个人设置预算：

1. 在 **Settings › Members** 中打开该成员。
2. 点击 **Create budget policy**，打开已选中该成员的策略构建器。
3. 输入金额并点击 **Save**。

其成员页面会列出适用的策略。如果所有成员预算也覆盖该成员，两个限额都会生效。

## 服务账号预算

在 **Controls** 中，选择 **All service accounts** 或 **These service accounts**，添加一条 **Budget** 规则，并设置单独或共享的每月额度。策略会覆盖这些账号的所有密钥。

## 金额与重置

- 金额以美元为单位，最多保留两位小数。
- 预算会在每月 1 日 00:00 UTC 重置。
- `$0` 预算会阻止所有计入预算的支出。
- 添加或更改预算会计入当月已经记录的支出，但不会重置额度。

## 计入范围

默认情况下，预算覆盖 **All spend**。你可以将其收窄到所选模型，此时只有这些模型会计入，可以为该组设置一个额度，也可以为每个模型分别设置额度。

| 支出                                                               | 计入预算        |
| ------------------------------------------------------------------- | ---------------------------- |
| Console 的付费模型                                                 | 是                          |
| [自有提供商](/console/providers)上已设置价格的模型 | 是，按配置的价格计算 |
| [网页搜索](/console/websearch)                                    | 是，针对全消费预算   |
| 免费模型                                                         | 否                           |
| 套餐内的 [Go](/console/go) 用量                            | 否                           |
| 用额度支付的 Go 额外用量                                        | 是                          |

## 达到预算后

在预算重置或所有者、管理员提高预算之前，新请求会以 HTTP `429` 失败。响应会指出是策略预算失败，但不会指明具体预算。在 **Activity › Logs** 中打开该请求，即可查看阻止它的策略。

```text
Upstream request failed: Policy budget exceeded
```

预算在请求开始时检查。已经在进行中的请求会完成，因此支出可能会略微超出限额。

## 跟踪支出

每位成员都可以在 **Activity** 中查看自己的支出和限额。打开 **My usage** 查看 **Activity › Overview**，其中包括预算详情和重置日期。

所有者和管理员可以从支出图表打开 **Activity › Usage**。它会按天、模型和人员细分费用，**Export usage** 按钮可以下载最近 7、30 或 90 天的每日汇总 CSV。若要从脚本下载同一文件，请使用[用量导出 API](/console/api/usage-export)。
