OpenCode Go 提供三档包月套餐，让你稳定使用热门的开放编程模型：

| 套餐         | 价格                                  | 包含用量                                                             |
| ------------ | -------------------------------------- | -------------------------------------------------------------------------- |
| **Go**       | **$10/月**                          | 以更低成本使用下列模型                                      |
| **Go Plus**  | **$40/月**                          | 下列模型的用量上限更高                                |
| **Go Teams** | **每人每月 $20**，至少 2 名成员 | 每位成员有独立的用量限额，每个模型的月度限额都比 Go 高 $5 |

在 OpenCode 中，Go 的用法和其他提供商一样：订阅 OpenCode Go 后即可获取 API 密钥。**订不订阅由你决定**，不订阅也能正常使用 OpenCode。

Go 主要面向国际用户，在全球各地都能稳定访问。

## 工作原理

1. 登录 [OpenCode 控制台](https://opencode.ai/console)，订阅 Go、Go Plus 或 Go Teams，添加账单信息，然后复制你的 API 密钥。
2. 在 TUI 中运行 `/connect`，选择 **OpenCode Go**，然后粘贴 API 密钥。

   ```text
   /connect
   ```

3. 运行 `/models`，选择一个可通过 Go 使用的模型。

   ```text
   /models
   ```

<Callout>
  Go 和 Go Plus 适用于订阅者本人及工作区的 API 密钥。你邀请的其他成员可以使用免费模型，也可以通过工作区余额按量付费。这两种套餐都可以随时升级到 Go Teams，当月未用完的额度会折抵升级费用。Go Teams 适用于工作区内的所有成员，每人每月 $20，至少订购 2 个席位（每月 $40）。下一位加入的成员可使用已付费的第二个席位，无须另付费。之后每有一名成员在计费周期中途加入，就会收取 $20，该成员可获得完整的月度额度。Go Teams 不适用于服务账号。
</Callout>

请参阅[当前的模型列表](https://opencode.ai/console/go#models)。随着我们测试和添加新模型，列表可能会变化。

### 启用受限模型

工作区的隐私设置同样适用于 Go。默认不允许使用会拿请求数据做训练的付费端点，地区仅允许 **Europe & United States**。如果工作区从未保存过隐私设置，来自中国的请求还可以路由到 **Global**。

在 **Settings › Privacy** 中，所有者或管理员可以启用：

- **DeepSeek V4.1 Flash 和 V4 Pro：** 在 **Regions** 下选择 **Global**。
- **LongCat 2.5：** 在 **Regions** 下选择 **Global**。
- **Muse Spark 1.3 Contributor 和 Muse Spark 1.2 Contributor：** 开启 **Allow paid endpoints that train on request data**。

每个模型的训练和数据保留条款请参阅[隐私](#privacy)。

## 用额度支付

所有者和管理员可以用工作区的余额支付 Go 订阅、续费和升级费用。订阅时可选择 **Credit** 作为付款方式，也可以稍后在 **Manage subscription** 中修改。[额外用量](#usage-beyond-limits)则是另一项设置，用于支付超出限额的用量。

- 全部费用均从余额中扣除。如果余额不足，可以先充值。
- 计费周期结束时，系统会从余额中扣取续费费用。如果余额不足，Go 会继续生效，系统会在周期结束后第 1、3、7 天重试扣款，余额补足后也会立即重试。如果最后一次重试仍失败，Go 订阅就会结束。
- 使用[按发票结算](/console/billing#invoiced-billing)的工作区无法用额度支付 Go。
- 用额度支付的 Go 费用会退回工作区余额，退款后该计费周期随即结束。

## 可以在哪里使用？

OpenCode Go 面向 [OpenCode](https://opencode.ai) 以及发送类似请求的其他编程 agent。我们会监测可能影响其他用户体验的滥用流量。

你的客户端应当：

1. 发送编程 agent 通常会发出的请求。
2. 使用客户端专属的 User-Agent 表明身份，例如 `my-coding-agent/1.0`，而不是通用的 SDK 或 HTTP 库名称。
3. 在同一段对话中始终通过 `x-opencode-session` 发送同一个会话 ID，便于我们优化路由和提示词缓存。

[决策](#decision-models)和[嵌入](#embedding-models)请求不需要 `x-opencode-session`，因此任何客户端（例如 RAG 库、记忆服务或脚本）都可以使用你的 Go 密钥调用它们。

要在 Claude Code、Codex、Hermes、OpenClaw、Pi 或 Raycast 中使用 Go，请参阅 [harness 配置指南](/console/harnesses)。

## 用量限额

Go 的付费模型共用同一份额度。在 Go Teams 中，每位成员有一份独立的额度，用于所有模型。

- **5 小时限额**为每月额度的 20%。从你开始使用额度时起计，连续 5 小时。
- **每周限额**为每月额度的 50%。它会在每周一 00:00 UTC 重置。
- **每月额度**会在新的付费周期开始时重置。

换模型不会改变剩余额度。达到限额后，在额度恢复之前，你可以改用免费模型，或开启[额外用量](#usage-beyond-limits)，用控制台余额按量付费。

每个模型的[每月限额](https://opencode.ai/console/go#limits)表示：如果一整个月只用这个模型，套餐能覆盖多少用量。
例如，月度限额为 $15 的模型用掉 $1.50，或月度限额为 $60 的模型用掉 $6，都相当于消耗月度额度的 10%。Go 会在响应的 [`opencode.allowance`](/console/api/inference#cost) 中说明本次请求消耗了多少额度。

[Token 价格](https://opencode.ai/console/go#pricing)按每百万 token 标示，Go、Go Plus 和 Go Teams 的价格一致。

[决策](#decision-models)和[嵌入](#embedding-models)模型按标价计费，没有 Go 折扣：它们的每月限额与你的付费金额一致，Go 为 $10，Go Plus 为 $40。Go Teams 为 $15，和所有模型一样比 Go 高 $5。

**Beam Free：** 限时免费。不在以下国家或地区提供：安哥拉、白俄罗斯、柬埔寨、中国（包括香港和澳门）、古巴、刚果民主共和国、赤道几内亚、伊朗、伊拉克、老挝、利比亚、尼日利亚、朝鲜、俄罗斯、叙利亚、土库曼斯坦、乌兹别克斯坦、委内瑞拉，以及乌克兰的克里米亚、顿涅茨克和卢甘斯克地区。

**Gemini 4 Argon：** 50% 折扣有效期至 2026 年 11 月 30 日。

**HungerG Free：** 限时免费。

### 超出限额的用量

如果控制台还有余额，可以在 **Go** 页面开启 **Extra Usage**。这样达到用量限额后，Go 不会拦截请求，而是从[按量付费余额](/console/models#pricing)中扣费。

Go Teams 默认开启 **Extra Usage**，你可以在 **Go** 页面上关闭或重新开启。

### 为什么有些模型的用量限额更低

在 Go 中，包含的每月用量因模型而异。

对大多数模型，我们靠批量折扣和预留的 GPU 容量做到这一点，再把节省下来的成本以更高的每月用量回馈给你。

有些模型刚推出，或者公开标价已打过折，我们目前还没能拿到额外折扣或以更低的成本托管。

对这些模型，你获得的用量仍比直接向模型提供商付费略多一些；这也是它们包含的每月用量较低的原因。

你也可以通过 `https://opencode.ai/inference/go` 上的 API 调用 Go 模型。各模型的 [ID、路径和 AI SDK 包](https://opencode.ai/console/go#api)见控制台的 Go 页面。列表中标的是各模型的原生 API，但对于文本模型，也可以通过其他 API 调用，控制台会负责转换。完整列表请参阅[基础 URL](/console/harnesses#base-urls)。

这些 AI SDK 包适用于直接调用 Go 的应用。要在 OpenCode 中使用 Go，请通过 `/connect` 连接，并使用 `opencode-go/<model-id>` 格式设置[模型](/models)：

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "model": "opencode-go/kimi-k3",
```

### 决策模型

决策模型针对 `state` 回答指定了类型的问题，而不是生成文本。请使用 Go 密钥，将与[控制台模型](/console/models#jev)格式相同的 System One 请求发送到 `https://opencode.ai/inference/go/systemone/v1/systemone`：

```bash
curl https://opencode.ai/inference/go/systemone/v1/systemone \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jev-1.14",
    "state": "My payments have failed for three days and I am losing sales.",
    "questions": {
      "is_urgent": {
        "type": "noul",
        "instructions": "Does this request require urgent attention?"
      }
    }
  }'
```

| 模型                               | 模型 ID            | 输入  | 输出 | 缓存读取 | 缓存写入 |
| ----------------------------------- | ------------------- | ------ | ------ | ----------- | ------------ |
| Jev 1.14                            | jev-1.14            | $0.042 | 免费   | -           | -            |
| Gemini Decision 1                   | gemini-decision-1   | $0.10  | 免费   | -           | -            |
| GPT 6 Luna Decision (≤ 272K tokens) | gpt-6-luna-decision | $0.10  | 免费   | $0.01       | $0.125       |
| GPT 6 Luna Decision (> 272K tokens) | gpt-6-luna-decision | $0.20  | 免费   | $0.02       | $0.25        |

- 价格按每 1M token 计算。
- OpenAI Decisions 格式的请求可通过 `https://opencode.ai/inference/go/openai/v1/decisions` 使用。
- 问题类型请参阅 [Jev](/console/models#jev)，`state` 中的图片、音频、视频和 PDF 请参阅 [GPT 6 Luna Decision 与 Gemini Decision 1](/console/models#gpt-6-luna-decision-and-gemini-decision-1)。

### 嵌入模型

嵌入模型会把文本转换为向量。请使用 Go 密钥，在 OpenAI 的 Embeddings API（`https://opencode.ai/inference/go/openai/v1/embeddings`）上调用它们：

```bash
curl https://opencode.ai/inference/go/openai/v1/embeddings \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "text-embedding-3-small",
    "input": ["hello world", "goodbye"]
  }'
```

| 模型                  | 模型 ID               | 输入 |
| ---------------------- | ---------------------- | ----- |
| text-embedding-3-small | text-embedding-3-small | $0.02 |
| Qwen3 Embedding 8B     | qwen3-embedding-8b     | $0.01 |
| Gemini Embedding 2     | gemini-embedding-2     | $0.20 |

- 价格按每 1M 输入 token 计算。
- 请求还接受 `dimensions` 和 `encoding_format`。请参阅[嵌入模型](/console/models#embedding-models)。

### 用量

查看你已使用多少[用量限额](#usage-limits)，例如在你自己的客户端中展示：

```bash
curl https://opencode.ai/inference/go/v1/usage \
  -H "Authorization: Bearer <token>"
```

请使用平时调用 Go 的密钥。Go 和 Go Plus 可使用订阅者的[个人 API 密钥](/console/api#personal-api-keys)或[服务账号密钥](/console/api#service-accounts)，Go Teams 则可使用任意成员的个人 API 密钥。

响应会分别返回各项限额的用量：`rolling` 对应 5 小时限额，`weekly` 和 `monthly` 分别对应每周和每月限额。

```json
{
  "usage": {
    "rolling": { "status": "ok", "percent": 30, "resetsAt": "2026-11-21T15:00:00.000Z" },
    "weekly": { "status": "rate-limited", "percent": 100, "resetsAt": "2026-11-23T00:00:00.000Z" },
    "monthly": { "status": "ok", "percent": 50, "resetsAt": "2026-12-01T00:00:00.000Z" }
  }
}
```

| 字段      | 含义                                                                                                    |
| ---------- | ---------------------------------------------------------------------------------------------------------- |
| `status`   | `ok`，或限额用尽后的 `rate-limited`。                                                         |
| `percent`  | 已用额度占限额的百分比，为 `0` 到 `100` 的整数。 |
| `resetsAt` | 限额重置时间，采用 ISO 8601 格式。如果 5 小时窗口尚未开始，`rolling` 的重置时间为当前时间往后 5 小时。 |

请求未提供有效密钥时，返回 HTTP `401`。如果密钥无权使用 Go，则返回 HTTP `403` 并说明原因，例如工作区没有有效的 Go 订阅。

```json
{ "type": "error", "error": { "type": "EntitlementError", "message": "OpenCode Go subscription required." } }
```

## 背景

开放模型的表现已经很出色，在编程任务上接近专有模型。许多提供商都能提供这些模型，价格竞争也让它们通常便宜得多。

然而，要稳定、低延迟地访问它们并不容易。不同提供商的质量和可用性参差不齐。

<Callout type="tip">我们测试并筛选了与 OpenCode 配合良好的模型和提供商。</Callout>

为了解决这个问题，我们做了几件事：

1. 我们测试了一批开放模型，并和各模型团队探讨怎样运行效果最好。
2. 我们与几家提供商合作，确保它们能正确运行这些模型。
3. 我们对不同的模型与提供商组合做了基准测试，整理出一份推荐清单。

Go、Go Plus 和 Go Teams 都可以使用这些模型；请根据你的使用量选择合适的套餐，或选择 Go Teams 覆盖整个团队。

## 目标

我们创建 OpenCode Go 的目标是：

1. 通过低成本订阅，让更多人**用得起** AI 编程。
2. 让你**稳定**地用上优质的开放编程模型。
3. 精选经过**测试和基准评估**、适合编程 agent 使用的模型。
4. **不绑定提供商**：你仍可在 OpenCode 中使用任何其他提供商。
