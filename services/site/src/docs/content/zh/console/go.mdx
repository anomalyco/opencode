OpenCode Go 让你稳定地使用热门的开源编程模型，提供三种按月订阅的套餐：

| 套餐         | 价格                                  | 包含用量                                                             |
| ------------ | -------------------------------------- | -------------------------------------------------------------------------- |
| **Go**       | **$10/月**                          | 以更低成本使用下列模型                                      |
| **Go Plus**  | **$40/月**                          | 下列模型的用量上限更高                                |
| **Go Teams** | **$20/成员/月**，至少 2 名成员 | 每位成员拥有自己的限额，每个模型的每月额度都比 Go 高 $5 |

Go 在 OpenCode 中的用法和其他提供商一样：订阅 OpenCode Go 后获取 API 密钥即可。它**完全是可选的**，不订阅也能正常使用 OpenCode。

该服务主要面向国际用户设计，提供稳定的全球访问。

## 工作原理

1. 登录 [OpenCode 控制台](https://opencode.ai/console)，订阅 Go、Go Plus 或 Go Teams，添加账单信息，然后复制你的 API 密钥。
2. 在 TUI 中运行 `/connect`，选择 **OpenCode Go**，然后粘贴 API 密钥。

   ```text
   /connect
   ```

3. 运行 `/models`，选择一个 Go 提供的模型。

   ```text
   /models
   ```

<Callout>
  Go 和 Go Plus 覆盖订阅者本人以及工作区的 API 密钥。你邀请的其他成员会使用免费模型或工作区余额。两者都可以随时升级到 Go Teams，当月未使用的部分额度会予以抵扣。Go Teams 覆盖工作区中的每位成员，每位成员每月 $20，至少 2 名成员（每月 $40）。第二个席位无需额外付费，覆盖下一位加入的成员；此后，在周期中途加入的成员会被收取 $20，并获得完整的每月额度。服务账号不在 Go Teams 的覆盖范围内。
</Callout>

请参阅[当前的模型列表](https://opencode.ai/console/go#models)。随着我们测试和添加新模型，列表可能会变化。

### 启用受限模型

工作区隐私设置同样适用于 Go。默认情况下，会阻止用请求数据训练的付费端点，允许的地区为 **Europe & United States**。未保存隐私设置的工作区还会允许来自中国的请求使用 **Global**。

在 **Settings › Privacy** 中，所有者或管理员可以启用：

- **DeepSeek V4.1 Flash 和 V4 Pro：** 在 **Regions** 下选择 **Global**。
- **LongCat 2.5：** 在 **Regions** 下选择 **Global**。
- **Muse Spark 1.3 Contributor 和 Muse Spark 1.2 Contributor：** 开启 **Allow paid endpoints that train on request data**。

每个模型的训练和数据保留条款请参阅[隐私](#privacy)。

## 用额度支付

所有者和管理员可以使用工作区额度支付 Go，包括续费和升级。订阅时选择 **Credit** 作为付款方式，也可以之后在 **Manage subscription** 中选择。这与[额外用量](#usage-beyond-limits)不同，后者用于支付超出限额的用量。

- 全部费用从额度余额中扣除。余额不足时，可以先充值额度。
- 周期结束时，续费会从额度余额中扣款。如果额度不足，Go 会保持有效，并在周期结束后第 1、3、7 天重试续费；额度补足后会立即再次重试。如果最后一次重试失败，Go 会结束。
- 使用[按发票结算](/console/billing#invoiced-billing)的工作区无法用额度支付 Go。
- 用额度支付的 Go 费用退款后会退回额度，并结束该 Go 周期。

## 可以在哪里使用？

OpenCode Go 专为 [OpenCode](https://opencode.ai) 以及会产生类似请求的其他编程 agent 而设计。我们会监控损害其他用户体验的滥用流量。

你的客户端应当：

1. 发送典型的编程 agent 流量
2. 使用自己的 user agent 标识自身，例如 `my-coding-agent/1.0`，而不是通用的 SDK 或 HTTP 库名称。
3. 为每个对话在 `x-opencode-session` 中发送稳定的会话 ID，以便我们优化路由和提示词缓存。

[决策](#decision-models)和[嵌入](#embedding-models)请求不需要 `x-opencode-session`，因此任何客户端（例如 RAG 库、记忆服务或脚本）都可以使用你的 Go 密钥调用它们。

在 Claude Code、Codex、Hermes、OpenClaw、Pi 和 Raycast 中设置 Go，请参阅 [Harnesses](/console/harnesses)。

## 用量限额

你在 Go 上使用的付费模型共享同一份额度。在 Go Teams 中，每位成员在所有模型上拥有自己的额度。

- **5 小时限额**为每月额度的 20%。窗口从你首次使用额度时开始，持续 5 小时。
- **每周限额**为每月额度的 50%。它会在每周一 00:00 UTC 重置。
- **每月额度**会在新的付费周期开始时重置。

切换模型会从同一份额度中扣除。达到限额后，你可以使用免费模型，或开启[额外用量](#usage-beyond-limits)，在额度恢复之前使用控制台额度。

每个模型的[每月限额](https://opencode.ai/console/go#limits)显示了套餐能覆盖多少用量，前提是你整月只使用该模型。
例如，在限额为 $15 的模型上使用 $1.50，会占用每月额度的 10%；在限额为 $60 的模型上使用 $6 也是如此。Go 的响应会在 [`opencode.allowance`](/console/api/inference#cost) 中报告每个请求计入了多少。

[Token 价格](https://opencode.ai/console/go#pricing)按每 1M token 计算，Go、Go Plus 和 Go Teams 相同。

[决策](#decision-models)和[嵌入](#embedding-models)模型按标价计费，没有 Go 折扣：它们的每月限额与你的付费金额一致，Go 为 $10，Go Plus 为 $40。Go Teams 为 $15，和所有模型一样比 Go 高 $5。

**Beam Free：** 限时免费。不在以下国家或地区提供：安哥拉、白俄罗斯、柬埔寨、中国（包括香港和澳门）、古巴、刚果民主共和国、赤道几内亚、伊朗、伊拉克、老挝、利比亚、尼日利亚、朝鲜、俄罗斯、叙利亚、土库曼斯坦、乌兹别克斯坦、委内瑞拉，以及乌克兰的克里米亚、顿涅茨克和卢甘斯克地区。

**Gemini 4 Argon：** 50% 折扣有效期至 2026 年 11 月 30 日。

**HungerG Free：** 限时免费。

控制台的 Go 页面会针对每个模型[估算每 5 小时的请求数](https://opencode.ai/console/go#limits)，依据是典型的 Go 使用模式。实际用量会有所不同。

你可以在 [控制台](https://opencode.ai/console) 中，或通过[用量端点](#usage)跟踪当前用量。

随着我们从早期用量和反馈中积累经验，用量限额可能会变化。

### 超出限额的用量

如果你的控制台余额中还有额度，可以在 **Go** 页面上开启 **Extra Usage**。启用后，Go 会在你达到用量限额后回退到[按量付费余额](/console/models#pricing)，而不是阻止请求。

Go Teams 默认开启 **Extra Usage**，你可以在 **Go** 页面上关闭或重新开启。

### 为什么有些模型的用量更低

在 Go 中，包含的每月用量因模型而异。

对大多数模型，我们靠批量折扣和预留的 GPU 容量做到这一点，再把节省下来的成本以更高的每月用量回馈给你。

有些模型，我们还没有机会谈下折扣或以更低成本托管，原因可能是模型较新，或者其公开定价已经打过折。

对这些模型，你获得的用量仍比直接向模型提供商付费略多一些；这也是它们包含的每月用量较低的原因。

## 端点

你也可以通过 `https://opencode.ai/inference/go` 上的 API 访问 Go 模型。每个模型的 [ID、路径和 AI SDK 包](https://opencode.ai/console/go#api)见控制台的 Go 页面。每个模型都以其原生 API 列出，但所有文本模型也能通过控制台转换的其他 API 使用。完整列表请参阅[基础 URL](/console/harnesses#base-urls)。

这些 AI SDK 包适用于直接调用 Go 的应用。要在 OpenCode 中使用 Go，请通过 `/connect` 连接，并使用 `opencode-go/<model-id>` 格式设置[模型](/models)：

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "model": "opencode-go/kimi-k3",
}
```

从模型端点获取可用模型及其元数据的完整列表：

```bash
curl https://opencode.ai/inference/go/v1/models
```

响应中的每个字段（包括 Go 的每月用量限额）请参阅[模型列表 API](/console/api/models)。

### 决策模型

决策模型针对 `state` 回答有类型定义的问题，而不是生成文本。请使用 Go 密钥，把与 [控制台模型](/console/models#jev)相同的 System One 请求发送到 `https://opencode.ai/inference/go/systemone/v1/systemone`：

```bash
curl https://opencode.ai/inference/go/systemone/v1/systemone \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jev-1.14",
    "state": "My payments have failed for three days and I am losing sales.",
    "questions": {
      "is_urgent": {
        "type": "noul",
        "instructions": "Does this request require urgent attention?"
      }
    }
  }'
```

| 模型                               | 模型 ID            | 输入  | 输出 | 缓存读取 | 缓存写入 |
| ----------------------------------- | ------------------- | ------ | ------ | ----------- | ------------ |
| Jev 1.14                            | jev-1.14            | $0.042 | 免费   | -           | -            |
| Gemini Decision 1                   | gemini-decision-1   | $0.10  | 免费   | -           | -            |
| GPT 6 Luna Decision (≤ 272K tokens) | gpt-6-luna-decision | $0.10  | 免费   | $0.01       | $0.125       |
| GPT 6 Luna Decision (> 272K tokens) | gpt-6-luna-decision | $0.20  | 免费   | $0.02       | $0.25        |

- 价格按每 1M token 计算。
- OpenAI Decisions 格式的请求可通过 `https://opencode.ai/inference/go/openai/v1/decisions` 使用。
- 问题类型请参阅 [Jev](/console/models#jev)，`state` 中的图片、音频、视频和 PDF 请参阅 [GPT 6 Luna Decision 与 Gemini Decision 1](/console/models#gpt-6-luna-decision-and-gemini-decision-1)。

### 嵌入模型

嵌入模型会把文本转换为向量。请使用 Go 密钥，在 OpenAI 的 Embeddings API（`https://opencode.ai/inference/go/openai/v1/embeddings`）上调用它们：

```bash
curl https://opencode.ai/inference/go/openai/v1/embeddings \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "text-embedding-3-small",
    "input": ["hello world", "goodbye"]
  }'
```

| 模型                  | 模型 ID               | 输入 |
| ---------------------- | ---------------------- | ----- |
| text-embedding-3-small | text-embedding-3-small | $0.02 |
| Qwen3 Embedding 8B     | qwen3-embedding-8b     | $0.01 |
| Gemini Embedding 2     | gemini-embedding-2     | $0.20 |

- 价格按每 1M 输入 token 计算。
- 请求还接受 `dimensions` 和 `encoding_format`。请参阅[嵌入模型](/console/models#embedding-models)。

### 用量

查看你已使用多少[用量限额](#usage-limits)，例如在你自己的客户端中展示：

```bash
curl https://opencode.ai/inference/go/v1/usage \
  -H "Authorization: Bearer <token>"
```

请使用与 Go 相同的密钥。在 Go 和 Go Plus 上，这是订阅者的[个人 API 密钥](/console/api#personal-api-keys)或[服务账号密钥](/console/api#service-accounts)。在 Go Teams 上，则是任意成员的个人 API 密钥。

响应中每个限额对应一个计量项：5 小时限额为 `rolling`，以及 `weekly` 和 `monthly`。

```json
{
  "usage": {
    "rolling": { "status": "ok", "percent": 30, "resetsAt": "2026-11-21T15:00:00.000Z" },
    "weekly": { "status": "rate-limited", "percent": 100, "resetsAt": "2026-11-23T00:00:00.000Z" },
    "monthly": { "status": "ok", "percent": 50, "resetsAt": "2026-12-01T00:00:00.000Z" }
  }
}
```

| 字段      | 含义                                                                                                    |
| ---------- | ---------------------------------------------------------------------------------------------------------- |
| `status`   | `ok`，或限额用尽后的 `rate-limited`。                                                         |
| `percent`  | 已使用限额的比例，为 `0` 到 `100` 的整数。                                        |
| `resetsAt` | 限额重置的时间，ISO 8601 格式。在 5 小时窗口开始前，`rolling` 会在从现在起 5 小时后重置。 |

没有有效密钥的请求会返回 HTTP `401`。Go 不覆盖的密钥会返回 HTTP `403`，并附带说明原因的提示，例如工作区没有生效中的 Go 订阅。

```json
{ "type": "error", "error": { "type": "EntitlementError", "message": "OpenCode Go subscription required." } }
```

## 背景

开源模型已经变得非常出色。在编程任务上，它们的性能已经接近专有模型。由于许多提供商都能以有竞争力的方式提供这些模型，它们通常要便宜得多。

然而，要稳定、低延迟地访问它们并不容易。不同提供商的质量和可用性参差不齐。

<Callout type="tip">我们测试了一组与 OpenCode 配合良好的精选模型和提供商。</Callout>

为了解决这个问题，我们做了几件事：

1. 我们测试了一组精选的开源模型，并与各模型团队交流了最佳运行方式。
2. 我们与几家提供商合作，确保这些模型能够正确提供服务。
3. 我们对模型与提供商的组合做基准测试，整理出一份我们愿意推荐的列表。

Go、Go Plus 和 Go Teams 都可以使用这些模型；请根据你的使用量选择合适的套餐，或选择 Go Teams 覆盖整个团队。

## 目标

我们创建 OpenCode Go 的目标是：

1. 通过低成本订阅，让更多人**用得起** AI 编程。
2. 提供对最好的开源编程模型的**稳定**访问。
3. 精选经过**测试和基准评估**、适合编程 agent 使用的模型。
4. **不锁定**：你同样可以在 OpenCode 中使用任何其他提供商。
