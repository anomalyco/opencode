在项目目录中运行 OpenCode，输入你的需求，然后按 **Enter**。

```bash
cd ~/code/my-project
opencode
```

```text
Explain how authentication works in this project
```

按 **Shift+Enter**、**Ctrl+Enter**、**Alt+Enter** 或 **Ctrl+J** 换行。OpenCode 正在处理任务时，按 **Enter** 发送提示词，介入当前会话；如果想让提示词排队、稍后处理，先按 **Ctrl+X** 再按 **Enter**。

## 项目与目录

OpenCode 会在启动时所在的目录中查找文件、执行 shell 命令。同一个 Git 仓库下的目录（含各工作树中的目录）都属于同一个项目。未纳入版本控制的目录自成一个项目。

启动时传入目录，即可打开另一个项目：

```bash
opencode ~/code/another-project
```

按 **Ctrl+O** 打开最近会话和项目列表。选中项目后按 **Right** 查看工作树列表，再按 **Ctrl+N** 新建工作树。

## 上下文

输入 `@` 搜索文件，选中后就能将文件附加到提示词。在 `@` 后继续输入可以缩小搜索范围。

```text
Review @src/auth.ts for error handling problems
```

你还可以在路径后指定某一行或一段行号范围。

```text
Explain @src/auth.ts#20-45
```

## Shell

输入框为空时，输入 `!` 进入 Shell 模式。输入命令后按 **Enter** 执行；按 **Esc** 可直接退出，不执行命令。

```text
!git status
```

Shell 命令在会话的工作目录中运行，输出会保留在会话中。

## 命令

输入 `/` 查看斜杠命令。继续输入可以筛选列表，再按 **Enter** 运行所选命令。

```text
/models
```

常用命令包括 `/new`、`/sessions`、`/models`、`/agents`、`/undo`、`/redo` 和 `/editor`。按 **Ctrl+P** 打开命令面板，查看当前视图中可用的所有操作。

更新后，OpenCode 会在首页显示一次本版本的更新亮点。运行 `/highlights` 可以再次查看；如果不想让它自动打开，可以在 [`cli.json`](/cli/config#alerts) 中设置 `"highlights": false`。

## 顺便提问

运行 `/btw <question>` 可以针对目前的对话随手问个问题。OpenCode 会用当前模型和会话上下文回答，但不会把回答写进对话，因此不会影响后续提示词。等待回答时，输入框底部会显示 `/btw`；回答会单独显示在对话框里，按 **C** 即可复制。

```text
/btw why did the test in step 2 fail?
```

## 模型

先按 **Ctrl+X** 再按 **M** 选择模型，或运行 `/models`。按 **F2** 在最近使用的模型之间切换。

先按 **Ctrl+X** 再按 **A** 选择 agent，或运行 `/agents`。按 **Shift+Tab** 在 agent 之间切换。

## 会话

每个会话都是一次独立的对话，有自己的历史记录和目录。要处理一项新任务，可以运行 `/new`，或先按 **Ctrl+X** 再按 **N** 新建会话；之前的会话仍可继续使用。新会话默认使用启动 OpenCode 时所在的目录；如果将 [`session.new_location`](/cli/config#sessions) 设为 `inherit`，则会沿用当前会话的目录。

要回到已有会话，先按 **Ctrl+X** 再按 **L**，或运行 `/sessions`。在会话列表中，按 **Ctrl+A** 可以在当前目录的会话与所有项目的会话之间切换。按 **Ctrl+O** 会同时列出最近的会话和项目。

标签页默认启用。用 **Ctrl+Tab** 和 **Ctrl+Shift+Tab** 在标签页间切换，先按 **Ctrl+X** 再按 **W** 关闭当前标签页，按 **Ctrl+Shift+T** 重新打开最近关闭的标签页。

## 历史记录

先按 **Ctrl+X** 再按 **U**，或运行 `/undo`，可以撤销最近一条用户消息及其之后的所有工作。被撤销的提示词会回到输入框，方便你修改。

先按 **Ctrl+X** 再按 **R**，或运行 `/redo`，可以恢复撤销的内容。如果直接发送新提示词，会话就会保留撤销结果，并从撤销后的位置继续。

## 编辑器

设置 `VISUAL` 或 `EDITOR` 后，先按 **Ctrl+X** 再按 **E**，或运行 `/editor`，即可在该编辑器中编辑当前提示词。保存并退出后，文本会回到输入框，再按 **Enter** 发送。

```bash
export EDITOR="nvim"
opencode
```

Leader 键默认为 **Ctrl+X**。如需修改这些快捷键，请参阅[快捷键](/cli/keybinds)。
