Налаштування CLI керують лише термінальними клієнтами. Вони відокремлені від налаштувань сервера й проєкту в
`opencode.json(c)`.

Натисніть `Ctrl+P`, потім виберіть **Open settings**, щоб змінити поширені налаштування з TUI.

<img src={`${import.meta.env.BASE_URL}assets/cli/settings.png`} alt="OpenCode TUI settings dialog" />

## Файл конфігурації

OpenCode зберігає налаштування CLI в одному глобальному файлі:

```text
~/.config/opencode/cli.json
```

Коли задано `$XDG_CONFIG_HOME`, OpenCode використовує:

```text
$XDG_CONFIG_HOME/opencode/cli.json
```

Локального для проєкту файлу налаштувань CLI немає. Додайте опубліковану JSON-схему для перевірки й автодоповнення:

```json title="cli.json"
{
  "$schema": "https://opencode.ai/v2/cli.json"
}
```

OpenCode додає `$schema`, коли створює або переносить цей файл. Якщо зміни коректні, TUI застосовує їх без перезапуску.

Невідомі налаштування ігноруються. Залишайте `$schema`, щоб редактор позначав недійсні значення.

## Вбудована конфігурація

Задайте `OPENCODE_CLI_CONFIG_CONTENT`, щоб застосувати налаштування CLI з вбудованого JSON:

```sh
OPENCODE_CLI_CONFIG_CONTENT='{"tabs":{"mode":"off"}}' opencode
```

OpenCode накладає вбудовані налаштування поверх глобального `cli.json`. Вкладені об'єкти об'єднуються, а масиви й скалярні
значення зі змінної середовища замінюють глобальні значення. Вбудовані налаштування мають перевагу, поки змінну задано.

## Вигляд

Виберіть тему, керуйте анімацією інтерфейсу й перевизначте курсор термінала:

```json title="cli.json"
{
  "theme": {
    "name": "tokyonight",
    "mode": "system"
  },
  "animations": true,
  "cursor": {
    "style": "block",
    "blinking": true
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="Appearance settings" tabIndex={0}>

| Параметр          | Значення                                | Опис                                                                     |
| ----------------- | --------------------------------------- | ------------------------------------------------------------------------ |
| `theme.name`      | string                                  | Вибирає вбудовану, власну або похідну від термінала тему.                |
| `theme.mode`      | `system`, `dark` або `light`            | Узгоджує тему з виглядом термінала або фіксує один колірний режим. |
| `animations`      | boolean                                 | Вмикає анімації інтерфейсу.                                               |
| `cursor.style`    | `block`, `underline`, `line`, `default` | Задає форму курсора. `default` зберігає форму курсора термінала.           |
| `cursor.blinking` | boolean                                 | Керує блиманням курсора. Не діє, коли стиль — `default`.                  |

</div>

Дивіться [Тему](/cli/theme), щоб вибирати й створювати теми.

## Введення

Налаштуйте захоплення миші, прокручування, контекст редактора, вставлення й попередній перегляд зображень у промпті:

```json title="cli.json"
{
  "mouse": true,
  "scroll": {
    "speed": 3,
    "acceleration": false
  },
  "prompt": {
    "editor": true,
    "paste": "compact",
    "image_preview": false
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="Input settings" tabIndex={0}>

| Параметр                   | Значення                        | Опис                                                                         |
| -------------------------- | ------------------------------- | ---------------------------------------------------------------------------- |
| `mouse`                    | boolean                         | Вмикає захоплення миші в терміналі.                                           |
| `scroll.speed`             | number, щонайменше `0.001`      | Задає фіксовану відстань за один крок прокручування.                          |
| `scroll.acceleration`      | boolean                         | Прискорює повторне прокручування. Коли ввімкнено, має перевагу над швидкістю. |
| `prompt.editor`            | boolean                         | Додає файл або виділення з активного редактора як контекст промпту.          |
| `prompt.paste`             | `compact` або `full`            | Показує великі вставлення як компактні заповнювачі або як повний текст.       |
| `prompt.image_preview`     | boolean                         | Показує попередній перегляд прикріплених зображень над полем промпту.        |

</div>

## Сесії

Налаштуйте, як показуються сесії повноекранного TUI і де починаються нові сесії:

```json title="cli.json"
{
  "session": {
    "sidebar": "auto",
    "scrollbar": false,
    "submit_scroll": "bottom",
    "thinking": "hide",
    "grouping": "auto",
    "image_preview": false,
    "tps": true,
    "markdown": "rendered",
    "new_location": "launch",
    "permissions": "prompt"
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="Session settings" tabIndex={0}>

| Параметр                | Значення                    | Опис                                                                         |
| ----------------------- | --------------------------- | ---------------------------------------------------------------------------- |
| `session.sidebar`       | `auto` або `hide`           | Показує бічну панель, коли є місце, або завжди ховає її.                      |
| `session.scrollbar`     | boolean                     | Показує смугу прокручування розшифровки.                                     |
| `session.submit_scroll` | `bottom` або `keep`         | Переходить до останнього повідомлення після надсилання промпту або зберігає вашу позицію. |
| `session.thinking`      | `show` або `hide`           | Типово показує або ховає міркування моделі.                                  |
| `session.grouping`      | `auto` або `none`           | Групує пов'язані елементи розшифровки або показує кожен окремо.              |
| `session.image_preview` | boolean                     | Показує в розшифровці зображення, прикріплені користувачем, і зображення з результатів інструментів. |
| `session.tps`           | boolean                     | Показує вихідні токени за секунду в нижніх колонтитулах відповідей асистента. |
| `session.markdown`      | `source` або `rendered`     | Показує маркери синтаксису Markdown або приховує їх у відтвореному вмісті.   |
| `session.new_location`  | `launch` або `inherit`      | Починає в каталозі запуску TUI або успадковує розташування активної сесії.   |
| `session.permissions`   | `prompt` або `autoaccept`   | Запитує дозволи або автоматично схвалює кожен запит.                         |

</div>

## Вкладки

Налаштуйте постійну смугу вкладок сесій:

```json title="cli.json"
{
  "tabs": {
    "mode": "auto",
    "scope": "cwd",
    "layout": "horizontal",
    "indicators": "status"
  }
}
```

Застаріле булеве налаштування `tabs.enabled` усе ще підтримується: `true` означає `on`, а `false` — `off`. OpenCode читає його, не переписуючи файл конфігурації.

<div class="docs-table-scroll" role="region" aria-label="Tab settings" tabIndex={0}>

| Параметр          | Значення                    | Опис                                                                          |
| ----------------- | --------------------------- | ----------------------------------------------------------------------------- |
| `tabs.mode`       | `auto`, `on` або `off`      | Використовує вкладки автоматично, завжди або ніколи. Автоматичний режим ховає їх у Herdr. |
| `tabs.scope`      | `cwd` або `global`          | Тримає окремі вкладки для кожного робочого каталогу або ділить їх глобально.  |
| `tabs.layout`     | `horizontal` або `vertical` | Розміщує вкладки в горизонтальній смузі або вертикальній бічній панелі.       |
| `tabs.indicators` | `status` або `numbers`      | Показує значки статусу або завжди показує номери вкладок.                      |

</div>

Числові індикатори зберігають кольори статусу й фонові анімації. Комбінації Ctrl+число перемикають вкладки в обох
режимах індикаторів.

## Diff

Налаштуйте початковий обсяг і подання diff:

```json title="cli.json"
{
  "diffs": {
    "source": "branch",
    "wrap": "word",
    "tree": true,
    "single": false,
    "view": "auto"
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="Diff settings" tabIndex={0}>

| Параметр       | Значення                                    | Опис                                                      |
| -------------- | ------------------------------------------- | --------------------------------------------------------- |
| `diffs.source` | `branch`, `committed`, `working` або `turn` | Задає початковий обсяг перегляду.                         |
| `diffs.wrap`   | `word` або `none`                           | Переносить довгі рядки на межах слів або залишає їх без перенесення. |
| `diffs.tree`   | boolean                                     | Показує дерево файлів у Diff. |
| `diffs.single` | boolean                                     | Показує лише патч вибраного файлу.                        |
| `diffs.view`   | `auto`, `split` або `unified`               | Задає компонування. `auto` вибирає за доступною шириною.  |

</div>

`branch` показує **All** — зміни гілки й локальні зміни, `committed` показує лише коміти гілки, а `working` — індексовані,
неіндексовані й невідстежувані зміни. `turn` показує **Last turn** — файли, які сесія змінила в останньому ході; він
оновлюється, коли сесія завершує хід, і повертається до `branch`, коли `/diff` відкрито не з сесії.

У `/diff` натисніть `d`, щоб змінити обсяг або вибрати гілку для порівняння в **Base**. Ці вибори в поданні діють, доки
TUI не завершиться, і не змінюють `cli.json`.

## Сповіщення

Увімкніть системні сповіщення й звуки привернення уваги незалежно:

```json title="cli.json"
{
  "attention": {
    "notifications": true,
    "sound": true,
    "volume": 0.4,
    "sound_pack": "opencode.default",
    "sounds": {
      "permission": "/home/me/sounds/permission.wav"
    }
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="Alert settings" tabIndex={0}>

| Параметр                 | Значення               | Опис                                                                                                     |
| ------------------------ | ---------------------- | -------------------------------------------------------------------------------------------------------- |
| `attention.notifications` | boolean               | Показує системні сповіщення, зазвичай коли термінал не у фокусі.                                         |
| `attention.sound`        | boolean                | Відтворює звуки привернення уваги.                                                                       |
| `attention.volume`       | number від `0` до `1`  | Задає гучність звуку.                                                                                    |
| `attention.sound_pack`   | string                 | Вибирає ID активного набору звуків.                                                                      |
| `attention.sounds`       | object                 | Перевизначає звукові файли для `default`, `question`, `permission`, `error`, `done` або `subagent_done`.  |

</div>

Недійсне або недоступне перевизначення використовує вбудований звук для цієї події.

Після оновлення TUI один раз показує на головному екрані найважливіше з нового випуску. Виконайте `/highlights`, щоб
побачити це знову, або вимкніть діалог:

```json title="cli.json"
{
  "highlights": false
}
```

## Mini

Група `mini` керує [`opencode mini`](/cli#mini) — мінімальним інтерактивним інтерфейсом:

```json title="cli.json"
{
  "mini": {
    "thinking": "show",
    "tools": "hide",
    "shell_output": "hide",
    "turn_summary": "show",
    "footer": "show",
    "splash": "show",
    "work_spinner": "block-soft-slide",
    "mono": false,
    "replay": true,
    "replay_limit": 200
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="Mini settings" tabIndex={0}>

| Параметр            | Значення                       | Опис                                                                              |
| ------------------- | ------------------------------ | ---------------------------------------------------------------------------------- |
| `mini.thinking`     | `show` або `hide`              | Показує або ховає міркування моделі.                                              |
| `mini.tools`        | `show` або `hide`              | Показує або ховає виклики інструментів і текст асистента перед ними.               |
| `mini.shell_output` | `show` або `hide`              | Показує або ховає необроблений вивід інструмента shell.                            |
| `mini.turn_summary` | `show` або `hide`              | Показує або ховає підсумок агента, моделі й тривалості в історії прокрутки.        |
| `mini.footer`       | `show` або `hide`              | Показує або ховає постійні відомості про активність, модель, використання й контекст. |
| `mini.splash`       | `show` або `hide`              | Показує або ховає вітальні банери під час входу й виходу.                          |
| `mini.work_spinner` | ID спінера                    | Вибирає анімацію роботи в нижньому колонтитулі.                                    |
| `mini.mono`         | boolean                        | Використовує монохромний ASCII-вивід.                                              |
| `mini.replay`       | boolean                        | Відновлює історію сесії під час відновлення й зміни розміру термінала.             |
| `mini.replay_limit` | додатне ціле число             | Обмежує відтворення найновішими повідомленнями. Типова межа — `200`.               |

</div>

Доступні ID спінерів:

```text
block-soft-slide  block-soft-sweep  block-low-comet  block-low-duet
block-shuttle     block-bridge      block-squeeze    small-toggle
square-toggle     grow-shrink       quadrant-orbit   crosshatch
density-wave      seed
```

Прапорці відтворення `mini` в командному рядку перевизначають ці налаштування для цього запуску.

## Комбінації клавіш

Перевизначте прив'язку команди й тайм-аут клавіші leader:

```json title="cli.json"
{
  "keybinds": {
    "leader": "ctrl+x",
    "app.exit": ["ctrl+c", "ctrl+d", "<leader>q"],
    "prompt.paste": {
      "key": "ctrl+v",
      "event": "press",
      "preventDefault": false,
      "fallthrough": false
    },
    "help.show": false
  },
  "leader": {
    "timeout": 2000
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="Keybind settings" tabIndex={0}>

| Параметр                | Значення                                         | Опис                                                              |
| ----------------------- | ------------------------------------------------ | -------------------------------------------------------------------- |
| `keybinds.leader`       | значення прив'язки                               | Задає клавішу, на яку посилається `<leader>` в інших прив'язках.     |
| `keybinds.<command>`    | значення прив'язки                               | Перевизначає прив'язку для одного ID команди.                        |
| `keybinds.*.key`        | рядок клавіші або дескриптор                     | Вибирає клавішу для об'єктної прив'язки.                             |
| `keybinds.*.event`      | `press` або `release`                            | Обмежує об'єктну прив'язку однією подією клавіші.                    |
| `keybinds.*.preventDefault` | boolean                                      | Керує тим, чи блокується типова поведінка клавіші термінала.         |
| `keybinds.*.fallthrough` | boolean                                         | Дозволяє обробникам нижчого пріоритету отримувати ту саму подію.     |
| `leader.timeout`        | додатне ціле число                               | Задає, скільки мілісекунд чекати після клавіші leader.              |

</div>

Значення прив'язки може бути рядком, масивом альтернатив або об'єктом. Використовуйте `"none"` або `false`, щоб вимкнути прив'язку.
Дивіться [Комбінації клавіш](/cli/keybinds), щоб дізнатися про прийнятий синтаксис клавіш, усі ID команд і всі типові прив'язки.

## Плагіни

Завантажуйте плагіни лише для термінала в заданому порядку:

```json title="cli.json"
{
  "plugins": [
    "-opencode.notifications",
    {
      "package": "./plugins/status",
      "options": {
        "compact": true
      }
    }
  ]
}
```

<div class="docs-table-scroll" role="region" aria-label="Plugin settings" tabIndex={0}>

| Параметр             | Значення        | Опис                                                          |
| -------------------- | --------------- | --------------------------------------------------------------- |
| `plugins`            | array           | Оголошує впорядковані директиви ввімкнення й зовнішні плагіни. |
| `plugins[].package`  | string          | Задає назву пакета, локальний шлях або URL-адресу файлу.        |
| `plugins[].options`  | object          | Передає плагіну його власні параметри.                          |

</div>

Дивіться [Плагіни](/cli/plugins), щоб дізнатися про форми пакетів, локальне виявлення, шаблони й директиви вимкнення.

## Налагодження й експерименти

Увімкніть діагностику або активуйте доступний наразі експеримент:

```json title="cli.json"
{
  "debug": {
    "devtools": false,
    "timing": false,
    "turn_tokens": "verbose"
  },
  "experimental": {}
}
```

<div class="docs-table-scroll" role="region" aria-label="Debug and experimental settings" tabIndex={0}>

| Параметр            | Значення                        | Опис                                                                               |
| ------------------- | ------------------------------- | ----------------------------------------------------------------------------------- |
| `debug.devtools`    | boolean                         | Показує панель налагодження DevTools.                                              |
| `debug.timing`      | boolean                         | Показує діагностику часу до першого відображення в панелі налагодження.             |
| `debug.turn_tokens` | boolean або `verbose`           | Показує використання токенів за хід; `verbose` також додає вхідні дані викликів інструментів. |
| `experimental`      | об'єкт із ID функцій і значень boolean | Вмикає або вимикає експерименти, які можуть змінитися або зникнути без попередження. |

</div>

Використовуйте лише ID функцій, які наразі перелічені в діалозі **Experiments** TUI. Невідомі ID не діють.
