---
title: "Комбінації клавіш"
description: "Налаштуйте комбінації клавіш OpenCode CLI у cli.json і знайдіть ID кожної команди та типову комбінацію."
---

Налаштуйте комбінації в `cli.json`:

```json title="cli.json"
{
  "keybinds": {
    "leader": "ctrl+space",
    "command.palette.show": "ctrl+k",
    "app.exit": ["ctrl+c", "ctrl+d"],
    "app.debug": false
  },
  "leader": {
    "timeout": 1500
  }
}
```

Використовуйте рядок для однієї клавіші:

```json
{
  "keybinds": {
    "command.palette.show": "ctrl+k"
  }
}
```

Розділяйте альтернативи комами:

```json
{
  "keybinds": {
    "app.exit": "ctrl+c,ctrl+d"
  }
}
```

Вимкніть комбінацію через `"none"` або `false`:

```json
{
  "keybinds": {
    "app.debug": "none",
    "help.show": false
  }
}
```

Використовуйте об'єкт для поведінки події:

```json
{
  "keybinds": {
    "prompt.paste": {
      "key": "ctrl+v",
      "preventDefault": false
    }
  }
}
```

`leader` типово — `ctrl+x`. `<leader>` в іншій комбінації посилається на цю клавішу.

```json
{
  "keybinds": {
    "leader": "ctrl+space",
    "model.list": "<leader>m"
  },
  "leader": {
    "timeout": 2000
  }
}
```

Невідомі ID команд ігноруються.

## Mini

Команда `app.clear` працює лише в [`opencode mini`](/cli). Натисніть `ctrl+l`, щоб очистити видиму частину екрана й знову показати промпт. Термінал зберігає історію прокрутки.

```json title="cli.json"
{
  "keybinds": {
    "app.clear": "ctrl+l"
  }
}
```

| ID          | Типово   | Опис           |
| ----------- | -------- | -------------- |
| `app.clear` | `ctrl+l` | Очистити екран |

## Переглядач Diff

Натисніть `d` (`diff.switch_source`), щоб вибрати **All**, **Committed**, **Uncommitted** або **Last turn** (усередині сесії), або виберіть **Base**, щоб змінити гілку порівняння. Вибір зберігається до виходу з TUI. Задайте початковий обсяг через [`diffs.source` у `cli.json`](/cli/config#diffs).

Комбінації для прокручування, посторінкової навігації та переходу на початок або в кінець завжди діють у переглядачі Diff. Фокус не можна перемкнути клавіатурою: клацніть файл, щоб відкрити його, або каталог, щоб розгорнути чи згорнути його. Дерево файлів прокручуйте колесом миші.

Використовуйте `n` / `p` або `alt+down` / `alt+up` (Option у macOS), щоб переходити між файлами. У переглядачі Diff комбінації з Alt перемикають файли, а не вкладки сесій.

Натисніть `m`, щоб позначити файл як переглянутий і згорнути його патч. У режимі перегляду всіх файлів натисніть `m` ще раз, щоб зняти позначку й знову розгорнути патч. У режимі перегляду одного файлу позначення відкриває наступний файл, але після останнього файлу не повертає до першого. Зняття позначки не відкриває іншого файлу.

Клацніть файл правою кнопкою в бічній панелі або в його заголовку diff, щоб вибрати **Mark complete** (або **Mark incomplete**). Це змінює той самий стан перегляду, що й `m`. Позначення іншого файлу з його меню не вибирає його й не переходить від файлу, який ви зараз читаєте.

Виберіть запущену команду на вкладці **Shell** і натисніть **Enter** або клацніть її, щоб переглянути перехоплені stdout і stderr.
Використовуйте **↑/↓**, **Page Up/Down** або **Home**, щоб прокручувати, **End**, щоб стежити за новим виводом, і **Esc**, щоб повернутися, не зупиняючи команду.
Переглядач показує нещодавній вивід і залишається відкритим після завершення; вивід, спрямований у файл, не включається.
