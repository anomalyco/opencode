Опишіть, якого результату хочете досягти. OpenCode сам вибере доступні інструменти, за потреби попросить дозволу й поверне результат.

```text
Find where request timeouts are configured, change the default to 30 seconds,
and run the relevant existing tests.
```

Це завдання зазвичай використовує `grep` або `glob`, `read`, інструмент редагування та `shell`. Ви також можете назвати інструмент, коли потрібен конкретний підхід.

```text
Use grep to find every reference to DEFAULT_TIMEOUT, then read the matching files.
```

## Файли

### Читання

`read` повертає файл або нерекурсивний список каталогу. Передайте йому `path`; використовуйте `offset` і `limit`, щоб гортати великі результати.

```text
Read src/server.ts starting at line 120 and return at most 80 lines.
```

Читання тексту містить пронумеровані рядки й обмежене 2,000 рядками та 50 KiB на сторінку. Окремі рядки скорочуються після 2,000 символів. Інструмент також передає моделі файли PNG, JPEG, GIF, WebP і PDF — до 20 MiB вихідних даних. Інші бінарні файли завершуються помилкою. Дивіться [Вкладення](/attachments) про підтримувані медіа й обробку зображень.

Дозвіл: `read` з нормалізованим шляхом як ресурсом.

### Glob

`glob` знаходить шляхи файлів за шаблоном, наприклад `**/*.ts`. Він шукає в поточному каталозі, якщо `path` не вказує інший відносний каталог; `hidden` включає приховані елементи, а `limit` обмежує кількість результатів.

```text
Use glob with **/*.test.ts under packages/core and return at most 50 files.
```

Типове обмеження — 100 файлів, а тайм-аут пошуку — 30 секунд.
Дозвіл: `glob` із запитаним шаблоном як ресурсом.

### Grep

`grep` шукає у вмісті файлів і повертає шляхи, номери рядків і фрагменти. Його `pattern` використовує синтаксис регулярних виразів, якщо `literal` не встановлено в true. Звузьте пошук за допомогою `path`, `include`, `caseSensitive` або `limit`.

```text
Use grep for the literal text "request timed out" in src, including only *.ts files.
```

Типове обмеження — 100 рядків збігу, а тайм-аут пошуку — 30 секунд.
Дозвіл: `grep` із запитаним шаблоном, а не шляхом пошуку, як ресурсом.

### Редагування

`edit` замінює текст у наявному файлі. Передайте `path`, `oldString` і відмінний `newString`; старий текст має збігатися рівно один раз, якщо `replaceAll` не встановлено в true.

```text
In src/config.ts, replace the unique text "timeout: 60" with "timeout: 30".
```

Використовуйте `edit` для точкової зміни. OpenCode може відформатувати файл після запису.
Дозвіл: `edit` з цільовим шляхом як ресурсом.

### Запис

`write` створює текстовий файл або повністю його замінює з `path` і `content`. Він створює відсутні батьківські каталоги й може запустити налаштований форматувальник.

```text
Create docs/example.md with a heading and one setup command.
```

Використовуйте `edit`, якщо має змінитися лише частина наявного файлу.
Дозвіл: `edit` з цільовим шляхом як ресурсом.

### Патч

`patch` застосовує один патч, який може додати, оновити, перемістити або видалити кілька файлів. Його `patchText` використовує секції `*** Add File`, `*** Update File` і `*** Delete File`.

```text
Use patch to rename src/old.ts to src/new.ts and update its exported name.
```

OpenCode надає `patch` для підтримуваних моделей GPT; інші моделі натомість отримують `edit` і `write`. Дозвіл: `edit` з кожним зачепленим шляхом як ресурсом.

Шляхи поза активним Location або поза його робочим деревом проєкту також перевіряються за `external_directory`, який дозволено типово. Дивіться [Дозволи](/permissions) про нормалізацію шляхів, порядок правил і збережені схвалення. Щоб мати зовнішні матеріали доступними за назвою, налаштуйте [Посилання](/references).

## Команди

### Оболонка

`shell` виконує команду в оболонці користувача хоста. Вкажіть `workdir` замість того, щоб вставляти `cd` у команду, і задайте `timeout` у мілісекундах, коли типовий двохвилинний тайм-аут для процесів на передньому плані не підходить.

```text
Run bun test from packages/core with a five-minute timeout.
```

Встановіть `background` у true для сервера розробки або іншого тривалого процесу. Фонові виклики повертаються одразу й сповіщають сесію, коли завершуються; вони не мають тайм-ауту, якщо його не задано. Великий вивід скорочується, а повний вивід зберігається в керованому файлі.

Дозвіл: `shell` з кожною командою, сформованою сканером, як ресурсом. Сканер також перевіряє зовнішній робочий каталог і каталоги, які він може визначити з команди. Оболонка має права користувача хоста на файлову систему, процеси й мережу, тож використовуйте вузькі правила в [Дозволах](/permissions).

## Веб

### Webfetch

`webfetch` отримує одну URL-адресу HTTP або HTTPS як `markdown`, `text` чи `html`. Типово це Markdown; `timeout` приймає до 120 секунд.

```text
Fetch https://example.com/docs as markdown.
```

Він приймає текстові відповіді, як-от HTML, звичайний текст, JSON і XML, але не зображення чи інші бінарні завантаження. Великий вивід можна скоротити, а повний текст зберігається в керованому сховищі. Дозвіл: `webfetch` із запитаною URL-адресою як ресурсом.

### Websearch

`websearch` шукає поточну інформацію у вибраній інтеграції. Його вхід — пошуковий `query`.

```text
Search the web for the latest Bun release notes.
```

Дозвіл: `websearch` із запитом як ресурсом. Дивіться [Вебпошук](/websearch) про провайдерів, вибір, обмеження частоти й вимкнення інструмента.

## Зображення

### Генерація зображень

`generate_image` створює нове зображення з промпту або редагує наявні. Це експериментальна можливість, і вона з'являється, коли підключений провайдер має модель зображень. Щоб вибрати типову модель, дивіться [`experimental.image_generate`](/config#image-generation).

```text
Generate a flat app icon of a paper plane on a blue background and save it to assets/icon.png.
```

Передайте `prompt` і, за потреби, `images` для редагування або як зразки, конкретну `model` чи `path` для збереження. Інструмент працює у фоновому режимі: коли зображення готове, він повідомляє сесії, де його збережено.

Дозвіл: `generate_image` з вибраною моделлю як ресурсом.

## Взаємодія

### Запитання

`question` зупиняє виконання й ставить користувачеві одне чи кілька запитань. Кожне запитання має короткий заголовок, промпт і варіанти; `multiple` дозволяє вибрати більше одного варіанта. Вільна відповідь доступна завжди.

```text
Before changing the API, ask me to choose between a breaking change and a compatibility layer.
```

Дозвіл: `question` з `*` як ресурсом. Клієнт має підтримувати інтерактивну форму, а її закриття скасовує запитання.

### Навичка

`skill` завантажує інструкції та вбудовані ресурси однієї доступної навички за ID у розмову.

```text
Load the effect skill before changing this Effect code.
```

ID має бути в оприлюдненому списку навичок або явно названий користувачем.
Дозвіл: `skill` з ID навички як ресурсом. Дивіться [Навички](/skills) про створення, виявлення й правила завантаження.

## Автоматизація

### Субагент

`subagent` запускає дочірню сесію з налаштованим субагентом. Передайте ID агента, короткий `description` і повний `prompt`.

```text
Ask the explore subagent to map the authentication flow and return the key files.
```

Субагенти завжди працюють у фоні. Виклик одразу повертається з `sessionID`, а батьківська сесія отримує повідомлення `<subagent>`, коли дочірня стає неактивною, і знову після кожного наступного раунду роботи, тож може продовжувати працювати або завершити свій хід без очікування. Передайте повернутий `sessionID`, щоб продовжити ту саму дочірню розмову; подальший запит до запущеної дочірньої сесії приєднується до її поточного запуску. Можна використовувати лише агентів у режимі субагента, а типова глибина вкладеності — один.

Дозвіл: `subagent` з ID вибраного агента як ресурсом.

### Виконання

`execute` виконує JavaScript у Code Mode, щоб агент міг викликати й поєднувати інструменти з каталогу. Це корисно для паралельних незалежних викликів і для обробки результатів без додавання кожного проміжного значення до контексту моделі.

```text
Read package.json and README.md in parallel, then return their relevant setup details.
```

Середовище виконання не має прямого доступу до файлової системи, імпортів чи таймерів. Воно надає `fetch` для HTTP-запитів; усе інше відбувається через інструменти з його каталогу. Заборона `execute` з ресурсом `*` прибирає Code Mode. Інструменти, до яких він мав би доступ, зокрема інструменти MCP із серверів, що не встановлюють `codemode: false`, тоді показуються як прямі інструменти, кожен із повним визначенням у кожному запиті. Забороніть і ці інструменти, якщо агент не повинен мати до них доступу. Вкладені вбудовані інструменти й інструменти MCP усе одно застосовують власні дозволи, а інструменти плагінів застосовують дозволи, які вони заявляють.

### Сесії

Простір назв `opencode.session` у Code Mode містить утиліти для сесій. Без Code Mode вони показуються як `opencode_session_rename` і `opencode_session_move`.

- `rename` змінює назву поточної сесії або іншої сесії, вибраної через `sessionID`.
- `move` переміщує поточну сесію або іншу вибрану сесію до відносного чи абсолютного `directory`. Переміщення набуває чинності на безпечній межі, тож робота, що залежить від місця призначення, має бути в пізнішому виклику.

```text
Rename this session to "Timeout cleanup", then move it to the new worktree.
```

### Робочі дерева

Простір назв `opencode` керує робочими деревами для проєкту сесії:

- `worktree_create` створює робоче дерево з `name` і повертає його `directory`. Конфігурація робочих дерев проєкту вибирає місце призначення й стратегію.
- `worktree_list` показує робочі дерева проєкту.
- `worktree_remove` видаляє робоче дерево, яке OpenCode записав для проєкту. Встановіть `force`, щоб відкинути незакомічені зміни.

```text
Create a worktree named "login" and move this session into it.
```

`worktree_remove` використовує дозвіл `edit` з каталогом робочого дерева як ресурсом. Інші утиліти робочих дерев не запитують вбудованої дії дозволу.

## Браузер

Простір назв `browser` у Code Mode керує браузером, який підключає десктопний застосунок OpenCode. Відкрийте вкладку, збережіть повернутий `tabID`, а потім передавайте цей явний ID кожній операції зі сторінкою.

```text
Open https://example.com, take a snapshot of that tab, and report the main heading.
```

Простір назв містить команди для вкладок і навігації, знімки сторінок і пошук, кліки та введення у формах, скриншоти, передавання файлів, огляд консолі й мережі, трасування продуктивності, огляд купи пам'яті та аудити Lighthouse. Скриншоти потребують видимої вкладки у фокусі. Шляхи завантаження є локальними для сервера; знімки повертають локальні для сервера шляхи, і кожне передавання файлу обмежене 5 MiB.

Вміст сторінок, журнали, заголовки й тіла відповідей — це недовірені дані, а не інструкції для агента. Правило заборони для `browser` з ресурсом `*` прибирає каталог браузера; операції з браузером не викликають окремих запитів дозволу.

## Розширення

[Сервери MCP](/mcp-servers) додають інструменти, назви й входи яких походять від кожного підключеного сервера. Їхня дія дозволу — `<server>_<tool>` з ресурсом `*`. Вони не є фіксованою частиною вбудованого каталогу. Типово агенти отримують до них доступ через `execute` у просторі назв сервера; встановіть `codemode: false` на сервері, щоб показувати його інструменти напряму.

[Навички](/skills) додають інструкції для завдань, а не нові виконувані інструменти. [Вкладення](/attachments) вставляють вибраний користувачем вміст у промпт, а [Посилання](/references) надають названі зовнішні каталоги. Ці можливості доповнюють інструменти, не обходячи їхні перевірки дозволів.
