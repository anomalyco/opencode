`GET https://opencode.ai/console/api/v2/usage/export` повертає використання робочого простору у форматі CSV, по одному рядку на кожен день
UTC, учасника або сервісний обліковий запис, провайдера й модель. Це той самий файл, який завантажує кнопка **Export usage** з
**Activity › Usage**.

```bash
curl --fail-with-body "https://opencode.ai/console/api/v2/usage/export?range=30d" \
  --header "Authorization: Bearer oc_sk_..." \
  --output usage-30d.csv
```

## Автентифікація

Надішліть [API-ключ](/console/api#api-keys) як bearer-токен. За цим ключем експортуються дані того робочого простору, у якому його створено.

```text
Authorization: Bearer oc_sk_...
```

Ключу потрібен **Usage › Read**. Ключі з **All** або **Read only** його мають. Обмеженому ключу потрібно:

```text
Permissions: Restricted
Usage:       Read
```

Використовуйте [ключ сервісного облікового запису](/console/api#service-accounts) для експортів за розкладом або [особистий API-ключ](/console/api#personal-api-keys)
власника чи адміністратора. Учасники не можуть читати використання робочого простору, тож їхні
ключі повертають `403`.

## Запит

| Параметр  | Обов'язковий | Значення                                                                                                              |
| --------- | -------- | --------------------------------------------------------------------------------------------------------------------- |
| `range`   | Так      | `7d`, `30d` або `90d`.                                                                                                |
| `user_id` | Ні       | ID учасника (`user_...`) або ID сервісного облікового запису (`svcacct_...`). Повертає лише рядки цього учасника або сервісного облікового запису. |

Параметр `range` охоплює дні за UTC, зокрема поточний день. Наприклад, `7d` — це сьогодні й шість попередніх днів.
Дані в рядках за поточний день оновлюються до опівночі UTC.

Щоб експортувати використання одного сервісного облікового запису, передайте його ID зі стовпця `user_id` попереднього експорту:

```bash
curl --fail-with-body "https://opencode.ai/console/api/v2/usage/export?range=7d&user_id=svcacct_01JD8Z4Q2W7N3K5M6P9R0S1T2V" \
  --header "Authorization: Bearer oc_sk_..."
```

ID, якого немає в робочому просторі, повертає лише рядок заголовка.

## Відповідь

Успішний запит повертає `200` з `Content-Type: text/csv; charset=utf-8`. Перший рядок — заголовок. Далі
йдуть рядки, починаючи з найновішого дня.

```csv
day,user_type,user_id,user_name,provider,model,requests,input_tokens,output_tokens,cache_read_tokens,cache_write_5m_tokens,cache_write_1h_tokens,cost_micro_cents,cost_usd
2026-11-24,service_account,svcacct_01JD8Z4Q2W7N3K5M6P9R0S1T2V,CI Pipeline,opencode,claude-sonnet-5-5,412,1830211,96402,5120330,210044,0,1512334800,15.123348
2026-11-24,member,user_01JC2X7Y8Z9A0B1C2D3E4F5G6H,ada@example.com,opencode,claude-haiku-5-5,57,402118,31877,880012,0,0,214500000,2.145
2026-11-23,member,user_01JC2X7Y8Z9A0B1C2D3E4F5G6H,ada@example.com,opencode,claude-sonnet-5-5,96,711560,48210,2204118,61022,0,587000000,5.87
```

- Рядки завершуються `\r\n`.
- Дні без використання не мають рядків.
- Відповідь є завантаженням (`Content-Disposition: attachment; filename="usage-30d.csv"`) і ніколи не кешується
  (`Cache-Control: private, no-store`).
- Текстова клітинка, що починається з `=`, `+`, `-` або `@`, отримує на початку `'`, щоб електронні таблиці не виконували її як формулу.

### Стовпці

| Стовпець                | Значення                                                                                                      |
| ----------------------- | ------------------------------------------------------------------------------------------------------------- |
| `day`                   | Дата за UTC у форматі `YYYY-MM-DD`.                                                                           |
| `user_type`             | `member` або `service_account`.                                                                               |
| `user_id`               | ID учасника або сервісного облікового запису.                                                                 |
| `user_name`             | Електронна пошта учасника або назва сервісного облікового запису. Може бути порожнім.                         |
| `provider`              | Провайдер, який виконав запити, наприклад `opencode` для [OpenCode Models](/console/models).                   |
| `model`                 | ID моделі.                                                                                                    |
| `requests`              | Кількість запитів.                                                                                            |
| `input_tokens`          | Вхідні токени.                                                                                                |
| `output_tokens`         | Вихідні токени.                                                                                               |
| `cache_read_tokens`     | Токени, прочитані з кешу промптів.                                                                            |
| `cache_write_5m_tokens` | Токени, записані в кеш промптів із часом життя 5 хвилин.                                                      |
| `cache_write_1h_tokens` | Токени, записані в кеш промптів на 1 годину. |
| `cost_micro_cents`      | Витрати як ціле число мікросентів. Один долар США — `100000000`.                                              |
| `cost_usd`              | Ті самі витрати в доларах США, як точний десятковий дріб щонайменше з двома знаками після коми, наприклад `2.145` або `0.00`. |

### Що включається

- Кожен запит до моделі, зроблений учасниками та сервісними обліковими записами робочого простору.
- Запити до безкоштовних моделей і запити, які учасники роблять через власні підписки Claude Code, Codex або OpenCode,
  включаються з їхніми токенами за нульовою вартістю.
- Дані про [вебпошук](/console/websearch) та інші хмарні сервіси не експортуються.
- Підсумки можуть відставати від нових запитів приблизно на хвилину.

## Обмеження

- Експорт охоплює щонайбільше 90 днів. Щоб зберігати довшу історію, зберігайте файли за розкладом.
- Запити зараховуються до ліміту Console API — 300 запитів на хвилину на обліковий запис, спільного з іншими його
  ендпоінтами. Особисті API-ключі зараховуються тому учаснику, якому належать.

## Помилки

| Статус | Значення                                                                                              |
| ------ | ----------------------------------------------------------------------------------------------------- |
| `400`  | `range` відсутній або не дорівнює `7d`, `30d` чи `90d`, або `user_id` не є ID учасника чи сервісного облікового запису. |
| `401`  | Немає облікових даних або ключ прострочений чи відкликаний.                                            |
| `403`  | Ключ не має **Usage › Read** або належить учаснику, який не є власником чи адміністратором.            |
| `429`  | Перевищено ліміт швидкості. Повторіть запит через кількість секунд, указану в заголовку `Retry-After`.  |
| `503`  | Щоденні підсумки ще недоступні. Повторіть запит пізніше.                                               |
