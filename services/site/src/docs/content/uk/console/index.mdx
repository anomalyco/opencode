[OpenCode Console](https://opencode.ai/console) — необов'язковий сервіс, який дає додаткові можливості
для роботи з OpenCode — самостійно або в команді.

- [Робочі простори](/console/workspaces) для спільного доступу з вашою [командою](/console/members)
- [Інференс](/console/models) для пропрієтарних моделей і моделей із відкритим кодом
- [Провайдери](/console/providers) для підключення власних облікових записів провайдерів через шлюз Console
- Відстеження використання та контроль [бюджетів](/console/budgets)
- Політики, що визначають поведінку OpenCode для всієї команди
- [Вебпошук](/console/websearch)
- [Harness](/console/harnesses) для використання моделей Console з Claude Code, Codex та інших агентів
- [OpenCode Go, Go Plus і Go Teams](/console/go) — підписки на моделі з відкритим кодом за $10 і $40 на місяць для Go і Go Plus відповідно та $20 за учасника на місяць для Go Teams

## Початок роботи

Щоб користуватися Console, команда не потрібна. Для кожного облікового запису спочатку створюється робочий простір **Personal**, у якому ви єдиний учасник.

1. Увійдіть у [Console](https://opencode.ai/console).
2. Підпишіться на [Go](/console/go), додайте [кредити](/console/billing#add-credits) або підключіть [провайдера](/console/providers).
3. Виконайте `/connect` в OpenCode і виберіть робочий простір.
4. За бажанням [запросіть](/console/members#invite-members) свою команду.

```text
/connect
```

## Політики

Правила для провайдерів та інструментів зі сторінки Policies діють у кожному клієнті OpenCode, підключеному до робочого простору. Вони надходять у вигляді [політик](/policies#console), які мають вищий пріоритет за конфігурацію учасника й проєкту та починають діяти приблизно за хвилину. Керовані налаштування й системний файл конфігурації мають вищий пріоритет за політики робочого простору; дивіться [порядок пріоритетів](/policies#precedence).
