Виберіть тему в термінальному інтерфейсі: натисніть `Ctrl+P`, виберіть **Open settings** і відкрийте **Theme**. Також
можна задати її напряму в глобальній конфігурації CLI:

```json title="~/.config/opencode/cli.json"
{
  "theme": {
    "name": "tokyonight",
    "mode": "system"
  }
}
```

Теми належать термінальному клієнту. Розміщуйте вибір теми в `cli.json`, а не в `opencode.json`. Дивіться
[Налаштування CLI](/cli/config), щоб дізнатися про розташування конфігурації та інші налаштування термінала.

## Режими

Використовуйте `system`, щоб наслідувати вигляд термінала, або зафіксуйте тему в одному режимі:

```json title="~/.config/opencode/cli.json"
{
  "theme": {
    "name": "opencode",
    "mode": "dark"
  }
}
```

| Значення | Поведінка                                      |
| -------- | --------------------------------------------- |
| `system` | Наслідує світлий або темний режим термінала. |
| `dark`   | Завжди використовує темну тему.                   |
| `light`  | Завжди використовує світлу тему.                  |

Якщо власна тема надає лише один режим, OpenCode використовує його, коли запитано інший.

## Вбудовані теми

Виберіть вбудовану тему за назвою:

```json title="~/.config/opencode/cli.json"
{
  "theme": {
    "name": "catppuccin"
  }
}
```

Доступні теми:

- `aura`, `ayu`, `carbonfox`, `cobalt2`, `cursor`, `dracula`, `everforest`, `flexoki`
- `catppuccin`, `catppuccin-frappe`, `catppuccin-macchiato`
- `github`, `gruvbox`, `kanagawa`, `material`, `matrix`, `mercury`, `monokai`, `nightowl`, `nord`
- `one-dark`, `opencode`, `opencode-classic`, `orng`, `lucent-orng`, `osaka-jade`, `palenight`, `rosepine`
- `solarized`, `synthwave84`, `tokyonight`, `vercel`, `vesper`, `zenburn`

Тема `system` доступна, коли OpenCode може прочитати палітру вашого термінала.

## Файли

Щоб створити глобальну тему з назвою `ocean`, скористайтеся інструментом тем, щоб згенерувати повний файл у
глобальному каталозі тем. Її важлива структура виглядає так:

```json title="~/.config/opencode/themes/ocean.json (excerpt)"
{
  "base": {
    "text": {
      "base": "#d8f3ff"
    }
  },
  "dark": {
    "hue": {
      "accent": "$hue.cyan"
    }
  }
}
```

Потім виберіть `ocean` у налаштуваннях або задайте `theme.name` як `ocean` у `cli.json`. Ім'я файлу без `.json` — це
назва теми.

| Область | Каталог                                  |
| ------- | ------------------------------------------ |
| Глобальна  | `~/.config/opencode/themes/`               |
| Проєкт | `.opencode/themes/` у дереві проєкту    |

OpenCode читає лише файли `.json`. Тема, ближча до поточного каталогу, замінює глобальну або батьківську тему з такою
самою назвою.

## Формат

Кожна тема V2 оголошує одне повне дерево токенів `base` і щонайменше одну палітру відтінків `light` або `dark`.
Режими успадковують значення лише з базового дерева цього файлу, а не з вбудованої теми OpenCode чи один з одного.
Спершу згенеруйте повне базове дерево інструментом для роботи з темами, а вже потім його налаштовуйте.

Наведені нижче приклади показують лише розділи, що стосуються кожної концепції; це не повні файли тем.

```json title="themes/ocean.json"
{
  "base": {
    "text": {
      "base": "#16324f"
    }
  },
  "light": {
    "hue": {}
  },
  "dark": {
    "hue": {},
    "text": { "base": "#d8f3ff" }
  }
}
```

## Кольори

Використовуйте hex-колір, `transparent` або посилання на інший колір теми:

```json title="themes/ocean.json"
{
  "base": {
    "text": {
      "base": "#d8f3ff",
      "muted": "$hue.neutral.400"
    },
    "background": {
      "base": "transparent"
    }
  }
}
```

Hex-значення можуть мати 3, 4, 6 або 8 цифр. Посилання починаються з `$`; посилання на відтінки мають вигляд
`$hue.<name>.<step>`.

## Відтінки

Перевизначте псевдонім відтінку, щоб змінити одразу всю групу пов'язаних кольорів:

```json title="themes/ocean.json"
{
  "base": {
    "categorical": ["accent", "purple", "green"]
  },
  "dark": {
    "hue": {
      "accent": "$hue.cyan",
      "interactive": "$hue.blue"
    }
  }
}
```

| Вид    | Значення                                                               |
| ------- | -------------------------------------------------------------------- |
| Базові    | `gray`, `red`, `orange`, `yellow`, `green`, `cyan`, `blue`, `purple` |
| Псевдоніми   | `accent`, `interactive`, `neutral`                                 |
| Крок    | `100`, `200`, `300`, `400`, `500`, `600`, `700`, `800`, `900`      |

Кроки відтінків підкоряються напрямку контрасту режиму: світлі теми йдуть від темного на `100` до світлого на `900`,
а темні — від світлого на `100` до темного на `900`.

`categorical` задає впорядковані відтінки, якими розрізняють агентів та інші повторювані елементи. Він має містити
щонайменше один базовий відтінок або псевдонім.

## Стани

Ключі станів змінюють кольори інтерактивних елементів. Незазначені стани використовують найближче базове значення:

```json title="themes/ocean.json"
{
  "base": {
    "text": {
      "action": {
        "primary": {
          "base": "$hue.interactive.400",
          "$hovered": "$hue.interactive.300",
          "$disabled": "$hue.neutral.600"
        }
      }
    }
  }
}
```

| Група     | Значення                                                    |
| --------- | --------------------------------------------------------- |
| Дії   | `primary`, `secondary`, `destructive`                     |
| Стани    | `$hovered`, `$focused`, `$pressed`, `$selected`, `$disabled` |

Поля форм використовують ті самі ключі станів безпосередньо в `text.formfield` або `background.formfield`.

## Токени

Повний `base` містить усі групи токенів. Режим може перевизначити будь-яку його частину після того, як надасть повну
палітру відтінків:

```json title="themes/ocean.json"
{
  "base": {
    "border": {
      "base": "$hue.neutral.700"
    },
    "syntax": {
      "comment": "$hue.neutral.500",
      "keyword": "$hue.accent.400"
    },
    "diff": {
      "text": {
        "added": "$hue.green.400",
        "removed": "$hue.red.400"
      }
    }
  }
}
```

| Група        | Призначення                                                       |
| ------------ | ------------------------------------------------------------- |
| `text`       | Основний, приглушений, тьмяний текст, виділення, дії, поля форм і текст зворотного зв'язку |
| `background` | Основний фон, виділення, поверхні, дії, поля форм і заливки зворотного зв'язку |
| `border`     | Межі                                                       |
| `scrollbar`  | Смуги прокрутки                                                    |
| `diff`       | Кольори доданого, видаленого, контексту, підсвічування та номерів рядків     |
| `syntax`     | Підсвічування вихідного коду                                      |
| `markdown`   | Елементи Markdown                                              |

Ключі синтаксису — `comment`, `keyword`, `function`, `variable`, `string`, `number`, `type`, `operator` і
`punctuation`. Ключі Markdown — `text`, `heading`, `link`, `linkText`, `code`, `blockQuote`, `emphasis`, `strong`,
`horizontalRule`, `listItem`, `listEnumeration`, `image`, `imageText` і `codeBlock`.

## Підняті поверхні

Панелі, діалоги, меню й тости вибирають свою глибину з `background.raised`. Діалоги додатково підтримують контекстну
поверхню `@dialog`. TUI повторно обчислює палітру після застосування `@dialog`, тому токени, що посилаються на
`$background.base`, наслідують фон діалогу:

```json title="themes/ocean.json"
{
  "base": {
    "background": {
      "base": "#071521",
      "raised": {
        "base": "#0c1f2e",
        "high": "#102a3c",
        "max": "#16364b"
      }
    },
    "@dialog": {
      "background": {
        "base": "$background.raised.base"
      }
    }
  }
}
```

`@dialog` приймає ті самі групи токенів, що й базовий режим. Контекстний `base` дії також стає запасним значенням для
її незазначених станів; явне перевизначення стану все одно має перевагу.
