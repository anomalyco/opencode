OpenCode — це відкритий агент для кодування. Він доступний як термінальний інтерфейс, десктопний застосунок або вебзастосунок.

Пакет npm використовує postinstall-скрипт, щоб вибрати нативний бінарник `opencode` для вашої платформи. Команди Bun і pnpm
явно дозволяють потрібний скрипт; Vite+ не потребує додаткового прапорця. Команда mise потребує mise 2026.10.9 або новішої версії;
старіші версії встановлюють OpenCode 1.

Менеджери пакетів Windows не підтримуються.


Завантажте окремий бінарник CLI для своєї платформи.

- **macOS:** [Apple silicon](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-arm64.zip) · [Intel](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-x64.zip) · [Intel (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-x64-baseline.zip)
- **Windows:** [ARM64](https://opencode.ai/update/api/latest/cli/opencode/opencode-windows-arm64.zip) · [x64](https://opencode.ai/update/api/latest/cli/opencode/opencode-windows-x64.zip) · [x64 (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-windows-x64-baseline.zip)
- **Linux (glibc):** [ARM64](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-arm64.tar.gz) · [x64](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-x64.tar.gz) · [x64 (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-x64-baseline.tar.gz)
- **Linux (musl):** [ARM64](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-arm64-musl.tar.gz) · [x64](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-x64-musl.tar.gz) · [x64 (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-x64-baseline-musl.tar.gz)

## Web

Відкрийте вебінтерфейс OpenCode командою `opencode pair`.

```bash
$ opencode pair

  Open a link to connect. Links work once and expire in 5 minutes.

  http://127.0.0.1:49374/auth/connect/...
```

## Docker

Образи Docker мають теги з номерами версій, наприклад `ghcr.io/anomalyco/opencode:2.0.0`.

## Підключення

OpenCode має вбудовану підтримку багатьох провайдерів LLM. Ви можете підключитися до них
безпосередньо [у TUI](/cli/providers) за допомогою `/connect`.

Дивіться [Провайдери](/providers), щоб налаштувати власних провайдерів.

Якщо вам потрібен простий доступ до найкращих моделей для кодування, спробуйте
[OpenCode Console](/console).

Також можна спробувати [OpenCode Go](/console/go) — підписку за $10/місяць,
яка відкриває доступ до найкращих моделей для кодування.

## Налаштування

Налаштуйте OpenCode під себе: відредагуйте [OpenCode config](/config), [завантажте плагіни](/plugins), [підключіть MCP-сервери](/mcp-servers)
або [створіть команди](/commands). Про теми та комбінації клавіш термінального інтерфейсу читайте в розділі [Налаштування CLI](/cli/config).
