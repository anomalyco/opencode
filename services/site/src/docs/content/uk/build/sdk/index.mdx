---

`@opencode/sdk` розміщує OpenCode безпосередньо у вашому застосунку. На відміну від
[мережевого клієнта](/build/client), він збирає сервер OpenCode й маршрутизує виклики
API через його HTTP-маршрутизатор у пам'яті. Він не відкриває HTTP-слухач і не додає
мережевого переходу між клієнтом і сервером.

Для Cloudflare Durable Objects дивіться [посібник із Cloudflare](/build/sdk/cloudflare).

Встановіть SDK:

```sh
bun add @opencode/sdk
```

## Створення хоста

`OpenCode.create()` повертає хост із явним володінням. Використовуйте `await using`, щоб
звільнити його маршрутизатор, служби Location, файбери й реєстрації плагінів зі Scope:

```ts
import { OpenCode } from "@opencode/sdk"

await using opencode = await OpenCode.create()
const session = await opencode.sessions.create({
  location: { directory: "/workspace" },
})

await opencode.sessions.prompt({
  sessionID: session.id,
  text: "Review the current changes",
})
```

Викличте `await opencode.close()` явно, якщо явне керування ресурсами
недоступне.

Вбудований хост використовує ті самі Promise-значення, оголошені помилки, параметри
запитів і потоки `AsyncIterable`, що й `@opencode/client`. Він надає
повний згенерований клієнт і додає зручні псевдоніми `sessions` та `events`
для груп сесій і подій.

## Робочі дерева

Операції з робочими деревами потребують `projectID`. Створення й оновлення завантажують конфігурацію та плагіни зі
збереженої канонічної робочої копії проєкту. Операція отримання списку читає лише збережений перелік. Видалення активує
плагіни з канонічної копії й використовує зафіксовану стратегію. Якщо ця стратегія недоступна, видалення завершується помилкою.

```ts
const projectID = session.projectID
const worktree = await opencode.worktree.create({ projectID, name: "task" })
await opencode.worktree.refresh({ projectID })
await opencode.worktree.remove({ projectID, directory: worktree.directory, force: false })
```

Оновлення знаходить робочі дерева в усіх відомих коренях копій, використовуючи всі доступні стратегії. Зареєструйте власну стратегію
через [перетворення робочих дерев у плагіні](/build/plugins/server#worktrees).

## Потокові події

```ts
for await (const event of opencode.events.subscribe()) {
  console.log(event.type)
}
```

Передайте `AbortSignal` через згенеровані параметри запиту або вийдіть з
ітерації, щоб скасувати тіло відповіді.

## Налаштування

Налаштуйте свій екземпляр OpenCode, зареєструвавши плагіни. Передайте плагіни в
`OpenCode.create()`, щоб налаштувати агентів, моделі, інструменти та іншу поведінку, коли
вбудований хост запускається:

```ts
import { Plugin } from "@opencode/plugin"
import { OpenCode } from "@opencode/sdk"

const plugin = Plugin.define({
  id: "customize-agent",
  async setup(ctx) {
    await ctx.agent.transform((agents) => {
      agents.update("build", (agent) => {
        agent.description = "Builds features and fixes bugs for our team"
      })
    })
  },
})

await using opencode = await OpenCode.create({ plugins: [plugin] })
```

Викличте `await opencode.plugin(plugin)`, щоб зареєструвати ще один плагін після запуску.

Дивіться [повну документацію з плагінів](/build/plugins/server), щоб дізнатися про хуки плагінів,
перетворення, інструменти й повний контекст плагіна.
