OpenCode щодня використовують мільйони людей. Розробляйте на його основі власні
застосунки, інтеграції та агентні рішення, не починаючи з
нуля.

Ми також пропонуємо API для Effect: для [плагінів](/build/plugins/effect),
[клієнтів](/build/client/effect) і [застосунків із вбудованим OpenCode](/build/sdk/effect).
