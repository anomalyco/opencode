Effect-плагіни можуть надавати методи й події, що повертають типізовані Effect і
Stream.

## Означення

Використовуйте `Rpc.define` з Effect Schema, щоб означити RPC.

```ts title="src/rpc.ts"
import { Rpc } from "@opencode/plugin/rpc"
import { Schema } from "effect"

export const Acme = Rpc.define({
  id: "acme",
  methods: {
    search: {
      input: Schema.Struct({ query: Schema.String }),
      output: Schema.Struct({ text: Schema.String }),
      errors: {
        not_found: Schema.Struct({ query: Schema.String }),
      },
    },
  },
  events: {
    updated: {
      schema: Schema.Struct({ itemID: Schema.String, text: Schema.String }),
    },
  },
})
```

### Перевірка

Effect Schema перевіряє значення й виводить їхні типи TypeScript.

```ts
input: Schema.Struct({ query: Schema.String })
```

JSON Schema і Standard Schema також підтримуються.

### Вхід і вихід

Використовуйте `input` для аргументу методу, а `output` — для його поверненого значення. Пропустіть
ту чи ту, коли значення немає.

```ts
search: {
  input: Schema.Struct({ query: Schema.String }),
  output: Schema.Struct({ text: Schema.String }),
}
```

### Помилки

Додавайте очікувані збої до `errors`. Кожен ключ стає `type` помилки.

```ts
errors: {
  not_found: Schema.Struct({ query: Schema.String }),
}
```

### Події

Додавайте події до мапи `events` верхнього рівня. Дані події мають бути об'єктом.

```ts
events: {
  updated: {
    schema: Schema.Struct({ itemID: Schema.String, text: Schema.String }),
  },
}
```

## Реалізація

Зареєструйте реалізацію з Effect плагіна:

```ts title="src/index.ts"
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"
import { Acme } from "./rpc.js"

export default Plugin.define({
  id: "acme-effect-plugin",
  effect: (ctx) =>
    Effect.gen(function* () {
      const registration = yield* ctx.rpc.register(Acme, {
        search: ({ query }, context) =>
          findText(query).pipe(
            Effect.flatMap((text) =>
              text
                ? Effect.succeed({ text })
                : Effect.fail(context.error("not_found", "Result not found", { query })),
            ),
          ),
      })

      const acme = ctx.rpc(Acme)
      const result = yield* acme.search({ query: "hello" })

      yield* registration.events.emit("updated", { itemID: "item-1", text: result.text })
    }).pipe(Effect.orDie),
})
```

Мапа помилок стає типом помилки Effect кожного методу. Використовуйте
`context.error(...)`, щоб створити оголошену помилку.

## Виклик

Після реєстрації RPC його можна викликати через HTTP або з іншого плагіна.

### HTTP

Створіть Effect-клієнт, а потім створіть субклієнт RPC:

```ts
import { OpenCode } from "@opencode/client/effect"
import { Effect } from "effect"
import { FetchHttpClient } from "effect/http"
import { Acme } from "opencode-acme-plugin/rpc"

const program = Effect.gen(function* () {
  const client = yield* OpenCode.make({ baseUrl: "http://localhost:4096" })
  const acme = client.rpc(Acme)
  return yield* acme.search({ query: "hello" })
})

const result = await Effect.runPromise(program.pipe(Effect.provide(FetchHttpClient.layer)))
```

### Плагін

Інший Effect-плагін може створити локальний субклієнт зі свого контексту:

```ts
import { Effect } from "effect"

effect: (ctx) =>
  Effect.gen(function* () {
    const acme = ctx.rpc(Acme)
    const result = yield* acme.search({ query: "hello" })
    yield* Effect.logInfo(result.text)
  }).pipe(Effect.orDie)
```

### Підписка

Події RPC доступні як потоки Stream. Підпишіться за назвою події й запустіть потік у файбері, обмеженому відповідним Scope:

{/* prettier-ignore */}
```ts
import { Effect, Stream } from "effect"

const acme = ctx.rpc(Acme)

yield* acme.events.subscribe("updated").pipe(
  Stream.runForEach((event) => Effect.logInfo(event.data.text)),
  Effect.forkScoped,
)
```

Підписки працюють лише в реальному часі й закриваються, коли споживання Stream припиняється.
