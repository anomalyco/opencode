Use your Antigravity subscription in OpenCode. The Google Antigravity provider runs the Antigravity CLI on your machine
over the Agent Client Protocol, so install the CLI and sign in first.

```bash
agy
```

Then choose a model.

```text
/models
# Select Google Antigravity.
```

The model list comes from your account, so it is what the CLI reports for the plan you are on. Effort levels are
variants, such as `antigravity/gemini-3.8-flash#high`.

OpenCode finds `agy` on your `PATH`. To use another copy, set `OPENCODE_ANTIGRAVITY_PATH` on the server.

```bash
opencode service set env OPENCODE_ANTIGRAVITY_PATH /opt/agy/bin/agy
```

## How it works

The agent calls the model, and OpenCode does everything else.

- The agent runs with the Antigravity CLI's own system prompt, tools and instruction files.
- The agent's tool calls are shown in OpenCode as provider-executed calls. OpenCode does not run them.
- When the agent asks for permission, OpenCode checks the request against your permission rules for the current agent
  and asks you when a rule says to. Edits map to `edit`, shell commands to `bash`, reads to `read`.
- Each OpenCode session has its own Antigravity conversation, and the model and effort level you pick are used for
  each turn.
- Your Antigravity settings are not loaded into OpenCode.

## Cost

A consumer Antigravity subscription covers the usage, so no cost is shown.

## Limitations

- The Antigravity CLI must be installed on the same machine as the OpenCode server. The provider is not available in
  remote workspaces.
- The agent's tools are the CLI's own. OpenCode's permission rules apply only to what the agent asks permission for,
  and the CLI's own permission settings decide what that is.
- Temperature, top-p, top-k, seed, and stop sequences are not supported.
- The agent cannot be steered mid-turn.

## Terms

This provider drives the CLI's `antigravity-acp` runtime, which is the surface Google's Antigravity FAQ names as usable
for single-user interactive development. It does not drive the CLI's print mode (`agy -p`), which the FAQ says is not
supported for third-party agents on consumer plans.

## Errors

| Error or symptom | Check |
| --- | --- |
| `Could not start the Antigravity CLI` | Install the Antigravity CLI so `agy` is on `PATH`. |
| No Antigravity models listed | Run `agy` once and sign in, then restart OpenCode. |
