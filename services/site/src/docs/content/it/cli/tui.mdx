Esegui OpenCode dal tuo progetto, digita una richiesta e premi **Enter**.

```bash
cd ~/code/my-project
opencode
```

```text
Explain how authentication works in this project
```

Premi **Shift+Enter**, **Ctrl+Enter**, **Alt+Enter** o **Ctrl+J** per andare a capo. Mentre OpenCode lavora, premi **Enter** per orientare la sessione in corso, oppure **Ctrl+X** seguito da **Enter** per mettere il prompt in coda.

## Progetti e directory

OpenCode cerca i file ed esegue i comandi della shell nella directory da cui lo avvii. Le directory dello stesso repository Git,
compresi i suoi worktree, appartengono a un unico progetto. Una directory senza controllo di versione costituisce un progetto a sé.

Passa una directory per avviare OpenCode in un altro progetto:

```bash
opencode ~/code/another-project
```

Premi **Ctrl+O** per aprire le sessioni e i progetti recenti. Seleziona un progetto e premi **Right** per elencarne i worktree.
Da quell'elenco, premi **Ctrl+N** per crearne uno.

## Contesto

Digita `@` per cercare un file, poi selezionalo per allegare quel file al prompt. Continua a digitare dopo `@` per restringere i risultati.

```text
Review @src/auth.ts for error handling problems
```

Puoi includere una riga o un intervallo dopo il percorso.

```text
Explain @src/auth.ts#20-45
```

## Shell

Digita `!` all'inizio di un prompt vuoto per entrare in modalità shell. Inserisci un comando e premi **Enter**; premi **Esc** per uscire dalla modalità shell senza eseguirne uno.

```text
!git status
```

I comandi shell vengono eseguiti nella directory di lavoro della sessione e il loro output resta nella sessione.

## Comandi

Digita `/` per elencare i comandi slash. Continua a digitare per filtrare l'elenco, poi premi **Enter** per eseguire il comando selezionato.

```text
/models
```

Tra i comandi comuni ci sono `/new`, `/sessions`, `/models`, `/agents`, `/undo`, `/redo` e `/editor`. Premi **Ctrl+P** per aprire la palette dei comandi per ogni azione disponibile nella vista corrente.

Dopo un aggiornamento, OpenCode mostra una volta nella schermata iniziale le novità della release. Esegui `/highlights` per rivederle, oppure imposta `"highlights": false` in [`cli.json`](/cli/config#alerts) per impedire che si aprano automaticamente.

## Domande a margine

Esegui `/btw <question>` per fare una domanda rapida sulla conversazione finora. La risposta usa il contesto della sessione e il modello corrente ma non viene aggiunta alla conversazione, quindi non influisce sui prompt successivi. Un indicatore `/btw` compare nel piè di pagina del prompt mentre è in esecuzione, e la risposta si apre in un dialogo; premi **C** per copiarla.

```text
/btw why did the test in step 2 fail?
```

## Modelli

Premi **Ctrl+X**, poi **M** per scegliere un modello, oppure esegui `/models`. Premi **F2** per scorrere i modelli usati di recente.

Premi **Ctrl+X**, poi **A** per scegliere un agente, oppure esegui `/agents`. Premi **Shift+Tab** per scorrere gli agenti.

## Sessioni

Ogni sessione è una conversazione separata, con una propria cronologia e una propria directory. Per passare a un'altra attività,
esegui `/new` o premi **Ctrl+X**, poi **N**: le sessioni precedenti restano disponibili. Le nuove sessioni partono dalla
directory da cui hai avviato OpenCode o, se imposti [`session.new_location`](/cli/config#sessions) su `inherit`,
dalla directory della sessione corrente.

Premi **Ctrl+X**, poi **L**, o esegui `/sessions` per tornare a una sessione esistente. Nell'elenco, **Ctrl+A** alterna la vista
delle sessioni nella directory corrente e quella delle sessioni di tutti i progetti. **Ctrl+O** apre insieme sessioni e progetti recenti.

Le schede sono abilitate per impostazione predefinita. Usa **Ctrl+Tab** e **Ctrl+Shift+Tab** per spostarti tra loro, **Ctrl+X** poi **W** per chiuderne una, e **Ctrl+Shift+T** per riaprire l'ultima scheda chiusa.

## Cronologia

Premi **Ctrl+X**, poi **U**, o esegui `/undo`, per annullare l'ultimo messaggio utente e il lavoro che è seguito. Il prompt annullato torna nell'area di composizione, così puoi modificarlo.

Premi **Ctrl+X**, poi **R**, o esegui `/redo`, per ripristinare il lavoro annullato. Se invece invii un nuovo prompt, confermi l'annullamento e riprendi da quel punto.

## Editor

Imposta `VISUAL` o `EDITOR`, poi premi **Ctrl+X**, poi **E**, o esegui `/editor`, per modificare il prompt corrente in quell'editor. Salva ed esci per riportare il testo nell'area di composizione, poi premi **Enter** per inviarlo.

```bash
export EDITOR="nvim"
opencode
```

Il tasto leader è **Ctrl+X** per impostazione predefinita. Vedi [Scorciatoie da tastiera](/cli/keybinds) per cambiarle.
