---
title: "Plugin CLI"
description: "Carica nella CLI i plugin TUI configurati in OpenCode e aggiungi in cli.json i plugin specifici per la CLI e le relative opzioni."
---

I plugin configurati in `opencode.json(c)` che espongono un componente TUI vengono caricati automaticamente dalla CLI. Per scoprire come
creare plugin, vedi [Creare plugin](/build/plugins). Non devi aggiungere lo stesso pacchetto a `cli.json`. La CLI
ottiene l'elenco dei plugin attivi dal server OpenCode collegato, quindi funziona anche quando il server è remoto.

Usa `cli.json` per i plugin specifici per la CLI. Questi plugin si eseguono in locale nel terminale e restano attivi quando la CLI si collega
a un server remoto:

```json title="cli.json"
{
  "plugins": [
    "opencode.example",
    "opencode.example@1.0.0",
    "@example/opencode-tui",
    "@example/opencode-tui@1.0.0",
    "./plugins/status",
    "../plugins/status",
    "/home/user/plugins/status",
    "file:///home/user/plugins/status"
  ]
}
```

Le voci vengono elaborate in ordine. Anteponi `-` a un ID o a un carattere jolly per disabilitare i plugin corrispondenti:

```json title="cli.json"
{
  "plugins": ["*", "-opencode.notifications", "-team.*"]
}
```

Passa le opzioni dei plugin usando la sintassi a oggetto:

```json title="cli.json"
{
  "plugins": [
    {
      "package": "@example/opencode-tui",
      "options": {
        "compact": true
      }
    }
  ]
}
```

OpenCode scopre i plugin anche nella directory di configurazione globale e nelle directory `.opencode` dei progetti. Ogni plugin usa
la stessa struttura di un pacchetto pubblicato, con i punti di ingresso del server e della TUI tenuti insieme.

```text title="Plugin discovery paths"
<global-config>/plugins/status/index.ts
<global-config>/plugins/status/tui.ts
<project>/.opencode/plugins/status/index.ts
<project>/.opencode/plugins/status/tui.ts
```

I plugin trovati in queste directory possono importare direttamente `@opencode/plugin/tui`: OpenCode risolve il pacchetto a runtime. Vedi
[Creare plugin TUI](/build/plugins/cli) per gli esempi.
