---
title: "Scorciatoie da tastiera"
description: "Personalizza le scorciatoie della CLI di OpenCode in cli.json e consulta l'ID e il binding predefinito di ogni comando."
---

Personalizza i binding in `cli.json`:

```json title="cli.json"
{
  "keybinds": {
    "leader": "ctrl+space",
    "command.palette.show": "ctrl+k",
    "app.exit": ["ctrl+c", "ctrl+d"],
    "app.debug": false
  },
  "leader": {
    "timeout": 1500
  }
}
```

Usa una stringa per un singolo tasto:

```json
{
  "keybinds": {
    "command.palette.show": "ctrl+k"
  }
}
```

Separa le alternative con virgole:

```json
{
  "keybinds": {
    "app.exit": "ctrl+c,ctrl+d"
  }
}
```

Disabilita un binding con `"none"` o `false`:

```json
{
  "keybinds": {
    "app.debug": "none",
    "help.show": false
  }
}
```

Usa un oggetto per il comportamento degli eventi:

```json
{
  "keybinds": {
    "prompt.paste": {
      "key": "ctrl+v",
      "preventDefault": false
    }
  }
}
```

`leader` è `ctrl+x` per impostazione predefinita. `<leader>` in un altro binding si riferisce a quel tasto.

```json
{
  "keybinds": {
    "leader": "ctrl+space",
    "model.list": "<leader>m"
  },
  "leader": {
    "timeout": 2000
  }
}
```

Gli ID comando sconosciuti vengono ignorati.

## Mini

Il comando `app.clear` funziona solo in [`opencode mini`](/cli). Premi `ctrl+l` per pulire la schermata visibile e ridisegnare il prompt. Il terminale conserva la cronologia.

```json title="cli.json"
{
  "keybinds": {
    "app.clear": "ctrl+l"
  }
}
```

| ID          | Predefinito | Descrizione       |
| ----------- | ----------- | ----------------- |
| `app.clear` | `ctrl+l`    | Pulisce lo schermo |

## Visualizzatore dei diff

Premi `d` (`diff.switch_source`) per scegliere **All**, **Committed**, **Uncommitted** o **Last turn** (dentro una sessione), oppure seleziona **Base** per cambiare il branch di confronto. Le scelte vengono ricordate fino all'uscita dalla TUI. Imposta l'ambito iniziale con [`diffs.source` in `cli.json`](/cli/config#diffs).

Scorrimento, paginazione e scorciatoie di inizio/fine controllano sempre il diff. Non c'è un cambio di focus da tastiera: fai clic sui file per aprirli, sulle cartelle per espanderle o comprimerle, e usa la rotellina del mouse per scorrere l'albero dei file.

Usa `n` / `p` o `alt+down` / `alt+up` (Option su macOS) per spostarti tra i file. Dentro il visualizzatore dei diff, le scorciatoie Alt navigano i file invece delle schede delle sessioni.

Premi `m` per contrassegnare un file come revisionato e richiuderne la patch. Nella vista di tutti i file, premi di nuovo `m` per togliere il contrassegno e riaprire la patch. Nella vista a file singolo, il contrassegno fa passare automaticamente al file successivo, ma dall'ultimo non si torna al primo. Togliere il contrassegno non fa mai avanzare.

Fai clic con il tasto destro su un file nella barra laterale o sulla sua intestazione del diff per **Mark complete** (o **Mark incomplete**). Questo cambia lo stesso stato revisionato di `m`. Completare un altro file dal suo menu non lo seleziona né fa avanzare il file che stai leggendo.

Le alternative con Shift di `diff.help` supportano i terminali che riportano il modificatore Shift quando premi `?`.
