---
title: "API di esportazione dell'utilizzo"
description: "Scarica l'utilizzo giornaliero di uno spazio di lavoro in CSV, con richieste, token e costo per ogni giorno, persona, provider e modello."
---

`GET https://opencode.ai/console/api/v2/usage/export` restituisce l'utilizzo di uno spazio di lavoro in CSV, con una riga per ogni giorno UTC,
membro o account di servizio, provider e modello. È lo stesso file che scarica il pulsante **Export usage** da
**Activity › Usage**.

```bash
curl --fail-with-body "https://opencode.ai/console/api/v2/usage/export?range=30d" \
  --header "Authorization: Bearer oc_sk_..." \
  --output usage-30d.csv
```

## Autenticazione

Invia una [chiave API](/console/api#api-keys) come token bearer. L'esportazione riguarda lo spazio di lavoro in cui hai creato la chiave.

```text
Authorization: Bearer oc_sk_...
```

La chiave richiede **Usage › Read**. Le chiavi con **All** o **Read only** ce l'hanno. Una chiave limitata richiede:

```text
Permissions: Restricted
Usage:       Read
```

Usa una [chiave di account di servizio](/console/api#service-accounts) per esportazioni pianificate, oppure la
[chiave API personale](/console/api#personal-api-keys) di un proprietario o amministratore. I membri non possono leggere l'utilizzo dello spazio di lavoro, quindi le loro
chiavi restituiscono `403`.

## Richiesta

| Parametro | Obbligatorio | Valore                                                                                                                |
| --------- | ------------ | --------------------------------------------------------------------------------------------------------------------- |
| `range`   | Sì           | `7d`, `30d` o `90d`.                                                                                                  |
| `user_id` | No           | Un ID membro (`user_...`) o un ID account di servizio (`svcacct_...`). Restituisce solo le righe di quel membro o account di servizio. |

`range` conta i giorni UTC e include la data odierna: `7d` comprende oggi e i sei giorni precedenti.
I dati di oggi continuano ad accumularsi fino a mezzanotte UTC.

Per esportare l'utilizzo di un solo account di servizio, passa il suo ID dalla colonna `user_id` di un'esportazione precedente:

```bash
curl --fail-with-body "https://opencode.ai/console/api/v2/usage/export?range=7d&user_id=svcacct_01JD8Z4Q2W7N3K5M6P9R0S1T2V" \
  --header "Authorization: Bearer oc_sk_..."
```

Un ID che non è nello spazio di lavoro restituisce solo la riga di intestazione.

## Risposta

Una richiesta riuscita restituisce `200` con `Content-Type: text/csv; charset=utf-8`. La prima riga è l'intestazione. Seguono le righe,
con il giorno più recente per primo.

```csv
day,user_type,user_id,user_name,provider,model,requests,input_tokens,output_tokens,cache_read_tokens,cache_write_5m_tokens,cache_write_1h_tokens,cost_micro_cents,cost_usd
2026-11-24,service_account,svcacct_01JD8Z4Q2W7N3K5M6P9R0S1T2V,CI Pipeline,opencode,claude-sonnet-5-5,412,1830211,96402,5120330,210044,0,1512334800,15.123348
2026-11-24,member,user_01JC2X7Y8Z9A0B1C2D3E4F5G6H,ada@example.com,opencode,claude-haiku-5-5,57,402118,31877,880012,0,0,214500000,2.145
2026-11-23,member,user_01JC2X7Y8Z9A0B1C2D3E4F5G6H,ada@example.com,opencode,claude-sonnet-5-5,96,711560,48210,2204118,61022,0,587000000,5.87
```

- Le righe terminano con `\r\n`.
- I giorni senza utilizzo non hanno righe.
- La risposta è un download (`Content-Disposition: attachment; filename="usage-30d.csv"`) e non viene mai messa in cache
  (`Cache-Control: private, no-store`).
- Una cella di testo che inizia con `=`, `+`, `-` o `@` riceve un `'` iniziale, così i fogli di calcolo non la eseguono come formula.

### Colonne

| Colonna                 | Significato                                                                                                   |
| ----------------------- | ------------------------------------------------------------------------------------------------------------- |
| `day`                   | La data UTC, come `YYYY-MM-DD`.                                                                                |
| `user_type`             | `member` o `service_account`.                                                                                 |
| `user_id`               | L'ID del membro o dell'account di servizio.                                                                    |
| `user_name`             | L'email del membro o il nome dell'account di servizio. Può essere vuoto.                                       |
| `provider`              | Il provider che ha servito le richieste, ad esempio `opencode` per [OpenCode Models](/console/models).         |
| `model`                 | L'ID del modello.                                                                                             |
| `requests`              | Numero di richieste.                                                                                          |
| `input_tokens`          | Token di input.                                                                                               |
| `output_tokens`         | Token di output.                                                                                              |
| `cache_read_tokens`     | Token letti dalla cache dei prompt.                                                                           |
| `cache_write_5m_tokens` | Token scritti nella cache dei prompt con una durata di 5 minuti.                                              |
| `cache_write_1h_tokens` | Token scritti nella cache dei prompt con una durata di 1 ora.                                                 |
| `cost_micro_cents`      | Costo come numero intero di micro-centesimi. Un dollaro statunitense è `100000000`.                           |
| `cost_usd`              | Lo stesso costo in dollari statunitensi, come decimale esatto con almeno due decimali, ad esempio `2.145` o `0.00`. |

### Cosa è incluso

- Ogni richiesta di modello fatta dai membri e dagli account di servizio dello spazio di lavoro.
- Le richieste ai modelli gratuiti e quelle che i membri fanno tramite i propri abbonamenti Claude Code, Codex o OpenCode
  sono incluse con i loro token a costo zero.
- [Ricerca web](/console/websearch) e altri servizi ospitati non sono inclusi.
- I totali possono arrivare con circa un minuto di ritardo rispetto alle nuove richieste.

## Limiti

- Un'esportazione copre al massimo 90 giorni. Per conservare uno storico più lungo, pianifica il salvataggio periodico dei file.
- Le richieste concorrono al limite di 300 richieste al minuto per account, condiviso con gli altri endpoint dell'API di Console.
  Le richieste con una chiave API personale concorrono al limite del membro titolare della chiave.

## Errori

| Stato | Significato                                                                                            |
| ----- | ------------------------------------------------------------------------------------------------------ |
| `400` | `range` manca o non è `7d`, `30d` o `90d`, oppure `user_id` non è un ID di membro o account di servizio. |
| `401` | Nessuna credenziale, o una chiave scaduta o revocata.                                                  |
| `403` | La chiave non ha **Usage › Read**, oppure appartiene a un membro che non è proprietario o amministratore. |
| `429` | Limite di frequenza superato. Riprova dopo il numero di secondi nell'header `Retry-After`.              |
| `503` | I totali giornalieri non sono ancora disponibili. Riprova più tardi.                                   |
