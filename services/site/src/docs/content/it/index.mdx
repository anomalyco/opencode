OpenCode è un agente di coding open source. Puoi usarlo da terminale, dall'app desktop o dall'app web.

Il pacchetto npm usa uno script postinstall per selezionare il binario nativo `opencode` per la tua piattaforma. I comandi Bun e pnpm consentono esplicitamente lo script richiesto; Vite+ non richiede alcun flag aggiuntivo. Il comando mise richiede mise 2026.10.9 o successivo; le versioni precedenti installano OpenCode 1.

I gestori di pacchetti di Windows non sono supportati.


Scarica un binario CLI autonomo per la tua piattaforma.

- **macOS:** [Apple silicon](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-arm64.zip) · [Intel](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-x64.zip) · [Intel (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-x64-baseline.zip)
- **Windows:** [ARM64](https://opencode.ai/update/api/latest/cli/opencode/opencode-windows-arm64.zip) · [x64](https://opencode.ai/update/api/latest/cli/opencode/opencode-windows-x64.zip) · [x64 (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-windows-x64-baseline.zip)
- **Linux (glibc):** [ARM64](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-arm64.tar.gz) · [x64](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-x64.tar.gz) · [x64 (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-x64-baseline.tar.gz)
- **Linux (musl):** [ARM64](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-arm64-musl.tar.gz) · [x64](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-x64-musl.tar.gz) · [x64 (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-x64-baseline-musl.tar.gz)

## Web

Accedi all'interfaccia web di OpenCode con il comando `opencode pair`.

```bash
$ opencode pair

  Open a link to connect. Links work once and expire in 5 minutes.

  http://127.0.0.1:49374/auth/connect/...
```

## Docker

Le immagini Docker usano tag con la versione, ad esempio `ghcr.io/anomalyco/opencode:2.0.0`.

## Connessione

OpenCode supporta nativamente molti provider LLM. Puoi collegarti direttamente [nella TUI](/cli/providers) con `/connect`.

Vedi [Provider](/providers) per configurare provider personalizzati.

Se vuoi un accesso semplice ai migliori modelli di coding, prova [OpenCode Console](/console).

Puoi anche provare [OpenCode Go](/console/go), un abbonamento da $10/mese che ti dà accesso ai migliori modelli di coding.

## Personalizza

Personalizza OpenCode modificando il file di configurazione ([OpenCode config](/config)), [caricando plugin](/plugins), [collegando server MCP](/mcp-servers) o [creando comandi](/commands).
