title: "Atalhos"
description: "Personalize os atalhos da CLI do OpenCode em cli.json e consulte o ID e o atalho padrão de cada comando."
---

Personalize os atalhos em `cli.json`:

```json title="cli.json"
{
  "keybinds": {
    "leader": "ctrl+space",
    "command.palette.show": "ctrl+k",
    "app.exit": ["ctrl+c", "ctrl+d"],
    "app.debug": false
  },
  "leader": {
    "timeout": 1500
  }
}
```

Use uma string para uma tecla:

```json
{
  "keybinds": {
    "command.palette.show": "ctrl+k"
  }
}
```

Separe alternativas com vírgulas:

```json
{
  "keybinds": {
    "app.exit": "ctrl+c,ctrl+d"
  }
}
```

Desative um atalho com `"none"` ou `false`:

```json
{
  "keybinds": {
    "app.debug": "none",
    "help.show": false
  }
}
```

Use um objeto para o comportamento de evento:

```json
{
  "keybinds": {
    "prompt.paste": {
      "key": "ctrl+v",
      "preventDefault": false
    }
  }
}
```

`leader` é `ctrl+x` por padrão. `<leader>` em outro atalho se refere a essa tecla.

```json
{
  "keybinds": {
    "leader": "ctrl+space",
    "model.list": "<leader>m"
  },
  "leader": {
    "timeout": 2000
  }
}
```

IDs de comando desconhecidos são ignorados.

## Mini

O comando `app.clear` só funciona em [`opencode mini`](/cli). Pressione `ctrl+l` para limpar a parte visível da tela e exibir
o prompt de novo. O terminal preserva o histórico de rolagem.

```json title="cli.json"
{
  "keybinds": {
    "app.clear": "ctrl+l"
  }
}
```

| ID          | Padrão  | Descrição      |
| ----------- | -------- | ---------------- |
| `app.clear` | `ctrl+l` | Limpar a tela |

## Visualizador de Diff

Pressione `d` (`diff.switch_source`) para escolher **All**, **Committed**, **Uncommitted** ou **Last turn** (dentro de uma sessão), ou selecione **Base**
para mudar o branch de comparação. A TUI mantém as escolhas até você sair. Defina o escopo inicial com [`diffs.source` em `cli.json`](/cli/config#diffs).

Rolagem, paginação e atalhos de início e fim sempre controlam o diff. Não há troca de foco por teclado: clique nos arquivos para abri-los, clique nas pastas para expandi-las ou recolhê-las, e use a roda do mouse para rolar a árvore de arquivos.

Use `n` / `p` ou `alt+down` / `alt+up` (Option no macOS) para navegar entre arquivos. No visualizador de Diff, os atalhos Alt alternam entre arquivos, não entre abas de sessão.

Pressione `m` para marcar um arquivo como revisado e recolher seu patch. Na visualização de todos os arquivos, pressione `m` de novo
para desmarcar o arquivo e reabrir o patch. Na visualização de um único arquivo, marcar como revisado abre automaticamente o próximo arquivo,
mas a lista não volta ao início quando você chega ao último. Desmarcar um arquivo não muda o arquivo exibido.

Clique com o botão direito em um arquivo na barra lateral ou no cabeçalho do diff dele para **Mark complete** (ou **Mark incomplete**). Isso muda o mesmo estado de revisão que `m`. Concluir outro arquivo pelo menu não o seleciona nem avança o arquivo que está sendo lido.

As alternativas com Shift de `diff.help` dão suporte a terminais que informam o modificador Shift quando você pressiona `?`.
