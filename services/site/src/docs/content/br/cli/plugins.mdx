---
title: "Plugins da CLI"
description: "Carregue plugins da TUI na CLI a partir da configuração do OpenCode. Adicione plugins exclusivos da CLI e suas opções em cli.json."
---

A CLI carrega automaticamente os plugins configurados em `opencode.json(c)` que disponibilizam um componente para a TUI. Para saber como
criar plugins, consulte [Criar plugins](/build/plugins). Você não precisa adicionar o mesmo pacote a `cli.json`. A CLI
obtém a lista de plugins ativos do servidor OpenCode conectado, então isso também funciona quando o servidor é remoto.

Use `cli.json` para plugins exclusivos da CLI. Esses plugins rodam localmente no terminal e continuam ativos quando a CLI se conecta
a um servidor remoto:

```json title="cli.json"
{
  "plugins": [
    "opencode.example",
    "opencode.example@1.0.0",
    "@example/opencode-tui",
    "@example/opencode-tui@1.0.0",
    "./plugins/status",
    "../plugins/status",
    "/home/user/plugins/status",
    "file:///home/user/plugins/status"
  ]
}
```

As entradas são processadas em ordem. Prefixe um ID ou curinga com `-` para desativar os plugins correspondentes:

```json title="cli.json"
{
  "plugins": ["*", "-opencode.notifications", "-team.*"]
}
```

Para definir as opções de um plugin, use um objeto:

```json title="cli.json"
{
  "plugins": [
    {
      "package": "@example/opencode-tui",
      "options": {
        "compact": true
      }
    }
  ]
}
```

O OpenCode também descobre plugins no diretório de configuração global e nos diretórios `.opencode` do projeto. Cada plugin usa
a mesma estrutura de um pacote publicado, com os pontos de entrada do servidor e da TUI juntos.

```text title="Plugin discovery paths"
<global-config>/plugins/status/index.ts
<global-config>/plugins/status/tui.ts
<project>/.opencode/plugins/status/index.ts
<project>/.opencode/plugins/status/tui.ts
```

Os plugins descobertos podem importar `@opencode/plugin/tui` diretamente; o OpenCode resolve o pacote em tempo de execução. Consulte
[Criar plugins de TUI](/build/plugins/cli) para ver exemplos.
