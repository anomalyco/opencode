---
title: "Criar com o OpenCode"
description: "Desenvolva com o OpenCode usando plugins, o cliente TypeScript para a API HTTP ou o SDK para integrar o OpenCode à sua aplicação."
---

Milhões de pessoas usam o OpenCode todos os dias. Aproveite essa base para criar suas próprias
aplicações, integrações e experiências com agentes sem precisar começar do zero.

Também oferecemos APIs Effect para [plugins](/build/plugins/effect),
[clientes](/build/client/effect) e [apps incorporados](/build/sdk/effect).

<CardGroup cols={1}>
  <Card title="Extend OpenCode" href="/build/plugins">
    Crie plugins que adicionam ferramentas, integrações, comandos, agentes e comportamento personalizado, mantendo o restante do OpenCode
    intacto.
  </Card>
  <Card title="Run it as a server" href="/build/client">
    Conecte-se ao OpenCode com o mesmo cliente usado pela TUI e pelo app desktop e construa qualquer interface, fluxo de trabalho ou
      experiência com agentes a partir dessa base.
  </Card>
  <Card title="Embed it" href="/build/sdk">
    Incorpore o OpenCode diretamente na sua aplicação e construa um agente, uma interface ou um produto para desenvolvedores totalmente personalizado
      com essa base.
  </Card>
</CardGroup>
