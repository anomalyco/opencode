---
title: "RPC de plugin Effect"
description: "Exponha os métodos e eventos de um plugin Effect como Effects e Streams tipados."
---

Os plugins Effect podem expor métodos e eventos que retornam Effects e Streams
tipados.

## Definir

Use `Rpc.define` com Effect Schema para definir o RPC.

```ts title="src/rpc.ts"
import { Rpc } from "@opencode/plugin/rpc"
import { Schema } from "effect"

export const Acme = Rpc.define({
  id: "acme",
  methods: {
    search: {
      input: Schema.Struct({ query: Schema.String }),
      output: Schema.Struct({ text: Schema.String }),
      errors: {
        not_found: Schema.Struct({ query: Schema.String }),
      },
    },
  },
  events: {
    updated: {
      schema: Schema.Struct({ itemID: Schema.String, text: Schema.String }),
    },
  },
})
```

### Validação

O Effect Schema valida valores e infere os tipos TypeScript deles.

```ts
input: Schema.Struct({ query: Schema.String })
```

JSON Schema e Standard Schema também são compatíveis.

### Entrada e saída

Use `input` para o argumento do método e `output` para o valor de retorno. Omita
o campo correspondente quando não houver valor.

```ts
search: {
  input: Schema.Struct({ query: Schema.String }),
  output: Schema.Struct({ text: Schema.String }),
}
```

### Erros

Adicione falhas esperadas a `errors`. Cada chave vira o `type` do erro.

```ts
errors: {
  not_found: Schema.Struct({ query: Schema.String }),
}
```

### Eventos

Adicione eventos ao mapa `events` de nível superior. Os dados de evento precisam ser um objeto.

```ts
events: {
  updated: {
    schema: Schema.Struct({ itemID: Schema.String, text: Schema.String }),
  },
}
```

## Implementar

Registre a implementação no Effect do plugin:

```ts title="src/index.ts"
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"
import { Acme } from "./rpc.js"

export default Plugin.define({
  id: "acme-effect-plugin",
  effect: (ctx) =>
    Effect.gen(function* () {
      const registration = yield* ctx.rpc.register(Acme, {
        search: ({ query }, context) =>
          findText(query).pipe(
            Effect.flatMap((text) =>
              text
                ? Effect.succeed({ text })
                : Effect.fail(context.error("not_found", "Result not found", { query })),
            ),
          ),
      })

      const acme = ctx.rpc(Acme)
      const result = yield* acme.search({ query: "hello" })

      yield* registration.events.emit("updated", { itemID: "item-1", text: result.text })
    }).pipe(Effect.orDie),
})
```

O mapa de erros vira o tipo de erro do Effect de cada método. Use
`context.error(...)` para criar um erro declarado.

## Chamar

Depois que o RPC está registrado, ele pode ser chamado por HTTP ou por outro plugin.

### HTTP

Crie o cliente Effect e depois crie o subcliente RPC:

```ts
import { OpenCode } from "@opencode/client/effect"
import { Effect } from "effect"
import { FetchHttpClient } from "effect/http"
import { Acme } from "opencode-acme-plugin/rpc"

const program = Effect.gen(function* () {
  const client = yield* OpenCode.make({ baseUrl: "http://localhost:4096" })
  const acme = client.rpc(Acme)
  return yield* acme.search({ query: "hello" })
})

const result = await Effect.runPromise(program.pipe(Effect.provide(FetchHttpClient.layer)))
```

### Plugin

Outro plugin Effect pode criar um subcliente local a partir do contexto dele:

```ts
import { Effect } from "effect"

effect: (ctx) =>
  Effect.gen(function* () {
    const acme = ctx.rpc(Acme)
    const result = yield* acme.search({ query: "hello" })
    yield* Effect.logInfo(result.text)
  }).pipe(Effect.orDie)
```

### Assinar

Os eventos RPC são Streams. Assine pelo nome do evento e execute o Stream em uma fibra
com escopo:

{/* prettier-ignore */}
```ts
import { Effect, Stream } from "effect"

const acme = ctx.rpc(Acme)

yield* acme.events.subscribe("updated").pipe(
  Stream.runForEach((event) => Effect.logInfo(event.data.text)),
  Effect.forkScoped,
)
```

As assinaturas só entregam eventos em tempo real e são encerradas quando o consumo do Stream é interrompido.
