OpenCode é um agente de codificação de código aberto. Use pela interface de terminal, pelo app desktop ou pelo app web.

O pacote npm usa um script de pós-instalação para escolher o binário nativo `opencode` da sua plataforma. Os comandos do Bun e do pnpm liberam explicitamente o script necessário; o Vite+ não exige nenhuma flag adicional. O comando do mise exige mise 2026.10.9 ou mais recente; versões anteriores instalam o OpenCode 1.

Gerenciadores de pacotes do Windows não são compatíveis.


Baixe o binário independente da CLI para sua plataforma.

- **macOS:** [Apple silicon](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-arm64.zip) · [Intel](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-x64.zip) · [Intel (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-x64-baseline.zip)
- **Windows:** [ARM64](https://opencode.ai/update/api/latest/cli/opencode/opencode-windows-arm64.zip) · [x64](https://opencode.ai/update/api/latest/cli/opencode/opencode-windows-x64.zip) · [x64 (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-windows-x64-baseline.zip)
- **Linux (glibc):** [ARM64](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-arm64.tar.gz) · [x64](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-x64.tar.gz) · [x64 (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-x64-baseline.tar.gz)
- **Linux (musl):** [ARM64](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-arm64-musl.tar.gz) · [x64](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-x64-musl.tar.gz) · [x64 (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-x64-baseline-musl.tar.gz)

## Web

Acesse a interface web do OpenCode com o comando `opencode pair`.

```bash
$ opencode pair

  Open a link to connect. Links work once and expire in 5 minutes.

  http://127.0.0.1:49374/auth/connect/...
```

## Docker

As imagens Docker usam tags de versão, como `ghcr.io/anomalyco/opencode:2.0.0`. Veja como executar o servidor em um contêiner
na seção [Docker](/cli/web#docker).

## Conectar

O OpenCode tem suporte integrado a muitos provedores de LLM. Você pode se conectar a eles
diretamente [na TUI](/cli/providers) com `/connect`.

Consulte [Provedores](/providers) para configurar provedores personalizados.

Se você quiser acesso fácil aos melhores modelos de codificação, experimente o
[OpenCode Console](/console).

Você também pode experimentar o [OpenCode Go](/console/go), uma assinatura de
$10/mês que dá acesso aos melhores modelos de codificação.

---

## Personalizar

Para personalizar o OpenCode, edite [OpenCode config](/config), [carregue plugins](/plugins), [conecte servidores
MCP](/mcp-servers) ou [crie comandos](/commands). Para temas e atalhos da interface de terminal, consulte as [configurações
da CLI](/cli/config).
