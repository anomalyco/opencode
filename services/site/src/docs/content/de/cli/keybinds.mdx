description: "Passe die Tastenbelegung der OpenCode CLI in cli.json an und schlage die ID und Standardbindung jedes Befehls nach."
---

Passe Bindungen in `cli.json` an:

```json title="cli.json"
{
  "keybinds": {
    "leader": "ctrl+space",
    "command.palette.show": "ctrl+k",
    "app.exit": ["ctrl+c", "ctrl+d"],
    "app.debug": false
  },
  "leader": {
    "timeout": 1500
  }
}
```

Nutze einen String für eine Taste:

```json
{
  "keybinds": {
    "command.palette.show": "ctrl+k"
  }
}
```

Trenne Alternativen mit Kommas:

```json
{
  "keybinds": {
    "app.exit": "ctrl+c,ctrl+d"
  }
}
```

Deaktiviere eine Bindung mit `"none"` oder `false`:

```json
{
  "keybinds": {
    "app.debug": "none",
    "help.show": false
  }
}
```

Nutze ein Objekt für Ereignisverhalten:

```json
{
  "keybinds": {
    "prompt.paste": {
      "key": "ctrl+v",
      "preventDefault": false
    }
  }
}
```

`leader` ist standardmäßig `ctrl+x`. `<leader>` in einer anderen Bindung verweist auf diese Taste.

```json
{
  "keybinds": {
    "leader": "ctrl+space",
    "model.list": "<leader>m"
  },
  "leader": {
    "timeout": 2000
  }
}
```

Unbekannte Befehls-IDs werden ignoriert.

## Mini

Der Befehl `app.clear` funktioniert nur in [`opencode mini`](/cli). Drücke `ctrl+l`, um den sichtbaren Bildschirm zu leeren und den Prompt
erneut zu zeichnen. Das Terminal behält den Scrollback.

```json title="cli.json"
{
  "keybinds": {
    "app.clear": "ctrl+l"
  }
}
```

## Diff-Viewer

Drücke `d` (`diff.switch_source`), um **All**, **Committed**, **Uncommitted** oder **Last turn** (innerhalb einer Session) zu wählen, oder wähle **Base**, um den Vergleichsbranch zu ändern. Auswahlen bleiben bis zum Beenden der TUI gemerkt. Setze den anfänglichen Umfang mit [`diffs.source` in `cli.json`](/cli/config#diffs).

Scrollen, Blättern und Start-/Ende-Tastenkürzel steuern immer den Diff. Es gibt keinen Tastatur-Fokuswechsel: Klicke Dateien an, um sie zu öffnen, Ordner, um sie ein- oder auszuklappen, und nutze das Mausrad, um den Dateibaum zu scrollen.

Nutze `n` / `p` oder `alt+down` / `alt+up` (Option unter macOS), um zwischen Dateien zu wechseln. Im Diff-Viewer navigieren die Alt-Tastenkürzel zwischen Dateien statt zwischen Session-Tabs.

Drücke `m`, um eine Datei als geprüft zu markieren und ihren Patch-Body einzuklappen. In der Ansicht aller Dateien drücke erneut `m`, um die Markierung zu entfernen und den Patch wieder zu öffnen. Die Einzeldateiansicht springt beim Markieren automatisch zur nächsten Datei, bleibt aber bei der letzten Datei, statt umzulaufen. Das Aufheben der Markierung springt nie weiter.

Klicke mit der rechten Maustaste auf eine Datei in der Seitenleiste oder ihre Diff-Überschrift für **Mark complete** (oder **Mark incomplete**). Das ändert denselben Prüfstatus wie `m`. Eine andere Datei über ihr Menü abzuschließen, wählt sie nicht aus und springt nicht von der aktuell gelesenen Datei weg.

Die Alternativen mit Shift für `diff.help` unterstützen Terminals, die bei `?` auch die gedrückte Shift-Taste melden.
