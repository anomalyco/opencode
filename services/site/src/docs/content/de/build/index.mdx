Millionen Menschen nutzen OpenCode jeden Tag. Entwickle darauf aufbauend eigene Anwendungen, Integrationen und
Angebote rund um Agenten, ohne bei null anzufangen.

Wir bieten außerdem Effect-APIs für [Plugins](/build/plugins/effect),
[Clients](/build/client/effect) und [eingebettete Apps](/build/sdk/effect).

  <Card title="Extend OpenCode" href="/build/plugins">

    OpenCode unverändert bleibt.
  </Card>
  <Card title="Run it as a server" href="/build/client">

    darauf aufbauend eigene Oberflächen, Workflows oder Agenten-Anwendungen.
  </Card>
  <Card title="Embed it" href="/build/sdk">
    Bette OpenCode direkt ein und entwickle darauf aufbauend einen maßgeschneiderten Agenten, eine eigene
    Oberfläche oder ein Produkt für Entwickler.
  </Card>
</CardGroup>
