OpenCode — агент для программирования с открытым исходным кодом. Он доступен в виде терминального интерфейса, десктопного приложения и веб-приложения.

Пакет npm выбирает нативный бинарник `opencode` для вашей платформы с помощью скрипта postinstall. Команды для Bun и pnpm явно разрешают запуск этого скрипта, а Vite+ не требует дополнительного флага. Для команды mise нужна версия 2026.10.9 или новее: более ранние версии устанавливают OpenCode 1.

Менеджеры пакетов Windows не поддерживаются.


Скачайте отдельный бинарник CLI для вашей платформы.

- **macOS:** [Apple silicon](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-arm64.zip) · [Intel](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-x64.zip) · [Intel (базовая сборка)](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-x64-baseline.zip)
- **Windows:** [ARM64](https://opencode.ai/update/api/latest/cli/opencode/opencode-windows-arm64.zip) · [x64](https://opencode.ai/update/api/latest/cli/opencode/opencode-windows-x64.zip) · [x64 (базовая сборка)](https://opencode.ai/update/api/latest/cli/opencode/opencode-windows-x64-baseline.zip)
- **Linux (glibc):** [ARM64](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-arm64.tar.gz) · [x64](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-x64.tar.gz) · [x64 (базовая сборка)](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-x64-baseline.tar.gz)
- **Linux (musl):** [ARM64](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-arm64-musl.tar.gz) · [x64](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-x64-musl.tar.gz) · [x64 (базовая сборка)](https://opencode.ai/update/api/latest/cli/opencode/opencode-linux-x64-baseline-musl.tar.gz)

## Веб

Откройте веб-интерфейс OpenCode командой `opencode pair`.

```bash
$ opencode pair

  Open a link to connect. Links work once and expire in 5 minutes.

  http://127.0.0.1:49374/auth/connect/...
```

## Docker

Теги Docker-образов содержат номер версии, например `ghcr.io/anomalyco/opencode:2.0.0`.

## Подключение

OpenCode поддерживает множество провайдеров LLM из коробки. Подключиться к ним можно напрямую [в TUI](/cli/providers) с помощью `/connect`.

Как настроить собственных провайдеров, см. в разделе [Провайдеры](/providers).

Если вам нужен простой доступ к лучшим моделям для программирования, попробуйте
[OpenCode Console](/console).

Также можно попробовать [OpenCode Go](/console/go) — подписку за $10 в месяц
с доступом к лучшим моделям для программирования.
