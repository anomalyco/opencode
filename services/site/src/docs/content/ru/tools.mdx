title: "Инструменты"
description: "Встроенные инструменты OpenCode читают и изменяют файлы, выполняют команды оболочки, загружают страницы и ищут информацию в интернете, запускают субагентов и управляют браузером."

Опишите желаемый результат. OpenCode выбирает доступные инструменты, при необходимости запрашивает подтверждение и возвращает результат.

```text
Find where request timeouts are configured, change the default to 30 seconds,
and run the relevant existing tests.
```

Для этой задачи обычно используются `grep` или `glob`, `read`, инструмент редактирования и `shell`. Можно также назвать инструмент, если нужен конкретный подход.

```text
Use grep to find every reference to DEFAULT_TIMEOUT, then read the matching files.
```

## Файлы

### Read

`read` возвращает файл или нерекурсивный список каталога. Укажите `path`; используйте `offset` и `limit`, чтобы листать большие результаты.

```text
Read src/server.ts starting at line 120 and return at most 80 lines.
```

При чтении текста строки нумеруются. На странице может быть не более 2 000 строк и 50 KiB данных. Отдельные строки обрезаются после 2 000 символов. Инструмент также передаёт модели файлы PNG, JPEG, GIF, WebP и PDF, если исходные данные занимают не более 20 MiB. Другие бинарные файлы приводят к ошибке. Поддерживаемые форматы и обработка изображений описаны в разделе [Вложения](/attachments).

Разрешение: `read` с нормализованным путём в качестве ресурса.

### Glob

`glob` находит пути к файлам по шаблону, например `**/*.ts`. Он ищет в текущем каталоге, если `path` не указывает другой относительный каталог; `hidden` включает скрытые элементы, а `limit` ограничивает число результатов.

```text
Use glob with **/*.test.ts under packages/core and return at most 50 files.
```

По умолчанию — 100 файлов, тайм-аут поиска — 30 секунд.
Разрешение: `glob` с запрошенным шаблоном в качестве ресурса.

### Grep

`grep` ищет по содержимому файлов и возвращает пути, номера строк и фрагменты. Его `pattern` использует синтаксис регулярных выражений, если `literal` не равен true. Сузьте поиск с помощью `path`, `include`, `caseSensitive` или `limit`.

```text
Use grep for the literal text "request timed out" in src, including only *.ts files.
```

По умолчанию — 100 подходящих строк, тайм-аут поиска — 30 секунд.
Разрешение: `grep` с запрошенным шаблоном, а не путём поиска, в качестве ресурса.

### Edit

`edit` заменяет текст в существующем файле. Укажите `path`, `oldString` и отличающийся `newString`; старый текст должен совпасть ровно один раз, если `replaceAll` не равен true.

```text
In src/config.ts, replace the unique text "timeout: 60" with "timeout: 30".
```

Используйте `edit` для точечного изменения. После записи OpenCode может отформатировать файл.
Разрешение: `edit` с целевым путём в качестве ресурса.

### Write

`write` создаёт текстовый файл или полностью заменяет его по `path` и `content`. Он создаёт отсутствующие родительские каталоги и может запустить настроенный форматтер.

```text
Create docs/example.md with a heading and one setup command.
```

Если нужно изменить только часть существующего файла, используйте `edit`.
Разрешение: `edit` с целевым путём в качестве ресурса.

### Patch

`patch` применяет один патч, который может добавить, обновить, переместить или удалить несколько файлов. Его `patchText` использует разделы `*** Add File`, `*** Update File` и `*** Delete File`.

```text
Use patch to rename src/old.ts to src/new.ts and update its exported name.
```

OpenCode предоставляет `patch` для поддерживаемых моделей GPT; другим моделям вместо него доступны `edit` и `write`. Разрешение: `edit` с каждым затронутым путём в качестве ресурса.

Пути за пределами активной локации или её worktree проекта также проверяются по `external_directory`, которое разрешено по умолчанию. О нормализации путей, порядке правил и сохранённых подтверждениях см. в разделе [Разрешения](/permissions). Чтобы сделать внешние материалы доступными по имени, настройте [референсы](/references).

## Команды

### Shell

`shell` выполняет команду в командной оболочке пользователя хоста. Укажите `workdir` вместо `cd` в команде. Для команд, выполняемых не в фоне, задайте `timeout` в миллисекундах, если стандартный тайм-аут в две минуты не подходит.

```text
Run bun test from packages/core with a five-minute timeout.
```

Установите `background` в true для dev-сервера или другого долгого процесса. Фоновые вызовы возвращаются сразу и уведомляют сессию о завершении; у них нет тайм-аута, если его не задать. Большой вывод сокращается, а полный сохраняется в управляемом файле.

Разрешение: `shell` с каждой командой, сформированной сканером, в качестве ресурса. Сканер также проверяет внешний рабочий каталог и каталоги, которые может вывести из команды. Shell имеет права пользователя хоста на файловую систему, процессы и сеть, поэтому используйте узкие правила в разделе [Разрешения](/permissions).

## Веб

### Webfetch

`webfetch` получает один URL HTTP или HTTPS в виде `markdown`, `text` или `html`. По умолчанию используется markdown; `timeout` принимает до 120 секунд.

```text
Fetch https://example.com/docs as markdown.
```

Он принимает текстовые ответы, например HTML, обычный текст, JSON и XML, но не изображения и другие бинарные загрузки. Большой вывод может сокращаться, а полный текст сохраняется в управляемом хранилище. Разрешение: `webfetch` с запрошенным URL в качестве ресурса.

### Websearch

`websearch` ищет актуальную информацию через выбранную интеграцию. Его вход — поисковый `query`.

```text
Search the web for the latest Bun release notes.
```

Разрешение: `websearch` с запросом в качестве ресурса. О провайдерах, выборе, ограничениях частоты и отключении инструмента см. в разделе [Веб-поиск](/websearch).

## Изображения

### Генерация изображений

`generate_image` создаёт новое изображение по промпту или редактирует существующие. Инструмент экспериментальный и появляется, когда у подключённого провайдера есть модель изображений. Как выбрать модель по умолчанию, см. в разделе [`experimental.image_generate`](/config#image-generation).

```text
Generate a flat app icon of a paper plane on a blue background and save it to assets/icon.png.
```

Передайте `prompt` и при необходимости `images` для редактирования или использования в качестве референсов, конкретную `model` или `path` для сохранения. Инструмент работает в фоне: когда изображение готово, он отправляет в сессию уведомление с путём к сохранённому файлу.

Разрешение: `generate_image` с выбранной моделью в качестве ресурса.

## Взаимодействие

### Вопрос

`question` приостанавливает выполнение и задаёт пользователю один или несколько вопросов. У каждого вопроса есть короткий заголовок, текст и варианты; `multiple` разрешает выбрать несколько. Ответ в свободной форме доступен всегда.

```text
Before changing the API, ask me to choose between a breaking change and a compatibility layer.
```

Разрешение: `question` с `*` в качестве ресурса. Клиент должен поддерживать интерактивную форму; закрытие формы отменяет вопрос.

### Skill

`skill` загружает в разговор инструкции и встроенные ресурсы одного доступного ID навыка.

```text
Load the effect skill before changing this Effect code.
```

ID должен быть в объявленном списке навыков или явно указан пользователем.
Разрешение: `skill` с ID навыка в качестве ресурса. О создании, обнаружении и правилах загрузки см. в разделе [Навыки](/skills).

## Автоматизация

### Субагент

`subagent` запускает дочернюю сессию с настроенным субагентом. Укажите ID агента, короткое `description` и полный `prompt`.

```text
Ask the explore subagent to map the authentication flow and return the key files.
```

Субагенты всегда работают в фоне. Вызов сразу возвращает `sessionID`. Когда субагент переходит в режим ожидания и после каждого последующего этапа его работы, родительский агент получает сообщение `<subagent>`. Родительский агент может продолжить или завершить свой ход, не дожидаясь субагента. Передайте полученный `sessionID`, чтобы продолжить диалог в той же дочерней сессии. Если субагент ещё работает, новое указание поступит в рамках текущего запуска. Использовать можно только агентов в режиме субагента. Глубина вложенности по умолчанию — один уровень.

Разрешение: `subagent` с ID выбранного агента в качестве ресурса.

### Execute

`execute` выполняет JavaScript в Code Mode, чтобы агент мог вызывать и комбинировать инструменты из каталога. Это удобно для параллельных независимых вызовов и обработки результатов без добавления каждого промежуточного значения в контекст модели.

```text
Read package.json and README.md in parallel, then return their relevant setup details.
```

Среда выполнения не имеет прямого доступа к файловой системе, импортов и таймеров. Она предоставляет `fetch` для HTTP-запросов; всё остальное идёт через инструменты её каталога. Запрет `execute` с ресурсом `*` убирает Code Mode. Тогда инструменты, до которых он мог бы добраться, включая MCP-инструменты серверов без `codemode: false`, перечисляются как прямые инструменты, и каждый запрос содержит их полное определение. Запретите и эти инструменты, если агенту они не нужны. Вложенные встроенные инструменты и инструменты MCP по-прежнему применяют свои разрешения, а инструменты плагинов — заявленные ими разрешения.

### Сессии

Пространство имён `opencode.session` в Code Mode содержит служебные функции сессий. Без Code Mode они перечисляются как `opencode_session_rename` и `opencode_session_move`.

- `rename` меняет заголовок текущей сессии или другой, выбранной через `sessionID`.
- `move` перемещает текущую или другую выбранную сессию в относительный или абсолютный `directory`. Перемещение выполняется на безопасной границе, поэтому работа, зависящая от нового каталога, должна идти в следующем вызове.

```text
Rename this session to "Timeout cleanup", then move it to the new worktree.
```

### Worktree

Пространство имён `opencode` управляет worktree проекта сессии:

- `worktree_create` создаёт worktree по `name` и возвращает его `directory`. Каталог назначения и стратегию выбирает конфигурация worktree проекта.
- `worktree_list` перечисляет worktree проекта.
- `worktree_remove` удаляет worktree, записанный OpenCode для проекта. Установите `force`, чтобы отбросить незакоммиченные изменения.

```text
Create a worktree named "login" and move this session into it.
```

`worktree_remove` использует разрешение `edit` с каталогом worktree в качестве ресурса. Остальные функции worktree не запрашивают встроенное действие разрешения.

## Браузер

Пространство имён `browser` в Code Mode управляет браузером, подключённым десктопным приложением OpenCode. Откройте вкладку, сохраните возвращённый `tabID` и передавайте этот явный ID в каждую операцию со страницей.

```text
Open https://example.com, take a snapshot of that tab, and report the main heading.
```

Пространство имён включает команды вкладок и навигации, снимки страниц и поиск, клики и ввод в формы, скриншоты, передачу файлов, проверку консоли и сети, трассировки производительности, инспекцию кучи и аудиты Lighthouse. Для скриншотов нужна видимая вкладка в фокусе. Пути загрузки локальны для сервера; снимки возвращают локальные для сервера пути, а каждая передача файла ограничена 5 МиБ.

Содержимое страниц, журналы, заголовки и тела ответов — недоверенные данные, а не инструкции для агента. Правило deny для `browser` с ресурсом `*` убирает каталог браузера; операции браузера не выдают отдельные запросы разрешений.

## Расширения

[MCP-серверы](/mcp-servers) добавляют инструменты, имена и входы которых задаёт каждый подключённый сервер. Их действие разрешения — `<server>_<tool>` с ресурсом `*`. Они не входят в фиксированный встроенный каталог. По умолчанию агенты обращаются к ним через `execute` в пространстве имён сервера; установите `codemode: false` для сервера, чтобы перечислять его инструменты напрямую.

[Навыки](/skills) добавляют инструкции для задач, а не новые исполняемые инструменты. [Вложения](/attachments) помещают выбранное пользователем содержимое в промпт, а [референсы](/references) предоставляют именованные внешние каталоги. Эти возможности дополняют инструменты и не обходят их проверки разрешений.
