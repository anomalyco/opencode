Сама Console бесплатна для команд любого размера: платы за участников нет. Вы платите только за фактическое использование: средства списываются с общего предоплаченного баланса рабочего пространства. Владельцы и администраторы управляют оплатой в **Settings › Billing**.

Плату за запросы через [ваших провайдеров](/console/providers) взимают сами провайдеры, а не Console.

## Добавление способа оплаты

1. Откройте **Settings › Billing**.
2. В разделе **Payment methods** нажмите **Add**.
3. Выберите способ и завершите настройку в Stripe.

Поддерживаемые способы оплаты:

- Card
- Link
- Alipay
- UPI
- WeChat Pay

В меню **⋯ › Make default** выберите способ оплаты для автоматических списаний. Если удалить этот способ, автопополнение и продление Go могут перестать работать.

## Добавление кредитов

1. В разделе **Credits** нажмите **Add credits**.
2. Выберите $10, $50 или $100 либо выберите **Other** и введите сумму.
3. Выберите способ оплаты и нажмите **Confirm and pay**.

К сумме платежа прибавляется комиссия 4,6% + $0.31. При пополнении на $50 вы заплатите $52.61, а на баланс поступят все $50.

## Автопополнение

Автопополнение срабатывает, когда остаток кредитов становится слишком мал.

1. В разделе **Auto-recharge** нажмите **Add rule**.
2. Укажите порог срабатывания и сумму пополнения.
3. Нажмите **Save**.

При автопополнении сумма вместе с комиссией списывается с помощью способа оплаты по умолчанию. Если платёж не проходит, автопополнение отключается. Чтобы возобновить его, настройте его заново.

## Проверка баланса

Карточка **Billing** на **Activity** показывает баланс владельцам и администраторам и открывает **Settings › Billing**.

Кнопка **Billing** в верхней панели рабочего пространства или клавиша `B` открывает панель с текущими лимитами Go, балансом кредитов и статистикой использования. Владельцы и администраторы видят баланс, статистику использования и настройки автопополнения рабочего пространства; участники — только собственную статистику и лимиты.

## Когда кредиты заканчиваются

Платные запросы завершаются ошибкой HTTP `402`, когда баланс достигает нуля. Баланс никогда не становится отрицательным.

```text
Upstream request failed: Insufficient account funds
```

## Счета

Каждый платёж отображается в **Invoices** со статусом и ссылкой **Download invoice** или **View receipt**.

| Запись             | Когда создаётся                            |
| ------------------ | ------------------------------------------ |
| Пополнение баланса | Добавление кредитов                        |
| Автоматическое пополнение | Автопополнение                       |
| Подписка Go        | Оформление Go, Go Plus или Go Teams        |
| Продление Go       | Ежемесячное продление Go                   |
| Переход на Go Plus | Переход с Go на Go Plus                    |
| Переход на Go Teams | Переход с Go или Go Plus на Go Teams      |
| Участник Go Teams  | В рабочее пространство с Go Teams добавляется участник |
| Расходы за месяц | Оплата по счёту                              |

## Оплата по счёту

Если для рабочего пространства заключён кредитный договор, вместо покупки кредитов можно оплачивать ежемесячные счета. Чтобы подключить этот способ оплаты, обратитесь в поддержку.

- Расходы засчитываются в кредитный лимит, а не списываются с предоплаченного баланса.
- Счёт за каждый месяц выставляется 1-го числа (UTC); срок оплаты — 14 дней с даты выставления.
- У неоплаченных счетов есть кнопка **Pay now**.
- Запросы завершаются ошибкой HTTP `402`, когда достигнут кредитный лимит или счёт просрочен.

## Go

Для подписок [OpenCode Go](/console/go) действуют те же способы оплаты, а платежи отображаются в общем списке счетов. Также можно [оплатить Go кредитами](/console/go#pay-with-credit). Включите **Extra Usage** на странице **Go**, чтобы после достижения лимита Go оплачивать запросы с баланса кредитов.
