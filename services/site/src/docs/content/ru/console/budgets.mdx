---
title: "Бюджеты"
description: "Ограничивайте ежемесячные расходы рабочего пространства, его участников и сервисных аккаунтов."
---

Бюджет — это лимит расходов на месяц, заданный в политике. Владельцы и администраторы управляют бюджетами в **Controls**.

## Уровни бюджетов

| Область действия политики | К чему применяется                                     |
| ----------------------- | --------------------------------------------------------- |
| Всё рабочее пространство | Совокупные расходы всех участников и сервисных аккаунтов |
| Все участники           | Каждый участник или одна общая квота для всех участников  |
| Участники с тегами      | Участники с выбранными тегами                             |
| Выбранные участники     | Конкретные участники                                      |
| Все сервисные аккаунты  | Каждый сервисный аккаунт или одна общая квота             |
| Выбранные сервисные аккаунты | Конкретные сервисные аккаунты                        |

Расходы на запрос должны укладываться во все действующие для него лимиты. Более высокий лимит не отменяет более низкий. Если бюджетов нет, расходы не ограничены.

## Бюджет рабочего пространства

Когда исчерпан общий бюджет рабочего пространства, новые запросы блокируются для всех.

1. Откройте **Controls** и нажмите **Add policy**.
2. Выберите **Entire workspace** и добавьте правило **Budget**.
3. Введите месячный лимит в USD и нажмите **Save**.

## Бюджеты участников

Выберите **All members** в политике, чтобы задать лимит на месяц для каждого участника или один общий лимит на всю группу. Чтобы ограничить действие политики, выберите отдельных участников или теги.

Чтобы задать бюджет одному человеку:

1. Откройте страницу участника в **Settings › Members**.
2. Нажмите **Create budget policy**. В редакторе политики этот участник будет уже выбран.
3. Введите сумму и нажмите **Save**.

На странице участника перечислены действующие для него политики. Если на участника распространяется и бюджет для всех участников, действуют оба лимита.

## Бюджеты сервисных аккаунтов

В **Controls** выберите **All service accounts** или **These service accounts**, добавьте правило **Budget** и задайте индивидуальную или общую месячную квоту. Политика охватывает каждый ключ, принадлежащий этим аккаунтам.

## Суммы и сброс

- Суммы указываются в долларах США, не более двух знаков после запятой.
- Бюджеты сбрасываются 1-го числа каждого месяца в 00:00 UTC.
- Бюджет `$0` блокирует все расходы, учитываемые бюджетами.
- При добавлении или изменении бюджета расходы, уже учтённые в этом месяце, не обнуляются.

## Что учитывается

По умолчанию бюджет покрывает **All spend**. Его можно сузить до выбранных моделей; тогда учитываются только они — с одной квотой на набор или отдельной квотой на каждую модель.

| Расход                                                              | Учитывается в бюджетах       |
| ------------------------------------------------------------------- | ---------------------------- |
| Платные модели Console                                              | Да                           |
| Модели [ваших провайдеров](/console/providers) с заданной ценой     | Да, по указанной цене        |
| [Веб-поиск](/console/websearch)                                     | Да, если бюджет охватывает все расходы |
| Бесплатные модели                                                   | Нет                          |
| Использование [Go](/console/go) в пределах тарифа                   | Нет                          |
| Дополнительное использование Go, оплаченное кредитами               | Да                           |

## Когда бюджет исчерпан

Новые запросы завершаются ошибкой HTTP `429`, пока бюджет не сбросится или владелец либо администратор не увеличит его. Ответ указывает на превышение бюджета политики, но не называет бюджет. Откройте запрос в **Activity › Logs**, чтобы увидеть политику, которая его заблокировала.

```text
Upstream request failed: Policy budget exceeded
```

Бюджеты проверяются при запуске запроса. Уже выполняющиеся запросы завершаются, поэтому расходы могут немного превысить лимит.

## Учёт расходов

Каждый участник видит свои расходы и лимит в **Activity**. Нажмите **My usage**, чтобы перейти в **Activity › Overview** и посмотреть сведения о бюджете и даты сброса.

Владельцы и администраторы могут перейти с графика расходов в **Activity › Usage**. В этом разделе расходы разбиты по дням, моделям и участникам. Кнопка **Export usage** скачивает итоги по дням за последние 7, 30 или 90 дней в формате CSV. Чтобы скачать тот же файл из скрипта, используйте [API экспорта статистики использования](/console/api/usage-export).
