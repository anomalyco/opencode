`GET https://opencode.ai/console/api/v2/usage/export` возвращает статистику рабочего пространства в CSV: по одной строке на
каждое сочетание даты по UTC, участника или сервисного аккаунта, провайдера и модели. Это тот же файл, который скачивает кнопка
**Export usage** в **Activity › Usage**.

```bash
curl --fail-with-body "https://opencode.ai/console/api/v2/usage/export?range=30d" \
  --header "Authorization: Bearer oc_sk_..." \
  --output usage-30d.csv
```

## Аутентификация

Передайте [API-ключ](/console/api#api-keys) как токен Bearer. Он позволяет выгружать данные того рабочего пространства, в котором был создан.

```text
Authorization: Bearer oc_sk_...
```

Ключу нужно **Usage › Read**. Ключи с **All** или **Read only** его имеют. Ограниченному ключу нужно:

```text
Permissions: Restricted
Usage:       Read
```

Используйте [ключ сервисного аккаунта](/console/api#service-accounts) для регулярных экспортов или
[личный API-ключ](/console/api#personal-api-keys) владельца либо администратора. Обычные участники не могут читать общую статистику
рабочего пространства, поэтому запросы с их ключами возвращают `403`.

## Запрос

| Параметр  | Обязателен | Значение                                                                                                              |
| --------- | ---------- | --------------------------------------------------------------------------------------------------------------------- |
| `range`   | Да         | `7d`, `30d` или `90d`.                                                                                                |
| `user_id` | Нет        | ID участника (`user_...`) или сервисного аккаунта (`svcacct_...`). Возвращает только строки этого участника или аккаунта. |

`range` задаёт число дней по UTC, включая текущий: `7d` — это текущий день и шесть предыдущих. Показатели за текущий день
обновляются до полуночи UTC.

Чтобы экспортировать использование одного сервисного аккаунта, передайте его ID из столбца `user_id` более раннего
экспорта:

```bash
curl --fail-with-body "https://opencode.ai/console/api/v2/usage/export?range=7d&user_id=svcacct_01JD8Z4Q2W7N3K5M6P9R0S1T2V" \
  --header "Authorization: Bearer oc_sk_..."
```

Если указанный ID не найден в рабочем пространстве, ответ содержит только строку заголовка.

## Ответ

Успешный запрос возвращает `200` с `Content-Type: text/csv; charset=utf-8`. Первая строка — заголовок. Далее идут
строки, начиная с самого нового дня.

```csv
day,user_type,user_id,user_name,provider,model,requests,input_tokens,output_tokens,cache_read_tokens,cache_write_5m_tokens,cache_write_1h_tokens,cost_micro_cents,cost_usd
2026-11-24,service_account,svcacct_01JD8Z4Q2W7N3K5M6P9R0S1T2V,CI Pipeline,opencode,claude-sonnet-5-5,412,1830211,96402,5120330,210044,0,1512334800,15.123348
2026-11-24,member,user_01JC2X7Y8Z9A0B1C2D3E4F5G6H,ada@example.com,opencode,claude-haiku-5-5,57,402118,31877,880012,0,0,214500000,2.145
2026-11-23,member,user_01JC2X7Y8Z9A0B1C2D3E4F5G6H,ada@example.com,opencode,claude-sonnet-5-5,96,711560,48210,2204118,61022,0,587000000,5.87
```

- Строки заканчиваются на `\r\n`.
- У дней без использования нет строк.
- Ответ — скачивание (`Content-Disposition: attachment; filename="usage-30d.csv"`) и никогда не кэшируется
  (`Cache-Control: private, no-store`).
- Если текст в ячейке начинается с `=`, `+`, `-` или `@`, к нему добавляется `'`, чтобы редактор таблиц не воспринял его как формулу.

### Столбцы

| Столбец                 | Значение                                                                                                      |
| ----------------------- | ------------------------------------------------------------------------------------------------------------- |
| `day`                   | Дата UTC в формате `YYYY-MM-DD`.                                                                              |
| `user_type`             | `member` или `service_account`.                                                                               |
| `user_id`               | ID участника или сервисного аккаунта.                                                                         |
| `user_name`             | Почта участника или имя сервисного аккаунта. Может быть пустым.                                               |
| `provider`              | Провайдер, обслуживший запросы, например `opencode` для [OpenCode Models](/console/models).                    |
| `model`                 | ID модели.                                                                                                     |
| `requests`              | Число запросов.                                                                                                |
| `input_tokens`          | Входные токены.                                                                                                |
| `output_tokens`         | Выходные токены.                                                                                               |
| `cache_read_tokens`     | Токены, прочитанные из кэша промптов.                                                                          |
| `cache_write_5m_tokens` | Токены, записанные в кэш промптов со временем жизни 5 минут.                                                   |
| `cache_write_1h_tokens` | Токены, записанные в кэш промптов со временем жизни 1 час.                                                     |
| `cost_micro_cents`      | Стоимость целым числом микросентов. Один доллар США — `100000000`.                                             |
| `cost_usd`              | Та же стоимость в долларах США точной десятичной дробью минимум с двумя знаками, например `2.145` или `0.00`. |

### Что включается

- Все запросы участников и сервисных аккаунтов рабочего пространства к моделям.
- Запросы к бесплатным моделям и запросы участников через их собственные подписки Claude Code, Codex или OpenCode
  включаются с их токенами по нулевой стоимости.
- [Веб-поиск](/console/websearch) и другие размещённые сервисы не включаются.
- Итоги могут отставать от новых запросов примерно на минуту.

## Ограничения

- Экспорт охватывает не более 90 дней. Чтобы хранить историю дольше, сохраняйте файлы по расписанию.
- Запросы учитываются в лимите API Console — 300 запросов в минуту на аккаунт — общем с другими его эндпоинтами.
  Личные API-ключи учитываются за участником, которому принадлежат.

## Ошибки

| Статус | Значение                                                                                              |
| ------ | ----------------------------------------------------------------------------------------------------- |
| `400`  | `range` отсутствует или не `7d`, `30d`, `90d`, либо `user_id` не ID участника или сервисного аккаунта. |
| `401`  | Нет учётных данных либо ключ просрочен или отозван.                                                   |
| `403`  | У ключа нет **Usage › Read** или он принадлежит участнику, который не владелец и не администратор.    |
| `429`  | Превышен лимит частоты. Повторите после числа секунд в заголовке `Retry-After`.                       |
| `503`  | Дневные итоги ещё недоступны. Повторите запрос позже.                                                 |
