OpenCode Go даёт надёжный доступ к популярным открытым моделям для программирования с тремя месячными тарифами:

| Тариф        | Цена                                   | Включённое использование                                                   |
| ------------ | -------------------------------------- | -------------------------------------------------------------------------- |
| **Go**       | **$10/месяц**                          | Более дешёвый доступ к моделям ниже                                        |
| **Go Plus**  | **$40/месяц**                          | Более высокие лимиты использования моделей ниже                            |
| **Go Teams** | **$20 за участника в месяц**, минимум 2 участника | У каждого участника свои лимиты: для каждой модели месячный лимит на $5 выше, чем в Go |

Go работает как любой другой провайдер в OpenCode. Вы оформляете подписку OpenCode Go и получаете API-ключ. Это **совершенно необязательно**, и для использования OpenCode он не нужен.

Сервис рассчитан в первую очередь на международных пользователей и обеспечивает стабильный глобальный доступ.

## Как это работает

1. Войдите в [OpenCode Console](https://opencode.ai/console), оформите Go, Go Plus или Go Teams, добавьте платёжные данные и скопируйте API-ключ.
2. Запустите `/connect` в TUI, выберите **OpenCode Go** и вставьте API-ключ.

   ```text
   /connect
   ```

3. Запустите `/models`, чтобы выбрать модель, доступную через Go.

   ```text
   /models
   ```

<Callout>
  Подписки Go и Go Plus действуют для подписчика и API-ключей рабочего пространства. Остальные приглашённые участники
  пользуются бесплатными моделями или оплачивают запросы с общего баланса. С любого из этих двух тарифов можно в любой
  момент перейти на Go Teams с зачётом неиспользованной части месячной квоты. Go Teams действует для всех участников
  рабочего пространства и стоит $20 за участника в месяц, минимум за двоих ($40 в месяц). Следующий участник занимает
  уже оплаченное второе место. За каждого последующего участника, присоединившегося в середине платёжного периода,
  списывается $20, и он получает полную месячную квоту. На сервисные аккаунты Go Teams не распространяется.
</Callout>

См. [актуальный список моделей](https://opencode.ai/console/go#models). Он может меняться, пока мы тестируем и добавляем новые.

### Включение ограниченных моделей

На Go распространяются настройки конфиденциальности рабочего пространства. По умолчанию платные эндпоинты, использующие данные запросов для обучения, заблокированы, а для регионов выбрано **Europe & United States**. Если настройки конфиденциальности рабочего пространства ещё не сохранены, для запросов из Китая также разрешён вариант **Global**.

В **Settings › Privacy** владелец или администратор может включить:

- **DeepSeek V4.1 Flash и V4 Pro:** выберите **Global** в разделе **Regions**.
- **LongCat 2.5:** выберите **Global** в разделе **Regions**.
- **Muse Spark 1.3 Contributor и Muse Spark 1.2 Contributor:** включите **Allow paid endpoints that train on request data**.

Об условиях обучения и хранения для каждой модели см. [Конфиденциальность](#privacy).

## Оплата кредитами

Владельцы и администраторы могут оплачивать подписку Go, её продление и переход на более высокий тариф с баланса рабочего пространства. Выберите **Credit** в качестве способа оплаты при оформлении подписки или позже в **Manage subscription**. Эта настройка не связана с [Extra Usage](#usage-beyond-limits): та отвечает за оплату запросов сверх лимита.

- Полная цена списывается с баланса кредитов. Если баланса не хватает, сначала можно добавить кредиты.
- При продлении сумма списывается с баланса в конце платёжного периода. Если средств не хватает, подписка Go остаётся активной. Повторные попытки списания выполняются через 1, 3 и 7 дней после окончания периода, а также сразу после пополнения баланса до нужной суммы. Если последняя попытка не удалась, подписка прекращается.
- Если рабочее пространство использует [оплату по счёту](/console/billing#invoiced-billing), оплатить Go кредитами нельзя.
- При возврате платежа за Go, внесённого кредитами, сумма возвращается на баланс, а соответствующий период подписки завершается.

## Где можно использовать?

OpenCode Go рассчитан на [OpenCode](https://opencode.ai) и другие агенты для программирования, создающие похожие типы запросов. Трафик проверяется на злоупотребления, ухудшающие опыт других пользователей.

Ваш клиент должен:

1. Отправлять типичный трафик агента для программирования.
2. Представляться собственным user agent, например `my-coding-agent/1.0`, а не общим именем SDK или HTTP-библиотеки.
3. Отправлять стабильный ID сессии в `x-opencode-session` для каждого разговора, чтобы мы могли оптимизировать маршрутизацию и кэширование промптов.

Запросам [решений](#decision-models) и [эмбеддингов](#embedding-models) `x-opencode-session` не нужен, поэтому любой клиент, например библиотека RAG, провайдер памяти или скрипт, может вызывать их с вашим ключом Go.

О настройке Go в Claude Code, Codex, Hermes, OpenClaw, Pi и Raycast см. [Harness](/console/harnesses).

## Лимиты использования

У всех платных моделей в Go общая квота. В Go Teams у каждого участника своя квота, общая для всех моделей.

- **Лимит на 5 часов** — 20% вашей месячной квоты. Окно начинается с первого использования квоты и длится пять часов.
- **Недельный лимит** — 50% вашей месячной квоты. Он сбрасывается в понедельник в 00:00 UTC.
- Ваша **месячная квота** сбрасывается при начале нового платного периода.

Смена моделей расходует одну и ту же квоту. Если вы достигли лимита, можно использовать бесплатную модель или включить [Extra Usage](#usage-beyond-limits), чтобы тратить кредиты Console, пока квота снова не появится.

[Месячный лимит](https://opencode.ai/console/go#limits) показывает объём использования, который покрывает тариф, если весь месяц работать только с этой моделью. Например, запросы на $1.50 к модели с лимитом $15 расходуют 10% месячной квоты. Столько же расходуют запросы на $6 к модели с лимитом $60. В ответах Go поле [`opencode.allowance`](/console/api/inference#cost) показывает, какая доля квоты ушла на запрос.

[Цены за токены](https://opencode.ai/console/go#pricing) указаны за 1M токенов и одинаковы для Go, Go Plus и Go Teams.

[Модели решений](#decision-models) и [эмбеддингов](#embedding-models) идут по прайс-листу без скидки Go: их месячный лимит соответствует вашей оплате — $10 в Go и $40 в Go Plus. В Go Teams это $15, на $5 выше Go, как и на каждой модели.

**Beam Free:** бесплатно ограниченное время. Недоступно в Анголе, Беларуси, Камбодже, Китае (включая Гонконг и Макао), на Кубе, в Демократической Республике Конго, Экваториальной Гвинее, Иране, Ираке, Лаосе, Ливии, Нигерии, Северной Корее, России, Сирии, Туркменистане, Узбекистане, Венесуэле, а также в Крымском, Донецком и Луганском регионах Украины.

**Gemini 4 Argon:** скидка 50% действует до 30 ноября 2026 года.

**HungerG Free:** бесплатно ограниченное время.

### Использование сверх лимитов

Если на балансе Console есть кредиты, можно включить **Extra Usage** на странице **Go**. Тогда после исчерпания лимитов запросы не блокируются, а [оплачиваются с баланса](/console/models#pricing).

Go Teams начинает с включённым **Extra Usage**, и его можно выключить или снова включить на странице **Go**.

### Почему у некоторых моделей квота ниже

В Go включённая месячная квота зависит от модели.

Для большинства моделей мы добиваемся этого за счёт оптовых скидок и зарезервированных мощностей GPU. Затем передаём эту экономию вам в виде большей месячной квоты.

Для некоторых моделей у нас не было возможности договориться о скидке или разместить их дешевле — потому что модель новая или её публичная цена уже со скидкой.

Для таких моделей вы всё равно получаете немного больше, чем при прямой оплате провайдерам моделей; поэтому их включённая месячная квота ниже.

## Эндпоинты

Модели Go также доступны через API по адресу `https://opencode.ai/inference/go`. Для каждой модели указаны [ID, путь и пакет AI SDK](https://opencode.ai/console/go#api). В списке указан собственный API каждой модели, но с любой текстовой моделью можно работать и через другие API: Console преобразует запросы. Полный список см. в разделе [Базовые URL](/console/harnesses#base-urls).

Эти пакеты AI SDK предназначены для приложений, вызывающих Go напрямую. Чтобы использовать Go в OpenCode, подключитесь через `/connect` и задайте [модель](/models) в формате `opencode-go/<model-id>`:

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "model": "opencode-go/kimi-k3",
}
```

### Модели

Получите полный список доступных моделей и их метаданные из эндпоинта моделей:

```bash
curl https://opencode.ai/inference/go/v1/models
```

О каждом поле ответа, включая месячные лимиты Go, см. [API списка моделей](/console/api/models).

### Модели решений

Модели решений отвечают на типизированные вопросы о `state` вместо генерации текста. Отправьте тот же запрос System One, что и в [моделях Console](/console/models#jev), на `https://opencode.ai/inference/go/systemone/v1/systemone` со своим ключом Go:

```bash
curl https://opencode.ai/inference/go/systemone/v1/systemone \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jev-1.14",
    "state": "My payments have failed for three days and I am losing sales.",
    "questions": {
      "is_urgent": {
        "type": "noul",
        "instructions": "Does this request require urgent attention?"
      }
    }
  }'
```

| Модель                              | ID модели           | Вход   | Выход | Чтение кэша | Запись кэша |
| ----------------------------------- | ------------------- | ------ | ----- | ----------- | ----------- |
| Jev 1.14                            | jev-1.14            | $0.042 | Бесплатно | -       | -           |
| Gemini Decision 1                   | gemini-decision-1   | $0.10  | Бесплатно | -       | -           |
| GPT 6 Luna Decision (≤ 272K tokens) | gpt-6-luna-decision | $0.10  | Бесплатно | $0.01   | $0.125      |
| GPT 6 Luna Decision (> 272K tokens) | gpt-6-luna-decision | $0.20  | Бесплатно | $0.02   | $0.25       |

- Цены указаны за 1M токенов.
- Запросы в формате Decisions от OpenAI работают по адресу `https://opencode.ai/inference/go/openai/v1/decisions`.
- О типах вопросов см. [Jev](/console/models#jev), а об изображениях, аудио, видео и PDF в `state` — [GPT 6 Luna Decision и Gemini Decision 1](/console/models#gpt-6-luna-decision-and-gemini-decision-1).

### Модели эмбеддингов

Модели эмбеддингов превращают текст в векторы. Вызывайте их через Embeddings API OpenAI по адресу `https://opencode.ai/inference/go/openai/v1/embeddings` со своим ключом Go:

```bash
curl https://opencode.ai/inference/go/openai/v1/embeddings \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "text-embedding-3-small",
    "input": ["hello world", "goodbye"]
  }'
```

| Модель                 | ID модели              | Вход  |
| ---------------------- | ---------------------- | ----- |
| text-embedding-3-small | text-embedding-3-small | $0.02 |
| Qwen3 Embedding 8B     | qwen3-embedding-8b     | $0.01 |
| Gemini Embedding 2     | gemini-embedding-2     | $0.20 |

- Цены указаны за 1M входных токенов.
- Запрос также принимает `dimensions` и `encoding_format`. См. [Модели эмбеддингов](/console/models#embedding-models).

### Использование

Узнайте, какая доля каждого из [лимитов использования](#usage-limits) израсходована, например чтобы отобразить эти данные в своём клиенте:

```bash
curl https://opencode.ai/inference/go/v1/usage \
  -H "Authorization: Bearer <token>"
```

Используйте тот же ключ, что и для Go. В Go и Go Plus это [личный API-ключ](/console/api#personal-api-keys) подписчика или [ключ сервисного аккаунта](/console/api#service-accounts). В Go Teams это личный API-ключ любого участника.

Ответ содержит по одному счётчику на каждый лимит: `rolling` для 5-часового лимита, `weekly` и `monthly`.

```json
{
  "usage": {
    "rolling": { "status": "ok", "percent": 30, "resetsAt": "2026-11-21T15:00:00.000Z" },
    "weekly": { "status": "rate-limited", "percent": 100, "resetsAt": "2026-11-23T00:00:00.000Z" },
    "monthly": { "status": "ok", "percent": 50, "resetsAt": "2026-12-01T00:00:00.000Z" }
  }
}
```

| Поле       | Значение                                                                                                     |
| ---------- | ------------------------------------------------------------------------------------------------------------ |
| `status`   | `ok` или `rate-limited`, когда лимит исчерпан.                                                               |
| `percent`  | Израсходованная доля лимита в процентах, целое число от `0` до `100`.                                       |
| `resetsAt` | Время сброса лимита в формате ISO 8601. До начала 5-часового периода `rolling` указывает на момент через пять часов от текущего времени. |

Запросы без действующего ключа возвращают HTTP `401`. Если ключ не даёт доступа к Go, запрос возвращает HTTP `403` с указанием причины — например, если у рабочего пространства нет активной подписки Go.

```json
{ "type": "error", "error": { "type": "EntitlementError", "message": "OpenCode Go subscription required." } }
```

## Предыстория

Открытые модели заметно улучшились и теперь решают задачи программирования почти на уровне проприетарных. Обычно они обходятся намного дешевле: доступ к ним предлагают многие провайдеры, конкурируя между собой.

Однако получить надёжный доступ к ним с низкой задержкой может быть сложно. Качество и доступность провайдеров различаются.

<Callout type="tip">Мы протестировали избранную группу моделей и провайдеров, хорошо работающих с OpenCode.</Callout>

Чтобы исправить это, мы сделали несколько вещей:

1. Протестировали несколько открытых моделей и обсудили с их разработчиками, как лучше их запускать.
2. Вместе с несколькими провайдерами проверили, что модели работают у них корректно.
3. Измерили производительность сочетаний модели и провайдера и составили список, который готовы рекомендовать.

Go, Go Plus и Go Teams предоставляют доступ к этим моделям; выберите тариф, подходящий по объёму использования, или Go Teams, чтобы покрыть всю команду.

## Цели

Мы создали OpenCode Go, чтобы:

1. Сделать программирование с помощью AI **доступным** большему числу людей с недорогой подпиской.
2. Обеспечить **надёжный** доступ к лучшим открытым моделям для программирования.
3. Отобрать модели, для которых мы **проверили работу и измерили производительность** в агентах для программирования.
4. **Не привязывать** пользователей к одному провайдеру: в OpenCode можно использовать любого другого.
