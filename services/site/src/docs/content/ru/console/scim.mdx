Синхронизация каталога (SCIM 2.0) добавляет пользователей в рабочее пространство, когда вы назначаете их у поставщика удостоверений, и отзывает доступ, когда вы снимаете назначение. Роли по-прежнему настраиваются в Console.

```text
https://opencode.ai/console/scim/v2
```

## Перед началом

- Настройте [SSO](/console/sso) для рабочего пространства.
- [Подтвердите](/console/sso#verify-email-domains) каждый домен электронной почты, с которым входят ваши люди. Синхронизация
  каталога добавляет только людей на подтверждённом домене; остальных приглашайте из [Участников](/console/members).

## Создание токена

Настраивать синхронизацию каталога и создавать или отзывать её токены могут только владельцы рабочего пространства.

1. Откройте **Settings › Security** и нажмите **Set up** в разделе **Directory sync**.
2. Скопируйте **SCIM base URL** и токен. Токен показывается только один раз, поэтому сохраните его в менеджере секретов.

Ваш поставщик удостоверений отправляет токен в каждом запросе.

```text
Authorization: Bearer <token>
```

## Подключение поставщика удостоверений

### Okta

1. Добавьте приложение **SCIM 2.0 Test App (Header Auth)**.
2. Задайте базовый URL и введите `Bearer `, а затем токен в поле **API Token**.
3. Включите **Create Users**, **Update User Attributes** и **Deactivate Users**. Оставьте **Import Groups** и
   синхронизацию паролей выключенными.

### Microsoft Entra ID

1. В корпоративном приложении откройте **Provisioning** и установите режим **Automatic**.
2. Укажите базовый URL в поле **Tenant URL**, а токен — в поле **Secret Token**.
3. Назначьте пользователей и группы, затем запустите автоматическую настройку доступа.

### Другие провайдеры

Используйте приложение SCIM 2.0 с аутентификацией токеном в заголовке, направленное на базовый URL. Console
поддерживает эндпоинты `/Users` и `/Groups`.

Сначала назначьте одного пользователя для проверки. В разделе **Directory sync** статус **Connected to your identity provider** появится после
первого запроса.

## Что синхронизируется

| У поставщика удостоверений      | В Console                                                                         |
| ------------------------------- | --------------------------------------------------------------------------------- |
| Назначение человека             | Добавляется как **Member**. Существующие участники сохраняют роль.                |
| Обновление имени                | Профиль обновляется.                                                              |
| Снятие назначения или деактивация | Доступ приостанавливается, участник получает статус **Deactivated**, а созданные им API-ключи отзываются. |
| Повторное назначение            | Доступ восстанавливается. Отозванные ключи остаются отозванными.                  |
| Удаление                        | Участник удаляется из рабочего пространства. Его аккаунт и другие рабочие пространства не затрагиваются. |

- Роли и адреса электронной почты синхронизация каталога не меняет.
- Последнего владельца нельзя деактивировать или удалить.
- В рабочие пространства с подпиской [Go](/console/go) нельзя добавлять участников через синхронизацию каталога.

## Группы

Передавайте группы, чтобы отмечать их участников, например через **Push Groups** в Okta или назначение групп в Entra.
Назначьте людей до передачи их групп.

```text
Platform Admins  →  platform-admins
```

Каждая группа отмечает участников тегом с именем группы. В **Settings › Security › Group tags** можно переименовать
тег, направить несколько групп на один тег или перестать отмечать группу. Выход из группы удаляет её тег.

## Ротация токена

1. Нажмите **New token** и укажите новый токен в настройках поставщика удостоверений.
2. Дождитесь, пока для нового токена отобразится время последнего использования.
3. Отзовите старый токен.

Отзыв токена останавливает будущие обновления, но не меняет существующих участников. Удаление подключения SSO отзывает
все токены.

## SSO и синхронизация каталога

После создания токена для рабочего пространства SSO больше не [добавляет участников автоматически](/console/sso#automatic-membership).
Состав участников определяется каталогом, даже если впоследствии токен отозван.
