OpenCode Console предоставляет список моделей, протестированных и проверенных командой OpenCode. Войдите, добавьте кредиты и получите
API-ключ, чтобы использовать их в OpenCode или другом агенте для программирования.

Console работает как любой другой провайдер в OpenCode. Это **совершенно необязательно**, и вместо него можно использовать любого другого
провайдера. О подписке с включённым использованием см. [OpenCode Go](/console/go).

## Как это работает

1. Войдите в [Console](https://opencode.ai/console), добавьте платёжные данные и кредиты, затем скопируйте API-ключ.
2. Запустите `/connect` в TUI, выберите провайдера OpenCode с оплатой по факту и вставьте API-ключ.

   ```text
   /connect
   ```

3. Запустите `/models`, чтобы увидеть доступные модели, и выберите одну.

   ```text
   /models
   ```

Плата взимается за каждый запрос, а кредиты можно добавлять на аккаунт.

## Эндпоинты

Модели также доступны напрямую через следующие эндпоинты API. Чат-модели бесплатного уровня требуют OpenCode;
из других клиентов используйте платные модели или [Go](/console/go).

Каждая модель указана со своим нативным API, но каждая текстовая модель также работает через другие API, которые переводит
Console. Полный набор см. в разделе [Базовые URL](/console/harnesses#base-urls).

### Jev

Jev — модель System One от TypeSafe AI для быстрых структурированных решений. Вместо генерации текста она отвечает на типизированные вопросы о `state` и возвращает значения и вероятности, которые можно сразу использовать в коде. Поддерживаются вопросы с ответом «да» или «нет» (`noul`), выбором из вариантов (`choice`) и оценкой по заданным критериям (`score`).

Используйте API-ключ OpenCode Console с эндпоинтом `https://opencode.ai/inference/systemone/v1/systemone`. Этот пример проверяет, срочен ли запрос в поддержку:

```bash
curl https://opencode.ai/inference/systemone/v1/systemone \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jev-1.14",
    "state": "My payments have failed for three days and I am losing sales. Please help now.",
    "questions": {
      "is_urgent": {
        "type": "noul",
        "instructions": "Does this request require urgent attention?"
      }
    }
  }'
```

В одном запросе можно задать несколько вопросов. Jev оценивает их параллельно и возвращает каждый ответ под соответствующим ID вопроса:

```bash
curl https://opencode.ai/inference/systemone/v1/systemone \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jev-1.14",
    "state": "My order arrived late and the item is damaged. I want a refund.",
    "questions": {
      "department": {
        "type": "choice",
        "instructions": "Which team should handle this request?",
        "criteria": {
          "returns": "Refunds, exchanges, or damaged items",
          "shipping": "Delivery delays or lost packages",
          "billing": "Charges, invoices, or payment problems"
        }
      },
      "frustration": {
        "type": "score",
        "instructions": "How frustrated is the customer?",
        "criteria": ["Calm", "Frustrated", "Very angry"]
      }
    }
  }'
```

Используйте `jev-1.13-free`, чтобы задействовать временно бесплатную модель, которая запускает Jev 1.13. О типах вопросов и полях ответа см. [документацию TypeSafe AI](https://docs.typesafe.ai/).

### GPT 6 Luna Decision и Gemini Decision 1

`gpt-6-luna-decision` и `gemini-decision-1` принимают тот же запрос System One, что и Jev, на том же эндпоинте. Передавайте изображения, аудио, видео и PDF в `state` как части в стиле чата (`image_url`, `input_audio`, `video_url`, `file`). GPT 6 Luna Decision принимает текст и изображения; Gemini Decision 1 также принимает аудио, видео и PDF.

```bash
curl https://opencode.ai/inference/systemone/v1/systemone \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gemini-decision-1",
    "state": "I was charged twice for my order.",
    "questions": {
      "refund": {
        "type": "noul",
        "instructions": "Is this a refund request?"
      }
    }
  }'
```

### Модели изображений

`gpt-image-2.5-sunburst`, `gemini-nano-banana-2.1` и `grok-imagine-image-2.0` генерируют и редактируют изображения. Это не чат-модели, поэтому они никогда не появляются в `/models` или эндпоинте моделей,
и `opencode/<model-id>` их не выбирает. Вызывайте их через нативный API с ключом Console или позвольте инструменту
OpenCode [`generate_image`](/tools#image-generate) использовать модель изображений, задав
`experimental.image_generate.model`, например `opencode/gpt-image-2.5-sunburst`.

```bash
curl https://opencode.ai/inference/openai/v1/images/generations \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2.5-sunburst",
    "prompt": "A mountain at sunrise",
    "size": "1024x1024"
  }'
```

Google принимает свои нативные `contents` и `generationConfig`, а xAI — свои параметры вроде `resolution` и
`quality`. OpenAI Images и xAI Images также принимают редактирование по адресу `/images/edits`.

### Модели эмбеддингов

`text-embedding-3-small`, `qwen3-embedding-8b` и другие модели эмбеддингов из таблицы выше превращают текст в
векторы. OpenCode не использует их для чата, поэтому они никогда не появляются в `/models`, а бесплатный уровень их не включает.
[Go](/console/go#embedding-models) включает некоторые из них. Вызывайте их через Embeddings API OpenAI с ключом Console.

```bash
curl https://opencode.ai/inference/openai/v1/embeddings \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "text-embedding-3-small",
    "input": ["hello world", "goodbye"]
  }'
```

- `input` принимает строку или массив строк. `data` возвращает по одному вектору на каждый вход в том же порядке.
- `dimensions` сокращает векторы у моделей, которые это поддерживают, например `text-embedding-3-small`.
- `encoding_format: "base64"` возвращает векторы в кодировке base64 вместо чисел с плавающей точкой.
- Каждый вход должен помещаться в контекстное окно модели.
- Ответ сообщает `usage.cost`, как и любой запрос инференса. См. [Стоимость](/console/api/inference#cost).

Векторы разных моделей нельзя сравнивать, поэтому преобразуйте документы и запросы в векторы одной и той же моделью.
[Подключённый провайдер](/console/api/providers#endpoints) обслуживает свои модели эмбеддингов по адресу `/embeddings`.

## Предыстория

Доступно много моделей, но лишь немногие хорошо работают как агенты для программирования. Провайдеры также различаются
конфигурацией, производительностью и качеством, поэтому модель через шлюз вроде OpenRouter может работать иначе.

<Callout type="tip">Мы протестировали избранную группу моделей и провайдеров, хорошо работающих с OpenCode.</Callout>

Чтобы собрать этот каталог, мы:

1. Протестировали избранную группу моделей и поговорили с их командами о том, как лучше их запускать.
2. Поработали с провайдерами, чтобы модели обслуживались правильно.
3. Замерили каждую комбинацию модель/провайдер, чтобы составить список, который готовы рекомендовать.

Console — AI-шлюз, дающий доступ к этим моделям.

## Цели

Мы создали Console, чтобы:

1. **Замерять** лучшие модели и провайдеров для агентов программирования.
2. Предлагать **самые качественные** варианты, не снижая производительность и не перенаправляя на более дешёвых провайдеров.
3. Передавать **снижение цен**, продавая по себестоимости с наценкой только для покрытия комиссий.
4. Избежать **привязки**: используйте Console с любым агентом для программирования или другого провайдера с OpenCode.
