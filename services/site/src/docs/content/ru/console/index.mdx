[OpenCode Console](https://opencode.ai/console) — дополнительный сервис для тех, кто пользуется OpenCode самостоятельно или в команде.

- [Рабочие пространства](/console/workspaces) для совместного доступа с [командой](/console/members)
- [Инференс](/console/models) для проприетарных моделей и моделей с открытым исходным кодом
- [Провайдеры](/console/providers) для подключения собственных аккаунтов провайдеров через шлюз Console
- Учёт использования и управление [бюджетами](/console/budgets)
- Политики для всей команды, управляющие поведением OpenCode
- [Веб-поиск](/console/websearch)
- [Harness](/console/harnesses) для доступа к моделям Console из Claude Code, Codex и других агентов
- [OpenCode Go, Go Plus и Go Teams](/console/go) — подписки для доступа к моделям с открытым исходным кодом: $10 в месяц за Go, $40 в месяц за Go Plus и $20 за участника в месяц за Go Teams

## Начало работы

Для работы в Console не нужна команда. В каждом новом аккаунте есть рабочее пространство **Personal**, где вы единственный участник.

1. Войдите в [Console](https://opencode.ai/console).
2. Оформите [Go](/console/go), добавьте [кредиты](/console/billing#add-credits) или подключите [провайдера](/console/providers).
3. Выполните `/connect` в OpenCode и выберите рабочее пространство.
4. При необходимости [пригласите](/console/members#invite-members) команду.

```text
/connect
```

## Политики

Правила Providers и Tools со страницы Policies действуют во всех клиентах OpenCode, подключённых к рабочему пространству. Console передаёт их как положения [политики](/policies#console): они имеют приоритет над пользовательскими настройками и настройками проекта и вступают в силу примерно в течение минуты. Управляемые настройки и системный файл конфигурации по-прежнему имеют приоритет над политиками рабочего пространства; см. [порядок применения](/policies#precedence).
