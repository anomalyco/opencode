---
title: "Веб-поиск в Console"
description: "Веб-поиск для OpenCode на стороне Console."
---

Console предоставляет веб-поиск подключённым пользователям OpenCode. Владелец или администратор включает его один раз для всего рабочего пространства: участникам не нужен отдельный ключ провайдера поиска.

Каждый успешный поисковый запрос стоит **$0.01**. Эта сумма списывается с баланса рабочего пространства и учитывается в лимитах расходов участников.

## Включение

1. Войдите в [Console](https://opencode.ai/console) как владелец или администратор рабочего пространства.
2. Откройте **Integrations** и нажмите **Set up** у **Hosted Web Search**.
3. Нажмите **Enable**.

Затем каждый участник подключает OpenCode к рабочему пространству через `/connect`.

```text
/connect
```

Конфигурация рабочего пространства задаёт **OpenCode Web Search** как провайдера по умолчанию. Участникам не нужно указывать `websearch.provider` или добавлять API-ключ провайдера. Если участник укажет свой `websearch.provider`, будет использоваться его настройка.

## Поиск

Попросите OpenCode найти актуальную информацию в промпте. Поиски выполняются из OpenCode, а не со страницы в Console.

```text
Find the latest Bun release and summarize the changes with source links.
```

Размещённый провайдер ищет в публичном интернете и возвращает до восьми результатов. OpenCode использует результаты, чтобы ответить на промпт и указать источники.

О настройке разрешений или отключении инструмента см. [руководство по веб-поиску](/websearch).

## Оплата

Console списывает **$0.01** после того, как поиск вернул корректный набор результатов. За неудачные поиски и поиски с ограничением частоты плата не взимается.

Веб-поиск отображается отдельно от использования моделей в **Activity › Usage**, **Activity › Overview**, активности участников, счетах и экспортах CSV. Применимые политики бюджета всех расходов включают расходы на веб-поиск.

## Конфиденциальность

Сервис веб-поиска не хранит данные. Console и её провайдер поиска обрабатывают запросы и результаты, но не сохраняют их содержимое.
