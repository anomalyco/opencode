OpenCode ежедневно используют миллионы. Создавайте на его основе приложения, интеграции и сценарии работы с агентами — без разработки с нуля.

Мы также предлагаем Effect API для [плагинов](/build/plugins/effect), [клиентов](/build/client/effect) и [встроенных приложений](/build/sdk/effect).
