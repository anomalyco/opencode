Выберите тему в терминальном интерфейсе: нажмите `Ctrl+P`, выберите **Open settings** и откройте **Theme**. Также её можно задать напрямую в глобальной конфигурации CLI:

```json title="~/.config/opencode/cli.json"
{
  "theme": {
    "name": "tokyonight",
    "mode": "system"
  }
}
```

Темы относятся к терминальному клиенту. Выбор темы указывайте в `cli.json`, а не в `opencode.json`. О расположении конфигурации и других настройках терминала см. [Настройки CLI](/cli/config).

## Режимы

Используйте `system`, чтобы следовать оформлению терминала, или зафиксируйте тему в одном режиме:

```json title="~/.config/opencode/cli.json"
{
  "theme": {
    "name": "opencode",
    "mode": "dark"
  }
}
```

| Значение | Поведение                                        |
| -------- | ------------------------------------------------ |
| `system` | Следует светлому или тёмному режиму терминала.   |
| `dark`   | Всегда использует тёмную тему.                   |
| `light`  | Всегда использует светлую тему.                  |

Если пользовательская тема предоставляет только один режим, OpenCode использует его, когда запрошен другой.

## Встроенные темы

Выберите встроенную тему по имени:

```json title="~/.config/opencode/cli.json"
{
  "theme": {
    "name": "catppuccin"
  }
}
```

Среди доступных тем:

- `aura`, `ayu`, `carbonfox`, `cobalt2`, `cursor`, `dracula`, `everforest`, `flexoki`
- `catppuccin`, `catppuccin-frappe`, `catppuccin-macchiato`
- `github`, `gruvbox`, `kanagawa`, `material`, `matrix`, `mercury`, `monokai`, `nightowl`, `nord`
- `one-dark`, `opencode`, `opencode-classic`, `orng`, `lucent-orng`, `osaka-jade`, `palenight`, `rosepine`
- `solarized`, `synthwave84`, `tokyonight`, `vercel`, `vesper`, `zenburn`

Тема `system` доступна, когда OpenCode может прочитать палитру терминала.

## Файлы

Чтобы создать глобальную тему `ocean`, сгенерируйте полный файл в глобальном каталоге тем с помощью инструмента для работы с темами. Вот основные элементы файла:

```json title="~/.config/opencode/themes/ocean.json (excerpt)"
{
  "base": {
    "text": {
      "base": "#d8f3ff"
    }
  },
  "dark": {
    "hue": {
      "accent": "$hue.cyan"
    }
  }
}
```

Затем выберите `ocean` в настройках или установите `theme.name` в `ocean` в `cli.json`. Имя файла без `.json` — это имя темы.

| Область | Каталог                                 |
| ------- | --------------------------------------- |
| Глобально | `~/.config/opencode/themes/`          |
| Проект  | `.opencode/themes/` в дереве проекта    |

OpenCode читает только файлы `.json`. Тема ближе к текущему каталогу заменяет глобальную или родительскую тему с тем же именем.

## Формат

Каждая тема V2 объявляет одно полное дерево токенов `base` и хотя бы одну палитру оттенков `light` или `dark`. Режимы наследуют только базу этого файла; они не наследуют от встроенной темы OpenCode или друг от друга. Прежде чем настраивать, сгенерируйте полную базу инструментом тем.

Примеры ниже показывают только разделы, относящиеся к каждому понятию; это не полные файлы тем.

```json title="themes/ocean.json"
{
  "base": {
    "text": {
      "base": "#16324f"
    }
  },
  "light": {
    "hue": {}
  },
  "dark": {
    "hue": {},
    "text": { "base": "#d8f3ff" }
  }
}
```

## Цвета

Используйте hex-цвет, `transparent` или ссылку на другой цвет темы:

```json title="themes/ocean.json"
{
  "base": {
    "text": {
      "base": "#d8f3ff",
      "muted": "$hue.neutral.400"
    },
    "background": {
      "base": "transparent"
    }
  }
}
```

Hex-значения могут содержать 3, 4, 6 или 8 цифр. Ссылки начинаются с `$`; ссылки на оттенки имеют вид `$hue.<name>.<step>`.

## Оттенки

Переопределите псевдоним оттенка, чтобы сразу изменить семейство связанных цветов:

```json title="themes/ocean.json"
{
  "base": {
    "categorical": ["accent", "purple", "green"]
  },
  "dark": {
    "hue": {
      "accent": "$hue.cyan",
      "interactive": "$hue.blue"
    }
  }
}
```

| Вид        | Значения                                                             |
| ---------- | -------------------------------------------------------------------- |
| Базовые    | `gray`, `red`, `orange`, `yellow`, `green`, `cyan`, `blue`, `purple` |
| Псевдонимы | `accent`, `interactive`, `neutral`                                   |
| Шаги       | `100`, `200`, `300`, `400`, `500`, `600`, `700`, `800`, `900`        |

Порядок оттенков зависит от режима: в светлой теме шкала идёт от тёмного `100` к светлому `900`, в тёмной — от светлого `100` к тёмному `900`.

`categorical` задаёт упорядоченные оттенки для различения агентов и других повторяющихся элементов. Он должен содержать хотя бы один базовый оттенок или псевдоним.

## Состояния

Используйте ключи состояний, чтобы менять цвета интерактивных элементов. Неуказанные состояния используют ближайшее базовое значение:

```json title="themes/ocean.json"
{
  "base": {
    "text": {
      "action": {
        "primary": {
          "base": "$hue.interactive.400",
          "$hovered": "$hue.interactive.300",
          "$disabled": "$hue.neutral.600"
        }
      }
    }
  }
}
```

| Группа    | Значения                                                  |
| --------- | --------------------------------------------------------- |
| Действия  | `primary`, `secondary`, `destructive`                     |
| Состояния | `$hovered`, `$focused`, `$pressed`, `$selected`, `$disabled` |

Поля форм используют те же ключи состояний непосредственно в `text.formfield` или `background.formfield`.

## Токены

Полная `base` содержит все группы токенов. Режим может переопределить любую её часть, предоставив полную палитру оттенков:

```json title="themes/ocean.json"
{
  "base": {
    "border": {
      "base": "$hue.neutral.700"
    },
    "syntax": {
      "comment": "$hue.neutral.500",
      "keyword": "$hue.accent.400"
    },
    "diff": {
      "text": {
        "added": "$hue.green.400",
        "removed": "$hue.red.400"
      }
    }
  }
}
```

| Группа       | Назначение                                                     |
| ------------ | -------------------------------------------------------------- |
| `text`       | Базовый, приглушённый, слабый текст, выделение, действия, поля форм и обратная связь |
| `background` | База, выделение, поверхности, действия, поля форм и заливки обратной связи |
| `border`     | Границы                                                        |
| `scrollbar`  | Полосы прокрутки                                               |
| `diff`       | Цвета добавленных, удалённых, контекстных, подсвеченных строк и номеров строк |
| `syntax`     | Подсветка исходного кода                                       |
| `markdown`   | Элементы Markdown                                              |

Ключи подсветки: `comment`, `keyword`, `function`, `variable`, `string`, `number`, `type`, `operator` и `punctuation`. Ключи Markdown: `text`, `heading`, `link`, `linkText`, `code`, `blockQuote`, `emphasis`, `strong`, `horizontalRule`, `listItem`, `listEnumeration`, `image`, `imageText` и `codeBlock`.

## Приподнятые поверхности

Уровни фона для панелей, диалоговых окон, меню и всплывающих уведомлений задаются в `background.raised`. Для диалоговых окон также поддерживается контекстная поверхность `@dialog`. После применения `@dialog` TUI пересчитывает палитру, поэтому токены со ссылкой на `$background.base` используют фон диалогового окна:

```json title="themes/ocean.json"
{
  "base": {
    "background": {
      "base": "#071521",
      "raised": {
        "base": "#0c1f2e",
        "high": "#102a3c",
        "max": "#16364b"
      }
    },
    "@dialog": {
      "background": {
        "base": "$background.raised.base"
      }
    }
  }
}
```

`@dialog` принимает те же группы токенов, что и базовый режим. Контекстная `base` действия также становится запасным значением для его неуказанных состояний; явное переопределение состояния по-прежнему побеждает.
