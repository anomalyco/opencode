---
title: "Плагины CLI"
description: "Загружайте плагины TUI из конфигурации OpenCode в CLI и добавляйте плагины только для CLI и их параметры в cli.json."
---

Плагины, настроенные в `opencode.json(c)` и предоставляющие компонент TUI, CLI загружает автоматически. О том, как создавать плагины, см. [Создание плагинов](/build/plugins). Добавлять тот же пакет в `cli.json` не нужно. CLI получает список активных плагинов от подключённого сервера OpenCode, поэтому это работает и с удалённым сервером.

Плагины, предназначенные только для CLI, указывайте в `cli.json`. Они работают локально в терминале и остаются активными при подключении CLI к удалённому серверу:

```json title="cli.json"
{
  "plugins": [
    "opencode.example",
    "opencode.example@1.0.0",
    "@example/opencode-tui",
    "@example/opencode-tui@1.0.0",
    "./plugins/status",
    "../plugins/status",
    "/home/user/plugins/status",
    "file:///home/user/plugins/status"
  ]
}
```

Записи обрабатываются по порядку. Поставьте `-` перед ID или шаблоном, чтобы отключить подходящие плагины:

```json title="cli.json"
{
  "plugins": ["*", "-opencode.notifications", "-team.*"]
}
```

Для передачи параметров плагина используйте запись в виде объекта:

```json title="cli.json"
{
  "plugins": [
    {
      "package": "@example/opencode-tui",
      "options": {
        "compact": true
      }
    }
  ]
}
```

OpenCode также ищет плагины в глобальном каталоге конфигурации и в каталогах проектов `.opencode`. Структура каждого плагина такая же, как у опубликованного пакета: точки входа сервера и TUI находятся рядом.

```text title="Plugin discovery paths"
<global-config>/plugins/status/index.ts
<global-config>/plugins/status/tui.ts
<project>/.opencode/plugins/status/index.ts
<project>/.opencode/plugins/status/tui.ts
```

Найденные плагины могут импортировать `@opencode/plugin/tui` напрямую: OpenCode определяет путь к пакету во время выполнения. Примеры см. в разделе [Создание плагинов TUI](/build/plugins/cli).
