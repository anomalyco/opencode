---
title: "Сочетания клавиш"
description: "Настройте сочетания клавиш OpenCode CLI в cli.json и узнайте ID каждой команды и стандартное сочетание."
---

Настройте сочетания в `cli.json`:

```json title="cli.json"
{
  "keybinds": {
    "leader": "ctrl+space",
    "command.palette.show": "ctrl+k",
    "app.exit": ["ctrl+c", "ctrl+d"],
    "app.debug": false
  },
  "leader": {
    "timeout": 1500
  }
}
```

Используйте строку для одной клавиши:

```json
{
  "keybinds": {
    "command.palette.show": "ctrl+k"
  }
}
```

Разделяйте альтернативы запятыми:

```json
{
  "keybinds": {
    "app.exit": "ctrl+c,ctrl+d"
  }
}
```

Отключите сочетание через `"none"` или `false`:

```json
{
  "keybinds": {
    "app.debug": "none",
    "help.show": false
  }
}
```

Используйте объект для поведения события:

```json
{
  "keybinds": {
    "prompt.paste": {
      "key": "ctrl+v",
      "preventDefault": false
    }
  }
}
```

`leader` по умолчанию — `ctrl+x`. `<leader>` в другом сочетании ссылается на эту клавишу.

```json
{
  "keybinds": {
    "leader": "ctrl+space",
    "model.list": "<leader>m"
  },
  "leader": {
    "timeout": 2000
  }
}
```

Неизвестные ID команд игнорируются.

## Mini

Команда `app.clear` работает только в [`opencode mini`](/cli). Нажмите `ctrl+l`, чтобы очистить видимую часть экрана и заново отобразить промпт. История прокрутки терминала сохраняется.

```json title="cli.json"
{
  "keybinds": {
    "app.clear": "ctrl+l"
  }
}
```

| ID          | По умолчанию | Описание        |
| ----------- | ------------ | --------------- |
| `app.clear` | `ctrl+l`     | Очистить экран  |

## Просмотр Diff

Нажмите `d` (`diff.switch_source`), чтобы выбрать **All**, **Committed**, **Uncommitted** или **Last turn** (внутри сессии), либо выберите **Base**, чтобы изменить ветку сравнения. Выбор запоминается до выхода из TUI. Задайте начальную область через [`diffs.source` в `cli.json`](/cli/config#diffs).

Прокрутка, постраничный переход и сочетания начала и конца всегда управляют Diff. Переключения фокуса с клавиатуры нет: щёлкайте по файлам, чтобы открыть их, по каталогам, чтобы развернуть или свернуть, и используйте колесо мыши для прокрутки дерева файлов.

Используйте `n` / `p` или `alt+down` / `alt+up` (Option в macOS), чтобы перемещаться между файлами. Внутри просмотра Diff сочетания Alt перемещают по файлам, а не по вкладкам сессий.

Нажмите `m`, чтобы отметить файл как просмотренный и свернуть его патч. В режиме просмотра всех файлов снова нажмите `m`, чтобы снять отметку и развернуть патч. При просмотре по одному файлу после отметки открывается следующий файл. Если файл последний, он остаётся открытым — возврата к первому нет. При снятии отметки перехода нет.

Щёлкните правой кнопкой мыши по файлу на боковой панели или по его заголовку в Diff и выберите **Mark complete** (или **Mark incomplete**). Это та же отметка о просмотре, которую меняет `m`. Если поставить отметку через меню другого файла, этот файл не будет выбран, а текущий останется открытым.

Альтернативы `diff.help` с Shift поддерживают терминалы, сообщающие модификатор Shift при нажатии `?`.
