Запустите CLI в проекте, чтобы открыть полноэкранный терминальный интерфейс:

```bash
opencode
```

Передайте каталог, чтобы работать в другом проекте:

```bash
opencode ~/code/my-project
```

Рекомендуемые терминалы:

- [Ghostty](https://ghostty.org)
- [WezTerm](https://wezterm.org)
- [Alacritty](https://alacritty.org)
- [Kitty](https://sw.kovidgoyal.net/kitty/)

С поддержкой Truecolor цвета тем отображаются точнее всего. Без неё терминал подбирает ближайшие цвета из доступной палитры.

## Автоматизация

Используйте `opencode run`, чтобы отправить промпт, не открывая интерактивный интерфейс. Команда рассчитана на скрипты, задачи CI и другие сценарии, которым нужен вывод модели прямо в терминале.

```bash
opencode run "Explain this repository"
```

## Mini

Используйте `opencode mini`, чтобы запустить минимальный интерактивный интерфейс OpenCode вместо полноэкранного TUI.

```bash
opencode mini
```

Запустите `opencode mini --help`, чтобы увидеть параметры сессий, моделей, агентов, промптов и воспроизведения.

## Фоновый сервис

По умолчанию OpenCode находит или запускает один общий фоновый сервер для вашего аккаунта. К нему подключаются все локальные клиенты OpenCode. Сервер управляет сессиями, конфигурацией, интеграциями и разрешениями, а также выполняет инструменты.

Используйте `--standalone`, чтобы запустить отдельный сервер, или `--server`, чтобы подключиться к серверу по заданному URL:

```bash
opencode --standalone
opencode --server http://localhost:4096
```

Чтобы команды CLI по умолчанию использовали отдельные серверы, отключите общий сервис:

```bash
opencode service set disabled true
opencode
```

Это останавливает работающий фоновый сервис. `--server` по-прежнему подключается к явно выбранному серверу; `opencode service start` всё ещё может явно запустить общий сервис. Чтобы вернуться к автоматическому использованию сервиса, выполните `opencode service unset disabled`. Сопряжение требует общего сервиса и недоступно, пока он отключён.

О диагностике общего сервиса см. [Устранение неполадок](/troubleshooting), а об эндпоинтах сервера — [справочник API](/api).

## Пути

Выведите конкретный локальный путь для использования другими инструментами:

```bash
opencode debug paths db
sqlite3 "$(opencode debug paths db)"
```

Необязательный аргумент принимает `db`, `home`, `data`, `config`, `cache`, `state`, `tmp`, `bin`, `log` или `repos`. Команда выведет только путь и символ новой строки. Путь к базе данных зависит от канала выпуска и `OPENCODE_DB`: если задан относительный путь, он отсчитывается от каталога данных, а `:memory:` выводится как есть. Команда не запускает сервер и не открывает базу данных.

Не указывайте аргумент, чтобы вывести все пути с подписями:

```bash
opencode debug paths
```

## Удаление

Просмотрите файлы и установку, которые будут удалены:

```bash
opencode uninstall --dry-run
```

Запустите `opencode uninstall`, чтобы подтвердить удаление. OpenCode останавливает зарегистрированные фоновые сервисы и постоянные терминалы перед удалением глобального каталога кэша, общего для версий и каналов OpenCode. Данные сессий, конфигурация и состояние никогда не удаляются.

- `--force` (`-f`) пропускает подтверждение; используйте его для неинтерактивного удаления.
- Установки через менеджер пакетов используют обнаруженный менеджер. Установки через curl выводят итоговую команду для ручного удаления исполняемого файла.
