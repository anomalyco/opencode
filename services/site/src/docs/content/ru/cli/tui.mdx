Запустите OpenCode в проекте, введите запрос и нажмите **Enter**.

```bash
cd ~/code/my-project
opencode
```

```text
Explain how authentication works in this project
```

Нажмите **Shift+Enter**, **Ctrl+Enter**, **Alt+Enter** или **Ctrl+J**, чтобы начать новую строку. Пока OpenCode работает, **Enter** отправляет указание в текущую сессию. Чтобы отложить промпт, нажмите **Ctrl+X**, затем **Enter**: промпт попадёт в очередь.

## Контекст

Введите `@`, чтобы найти файл, затем выберите его, чтобы прикрепить к промпту. Продолжайте печатать после `@`, чтобы сузить результаты.

```text
Review @src/auth.ts for error handling problems
```

После пути можно указать строку или диапазон.

```text
Explain @src/auth.ts#20-45
```

## Shell

Введите `!` в начале пустого промпта, чтобы войти в режим shell. Введите команду и нажмите **Enter**; нажмите **Esc**, чтобы выйти из режима shell, ничего не запустив.

```text
!git status
```

Shell-команды выполняются в рабочем каталоге сессии, а их вывод остаётся в сессии.

## Команды

Введите `/`, чтобы увидеть список слеш-команд. Продолжайте печатать, чтобы отфильтровать список, затем нажмите **Enter**, чтобы выполнить выбранную команду.

```text
/models
```

Распространённые команды: `/new`, `/sessions`, `/models`, `/agents`, `/undo`, `/redo` и `/editor`. Нажмите **Ctrl+P**, чтобы открыть палитру команд со всеми действиями, доступными в текущем представлении.

После обновления OpenCode один раз показывает на главном экране, что нового в релизе. Запустите `/highlights`, чтобы увидеть это снова, или установите `"highlights": false` в [`cli.json`](/cli/config#alerts), чтобы окно не открывалось автоматически.

## Вопросы вне диалога

Запустите `/btw <question>`, чтобы задать короткий вопрос о том, что уже обсуждалось. На него отвечает текущая модель с учётом контекста сессии. Ответ не попадает в историю диалога и не влияет на последующие промпты. Пока модель отвечает, под полем ввода виден индикатор `/btw`. Ответ откроется в диалоговом окне; нажмите **C**, чтобы скопировать его.

```text
/btw why did the test in step 2 fail?
```

## Модели

Нажмите **Ctrl+X**, затем **M**, чтобы выбрать модель, или запустите `/models`. Нажмите **F2**, чтобы переключаться между недавно использованными моделями.

Нажмите **Ctrl+X**, затем **A**, чтобы выбрать агента, или запустите `/agents`. Нажмите **Shift+Tab**, чтобы переключать агентов.

## Сессии

Нажмите **Ctrl+X**, затем **N**, чтобы начать новую сессию. Нажмите **Ctrl+X**, затем **L**, или запустите `/sessions`, чтобы вернуться к существующей сессии; **Ctrl+O** открывает недавние сессии и проекты вместе.

Вкладки включены по умолчанию. Используйте **Ctrl+Tab** и **Ctrl+Shift+Tab** для переключения между ними, **Ctrl+X**, затем **W**, чтобы закрыть вкладку, и **Ctrl+Shift+T**, чтобы снова открыть последнюю закрытую.

## История

Нажмите **Ctrl+X**, затем **U**, или запустите `/undo`, чтобы отменить последнее сообщение пользователя и последовавшую за ним работу. Отменённый промпт возвращается в поле ввода, чтобы его можно было отредактировать.

Нажмите **Ctrl+X**, затем **R**, или запустите `/redo`, чтобы восстановить отменённую работу. Если вместо этого отправить новый промпт, откат принимается и работа продолжается с этой точки.

## Редактор

Задайте `VISUAL` или `EDITOR`, затем нажмите **Ctrl+X**, затем **E**, или запустите `/editor`, чтобы отредактировать текущий промпт в этом редакторе. Сохраните и выйдите, чтобы вернуть текст в поле ввода, затем нажмите **Enter**, чтобы отправить его.

```bash
export EDITOR="nvim"
opencode
```

Лидер-клавиша по умолчанию — **Ctrl+X**. О том, как изменить эти сочетания, см. [Сочетания клавиш](/cli/keybinds).
