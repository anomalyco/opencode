Настройки CLI управляют только терминальными клиентами. Они отделены от серверных и проектных настроек в `opencode.json(c)`.

Нажмите `Ctrl+P`, затем выберите **Open settings**, чтобы изменить общие настройки из TUI.

<img src={`${import.meta.env.BASE_URL}assets/cli/settings.png`} alt="OpenCode TUI settings dialog" />

## Файл конфигурации

OpenCode хранит настройки CLI в одном глобальном файле:

```text
~/.config/opencode/cli.json
```

Если задан `$XDG_CONFIG_HOME`, OpenCode использует:

```text
$XDG_CONFIG_HOME/opencode/cli.json
```

Локального файла настроек CLI для проекта нет. Добавьте опубликованную схему JSON для проверки и автодополнения:

```json title="cli.json"
{
  "$schema": "https://opencode.ai/v2/cli.json"
}
```

OpenCode добавляет `$schema` при создании или миграции файла. Если изменения корректны, TUI применяет их без перезапуска.

Неизвестные настройки игнорируются. Оставляйте `$schema`, чтобы редактор отмечал недопустимые значения.

## Встроенная конфигурация

Установите `OPENCODE_CLI_CONFIG_CONTENT`, чтобы применить настройки CLI из встроенного JSON:

```sh
OPENCODE_CLI_CONFIG_CONTENT='{"tabs":{"mode":"off"}}' opencode
```

OpenCode накладывает встроенные настройки поверх глобального `cli.json`. Вложенные объекты сливаются, а массивы и скалярные значения из окружения заменяют глобальные. Встроенные настройки остаются главными, пока переменная задана.

## Внешний вид
Выберите тему, управляйте анимацией интерфейса и переопределите курсор терминала:

```json title="cli.json"
{
  "theme": {
    "name": "tokyonight",
    "mode": "system"
  },
  "animations": true,
  "cursor": {
    "style": "block",
    "blinking": true
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="Appearance settings" tabIndex={0}>

| Настройка         | Значения                                | Описание                                                                 |
| ----------------- | --------------------------------------- | ------------------------------------------------------------------------ |
| `theme.name`      | string                                  | Выбирает встроенную, пользовательскую или производную от терминала тему. |
| `theme.mode`      | `system`, `dark` или `light`            | Следует оформлению терминала или фиксирует тему в одном цветовом режиме.  |
| `animations`      | boolean                                 | Включает анимации интерфейса.                                            |
| `cursor.style`    | `block`, `underline`, `line`, `default` | Задаёт форму курсора. `default` сохраняет форму курсора терминала.        |
| `cursor.blinking` | boolean                                 | Управляет миганием курсора. Не действует при стиле `default`.            |

</div>

О выборе и создании тем см. [Тема CLI](/cli/theme).

## Ввод

Настройте захват мыши, прокрутку, контекст редактора, вставку и предпросмотр изображений в промпте:

```json title="cli.json"
{
  "mouse": true,
  "scroll": {
    "speed": 3,
    "acceleration": false
  },
  "prompt": {
    "editor": true,
    "paste": "compact",
    "image_preview": false
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="Input settings" tabIndex={0}>

| Настройка                  | Значения                        | Описание                                                                    |
| -------------------------- | ------------------------------- | --------------------------------------------------------------------------- |
| `mouse`                    | boolean                         | Включает захват мыши терминалом.                                            |
| `scroll.speed`             | число не меньше `0.001`         | Задаёт фиксированное расстояние на один тик прокрутки.                       |
| `scroll.acceleration`      | boolean                         | Ускоряет повторную прокрутку. При включении имеет приоритет над скоростью.   |
| `prompt.editor`            | boolean                         | Включает активный файл или выделение редактора в контекст промпта.           |
| `prompt.paste`             | `compact` или `full`            | Показывает большие вставки компактными заполнителями или полным текстом.     |
| `prompt.image_preview`     | boolean                         | Показывает предпросмотр прикреплённых изображений над полем ввода.          |

</div>

## Сессии

Настройте, как отображаются полноэкранные сессии TUI и где начинаются новые сессии:

```json title="cli.json"
{
  "session": {
    "sidebar": "auto",
    "scrollbar": false,
    "submit_scroll": "bottom",
    "thinking": "hide",
    "grouping": "auto",
    "image_preview": false,
    "tps": true,
    "markdown": "rendered",
    "new_location": "launch",
    "permissions": "prompt"
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="Session settings" tabIndex={0}>

| Настройка               | Значения                    | Описание                                                                     |
| ----------------------- | --------------------------- | ---------------------------------------------------------------------------- |
| `session.sidebar`       | `auto` или `hide`           | Показывает боковую панель, когда хватает места, или всегда скрывает.         |
| `session.scrollbar`     | boolean                     | Показывает полосу прокрутки транскрипта.                                     |
| `session.submit_scroll` | `bottom` или `keep`         | Переходит к последнему сообщению при отправке промпта или сохраняет позицию. |
| `session.thinking`      | `show` или `hide`           | По умолчанию показывает или скрывает рассуждения модели.                     |
| `session.grouping`      | `auto` или `none`           | Группирует связанные элементы транскрипта или отображает каждый отдельно.    |
| `session.image_preview` | boolean                     | Показывает изображения вложений пользователя и результатов инструментов.    |
| `session.tps`           | boolean                     | Показывает выходные токены в секунду в подписях ассистента.                 |
| `session.markdown`      | `source` или `rendered`     | Показывает маркеры синтаксиса Markdown или скрывает их.                     |
| `session.new_location`  | `launch` или `inherit`      | Начинает в каталоге запуска TUI или наследует расположение активной сессии.  |
| `session.permissions`   | `prompt` или `autoaccept`   | Запрашивает разрешения или автоматически принимает каждый запрос.            |

</div>

## Вкладки

Настройте постоянную полосу вкладок сессий:

```json title="cli.json"
{
  "tabs": {
    "mode": "auto",
    "scope": "cwd",
    "layout": "horizontal",
    "indicators": "status"
  }
}
```

Устаревшая булева настройка `tabs.enabled` по-прежнему поддерживается: `true` — это `on`, а `false` — `off`. OpenCode читает её, не переписывая файл конфигурации.

<div class="docs-table-scroll" role="region" aria-label="Tab settings" tabIndex={0}>

| Настройка         | Значения                    | Описание                                                                     |
| ----------------- | --------------------------- | ---------------------------------------------------------------------------- |
| `tabs.mode`       | `auto`, `on` или `off`      | Использует вкладки автоматически, всегда или никогда. Auto скрывает их внутри Herdr. |
| `tabs.scope`      | `cwd` или `global`          | Держит отдельные вкладки для каждого рабочего каталога или делит их глобально. |
| `tabs.layout`     | `horizontal` или `vertical` | Размещает вкладки горизонтальной полосой или вертикальной боковой панелью.    |
| `tabs.indicators` | `status` или `numbers`      | Показывает значки состояния или всегда показывает номера вкладок.            |

</div>

Индикаторы номеров сохраняют цвета состояния и фоновые анимации. Сочетания Ctrl+число переключают вкладки в любом режиме индикаторов.

## Diff

Настройте начальную область и представление Diff:

```json title="cli.json"
{
  "diffs": {
    "source": "branch",
    "wrap": "word",
    "tree": true,
    "single": false,
    "view": "auto"
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="Diff settings" tabIndex={0}>

| Настройка      | Значения                                    | Описание                                                 |
| -------------- | ------------------------------------------- | -------------------------------------------------------- |
| `diffs.source` | `branch`, `committed`, `working` или `turn` | Задаёт начальную область просмотра.                      |
| `diffs.wrap`   | `word` или `none`                           | Переносит длинные строки по словам или оставляет без переноса. |
| `diffs.tree`   | boolean                                     | Показывает дерево файлов Diff.                           |
| `diffs.single` | boolean                                     | Показывает только патч выбранного файла.                 |
| `diffs.view`   | `auto`, `split` или `unified`               | Задаёт раскладку. `auto` выбирает по доступной ширине.   |

</div>

`branch` показывает **All** — изменения ветки и локальные, `committed` — только коммиты ветки, а `working` — изменения в индексе, вне индекса и неотслеживаемые. `turn` показывает **Last turn** — файлы, изменённые сессией в последнем ходе; список обновляется по завершении хода и возвращается к `branch`, если `/diff` открыт не из сессии.

В `/diff` нажмите `d`, чтобы изменить область просмотра, или выберите ветку для сравнения в **Base**. Выбор сохраняется до выхода из TUI и не меняет `cli.json`.

## Уведомления

Системные уведомления и звуковые сигналы включаются независимо:

```json title="cli.json"
{
  "attention": {
    "notifications": true,
    "sound": true,
    "volume": 0.4,
    "sound_pack": "opencode.default",
    "sounds": {
      "permission": "/home/me/sounds/permission.wav"
    }
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="Alert settings" tabIndex={0}>

| Настройка                  | Значения                | Описание                                                                                              |
| -------------------------- | ----------------------- | ----------------------------------------------------------------------------------------------------- |
| `attention.notifications`  | boolean                 | Показывает системные уведомления, обычно когда терминал не в фокусе.                                  |
| `attention.sound`          | boolean                 | Проигрывает звуки внимания.                                                                           |
| `attention.volume`         | число от `0` до `1`     | Задаёт громкость звука.                                                                               |
| `attention.sound_pack`     | string                  | Выбирает ID активного набора звуков.                                                                  |
| `attention.sounds`         | object                  | Переопределяет звуковые файлы для `default`, `question`, `permission`, `error`, `done` или `subagent_done`. |

</div>

Если задан недопустимый звук или его файл не удаётся прочитать, для этого события используется встроенный звук.

После обновления TUI один раз показывает новинки релиза на главном экране. Запустите `/highlights`, чтобы увидеть их снова, или отключите диалог:

```json title="cli.json"
{
  "highlights": false
}
```

## Терминал

Настройте интеграцию с терминалом:

```json title="cli.json"
{
  "terminal": {
    "title": true,
    "copy": "select"
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="Terminal settings" tabIndex={0}>

| Настройка        | Значения             | Описание                                                                                              |
| ---------------- | -------------------- | ----------------------------------------------------------------------------------------------------- |
| `terminal.title` | boolean              | Обновляет заголовок окна терминала.                                                                   |
| `terminal.copy`  | `manual` или `select` | Копирует вручную или сразу после выделения. По умолчанию на платформе `manual` в Windows и `select` в остальных. |

</div>

## Mini

Группа `mini` управляет [`opencode mini`](/cli#mini) — минимальным интерактивным интерфейсом:

```json title="cli.json"
{
  "mini": {
    "thinking": "show",
    "tools": "hide",
    "shell_output": "hide",
    "turn_summary": "show",
    "footer": "show",
    "splash": "show",
    "work_spinner": "block-soft-slide",
    "mono": false,
    "replay": true,
    "replay_limit": 200
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="Mini settings" tabIndex={0}>

| Настройка           | Значения                       | Описание                                                                        |
| ------------------- | ------------------------------ | ------------------------------------------------------------------------------- |
| `mini.thinking`     | `show` или `hide`              | Показывает или скрывает рассуждения модели.                                     |
| `mini.tools`        | `show` или `hide`              | Показывает или скрывает вызовы инструментов и предшествующий им текст ассистента. |
| `mini.shell_output` | `show` или `hide`              | Показывает или скрывает сырой вывод инструмента shell.                          |
| `mini.turn_summary` | `show` или `hide`              | Показывает или скрывает сводку агента, модели и длительности в истории прокрутки. |
| `mini.footer`       | `show` или `hide`              | Показывает или скрывает постоянные сведения об активности, модели, использовании и контексте. |
| `mini.splash`       | `show` или `hide`              | Показывает или скрывает заставки входа и выхода.                                |
| `mini.work_spinner` | ID анимации                    | Выбирает анимацию работы в нижней части.                                        |
| `mini.mono`         | boolean                        | Использует монохромный вывод ASCII.                                             |
| `mini.replay`       | boolean                        | Восстанавливает историю сессии при возобновлении и изменении размера терминала. |
| `mini.replay_limit` | положительное целое число      | Ограничивает воспроизведение последними сообщениями. По умолчанию `200`.       |

</div>

Доступные ID анимаций:

```text
block-soft-slide  block-soft-sweep  block-low-comet  block-low-duet
block-shuttle     block-bridge      block-squeeze    small-toggle
square-toggle     grow-shrink       quadrant-orbit   crosshatch
density-wave      seed
```

Флаги воспроизведения `mini` в командной строке переопределяют эти настройки для данного вызова.

## Сочетания клавиш

Переопределите сочетание команды и тайм-аут лидер-клавиши:

```json title="cli.json"
{
  "keybinds": {
    "leader": "ctrl+x",
    "app.exit": ["ctrl+c", "ctrl+d", "<leader>q"],
    "prompt.paste": {
      "key": "ctrl+v",
      "event": "press",
      "preventDefault": false,
      "fallthrough": false
    },
    "help.show": false
  },
  "leader": {
    "timeout": 2000
  }
}
```

<div class="docs-table-scroll" role="region" aria-label="Keybind settings" tabIndex={0}>

| Настройка                   | Значения                                         | Описание                                                              |
| --------------------------- | ------------------------------------------------ | --------------------------------------------------------------------- |
| `keybinds.leader`           | значение сочетания                               | Задаёт клавишу, на которую ссылается `<leader>` в других сочетаниях.   |
| `keybinds.<command>`        | значение сочетания                               | Переопределяет сочетание для ID одной команды.                        |
| `keybinds.*.key`            | строка клавиши или дескриптор                    | Выбирает клавишу для объектного сочетания.                            |
| `keybinds.*.event`          | `press` или `release`                            | Ограничивает объектное сочетание одним событием клавиши.              |
| `keybinds.*.preventDefault` | boolean                                          | Управляет тем, предотвращается ли стандартное поведение клавиши.      |
| `keybinds.*.fallthrough`    | boolean                                          | Позволяет обработчикам с меньшим приоритетом получить то же событие.  |
| `leader.timeout`            | положительное целое число                        | Задаёт, сколько миллисекунд ждать после лидер-клавиши.                |

</div>

Значение сочетания может быть строкой, массивом альтернатив или объектом. Используйте `"none"` или `false`, чтобы отключить сочетание. О синтаксисе клавиш, всех ID команд и всех стандартных сочетаниях см. [Сочетания клавиш](/cli/keybinds).

## Плагины

Загружайте плагины только для терминала по порядку:

```json title="cli.json"
{
  "plugins": [
    "-opencode.notifications",
    {
      "package": "./plugins/status",
      "options": {
        "compact": true
      }
    }
  ]
}
```

<div class="docs-table-scroll" role="region" aria-label="Plugin settings" tabIndex={0}>

| Настройка           | Значения | Описание                                                        |
| ------------------- | -------- | --------------------------------------------------------------- |
| `plugins`           | array    | Объявляет упорядоченные директивы включения и внешние плагины.   |
| `plugins[].package` | string   | Задаёт имя пакета, локальный путь или URL файла.                 |
| `plugins[].options` | object   | Передаёт параметры, специфичные для плагина.                     |

</div>

О формах пакетов, локальном обнаружении, шаблонах и директивах отключения см. [Плагины](/cli/plugins).

## Отладка и эксперименты

Включите диагностику или подключите доступный сейчас эксперимент:

```json title="cli.json"
{
  "debug": {
    "devtools": false,
    "timing": false,
    "turn_tokens": "verbose"
  },
  "experimental": {}
}
```

<div class="docs-table-scroll" role="region" aria-label="Debug and experimental settings" tabIndex={0}>

| Настройка           | Значения                        | Описание                                                                         |
| ------------------- | ------------------------------- | --------------------------------------------------------------------------------- |
| `debug.devtools`    | boolean                         | Показывает панель отладки DevTools.                                              |
| `debug.timing`      | boolean                         | Показывает диагностику времени до первой отрисовки в панели отладки.             |
| `debug.turn_tokens` | boolean или `verbose`           | Показывает использование токенов за ход; `verbose` также включает входы вызовов инструментов. |
| `experimental`      | объект ID функций в boolean     | Включает или отключает эксперименты, которые могут меняться или исчезать без предупреждения. |

</div>

Используйте только ID функций, которые сейчас перечислены в диалоге **Experiments** в TUI. Неизвестные ID не действуют.
