---
title: "ملحقات CLI"
description: "حمّل ملحقات TUI من OpenCode config في CLI، وأضف الملحقات المخصّصة لـ CLI وخياراتها في cli.json."
---

تُحمَّل الملحقات المضبوطة في `opencode.json(c)` التي تعرض مكوّن TUI تلقائيًا بواسطة CLI. ولمعرفة كيفية
بناء الملحقات، راجع [بناء الملحقات](/build/plugins). ولا تحتاج إلى إضافة الحزمة نفسها إلى `cli.json`. فـCLI
يحصل على قائمة الملحقات النشطة من خادم OpenCode المرتبط، لذا يعمل ذلك أيضًا عندما يكون الخادم بعيدًا.

واستخدم `cli.json` لملحقات CLI وحدها. فهي تعمل محليًا في الطرفية وتبقى نشطة عندما يتصل CLI
بخادم بعيد:

```json title="cli.json"
{
  "plugins": [
    "opencode.example",
    "opencode.example@1.0.0",
    "@example/opencode-tui",
    "@example/opencode-tui@1.0.0",
    "./plugins/status",
    "../plugins/status",
    "/home/user/plugins/status",
    "file:///home/user/plugins/status"
  ]
}
```

تُعالَج الإدخالات بالترتيب. ضع `-` قبل المعرّف أو حرف البدل لتعطيل الملحقات المطابقة:

```json title="cli.json"
{
  "plugins": ["*", "-opencode.notifications", "-team.*"]
}
```

ومرّر خيارات الملحق بصيغة الكائن:

```json title="cli.json"
{
  "plugins": [
    {
      "package": "@example/opencode-tui",
      "options": {
        "compact": true
      }
    }
  ]
}
```

ويكتشف OpenCode الملحقات أيضًا تحت مجلد الإعداد العام ومجلدات `.opencode` في المشروع. ويستخدم كل ملحق
التخطيط نفسه الذي تستخدمه الحزمة المنشورة، مع إبقاء نقاط دخول الخادم وTUI معًا.

```text title="Plugin discovery paths"
<global-config>/plugins/status/index.ts
<global-config>/plugins/status/tui.ts
<project>/.opencode/plugins/status/index.ts
<project>/.opencode/plugins/status/tui.ts
```

يمكن للملحقات المكتشفة استيراد `@opencode/plugin/tui` مباشرةً؛ ويحدّد OpenCode موقع الحزمة وقت التشغيل. راجع
[بناء ملحقات TUI](/build/plugins/cli) للأمثلة.
