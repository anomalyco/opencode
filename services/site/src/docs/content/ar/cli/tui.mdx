شغّل OpenCode من مشروعك، واكتب طلبًا، واضغط **Enter**.

```bash
cd ~/code/my-project
opencode
```

```text
Explain how authentication works in this project
```

اضغط **Shift+Enter** أو **Ctrl+Enter** أو **Alt+Enter** أو **Ctrl+J** لإدراج سطر جديد. أثناء عمل OpenCode، اضغط **Enter** لتوجيه الجلسة النشطة بالمطالبة؛ أو اضغط **Ctrl+X** ثم **Enter** لإضافتها إلى قائمة الانتظار.

## السياق

اكتب `@` للبحث عن ملف، ثم اختره لإرفاقه بالمطالبة. وتابع الكتابة بعد `@` لتضييق النتائج.

```text
Review @src/auth.ts for error handling problems
```

ويمكنك تضمين سطر أو نطاق بعد المسار.

```text
Explain @src/auth.ts#20-45
```

## shell

اكتب `!` في بداية مطالبة فارغة لدخول وضع shell. وأدخل أمرًا واضغط **Enter**؛ واضغط **Esc** للخروج من وضع shell دون تشغيل أمر.

```text
!git status
```

وتعمل أوامر shell في مجلد عمل الجلسة ويبقى مخرجها في الجلسة.

## الأوامر

اكتب `/` لسرد أوامر الشرطة المائلة. وتابع الكتابة لتصفية القائمة، ثم اضغط **Enter** لتشغيل الأمر المختار.

```text
/models
```

ومن الأوامر الشائعة `/new` و`/sessions` و`/models` و`/agents` و`/undo` و`/redo` و`/editor`. واضغط **Ctrl+P** لفتح لوحة الأوامر لكل إجراء متاح في العرض الحالي.

بعد التحديث، يعرض OpenCode مستجدات الإصدار مرة واحدة على الشاشة الرئيسية. شغّل `/highlights` لعرضها مجددًا، أو اضبط `"highlights": false` في [`cli.json`](/cli/config#alerts) لمنع فتحها تلقائيًا.

## أسئلة جانبية

شغّل `/btw <question>` لطرح سؤال سريع عن المحادثة حتى الآن. وتستخدم الإجابة سياق الجلسة ونموذجها الحالي لكنها لا تُضاف إلى المحادثة، فلا تؤثر في المطالبات اللاحقة. ويظهر مؤشر `/btw` في تذييل المطالبة أثناء عمله، وتُفتح الإجابة في مربع حوار؛ واضغط **C** لنسخها.

```text
/btw why did the test in step 2 fail?
```

## النماذج

اضغط **Ctrl+X** ثم **M** لاختيار نموذج، أو شغّل `/models`. واضغط **F2** للتنقل بين النماذج المستخدمة حديثًا.

واضغط **Ctrl+X** ثم **A** لاختيار وكيل، أو شغّل `/agents`. واضغط **Shift+Tab** للتنقل بين الوكلاء.

## الجلسات

اضغط **Ctrl+X** ثم **N** لبدء جلسة جديدة. واضغط **Ctrl+X** ثم **L** أو شغّل `/sessions` للعودة إلى جلسة قائمة؛ ويفتح **Ctrl+O** الجلسات والمشاريع الحديثة معًا.

وعلامات التبويب مفعّلة افتراضيًا. استخدم **Ctrl+Tab** و**Ctrl+Shift+Tab** للتنقل بينها، و**Ctrl+X** ثم **W** لإغلاق واحدة، و**Ctrl+Shift+T** لإعادة فتح آخر علامة تبويب مغلقة.

## السجل

اضغط **Ctrl+X** ثم **U**، أو شغّل `/undo`، للتراجع عن آخر رسالة مستخدم والعمل الذي تلاها. وتعود المطالبة المتراجَع عنها إلى مربع الإدخال لتتمكن من تحريرها.

واضغط **Ctrl+X** ثم **R**، أو شغّل `/redo`، لاستعادة العمل المتراجَع عنه. وإرسال مطالبة جديدة بدلًا من ذلك يقبل التراجع ويكمل من تلك النقطة.

## المحرر

اضبط `VISUAL` أو `EDITOR`، ثم اضغط **Ctrl+X** ثم **E**، أو شغّل `/editor`، لتحرير المطالبة الحالية في ذلك المحرر. احفظ واخرج لإعادة النص إلى مربع الإدخال، ثم اضغط **Enter** لإرساله.

```bash
export EDITOR="nvim"
opencode
```

مفتاح القائد هو **Ctrl+X** افتراضيًا. راجع [اختصارات لوحة المفاتيح](/cli/keybinds) لتغيير هذه الاختصارات.
