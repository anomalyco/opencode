---

يأتي OpenCode بسمات مدمجة كثيرة للأوضاع الفاتحة والداكنة. اختر واحدة في الإعدادات، أو امزج ألوانك.

## اختيار سمة

اضغط `Ctrl+P`، واختر **Open settings**، ثم افتح **Theme**. والسمة الافتراضية `opencode`. ولا يزال الافتراضي السابق متاحًا باسم `opencode-classic`.

ويمكنك أيضًا ضبط السمة والوضع في [إعدادات CLI](/cli/config) العامة:

```json title="~/.config/opencode/cli.json"
{
  "$schema": "https://opencode.ai/v2/cli.json",
  "theme": {
    "name": "tokyonight",
    "mode": "dark"
  }
}
```

وشغّل `/themes` لتغيير السمات دون فتح الإعدادات.

## ألوان النظام

عندما يستطيع OpenCode قراءة لوحة ألوان الطرفية، تظهر سمة `system` في قائمة اختيار السمات. وتستمد هذه السمة ألوانها من لوني الواجهة الأمامية والخلفية ومن لوحة ANSI في الطرفية.

واسم السمة `system` يختار الألوان المشتقة من الطرفية. والوضع `system` يتبع مظهر الطرفية الفاتح أو الداكن.

## الوضع

استخدم `system` لاتباع مظهر طرفيتك، أو اقفل السمة على الوضع الفاتح أو الداكن:

| الوضع | السلوك |
| --- | --- |
| `system` | يتبع مظهر الطرفية الفاتح أو الداكن المكتشف. |
| `dark` | يستخدم ألوان السمة الداكنة دائمًا. |
| `light` | يستخدم ألوان السمة الفاتحة دائمًا. |

ويقابل ذلك حقل `mode` داخل `theme` في إعداد CLI لديك. وإذا وفّرت سمة مخصّصة وضعًا واحدًا فقط، استخدم OpenCode ذلك الوضع عند طلب الآخر.

## إضافة سمة

لإضافة سمة نزّلتها أو تلقيتها من غيرك، انسخ ملف JSON الخاص بها إلى مجلد السمات العام:

```bash
cp theme.json ~/.config/opencode/themes/
```

ويمكنك أيضًا وضع السمة في مجلد `.opencode/themes` في مشروع لتتوفر في ذلك المشروع فقط.

واسم الملف يصبح اسم السمة. فمثلًا يظهر `my-theme.json` باسم `my-theme`. وأعد تشغيل OpenCode بعد إضافة الملف، ثم شغّل `/themes` لاختيارها.

ولا يقرأ OpenCode إلا ملفات `.json`. والسمة الأقرب إلى المجلد الحالي تحل محل سمة عامة أو في مجلد أعلى بالاسم نفسه.

## استخدام السمات في الملحقات

تقرأ [ملحقات TUI](/build/plugins/cli) الألوان المحلولة عبر `context.theme` والوضع النشط عبر `context.themeMode`. واستخدم رموزًا دلالية ليتبع ملحقك السمة المختارة:

```tsx title="Inside a TUI plugin component"
import { usePlugin } from "@opencode/plugin/tui"

function Status() {
  const context = usePlugin()
  return <text fg={context.theme.text.base}>Ready</text>
}
```

ولا تسجّل واجهة ملحقات TUI العامة سمات. فأضف تعريفات السمات المخصّصة بملفات JSON في المجلدات أعلاه.

## إنشاء سمة

استخدم [أداة السمات](https://opencode.ai/theme/) لإنشاء السمات أو تحريرها. فهي تسهّل فهم البنية وتغييرها وتعريف ألوان مخصّصة. والشرح أدناه للمرجع.

وتفصل السمة بين الرموز الدلالية المشتركة ولوحات كل وضع:

| القسم | الغرض |
| --- | --- |
| `base` | شجرة الرموز الكاملة التي تتشاركها كل الأوضاع. |
| `light` و`dark` | لوحة تدرّجات كاملة وتجاوزات رموز اختيارية لذلك الوضع. |

وكل سمة توفّر `base` كاملًا وتعرّف `light` أو `dark` على الأقل. وترث الأوضاع من `base` في الملف؛ ولا ترث من سمة OpenCode المدمجة ولا من بعضها.

وتعرض الأمثلة أدناه الأقسام ذات الصلة بكل مفهوم فقط. واستخدم محرر السمات لتوليد ملف كامل قبل تخصيصه.

### البنية

ضع الألوان التي يستخدمها الوضعان في `base`، ثم تجاوزها داخل `light` أو `dark` عند الحاجة:

```json title="theme.json (excerpt)"
{
  "$schema": "https://opencode.ai/theme.json",
  "base": {
    "text": {
      "base": "$hue.neutral.200",
      "muted": "$hue.neutral.400"
    }
  },
  "light": {
    "hue": {}
  },
  "dark": {
    "hue": {},
    "text": {
      "muted": "$hue.neutral.300"
    }
  }
}
```

و`base` الكامل يوفّر كل رمز دلالي. وكل وضع يوفّر كل تدرّج مطلوب وقد يتجاوز أي جزء من شجرة رموز الأساس.

### الألوان والإشارات

يمكن أن يكون اللون قيمة سداسية أو `"transparent"` أو إشارة إلى لون سمة آخر:

```json title="Inside base or a mode"
{
  "text": {
    "base": "#eeeeee",
    "muted": "$hue.neutral.400"
  },
  "border": {
    "base": "$text.muted"
  }
}
```

### التدرّجات

التدرّجات سلالم ألوان من تسع درجات. ويعرّف كل وضع التدرّجات الأساسية الثمانية والثلاثة المستعارة:

| النوع | القيم |
| --- | --- |
| أساس | `gray` و`red` و`orange` و`yellow` و`green` و`cyan` و`blue` و`purple` |
| مستعار | `accent` و`interactive` و`neutral` |
| درجة | `100` و`200` و`300` و`400` و`500` و`600` و`700` و`800` و`900` |

وعرّف الدرجات التسع كلها لتدرّج أساسي، أو اجعل تدرّجًا مستعارًا لتدرّج آخر:

```json title="Inside light or dark"
{
  "hue": {
    "purple": {
      "100": "#b38ff4",
      "200": "#9d7cd8",
      "300": "#8869bd",
      "400": "#7357a2",
      "500": "#5f4688",
      "600": "#4b356f",
      "700": "#392557",
      "800": "#271640",
      "900": "#17072b"
    },
    "accent": "$hue.purple"
  }
}
```

وتتبع درجات التدرّج اتجاه التباين في الوضع. فالسمات الفاتحة تمتد من الداكن عند `100` إلى الفاتح عند `900`؛ والداكنة من الفاتح عند `100` إلى الداكن عند `900`.

وتضبط مصفوفة `categorical` في `base` التدرّجات المرتّبة المستخدمة للتمييز بين الوكلاء وغيرهم من العناصر المتكررة:

```json title="Inside base"
{
  "categorical": ["accent", "purple", "green", "blue"]
}
```

### الرموز الدلالية

تسند الرموز الدلالية الألوان إلى أدوار الواجهة. وتستخدم المكوّنات هذه الأدوار بدل اختيار الألوان مباشرةً.

| المجموعة | الغرض |
| --- | --- |
| `text` | نص الأساس والخافت والضعيف والتحديد والإجراء وحقول النماذج والملاحظات. و`faint` يؤول إلى `muted`. |
| `background` | تعبئات الأساس والتحديد والأسطح المرتفعة والإجراءات وحقول النماذج والملاحظات. |
| `border` و`scrollbar` | ألوان الحدود وأشرطة التمرير. |
| `diff` | ألوان المضاف والمحذوف والسياق والإبراز وأرقام الأسطر. |
| `syntax` | إبراز شفرة المصدر. |
| `markdown` | عناصر Markdown. |

مثلًا، يتحكم `text.muted` في النص الثانوي بينما يعرّف `background.raised` أسطحًا متصاعدة:

```json title="Inside base"
{
  "text": {
    "base": "$hue.neutral.200",
    "muted": "$hue.neutral.400"
  },
  "background": {
    "base": "$hue.neutral.800",
    "raised": {
      "base": "$hue.neutral.700",
      "high": "$hue.neutral.600",
      "max": "$hue.neutral.500"
    }
  }
}
```

ويلوّن `text.selection` و`background.selection` النص الذي تحدّده بالفأرة أو بلوحة المفاتيح. ويؤولان إلى الإجراء الأساسي المركّز، `text.action.primary.$focused` على `background.action.primary.$focused`.

ومفاتيح Syntax هي `comment` و`keyword` و`function` و`variable` و`string` و`number` و`type` و`operator` و`punctuation`.

ومفاتيح Markdown هي `text` و`heading` و`link` و`linkText` و`code` و`blockQuote` و`emphasis` و`strong` و`horizontalRule` و`listItem` و`listEnumeration` و`image` و`imageText` و`codeBlock`.

### الإجراءات والحالات

للإجراءات متغيّرات `primary` و`secondary` و`destructive`. وتستخدم الإجراءات وحقول النماذج `base` إضافة إلى حالات تفاعل اختيارية:

```json title="Inside base or a mode"
{
  "text": {
    "action": {
      "primary": {
        "base": "$hue.interactive.400",
        "$hovered": "$hue.interactive.300",
        "$disabled": "$hue.neutral.600"
      }
    }
  }
}
```

ومفاتيح الحالات هي `$hovered` و`$focused` و`$pressed` و`$selected` و`$disabled`. والحالة غير المحدّدة تستخدم لون `base` لذلك الإجراء أو حقل النموذج.

### سطح مربع الحوار

تختار اللوحات ومربعات الحوار والقوائم والإشعارات عمقها من `background.raised`. وقد تتجاوز مربعات الحوار الرموز الدلالية بـ`@dialog`:

```json title="Inside base or a mode"
{
  "@dialog": {
    "background": {
      "base": "$background.raised.base",
      "action": {
        "primary": {
          "$hovered": "$background.raised.high"
        }
      }
    }
  }
}
```

تعيد واجهة TUI تحديد القيم التي تشير إليها المراجع بعد تطبيق `@dialog`، فتأخذ الرموز التي تشير إلى `$background.base` خلفية مربع الحوار. ويُستخدم `base` الخاص بالإجراء في هذا السياق للحالات التي لم تُحدَّد قيمها؛ أما القيم المحدّدة صراحةً لكل حالة فلها الأولوية.
