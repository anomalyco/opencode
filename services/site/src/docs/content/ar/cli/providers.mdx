اربط مزوّدًا في TUI، ثم اختر أحد نماذجه:

```text
/connect
/models
```

ويسرد `/connect` التكاملات المتاحة من الخادم والمشروع الحاليين. اختر مزوّدًا، واختر طريقة
مصادقة إذا أتاح المزوّد أكثر من طريقة، ثم اتبع التعليمات التي تظهر لك.

## TUI

يدعم TUI مفاتيح API وOAuth وأوامر مصادقة المزوّدين. ويفتح OAuth عنوان URL للتفويض أو يعرض
رمزًا لإدخاله؛ واضغط `o` لفتح عنوان URL و`c` لنسخ تفاصيل التفويض.

```text
/connect
# Select OpenAI, then Codex device code (legacy).
```

وشغّل `/connect` مرة أخرى لإضافة حساب آخر. واختيار مزوّد مرتبط أصلًا يفتح قائمة حساباته، حيث يمكنك
تفعيل حساب محفوظ أو إعادة تسميته أو حذفه.

## CLI

استخدم `auth login` لطرق المزوّد نفسها دون فتح TUI. وبدون وسيط مزوّد، يفتح الأمر
منتقي مزوّدين تفاعليًا.

```bash
opencode auth login
```

ومرّر معرّف تكامل أو اسمًا لتخطي المنتقي الأول. واستخدم `--method key` لاختيار إدخال مفتاح API صراحةً.

```bash
opencode auth login anthropic --method key
```

ومعرّفات الطرق خاصة بكل مزوّد. شغّل الأمر دون `--method` لرؤية الطرق المتاحة عندما يكون للمزوّد
أكثر من طريقة.

```bash
opencode auth login openai
```

ويشترط إدخال مفتاح API ونماذج المزوّدين طرفية تفاعلية. كذلك تشترط طرق OAuth التي تطلب منك لصق رمز
تفويض.

## الطرق

يتلقى OpenCode بيانات اعتماد المزوّدين عبر أربع طرق تكامل:

| الطريقة | السلوك |
| --- | --- |
| مفتاح API | يطلب سرًّا ويحفظه كحساب مزوّد. |
| OAuth | يوفّر عنوان URL للمتصفح أو رمز جهاز أو مطالبة رمز تفويض، ثم يحفظ الرموز ويحدّثها عند الدعم. |
| أمر | يشغّل أمر مصادقة يوفّره المزوّد ويحفظ مخرجه القياسي كمفتاح. |
| البيئة | يقرأ متغيّرًا مدعومًا من عملية الخادم دون حفظه. |

ويمكن للمزوّدين إضافة نماذج إلى طريقتي مفتاح API وOAuth لتفاصيل مطلوبة مثل اسم مورد Azure أو نطاق
GitHub Enterprise. ويعرض CLI وTUI تلك النماذج قبل بدء المصادقة.

## البيئة

اضبط متغيّر البيئة المدعوم لمزوّد على عملية الخادم التي تجري طلبات النموذج. ولخادم خاص
لمرة واحدة، مرّره عند بدء الوضع المستقل.

```bash
ANTHROPIC_API_KEY=sk-ant-... opencode --standalone
```

وللخادم الخلفي المشترك، أضف المتغيّر إلى بيئته المُدارة. وهذا يوقف خدمة عاملة؛ ويبدأها أمر
OpenCode التالي بالقيمة الجديدة.

```bash
opencode service set env ANTHROPIC_API_KEY sk-ant-...
opencode auth list
```

وتظهر اتصالات البيئة في `auth list` بالنوع `environment`. وهي ليست حسابات: فلا يستطيع `auth logout`
إزالتها، فأزل ضبط المتغيّر لقطع الاتصال. والحساب المحفوظ له أولوية على اتصال البيئة
للتكامل نفسه.

```bash
opencode auth list
opencode service unset env ANTHROPIC_API_KEY
```

يعتمد بعض المزوّدين أيضًا على تسلسلهم المعتاد للبحث عن بيانات الاعتماد المتاحة في البيئة بدلًا من متغيّر مفتاح API:

- يدعم Amazon Bedrock سلسلة بيانات الاعتماد الافتراضية في AWS، بما في ذلك ملفات التعريف وبيئات مفاتيح الوصول والهوية عبر الويب
  وبيانات اعتماد الحاويات. ويدعم أيضًا `AWS_BEARER_TOKEN_BEDROCK`.
- ويستخدم Google Vertex بيانات الاعتماد الافتراضية للتطبيق ومشروعًا قابلًا للحل. مثلًا، صادق بـ
  `gcloud auth application-default login` واضبط `GOOGLE_CLOUD_PROJECT`.
- ويعرض Azure **Microsoft Entra ID (Azure CLI)** طريقةَ ربط عندما يكون `az` مثبّتًا. شغّل `az login` أولًا، ثم
  اختر تلك الطريقة في `/connect` أو `auth login azure`.

```bash
gcloud auth application-default login
GOOGLE_CLOUD_PROJECT=my-project opencode
```

راجع [المزوّدون](/providers) لإعدادات كل مزوّد وإعداد الخادم.

## الحسابات

كل تسجيل دخول ناجح بمفتاح API أو OAuth أو أمر ينشئ حسابًا محفوظًا. ويصبح أحدث حساب هو النشط؛ وبدّل
الحساب النشط بتسميته أو معرّف بيانات اعتماده.

```bash
opencode auth list
opencode auth switch anthropic work
```

وأزل حسابًا محفوظًا بـ`auth logout`. وكلا الأمرين يفتح منتقيًا عندما تُغفل وسائطه.

```bash
opencode auth logout anthropic work
```

وفي TUI، يوفّر `/connect` عمليات الإضافة والتفعيل وإعادة التسمية والحذف نفسها للحسابات المحفوظة.

## التخزين

تُحفَظ مفاتيح API ورموز OAuth في قاعدة بيانات SQLite الخاصة بالخادم. لعرض مسار قاعدة بيانات الخادم المحلي، شغّل:

```bash
opencode debug paths db
```

والمسار المعتاد في الإصدار هو `~/.local/share/opencode/opencode.db`؛ ويمكن أن تغيّره `XDG_DATA_HOME` وقناة الإصدار و`OPENCODE_DB`.
ولا تحرّر قاعدة البيانات لإدارة بيانات الاعتماد؛ استخدم `/connect` أو أوامر `auth`.

ويستورد V2 بيانات الاعتماد المدعومة من `auth.json` القديم في مجلد بيانات OpenCode أثناء ترحيل
قاعدة بياناته. وتُخزَّن بيانات الاعتماد الجديدة والمحدّثة في SQLite بدل كتابتها مجددًا في ذلك الملف.
