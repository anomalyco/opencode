خصّص عمليات الربط في `cli.json`:

```json title="cli.json"
{
  "keybinds": {
    "leader": "ctrl+space",
    "command.palette.show": "ctrl+k",
    "app.exit": ["ctrl+c", "ctrl+d"],
    "app.debug": false
  },
  "leader": {
    "timeout": 1500
  }
}
```

استخدم سلسلة لمفتاح واحد:

```json
{
  "keybinds": {
    "command.palette.show": "ctrl+k"
  }
}
```

افصل البدائل بفواصل:

```json
{
  "keybinds": {
    "app.exit": "ctrl+c,ctrl+d"
  }
}
```

عطّل ربطًا بـ`"none"` أو `false`:

```json
{
  "keybinds": {
    "app.debug": "none",
    "help.show": false
  }
}
```

استخدم كائنًا لسلوك الحادثة:

```json
{
  "keybinds": {
    "prompt.paste": {
      "key": "ctrl+v",
      "preventDefault": false
    }
  }
}
```

القيمة الافتراضية لـ `leader` هي `ctrl+x`. وتشير `<leader>` في أي اختصار آخر إلى هذا المفتاح.

```json
{
  "keybinds": {
    "leader": "ctrl+space",
    "model.list": "<leader>m"
  },
  "leader": {
    "timeout": 2000
  }
}
```

تُتجاهل معرّفات الأوامر غير المعروفة.

## Mini

يعمل أمر `app.clear` في [`opencode mini`](/cli) وحده. اضغط `ctrl+l` لمسح الشاشة المرئية ورسم المطالبة من جديد. وتحتفظ الطرفية بسجل التمرير.

```json title="cli.json"
{
  "keybinds": {
    "app.clear": "ctrl+l"
  }
}
```

| المعرّف          | الافتراضي  | الوصف      |
| ----------- | -------- | ---------------- |
| `app.clear` | `ctrl+l` | مسح الشاشة |

## عارض Diff

اضغط `d` (`diff.switch_source`) لاختيار **All** أو **Committed** أو **Uncommitted** أو **Last turn** (داخل جلسة)، أو اختر **Base** لتغيير فرع المقارنة. وتُتذكّر الاختيارات حتى يخرج TUI. واضبط النطاق الأولي بـ[`diffs.source` في `cli.json`](/cli/config#diffs).

تتحكم اختصارات التمرير والتنقل بين الصفحات والبداية والنهاية في الفروق دائمًا. ولا يوجد تبديل تركيز بلوحة المفاتيح: انقر الملفات لفتحها، وانقر المجلدات لتوسيعها أو طيّها، واستخدم عجلة الفأرة لتمرير شجرة الملفات.

استخدم `n` / `p` أو `alt+down` / `alt+up` (مفتاح Option على macOS) للتنقل بين الملفات. وفي عارض Diff، تتنقّل اختصارات Alt بين الملفات لا بين علامات تبويب الجلسات.

اضغط `m` لوضع علامة المراجعة على الملف وطيّ تفاصيل تغييراته. وفي عرض جميع الملفات، اضغط `m` مرة أخرى لإزالة العلامة وإظهار التغييرات. في عرض الملف الواحد، ينتقل العارض تلقائيًا إلى الملف التالي عند وضع العلامة، لكنه يتوقف عند الملف الأخير ولا يعود إلى الأول. ولا ينتقل إلى ملف آخر عند إزالة العلامة.

انقر ملفًا بزر الفأرة الأيمن في الشريط الجانبي أو في ترويسة فروقه لـ**Mark complete** (أو **Mark incomplete**). ويغيّر ذلك حالة المراجعة نفسها التي يغيّرها `m`. وإكمال ملف آخر من قائمته لا يختاره ولا يتقدم بالملف الذي تقرأه حاليًا.

| `composer.shell.kill`         | `ctrl+d` | إنهاء أمر shell   |

| `composer.terminal.down`      | `down,j` | الطرفية التالية        |
| `composer.terminal.select`    | `return` | Select terminal      |

اختر أمرًا عاملًا في تبويب **Shell** واضغط **Enter**، أو انقر عليه، لعرض stdout وstderr الملتقطين.
واستخدم **↑/↓** أو **Page Up/Down** أو **Home** للتمرير، و**End** لمتابعة المخرجات الجديدة، و**Esc** للعودة دون إيقاف الأمر.
ويعرض العارض المخرجات الحديثة ويبقى مفتوحًا بعد الخروج؛ ولا تُضمَّن المخرجات المعاد توجيهها إلى ملف.
