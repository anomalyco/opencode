title: "تسخين الجلسة"
description: "أرسل طلبات دورية تمنع انتهاء ذاكرة المطالبات المؤقتة لدى المزوّد أثناء توقفك بين المطالبات."
---

يرسل تسخين الجلسة طلبات نموذج دورية للحفاظ على ذاكرة المطالبات المؤقتة لدى المزوّد
أو غيرها من الحالات قصيرة العمر أثناء توقفك بين المطالبات. وهو
متوقف افتراضيًا.

فعّل التسخين في أي [ملف إعدادات لـ OpenCode](/config):

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "warming": true,
}
```

وبهذا الإعداد، يسخّن OpenCode جلسة نشطة حديثًا قبيل انتهاء
ذاكرة مطالباتها المؤقتة مباشرةً: عند 90% من
[`cache.ttl`](/models#cache-lifetime) للنموذج، أو كل أربع دقائق إذا لم يكن لهذا الإعداد
قيمة للنموذج. ويستمر التسخين حتى تمضي 30 دقيقة على آخر
طلب لا يخصّ التسخين.

## الخيارات

استخدم صيغة الكائن لتغيير مطالبة التسخين أو فترة الخمول أو نافذة
النشاط:

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "warming": {
    "prompt": "Do not perform any work. Reply with exactly: OK",
    "interval": "5 minutes",
    "duration": "1 hour",
  },
}
```

| الحقل | الافتراضي | الغرض |
| --- | --- | --- |
| `prompt` | تعليمة إبقاء الاتصال | تُضاف كرسالة مستخدم عابرة في كل طلب تسخين. والافتراضي يطلب من النموذج عدم أداء أي عمل، وعدم استخدام أي أدوات، والرد بـ `OK`. |
| `interval` | `"auto"` | فترة الخمول قبل طلب التسخين التالي. عند اختيار `"auto"`، تكون الفترة 90% من قيمة `cache.ttl` للنموذج، أو أربع دقائق إذا لم تُضبط تلك القيمة. |
| `duration` | `"30 minutes"` | مدة التسخين بدءًا من آخر طلب إلى النموذج لا يخصّ التسخين. |

تحتفظ حقول الكائن المُغفلة بقيمها الافتراضية. مثلًا، يغيّر هذا الفترة
وحدها:

```jsonc title="opencode.jsonc"
{
  "warming": {
    "interval": "2 minutes",
  },
}
```

## الفترة التلقائية

القيمة الافتراضية لـ `interval` هي `"auto"`، فيرسل OpenCode طلب التسخين قبيل انتهاء صلاحية ذاكرة المطالبات المؤقتة لكل نموذج.
ويستخدم لهذا الغرض 90% من قيمة
[`cache.ttl`](/models#cache-lifetime)، فإذا كانت القيمة `"5m"` أرسل طلبًا كل 4.5 دقيقة. أما النماذج التي لا تُضبط لها `cache.ttl` فتُسخَّن جلساتها كل أربع دقائق.

```jsonc title="opencode.jsonc"
{
  "warming": { "duration": "2 hours" },
  "providers": {
    "anthropic": { "settings": { "cache": { "ttl": "1h" } } },
  },
}
```

والذاكرة التي تدوم أطول من `duration`، مثل `"1h"` مع الافتراضي 30 دقيقة،
لا تُسخَّن، لأنها تتجاوز نافذة التسخين أصلًا. ويسجّل OpenCode ذلك مرة لكل جلسة. وارفع `duration` لتسخينها.

## لكل مزوّد ونموذج

اضبط `settings.cache.warming` على مزوّد أو نموذج لتسخين جلساته وحدها،
أو لمنحها توقيتها الخاص. ويأخذ القيم نفسها التي يأخذها `warming` في الأعلى، عدا `prompt`، ويتجاوزه.
ويتجاوز إعداد النموذج إعداد المزوّد.

```jsonc title="opencode.jsonc"
{
  "providers": {
    "anthropic": {
      "settings": { "cache": { "ttl": "5m", "warming": true } },
      "models": {
        "claude-haiku-5-5": { "settings": { "cache": { "warming": false } } },
      },
    },
  },
}
```

هنا تُسخَّن جلسات Anthropic كل 4.5 دقيقة، باستثناء جلسات Claude Haiku 5.5، ولا تُسخَّن جلسات المزوّدين الآخرين.
والحقول المغفلة في صيغة الكائن تأتي من `warming` في الأعلى، ثم من الافتراضيات. والإعداد غير الصالح يسجّل
تحذيرًا ويعود إلى `warming` في الأعلى.

## المدد

يقبل `interval` و`duration` سلاسل مدد. ويجب أن يؤول كلاهما إلى قيم
منتهية أكبر من صفر، وأن يكون `interval` أقصر من `duration`؛
وإلا تخطّى OpenCode التسخين وسجّل تحذيرًا.

```jsonc title="opencode.jsonc"
{
  "warming": {
    "interval": "30 seconds",
    "duration": "1 hour",
  },
}
```

## التوقيت

يبدأ التسخين بعد طلب نموذج غير تسخيني في جلسة عليا.
ولا تُسخَّن جلسات الوكلاء الفرعيين. وتُحسب كل فترة من وقت إرسال آخر
طلب أو طلب تسخين، لا من وقت انتهاء استجابته،
لأن عمر ذاكرة المزوّد المؤقتة يبدأ عند وصول الطلب إليه. وطلب التسخين
لا يمدّ نافذة النشاط.

```text
00:00  normal model request sent
00:01  response finishes
00:04  warming request
00:08  warming request
00:30  warming stops
```

وأي نشاط نموذج جديد غير تسخيني، بما في ذلك ضغط السياق، يعيد ضبط المؤقتين.
والفترة الصريحة التي تساوي المدة أو تتجاوزها تُرفض مع
تحذير، وفترة `"auto"` بهذا الطول تتخطى التسخين لأن الذاكرة
تتجاوز النافذة.

```text
00:00  normal model request
00:20  normal model request; window restarts
00:24  warming request
00:50  warming stops
```

ولا يرسل OpenCode طلب تسخين أبدًا أثناء تشغيل طلب نموذج، بما في ذلك
ضغط السياق. فإذا كان طلب ما زال يعمل عند حلول الفترة،
ينتظر التسخين انتهاءه ثم يرسل فورًا، ما دامت ذاكرة
ذلك الطلب لم تنته. وإذا انتهت، يتوقف التسخين حتى الطلب
العادي التالي.

```text
00:00  normal model request sent
00:04  interval due; request still running
00:04:30  response finishes; warming request
00:08:30  warming request
```

## الطلبات

يستخدم طلب التسخين نموذج الجلسة الحالي ووكيلها وتعليماتها
وسياق محادثتها. ويضيف OpenCode المطالبة المضبوطة إضافة عابرة،
ويجري استدعاء نموذج واحدًا، ويتجاهل الاستجابة.

```text
[current session context]
[transient user message: keep-alive prompt]
→ one model response, discarded
```

ولا يقبل الطلب إدخالًا، ولا يضيف رسائل إلى السجل، ولا يغيّر حالة
الجلسة الدائمة. ولا يرسل OpenCode استدعاءات أدوات محلية ولا يواصل حلقة
أدوات؛ والمطالبة الافتراضية تطلب من النموذج أيضًا عدم استخدام الأدوات.

## الإخفاقات

تُسجَّل إخفاقات التسخين دون إفشال الجلسة أو تغييرها. وينتظر OpenCode
حتى الفترة التالية قبل المحاولة مجددًا، بينما تستمر نافذة النشاط الأصلية
في العد التنازلي.

```text
00:04  warming request fails; session is unchanged
00:08  next warming attempt
```

وطلب التسخين الذي يفوّت الذاكرة المؤقتة، فيقرأ منها أقل مما يكتب،
يوقف التسخين لتلك الجلسة حتى طلبها التالي غير التسخيني. والمزوّدون
الذين لا يفيدون باستخدام الذاكرة المؤقتة لا يُحتسب لهم أي تفويت.

```text
00:04  warming request misses the cache; warming stops
00:10  normal model request; warming resumes
00:14  warming request
```

## التكاليف

تصل طلبات التسخين فعليًا إلى المزوّد. وقد تستهلك رموزًا، وتترتّب عليها تكاليف، وتُحتسب ضمن حدود المعدل، وقد تفشل مثل أي طلب آخر إلى النموذج.

- الفترات الأقصر تزيد حجم الطلبات.
- المدد الأطول تتيح مزيدًا من طلبات التسخين.
- لا تفعّل التسخين إلا عندما تستحق فائدته لدى المزوّد الاستخدام الإضافي.

مثلًا، على نموذج بلا `cache.ttl` تتيح الافتراضيات حتى سبع
محاولات تسخين خلال نافذة واحدة متصلة مدتها 30 دقيقة: عند الدقائق 4 و8
و12 و16 و20 و24 و28.

## التعطيل

اضبط `warming` على `false` لتعطيله صراحةً. وإغفال الحقل يبقي
التسخين متوقفًا أيضًا.

```jsonc title="opencode.jsonc"
{
  "warming": false,
}
```
