`@opencode/plugin/effect` هو الإصدار الأصلي في Effect من API ملحقات OpenCode. تعيد عمليات السياق
Effects أو Streams، وتعيد دوال ردّ النداء Effects، ويمثّل `Scope` مدّة عمل الملحق.

ويوفّر OpenCode `effect` (بما في ذلك المسارات الفرعية المصدّرة `effect/*`) و`@opencode/plugin` وقت التشغيل عند تحميل
الملحقات وتبعياتها في `node_modules`. ثبّتهما ضمن التبعيات النظيرة وتبعيات التطوير للتحقّق من الأنواع والاختبار محليًا
بدل تضمينهما في ملحقك.

```sh
bun add --peer @opencode/plugin effect@4.0.1
```

وصدّر ملحق Effect من `.opencode/plugins/` ليُحمَّل تلقائيًا.

```ts title=".opencode/plugins/concise/index.ts"
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "example",
  effect: (ctx) =>
    Effect.gen(function* () {
      const storage = ctx.storage
      yield* storage.set("loaded", true)
    }),
})
```

وتستخدم الحزم المنشورة ومجلدات الملحقات خارج `.opencode/plugins/` إعداد `plugins` نفسه الذي تستخدمه ملحقات
الخادم الأخرى.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": [
    "opencode-acme-effect-plugin",
    "opencode-acme-effect-plugin@1.2.0",
    "@acme/opencode-effect-plugin",
    "./plugins/local-effect",
    {
      "package": "@acme/opencode-effect-plugin",
      "options": { "agent": "reviewer", "strict": true },
    },
  ],
}
```

راجع [إعداد الملحقات](/plugins) للتفعيل وتحليل الحزم وأسبقية الإعداد.

```ts title="plugins/local-effect/index.ts"
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "local-effect",
  effect: (ctx) =>
    Effect.gen(function* () {
      yield* Effect.logInfo("Effect plugin loaded", { version: ctx.app.version })
    }),
})
```

## دورة الحياة

يعمل `effect` عند تحميل الملحق. ويُغلق نطاقه عند إعادة تحميل الملحق أو إلغاء تحميله، فيتولّى النطاق إلغاء التسجيلات وإيقاف وحدات التنفيذ الخفيفة (fibers)
المرتبطة به وتشغيل دوال الإنهاء، ضمن عملية التنظيف نفسها.

```ts
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "lifecycle",
  effect: (ctx) =>
    Effect.gen(function* () {
      yield* Effect.logInfo("loaded", { version: ctx.app.version })
      yield* Effect.addFinalizer(() => Effect.logInfo("unloaded"))
    }),
})
```

استخدم وحدات تنفيذ خفيفة مرتبطة بنطاق لتشغيل المهام في الخلفية. ويوقف نطاق الملحق هذه الوحدات أثناء تحرير موارده.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const storage = ctx.storage
    yield* Effect.repeat(
      storage.set("heartbeat", { time: Date.now() }),
      { schedule: Schedule.spaced("1 minute") },
    ).pipe(Effect.forkScoped)
  }),
```

### السياق

ويعرض السياق عميل Effect لخادم OpenCode المرتبط، إضافة إلى تحويلات وخطافات وتخزين وإعادات تحميل وخيارات
خاصة بالملحقات. ولا يعرض خدمات Core الخاصة في OpenCode.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const plugins = ctx.plugin
    const active = yield* plugins.list().pipe(Effect.orDie)
    yield* Effect.logInfo("active plugins", { count: active.data.length })
  }),
```

## التحويلات

تعدّل التحويلات الحالة تزامنيًا عبر محرّر. ويطبّق OpenCode التحويلات بترتيب التسجيل داخل كل
نطاق. وتوفّر المصادر أولًا المزوّدين وتعريفات النماذج غير القابلة للتغيير، ثم تعدّل تحويلات النماذج قائمة النماذج المرشّحة لدى
المزوّدين النشطين. ويبقى التسجيل في نطاق الملحق عند إرجاعه إلى Effect عبر المُولِّد.

```ts title="plugins/models-effect/index.ts"
import { Model, Plugin, Provider } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "company.models",
  effect: (ctx) =>
    Effect.gen(function* () {
      const providerID = Provider.ID.make("acme")
      const models = [{ ...Model.Info.default(providerID, Model.ID.make("reasoner")), name: "Acme Reasoner" }]
      yield* ctx.provider.transform((editor) => {
        editor.add({
          info: {
            ...Provider.Info.empty(providerID),
            name: "Acme",
            activation: "enabled",
            package: "@opencode/ai/providers/openai-compatible",
            settings: { baseURL: "http://127.0.0.1:8000/v1" },
          },
          models,
        })
      })
    }),
})
```

يمكن لتحويل النماذج فرض سياسة تسري على جميع النماذج المرشّحة لدى المزوّدين النشطين.

```ts title="plugins/model-budget-effect/index.ts"
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.model.transform((editor) => {
      editor
        .list()
        .filter((model) => model.cost.some((tier) => tier.output > 20))
        .forEach((model) => {
          editor.remove(model.providerID, model.id)
        })
    })
  }),
```

واستدعِ `reload` عندما تتغيّر حالة خارجية يستخدمها تحويل. وهنا، تعيد `loadFromSource()`
إدخالات `{ info: Provider.Info, models: readonly Model.Info[] }`؛ كما تُبطل إعادات تحميل المزوّد نتيجة النماذج كاملة.

```ts title="plugins/models-effect/index.ts"
effect: (ctx) =>
  Effect.gen(function* () {
    const provider = ctx.provider
    const source = { providers: yield* loadFromSource() }

    yield* provider.transform((editor) => {
      source.providers.forEach((provider) => editor.add(provider))
    })

    yield* Effect.repeat(
      Effect.gen(function* () {
        source.providers = yield* loadFromSource()
        yield* provider.reload()
      }),
      { schedule: Schedule.spaced("1 minute") },
    ).pipe(Effect.forkScoped)
  }),
```

## API

### الوكيل

اقرأ كل الوكلاء أو اجلب وكيلًا بمعرّفه. وتضم استجابات العميل الموقع المحلول وبيانات المخطط.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const agent = ctx.agent
    const agents = yield* agent.list().pipe(Effect.orDie)
    const build = yield* agent.get({ agentID: Agent.ID.make("build") }).pipe(Effect.orDie)
    yield* Effect.logInfo("agents", { count: agents.data.length, build: build.data.name })
  }),
```

حوّل الوكلاء أو أعد تحميلهم.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const agent = ctx.agent
    yield* agent.transform((editor) => {
      editor.default("build")
      editor.update("build", (item) => (item.description = "Builds features and fixes bugs"))
      editor.remove("legacy")
    })
    yield* agent.reload()
  }),
```

Schema: [`Agent.Info`](/api#schema-Agent.Info).

```ts
interface AgentEditor {
  list(): readonly Types.DeepMutable<Agent.Info>[]
  get(id: string): Types.DeepMutable<Agent.Info> | undefined
  default(id: string | undefined): void
  update(id: string, update: (agent: Types.DeepMutable<Agent.Info>) => void): void
  remove(id: string): void
}

interface AgentDomain extends AgentApi<unknown> {
  readonly transform: Transform<AgentEditor>
  readonly reload: () => Effect.Effect<void>
}
```

### المزوّدون

اقرأ المزوّدين المتاحين أو افحص بيانات مزوّد واحد الوصفية بمعرّفه.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const provider = ctx.provider
    const providers = yield* provider.list().pipe(Effect.orDie)
    const anthropic = yield* provider.get({ providerID: Provider.ID.make("anthropic") }).pipe(Effect.orDie)
    yield* Effect.logInfo("providers", {
      providers: providers.data.length,
      anthropic: anthropic.data.name,
    })
  }),
```

وتعدّل تحويلات المزوّد إعدادات المزوّد وتعريفات المصادر. وتضم قراءات المحرّر المزوّدين غير النشطين وتعرض
تعريفات غير قابلة للتغيير؛ ويعدّل `models.update` نسخة مملوكة من نموذج مصدر.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.provider.transform((editor) => {
      editor.update("anthropic", (provider) => {
        provider.headers = { ...provider.headers, "x-company": "engineering" }
      })
      editor.models.update("anthropic", "claude-sonnet-5-5", (model) => (model.name = "Team Sonnet"))
      editor.models.remove("anthropic", "legacy-model")
      editor.remove("legacy-provider")
    })
  }),
```

واستبدل جرد مصدر بـ`models.set`، ثم أعد التحميل بعد تغيّر تعريفاته الملتقطة.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const provider = ctx.provider
    const source = { models: yield* loadModels() }
    yield* provider.transform((editor) => editor.models.set("acme", source.models))
    source.models = yield* loadModels()
    yield* provider.reload()
  }),
```

وللاكتشاف الخاص بحساب، مرّر الاتصال المستخدم لتحميل الجرد كـ`sourceConnection`. ويستبعد OpenCode
ذلك المزوّد ما دام اتصال آخر مختارًا، حتى ينشر ملحقك جرده المحدّث.

{/* prettier-ignore */}
```ts
const connection = yield* ctx.integration.connection.active("acme")
if (!connection) return
const inventory = yield* loadInventory(connection)
yield* ctx.provider.transform((editor) => {
  editor.add({ info: inventory.provider, models: inventory.models, sourceConnection: connection })
})
```

Schemas: [`Provider.Info`](/api#schema-Provider.Info), [`Model.Info`](/api#schema-Model.Info).

```ts
interface ProviderRecord {
  readonly provider: Provider.Info
  readonly models: ReadonlyMap<string, Model.Info>
  readonly sourceConnection?: ConnectionInfo
}

interface ProviderEditor {
  list(): readonly ProviderRecord[]
  get(providerID: string): ProviderRecord | undefined
  add(input: { info: Provider.Info; models: readonly Model.Info[]; sourceConnection?: ConnectionInfo }): void
  update(providerID: string, update: (provider: Types.DeepMutable<Provider.Info>) => void): void
  remove(providerID: string): void
  readonly models: {
    set(providerID: string, models: readonly Model.Info[]): void
    update(providerID: string, modelID: string, update: (model: Types.DeepMutable<Model.Info>) => void): void
    remove(providerID: string, modelID: string): void
  }
}

interface ProviderDomain extends ProviderApi<unknown> {
  readonly transform: Transform<ProviderEditor>

}
```

### النماذج

اقرأ النماذج المتاحة والاختيار الافتراضي.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const model = ctx.model
    const models = yield* model.list().pipe(Effect.orDie)
    const selected = yield* model.default().pipe(Effect.orDie)
    yield* Effect.logInfo("models", { count: models.data.length, selected: selected.data?.name })
  }),
```

تعدّل تحويلات النماذج المجموعة الكاملة للنماذج المرشّحة لدى المزوّدين النشطين. ويمكن تعديل النماذج المعطّلة إلى أن تنتهي كل
التحويلات، ولا يستطيع `update` إضافة نموذج إلا إلى مزوّد متاح.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.model.transform((editor) => {
      editor.list("anthropic").forEach((model) => {
        editor.update(model.providerID, model.id, (draft) => {
          draft.enabled = draft.capabilities.tools
        })
      })
      editor.default.set("anthropic", "claude-sonnet-5-5")
      editor.remove("anthropic", "legacy-model")
    })
  }),
```

وتعدّل ردود النداء تجاوزات النموذج الخام. وتُدمج افتراضيات المزوّد مرة واحدة عندما يثبّت OpenCode النتيجة؛ وتعيد القراءات غير المتغيّرة
استخدام تلك النتيجة. ويقرأ `editor.provider` تعريفات المصادر غير القابلة للتغيير، بما في ذلك القوالب غير النشطة، لا
مخرجات تحويل النموذج.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const model = ctx.model
    yield* model.transform((editor) => {
      const source = editor.provider.get("anthropic")?.models.get("claude-sonnet-5-5")
      if (!source) return
      editor.update("anthropic", source.id, (draft) => {
        draft.limit.context = Math.min(draft.limit.context, source.limit.context)
      })
    })
    yield* model.reload()
  }),
```

Schema: [`Model.Info`](/api#schema-Model.Info).

```ts

  list(providerID?: string): readonly Types.DeepMutable<Model.Info>[]
  get(providerID: string, modelID: string): Types.DeepMutable<Model.Info> | undefined
  update(providerID: string, modelID: string, update: (model: Types.DeepMutable<Model.Info>) => void): void
  remove(providerID: string, modelID: string): void
  readonly default: {
    get(): { providerID: string; modelID: string } | undefined

```

### الأوامر

اقرأ الأوامر المتاحة في الموقع الحالي.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const command = ctx.command
    const commands = yield* command.list().pipe(Effect.orDie)
    yield* Effect.logInfo("commands", { names: commands.data.map((item) => item.name) })
  }),
```

وتحويل الأوامر الحالي للإضافة فقط. ويتلقى المنفّذ الجلسة ومرفقات المطالبة ووضع التسليم.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const command = ctx.command
    const session = ctx.session
    yield* command.transform((editor) => {
      editor.add({
        name: "security-review",
        description: "Review changes for security issues",
        execute: (input) =>
          session.prompt({
            ...input.prompt,
            sessionID: input.sessionID,
            text: `Review these changes for security issues.\n\n${input.prompt.text}`,
            delivery: input.delivery,
          }).pipe(Effect.asVoid),
      })
    })
    yield* command.reload()
  }),
```

Schemas: [`Command.Info`](/api#schema-Command.Info),
[`Session.Inbox.Delivery`](/api#schema-Session.Inbox.Delivery).


### التكاملات

اقرأ التكاملات وحلّ بيانات الاعتماد النشطة عندما توجد.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const integration = ctx.integration
    const integrations = yield* integration.list().pipe(Effect.orDie)
    const github = yield* integration.get({ integrationID: Integration.ID.make("github") }).pipe(Effect.orDie)
    const connection = yield* integration.connection.active("github")
    const credential = connection ? yield* integration.connection.resolve(connection).pipe(Effect.orDie) : undefined
    yield* Effect.logInfo("integration", {
      count: integrations.data.length,
      github: github.data.name,
      credential: credential?.type,
    })
  }),
```

واتصل بمفتاح أو أدر محاولة OAuth عبر الواجهة المرتبطة.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const integration = ctx.integration
    const token = yield* Config.Redacted("GITHUB_TOKEN").pipe(Effect.orDie)
    yield* integration.connect
      .key({ integrationID: Integration.ID.make("github"), key: Redacted.value(token) })
      .pipe(Effect.orDie)

    const attempt = yield* integration.oauth
      .connect({
        integrationID: Integration.ID.make("acme"),
        methodID: Integration.MethodID.make("oauth"),
      })
      .pipe(Effect.orDie)
    const status = yield* integration.oauth
      .status({
        integrationID: Integration.ID.make("acme"),
        attemptID: attempt.data.attemptID,
      })
      .pipe(Effect.orDie)
    yield* Effect.logInfo("OAuth status", { status: status.data })
  }),
```

حوّل التكاملات وطرق المصادقة. وردود نداء طرق OAuth هي Effects وقد تحصل على موارد
محدودة النطاق.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const integration = ctx.integration
    yield* integration.transform((editor) => {
      editor.update("acme", (item) => (item.name = "Acme"))
      editor.method.update({
        integrationID: "acme",
        method: { id: "device", type: "oauth", label: "Sign in with Acme" },
        authorize: () =>
          Effect.succeed({
            mode: "code",
            url: "https://acme.example/device",
            instructions: "Enter the displayed code",
            callback: (code) => exchangeCode(code),
          }),
      })
    })
    yield* integration.reload()
  }),
```

Schemas: [`Integration.Info`](/api#schema-Integration.Info), [`Integration.Method`](/api#schema-Integration.Method),
[`Connection.Info`](/api#schema-Connection.Info), [`Form.Answer`](/api#schema-Form.Answer).

```ts

  readonly url: string
  readonly instructions: string
  readonly expiresAt?: number

)

  readonly integrationID: string

}

}

  readonly transform: Transform<IntegrationEditor>

  }
}
```

### MCP

اسرد خوادم MCP وحالة اتصالها الحالية.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const mcp = ctx.mcp
    const servers = yield* mcp.list().pipe(Effect.orDie)
    yield* Effect.logInfo("MCP servers", { count: servers.data.length })
  }),
```

ولا تدير الملحقات خوادم MCP إلا عبر التحويلات. واستخدم `editor.set` لإضافة خادم أو استبداله، و`editor.update`
لتغيير إعداده، و`editor.remove` لإزالته. وافحص الإعداد بـ`editor.list` و`editor.get`.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const mcp = ctx.mcp
    yield* mcp.transform((editor) => {
      const servers = editor.list()
      const docs = editor.get("docs")
      editor.set("docs", { type: "remote", url: "https://mcp.example.com" })
      editor.update("docs", (server) => (server.disabled = false))
      editor.remove("legacy")
    })
  }),
```

### الأدوات

سجّل أدوات محدّدة النوع بـ`Schema` في Effect. ويتلقى المنفّذ إدخالًا مفكوك الترميز ويعيد Effectًا يحتوي مخرجات
محدّدة النوع أو محتوى عرض أو بيانات وصفية.

ويدعم المحرّر `add` و`update` و`remove`. ورد نداء التحويل متزامن: فلا يجوز أن يعيد Effect أو Promise. وحمّل
البيانات الخارجية قبل التسجيل أو إعادة التحميل. ويعيد OpenCode تشغيل التحويلات النشطة بترتيب التسجيل على محرّر
جديد؛ ولاسم الأداة الفعّال نفسه، يسود تسجيل صالح لاحق على تسجيل سابق.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const tool = ctx.tool
    yield* tool.transform((editor) => {
      editor.namespace({
        name: "acme",
        description: "Customer account tools",
      })
      editor.add({
        name: "greeting",
        description: "Create a greeting",
        input: Schema.Struct({ name: Schema.String }),
        output: Schema.Struct({ greeting: Schema.String }),
        options: { namespace: "acme", codemode: true },
        execute: ({ name }, context) =>
          Effect.gen(function* () {
            yield* context.progress({ status: "greeting" })
            return { output: { greeting: `Hello ${name}!` } }
          }),
      })
    })
  }),
```

واستدعِ `yield* ctx.tool.reload()` بعد تغيير بيانات المصدر التي التقطها رد النداء. فإعادة التحميل تعيد تشغيل التحويلات النشطة
دون تغيير ترتيبها؛ وهي لا تعيد تشغيل Effect الخاص بالملحق.

وتقبل أدوات Effect [إعلان الإدخال الحر](/build/plugins/server#freeform-tool-input) نفسه الذي تقبله أدوات Promise. وإذا لم يعلن النموذج تلك الصيغة، تحتفظ الأداة بإدخالها الكائني العادي.

وللأدوات `id` يحتوي اسمها الفعّال، ويعيد `get()` القيمة `undefined` عندما يغيب ذلك المعرّف. واستخدم
`update` و`remove` باسم الأداة الفعّال، بما في ذلك نطاقها (`acme_greeting` أعلاه). والنقاط في
النطاقات والأحرف غير المدعومة في أسماء الأدوات تصبح `_`. وتُتجاهل الأسماء الغائبة؛ وإنشاء أداة يحتاج
`add` بتعريف كامل. وتحفظ التحديثات الاسم والنطاق. وعيّن مخططات أو خيارات جديدة لتستبدلها
بدل تعديل القيم المتداخلة. وتُسجّل التحديثات غير الصالحة وتُبقي التعريف السابق سليمًا.

{/* prettier-ignore */}
```ts
yield* ctx.tool.transform((editor) => {
  editor.update("acme_greeting", (tool) => {
    tool.description = "Greet the user by name"
  })
  editor.remove("acme_obsolete")
})
```

وتُعاد التحديثات والإزالات بالترتيب مع الإضافات، بما في ذلك بعد تحديثات كتالوج MCP.

ويعيد `transform` تسجيلًا محدود النطاق. وشغّل `yield* registration.dispose` لإزالة تحويله وإعادة البناء
من التحويلات المتبقية، فيعود أيّ تعريف سابق حلّ هذا التحويل محلّه. ولا يترتّب على تكرار الإلغاء أيّ أثر إضافي. ويؤدّي إغلاق
نطاق الملحق أيضًا إلى إلغاء تسجيلاته.

وكل طلب نموذج يلتقط لقطة أدوات. وتؤثر إعادة التحميل والتخلص في اللقطات المستقبلية، لا في التعريفات أو
المنفّذين الذين التقطهم طلب قائم أصلًا. والمنفّذون الذين يغلقون على بيانات ملحق متغيّرة يلاحظون
تلك البيانات مع ذلك؛ فالتقط قيمة داخل التحويل عندما يجب أن تبقى مرتبطة بذلك التعريف.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const event = ctx.event
    yield* event.subscribe({ types: ["config.updated"] }).pipe(
      Stream.runForEach(() => Effect.logInfo("configuration changed")),
```

## الخطافات

تعترض الخطافات العمليات الجارية. ويمكن لعدة ملحقات تسجيل الخطاف نفسه؛ ويشغّلها OpenCode بترتيب الملحقات
فترى الخطافات اللاحقة التغييرات السابقة. وتبقى التسجيلات نشطة طوال نطاق الملحق.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const session = ctx.session
    yield* session.hook("context", () => Effect.void)
  }),
```

### الجلسات

عدّل تعليمات النظام المجمّعة أو الرسائل أو الأدوات قبل إرسال الطلب إلى النموذج مباشرةً. ويعمل `context` في حلقة
الوكيل؛ ويعمل `compaction` و`generate` و`title` لتلك الطلبات المساعدة. ويقبل `compaction` و`title`
`result` يتخطى استدعاء النموذج.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const session = ctx.session
    yield* session.hook("context", (event) =>
      Effect.sync(() => {
        event.system.push({ type: "text", text: "Keep the review focused on correctness." })
        delete event.tools.write
      }),
    )
    yield* session.hook("compaction", (event) =>
      Effect.map(summarize(event.messages), (summary) => {
        event.result = { summary }
      }),
    )
  }),
```

وتحمل الرسائل في خطافات `context` و`compaction` و`generate` بيانات `metadata` لرسالتها المخزّنة، للقراءة فقط
(مثلًا ما ضبطه خطاف `prompt`). ولا تُرسل إلى النموذج.

ويسرد جزء `system` الذي يحمل تعليمات OpenCode كل مصدر أيضًا في `metadata.experimental.instructions` كـ
`{ key, text }`، مثل `core/date` أو `core/environment`، ليستطيع الخطاف تمييز المصادر. والقائمة نسخة:
فتعديل `text` في الجزء لا يحدّثها. وهذه ميزة تجريبية قد تتغيّر.

عدّل إعدادات طلب النموذج وحدّد نطاق الخطاف لمزوّد واحد اختياريًا. ويحمل الحدث `kind` نفسه
الذي تحمله خطافات HTTP أدناه.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const session = ctx.session
    yield* session.hook(
      "model.request",
      (event) => Effect.sync(() => (event.headers["x-plugin"] = "review")),
      { providerID: "anthropic" },
    )
  }),
```

عدّل طلبات المزوّد الأصلية أو استجاباته. فأجسامها تدفقات تُقرأ مرة واحدة؛ فانسخ الجسم أو استبدله قبل
قراءته. ويعمل الخطافان لكل طلب تصدره الجلسة؛ و`event.kind` هو `"primary"` أو `"compaction"` أو `"title"` أو
`"generate"` حسب التدفق الذي أصدره.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const session = ctx.session
    yield* session.hook("http.request", (event) =>
      Effect.sync(() => {
        event.request.headers.set("x-session-id", event.sessionID)
        if (event.kind === "title") event.request.headers.set("x-priority", "background")
      }),
    )
    yield* session.hook("http.response", (event) =>
      Effect.sync(() => {
        event.response = new Response(event.response.body, {
          status: event.response.status,
          headers: { ...Object.fromEntries(event.response.headers), "x-plugin": "review" },
        })
      }),
    )
  }),
```

والمزوّدون الذين يبثّون عبر WebSocket يعيدون استخدام اتصال واحد لكل جلسة، فلا ترى خطافات HTTP تلك الحركة أبدًا. ويعمل
خطاف `experimental.ws.handshake` التجريبي مرة لكل استدعاء نموذج قبل اختيار الاتصال ويعرض
`url` و`headers` للاتصال؛ وتغيير أي منهما يعيد فتح المقبس. ولا تزال خطافات HTTP تعمل لأي طلب
يعود إليه مسار WebSocket.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.session.hook(
      "experimental.ws.handshake",
      (event) =>
        Effect.gen(function* () {
          event.headers.authorization = `Bearer ${yield* mintToken(event.url)}`
          delete event.headers["api-key"]
        }),
      { providerID: "azure" },
    )
  }),
```

ويعرض `experimental.ws.send` و`experimental.ws.receive` الإطارات نفسها: فيعمل `send` بعد بناء سائق
المزوّد إطارًا صادرًا، ويعمل `receive` على كل إطار وارد قبل أن يلاحظه السائق. وما يحمله `frame` عند إرجاع الخطاف هو ما يعبر السلك أو يصل إلى السائق؛
ولا يتحقق منه OpenCode.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.session.hook(
      "experimental.ws.send",
      (event) =>
        Effect.sync(() => {
          const body = JSON.parse(event.frame)
          if (body.type === "response.create") body.metadata = { ...body.metadata, session: event.sessionID }
          event.frame = JSON.stringify(body)
        }),
      { providerID: "openai" },
    )
  }),
```

تجاوز قرار إعادة المحاولة لفشل مزوّد أو استبدل مهلة التأخير بالمللي ثانية. ويعمل الخطاف بعد أن يصنّف OpenCode
الفشل ويقترح سياسته، لكن قبل جدولة أي إعادة محاولة. ولا يعرض كيفية إجراء OpenCode
للمحاولة التالية داخليًا.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    yield* ctx.session.hook("retry", (event) =>
      Effect.sync(() => {
        if (event.error.status === 429) {
          event.decision = { retry: true, delay: 10_000 }
          return
        }
        if (event.error.type === "provider.invalid-request" && event.attempt === 2) {
          event.decision = { retry: true, delay: 0 }
          return
        }
        if (event.attempt >= 3) event.decision = { retry: false }
      }),
    )
  }),
```

و`decision` الأولي هو سياسة OpenCode، فيمكن للخطافات جعل فشل مزوّد نهائي عادةً قابلًا لإعادة المحاولة أو نقض
إعادة محاولة مقترحة. وتعمل عدة خطافات بترتيب التسجيل وترى الخطافات اللاحقة القرار الحالي. ويبقى الحد الأقصى المدمج
لعدد المحاولات حدًّا صارمًا. و`attempt` المحاولة الفعلية المقترحة؛ فالطلب الأولي المحاولة `1`،
وأول إعادة محاولة المحاولة `2`. والتأخيرات غير الصالحة (`NaN` أو اللانهاية أو القيم السالبة) تعود إلى التأخير المحسوب.
ويبقى التعافي من فائض السياق منفصلًا لأنه يضغط المحادثة بدل إعادة محاولة الطلب نفسه.

```ts
effect: (ctx) =>
```

### الأدوات

يمكن للخطافات التي تعمل قبل التنفيذ استبدال الإدخال أو إيقاف التنفيذ بخطأ `Tool.Error`.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const tool = ctx.tool
    yield* tool.hook("execute.before", (event) =>
      event.tool === "write"
        ? Effect.fail(new Tool.Error({ message: "Writes are disabled" }))
        : Effect.logDebug("tool input", { tool: event.tool, input: event.input }),
    )
  }),
```

يمكن للخطافات التي تعمل بعد التنفيذ فحص النتائج الناجحة والأخطاء أو استبدالها.

```ts
effect: (ctx) =>
  Effect.gen(function* () {
    const tool = ctx.tool
    yield* tool.hook("execute.after", (event) => {
      if (event.status === "error") return Effect.logWarning("tool failed", { message: event.error.message })
      return Effect.sync(() => {
        event.result = { ...event.result, metadata: { observed: true } }
      })
    })
  }),
```

## النشر

ويستخدم ملحق الحزمة التصدير الافتراضي نفسه الذي يستخدمه ملحق Effect محلي. فصدّر تطبيق Effect من نقطة الدخول
الرئيسية وأعلن `effect` كـ`peerDependency`. وتحت `devDependencies`، ثبّت الإصدار الذي يستخدمه `@opencode/plugin`
ليثبّت التطوير نسخة واحدة فقط.

```json title="package.json"
{
  "name": "opencode-acme-effect-plugin",
  "version": "1.0.0",
  "type": "module",
  "exports": {
    ".": "./src/index.ts"
  },
  "dependencies": {
    "@opencode/plugin": "latest"
  },
  "peerDependencies": {
    "effect": "^4.0.1"
  },
  "devDependencies": {
    "effect": "4.0.1"
  }
}
```

ويعيد OpenCode توجيه استيرادات `effect` والمسارات الفرعية المصدّرة `effect/*` و`@opencode/plugin` (بما في ذلك الاستيرادات من
التبعيات في `node_modules` الخاصة بالملحق) إلى نسخ وقت التشغيل في المضيف، لكي تتشارك وحدات التنفيذ الخفيفة وأدوات التسجيل ومحلّلات `Schema`
نسخة وقت تشغيل واحدة.

- لا تضمّن `effect` في ناتج الملحق المنشور. وإذا استخدمت أداة تجميع أثناء البناء، فاجعل `effect` و`effect/*`
  خارجيين.
- تنفّذ الملحقات وتوابعها في `node_modules` دائمًا مقابل نسخة `effect` الخاصة بإصدار OpenCode المضيف.
  فاستخدم واجهات `effect` ومسارات وحداته المتوافقة مع إصدار OpenCode الذي تستهدفه؛ والتوابع المبنية على إصدار
  `effect` رئيسي آخر (مثل Effect 3) تتلقى `effect` المضيف أيضًا ولا تُدعم.
- ولا تُوفَّر إلا المسارات الفرعية العامة لـ`effect`. والملحق الذي يستورد أحد وحدات `internal` الخاصة في Effect يفشل في
  التحميل بخطأ يسمّي المسار.
- ولا يتضمن ملف OpenCode المترجم أصول Scalar وSwagger UI التي تستخدمها صفحات وثائق HTTP API في Effect؛
  وعرض تلك الصفحات من ملحق يُظهر إشعارًا بدلًا من ذلك.

وتصدّر نقطة دخول الحزمة `Plugin.define` بدالة `effect`.

```ts title="src/index.ts"
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"

export default Plugin.define({
  id: "acme.published",
  effect: (ctx) =>
    Effect.gen(function* () {
      const storage = ctx.storage
      yield* storage.set("installed", true)
    }),
})
```

واستخدم إصدارات متوافقة مع إصدار OpenCode الذي تستهدفه واختبر الحزمة المثبّتة لا
نسخة مرتبطة بمساحة عمل فقط.

```sh
bun pm pack
bun add ./opencode-acme-effect-plugin-1.0.0.tgz
```
