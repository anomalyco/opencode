يمكن لـ OpenCode تنسيق الملفات بعد أن تغيّرها أدوات `write` أو `edit` أو `patch`.
والمنسّقات متوقفة افتراضيًا، ففعّلها في إعدادك:

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "formatter": true,
}
```

## التفعيل

اضبط `formatter` على `true` لتفعيل جميع المنسّقات المدمجة. ولا يشغّل OpenCode أي منسّق مدمج
إلا إذا كان ملفه التنفيذي متاحًا وتوفّرت أي متطلبات خاصة بالمشروع.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "formatter": true,
}
```

وصيغة الكائن تفعّل المدمجات أيضًا وتتيح تجاوزها أو إضافة منسّقات
مخصّصة. والكائن الفارغ يحفظ إعدادات المنسّقات الموروثة، بينما تعيد `true`
ضبطها على المدمجات.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "formatter": {},
}
```

## المدمجة

يتضمن OpenCode تعريفات المنسّقات هذه. ومعظمها يشترط توفر الأمر
المسمّى؛ والتعريفات ذات قواعد الكشف الإضافية مذكورة أدناه.

وتشغيلها للملفات المطابقة:

```jsonc title="opencode.jsonc"
{
  "formatter": true,
}
```

## التخصيص

أضف إدخالًا مسمّى لتغيير منسّق مدمج أو تعريف منسّق مخصّص. ويحتاج المنسّق المخصّص
إلى `command` و`extensions` معًا ليعمل.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "formatter": {
    "prettier": {
      "environment": {
        "NODE_ENV": "development",
      },
      "extensions": [".js", ".ts"],
    },
    "deno-markdown": {
      "command": ["deno", "fmt", "$FILE"],
      "extensions": [".md"],
    },
  },
}
```

| الحقل | النوع | السلوك |
| --- | --- | --- |
| `disabled` | `boolean` | يزيل المنسّق المسمّى عندما يكون `true`. |
| `command` | `string[]` | يحل محل الأمر المدمج أو يعرّف أمرًا مخصّصًا. |
| `environment` | `Record<string, string>` | يضيف متغيّرات بيئة مع الحفاظ على بيئة الوالد. |
| `extensions` | `string[]` | يحل محل قائمة الامتدادات المدمجة أو يعرّف القائمة المخصّصة. أدرج النقطة البادئة. |

كل الحقول اختيارية. فالإدخال المدمج يرث القيم المُغفلة، بينما الإدخال الجديد
الذي بلا أمر أو امتدادات لا يستطيع العمل.

```jsonc title="opencode.jsonc"
{
  "formatter": {
    "prettier": {
      "extensions": [".md", ".mdx"],
    },
  },
}
```

## الأوامر

`command` مصفوفة وسائط، لا سلسلة أمر shell. فيستبدل OpenCode
`$FILE` بالمسار المطلق للملف ويشغّل الأمر من مجلد
المشروع النشط.

```jsonc title="opencode.jsonc"
{
  "formatter": {
    "custom": {
      "command": ["custom-fmt", "--write", "$FILE"],
      "extensions": [".custom"],
    },
  },
}
```

## المطابقة

يقارن OpenCode امتداد الملف الأخير بـ`extensions`. والمطابقة
حساسة لحالة الأحرف، والإدخالات المركبة مثل `.part.md` لا تطابق
`notes.part.md` لأن امتداده الأخير `.md`.

```jsonc title="opencode.jsonc"
{
  "formatter": {
    "markdown": {
      "command": ["deno", "fmt", "$FILE"],
      "extensions": [".md"],
    },
  },
}
```

وعندما تطابق عدة منسّقات، يجرّبها OpenCode بترتيب التسجيل
ويتوقف بعد أول أمر ناجح. وتحتفظ المدمجات بترتيبها
المدمج؛ وتتبع الإدخالات المخصّصة بترتيب الكائن. وإذا فشل أحدها،
يسجّل OpenCode الفشل ويجرّب المطابقة التالية.

```jsonc title="opencode.jsonc"
{
  "formatter": {
    "preferred": {
      "command": ["preferred-fmt", "$FILE"],
      "extensions": [".foo"],
    },
    "fallback": {
      "command": ["fallback-fmt", "$FILE"],
      "extensions": [".foo"],
    },
  },
}
```

## التعطيل

يكون التنسيق متوقفًا عندما لا يضبط أي ملف الإعداد `formatter`. ولتعطيل
تنسيق فعّله ملف أقل أولوية، اضبطه على `false`.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "formatter": false,
}
```

ولتعطيل منسّق مدمج واحد مع إبقاء الآخرين مفعّلين، علّم إدخاله المسمّى
معطّلًا.

```jsonc title="opencode.jsonc"
{
  "formatter": {
    "prettier": {
      "disabled": true,
    },
  },
}
```
