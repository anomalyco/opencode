تتيح لك Console API استدعاء النماذج وتصدير بيانات الاستخدام من البرامج النصية والتكاملات. ويتطلّب كل طلب مفتاح API
للمصادقة.

```bash
curl --fail-with-body "https://opencode.ai/inference/v1/models" \
  --header "Authorization: Bearer oc_sk_..."
```

| API                                       | نقاط النهاية                                      |
| ----------------------------------------- | ------------------------------------------------- |
| [النماذج](/console/api/models)             | `https://opencode.ai/console/api/v1/models`       |
| [الاستدلال](/console/api/inference)       | `https://opencode.ai/inference/...`               |
| [المزوّدون](/console/api/providers)        | `https://opencode.ai/inference/custom/...`        |
| [تصدير الاستخدام](/console/api/usage-export) | `https://opencode.ai/console/api/v2/usage/export` |

## مفاتيح API

يمكن لأعضاء مساحة العمل وحسابات الخدمة على السواء أن يملكوا مفاتيح API. أرسل المفتاح كرمز bearer.

```text
Authorization: Bearer oc_sk_...
```

|                  | مفتاح API شخصي                                        | مفتاح حساب خدمة                                                      |
| ---------------- | ------------------------------------------------------ | ------------------------------------------------------------------------ |
| يُنشئه            | أي عضو، لنفسه                                          | المالك والمسؤول                                                        |
| يُنشأ في          | **Account › Personal API keys**                        | **Settings › Service accounts**                                          |
| يعمل بصفة         | العضو الذي أنشأه                                       | حساب الخدمة                                                              |
| يُحتسب استخدامه على | [ميزانية](/console/budgets#member-budgets) العضو      | [ميزانية](/console/budgets#service-account-budgets) حساب الخدمة           |
| الأنسب لـ          | برامجك النصية و[أدوات harness](/console/harnesses)    | CI والأجهزة المشتركة والتكاملات                                          |

- يعمل كل مفتاح في مساحة عمل واحدة، تُختار عند إنشائه. ولا حاجة إلى ترويسة مساحة عمل.
- يُعرض المفتاح كاملًا مرة واحدة فقط، بعد إنشائه مباشرةً. وبعد ذلك لا تعرض Console إلا بادئته.
- **Expiration** اختياري: **Never** أو **1 day** أو **7 days** أو **30 days** أو **Custom** (من 1 إلى 365 يومًا). ولا يمكن تجديد مفتاح
  منتهٍ، فأنشئ مفتاحًا جديدًا.

## مفاتيح API الشخصية

يعمل المفتاح الشخصي نيابةً عنك، وتسري عليه صلاحيات دورك و[ميزانياتك](/console/budgets#member-budgets) وقواعد النماذج.

1. افتح **Account** من قائمة الحساب وابحث عن **Personal API keys**.
2. انقر **Add API key**.
3. اختر **Workspace** و**Key name** و**Expiration** اختياريًا. ويختار المالك والمسؤول أيضًا
   **Permissions**.
4. انقر **Create** وانسخ المفتاح.

```text
oc_sk_1a2b3c4d5e6f_...
```

يتبع المفتاح وصولك الحالي إلى مساحة العمل. فإذا تغيّر دورك، تغيّر ما يستطيعه المفتاح. وإذا كانت
مساحة العمل تفرض [SSO](/console/sso#sso-enforcement)، فلا يعمل المفتاح إلا ما دامت لديك جلسة SSO نشطة، إلا إذا
كنت مالكًا.

## حسابات الخدمة

حساب الخدمة عضو غير بشري في مساحة العمل، له مفاتيح API واستخدام و[ميزانية](/console/budgets#service-account-budgets)
خاصة به. استخدمه للأتمتة، فلا يرتبط الاستخدام بشخص. ويديره المالك والمسؤول.

1. افتح **Settings › Service accounts** وانقر **Add Service Account**، ثم سمّه، مثلًا `CI Pipeline`.
2. افتح حساب الخدمة وانقر **Add API Key**.
3. اختر **Key name** و**Expiration** اختياريًا و**Permissions**، ثم انقر **Create**.
4. انسخ المفتاح.

```bash
export SERVICE_API_KEY="oc_sk_..."
```

ويمكن للمالك والمسؤول إعادة تسمية مفتاح حساب خدمة أو تغيير أذونه لاحقًا بـ **Edit…** في قائمة إجراءات
المفتاح.

## الأذونات

لكل مفتاح مستوى إذن، يُختار تحت **Permissions** عند إنشائه.

| الأذونات       | يتيح                                                                               |
| -------------- | ------------------------------------------------------------------------------------ |
| **All**        | كل ما يستطيعه العضو أو حساب الخدمة، باستثناء **This account's API keys**. |
| **Restricted** | الموارد التي تختارها وحدها.                                                       |
| **Read only**  | وصول للقراءة إلى كل الموارد. فيسرد المفتاح النماذج دون استدعائها.            |

لا يتجاوز المفتاح أبدًا صلاحيات من يعمل بصفته. فالمفتاح الشخصي محدود بدور العضو الحالي، ومفتاح حساب
الخدمة محدود بـ[ما تستطيعه حسابات الخدمة](#limitations).

### المفاتيح المقيّدة

اضبط كل مورد على **None** أو **Read** أو **Write**. وتشمل **Write** الإذن **Read**.

| المورد                    | المستويات             |
| ------------------------- | --------------------- |
| **Models**                | **Read** و**Request** |
| **Usage**                 | **Read**              |
| **Budgets**               | **Read** و**Write**   |
| **Members**               | **Read** و**Write**   |
| **Providers**             | **Read** و**Write**   |
| **Billing**               | **Read** و**Write**   |
| **Workspace settings**    | **Read** و**Write**   |
| **SSO**                   | **Read**              |
| **Service accounts**      | **Read**              |
| **This account's API keys** | **Write**           |

يسرد **Models › Read** النماذج، ويستدعيها **Models › Request** أيضًا عبر واجهتي [الاستدلال](/console/api/inference)
و[المزوّدين](/console/api/providers). فمثلًا، يحتاج المفتاح الذي يستدعي النماذج فقط إلى:

```text
Permissions: Restricted
Models:      Request
```

أما المفاتيح المنشأة بصيغة **Inference only** قبل الأذونات المحدّدة النطاق فتظهر بـ **Restricted** و**Models** مضبوطًا على **Request**.

### من يمكنه منح الأذونات

- يستطيع **الأعضاء** إنشاء مفاتيح شخصية تسرد النماذج وتستدعيها فقط. وتعرض Console «This key can list and call
  models as you.» بدل خيارات الأذونات.
- ويمكن **للمالكين والمسؤولين** منح مفاتيحهم الشخصية **All** أو **Restricted** أو **Read only**، في حدود صلاحيات أدوارهم.
  والافتراضي **Restricted** و**Models** مضبوطًا على **Request**. وإذا خُفِّض دورهم لاحقًا، تقلّ صلاحيات مفاتيحهم
  تبعًا لذلك.
- تأتي **مفاتيح حسابات الخدمة** افتراضيًا بـ **All**. ويختار المالك والمسؤول أذونها.

### القيود

لا يمكن تنفيذ بعض الإجراءات إلا بعد تسجيل الدخول إلى Console، ولا يُسمح بإنشاء مفاتيح باستخدام مفتاح آخر إلا ضمن قيود صارمة.

- لا يستطيع أي مفتاح API تغيير إعدادات SSO أو حذف مساحة العمل.
- لا تستطيع مفاتيح حسابات الخدمة دعوة أعضاء، ولا تغيير الأدوار، ولا إزالة أعضاء، ولا إدارة الفوترة، ولا تغيير إعدادات مساحة العمل،
  ولا إدارة النماذج، ولا إنشاء حسابات خدمة أو إزالتها، حتى مع **All**.
- لا يتاح **This account's API keys** إلا في مفاتيح حسابات الخدمة، ولا يشمله **All**. ويستطيع المفتاح الذي يملكه
  إنشاء مفاتيح لحساب الخدمة الخاص به وإلغاؤها فقط. ويجب أن تكون المفاتيح الجديدة **Restricted**، وفي حدود
  أذون المفتاح المنشئ، وألا تشمل **This account's API keys**.
- لا تحصل المفاتيح الشخصية أبدًا على **This account's API keys**، ولا يستطيع أي مفتاح API إنشاء مفاتيح API شخصية أو إلغاؤها.

وتعيد الطلبات الخارجة عن أذون المفتاح HTTP `403`.

## الإلغاء

| المفتاح             | من يلغيه                | المكان                                                                             |
| ------------------- | ---------------------- | --------------------------------------------------------------------------------- |
| مفتاح API شخصي      | العضو الذي يملكه       | **Account › Personal API keys**، ثم **Revoke**                                  |
| مفتاح API شخصي      | المالك والمسؤول        | صفحة العضو في **Settings › Members**، تحت **API Keys**                   |
| مفتاح حساب خدمة     | المالك والمسؤول        | صفحة حساب الخدمة في **Settings › Service accounts**، تحت **API Keys** |

وتُلغى المفاتيح تلقائيًا أيضًا:

- إذا غادر عضو مساحة العمل أو أُزيل منها أو أُلغيت صلاحية وصوله عبر [SCIM](/console/scim)، يُلغى كل مفتاح
  أنشأه ذلك الشخص فيها، بما في ذلك مفاتيح حسابات الخدمة. وتواصل المفاتيح الأخرى على حساب الخدمة نفسه عملها.
- إزالة حساب خدمة تلغي جميع مفاتيحه.

تتوقف المفاتيح الملغاة والمنتهية عن العمل فورًا وتعيد HTTP `401`.
