يعيد `GET https://opencode.ai/console/api/v2/usage/export` استخدام مساحة عمل بصيغة CSV، بصف واحد لكل يوم بتوقيت UTC،
وعضو أو حساب خدمة، ومزوّد، ونموذج. وهو الملف نفسه الذي ينزّله زر **Export usage** من
**Activity › Usage**.

```bash
curl --fail-with-body "https://opencode.ai/console/api/v2/usage/export?range=30d" \
  --header "Authorization: Bearer oc_sk_..." \
  --output usage-30d.csv
```

## المصادقة

أرسل [مفتاح API](/console/api#api-keys) بصفته رمز bearer. يتيح المفتاح تصدير بيانات استخدام مساحة العمل التي أُنشئ فيها.

```text
Authorization: Bearer oc_sk_...
```

ويحتاج المفتاح إلى **Usage › Read**. وتملكه المفاتيح ذات **All** أو **Read only**. ويحتاج المفتاح المقيّد إلى:

```text
Permissions: Restricted
Usage:       Read
```

استخدم [مفتاح حساب خدمة](/console/api#service-accounts) للتصديرات المجدولة، أو
[مفتاح API شخصي](/console/api#personal-api-keys) لمالك أو مسؤول. ولا يستطيع الأعضاء قراءة استخدام مساحة العمل، لذا تعيد
مفاتيحهم `403`.

## الطلب

| المعامل   | مطلوب   | القيمة                                                                                                                 |
| --------- | -------- | --------------------------------------------------------------------------------------------------------------------- |
| `range`   | نعم      | `7d` أو `30d` أو `90d`.                                                                                                |
| `user_id` | لا       | معرّف عضو (`user_...`) أو معرّف حساب خدمة (`svcacct_...`). ويعيد صفوف ذلك العضو أو حساب الخدمة وحدها. |

يُحتسب `range` بالأيام بتوقيت UTC ويشمل اليوم الحالي. على سبيل المثال، يشمل `7d` اليوم والأيام الـ6 السابقة له. ويستمر تحديث بيانات اليوم
حتى منتصف الليل بتوقيت UTC.

ولتصدير استخدام حساب خدمة واحد، مرّر معرّفه من عمود `user_id` في تصدير سابق:

```bash
curl --fail-with-body "https://opencode.ai/console/api/v2/usage/export?range=7d&user_id=svcacct_01JD8Z4Q2W7N3K5M6P9R0S1T2V" \
  --header "Authorization: Bearer oc_sk_..."
```

ويعيد المعرّف غير الموجود في مساحة العمل صف الترويسة وحده.

## الاستجابة

يعيد الطلب الناجح `200` مع `Content-Type: text/csv; charset=utf-8`. والسطر الأول هو الترويسة. وتتبعها
الصفوف، بدءًا بأحدث يوم.

```csv
day,user_type,user_id,user_name,provider,model,requests,input_tokens,output_tokens,cache_read_tokens,cache_write_5m_tokens,cache_write_1h_tokens,cost_micro_cents,cost_usd
2026-11-24,service_account,svcacct_01JD8Z4Q2W7N3K5M6P9R0S1T2V,CI Pipeline,opencode,claude-sonnet-5-5,412,1830211,96402,5120330,210044,0,1512334800,15.123348
2026-11-24,member,user_01JC2X7Y8Z9A0B1C2D3E4F5G6H,ada@example.com,opencode,claude-haiku-5-5,57,402118,31877,880012,0,0,214500000,2.145
2026-11-23,member,user_01JC2X7Y8Z9A0B1C2D3E4F5G6H,ada@example.com,opencode,claude-sonnet-5-5,96,711560,48210,2204118,61022,0,587000000,5.87
```

- تنتهي الأسطر بـ `\r\n`.
- الأيام التي بلا استخدام ليس لها صفوف.
- الاستجابة تنزيل (`Content-Disposition: attachment; filename="usage-30d.csv"`) ولا تُخزَّن مؤقتًا أبدًا
  (`Cache-Control: private, no-store`).
- خلية نصية تبدأ بـ `=` أو `+` أو `-` أو `@` تُسبق بعلامة `'`، حتى لا تنفّذها جداول البيانات كصيغة.

### الأعمدة

| العمود                  | المعنى                                                                                                       |
| ----------------------- | ------------------------------------------------------------------------------------------------------------- |
| `day`                   | تاريخ UTC، بصيغة `YYYY-MM-DD`.                                                                                |
| `user_type`             | `member` أو `service_account`.                                                                                |
| `user_id`               | معرّف العضو أو حساب الخدمة.                                                                         |
| `user_name`             | بريد العضو الإلكتروني، أو اسم حساب الخدمة. وقد يكون فارغًا.                                              |
| `provider`              | المزوّد الذي عالج الطلبات، مثل `opencode` لـ [OpenCode Models](/console/models).             |
| `model`                 | معرّف النموذج.                                                                                 |
| `requests`              | عدد الطلبات.                                                                                           |
| `input_tokens`          | رموز الإدخال.                                                                                 |
| `output_tokens`         | رموز الإخراج.                                                                                |
| `cache_read_tokens`     | الرموز المقروءة من ذاكرة المطالبات المؤقتة.                                                                            |
| `cache_write_5m_tokens` | الرموز المكتوبة في ذاكرة المطالبات المؤقتة بعمر 5 دقائق.                                                  |
| `cache_write_1h_tokens` | الرموز المخزّنة مؤقتًا للمطالبات لمدة 1 ساعة.                                                    |
| `cost_micro_cents`      | التكلفة عددًا صحيحًا من أجزاء المليون من السنت. فالدولار الأمريكي الواحد `100000000`.                                          |
| `cost_usd`              | التكلفة نفسها بالدولار الأمريكي، كسرًا عشريًا دقيقًا بخانتين عشريتين على الأقل، مثل `2.145` أو `0.00`. |

### ما يتضمنه التصدير

- كل طلب نموذج يجريه أعضاء مساحة العمل وحسابات الخدمة.
- تُضمَّن طلبات النماذج المجانية، والطلبات التي يجريها الأعضاء عبر اشتراكاتهم الخاصة في Claude Code أو Codex أو OpenCode،
  برموزها بتكلفة صفر.
- لا يُضمَّن [البحث على الويب](/console/websearch) وغيره من الخدمات المُستضافة.
- قد تتأخر الإجماليات عن الطلبات الجديدة بنحو دقيقة.

## الحدود

- يغطي التصدير الواحد 90 يومًا كحد أقصى. وللاحتفاظ بسجل أطول، احفظ الملفات وفق جدول.
- تُحتسب الطلبات ضمن حد Console API البالغ 300 طلب في الدقيقة لكل حساب، المشترك مع نقاط نهايته الأخرى.
  وتُحتسب الطلبات التي تستخدم مفاتيح API الشخصية ضمن حدّ العضو مالك المفتاح.

## الأخطاء

| الحالة | المعنى                                                                                               |
| ------ | ----------------------------------------------------------------------------------------------------- |
| `400`  | `range` مفقود أو ليس `7d` أو `30d` أو `90d`، أو `user_id` ليس معرّف عضو أو حساب خدمة. |
| `401`  | لا توجد بيانات اعتماد، أو مفتاح منتهٍ أو ملغى.                                                         |
| `403`  | لا يملك المفتاح **Usage › Read**، أو ينتمي إلى عضو ليس مالكًا أو مسؤولًا.         |
| `429`  | تجاوز حد المعدل. أعد المحاولة بعد عدد الثواني في ترويسة `Retry-After`.                   |
| `503`  | الإجماليات اليومية غير متاحة بعد. أعد الطلب لاحقًا.                                           |
