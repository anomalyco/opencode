اربط حسابات المزوّدين التي تدفع مقابلها بالفعل، مثل Anthropic أو OpenAI أو AWS Bedrock، وشارك نماذجها
مع كل من في مساحة العمل. تخزّن Console بيانات الاعتماد وتقدّم كل مزوّد عبر بوابتها، فيستخدم الأعضاء
النماذج دون أن يروا مفتاح المزوّد أبدًا. والبوابة نفسها متاحة لأدواتك عبر
[API المزوّدين](/console/api/providers).

يدير المالك والمسؤول المزوّدين من تبويب **Providers**. ويحصل الأعضاء على النماذج المفعّلة في OpenCode بعد
تشغيل `/connect`.

## ربط مزوّد

1. افتح **Providers** وانقر **Connect Provider**.
2. اختر مزوّدًا من الكتالوج وأدخل مفتاح API الخاص به.
3. انقر **Test connection** إذا أردت اختبار الاتصال، ثم انقر **Save**.

يشمل الكتالوج Anthropic وOpenAI وGoogle وxAI وDeepSeek وMistral وGroq وOpenRouter وغيرها الكثير. ويأتي مزوّدو الكتالوج
بنماذجهم معدّة مسبقًا.

### مزوّدو السحابة

يحتاج مزوّدو السحابة إلى بعض التفاصيل الإضافية.

| المزوّد               | التفاصيل                              |
| --------------------- | ------------------------------------- |
| Azure                 | اسم المورد ومفتاح API                 |
| AWS Bedrock           | المنطقة ومفتاح API                    |
| Google Vertex AI      | المنطقة وملف JSON لحساب الخدمة        |
| Cloudflare AI Gateway | معرّف الحساب ومعرّف البوابة ورمز API  |
| Databricks            | عنوان URL لمساحة العمل والرمز         |

### مزوّدون مخصّصون

انقر **Add Custom Provider** لربط أي نقطة نهاية أخرى، ثم أضف نماذجها بـ **Add Model**.

| الحقل      | الوصف                                                                          |
| ---------- | ------------------------------------------------------------------------------- |
| Base URL   | الوجهة التي تمرّر إليها Console الطلبات، مثل `https://api.deepseek.com/v1`.     |
| Format     | Chat Completions أو Responses API أو Anthropic Compatible أو Google Generative AI. |
| Auth mode  | Bearer أو ترويسة مفتاح API أو ترويسة مخصّصة.                                    |
| Credential | المفتاح الذي ترسله Console إلى المزوّد.                                          |

## اختيار النماذج

افتح مزوّدًا لترى نماذجه. ولا تتاح للأعضاء إلا النماذج المفعّلة.

- استخدم مفتاح **Enabled** لتشغيل نموذج أو إيقافه.
- فعّل **New models** لتفعيل النماذج التي يضيفها المزوّد مستقبلًا.

## تعديل النماذج

انقر على نموذج لتعديله. تُحفظ التغييرات عند إغلاق اللوحة.

| القسم         | ما يمكنك تغييره                                                  |
| ------------- | --------------------------------------------------------------- |
| General       | اسم العرض ومعرّف API ودعم الأدوات وأنواع الإدخال والإخراج       |
| Variants      | الصيغ البديلة التي لها ترويسات أو جسم طلب خاص بها                |
| Configuration | الصيغة الافتراضية وترويسات الطلب وجسمه وحدود الرموز              |
| Cost Tiers    | أسعار الإدخال والإخراج والقراءة من الذاكرة المؤقتة والكتابة فيها لكل 1M رمز |

### تسعير مخصّص

تبدأ نماذج الكتالوج بسعر قائمة المزوّد. وإذا كانت لديك أسعار متفاوض عليها، مثل خصم على عقدك مع
OpenAI، فتجاوز الأسعار تحت **Cost Tiers** لتطابق تقارير الاستخدام و[الميزانيات](/console/budgets) ما
تدفعه فعلًا.

| الحقل            | سعر القائمة | سعرك  |
| ---------------- | ----------- | ----- |
| سعر الإدخال      | $2.50       | $2.00 |
| سعر الإخراج      | $15.00      | $12.00 |
| سعر قراءة الذاكرة المؤقتة | $0.25 | $0.20 |

تظهر الأسعار التي تغيّرها مميّزة في صفحة المزوّد. واستخدم **Restore default value** في الحقل، أو **⋯ › Restore...**
في النموذج، للعودة إلى سعر القائمة.

أضف فئة **Context** عندما يكلّف النموذج أكثر فوق حجم سياق معيّن، مثلًا للمطالبات التي تتجاوز 200K رمز.

### نماذج مخصّصة

انقر **Add Model** لإضافة نموذج لا يتضمنه الكتالوج، مع **Display name** و**Model ID**. واستخدم
**⋯ › Duplicate...** في نموذج موجود للبدء من إعداداته.

## نماذج OpenCode

يدير تبويب **Models** [النماذج](/console/models) التي تقدّمها Console، والتي تُدفع من رصيد مساحة العمل. وهو
يعمل كصفحة مزوّد:

- فعّل النماذج الفردية أو أوقفها.
- أوقف **Free models** لحجب النماذج المجانية عن مساحة العمل.
- فعّل **New models** لتفعيل نماذج Console الجديدة تلقائيًا.

أوقف المزوّد كاملًا من **⋯ › Disable** لاستخدام مزوّديك وحدهم.

## الاستخدام في OpenCode

يشغّل الأعضاء `/connect` ويختارون مساحة العمل. ويظهر كل مزوّد مفعّل باسم مساحة العمل يتبعه
اسم المزوّد، ويسرد `/models` نماذجه المفعّلة.

```text
Acme Inc. / Anthropic
```

فعّل **Managed providers only** في **Settings › General** لتقييد OpenCode بمزوّدي مساحة العمل
للجميع.

## إرسال الهوية

عندما يكون المزوّد بوابة تديرها أنت، فعّل **Send identity** في صفحته. عندئذٍ تضيف Console ترويسة `x-opencode-actor`
إلى كل طلب نموذج ترسله إليها. وتسمّي الترويسة العضو أو حساب الخدمة صاحب الطلب، فيمكن
لبوابتك تسجيل الطلبات أو تقييدها حسب المرسل.

```text
x-opencode-actor: eyJhbGciOiJFUzI1NiIsInR5cCI6Im9wZW5jb2RlLWFjdG9yK2p3dCIsImtpZCI6Ii4uLiJ9...
```

- وهي متوقفة افتراضيًا، ويؤدي تغيير عنوان URL الأساسي إلى إيقافها.
- لا يعرض المزوّد الذي ما زال على API مورّده، مثل `https://api.openai.com/v1`، هذا الإعداد، لأن
  المورّد يتجاهل الترويسة.
- تحذف Console أي ترويسة `x-opencode-*` يرسلها أي عميل، لذا فإن ترويسة `x-opencode-actor` الوحيدة التي تستقبلها بوابتك هي
  التي وقّعتها Console.
- يستدعي **Test connection** وسرد النماذج `GET <base URL>/models` ببيانات الاعتماد وحدها، فلا تشترط
  الترويسة على ذلك المسار.

### الرمز

الترويسة هي JWT توقّعه Console لكل طلب.

| الحقل        | القيمة                                            |
| ------------ | ------------------------------------------------ |
| `alg`        | `ES256`                                          |
| `typ`        | `opencode-actor+jwt`                             |
| `iss`        | `https://opencode.ai/inference`                  |
| `aud`        | عنوان URL الأساسي للمزوّد دون شرطات مائلة في نهايته         |
| `iat`, `exp` | `exp` بعد `iat` بـ 120 ثانية                     |

| بيان JWT             | القيمة                                                                  |
| -------------------- | ---------------------------------------------------------------------- |
| `sub`                | `user_id` للعضو، و`service_account_id` فيما عدا ذلك                     |
| `workspace_id`       | مساحة العمل التي نُفّذ فيها الطلب                                       |
| `user_id`, `email`   | العضو، عندما يرسل عضو الطلب                                             |
| `service_account_id` | حساب الخدمة، عندما يرسله حساب خدمة (بما في ذلك الوكلاء)                 |
| `session_id`         | معرّف جلسة العميل، عندما يرسل واحدًا                                     |
| `request_id`         | المعرّف الذي يستلمه العميل في ترويسة الاستجابة `x-opencode-log-id`       |

يحمل طلب العضو حمولة مثل هذه:

```json
{
  "iss": "https://opencode.ai/inference",
  "aud": "https://llm.example.com/v1",
  "sub": "user_...",
  "workspace_id": "org_...",
  "user_id": "user_...",
  "email": "ada@example.com",
  "session_id": "ses_...",
  "request_id": "019a6e8f-24a0-7b12-9c3d-4e5f6a7b8c9d",
  "iat": 1794500000,
  "exp": 1794500120
}
```

### التحقق من الرمز

تنشر Console مفاتيحها العامة على `https://opencode.ai/inference/.well-known/jwks.json`، وتُقدَّم مع
`Cache-Control: public, max-age=300`. تحقّق من التوقيع والجهة المُصدرة والجهة المستهدفة ونوع الرمز والمدة المنقضية منذ إصداره، ثم من مساحة العمل. وهذا
المثال يستخدم [jose](https://github.com/panva/jose).

```ts
import { createRemoteJWKSet, jwtVerify } from "jose"

const keys = createRemoteJWKSet(new URL("https://opencode.ai/inference/.well-known/jwks.json"))

export async function sender(request: Request) {
  const token = request.headers.get("x-opencode-actor")
  if (!token) throw new Error("Missing x-opencode-actor")
  const { payload } = await jwtVerify(token, keys, {
    issuer: "https://opencode.ai/inference",
    audience: "https://llm.example.com/v1",
    algorithms: ["ES256"],
    typ: "opencode-actor+jwt",
    maxTokenAge: "120s",
    clockTolerance: "5s",
  })
  if (payload.workspace_id !== "org_...") throw new Error("Another workspace")
  return payload
}
```

اضبط `audience` على عنوان URL الأساسي للمزوّد كما هو محفوظ في Console، من دون شرطات مائلة في نهايته، واستبدل `org_...`
بمعرّف مساحة العمل من عنوان URL الخاص بـ Console. وتنشر Console مفتاح توقيع جديدًا قبل أن توقّع به، لذا يواصل أي مدقّق
يبحث عن المفاتيح بـ `kid`، كما يفعل `createRemoteJWKSet`، عمله خلال تدوير المفاتيح.

## التعطيل أو الإزالة

افتح قائمة **⋯** الخاصة بالمزوّد:

- **Disable** يخفي المزوّد ونماذجه عن الأعضاء لكنه يبقي إعداداته.
- **Remove...** يحذف المزوّد ونماذجه. ويعرض مربع الحوار من استخدمه مؤخرًا، ويقترح
  **Disable instead**.

لاستبدال مفتاح، انقر على بيانات الاعتماد في صفحة المزوّد وأدخل المفتاح الجديد.

## الفوترة

يفوترك المزوّد مقابل الرموز؛ ولا تخصم Console رصيدًا مقابلها. ومع ذلك تسجّل Console كل طلب
وتكلفته باستخدام تسعير النموذج، لذا تشمله تقارير الاستخدام و[الميزانيات](/console/budgets).

ولاستدعاء مزوّد من أدواتك بدل OpenCode، استخدم [API المزوّدين](/console/api/providers).
