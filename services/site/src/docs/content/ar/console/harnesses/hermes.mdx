يتضمّن [Hermes Agent](https://hermes-agent.nousresearch.com) مزوّدي OpenCode للدفع حسب الاستخدام ولاشتراك Go. ويختار
API المناسبة لكل نموذج مدفوع أو نموذج Go. وتتطلّب نماذج المحادثة المجانية استخدام OpenCode، وتُرفض طلباتها من Hermes برمز HTTP `403`.

<Callout>
يتيح لك [Console CLI](/console/harnesses#console-cli) إعداد Hermes بأمر واحد، بما يشمل سياسات مساحة العمل
  وخوادم MCP والمهارات والتعليمات. شغّل `npx @opencode/console setup hermes`. والخطوات أدناه تعدّه
  يدويًا.
</Callout>

| المزوّد        | الخطة          | متغيّر المفتاح           |
| -------------- | ------------- | ---------------------- |
| `opencode-zen` | الدفع حسب الاستخدام | `OPENCODE_ZEN_API_KEY` |
| `opencode-go`  | Go            | `OPENCODE_GO_API_KEY`  |

## الإعداد

شغّل إعداد النموذج واختر **OpenCode Zen** للدفع حسب الاستخدام أو **OpenCode Go** لـ Go.

```bash
hermes model
```

الصق [مفتاح API شخصي](/console/harnesses#get-an-api-key)، ثم اختر نموذجًا. ويحفظ Hermes
المفتاح في `~/.hermes/.env` والاختيار في `~/.hermes/config.yaml`.

```yaml title="~/.hermes/config.yaml"
model:
  provider: opencode-go
  default: kimi-k3
```

<Callout>يتطلّب Go معرّف جلسة في كل طلب. ويرسله Hermes تلقائيًا بدءًا من الإصدار v0.21.6.</Callout>

## النماذج

استخدم معرّفات النماذج من جدول [Console](/console/models#endpoints) أو [Go](/console/go#endpoints) دون بادئة.
وبدّل النماذج في جلسة بـ `/model`، أو اختر نموذجًا لتشغيل واحد.

```bash
hermes chat --provider opencode-zen --model claude-sonnet-5-5
```

## Console MCP

أضف خادم [Console MCP](/console/harnesses#console-mcp) مع OAuth، ثم سجّل الدخول من المتصفح.

```bash
hermes mcp add opencode-console --url https://opencode.ai/console/mcp --auth oauth
hermes mcp login opencode-console
```

أو أضفه إلى `~/.hermes/config.yaml` وشغّل `/reload-mcp` في جلسة.

```yaml title="~/.hermes/config.yaml"
mcp_servers:
  opencode-console:
    url: https://opencode.ai/console/mcp
    auth: oauth
```
