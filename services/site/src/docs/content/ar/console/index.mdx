[OpenCode Console](https://opencode.ai/console) خدمة اختيارية توفّر مزايا إضافية لاستخدام
OpenCode، سواء كنت وحدك أو ضمن فريق.

- [مساحات عمل](/console/workspaces) لمشاركة الوصول مع [فريقك](/console/members)
- [استدلال النماذج](/console/models)، سواء كانت مملوكة أو مفتوحة المصدر
- [مزوّدون](/console/providers) يمكنك ربط حساباتك لديهم عبر بوابة Console
- تتبّع الاستخدام وضوابط [الميزانية](/console/budgets)
- نشر سياسات على مستوى الفريق للتحكم في سلوك OpenCode
- [البحث على الويب](/console/websearch)
- [أدوات harness](/console/harnesses) لاستخدام نماذج Console في Claude Code وCodex ووكلاء آخرين
- [OpenCode Go وGo Plus وGo Teams](/console/go)، اشتراكات للوصول إلى النماذج المفتوحة المصدر بأسعار شهرية تبلغ $10 لـ Go، و$40 لـ Go Plus، و$20/member لـ Go Teams

## البدء

لا تحتاج إلى فريق لاستخدام Console. فكل حساب يبدأ بمساحة عمل **Personal** تكون أنت عضوها الوحيد.

1. سجّل الدخول إلى [Console](https://opencode.ai/console).
2. اشترك في [Go](/console/go)، أو أضف [رصيدًا](/console/billing#add-credits)، أو اربط [مزوّدًا](/console/providers).
3. شغّل `/connect` في OpenCode واختر مساحة العمل.
4. يمكنك [دعوة](/console/members#invite-members) فريقك إن أردت.

```text
/connect
```

## السياسات

تسري قواعد Providers وTools من صفحة Policies على كل عميل OpenCode
متصل بمساحة العمل. وتصل إليه في صورة بنود [سياسة](/policies#console)
لها أسبقية على إعدادات المستخدم والمشروع لدى العضو، وتسري خلال دقيقة تقريبًا.
وتظلّ للتفضيلات المُدارة وملف إعدادات النظام أسبقية على إعدادات مساحة العمل؛
راجع [الأسبقية](/policies#precedence).
