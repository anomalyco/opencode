تقدّم OpenCode Console قائمة نماذج اختبرها فريق OpenCode وتحقق منها. سجّل الدخول، وأضف رصيدًا، واحصل على
مفتاح API لاستخدامها مع OpenCode أو وكيل برمجة آخر.

تعمل Console مثل أي مزوّد آخر في OpenCode. وهي **اختيارية تمامًا**؛ يمكنك استخدام أي مزوّد آخر
بدلًا منها. وللاطلاع على اشتراك يشمل قدرًا من الاستخدام، راجع [OpenCode Go](/console/go).

## كيف يعمل

1. سجّل الدخول إلى [Console](https://opencode.ai/console)، وأضف بيانات الفوترة واشحن الرصيد، ثم انسخ مفتاح API.
2. شغّل `/connect` في TUI، واختر مزوّد الدفع حسب الاستخدام من OpenCode، والصق مفتاح API.

   ```text
   /connect
   ```

3. شغّل `/models` لرؤية النماذج المتاحة واختر واحدًا.

   ```text
   /models
   ```

تُحتسب عليك التكلفة لكل طلب، ويمكنك إضافة رصيد إلى حسابك.

## نقاط النهاية

يمكنك أيضًا الوصول إلى النماذج مباشرةً عبر نقاط نهاية API التالية. وتتطلب نماذج المحادثة في الخطة المجانية OpenCode؛
فاستخدم النماذج المدفوعة أو [Go](/console/go) من عملاء آخرين.

تُدرج في الجدول API الأصلية لكل نموذج، لكن النماذج النصية تعمل أيضًا مع واجهات API الأخرى، إذ تحوّل Console الطلبات إلى الصيغة المناسبة.
راجع [عناوين URL الأساسية](/console/harnesses#base-urls) للاطلاع على القائمة الكاملة.

### قائمة النماذج

اجلب القائمة الكاملة للنماذج المتاحة وبياناتها الوصفية من نقطة نهاية النماذج:

```bash
curl https://opencode.ai/inference/v1/models
```

راجع [API قائمة النماذج](/console/api/models) لمعرفة تفاصيل كل حقل في الاستجابة وللاطلاع على قائمة Console، التي تشمل أيضًا
المزوّدين المرتبطين بمساحة عملك.

### Jev

Jev نموذج System One من TypeSafe AI لاتخاذ قرارات سريعة ومنظّمة. فبدل توليد نص، يقيّم `state` مقابل أسئلة محدّدة النوع ويعيد قيمًا واحتمالات يستخدمها كودك مباشرةً. ويدعم أسئلة نعم/لا (`noul`)، والاختيار من متعدد (`choice`)، والأسئلة القائمة على معايير (`score`).

استخدم مفتاح API الخاص بـ OpenCode Console مع نقطة النهاية `https://opencode.ai/inference/systemone/v1/systemone`. وهذا المثال يتحقق مما إذا كان طلب دعم عاجلًا:

```bash
curl https://opencode.ai/inference/systemone/v1/systemone \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jev-1.14",
    "state": "My payments have failed for three days and I am losing sales. Please help now.",
    "questions": {
      "is_urgent": {
        "type": "noul",
        "instructions": "Does this request require urgent attention?"
      }
    }
  }'
```

يمكنك طرح عدة أسئلة في طلب واحد. يقيّمها Jev بالتوازي ويعيد كل إجابة تحت معرّف السؤال المطابق:

```bash
curl https://opencode.ai/inference/systemone/v1/systemone \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jev-1.14",
    "state": "My order arrived late and the item is damaged. I want a refund.",
    "questions": {
      "department": {
        "type": "choice",
        "instructions": "Which team should handle this request?",
        "criteria": {
          "returns": "Refunds, exchanges, or damaged items",
          "shipping": "Delivery delays or lost packages",
          "billing": "Charges, invoices, or payment problems"
        }
      },
      "frustration": {
        "type": "score",
        "instructions": "How frustrated is the customer?",
        "criteria": ["Calm", "Frustrated", "Very angry"]
      }
    }
  }'
```

استخدم `jev-1.13-free` للاستعانة بالنموذج المجاني محدود المدة، الذي يشغّل Jev 1.13. راجع [وثائق TypeSafe AI](https://docs.typesafe.ai/) لتفاصيل أنواع الأسئلة وحقول الاستجابة.

يأخذ `gpt-6-luna-decision` و`gemini-decision-1` طلب System One نفسه الذي يأخذه Jev، على نقطة النهاية نفسها. مرّر الصور والصوت والفيديو وملفات PDF في `state` كأجزاء على نمط المحادثة (`image_url` و`input_audio` و`video_url` و`file`). يقبل GPT 6 Luna Decision النص والصور؛ ويقبل Gemini Decision 1 أيضًا الصوت والفيديو وملفات PDF.

```bash
curl https://opencode.ai/inference/systemone/v1/systemone \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gemini-decision-1",
    "state": "I was charged twice for my order.",
    "questions": {
      "refund": {
        "type": "noul",
        "instructions": "Is this a refund request?"
      }
    }
  }'
```

### نماذج الصور

تولّد `gpt-image-2.5-sunburst` و`gemini-nano-banana-2.1` و`grok-imagine-image-2.0` الصور وتحرّرها. وهي ليست نماذج محادثة، فلا تظهر أبدًا في `/models` أو نقطة نهاية النماذج،
ولا يختارها `opencode/<model-id>`. استدعها على API الأصلي لها بمفتاح Console، أو دع أداة
[`generate_image`](/tools#image-generate) في OpenCode تستخدم نموذج صور بضبط
`experimental.image_generate.model`، مثل `opencode/gpt-image-2.5-sunburst`.

```bash
curl https://opencode.ai/inference/openai/v1/images/generations \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2.5-sunburst",
    "prompt": "A mountain at sunrise",
    "size": "1024x1024"
  }'
```

تأخذ Google معاملاتها الأصلية `contents` و`generationConfig`، وتأخذ xAI خياراتها الأصلية مثل `resolution` و
`quality`. وتقبل OpenAI Images وxAI Images أيضًا التحرير على `/images/edits`.

### نماذج التضمين

تحوّل `text-embedding-3-small` و`qwen3-embedding-8b` وسائر نماذج التضمين في الجدول أعلاه النص إلى
متجهات. ولا يستخدمها OpenCode للمحادثة، فلا تظهر أبدًا في `/models`، ولا تشملها الخطة المجانية.
ويتضمن [Go](/console/go#embedding-models) بعضها. استدعها عبر واجهة Embeddings من OpenAI بمفتاح Console.

```bash
curl https://opencode.ai/inference/openai/v1/embeddings \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "text-embedding-3-small",
    "input": ["hello world", "goodbye"]
  }'
```

- يقبل `input` نصًا أو مصفوفة نصوص. ويعيد `data` متجهًا واحدًا لكل إدخال، بالترتيب نفسه.
- يقصّر `dimensions` المتجهات في النماذج التي تدعمه، مثل `text-embedding-3-small`.
- يعيد `encoding_format: "base64"` المتجهات مرمّزة بصيغة base64 بدلًا من أعداد الفاصلة العائمة.
- يجب ألا يتجاوز كل إدخال سعة نافذة سياق النموذج.
- تذكر الاستجابة `usage.cost` كما في أي طلب استدلال. راجع [التكلفة](/console/api/inference#cost).

المتجهات من نماذج مختلفة غير قابلة للمقارنة، لذا ضمّن مستنداتك واستعلاماتك بالنموذج نفسه. ويقدّم
[المزوّد المرتبط](/console/api/providers#endpoints) نماذج التضمين الخاصة به على `/embeddings`.

## الخلفية

ثمة نماذج كثيرة متاحة، لكن قليلًا منها يجيد العمل كوكيل برمجة. كما يتفاوت المزوّدون في الإعداد
والأداء والجودة، لذا قد يختلف أداء النموذج الذي يُستدعى عبر بوابة مثل OpenRouter.

<Callout type="tip">اختبرنا مجموعة مختارة من النماذج والمزوّدين التي تعمل جيدًا مع OpenCode.</Callout>

ولبناء هذا الكتالوج:

1. اختبرنا مجموعة مختارة من النماذج وتحدثنا إلى فرقها عن أفضل طريقة لتشغيلها.
2. عملنا مع المزوّدين للتأكد من تقديم النماذج بشكل صحيح.
3. اختبرنا أداء كل نموذج لدى كل مزوّد معنيّ للوصول إلى قائمة يمكننا التوصية بها بثقة.

Console بوابة AI تتيح لك الوصول إلى هذه النماذج.

## الأهداف

بنينا Console من أجل:

1. **قياس أداء** أفضل النماذج والمزوّدين لوكلاء البرمجة.
2. تقديم خيارات **أعلى جودة** دون خفض الأداء أو التوجيه إلى مزوّدين أرخص.
3. تمرير **انخفاض الأسعار** بالبيع بسعر التكلفة، مع هامش يغطي رسوم المعالجة فقط.
4. **عدم إلزامك بمزوّد بعينه**: يمكنك استخدام Console مع أي وكيل برمجة، أو استخدام مزوّد آخر مع OpenCode.
