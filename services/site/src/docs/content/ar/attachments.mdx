## الإرفاق

أرفق ملفًا محليًا، ثم اطلب من OpenCode استخدامه في مطالبتك. وفي عميل سطح المكتب
أو الويب، اختر **Attach file**، أو الصق ملفًا، أو اسحبه إلى مربع المطالبة.

```text
Summarize the attached README.md and list the required setup steps.
```

يمكن أن يصل الحجم الإجمالي للملفات المحدّدة في نافذة اختيار الملفات على سطح المكتب إلى 20 MiB. وقد تفرض الواجهات الأخرى
حدودًا أقل من جهة العميل.

<Callout type="warning">
  اختر نموذجًا يقبل الصور قبل إرفاق صورة. ويمكن لـ OpenCode تمرير الصور المدعومة إلى المزوّد، لكن
  المزوّد والنموذج يحددان الصيغ والأبعاد وأعداد الملفات وأحجامها المسموح بها. وقد يرفض الطلبَ نموذجٌ لا يقبل إلا النصوص.
</Callout>

## الصيغة

تحدّد مدخلات المطالبات والأوامر في V2 المرفق باستخدام `uri`، ويمكن أن تتضمن أيضًا `name` و`description`:

```json
{
  "uri": "file:///home/me/project/src/server.ts",
  "name": "server.ts",
  "description": "HTTP server entrypoint"
}
```

واستخدم عنوان `file:` مطلقًا لملف أو مجلد متاح للخادم. وللملفات النصية، يختار المعاملان الموجبان `start` و`end`
أسطرًا بترقيم يبدأ من واحد.

```text
file:///home/me/project/src/server.ts?start=20&end=60
```

استخدم عنوان `data:` لإرسال المحتوى مباشرةً ضمن العنوان:

```json
{
  "uri": "data:text/plain;base64,SGVsbG8sIE9wZW5Db2RlIQ==",
  "name": "greeting.txt"
}
```

ولا تُدعم عناوين URL للمرفقات بصيغة HTTP وHTTPS. راجع
[مرجع API](/api) المولّد لإرسال المطالبات برمجيًا.

## الصيغ

تجعل جلسات V2 الحالية أنواع المرفقات هذه مرئية للنموذج:

| الإدخال                   | ما يتلقاه النموذج                                           | مثال            |
| ----------------------- | -------------------------------------------------------- | ------------------ |
| ملف نصي UTF-8         | اسم الملف والنص المفكوك الترميز                                | `README.md`        |
| مجلد               | قائمة بملفات المجلد ومجلداته الفرعية المباشرة، دون سرد محتوياتها | `file:///home/me/` |
| PNG أو JPEG أو GIF أو WebP | وسائط صورة                                              | `diagram.png`      |
| PDF                     | وسائط مستند                                           | `report.pdf`       |

وتحتاج ملفات PDF إلى نموذج يقبل PDF. وإذا لم يدعم النموذج نوع المرفق،
يرسل OpenCode ملاحظة قصيرة بدلًا منه.

وتُعامل SVG كنص. أما AVIF وBMP والصوت والفيديو وغيرها من مرفقات المطالبات
الثنائية فلا تُضمَّن في طلب النموذج. فحوّل أي ملف ثنائي غير مدعوم إلى نص أو صورة مدعومة
أولًا؛ مثلًا حوّل صورة BMP إلى PNG قبل إرفاقها.

ويقرأ OpenCode كل مرفق قبل قبول المطالبة. ويرفض عناوين URL غير الصالحة والمسارات غير القابلة للقراءة
والمسارات التي لا تشير إلى ملف أو مجلد، والمرفقات التي تتجاوز 20 MiB بعد فك الترميز. ويُحدَّد نوع الوسائط من البايتات نفسها؛ لذا فإن تغيير
اسم الملف أو نوع الوسائط في عنوان `data:` لا يتيح للنموذج رؤية ملف ثنائي غير مدعوم.

## الصور

أعدّ تطبيع الصور في `opencode.json` أو `opencode.jsonc`:

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "media": {
    "image": {
      "auto_resize": true,
      "max_width": 2000,
      "max_height": 2000,
      "max_base64_bytes": 5242880,
    },
  },
}
```

وكل الحقول اختيارية:

| الحقل              | الافتراضي   | السلوك                                                                  |
| ------------------ | --------- | ------------------------------------------------------------------------- |
| `auto_resize`      | `true`    | يغيّر حجم صورة تتجاوز حدًّا مضبوطًا؛ وعند `false` يرفض الصورة.  |
| `max_width`        | `2000`    | العرض الأقصى بالبكسل؛ ويجب أن يكون عددًا صحيحًا موجبًا.                      |
| `max_height`       | `2000`    | الارتفاع الأقصى بالبكسل؛ ويجب أن يكون عددًا صحيحًا موجبًا.                     |
| `max_base64_bytes` | `5242880` | الحد الأقصى للبايتات في الصورة المرمّزة بـBase64؛ ويجب أن يكون عددًا صحيحًا موجبًا.    |

مثلًا، يرفض هذا صورة أعرض من 1200 بكسل بدل تغيير حجمها:

```jsonc title="opencode.jsonc"
{
  "media": {
    "image": {
      "auto_resize": false,
      "max_width": 1200,
    },
  },
}
```

وتنطبق هذه الإعدادات على الصور المدعومة المرفقة بالمطالبات وعلى الصور
التي تعيدها أداة `read` المدمجة.

## المعالجة

تتعرف أداة `read` على PNG وJPEG وGIF وWebP من محتواها وتقرأ
حتى 20 MiB من بيانات الصورة المصدر. وتتحقق من العرض والارتفاع وطول Base64
مقابل حدود الصور المضبوطة.

ومع `auto_resize: true`، يحافظ OpenCode على نسبة الأبعاد ويصغّر
إلى حدود الأبعاد. ثم يجرّب ترميزات PNG وJPEG أصغر تدريجيًا
حتى يجد ترميزًا لا يتجاوز حد Base64؛ لذا قد يتغيّر نوع الوسائط الناتج.

```text
Input:  4000 × 2000 WebP
Limits: 2000 × 2000
Output: 2000 × 1000 PNG or JPEG
```

إذا لم يستوفِ أي ترميز الحد، تفشل المعالجة. ومع `auto_resize: false`، تُرفض الصورة التي
تتجاوز أي حد دون تعديل؛ وتُرفض أيضًا إذا تعذّر فك ترميزها.

```text
Input:  2400 × 1600 JPEG
Limit:  max_width = 2000, auto_resize = false
Result: Image processing fails
```

وإذا لم يكن مغيّر حجم الصور متاحًا، يمرّر OpenCode الصورة الأصلية
دون تغيير. لذا فإعدادات الصور تقيّد المعالجة، ولا تضع حدًا للرفع أو تشكّل حاجزًا أمنيًا.

## الحدود

| الحد                         | القيمة أو السلوك                                             | مثال                                      |
| ----------------------------- | ------------------------------------------------------------- | -------------------------------------------- |
| الإرفاق المباشر             | 20 MiB مفكوكة لكل عنصر؛ وقد يفرض العملاء حدودًا أقل      | ملفان بحجم 12 MiB يمرّان حد العنصر     |
| اختيار منتقي سطح المكتب      | 20 MiB في المجموع                                                  | ملفان بحجم 12 MiB يتجاوزان حد الاختيار  |
| `max_base64_bytes`            | Base64 المرمّز فقط، دون عنوان `data:` كاملًا       | يُحتسب `SGVsbG8=` 8 بايتات                 |
| حدود صور المزوّد         | تنطبق بعد معالجة OpenCode                               | قد يرفض مزوّد صورة مقبولة      |
| دعم النماذج للمرفقات النصية | لا يحتاج نموذجًا متعدد الوسائط                           | يُدرج `notes.txt` كنص مطالبة       |
| حدود نص `read`            | تستخدم حدود ترقيم وتقصير منفصلة                    | اقرأ سجلًا كبيرًا على صفحات                    |

وقبول العميل لملف لا يضمن وصول محتواه إلى
النموذج. فيجب أن يستخدم المرفق صيغة مرئية للنموذج وأن يستوفي حدود OpenCode
والمزوّد معًا.
