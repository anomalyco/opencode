تتيح لك اللقطات التراجع عن تغييرات المحادثة والملفات الأخيرة معًا. استخدمها لتنقيح العمل الأخير، لكن أبقِ
سجل تغييرات Git أو نسخًا احتياطية لأي عمل مهم.

## سير العمل

شغّل `/undo` بعد استجابة تريد تنقيحها. فيجهّز OpenCode التراجع، ويستعيد الملفات المتأثرة، ويعيد
المطالبة المحذوفة إلى مربع الإدخال لتتمكن من تحريرها.

```text
/undo

# Edit the restored prompt, then submit it again.
Add validation without changing the public API.
```

وإرسال المطالبة المحرّرة يثبّت التراجع المجهّز. وقبل الإرسال، شغّل `/redo` لإلغائه واستعادة
المحادثة والملفات التي كانت لديك قبل `/undo`.

```text
/redo
```

وتوفّر الطرفية أيضًا اختصارات افتراضية:

| الإجراء | الأمر | الاختصار |
| --- | --- | --- |
| تجهيز التراجع عن الرسالة السابقة | `/undo` | `<leader>u` |
| إلغاء التراجع المجهّز | `/redo` | `<leader>r` |

ويمكنك أيضًا اختيار رسالة سابقة واختيار **Revert** لتجهيز تراجع إلى تلك النقطة.

## الالتقاط

في كل خطوة نموذج، يحاول OpenCode أخذ لقطة مباشرةً قبل استدعاء النموذج وأخرى عند بلوغ الخطوة
نجاحًا أو فشلًا مسجّلًا. وتسجّل رسالة المساعد المسارات التي تغيّرت بين تلك اللقطتين.

```text
before model step ── snapshot A
model edits src/api.ts
step finishes ────── snapshot B ── changed: src/api.ts
```

أخذ اللقطات ليس مضمونًا. إذا تعذّر أخذ أيّ من اللقطتين، تستمر المحادثة، لكن قد لا تتوفر تغييرات
ملفات تلك الخطوة للاستعادة.

## النطاق

تغطي اللقطات المجلد النشط للجلسة داخل worktree في Git. مثلًا، جلسة مفتوحة في `packages/app`
تلتقط الملفات المؤهلة تحت `packages/app`، لا التغييرات في بقية المستودع.

| المحتوى | يُلتقط | مثال |
| --- | --- | --- |
| الملفات المتعقّبة في المجلد النشط | نعم | `packages/app/src/app.tsx` |
| الملفات غير المتعقّبة غير المتجاهَلة حتى 2 MiB لكل ملف | نعم | `packages/app/notes.txt` |
| الملفات المتجاهَلة في Git | لا | `packages/app/dist/app.js` |
| الملفات غير المتعقّبة الفردية الأكبر من 2 MiB | لا | `packages/app/debug.log` |
| الملفات خارج المجلد النشط | لا | `packages/server/src/index.ts` |
| بيانات Git الوصفية وغيرها من الآثار الجانبية | لا | إيداعات التغييرات، أو الفروع، أو قواعد البيانات، أو العمليات |

وتحتاج لقطات نظام الملفات إلى مستودع Git. وخارجه، يمكن لـ`/undo` التراجع عن سجل المحادثة، لكنه
لا يستطيع استعادة الملفات.

## الاستعادة

لا يستعيد التراجع إلا المسارات المنسوبة إلى خطوات المساعد بعد حدّ المحادثة المختار. ويعود كل مسار
إلى حالته قبل أول خطوة متراجَع عنها؛ ويُحذف الملف الذي أنشأته تلك الخطوات إن لم يكن موجودًا حينها.

| الخط الزمني | `src/api.ts` | `src/new.ts` |
| --- | --- | --- |
| الحدّ المختار | النسخة A | مفقود |
| خطوات المساعد اللاحقة | النسخة B | أُنشئ |
| بعد التراجع | النسخة A | حُذف |

أما المسارات غير المنسوبة لتلك الخطوات فتبقى كما هي. وقد تُستبدل التعديلات الحالية على مسار متأثر، فراجع
ملخص الاستعادة و`git diff` قبل المتابعة.

```sh
git diff --stat
git diff
```

## التخزين

يخزّن OpenCode اللقطات محليًا في قاعدة كائنات Git داخلية منفصلة تحت مجلد بياناته. ولا ينشئ التقاط اللقطات
إيداعات في سجل Git، ولا ينقل الفروع، ولا يغيّر فهرس مستودعك عمدًا.

```sh
# Your repository remains an ordinary dirty worktree after capture.
git status --short
```

وقد تحتوي كائنات اللقطات المحتوى الكامل للملفات المتعقّبة والملفات غير المتعقّبة المؤهلة. فتعامل مع مجلد بيانات OpenCode
بيانات محلية حساسة.

## الإعدادات

اللقطات مفعّلة افتراضيًا. اضبط `snapshots` على `false` في [إعداداتك](/config#snapshots) لإيقاف التقاط
نظام الملفات مستقبلًا.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "snapshots": false,
}
```

ولا يحذف تعطيل اللقطات اللقطات المخزّنة أصلًا. ويبقى التراجع في المحادثة متاحًا، لكنه بلا
حالة نظام ملفات ملتقطة لا يستطيع استعادة تغييرات الملفات المرتبطة.

## الأمان

اللقطات وسيلة راحة، لا معاملة ولا نسخة احتياطية:

- يمكن لأوامر shell تغيير الخدمات والعمليات وموارد الشبكة وقواعد البيانات وحالة Git والمخرجات المتجاهَلة أو ملفات خارج
  المجلد النشط. واستعادة لقطة لا تعكس تلك الآثار.
- قد يترك العمل المتوقف أو الفاشل تغييرات عندما يفشل الالتقاط أو لا يوجد زوج لقطات صالح.
- استعادة المسارات المتأثرة تستبدل محتواها الحالي. كما أن إلغاء تراجع مجهّز قد يستبدل تعديلات لاحقة.
- يرفض OpenCode عمليات التراجع أثناء تشغيل الجلسة، لكن المحررات والأوامر الخارجية قد تغيّر
  worktree مع ذلك بين الالتقاط والاستعادة.
- تثبيت التراجع يزيل الرسائل من عرض المحادثة النشطة، لا من سجل الجلسة الدائم أو تخزين اللقطات القائم.
  وهو ليس محوًا آمنًا.

ثبّت عملك المهم أو انسخه احتياطيًا قبل استخدام `/undo` على worktree فيه تغييرات غير مثبّتة.
