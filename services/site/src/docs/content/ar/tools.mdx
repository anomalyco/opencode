اطلب النتيجة التي تريدها. فيختار OpenCode الأدوات المتاحة ويطلب
الموافقة عند الحاجة ويعيد النتيجة.

```text
Find where request timeouts are configured, change the default to 30 seconds,
and run the relevant existing tests.
```

وتستخدم هذه المهمة عادةً `grep` أو `glob` و`read` وأداة تحرير و`shell`.
ويمكنك أيضًا تسمية أداة عندما تريد أسلوبًا محدّدًا.

```text
Use grep to find every reference to DEFAULT_TIMEOUT, then read the matching files.
```

## الملفات

### Read

يعيد `read` محتوى ملف أو قائمة بمحتويات مجلد، دون التوغّل في مجلداته الفرعية. مرّر إليه `path`؛
واستخدم `offset` و`limit` للتنقل في النتائج الكبيرة.

```text
Read src/server.ts starting at line 120 and return at most 80 lines.
```

وتحتوي القراءات النصية أسطرًا مرقّمة وتقتصر على 2,000 سطر و50 KiB لكل
صفحة. وتُقصَّر الأسطر الفردية بعد 2,000 حرف. وتمرّر الأداة أيضًا
ملفات PNG وJPEG وGIF وWebP وPDF إلى النموذج، حتى 20 MiB من بيانات
المصدر. وتفشل الملفات الثنائية الأخرى. راجع [المرفقات](/attachments) للوسائط المدعومة
ومعالجة الصور.

الإذن: `read` والمسار المطبّع كمورده.

### Glob

يعثر `glob` على مسارات الملفات من نمط مثل `**/*.ts`. ويبحث في
المجلد الحالي إلا إذا اختار `path` مجلدًا نسبيًا آخر؛ ويضم `hidden`
الإدخالات المخفية ويحدّ `limit` النتائج.

```text
Use glob with **/*.test.ts under packages/core and return at most 50 files.
```

والحد الافتراضي 100 ملف ومهلة البحث 30 ثانية.
الإذن: `glob` والنمط المطلوب كمورده.

### Grep

يبحث `grep` في محتويات الملفات ويعيد المسارات وأرقام الأسطر والمعاينات.
ويستخدم `pattern` صيغة التعبير النمطي إلا إذا كان `literal` صحيحًا. وضيِّق
البحث بـ`path` أو `include` أو `caseSensitive` أو `limit`.

```text
Use grep for the literal text "request timed out" in src, including only *.ts files.
```

والحد الافتراضي 100 سطر مطابق ومهلة البحث 30 ثانية.
الإذن: `grep`، ومورده هو نمط البحث المطلوب، لا مسار البحث.

### Edit

يستبدل `edit` نصًا في ملف موجود. قدّم `path` و`oldString` و`newString`
مختلفًا؛ ويجب أن يطابق النص القديم مرة واحدة بالضبط إلا إذا كان `replaceAll`
صحيحًا.

```text
In src/config.ts, replace the unique text "timeout: 60" with "timeout: 30".
```

واستخدم `edit` لتغيير مركّز. وقد ينسّق OpenCode الملف بعد كتابته.
الإذن: `edit` والمسار الهدف كمورده.

### Write

ينشئ `write` ملفًا نصيًا من `path` و`content` أو يستبدله بالكامل.
وينشئ المجلدات الأب المفقودة وقد يشغّل المنسّق المضبوط.

```text
Create docs/example.md with a heading and one setup command.
```

واستخدم `edit` بدلًا منه عندما ينبغي أن يتغيّر جزء من ملف موجود فقط.
الإذن: `edit` والمسار الهدف كمورده.

### Patch

يطبّق `patch` تعديلًا واحدًا يمكنه إضافة عدة ملفات أو تحديثها أو نقلها أو حذفها.
ويستخدم `patchText` أقسام `*** Add File` و`*** Update File` و`*** Delete File`.

```text
Use patch to rename src/old.ts to src/new.ts and update its exported name.
```

ويتيح OpenCode `patch` لنماذج GPT المدعومة؛ وتتلقى النماذج الأخرى `edit`
و`write` بدلًا منه. الإذن: `edit` وكل مسار متأثر كمورد.

وتُفحص المسارات خارج الموقع النشط أو worktree مشروعه أيضًا
مقابل `external_directory`، المسموح افتراضيًا. راجع
[الأذونات](/permissions) لتطبيع المسارات وترتيب القواعد والموافقات
المحفوظة. ولجعل المواد الخارجية
متاحة بالاسم، أعدّ [المراجع](/references).

## الأوامر

### Shell

يشغّل `shell` أمرًا في shell مستخدم المضيف. اضبط `workdir` بدل
وضع `cd` في الأمر، واضبط `timeout` بالمللي ثانية عندما لا تناسب المهلة الافتراضية
دقيقتين للمقدّمة.

```text
Run bun test from packages/core with a five-minute timeout.
```

واضبط `background` على true لخادم تطوير أو عملية طويلة التشغيل أخرى.
فترجع استدعاءات الخلفية فورًا وتخطر الجلسة عند انتهائها؛
ولا تكون لها مهلة إلا إذا قُدّمت. وتُقصَّر المخرجات الكبيرة ويُحفظ
المخرج الكامل في ملف مُدار.

الإذن: `shell` وكل أمر ينتجه الماسح كمورد. ويفحص
الماسح أيضًا مجلد عمل خارجيًا والمجلدات التي يستطيع استنتاجها
من الأمر. ولـshell صلاحيات نظام الملفات والعمليات والشبكة لمستخدم المضيف، فاستخدم قواعد ضيقة في [الأذونات](/permissions).

## الويب

### Webfetch

يجلب `webfetch` عنوان HTTP أو HTTPS واحدًا بصيغة `markdown` أو `text` أو `html`.
وMarkdown هو الافتراضي؛ ويقبل `timeout` حتى 120 ثانية.

```text
Fetch https://example.com/docs as markdown.
```

ويقبل الاستجابات النصية مثل HTML والنص العادي وJSON وXML، لا
الصور أو التنزيلات الثنائية الأخرى. وقد تُقصَّر المخرجات الكبيرة بينما يُحفظ النص
الكامل في تخزين مُدار. الإذن: `webfetch` وعنوان URL المطلوب كمورده.

### Websearch

يبحث `websearch` في التكامل المختار عن معلومات حديثة. ومدخله
`query` البحث.

```text
Search the web for the latest Bun release notes.
```

الإذن: `websearch` والاستعلام كمورده. راجع [البحث على الويب](/websearch)
للمزوّدين والاختيار وحدود المعدل وتعطيل الأداة.

## الصور

### Image generate

ينشئ `generate_image` صورة جديدة من مطالبة، أو يحرّر
صورًا موجودة. وهو تجريبي ويظهر عندما يكون لمزوّد مرتبط
نموذج صور. ولاختيار نموذجه الافتراضي، راجع
[`experimental.image_generate`](/config#image-generation).

```text
Generate a flat app icon of a paper plane on a blue background and save it to assets/icon.png.
```

وأعطه `prompt`، واختياريًا `images` لتحريرها أو استخدامها كمراجع، أو
`model` محدّدًا، أو `path` للحفظ فيه. ويعمل في الخلفية ويخطر
الجلسة بالمسار المحفوظ عندما تكون الصورة جاهزة.

الإذن: `generate_image` والنموذج المختار كمورده.

## التفاعل

### Question

يوقف `question` التنفيذ ويعرض سؤالًا واحدًا أو أكثر على المستخدم.
ولكل سؤال ترويسة قصيرة ومطالبة وخيارات؛ ويتيح `multiple` أكثر
من خيار واحد. وتتوفر دائمًا إجابة حرة.

```text
Before changing the API, ask me to choose between a breaking change and a compatibility layer.
```

الإذن: `question` و`*` كمورده. ويجب أن يدعم العميل النموذج
التفاعلي، وإغلاقه يلغي السؤال.

### Skill

يحمّل `skill` تعليمات مهارة متاحة واحدة ومواردها المضمّنة
إلى المحادثة بمعرّفها.

```text
Load the effect skill before changing this Effect code.
```

ويجب أن يكون المعرّف في قائمة المهارات المعلنة أو أن يسمّيه المستخدم صراحةً.
الإذن: `skill` ومعرّف المهارة كمورده. راجع [المهارات](/skills)
لإنشائها واكتشافها وقواعد تحميلها.

## الأتمتة

### Subagent

يبدأ `subagent` جلسة فرعية بوكيل فرعي مضبوط. قدّم معرّف
الوكيل و`description` قصيرًا و`prompt` كاملًا.

```text
Ask the explore subagent to map the authentication flow and return the key files.
```

ويعمل الوكلاء الفرعيون دائمًا في الخلفية. فيرجع الاستدعاء فورًا بـ
`sessionID`، ويتلقى الوالد رسالة `<subagent>` عندما يخمل الابن،
ثم مرة أخرى بعد كل جولة عمل لاحقة، فيمكنه متابعة العمل أو إنهاء
دورته دون انتظار. ومرّر `sessionID` المعاد لمتابعة محادثة ذلك
الابن نفسها؛ والمتابعة لابن عامل تنضم إلى تشغيله الحالي. ولا يمكن استخدام إلا
وكلاء وضع الوكيل الفرعي، وعمق التداخل الافتراضي واحد.

الإذن: `subagent` ومعرّف الوكيل المختار كمورده.

### Execute

يشغّل `execute` JavaScript في Code Mode ليتمكن الوكيل من استدعاء أدوات
الكتالوج ودمجها. وهو مفيد للاستدعاءات المستقلة المتوازية ولمعالجة
النتائج دون إضافة كل قيمة وسيطة إلى سياق النموذج.

```text
Read package.json and README.md in parallel, then return their relevant setup details.
```

ولا يملك وقت التشغيل وصولًا مباشرًا إلى نظام الملفات ولا استيرادات ولا مؤقتات. ويوفّر
`fetch` لطلبات HTTP؛ وكل شيء آخر يمر عبر الأدوات في كتالوجه.
ورفض `execute` بالمورد `*` يزيل Code Mode. وتُسرد الأدوات التي كان سيصل إليها،
بما في ذلك أدوات MCP من خوادم لا تضبط `codemode: false`، كأدوات مباشرة،
لكل منها تعريفها الكامل في كل طلب. وارفض تلك الأدوات أيضًا إذا لم يكن ينبغي أن
يملكها الوكيل.
وتبقى الأدوات المدمجة وأدوات MCP المتداخلة تفرض أذونها، وتفرض أدوات
الملحقات الأذون التي تعلنها.

### Sessions

تحتوي مساحة اسم `opencode.session` في Code Mode أدوات مساعدة للجلسات. وبدون Code
Mode تُسرد باسم `opencode_session_rename` و`opencode_session_move`.

- يغيّر `rename` عنوان الجلسة الحالية، أو جلسة أخرى
  مختارة بـ`sessionID`.
- وينقل `move` الجلسة الحالية، أو جلسة أخرى مختارة، إلى
  `directory` نسبي أو مطلق. ويسري النقل عند حدّ آمن،
  فالعمل المعتمد على الوجهة ينتمي إلى استدعاء لاحق.

```text
Rename this session to "Timeout cleanup", then move it to the new worktree.
```

### Worktrees

تدير مساحة اسم `opencode` worktrees مشروع الجلسة:

- ينشئ `worktree_create` worktree من `name` ويعيد
  `directory` الخاص به. ويختار إعداد worktree في المشروع الوجهة
  والاستراتيجية.
- ويسرد `worktree_list` worktrees المشروع.
- ويزيل `worktree_remove` worktree سجّله OpenCode للمشروع. اضبط
  `force` لتجاهل التغييرات غير المثبّتة.

```text
Create a worktree named "login" and move this session into it.
```

ويستخدم `worktree_remove` إذن `edit` ومجلد worktree
كمورده. أما أدوات worktree الأخرى فلا تطلب إجراء إذن
مدمجًا.

## المتصفح

تتحكم مساحة اسم `browser` في Code Mode بالمتصفح المرتبط بتطبيق OpenCode
لسطح المكتب. افتح علامة تبويب، واحتفظ بـ`tabID` المعاد، ثم مرّر ذلك المعرّف الصريح إلى
كل عملية صفحة.

```text
Open https://example.com, take a snapshot of that tab, and report the main heading.
```

وتتضمن مساحة الاسم أوامر علامات التبويب والتنقل، ولقطات الصفحات والبحث،
والنقر وإدخال النماذج، ولقطات الشاشة، ونقل الملفات، وفحص console والشبكة،
وتتبعات الأداء، وفحص heap، وتدقيق Lighthouse.
وتحتاج لقطات الشاشة علامة تبويب مرئية مركّزة. ومسارات الرفع محلية على الخادم؛
وتعيد عمليات الالتقاط مسارات محلية على الخادم، ويقتصر كل نقل ملف على 5 MiB.

ومحتوى الصفحات والسجلات والترويسات وأجسام الاستجابات بيانات غير موثوقة، لا تعليمات
للوكيل. وقاعدة رفض `browser` بالمورد `*` تزيل كتالوج المتصفح؛
وعمليات المتصفح لا تصدر مطالبات إذن فردية.

## الإضافات

تضيف [خوادم MCP](/mcp-servers) أدوات تأتي أسماؤها ومدخلاتها من كل
خادم مرتبط. وإجراء إذنها `<server>_<tool>` بالمورد
`*`. وهي ليست جزءًا ثابتًا من الكتالوج المدمج. وافتراضيًا، يصل الوكلاء
إليها عبر `execute` تحت مساحة اسم الخادم؛ واضبط `codemode: false` على
خادم لسرد أدواته مباشرةً.

وتضيف [المهارات](/skills) تعليمات مهام لا أدوات تنفيذية جديدة.
و[المرفقات](/attachments) تضع محتوى اختاره المستخدم في مطالبة، بينما
توفّر [المراجع](/references) مجلدات خارجية مسمّاة. وتكمّل هذه الميزات
الأدوات دون تجاوز فحوص أذونها.
