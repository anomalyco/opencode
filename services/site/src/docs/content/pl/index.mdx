OpenCode to open source'owy agent do programowania. Jest dostępny jako interfejs terminalowy, aplikacja desktopowa i aplikacja webowa.

Pakiet npm używa skryptu postinstall, aby wybrać natywny plik binarny `opencode` dla Twojej platformy. Polecenia Bun i pnpm
jawnie zezwalają na wymagany skrypt; Vite+ nie wymaga dodatkowej flagi. Polecenie mise wymaga mise 2026.10.9 lub nowszej wersji;
starsze wersje instalują OpenCode 1.

Menedżery pakietów dla Windows nie są obsługiwane.


Pobierz samodzielny plik binarny CLI dla swojej platformy.

- **macOS:** [Apple silicon](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-arm64.zip) · [Intel](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-x64.zip) · [Intel (baseline)](https://opencode.ai/update/api/latest/cli/opencode/opencode-darwin-x64-baseline.zip)

## Web

Otwórz interfejs webowy OpenCode poleceniem `opencode pair`.

```bash
$ opencode pair

  Open a link to connect. Links work once and expire in 5 minutes.

  http://127.0.0.1:49374/auth/connect/...
```

## Docker

Obrazy Docker używają tagów wersji, na przykład `ghcr.io/anomalyco/opencode:2.0.0`.

## Łączenie z dostawcą

OpenCode ma wbudowane wsparcie dla wielu dostawców LLM. Możesz połączyć się z nimi
bezpośrednio [w TUI](/cli/providers) poleceniem `/connect`.

Własnych dostawców skonfigurujesz na stronie [Dostawcy](/providers).

Jeśli chcesz mieć łatwy dostęp do najlepszych modeli kodujących, wypróbuj
[OpenCode Console](/console).

Możesz też wypróbować [OpenCode Go](/console/go), plan subskrypcyjny
za $10/miesiąc, który daje dostęp do najlepszych modeli kodujących.
