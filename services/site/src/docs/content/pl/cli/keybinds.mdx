---
title: "Skróty klawiszowe"
description: "Dostosuj skróty klawiszowe OpenCode CLI w cli.json i sprawdź ID oraz domyślne przypisanie każdego polecenia."
---

Dostosuj skróty w `cli.json`:

```json title="cli.json"
{
  "keybinds": {
    "leader": "ctrl+space",
    "command.palette.show": "ctrl+k",
    "app.exit": ["ctrl+c", "ctrl+d"],
    "app.debug": false
  },
  "leader": {
    "timeout": 1500
  }
}
```

Użyj ciągu znaków dla jednego klawisza:

```json
{
  "keybinds": {
    "command.palette.show": "ctrl+k"
  }
}
```

Oddziel alternatywy przecinkami:

```json
{
  "keybinds": {
    "app.exit": "ctrl+c,ctrl+d"
  }
}
```

Wyłącz skrót przez `"none"` lub `false`:

```json
{
  "keybinds": {
    "app.debug": "none",
    "help.show": false
  }
}
```

Użyj obiektu, aby ustawić zachowanie zdarzenia:

```json
{
  "keybinds": {
    "prompt.paste": {
      "key": "ctrl+v",
      "preventDefault": false
    }
  }
}
```

`leader` ma domyślnie wartość `ctrl+x`. `<leader>` w innym skrócie odwołuje się do tego klawisza.

```json
{
  "keybinds": {
    "leader": "ctrl+space",
    "model.list": "<leader>m"
  },
  "leader": {
    "timeout": 2000
  }
}
```

Nieznane identyfikatory poleceń są ignorowane.

## Mini

Polecenie `app.clear` działa tylko w [`opencode mini`](/cli). Naciśnij `ctrl+l`, aby wyczyścić widoczny ekran i ponownie narysować prompt. Terminal zachowuje historię przewijania.

```json title="cli.json"
{
  "keybinds": {
    "app.clear": "ctrl+l"
  }
}
```

| ID          | Domyślnie  | Opis      |
| ----------- | -------- | ---------------- |
| `app.clear` | `ctrl+l` | Wyczyść ekran |

## Widok Diff

Naciśnij `d` (`diff.switch_source`), aby wybrać **All**, **Committed**, **Uncommitted** lub **Last turn** (w sesji), albo wybierz **Base**, aby zmienić gałąź porównania. Wybory są pamiętane do zakończenia TUI. Początkowy zakres ustawisz przez [`diffs.source` w `cli.json`](/cli/config#diffs).

Przewijanie, stronicowanie i skróty początku/końca zawsze sterują diffem. Nie ma przełączania fokusu klawiatury: kliknij pliki, aby je otworzyć, kliknij foldery, aby je rozwinąć lub zwinąć, a kółkiem myszy przewijaj drzewo plików.

Używaj `n` / `p` lub `alt+down` / `alt+up` (Option w macOS), aby przechodzić między plikami. W przeglądarce diffów skróty Alt nawigują po plikach, a nie po kartach sesji.

Naciśnij `m`, aby oznaczyć plik jako sprawdzony i zwinąć treść patcha. W widoku wszystkich plików naciśnij `m` ponownie,
aby usunąć oznaczenie i rozwinąć patch. W widoku pojedynczego pliku oznaczenie przenosi Cię do następnego pliku,
ale na końcu listy nie wraca do pierwszego. Usunięcie oznaczenia nie zmienia wybranego pliku.

Kliknij prawym przyciskiem plik na pasku bocznym lub nagłówek jego zmian, aby wybrać **Mark complete** (lub **Mark incomplete**).
Zmienia to to samo oznaczenie co `m`. Oznaczenie innego pliku z jego menu nie wybiera go ani nie przenosi Cię dalej
od aktualnie czytanego pliku.

Warianty `diff.help` z Shiftem obsługują terminale, które zgłaszają modyfikator Shift przy naciśnięciu `?`.
