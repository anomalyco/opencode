title: "SDK Effect"
description: "Osadź OpenCode w programie Effect przez @opencode/sdk/effect, natywny dla Effect osadzony SDK."
---

`@opencode/sdk/effect` to SDK do osadzania OpenCode w aplikacjach Effect. Operacje zwracają typowane wartości Effect
i Stream. Zamknięcie Scope, w którym działa host, zwalnia router, usługi Location, fibry i rejestracje pluginów.

```sh
bun add @opencode/sdk effect@4.0.1
```

## Tworzenie hosta

Utwórz host w `Effect.scoped`, a następnie używaj jego wygenerowanych grup API lub aliasu `sessions`.

```ts
import { AbsolutePath, Location, OpenCode } from "@opencode/sdk/effect"
import { Effect } from "effect"

const program = Effect.scoped(
  Effect.gen(function* () {
    const opencode = yield* OpenCode.create()
    const session = yield* opencode.sessions.create({
      location: Location.Ref.make({ directory: AbsolutePath.make("/workspace") }),
    })
    yield* opencode.sessions.prompt({
      sessionID: session.id,
      text: "Review the current changes",
    })
    return session
  }),
)

const session = await Effect.runPromise(program)
```

Osadzony host używa tych samych wartości schematów, deklarowanych błędów, opcji żądań i strumieni co
`@opencode/client/effect`.

```ts
const info = yield* opencode.server.info()
const sessions = yield* opencode.sessions.list()
```

## Strumień zdarzeń

Endpointy strumieniowe zwracają wartości `Stream` z Effect. Aby odczytywać je w tle, uruchom odbiorców w osobnych fibrach
w Scope hosta.

```ts
import { Effect, Stream } from "effect"

yield* opencode.events.subscribe().pipe(
  Stream.runForEach((event) => Effect.logInfo("OpenCode event", { type: event.type })),
  Effect.forkScoped,
)
```

## Dostosowywanie

Dostosuj instancję OpenCode, rejestrując pluginy Effect. Użyj osadzonego hosta, aby dostosować agentów, modele,
narzędzia i inne zachowania:

```ts
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"

const plugin = Plugin.define({
  id: "customize-agent",
  effect: (ctx) =>
    Effect.gen(function* () {
      const agent = ctx.agent
      yield* agent.transform((agents) => {
        agents.update("build", (agent) => {
          agent.description = "Builds features and fixes bugs for our team"
        })
      })
    }),
})

yield* opencode.plugin(plugin)
```

Pełną dokumentację hooków, transformacji, narzędzi i kontekstu pluginów Effect znajdziesz w
[dokumentacji pluginów Effect](/build/plugins/effect).

## Warstwa

Użyj `OpenCode.layer()`, gdy osadzony host ma być usługą aplikacji.

```ts
import { OpenCode } from "@opencode/sdk/effect"
import { Effect } from "effect"

const program = Effect.gen(function* () {
  const opencode = yield* OpenCode.Service
  return yield* opencode.server.info()
})

const health = await Effect.runPromise(program.pipe(Effect.provide(OpenCode.layer())))
```
