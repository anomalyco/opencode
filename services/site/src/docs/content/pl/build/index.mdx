---
title: "Twórz na bazie OpenCode"
description: "Rozbuduj OpenCode za pomocą pluginów, połącz się z jego API HTTP przez klienta TypeScript albo osadź go w swojej aplikacji za pomocą SDK."
---

Z OpenCode codziennie korzystają miliony osób. Na jego bazie możesz tworzyć własne
aplikacje, integracje i rozwiązania do pracy z agentami bez zaczynania od zera.

Oferujemy też API Effect dla [pluginów](/build/plugins/effect),
[klientów](/build/client/effect) i [osadzonych aplikacji](/build/sdk/effect).

<CardGroup cols={1}>
  <Card title="Extend OpenCode" href="/build/plugins">
    Twórz pluginy dodające narzędzia, integracje, polecenia, agentów i własne zachowania, nie zmieniając reszty OpenCode.
  </Card>
  <Card title="Run it as a server" href="/build/client">
    Połącz się z OpenCode tym samym klientem, którego używają TUI i aplikacja desktopowa, a następnie zbuduj wokół niego
    dowolny interfejs, proces lub rozwiązanie do pracy z agentami.
  </Card>
  <Card title="Embed it" href="/build/sdk">
    Osadź OpenCode bezpośrednio w swojej aplikacji i zbuduj wokół niego w pełni własnego agenta, interfejs lub produkt
    dla deweloperów.
  </Card>
</CardGroup>
