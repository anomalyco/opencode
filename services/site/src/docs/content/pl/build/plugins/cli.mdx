title: "Tworzenie pluginów TUI"
description: "Zbuduj część TUI pluginu OpenCode dla interfejsu terminalowego za pomocą @opencode/plugin/tui."
---

Pluginy TUI rozszerzają interfejs terminalowy o polecenia, trasy, sloty, renderery Markdown, powiadomienia i stan
lokalny. Plugin TUI to część `./tui` [pakietu pluginu](/build/plugins), zwykle obok
[części serwerowej](/build/plugins/server).

```ts title="src/tui.tsx"
import { Plugin } from "@opencode/plugin/tui"

export default Plugin.define({
  id: "acme.cli",
  setup(context) {
    context.ui.toast.show({ message: "TUI plugin loaded", variant: "success" })
  },
})
```

Importuj `@opencode/plugin/tui` bezpośrednio. OpenCode rozwiązuje ten import w czasie działania, więc lokalne pluginy TUI
nie potrzebują bezwzględnej ścieżki do checkoutu OpenCode.

## Kontekst

`setup` otrzymuje konfigurację, metadane aplikacji, bieżącą lokalizację, klienta OpenCode, dane z cache, tokeny motywu,
renderer OpenTUI i opisane poniżej API interfejsu.

```ts
setup(context) {
  const compact = context.options.compact === true
  const location = context.location ?? context.data.location.default()
  const version = context.app.version
  const channel = context.app.channel
  const client = context.client
  const renderer = context.renderer
  const theme = context.theme
}
```

Zwróć funkcję sprzątającą dla zasobów należących do pluginu.

```ts
setup(context) {
  const stop = context.data.on("session.execution.succeeded", () => {})
  return () => stop()
}
```

## Klient

`context.client` to wygenerowany klient OpenCode, który może wywoływać podłączony serwer, w tym zdalny.

```ts
const response = await context.client.plugin.list({
  location: context.location ?? context.data.location.default(),
})
const plugins = response.data
```

## Zdarzenia

Użyj `data.on` dla jednego typowanego zdarzenia lub `data.listen` dla każdego zdarzenia serwera; oba zwracają funkcję
anulującą subskrypcję.

```ts
const stopPermission = context.data.on("permission.asked", (event) => {
  context.ui.toast.show({ message: `Permission ${event.data.id}` })
})
const stopAll = context.data.listen(({ details }) => console.log(details.type))

return () => {
  stopPermission()
  stopAll()
}
```

## Sesje

Dane sesji udostępniają listę, wyszukiwanie, hierarchię, koszt, status, synchronizację i unieważnianie.

```ts
const sessions = context.data.session.list()
const session = context.data.session.get(sessionID)
const rootID = context.data.session.root(sessionID)
const familyIDs = context.data.session.family(sessionID)
const cost = context.data.session.cost(sessionID)
const status = context.data.session.status(sessionID)
await context.data.session.sync(sessionID)
context.data.session.invalidate(sessionID)
```

Oczekujące elementy skrzynki odbiorczej i wiadomości mają API listy, wyszukiwania, synchronizacji i unieważniania.

```ts
await context.data.session.pending.sync(sessionID)
const pending = context.data.session.pending.list(sessionID)
context.data.session.pending.invalidate(sessionID)

await context.data.session.message.sync(sessionID)
const messages = context.data.session.message.list(sessionID)
const message = context.data.session.message.get(sessionID, messageID)
context.data.session.message.invalidate(sessionID)
```

Żądania uprawnień można odczytywać i odświeżać dla sesji.

```ts
await context.data.session.permission.sync(sessionID)
const requests = context.data.session.permission.list(sessionID) ?? []
context.data.session.permission.invalidate(sessionID)
```

Formularze można wyświetlać, odświeżać, odpowiadać na nie i anulować w lokalizacji.

```ts
import type { SessionFormCancelInput, SessionFormReplyInput } from "@opencode/client"

async function handleForm(reply: SessionFormReplyInput, cancel: SessionFormCancelInput) {
  const location = context.location
  await context.data.session.form.sync(sessionID, location)
  const forms = context.data.session.form.list(sessionID, location) ?? []
  await context.data.session.form.reply(reply, location)
  await context.data.session.form.cancel(cancel, location)
  context.data.session.form.invalidate(sessionID, location)
}
```

const location = context.data.location.default()

terminala.

const result = await context.attention.notify({

## Motyw i renderer

Używaj semantycznych tokenów motywu z elementami OpenTUI i przekazuj `context.renderer` do pomocników właściwych dla
renderera.

```tsx
const Status = () => <text fg={context.theme.text.base}>Ready</text>
const renderer = context.renderer
```

Zasób OpenTUI rysowany przez renderer potrzebuje `context.renderer.nativeScene` jako właściciela. Na przykład
`<markdown>` i `<code>` potrzebują `SyntaxStyle`. Zniszcz zasób, gdy renderer jest bezczynny, po ostatniej klatce, która
go rysuje.

```tsx
import { SyntaxStyle } from "@opentui/core"

const style = SyntaxStyle.fromStyles({ default: { fg: context.theme.text.base } }, context.renderer.nativeScene)
context.ui.slot({ append: "home.footer", render: () => <markdown content="Ready" syntaxStyle={style} /> })
return () => context.renderer.idle().then(() => style.destroy())
```

Aby odczytać styl układu elementu renderowalnego, wywołaj metodę o nazwie gettera Yoga Node, taką jak
`box.getPadding(Yoga.Edge.Bottom)` lub `box.getMaxWidth()`. Elementy renderowalne hosta nie są częścią API pluginów. Ich
struktura i style mogą się zmienić w dowolnym wydaniu.

### Pluginy zbudowane dla OpenTUI 0.5

OpenCode uruchamia pluginy z własnym OpenTUI. Od OpenTUI 0.6:

- `SyntaxStyle.create()`, `SyntaxStyle.fromStyles()`, `SyntaxStyle.fromTheme()`, `TextBuffer.create()` i
  `EditBuffer.create()` przyjmują właściciela jako ostatni argument. `OptimizedBuffer.create()` przyjmuje go w opcji
  `owner`. Przekaż `context.renderer.nativeScene`. OpenTUI 0.5 ignoruje dodatkowy argument, więc plugin nadal działa na
  starszych wydaniach OpenCode.
- `generateSyntax()` z `@opencode/theme/tui` przyjmuje właściciela jako drugi argument:
  `generateSyntax(context.theme, context.renderer.nativeScene)`. Starsze wersje `@opencode/theme` budują styl bez
  właściciela, więc zaktualizuj też pakiet.
- `getLayoutNode()` jest usunięte. Zastąp `getLayoutNode().getMaxWidth()` i pozostałe gettery stylu metodą
  renderowalną o tej samej nazwie, w OpenTUI 0.6.5 lub nowszym. Zastąp `getComputedLayout()` i pozostałe gettery
  obliczonej pozycji i rozmiaru przez `getLayout()`, a `markDirty()` przez `invalidateIntrinsicSize()`. Obliczone
  padding, margin i border nie mają zamiennika, a `getPadding(edge)` odczytuje tylko padding ustawiony dla tej krawędzi.
  Aby przywrócić styl, który getter zgłasza jako nieustawiony (`Unit.Undefined`), przypisz `undefined` do właściwości,
  w OpenTUI 0.6.6 lub nowszym.

[Informacje o wydaniu OpenTUI 0.6.0](https://opentui.com/docs/releases/0.6.0) wymieniają każdą zmianę.

## Komponenty Solid

Użyj `usePlugin`, aby uzyskać dostęp do bieżącego kontekstu w JSX renderowanym przez trasę, okno lub slot.

```tsx
import { usePlugin } from "@opencode/plugin/tui"

function Status() {
  const context = usePlugin()
  return <text fg={context.theme.text.base}>{context.app.version}</text>
}
```

## Polecenia i keymapy

Rejestruj polecenia palety, polecenia z ukośnikiem i skróty klawiszowe w reaktywnej warstwie mapowania klawiszy.

```ts
context.keymap.layer(() => ({
  mode: "global",
  priority: 10,
  commands: [
    {
      id: "acme.status",
      title: "Show Acme status",
      group: "Acme",
      bind: "ctrl+g",
      palette: true,
      slash: { name: "acme", aliases: ["status"], arguments: true },
      enabled: () => true,
      suggested: true,
      run: async (input) => context.ui.toast.show({ message: input ?? "Ready" }),
    },
  ],
  bindings: ["acme.status"],
}))
```

Wywołaj `layer` w `setup`, także po `await`, lub w komponencie. Każda warstwa jest usuwana przy pierwszym z tych
zdarzeń:

- Plugin zostaje wyłączony, przeładowany lub nie przejdzie setup.
- Komponent lub reaktywne obliczenie, które ją utworzyło, takie jak slot, trasa lub okno, zostaje zwolnione.

Fabryka warstwy musi być czysta. OpenCode ocenia ją raz bez śledzenia zależności, aby zwalidować początkowy kształt
polecenia, a następnie reaktywnie. Błędy początkowego kształtu polecenia, takie jak polecenie palety bez ID, są zgłaszane
z `layer()`. OpenTUI obsługuje błędy parsowania skrótów. Błędy późniejszych reaktywnych aktualizacji podlegają obsłudze
błędów Solid.

```ts
async setup(context) {
  const settings = await loadSettings()
  context.keymap.layer(() => ({
    mode: "global",
    commands: [{ id: "acme.sync", title: "Sync Acme", palette: true, run: () => sync(settings) }],
  }))
}
```

Warstwa może wskazywać jeden element renderowalny OpenTUI i może zwrócić `false` z polecenia, aby kontynuować wysyłanie
klawiszy.

```ts
context.keymap.layer(() => ({
  target: () => panel,
  commands: [{ bind: "escape", run: (_input, event) => (event ? false : undefined) }],
}))
```

Wysyłaj polecenia, sprawdzaj skróty i stan poleceń albo włączaj tymczasowy tryb wejścia.

```ts
context.keymap.dispatch("acme.status", "verbose")
const shortcuts = context.keymap.shortcuts("acme.status")
const commands = context.keymap.commands()
const pending = context.keymap.pending()
const active = context.keymap.active()
const currentMode = context.keymap.mode.current()
const popMode = context.keymap.mode.push("acme-search")
popMode()
```

## Magazyn

Trwały magazyn zachowuje JSON między restartami i synchronizuje się między instancjami TUI.

```ts
const [settings, updateSettings] = context.storage.store("settings", {
  initial: { compact: false },
})
await updateSettings((draft) => {
  draft.compact = true
})
```

Magazyn pamięci przetrwa przeładowania pluginu, ale jest odrzucany po zakończeniu TUI.

```ts
const [state, updateState] = context.storage.memory("state", {
  initial: { count: 0 },
})
updateState((draft) => {
  draft.count++
})
```

## Okna i powiadomienia

Używaj okien opartych na Promise dla alertów, potwierdzeń, wprowadzania tekstu i wyboru.

```ts
await context.ui.dialog.alert({ title: "Acme", message: "Ready" })
const confirmed = await context.ui.dialog.confirm({
  title: "Continue?",
  message: "Run the Acme action?",
  label: { confirm: "Run", cancel: "Cancel" },
})
const name = await context.ui.dialog.prompt({ title: "Name", placeholder: "release" })
const mode = await context.ui.dialog.select({
  title: "Mode",
  current: "safe",
  options: [
    { title: "Safe", value: "safe", description: "Ask before changes" },
    { title: "Fast", value: "fast", disabled: false, category: "Advanced" },
  ],
})
```

### Wyszukiwanie w wyborze

Przekaż `search`, aby samodzielnie określić dopasowania i kolejność wyników. Funkcja działa dla każdego zapytania,
także pustego, i otrzymuje tylko włączone opcje. Lista zachowuje zwróconą kolejność i pokazuje kategorie wśród wyników.

```ts
const project = await context.ui.dialog.select({
  title: "Projects",
  options: [
    { title: "Alpha", value: "alpha", category: "Recent" },
    { title: "Beta", value: "beta", category: "Pinned" },
  ],
  search: (query, options) =>
    options
      .filter((option) => option.title.toLowerCase().includes(query.toLowerCase()))
      .toSorted((left, right) => right.title.localeCompare(left.title)),
})
```

### Akcje wyboru

Akcje pojawiają się w stopce i uruchamiają się przez skrót klawiszowy, kliknięcie lub fokus Tab, a następnie Enter.
Domyślnie otrzymują wybraną wartość i są niedostępne bez zaznaczenia. Użyj `selection: "none"` dla akcji, które nie
potrzebują zaznaczenia.

```ts
await context.ui.dialog.select({
  title: "Projects",
  options: [{ title: "Alpha", value: "alpha" }],
  actions: [
    { bind: "ctrl+o", title: "Inspect", onTrigger: (value) => context.ui.toast.show({ message: value }) },
    { bind: "ctrl+a", title: "Close", side: "right", selection: "none", onTrigger: () => context.ui.dialog.clear() },
  ],
})
```

- Akcja nie zamyka okna ani nie rozstrzyga Promise.
- Enter lub kliknięcie opcji rozstrzyga wybraną wartość.
- Escape, `clear()` lub pokazanie innego okna rozstrzyga `undefined`.
- Nie przypisuj `ctrl+n` ani `ctrl+p`. Okno rezerwuje je do nawigacji, a jego własne skróty mają pierwszeństwo.

Własne okna JSX mogą ustawiać rozmiar i zamykać się same.

```tsx
context.ui.dialog.set({ size: "large", centered: true })
context.ui.dialog.show(
  () => (
    <box>
      <text>Acme</text>
    </box>
  ),
  () => console.log("closed"),
)
context.ui.dialog.clear()
```

Powiadomienia obsługują tytuł, treść, wariant i czas trwania.

```ts
context.ui.toast.show({
  title: "Acme",
  message: "Saved",
  variant: "success",
  duration: 3000,
})
```

## Trasy i karty

Zarejestruj trasę JSX, sprawdź bieżącą trasę i przejdź do strony głównej, sesji lub strony pluginu.

```tsx
const unregister = context.ui.router.register({
  name: "dashboard",
  render: ({ data }) => <text>{String(data?.title ?? "Acme")}</text>,
})
const current = context.ui.router.current()
context.ui.router.navigate({ type: "plugin", name: "dashboard", data: { title: "Status" } })
context.ui.router.navigate({ type: "session", sessionID })
context.ui.router.navigate({ type: "home" })
return unregister
```

Gdy karty sesji są włączone, możesz je wyświetlać na liście, otwierać, ustawiać na nich fokus, przenosić i zamykać.
`open` nie zmienia fokusu; `focus` w razie potrzeby otwiera kartę.

```ts
if (context.ui.tabs.enabled()) {
  context.ui.tabs.open(backgroundSessionID)
  context.ui.tabs.focus(sessionID)
  const tabs = context.ui.tabs.list()
  context.ui.tabs.move(backgroundSessionID, tabs.length - 1)
  context.ui.tabs.close(sessionID)
  context.ui.tabs.close()
}
```

## Model

Odczytaj wybrany model promptu i zmień jego wariant. `current()` i `variant.list()` są reaktywne, gdy odczytywane są
w obliczeniu Solid. `variant` o wartości `undefined` oznacza wartość domyślną modelu.

```ts
const selected = context.ui.model.current()
const variants = context.ui.model.variant.list()
context.ui.model.variant.set("high")
context.ui.model.variant.set(undefined)
```

`variant.set` zwraca `false`, gdy nie wybrano modelu lub model nie ma takiego wariantu. Przypisz je do polecenia, aby
zastąpić wbudowany cykl wariantów, na przykład pomijając wartość domyślną modelu:

```ts
context.keymap.layer(() => ({
  commands: [
    {
      id: "acme.variant.cycle",
      title: "Cycle variants",
      bind: "tab",
      run() {
        const variants = context.ui.model.variant.list()
        if (variants.length === 0) return
        const index = variants.indexOf(context.ui.model.current()?.variant ?? "")
        context.ui.model.variant.set(variants[(index + 1) % variants.length])
      },
    },
  ],
}))
```

## Sloty

Sloty wstawiają lub zastępują JSX w `app`, `home.footer`, `home.footer.status`, `prompt.footer`,
`prompt.footer.status`, `prompt.footer.file`, `session.composer.top`, `sidebar.content` lub `sidebar.footer`.

```tsx
return context.ui.slot({
  append: "sidebar.content",
  render: ({ sessionID }) => <text>{context.data.session.get(sessionID)?.title}</text>,
})
```

Użyj `prepend`, `append`, `before`, `after` lub `replace` do umieszczenia.

```tsx
context.ui.slot({ prepend: "home.footer", render: () => <text>Before footer content</text> })
context.ui.slot({ append: "home.footer", render: () => <text>After footer content</text> })
context.ui.slot({ before: "home.footer", render: () => <text>Before footer slot</text> })
context.ui.slot({ after: "home.footer", render: () => <text>After footer slot</text> })
context.ui.slot({ replace: "home.footer", render: () => <text>New footer</text> })
```

Użyj `home.footer.status`, aby dodać treść do wbudowanego wiersza stopki bez jego zastępowania. Wkłady statusu pojawiają
się po wskaźnikach kondycji OpenCode i przed wersją.

```tsx
context.ui.slot({ append: "home.footer.status", render: () => <text>SYNCED</text> })
```

### Panele sesji

Zarejestruj wkład do `session.panel`, a następnie otwórz panel poleceniem. Host zarządza rozmiarem, fokusem i prezentacją
pełnoekranową; plugin zarządza jego treścią. Wybrana nazwa jest przekazywana do każdego wkładu jako `panel.name`, a każdy
wkład decyduje, czy się renderować.

```tsx
import { Show } from "solid-js"

context.ui.slot({
  append: "session.panel",
  render: (panel) => (
    <Show when={panel.name === "acme.review"}>
      <ReviewPanel panel={panel} />
    </Show>
  ),
})

context.ui.slot({
  append: "app",
  render: () => {
    context.keymap.layer(() => ({
      mode: "global",
      commands: [
        {
          id: "acme.review",
          title: "Open review",
          slash: { name: "review" },
          run: () => {
            context.ui.panel.open("acme.review")
          },
        },
      ],
    }))
    return null
  },
})
```

- Otwarcie poza sesją zwraca `false`.
- To zwykły slot: obowiązują wszystkie pięć umiejscowień i istniejące zasady kolejności zastępowania.
- Użyj `append` dla niezależnie wybieralnych wkładów, aby mogły współistnieć. `replace` nadal przejmuje slot.
- Nazwy to wspólne wartości wyboru, a nie zastrzeżone identyfikatory. Używaj nazwy z prefiksem pluginu, takiej jak
  `acme.review`, aby uniknąć kolizji. Otwarcie nazwy bez pasującego renderera pozostawia slot pusty.
- Zmiana prezentacji zachowuje zamontowane wkłady. Zamknięcie panelu je zwalnia; wyłączenie pluginu usuwa jego wkłady
  przez normalne sprzątanie slotów.
- Warstwy skrótów klawiszowych i tryby wprowadzania są aktywne tylko wtedy, gdy panel przechwytuje dane wejściowe.

Slot otrzymuje reaktywne właściwości `name`, `sessionID`, `width`, `presentation` i `focused` oraz akcje `focus`, `close`
i `toggleFullscreen`. Host utrzymuje wąskie terminale na pełnym ekranie; `toggleFullscreen` nie działa, dopóki nie ma
dość miejsca na panel boczny.

```tsx
import type { PanelInput } from "@opencode/plugin/tui/context"
import { usePlugin } from "@opencode/plugin/tui"

function ReviewPanel(props: { panel: PanelInput }) {
  const context = usePlugin()
  context.keymap.layer(() => ({
    commands: [
      {
        id: "acme.review.fullscreen",
        bind: "f",
        run: props.panel.toggleFullscreen,
      },
    ],
  }))
  return <text>Reviewing {props.panel.sessionID}</text>
}
```

Możesz początkowo zażądać prezentacji pełnoekranowej, sprawdzić aktywny panel lub go zamknąć bez wpływu na panel innego
pluginu.

```ts
context.ui.panel.open("acme.review", { presentation: "fullscreen" })
const current = context.ui.panel.current()
context.ui.panel.close()
```

## Formatowanie

Formatuj ścieżki systemu plików do wyświetlania, w tym skracanie katalogu domowego.

```ts
const displayPath = context.ui.format.path(context.location?.directory ?? "/home/me/project")
```

## Publikacja i wczytywanie

Udostępnij plugin TUI przez `./tui`; dodaj peer dependencies OpenTUI, gdy plugin renderuje JSX.

```json title="package.json"
{
  "name": "opencode-acme-plugin",
  "type": "module",
  "exports": {
    ".": "./src/index.ts",
    "./tui": "./src/tui.tsx"
  },
  "dependencies": {
    "@opencode/plugin": "latest"
  },
  "peerDependencies": {
    "@opentui/core": ">=0.6.6",
    "@opentui/solid": ">=0.6.6",
    "solid-js": ">=1.9.0"
  }
}
```

Eksportuj `./tui` obok [części serwerowej](/build/plugins/server) lub [części GUI](/build/plugins/gui), aby wczytywała
się automatycznie.

```ts title="src/index.ts"
import { Plugin } from "@opencode/plugin"

export default Plugin.define({
  id: "acme.server",
  setup() {},
})
```

Skonfiguruj pakiet tylko TUI w [`cli.json`](/cli/plugins), aby pozostawał aktywny wobec zdalnych serwerów.

```json title="cli.json"
{
  "plugins": ["opencode-acme-plugin"]
}
```
