---
title: "Hurtigtaster"
description: "Tilpass hurtigtastene i OpenCode CLI i cli.json, og slå opp kommando-ID-er og standardbindinger."
---

Tilpass bindingene i `cli.json`:

```json title="cli.json"
{
  "keybinds": {
    "leader": "ctrl+space",
    "command.palette.show": "ctrl+k",
    "app.exit": ["ctrl+c", "ctrl+d"],
    "app.debug": false
  },
  "leader": {
    "timeout": 1500
  }
}
```

Bruk en streng for én tast:

```json
{
  "keybinds": {
    "command.palette.show": "ctrl+k"
  }
}
```

Skill alternativer med komma:

```json
{
  "keybinds": {
    "app.exit": "ctrl+c,ctrl+d"
  }
}
```

Slå av en binding med `"none"` eller `false`:

```json
{
  "keybinds": {
    "app.debug": "none",
    "help.show": false
  }
}
```

Bruk et objekt for å styre hvordan hendelsen håndteres:

```json
{
  "keybinds": {
    "prompt.paste": {
      "key": "ctrl+v",
      "preventDefault": false
    }
  }
}
```

`leader` er som standard `ctrl+x`. `<leader>` i en annen binding refererer til den tasten.

```json
{
  "keybinds": {
    "leader": "ctrl+space",
    "model.list": "<leader>m"
  },
  "leader": {
    "timeout": 2000
  }
}
```

Ukjente kommando-ID-er ignoreres.

## Mini

Kommandoen `app.clear` virker bare i [`opencode mini`](/cli). Trykk `ctrl+l` for å tømme den synlige skjermen og tegne prompten på nytt. Terminalen beholder rullehistorikken.

```json title="cli.json"
{
  "keybinds": {
    "app.clear": "ctrl+l"
  }
}
```

## Diff-visning

Trykk `d` (`diff.switch_source`) for å velge **All**, **Committed**, **Uncommitted** eller **Last turn** (i en økt), eller velg **Base** for å endre sammenligningsgrenen. Valgene huskes til TUI-en avsluttes. Angi det opprinnelige omfanget med [`diffs.source` i `cli.json`](/cli/config#diffs).

Rulling, sideskift og start/slutt-snarveier styrer alltid diffen. Det finnes ingen tastaturfokusveksling: klikk på filer for å åpne dem, klikk på mapper for å utvide eller lukke dem, og bruk musehjulet til å rulle filtreet.

Bruk `n` / `p` eller `alt+down` / `alt+up` (Option på macOS) for å bytte mellom filer. I Diff-visningen bytter Alt-snarveiene fil i stedet for øktfane.

Trykk `m` for å merke en fil som gjennomgått og lukke endringsteksten. I visningen for alle filer trykker du `m` igjen for å fjerne merket og åpne endringen på nytt. Visningen for én fil går automatisk videre til neste fil når du merker som gjennomgått, men blir på den siste filen i stedet for å gå rundt. Fjerning av merke går aldri videre.

Høyreklikk en fil i sidepanelet eller i diff-overskriften for **Mark complete** (eller **Mark incomplete**). Dette endrer samme gjennomgått-tilstand som `m`. Hvis du fullfører en annen fil fra menyen, velges den ikke, og filen du leser, flyttes ikke.

De alternative bindingene for `diff.help` med Shift støtter terminaler som rapporterer Shift når du trykker `?`.
