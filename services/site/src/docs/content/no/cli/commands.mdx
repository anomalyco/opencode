title: "CLI-kommandoer"
description: "Referanse for opencode-kommandolinjen."
---

Hver kommando godtar `--help` for hele flagglisten, for eksempel `opencode run --help`. Enkelte serverbaserte kommandoer godtar `--standalone` for å kjøre en privat server eller `--server <url>` for å peke på en bestemt; sjekk kommandoens hjelp for hvilke flagg den støtter.

## run

Sender en melding og skriver ut svaret uten å åpne det interaktive grensesnittet.

```bash
$ opencode run "Explain this repository"
```

### CI

I CI sender du en leverandør-API-nøkkel som en hemmelighet og bruker frittstående modus, slik at den private serveren mottar den. For eksempel gjennomgår denne GitHub Actions-jobben repositoriet som er sjekket ut:

```yaml
name: OpenCode review
on: [pull_request]

jobs:
  review:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm install --global @opencode/cli
      - run: opencode run --standalone --model anthropic/claude-sonnet-5-5 "Review this repository for correctness and summarize any issues."
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
```

Velg en modell.

```bash
$ opencode run --model anthropic/claude-sonnet-5-5 "Refactor parseToken"
```

Fortsett den siste økten.

```bash
$ opencode run --continue "Now handle the expired case"
```

Skriv ut JSON med én melding per linje, til bruk i skript.

```bash
$ opencode run --format json "List the TODO comments"
```

Legg ved filer i meldingen.

```bash
$ opencode run --file src/server.ts --file src/client.ts "Review these for bugs"
```

Kjør med en bestemt agent.

```bash
$ opencode run --agent build "Fix the failing test"
```

Fortsett en bestemt økt.

```bash
$ opencode run --session ses_4f2a1c "Check edge cases"
```

Godta automatisk tillatelser som ikke er eksplisitt avslått.

```bash
$ opencode run --auto "Fix the failing test"
```

Opprett økten som arkivert, slik at økter fra skript og CI ikke vises i øktlistene eller innboksen. Økten finnes fortsatt: `opencode session list` viser den, og du kan åpne den via ID.

```bash
$ opencode run --archived "Review this diff"
```

Vis alle underkommandoer og flagg.

```bash
$ opencode run --help
```

## mini

Starter det minimale interaktive grensesnittet i stedet for den fullskjermede TUI-en.

```bash
$ opencode mini
```

Fortsett den siste økten.

```bash
$ opencode mini --continue
```

Start med en modell og en innledende prompt.

```bash
$ opencode mini --model anthropic/claude-sonnet-5-5 --prompt "Summarize this repository"
```

Fortsett en bestemt økt.

```bash
$ opencode mini --session ses_4f2a1c
```

Vis alle underkommandoer og flagg.

```bash
$ opencode mini --help
```

## session

Administrerer økter.

```bash
$ opencode session list
```

Begrens listen og skriv ut JSON.

```bash
$ opencode session list --max-count 20 --format json
```

Slett en økt og dens underordnede økter.

```bash
$ opencode session delete ses_9c1b08
```

Eksporter øktdata som JSON.

```bash
$ opencode session export ses_4f2a1c
```

Fjern sensitive data fra transkripsjon og filer ved eksport.

```bash
$ opencode session export ses_4f2a1c --sanitize
```

Importer øktdata fra en JSON-fil eller URL.

```bash
$ opencode session import session.json
```

Importer til en bestemt katalog.

```bash
$ opencode session import session.json --directory ~/code/project
```

Vis alle underkommandoer og flagg.

```bash
$ opencode session --help
```

## auth

Administrerer AI-leverandører og tilgangsopplysninger.

```bash
$ opencode auth list
```

List dem som JSON.

```bash
$ opencode auth list --format json
```

Logg inn på en leverandør.

```bash
$ opencode auth login anthropic
```

Logg inn med en bestemt autentiseringsmetode.

```bash
$ opencode auth login anthropic --method key
```

Logg ut av en lagret konto.

```bash
$ opencode auth logout anthropic work
```

Bytt aktiv konto for en integrasjon.

```bash
$ opencode auth switch anthropic work
```

Eksporter lagrede tilgangsopplysninger og importer dem på en annen maskin. Filen inneholder hemmeligheter.

```bash
$ opencode auth export anthropic > credentials.json
$ opencode auth import credentials.json
```

Vis alle underkommandoer og flagg.

```bash
$ opencode auth --help
```

## mcp

Administrerer MCP-servere (Model Context Protocol).

```bash
$ opencode mcp list
```

Legg til en ekstern server.

```bash
$ opencode mcp add context7 --url https://mcp.context7.com/mcp
```

Legg til en lokal server i den globale konfigurasjonen.

```bash
$ opencode mcp add everything --global -- npx -y @modelcontextprotocol/server-everything
```

Legg til en lokal server med en miljøvariabel.

```bash
$ opencode mcp add everything --env LOG_LEVEL=debug -- npx -y @modelcontextprotocol/server-everything
```

Legg til en ekstern server med en header.

```bash
$ opencode mcp add context7 --url https://mcp.context7.com/mcp --header CONTEXT7_API_KEY=secret
```

Autentiser med en ekstern server som støtter OAuth.

```bash
$ opencode mcp auth sentry
```

Fjern lagrede tilgangsopplysninger for OAuth for en server.

```bash
$ opencode mcp logout sentry
```

Vis alle underkommandoer og flagg.

```bash
$ opencode mcp --help
```

## plugin

Administrerer plugins.

```bash
$ opencode plugin list
```

Inkluder innebygde serverplugins.

```bash
$ opencode plugin list --builtin
```

Installer en plugin og legg den til i den globale konfigurasjonen.

```bash
$ opencode plugin add @example/opencode-tui
```

Se etter oppdateringer for pakkeplugins.

```bash
$ opencode plugin check
```

Oppdater pakkeplugins.

```bash
$ opencode plugin update
```

Fjern en plugin fra den globale konfigurasjonen.

```bash
$ opencode plugin remove @example/opencode-tui
```

Vis alle underkommandoer og flagg.

```bash
$ opencode plugin --help
```



## serve

Starter API- og webserveren. Se [Web](/cli/web).

```bash
$ opencode serve
```

Bind til alle grensesnitt på en fast port.

```bash
$ opencode serve --hostname 0.0.0.0 --port 4096
```

Tillat en nettleserklient med en annen origin.

```bash
$ opencode serve --cors https://app.example.com
```

Vis alle underkommandoer og flagg.

```bash
$ opencode serve --help
```

## pair

Skriver ut engangslenker, pluss en QR-kode for den første, som logger en nettleser eller
app inn på serveren. Lenkene utløper etter 5 minutter og virker én gang.

```bash
$ opencode pair
```

Bruk en ekstern URL i lenkene.

```bash
$ opencode pair --url https://dev.example.com
```

Par fra hvor som helst gjennom en ekstern OpenTunnel-adresse. Dette eksponerer
serveren på internett, så første gang den slår på ekstern tilgang, forklarer den
dette og ber deg godta. Se [Ekstern tilgang](/cli/web#remote-access).

```bash
$ opencode pair --remote
```

Godta uten spørsmål, for eksempel i et skript uten terminal.

```bash
$ opencode pair --remote --yes
```

Vis alle underkommandoer og flagg.

```bash
$ opencode pair --help
```

## service

Administrerer bakgrunnsserveren. Se [Web](/cli/web).

```bash
$ opencode service start
```

Start den på nytt.

```bash
$ opencode service restart
```

Vis statusen.

```bash
$ opencode service status
```

Stopp den.

```bash
$ opencode service stop
```

Les en innstilling.

```bash
$ opencode service get hostname
```

Angi en innstilling.

```bash
$ opencode service set hostname 0.0.0.0
```

Tillat en ekstra origin i CORS.

```bash
$ opencode service set cors https://app.example.com
```

Send en miljøvariabel til serverprosessen.

```bash
$ opencode service set env OPENCODE_LOG_LEVEL DEBUG
```

Tilbakestill en innstilling til standardverdien.

```bash
$ opencode service unset hostname
```

Vis alle underkommandoer og flagg.

```bash
$ opencode service --help
```

## reload

Laster inn konfigurasjonen på nytt uten å starte serveren på nytt. Pågående økter tar i bruk de oppdaterte tjenestene ved overgangen til neste trinn.

```bash
$ opencode reload
```

## api

Sender en forespørsel til den kjørende serveren.

```bash
$ opencode api GET /api/session
```

Kall en operasjons-ID med en spørringsparameter.

```bash
$ opencode api session.list --param limit=10
```

Send en JSON-body.

```bash
$ opencode api session.create --data '{"title": "New session"}'
```

Legg til en forespørselsheader.

```bash
$ opencode api GET /api/session -H "accept: application/json"
```

Vis alle underkommandoer og flagg.

```bash
$ opencode api --help
```

## debug

Tilbyr feilsøkings- og problemløsningsverktøy.

```bash
$ opencode debug agents
```

List konfigurasjonskilder.

```bash
$ opencode debug config
```

Skriv et heap-snapshot av den kjørende bakgrunnsserveren og skriv ut banen.

```bash
$ opencode debug heap-dump
```

Skriv snapshottet til en katalog du velger.

```bash
$ opencode debug heap-dump --directory ./snapshots
```

Vis globale baner.

```bash
$ opencode debug paths
```

Skriv ut en enkelt bane.

```bash
$ opencode debug paths db
```

Vis alle underkommandoer og flagg.

```bash
$ opencode debug --help
```

## upgrade

Oppgraderer OpenCode til nyeste eller en bestemt versjon. Alias: `update`.

```bash
$ opencode upgrade
```

Oppgrader til en bestemt versjon med en bestemt pakkebehandler.

```bash
$ opencode upgrade 2.0.21 --method bun
```

Vis alle underkommandoer og flagg.

```bash
$ opencode upgrade --help
```

## uninstall

Stopper bakgrunnstjenester, fjerner den globale hurtigbufferen og avinstallerer OpenCode. Øktdata, konfigurasjon og
tilstand fjernes ikke.

```bash
$ opencode uninstall
```

Forhåndsvis hva som fjernes.

```bash
$ opencode uninstall --dry-run
```

Vis alle underkommandoer og flagg.

```bash
$ opencode uninstall --help
```
