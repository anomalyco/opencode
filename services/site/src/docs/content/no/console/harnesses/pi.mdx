[Pi](https://pi.dev) har innebygd støtte for OpenCode-leverandører med betaling etter bruk og Go. Pi velger riktig API for hver betalte modell og Go-modell.
Chatmodeller på gratisnivået krever OpenCode. Bruker du dem fra Pi, får du HTTP `403`.

<Callout>
  [Console CLI](/console/harnesses#console-cli) setter opp Pi med én kommando, inkludert arbeidsområdets policyer, MCP-servere,
  skills og instruksjoner. Kjør `npx @opencode/console setup pi`. Trinnene nedenfor setter det opp manuelt.
</Callout>

| Leverandør    | Plan          |
| ------------- | ------------- |
| `opencode`    | Betaling etter bruk |
| `opencode-go` | Go            |

## Konfigurer

Begge leverandørene leser nøkkelen fra `OPENCODE_API_KEY`. Opprett en [personlig API-nøkkel](/console/harnesses#get-an-api-key).

```bash
export OPENCODE_API_KEY="oc_sk_..."
pi --model opencode/claude-sonnet-5-5
```

Du kan også kjøre `/login` i Pi og velge leverandøren. Pi lagrer nøkkelen i `~/.pi/agent/auth.json`.

```text
/login opencode
```

## Go

Bruk `opencode-go`-leverandøren med en nøkkel fra et arbeidsområde med [Go](/console/go)-abonnement.

```bash
pi --model opencode-go/kimi-k3
```

## Modeller

Velg en modell som `<provider>/<model-id>`, med ID-er fra tabellen for [Console](/console/models#endpoints) eller
[Go](/console/go#endpoints). Vis modellene Pi kjenner til, med `--list-models`.

```bash
pi --list-models opencode-go
```

Angi standardmodellen i `~/.pi/agent/settings.json`, eller trykk `Ctrl+S` i `/model`-velgeren.

```json title="~/.pi/agent/settings.json"
{
  "defaultProvider": "opencode-go",
  "defaultModel": "kimi-k3"
}
```

Kjør `pi update --models` når en ny Console-modell ikke vises ennå.

## Console MCP

Pi v0.99.0 og nyere støtter MCP. Legg til [Console MCP](/console/harnesses#console-mcp)-serveren, og logg inn i
nettleseren.

```bash
pi mcp add opencode-console --url https://opencode.ai/console/mcp
pi mcp login opencode-console
```
