OpenCode Console tilbyr en liste over modeller som er testet og verifisert av OpenCode-teamet. Logg inn, legg til kreditter og hent en
API-nøkkel for å bruke dem med OpenCode eller en annen kodingsagent.

Console fungerer som enhver annen leverandør i OpenCode. Det er **helt valgfritt**, og du kan bruke en hvilken som helst annen leverandør
i stedet. For et abonnement med inkludert bruk, se [OpenCode Go](/console/go).

## Slik fungerer det

1. Logg inn i [Console](https://opencode.ai/console), legg til faktureringsopplysninger og kreditter, og kopier API-nøkkelen.
2. Kjør `/connect` i TUI, velg OpenCode-leverandøren for betaling etter bruk, og lim inn API-nøkkelen.

   ```text
   /connect
   ```

3. Kjør `/models` for å se de tilgjengelige modellene og velge en.

   ```text
   /models
   ```

Du belastes per forespørsel og kan legge til kreditter på kontoen din.

## Endepunkter

Du kan også nå modellene direkte gjennom følgende API-endepunkter. Gratisnivåets chatmodeller krever OpenCode;
bruk betalte modeller eller [Go](/console/go) fra andre klienter.

Hver modell er oppført med sitt opprinnelige API, men alle tekstmodeller fungerer også gjennom de andre API-ene, som Console
oversetter. Se [Basis-URLer](/console/harnesses#base-urls) for hele settet.

### Jev

Jev er en System One-modell fra TypeSafe AI for raske, strukturerte beslutninger. I stedet for å generere tekst vurderer den en `state` mot typede spørsmål og returnerer verdier og sannsynligheter som koden din kan bruke direkte. Den støtter ja/nei (`noul`), flervalg (`choice`) og rubrikkbaserte (`score`) spørsmål.

Bruk OpenCode Console-API-nøkkelen din med endepunktet `https://opencode.ai/inference/systemone/v1/systemone`. Dette eksempelet sjekker om en supportforespørsel haster:

```bash
curl https://opencode.ai/inference/systemone/v1/systemone \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jev-1.14",
    "state": "My payments have failed for three days and I am losing sales. Please help now.",
    "questions": {
      "is_urgent": {
        "type": "noul",
        "instructions": "Does this request require urgent attention?"
      }
    }
  }'
```

Du kan stille flere spørsmål i én forespørsel. Jev vurderer dem parallelt og returnerer hvert svar under den tilhørende spørsmåls-ID-en:

```bash
curl https://opencode.ai/inference/systemone/v1/systemone \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jev-1.14",
    "state": "My order arrived late and the item is damaged. I want a refund.",
    "questions": {
      "department": {
        "type": "choice",
        "instructions": "Which team should handle this request?",
        "criteria": {
          "returns": "Refunds, exchanges, or damaged items",
          "shipping": "Delivery delays or lost packages",
          "billing": "Charges, invoices, or payment problems"
        }
      },
      "frustration": {
        "type": "score",
        "instructions": "How frustrated is the customer?",
        "criteria": ["Calm", "Frustrated", "Very angry"]
      }
    }
  }'
```

Velg `jev-1.13-free` for å bruke gratismodellen, som kjører Jev 1.13 og er tilgjengelig i en begrenset periode. Se [TypeSafe AI-dokumentasjonen](https://docs.typesafe.ai/) for detaljer om spørsmålstyper og svarfelter.

### GPT 6 Luna Decision og Gemini Decision 1

`gpt-6-luna-decision` og `gemini-decision-1` tar samme System One-forespørsel som Jev, på samme endepunkt. Send bilder, lyd, video og PDF-er i `state` som chat-stil-deler (`image_url`, `input_audio`, `video_url`, `file`). GPT 6 Luna Decision godtar tekst og bilder; Gemini Decision 1 godtar også lyd, video og PDF-er.

```bash
curl https://opencode.ai/inference/systemone/v1/systemone \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gemini-decision-1",
    "state": "I was charged twice for my order.",
    "questions": {
      "refund": {
        "type": "noul",
        "instructions": "Is this a refund request?"
      }
    }
  }'
```

### Bildemodeller

`gpt-image-2.5-sunburst`, `gemini-nano-banana-2.1` og `grok-imagine-image-2.0` genererer og redigerer bilder. De er ikke chatmodeller, så de vises aldri i `/models` eller modellendepunktet,
og `opencode/<model-id>` velger dem ikke. Kall dem på deres opprinnelige API med en Console-nøkkel, eller la OpenCode-verktøyet
[`generate_image`](/tools#image-generate) bruke en bildemodell ved å angi
`experimental.image_generate.model`, for eksempel `opencode/gpt-image-2.5-sunburst`.

```bash
curl https://opencode.ai/inference/openai/v1/images/generations \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-2.5-sunburst",
    "prompt": "A mountain at sunrise",
    "size": "1024x1024"
  }'
```

Google tar sine opprinnelige `contents` og `generationConfig`, og xAI sine opprinnelige alternativer som `resolution` og
`quality`. OpenAI Images og xAI Images godtar også redigeringer på `/images/edits`.

### Embedding-modeller

`text-embedding-3-small`, `qwen3-embedding-8b` og de andre embedding-modellene i tabellen ovenfor gjør tekst om til
vektorer. OpenCode bruker dem ikke til chat, så de vises aldri i `/models`, og gratisnivået inkluderer dem ikke.
[Go](/console/go#embedding-models) inkluderer noen av dem. Kall dem på OpenAIs Embeddings API med en Console-nøkkel.

```bash
curl https://opencode.ai/inference/openai/v1/embeddings \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "text-embedding-3-small",
    "input": ["hello world", "goodbye"]
  }'
```

- `input` tar en streng eller en matrise med strenger. `data` returnerer én vektor per inndata, i samme rekkefølge.
- `dimensions` forkorter vektorene på modeller som støtter det, for eksempel `text-embedding-3-small`.
- `encoding_format: "base64"` returnerer vektorene base64-kodet i stedet for som flyttall.
- Hver inndata må passe innenfor modellens kontekstvindu.
- Svaret rapporterer `usage.cost` som enhver inferensforespørsel. Se [Kostnad](/console/api/inference#cost).

Vektorer fra forskjellige modeller kan ikke sammenlignes. Bruk derfor samme modell til å gjøre både dokumenter og spørringer om til vektorer. En
[tilkoblet leverandør](/console/api/providers#endpoints) tilbyr sine egne embedding-modeller på `/embeddings`.

Del Console-modeller med teamet ditt fra et [arbeidsområde](/console/workspaces). Eiere og administratorer kan

## Bakgrunn

Det finnes mange modeller, men bare noen få fungerer godt som kodingsagenter. Leverandører varierer også i konfigurasjon,
ytelse og kvalitet, så en modell som nås gjennom en gateway som OpenRouter, kan oppføre seg annerledes.

<Callout type="tip">We tested a select group of models and providers that work well with OpenCode.</Callout>

Slik satte vi sammen katalogen:

1. Vi testet et utvalg modeller og snakket med teamene bak dem om hvordan modellene best kan kjøres.
2. Vi samarbeidet med leverandørene for å sikre at modellene ble gjort tilgjengelige på riktig måte.
3. Vi målte ytelsen for hver kombinasjon av modell og leverandør for å lage en liste vi trygt kan anbefale.

Console er en AI-gateway som gir deg tilgang til disse modellene.

## Mål

Vi bygde Console for å:

1. **Måle ytelsen** til de beste modellene og leverandørene for kodingsagenter.
2. Tilby alternativene med **høyest kvalitet** uten å nedgradere ytelsen eller rute til billigere leverandører.
3. Gi **priskutt** videre ved å selge til kostpris, med påslag bare for å dekke behandlingsgebyrer.
4. Unngå **innlåsing**: bruk Console med en hvilken som helst kodingsagent, eller bruk en annen leverandør med OpenCode.
