description: "Eksponer en Effect-plugins metoder og hendelser som typede Effects og Streams."
---

Effect-plugins kan gjøre metoder og hendelser tilgjengelige som Effects og Streams med definerte typer.

## Definer

Bruk `Rpc.define` med Effect Schema for å definere RPC-en.

```ts title="src/rpc.ts"
import { Rpc } from "@opencode/plugin/rpc"
import { Schema } from "effect"

export const Acme = Rpc.define({
  id: "acme",
  methods: {
    search: {
      input: Schema.Struct({ query: Schema.String }),
      output: Schema.Struct({ text: Schema.String }),
      errors: {
        not_found: Schema.Struct({ query: Schema.String }),
      },
    },
  },
  events: {
    updated: {
      schema: Schema.Struct({ itemID: Schema.String, text: Schema.String }),
    },
  },
})
```

### Validering

Effect Schema validerer verdier og utleder TypeScript-typene deres.

```ts
input: Schema.Struct({ query: Schema.String })
```

JSON Schema og Standard Schema støttes også.

### Inndata og utdata

Bruk `input` for metodeargumentet og `output` for returverdien. Begge er obligatoriske. Bruk `Schema.Struct({})` hvis
metoden ikke tar imot et argument eller ikke har noen returverdi. Send inn `{}` når metoden ikke tar imot et argument,
og returner `{}` når den ikke har noen returverdi.

```ts
search: {
  input: Schema.Struct({ query: Schema.String }),
  output: Schema.Struct({ text: Schema.String }),
}
```

### Feil

Legg forventede feil til i `errors`. Hver nøkkel blir feilens `type`.

```ts
errors: {
  not_found: Schema.Struct({ query: Schema.String }),
}
```

### Hendelser

Legg hendelsene i `events` på øverste nivå. Hendelsesdata må være et objekt. Feltet er obligatorisk. Bruk `events: {}`
hvis RPC-en ikke har noen hendelser.

```ts
events: {
  updated: {
    schema: Schema.Struct({ itemID: Schema.String, text: Schema.String }),
  },
}
```

## Implementer

Registrer implementasjonen fra Effect-koden i pluginen:

```ts title="src/index.ts"
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"
import { Acme } from "./rpc.js"

export default Plugin.define({
  id: "acme-effect-plugin",
  effect: (ctx) =>
    Effect.gen(function* () {
      const registration = yield* ctx.rpc.register(Acme, {
        search: ({ query }, context) =>
          findText(query).pipe(
            Effect.flatMap((text) =>
              text
                ? Effect.succeed({ text })
                : Effect.fail(context.error("not_found", "Result not found", { query })),
            ),
          ),
      })

      const acme = ctx.rpc(Acme)
      const result = yield* acme.search({ query: "hello" })

      yield* registration.events.emit("updated", { itemID: "item-1", text: result.text })
    }).pipe(Effect.orDie),
})
```

Feilkartet blir feiltypen til hver metode-Effect. Bruk
`context.error(...)` for å lage en deklarert feil.

## Kall

Når RPC-en er registrert, kan den kalles over HTTP eller fra en annen plugin.

### HTTP

Lag Effect-klienten, og lag deretter RPC-subklienten:

```ts
import { OpenCode } from "@opencode/client/effect"
import { Effect } from "effect"
import { FetchHttpClient } from "effect/http"
import { Acme } from "opencode-acme-plugin/rpc"

const program = Effect.gen(function* () {
  const client = yield* OpenCode.make({ baseUrl: "http://localhost:4096" })
  const acme = client.rpc(Acme)
  return yield* acme.search({ query: "hello" })
})

const result = await Effect.runPromise(program.pipe(Effect.provide(FetchHttpClient.layer)))
```

### Plugin

En annen Effect-plugin kan lage en lokal subklient fra konteksten sin:

```ts
import { Effect } from "effect"

effect: (ctx) =>
  Effect.gen(function* () {
    const acme = ctx.rpc(Acme)
    const result = yield* acme.search({ query: "hello" })
    yield* Effect.logInfo(result.text)
  }).pipe(Effect.orDie)
```

### Abonner

RPC-hendelser leveres som Streams. Abonner med hendelsesnavnet og les strømmen i en fiber som er bundet til scopet:

{/* prettier-ignore */}
```ts
import { Effect, Stream } from "effect"

const acme = ctx.rpc(Acme)

yield* acme.events.subscribe("updated").pipe(
  Stream.runForEach((event) => Effect.logInfo(event.data.text)),
  Effect.forkScoped,
)
```

Abonnementer leverer bare nye hendelser og lukkes når lesingen fra strømmen stopper.
