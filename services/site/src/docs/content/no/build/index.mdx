Millioner bruker OpenCode hver dag. Med OpenCode som grunnlag kan du lage egne
apper, integrasjoner og løsninger med agenter uten å starte fra bunnen av.

Vi tilbyr også Effect-API-er for [plugins](/build/plugins/effect),
[klienter](/build/client/effect) og [innebygde apper](/build/sdk/effect).
