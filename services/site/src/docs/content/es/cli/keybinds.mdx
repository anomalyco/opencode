---

Personaliza las combinaciones en `cli.json`:

```json title="cli.json"
{
  "keybinds": {
    "leader": "ctrl+space",
    "command.palette.show": "ctrl+k",
    "app.exit": ["ctrl+c", "ctrl+d"],
    "app.debug": false
  },
  "leader": {
    "timeout": 1500
  }
}
```

Usa una cadena para una sola tecla:

```json
{
  "keybinds": {
    "command.palette.show": "ctrl+k"
  }
}
```

Separa las alternativas con comas:

```json
{
  "keybinds": {
    "app.exit": "ctrl+c,ctrl+d"
  }
}
```

Deshabilita una combinación con `"none"` o `false`:

```json
{
  "keybinds": {
    "app.debug": "none",
    "help.show": false
  }
}
```

Usa un objeto para el comportamiento de los eventos:

```json
{
  "keybinds": {
    "prompt.paste": {
      "key": "ctrl+v",
      "preventDefault": false
    }
  }
}
```

`leader` es `ctrl+x` de forma predeterminada. `<leader>` en otra combinación hace referencia a esa tecla.

```json
{
  "keybinds": {
    "leader": "ctrl+space",
    "model.list": "<leader>m"
  },
  "leader": {
    "timeout": 2000
  }
}
```

Los ID de comando desconocidos se ignoran.

## Mini

El comando `app.clear` solo funciona en [`opencode mini`](/cli). Pulsa `ctrl+l` para borrar la pantalla visible y volver a dibujar el prompt. El terminal conserva el historial.

```json title="cli.json"
{
  "keybinds": {
    "app.clear": "ctrl+l"
  }
}
```

| ID          | Predeterminado | Descripción      |
| ----------- | -------------- | ---------------- |
| `app.clear` | `ctrl+l`       | Borra la pantalla |

## Visor de diff

Pulsa `d` (`diff.switch_source`) para elegir **All**, **Committed**, **Uncommitted** o **Last turn** (dentro de una sesión), o selecciona **Base** para cambiar la rama de comparación. Las opciones se recuerdan hasta que se cierra la TUI. Define el alcance inicial con [`diffs.source` en `cli.json`](/cli/config#diffs).

Los atajos de desplazamiento, paginación e inicio/fin siempre controlan el diff. No hay un cambio de foco por teclado: haz clic en los archivos para abrirlos, en las carpetas para expandirlas o contraerlas, y usa la rueda del ratón para desplazar el árbol de archivos.

Usa `n` / `p` o `alt+down` / `alt+up` (Option en macOS) para moverte entre archivos. Dentro del visor de diff, los atajos con Alt navegan por los archivos, no por las pestañas de sesión.

Pulsa `m` para marcar un archivo como revisado y contraer el cuerpo de su parche. En la vista de todos los archivos, pulsa `m` de nuevo para desmarcarlo y volver a abrir el parche. La vista de un solo archivo avanza automáticamente al siguiente archivo al marcarlo como revisado, pero se queda en el último en lugar de volver al principio. Desmarcar un archivo nunca avanza.

Haz clic derecho en un archivo de la barra lateral o en su encabezado de diff para **Mark complete** (o **Mark incomplete**). Esto cambia el mismo estado de revisión que `m`. Completar otro archivo desde su menú no lo selecciona ni avanza el archivo que se está leyendo.

Las alternativas con Shift de `diff.help` admiten terminales que informan del modificador Shift al pulsar `?`.

Selecciona un comando en ejecución en la pestaña **Shell** y pulsa **Enter**, o haz clic en él, para ver el stdout y el stderr capturados.
Usa **↑/↓**, **Page Up/Down** o **Home** para desplazarte, **End** para seguir la salida nueva y **Esc** para volver sin detener el comando.
El visor muestra la salida reciente y permanece abierto tras la salida; la salida redirigida a un archivo no se incluye.
