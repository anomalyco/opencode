---
title: "Desarrollar con OpenCode"
description: "Desarrolla con OpenCode mediante plugins, el cliente de TypeScript para su API HTTP o el SDK para integrarlo en tu aplicación."
---

Millones de personas usan OpenCode cada día. Úsalo como base para crear tus propias
aplicaciones, integraciones y experiencias con agentes sin empezar desde cero.

También ofrecemos API de Effect para [plugins](/build/plugins/effect),
[clientes](/build/client/effect) y [aplicaciones integradas](/build/sdk/effect).

<CardGroup cols={1}>
  <Card title="Extend OpenCode" href="/build/plugins">
    Crea plugins que agregan herramientas, integraciones, comandos, agentes y comportamiento personalizado sin alterar el resto de OpenCode.
  </Card>
  <Card title="Run it as a server" href="/build/client">
    Conéctate a OpenCode con el mismo cliente que usan la TUI y la aplicación de escritorio y crea cualquier interfaz, flujo de trabajo o
    experiencia con agentes a partir de él.
  </Card>
  <Card title="Embed it" href="/build/sdk">
    Integra OpenCode directamente en tu aplicación y úsalo como base para crear un agente, una interfaz o un producto para
    desarrolladores completamente personalizado.
  </Card>
</CardGroup>
