---
title: "SDK de Effect"
description: "Aloja OpenCode en un programa de Effect con @opencode/sdk/effect, el SDK integrado nativo de Effect."
---

`@opencode/sdk/effect` es el SDK integrado nativo de Effect. Las operaciones devuelven Effects y Streams tipados, y cerrar
el Scope al que pertenece el host libera el router, los servicios de Location, las fibras y los registros de plugins.

```sh
bun add @opencode/sdk effect@4.0.1
```

## Crear un host

Crea el host dentro de `Effect.scoped` y luego usa sus grupos de API generados o el alias `sessions`.

```ts
import { AbsolutePath, Location, OpenCode } from "@opencode/sdk/effect"
import { Effect } from "effect"

const program = Effect.scoped(
  Effect.gen(function* () {
    const opencode = yield* OpenCode.create()
    const session = yield* opencode.sessions.create({
      location: Location.Ref.make({ directory: AbsolutePath.make("/workspace") }),
    })
    yield* opencode.sessions.prompt({
      sessionID: session.id,
      text: "Review the current changes",
    })
    return session
  }),
)

const session = await Effect.runPromise(program)
```

El host integrado usa los mismos valores de esquema, errores declarados, opciones de solicitud y Streams que
`@opencode/client/effect`.

```ts
const info = yield* opencode.server.info()
const sessions = yield* opencode.sessions.list()
```

## Transmitir eventos

Los endpoints de streaming devuelven valores `Stream` de Effect. Para ejecutar los consumidores en segundo plano,
lánzalos en fibras separadas dentro del Scope del host.

```ts
import { Effect, Stream } from "effect"

yield* opencode.events.subscribe().pipe(
  Stream.runForEach((event) => Effect.logInfo("OpenCode event", { type: event.type })),
  Effect.forkScoped,
)
```

## Personalizar

Personaliza tu instancia de OpenCode registrando plugins de Effect. Usa el host integrado
para personalizar agentes, modelos, herramientas y otro comportamiento:

```ts
import { Plugin } from "@opencode/plugin/effect"
import { Effect } from "effect"

const plugin = Plugin.define({
  id: "customize-agent",
  effect: (ctx) =>
    Effect.gen(function* () {
      const agent = ctx.agent
      yield* agent.transform((agents) => {
        agents.update("build", (agent) => {
          agent.description = "Builds features and fixes bugs for our team"
        })
      })
    }),
})

yield* opencode.plugin(plugin)
```

Consulta la [documentación completa de plugins de Effect](/build/plugins/effect) para los hooks, las
transformaciones, las herramientas y el contexto completo de plugins.

## Layer

Usa `OpenCode.layer()` cuando el host integrado deba ser un servicio de la aplicación.

```ts
import { OpenCode } from "@opencode/sdk/effect"
import { Effect } from "effect"

const program = Effect.gen(function* () {
  const opencode = yield* OpenCode.Service
  return yield* opencode.server.info()
})

const health = await Effect.runPromise(program.pipe(Effect.provide(OpenCode.layer())))
```
