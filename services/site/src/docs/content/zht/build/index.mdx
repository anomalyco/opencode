每天都有數百萬人使用 OpenCode。以 OpenCode 為基礎，你不必從頭開始，
就能開發自己的應用程式、整合功能與 agent 體驗。

我們也為[外掛](/build/plugins/effect)、
[用戶端](/build/client/effect)與[嵌入式應用程式](/build/sdk/effect)提供 Effect API。

  <Card title="Extend OpenCode" href="/build/plugins">

    不變。
  </Card>
  <Card title="Run it as a server" href="/build/client">

    agent 體驗。
  </Card>
  <Card title="Embed it" href="/build/sdk">
    將 OpenCode 直接嵌入你的應用程式，打造完全自訂的 agent、介面或開發者產品。
  </Card>
