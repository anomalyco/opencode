不論團隊大小，控制台本身都免費，不收席次費。你只需按實際用量付費，費用從整個工作區共用的預付額度扣除。
擁有者與管理員可以在 **Settings › Billing** 管理帳單。

使用[你自己的供應商](/console/providers)時，費用由該供應商收取，不會由控制台計費。

## 新增付款方式

1. 開啟 **Settings › Billing**。
2. 在 **Payment methods** 下點選 **Add**。
3. 選擇付款方式並完成 Stripe 設定。

支援的付款方式：

- 卡片付款
- Link
- Alipay
- UPI
- WeChat Pay

使用 **⋯ › Make default** 設定自動扣款的付款方式。移除付款方式後，原本透過該方式扣款的自動儲值和 Go 續訂可能會停止。

## 新增額度

1. 在 **Credits** 下點選 **Add credits**。
2. 選擇 $10、$50 或 $100，或選擇 **Other** 並輸入金額。
3. 選擇付款方式並點選 **Confirm and pay**。

每筆儲值另收 4.6% + $0.31 手續費。例如儲值 $50 時，實際付款 $52.61，餘額會全額增加 $50。

## 自動儲值

開啟自動儲值後，餘額不足時會自動補充額度。

1. 在 **Auto-recharge** 下點選 **Add rule**。
2. 設定觸發儲值的餘額門檻和每次儲值的金額。
3. 點選 **Save**。

自動儲值會透過預設付款方式扣款，金額包含手續費。扣款失敗時，自動儲值會停用，直到你重新設定。

## 檢查餘額

在 **Activity** 頁面，擁有者和管理員可以在 **Billing** 卡片上查看餘額。點選卡片即可開啟 **Settings › Billing**。

點選工作區頁首的 **Billing** 按鈕，或按 `B` 鍵，即可開啟側邊面板，查看即時的 Go 用量上限、額度與用量。
擁有者與管理員可以查看工作區的餘額、用量與自動儲值設定；成員只能查看自己的用量與上限。

## 額度用盡時

餘額歸零後，付費請求會收到 HTTP `402` 錯誤。餘額不會低於零。

```text
Upstream request failed: Insufficient account funds
```

## 發票

每筆付款都會出現在 **Invoices** 下，包含其狀態與 **Download invoice** 或 **View receipt** 的連結。

| 項目 | 建立方式 |
| --- | --- |
| 餘額儲值 | 新增額度 |
| 自動儲值 | 自動儲值 |
| Go 訂閱 | 訂閱 Go、Go Plus 或 Go Teams |
| Go 續訂 | 每月 Go 續訂 |
| Go Plus 升級 | 將 Go 升級為 Go Plus |
| Go Teams 升級 | 將 Go 或 Go Plus 升級為 Go Teams |
| Go Teams 成員 | 成員加入 Go Teams 工作區 |
| 每月用量 | 按發票結算 |

## 按發票結算

已簽訂授信協議的工作區可改採每月開立發票結算，不必預購額度。如需開通，請聯絡客服。

- 使用費用會計入授信額度，而不是從預付餘額扣除。
- 每月 1 日（UTC）開立發票，付款期限為開立後 14 天。
- 未結清的發票會有 **Pay now** 按鈕。
- 用滿授信額度或發票逾期時，請求會收到 HTTP `402` 錯誤。

## Go

[OpenCode Go](/console/go) 訂閱使用相同的付款方式，並出現在相同的發票清單中。你也可以
[以額度支付 Go](/console/go#pay-with-credit)。在 **Go** 頁面開啟 **Extra Usage** 後，達到 Go 用量上限時，
額外用量會從額度扣款。
