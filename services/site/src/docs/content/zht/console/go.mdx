OpenCode Go 讓你可靠地存取熱門的開放編碼模型，並提供三種每月方案：

| 方案 | 價格 | 包含的用量 |
| --- | --- | --- |
| **Go** | **每月 $10** | 以較低成本存取下列模型 |
| **Go Plus** | **每月 $40** | 下列模型的較高用量上限 |
| **Go Teams** | **每位成員每月 $20**，至少 2 位成員 | 每位成員各有自己的用量上限，每個模型的每月上限比 Go 高 $5 |

Go 的運作方式與 OpenCode 中的其他供應商相同。你訂閱 OpenCode Go 並取得 API 金鑰。它**完全為選用**，使用 OpenCode 並不需要它。

此服務主要為國際使用者設計，提供穩定的全球存取。

## 運作方式

1. 登入 [OpenCode 控制台](https://opencode.ai/console)、訂閱 Go、Go Plus 或 Go Teams、新增帳單詳細資料，並複製 API 金鑰。
2. 在 TUI 中執行 `/connect`、選擇 **OpenCode Go**，並貼上 API 金鑰。

   ```text
   /connect
   ```

3. 執行 `/models` 選擇可透過 Go 使用的模型。

   ```text
   /models
   ```

<Callout>
  Go 與 Go Plus 涵蓋訂閱者本人與工作區的 API 金鑰。你邀請的其他成員會使用免費模型
  或工作區餘額。兩者都可以隨時升級至 Go Teams，當月未使用的額度部分
  會折抵。Go Teams 以每位成員每月 $20 涵蓋工作區的每位成員，最少 2 位成員
  （每月 $40）。下一位加入的成員會使用已計費的第二個席次，不另收費。之後若有成員在計費週期中途加入，
  系統會收取 $20，該成員可獲得完整的每月額度。Go Teams 不涵蓋服務帳號。
</Callout>

請參閱[目前的模型清單](https://opencode.ai/console/go#models)。隨著我們測試並新增模型，清單可能變更。

### 啟用受限模型

工作區隱私設定會套用至 Go。付費端點若會以請求資料進行訓練，預設會遭到封鎖，允許的地區為
**Europe & United States**。沒有儲存隱私設定的工作區，也會為來自中國的請求允許 **Global**。

在 **Settings › Privacy** 中，擁有者或管理員可以啟用：

- **DeepSeek V4.1 Flash 與 V4 Pro：** 在 **Regions** 下選擇 **Global**。
- **LongCat 2.5：** 在 **Regions** 下選擇 **Global**。
- **Muse Spark 1.3 Contributor 與 Muse Spark 1.2 Contributor：** 開啟 **Allow paid endpoints that train on request data**。

各模型的訓練與保留條款請參閱[隱私](#privacy)。

## 以額度支付

擁有者與管理員可以使用工作區額度支付 Go，包括續訂與升級。訂閱時請選擇 **Credit** 作為
付款方式，或之後在 **Manage subscription** 中選擇。這與
[額外用量](#usage-beyond-limits)不同，後者是為超出限制的用量付費。

- 全額會從你的額度餘額扣除。若餘額不足，你可以先新增額度。
- 續訂費用會在計費週期結束時從額度扣除。若額度不足，Go 仍可使用；系統會在週期結束後的
  第 1、3、7 天重試扣款，額度補足後也會立即重試。若最後一次重試仍失敗，Go 訂閱就會終止。
- 使用[按發票結算](/console/billing#invoiced-billing)的工作區無法以額度支付 Go。
- 以額度支付的 Go 款項退款會回到你的額度，並結束該 Go 期間。

## 可以在哪裡使用？

OpenCode Go 是為 [OpenCode](https://opencode.ai) 與其他會產生類似類型請求的編碼 agent
所設計。流量會受到監控，以防止濫用而
降低其他使用者的體驗。

你的用戶端應該：

1. 傳送典型的編碼 agent 流量
2. 使用專屬的 User-Agent 識別用戶端，例如 `my-coding-agent/1.0`，
   而不是通用的 SDK 或 HTTP 程式庫名稱。
3. 同一段對話的每個請求都在 `x-opencode-session` 中傳送相同的工作階段 ID，讓我們能最佳化路由與
   提示詞快取。

[決策](#decision-models)與[嵌入](#embedding-models)請求不需要 `x-opencode-session`，因此任何
用戶端（例如 RAG 程式庫、記憶供應商或指令碼）都可以使用你的 Go 金鑰呼叫它們。

在 Claude Code、Codex、Hermes、OpenClaw、Pi 與 Raycast 中設定 Go 請參閱 [Harness](/console/harnesses)。

## 用量上限

你在 Go 上使用的付費模型共用一份額度。在 Go Teams 上，每位成員在模型之間擁有自己的額度。

- **5 小時用量上限**為每月額度的 20%。首次使用額度時開始計時，持續五小時。
- **每週用量上限**為每月額度的 50%，於週一 00:00 UTC 重設。
- 你的**每月額度**會在新的付費期間開始時重設。

切換模型會從同一份額度扣除。若達到限制，你可以使用免費模型，或開啟
[額外用量](#usage-beyond-limits)以使用控制台額度，直到你再次有可用額度。

每個模型的[每月限制](https://opencode.ai/console/go#limits)顯示，若你整月只使用該模型，你的方案涵蓋多少用量。
例如，在限制為 $15 的模型上使用 $1.50 會用掉每月額度的 10%。在限制為 $60 的模型上使用 $6 也是如此。Go 回應會透過
[`opencode.allowance`](/console/api/inference#cost) 回報每個請求計入多少。

[Token 價格](https://opencode.ai/console/go#pricing)為每 100 萬 token，且 Go、Go Plus 與 Go Teams 相同。

[決策](#decision-models)與[嵌入](#embedding-models)模型依定價計費，沒有 Go 折扣：其
每月限制等於你支付的金額，Go 為 $10，Go Plus 為 $40。Go Teams 則為 $15，比 Go 高 $5，
與每個模型相同。

**Beam Free：** 限時免費。安哥拉、白俄羅斯、柬埔寨、中國（包括香港與澳門）、古巴、剛果民主共和國、赤道幾內亞、伊朗、伊拉克、寮國、利比亞、奈及利亞、北韓、俄羅斯、敘利亞、土庫曼、烏茲別克、委內瑞拉，以及烏克蘭的克里米亞、頓內茨克與盧甘斯克地區無法使用。

**Gemini 4 Argon：** 50% 折扣適用至 2026 年 11 月 30 日。

**HungerG Free：** 限時免費。

### 超出限制的用量

若你的控制台餘額中也有額度，可以在
**Go** 頁面開啟 **Extra Usage**。啟用後，達到用量上限時，Go 會改從[按用量計費的餘額](/console/models#pricing)扣款，
而不是擋下請求。

Go Teams 預設會開啟 **Extra Usage**，你可以在 **Go** 頁面將其關閉或再次開啟。

### 為什麼有些模型的用量較低

使用 Go 時，包含的每月用量依模型而異。

對大多數模型，我們透過大量採購取得折扣，並預留 GPU 算力，再把省下的成本轉為更多每月用量回饋給你。

對某些模型，我們沒有機會談到折扣或以較低成本託管，因為模型是新的，或其公開定價已經打折。

對這些模型，你仍會比直接向模型供應商付費多得到一些；這就是其包含的每月用量較低的原因。

你也可以透過 `https://opencode.ai/inference/go` 的 API 存取 Go 模型。請參閱每個模型的
[ID、路徑與 AI SDK 套件](https://opencode.ai/console/go#api)。每個模型都會列出其原生 API，但每個

`opencode-go/<model-id>` 格式設定[模型](/models)：

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "model": "opencode-go/kimi-k3",

```

### 決策模型

決策模型會回答關於 `state` 的具型別問題，而不是產生文字。請以你的 Go
金鑰，將與[控制台模型](/console/models#jev)相同的 System One 請求傳送到 `https://opencode.ai/inference/go/systemone/v1/systemone`：

```bash
curl https://opencode.ai/inference/go/systemone/v1/systemone \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jev-1.14",
    "state": "My payments have failed for three days and I am losing sales.",
    "questions": {
      "is_urgent": {
        "type": "noul",
        "instructions": "Does this request require urgent attention?"
      }
    }
  }'
```

| 模型 | 模型 ID | 輸入 | 輸出 | 快取讀取 | 快取寫入 |
| --- | --- | --- | --- | --- | --- |
| Jev 1.14 | jev-1.14 | $0.042 | 免費 | - | - |
| Gemini Decision 1 | gemini-decision-1 | $0.10 | 免費 | - | - |
| GPT 6 Luna Decision (≤ 272K tokens) | gpt-6-luna-decision | $0.10 | 免費 | $0.01 | $0.125 |
| GPT 6 Luna Decision (> 272K tokens) | gpt-6-luna-decision | $0.20 | 免費 | $0.02 | $0.25 |

- 價格為每 100 萬 token。
- 使用 OpenAI Decisions 格式的請求可在 `https://opencode.ai/inference/go/openai/v1/decisions` 使用。
- 問題類型請參閱 [Jev](/console/models#jev)，`state` 中的圖片、
  音訊、影片與 PDF 請參閱
  [GPT 6 Luna Decision 與 Gemini Decision 1](/console/models#gpt-6-luna-decision-and-gemini-decision-1)。

### 嵌入模型

嵌入模型會將文字轉為向量。請以你的 Go 金鑰，在 OpenAI 的 Embeddings API 上呼叫它們：
`https://opencode.ai/inference/go/openai/v1/embeddings`：

```bash
curl https://opencode.ai/inference/go/openai/v1/embeddings \
  -H "Authorization: Bearer $OPENCODE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "text-embedding-3-small",
    "input": ["hello world", "goodbye"]
  }'
```

| 模型 | 模型 ID | 輸入 |
| --- | --- | --- |
| text-embedding-3-small | text-embedding-3-small | $0.02 |
| Qwen3 Embedding 8B | qwen3-embedding-8b | $0.01 |
| Gemini Embedding 2 | gemini-embedding-2 | $0.20 |

- 價格為每 100 萬輸入 token。
- 請求也接受 `dimensions` 與 `encoding_format`。請參閱[嵌入模型](/console/models#embedding-models)。

### 用量

你可以查詢已用掉多少[用量上限](#usage-limits)，例如在自己的用戶端顯示用量：

```bash
curl https://opencode.ai/inference/go/v1/usage \
  -H "Authorization: Bearer <token>"
```

請使用你於 Go 使用的相同金鑰。在 Go 與 Go Plus 上，這是訂閱者的
[個人 API 金鑰](/console/api#personal-api-keys)或[服務帳號金鑰](/console/api#service-accounts)。在 Go
Teams 上，則是任何成員的個人 API 金鑰。

回應會為每個限制提供一個計量：5 小時限制為 `rolling`，另有 `weekly` 與 `monthly`。

```json
{
  "usage": {
    "rolling": { "status": "ok", "percent": 30, "resetsAt": "2026-11-21T15:00:00.000Z" },
    "weekly": { "status": "rate-limited", "percent": 100, "resetsAt": "2026-11-23T00:00:00.000Z" },
    "monthly": { "status": "ok", "percent": 50, "resetsAt": "2026-12-01T00:00:00.000Z" }
  }
}
```

| 欄位 | 意義 |
| --- | --- |
| `status` | `ok`，或限制用盡後的 `rate-limited`。 |
| `percent` | 已使用的限制比例，為 `0` 到 `100` 的整數。 |
| `resetsAt` | 限制重設的時間，格式為 ISO 8601。5 小時視窗開始前，`rolling` 會從現在起五小時後重設。 |

沒有有效金鑰的請求會回傳 HTTP `401`。Go 未涵蓋的金鑰會回傳 HTTP `403`，並附上說明原因的訊息，
例如工作區沒有作用中的 Go 訂閱。

```json
{ "type": "error", "error": { "type": "EntitlementError", "message": "OpenCode Go subscription required." } }
```

## 背景

開放模型已經變得非常好。它們現在在編碼工作上已接近專有模型的表現。由於許多供應商能以具競爭力的方式提供它們，價格通常低得多。

然而，要可靠且低延遲地存取它們可能很困難。供應商的品質與可用性各不相同。

<Callout type="tip">我們測試了一組精選的模型與供應商，確認它們能與 OpenCode 良好搭配。</Callout>

為了解決這個問題，我們做了幾件事：

1. 我們測試一組精選的開放模型，並與其團隊討論最佳的執行方式。
2. 我們與幾家供應商合作，確保這些模型正確提供。
3. 我們對模型／供應商組合進行基準測試，整理出一份我們能安心推薦的清單。

Go、Go Plus 與 Go Teams 都提供這些模型的存取權；請選擇符合你使用量的方案，或選擇 Go
Teams 以涵蓋整個團隊。

## 目標

我們建立 OpenCode Go 是為了：

1. 以低成本訂閱讓更多人**易於使用** AI 編碼。
2. 提供**可靠**的管道，存取最好的開放編碼模型。
3. 精選**經過測試與基準測試**、適合編碼 agent 使用的模型。
4. **不綁定**，讓你也能在 OpenCode 中使用任何其他供應商。
