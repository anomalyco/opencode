---
title: "預算"
description: "限制工作區、其成員與服務帳號的每月支出。"
---

預算會透過原則限制每月支出。擁有者與管理員在 **Controls** 中管理它們。

## 預算層級

| 原則對象 | 適用於 |
| --- | --- |
| 整個工作區 | 所有成員與服務帳號的合計支出 |
| 所有成員 | 每位成員，或所有成員共用一份額度 |
| 標記為以下的成員 | 具有所選標籤的成員 |
| 這些成員 | 特定成員 |
| 所有服務帳號 | 每個服務帳號，或共用一份額度 |
| 這些服務帳號 | 特定服務帳號 |

請求不得超出任何一項適用預算。較高的額度不會取代較低的額度。未設定預算時，支出沒有上限。

## 工作區預算

工作區達到預算後，會為所有人封鎖請求。

1. 開啟 **Controls** 並點選 **Add policy**。
2. 選擇 **Entire workspace** 並新增 **Budget** 規則。
3. 輸入每月支出上限（美元），再點選 **Save**。

## 成員預算

在原則中選擇 **All members**，為每位成員提供每月額度，或在群組中共用一個金額。
選擇特定成員或標籤，以涵蓋較小的群組。

若要為一個人設定預算：

1. 在 **Settings › Members** 中開啟該成員。
2. 點選 **Create budget policy**，開啟原則編輯器，其中已預先選取該成員。
3. 輸入金額並點選 **Save**。

該成員的詳細資料頁面會列出適用的原則。如果另有適用於所有成員的預算，兩項上限都有效。

## 服務帳號預算

在 **Controls** 中選擇 **All service accounts** 或 **These service accounts**，新增 **Budget** 規則，並設定
個別或共用的每月額度。該原則涵蓋屬於這些帳號的每個金鑰。

## 金額與重設

- 金額以美元表示，最多可輸入兩位小數。
- 預算會在每月 1 日 00:00 UTC 重設。
- `$0` 預算會封鎖所有計入預算的支出。
- 新增或變更預算會涵蓋該月已記錄的支出；不會重設額度。

## 計入範圍

預算預設涵蓋 **All spend**。你可以將其縮小到所選模型；如此只有這些模型會計入，
可為整組提供一份額度，或為每個模型提供個別額度。

| 支出 | 計入預算 |
| --- | --- |
| 付費控制台模型 | 是 |
| 已設定價格之[你自己的供應商](/console/providers)上的模型 | 是，依設定的價格 |
| [網路搜尋](/console/websearch) | 是，適用於全支出預算 |
| 免費模型 | 否 |
| 方案內的 [Go](/console/go) 用量 | 否 |
| 從額度支付的 Go 額外用量 | 是 |

## 達到預算時

新請求會收到 HTTP `429`，直到預算重設，或擁有者或管理員調高預算。回應會指出
請求因超出原則規定的預算而失敗，但不會指明是哪一項預算。請在 **Activity › Logs** 開啟該請求，
查看是哪一項原則擋下請求。

```text
Upstream request failed: Policy budget exceeded
```

預算會在請求開始時檢查。已在進行中的請求會完成，因此支出可能略高於
上限。

## 追蹤支出

每位成員會在 **Activity** 上看到自己的支出與限制。開啟 **My usage** 查看 **Activity › Overview**，
包括預算詳細資料與重設日期。

擁有者與管理員可以從支出圖表開啟 **Activity › Usage**。它會依日期、模型與
人員細分成本，**Export usage** 按鈕會將最近 7、30 或 90 天的每日總計下載為 CSV。若要從指令碼下載
相同檔案，請使用[用量匯出 API](/console/api/usage-export)。
