工作區包含[控制台](https://opencode.ai/console)中的一切：成員、額度、預算、供應商、
原則與服務帳號。用量與帳單會依工作區追蹤。

工作區可以只有一位成員。你可以自行使用額度、[自己的供應商](/console/providers)、預算與 [Go](/console/go)，
並只在需要時[邀請成員](/console/members)。

## 你的第一個工作區

你註冊時，控制台會建立名為 **Personal** 的工作區，你是其擁有者與唯一成員。若你
從邀請註冊，則會改為加入邀請你的工作區，不會建立 Personal 工作區。

## 建立工作區

1. 開啟頂端列中的工作區選單。
2. 點選 **Create Workspace**。
3. 輸入 **Workspace name** 並點選 **Create**。

你會成為新工作區的擁有者。

## 切換工作區

從工作區選單選擇另一個工作區。控制台會讓你停留在相同頁面，因此從
`/acme/settings/members` 切換時，會開啟另一個工作區的「成員」頁面。

待處理的邀請會出現在同一選單的頂端。請參閱[成員](/console/members#accept-an-invitation)。

## 連接 OpenCode

在 OpenCode 中執行 `/connect`，並在瀏覽器中選擇工作區。OpenCode 接著會使用該工作區的模型、
原則與預算。

```text
/connect
```

再次執行 `/connect` 可將 OpenCode 切換到另一個工作區。工作區[原則](/policies#console)會替換為
新工作區的原則，並在中斷連接時清除。

## 角色

每位成員都有一個角色。新成員一律以 **Member** 身分加入。

| 角色 | 可以做的事 |
| --- | --- |
| Member | 使用 OpenCode、查看自己的用量、日誌與預算。 |
| Admin | 成員能做的所有事，以及管理成員、帳單、預算、供應商、原則、服務帳號與設定。 |
| Owner | 管理員能做的所有事，以及管理 SSO 與目錄同步、授予 Owner 角色，以及刪除工作區。 |

成員會在 **Activity** 上看到自己的用量與日誌，以及對成員可見時的排行榜。
當工作區具有 [Go Teams](/console/go) 訂閱時，他們也會看到 **Go** 與自己的限制。
他們從帳號選單開啟 **Account**。

### 角色規則

- 一個工作區可以有多位擁有者，且一律保留至少一位。
- 你不能指派高於自身的角色，因此只有擁有者能將擁有者角色授予其他成員。
- 你不能變更自己的角色。

### 移轉擁有權

1. 以擁有者身分開啟 **Settings › Members**，將新擁有者的角色設為 **Owner**。
2. 請新擁有者將你的角色變更為 **Admin** 或 **Member**。

## 刪除工作區

只有擁有者可以刪除工作區，而且該擁有者必須同時是至少另一個工作區的成員。

1. 開啟 **Settings › General** 並點選 **Delete workspace**。
2. 勾選每一項確認。
3. 點選 **Delete workspace** 確認。

刪除會立即生效且無法復原：

- 成員會立即失去存取權。
- 所有服務帳號 API 金鑰與待處理邀請都會撤銷。
- 自動儲值會停止。
- 尚未到期的 Go 訂閱會終止。
- 未用完的額度將失效。

<Callout type="warning">處理付款期間無法刪除工作區。請等幾分鐘再試。</Callout>

## 離開工作區

1. 從帳號選單開啟 **Account**。
2. 在 **Connected workspaces** 下，點選工作區旁的 **Leave**。
3. 以 **Leave workspace** 確認。

最後一位擁有者不能離開；請先讓另一位成員成為擁有者。在具有 SSO 或目錄同步的工作區中，
成員資格由你的身分識別提供者管理，因此你無法從控制台離開。離開後若要重新加入，請要求新的
邀請。
