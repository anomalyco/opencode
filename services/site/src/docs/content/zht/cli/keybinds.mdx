---

在 `cli.json` 中自訂繫結：

```json title="cli.json"
{
  "keybinds": {
    "leader": "ctrl+space",
    "command.palette.show": "ctrl+k",
    "app.exit": ["ctrl+c", "ctrl+d"],
    "app.debug": false
  },
  "leader": {
    "timeout": 1500
  }
}
```

單一按鍵請使用字串：

```json
{
  "keybinds": {
    "command.palette.show": "ctrl+k"
  }
}
```

以逗號分隔替代按鍵：

```json
{
  "keybinds": {
    "app.exit": "ctrl+c,ctrl+d"
  }
}
```

使用 `"none"` 或 `false` 停用繫結：

```json
{
  "keybinds": {
    "app.debug": "none",
    "help.show": false
  }
}
```

事件行為請使用物件：

```json
{
  "keybinds": {
    "prompt.paste": {
      "key": "ctrl+v",
      "preventDefault": false
    }
  }
}
```

`leader` 預設為 `ctrl+x`。其他繫結中的 `<leader>` 會引用該按鍵。

```json
{
  "keybinds": {
    "leader": "ctrl+space",
    "model.list": "<leader>m"
  },
  "leader": {
    "timeout": 2000
  }
}
```

未知的指令 ID 會被忽略。

## Mini

`app.clear` 指令只適用於 [`opencode mini`](/cli)。按 `ctrl+l` 清除可見畫面並重新繪製提示詞。終端機會保留捲動歷史。

```json title="cli.json"
{
  "keybinds": {
    "app.clear": "ctrl+l"
  }
}
```

## Diff 檢視器

按 `d`（`diff.switch_source`）選擇 **All**、**Committed**、**Uncommitted** 或 **Last turn**（在工作階段內），或選擇 **Base** 變更比較分支。選擇會保留到 TUI 結束。初始範圍請以 [`cli.json` 中的 `diffs.source`](/cli/config#diffs) 設定。

捲動、翻頁與跳到開頭或結尾的快捷鍵一律作用於 Diff。無法用鍵盤切換焦點；點選檔案可開啟，點選資料夾可展開或收合，滑動滾輪則可捲動檔案樹。

使用 `n` / `p` 或 `alt+down` / `alt+up`（macOS 上為 Option）切換檔案。在 Diff 檢視器內，Alt 快捷鍵切換的是檔案，不是工作階段分頁。

按 `m` 將檔案標記為已審查並收合其修補內容。在全部檔案檢視中，再按一次 `m` 可取消標記並重新開啟修補。單一檔案檢視在標記為已審查時會自動前進到下一個檔案，但會停留在最後一個檔案，不會繞回。取消標記檔案永遠不會前進。

在側邊欄或 Diff 標題上按右鍵，可選擇 **Mark complete**（或 **Mark incomplete**）。這會變更與 `m` 相同的已審查狀態。從選單完成另一個檔案不會選取它，也不會前進目前正在閱讀的檔案。

帶 Shift 的 `diff.help` 替代按鍵支援在你按 `?` 時回報 Shift 修飾鍵的終端機。

| `composer.shell.down` | `down` | 下一個 shell |
| `composer.shell.select` | `return` | 檢視 shell 輸出 |
| `composer.shell.kill` | `ctrl+d` | 終止 shell 指令 |
| `composer.terminal.up` | `up,k` | 上一個終端機 |
| `composer.terminal.down` | `down,j` | 下一個終端機 |
| `composer.terminal.select` | `return` | 選取終端機 |

在 **Shell** 分頁中選取執行中的指令並按 **Enter**，或點選它，即可檢視擷取的 stdout 與 stderr。
使用 **↑/↓**、**Page Up/Down** 或 **Home** 捲動，**End** 跟隨新輸出，**Esc** 返回而不停止指令。
檢視器會顯示最近的輸出，並在結束後保持開啟；重新導向到檔案的輸出不會包含在內。
