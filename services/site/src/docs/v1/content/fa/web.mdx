با نسخهٔ وب OpenCode می‌توانید مستقیماً در مرورگر و بدون نیاز به ترمینال، با کمک هوش مصنوعی کدنویسی کنید.

![نشست تازه در نسخهٔ وب OpenCode](../../../assets/web/web-homepage-new-session.png)

## شروع کار

برای راه‌اندازی رابط وب، این فرمان را اجرا کنید.

```bash
opencode web
```

این فرمان سروری محلی روی `127.0.0.1` و پورتی آزاد که به‌صورت تصادفی انتخاب می‌شود راه‌اندازی می‌کند و OpenCode را در مرورگر پیش‌فرض شما باز می‌کند.

:::caution
اگر `OPENCODE_SERVER_PASSWORD` را تنظیم نکنید، سرور بدون محافظت خواهد بود. برای استفادهٔ محلی اشکالی ندارد، اما برای دسترسی از شبکه گذرواژه تعیین کنید.
:::

:::tip[کاربران ویندوز]
در ویندوز بهتر است `opencode web` را در [WSL](/docs/windows-wsl) اجرا کنید تا دسترسی به فایل‌ها و ارتباط با ترمینال درست کار کند.
:::

## پیکربندی

تنظیمات وب‌سرور را می‌توانید با گزینه‌های خط فرمان یا در [فایل پیکربندی](/docs/config) تعیین کنید.

### پورت

OpenCode به‌طور پیش‌فرض یک پورت آزاد انتخاب می‌کند. برای تعیین پورت دلخواه، فرمان زیر را اجرا کنید.

```bash
opencode web --port 4096
```

### نام میزبان

سرور به‌طور پیش‌فرض فقط روی `127.0.0.1` (میزبان محلی) گوش می‌دهد. برای دسترسی از شبکه، این فرمان را اجرا کنید.

```bash
opencode web --hostname 0.0.0.0
```

با `0.0.0.0`، OpenCode هم نشانی محلی و هم نشانی شبکه را نمایش می‌دهد.

```
  Local access:       http://localhost:4096
  Network access:     http://192.168.1.100:4096
```

### کشف سرویس با mDNS

برای اینکه دستگاه‌های شبکهٔ محلی بتوانند سرور را پیدا کنند، mDNS را فعال کنید.

```bash
opencode web --mdns
```

با فعال شدن این گزینه، نام میزبان روی `0.0.0.0` تنظیم می‌شود و سرور با نام `opencode.local` خود را به شبکه معرفی می‌کند.

برای اجرای چند نمونه در یک شبکه، می‌توانید نام دامنهٔ mDNS را تغییر دهید.

```bash
opencode web --mdns --mdns-domain myproject.local
```

### CORS

برای مجاز کردن دامنه‌های دیگر در CORS، برای مثال هنگام استفاده از رابط وب سفارشی، این گزینه را به کار ببرید.

```bash
opencode web --cors https://example.com
```

### احراز هویت

برای محدود کردن دسترسی، با متغیر محیطی `OPENCODE_SERVER_PASSWORD` گذرواژه تعیین کنید.

```bash
OPENCODE_SERVER_PASSWORD=secret opencode web
```

نام کاربری پیش‌فرض `opencode` است. با `OPENCODE_SERVER_USERNAME` می‌توانید آن را تغییر دهید.

## استفاده از رابط وب

پس از راه‌اندازی، از طریق رابط وب به نشست‌های OpenCode دسترسی دارید.

### نشست‌ها

در صفحهٔ اصلی می‌توانید نشست‌های فعال را ببینید، نشست‌هایتان را مدیریت کنید و نشست تازه‌ای بسازید.

![نشست فعال در نسخهٔ وب OpenCode](../../../assets/web/web-homepage-active-session.png)

### وضعیت سرور

برای دیدن سرورهای متصل و وضعیت آن‌ها، روی «See Servers» بزنید.

![نمایش سرورها در نسخهٔ وب OpenCode](../../../assets/web/web-homepage-see-servers.png)

## اتصال ترمینال

می‌توانید رابط ترمینالی را به وب‌سرور در حال اجرا متصل کنید.

```bash
# Start the web server
opencode web --port 4096

# In another terminal, attach the TUI
opencode attach http://localhost:4096
```

به این ترتیب رابط وب و ترمینال را هم‌زمان به کار می‌برید و هر دو به همان نشست‌ها و وضعیت دسترسی دارند.

---

## فایل پیکربندی

تنظیمات سرور را می‌توانید در فایل پیکربندی `opencode.json` هم تعیین کنید.

```json
{
  "server": {
    "port": 4096,
    "hostname": "0.0.0.0",
    "mdns": true,
    "cors": ["https://example.com"]
  }
}
```

گزینه‌های خط فرمان بر تنظیمات فایل پیکربندی اولویت دارند.
