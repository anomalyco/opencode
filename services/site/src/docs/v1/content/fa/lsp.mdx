OpenCode می‌تواند به سرورهایی که از پروتکل سرور زبان (LSP) استفاده می‌کنند متصل شود تا عامل هنگام کار به گزارش خطاها و هشدارهای آن‌ها دسترسی داشته باشد.

---

LSP به‌طور پیش‌فرض غیرفعال است. پس از فعال‌سازی، وقتی یکی از پسوندهای بالا شناسایی شود و پیش‌نیازها فراهم باشند، سرور مربوط اجرا می‌شود.

:::note
برای غیرفعال کردن دانلود خودکار سرورهای زبان، متغیر محیطی `OPENCODE_DISABLE_LSP_DOWNLOAD` را روی `true` بگذارید.
:::

---

## نحوهٔ کار

وقتی LSP فعال باشد و OpenCode فایلی را باز کند، مراحل زیر را طی می‌کند.

1. پسوند فایل را با سرورهای زبان فعال مطابقت می‌دهد.
2. سرور زبان مناسب را، اگر از قبل در حال اجرا نباشد، راه‌اندازی می‌کند.

---

## توصیه‌های کاربردی

گزارش خطاهای سرور زبان می‌تواند به عامل در پیدا کردن و رفع مشکل کمک کند. میزان سودمندی آن به پروژه بستگی دارد.

سرورهای زبان گاهی با تغییرات فایل‌ها هماهنگ نمی‌مانند، حافظهٔ زیادی مصرف می‌کنند یا اجرای کار عامل را کند می‌کنند. رفتارشان نیز به نسخه و پروژه بستگی دارد. در بسیاری از پروژه‌ها بهتر است عامل مستقیماً ابزار تحلیل ایستا، بررسی نوع یا دیگر ابزارهای تشخیصی خط فرمان را اجرا کند تا خطاها را همان‌جا دریافت کند. فرمان‌های لازم را در فایل دستورالعملی مانند `AGENTS.md` یا در مهارت‌ها بنویسید. اگر گزارش‌های تکمیلی سرور زبان به کار پروژه می‌آید، LSP را فعال کنید.

## پیکربندی

در بخش `lsp` پیکربندی OpenCode می‌توانید سرورهای زبان را فعال و تنظیم کنید.

برای فعال کردن همهٔ سرورهای زبان داخلی، `lsp` را روی `true` بگذارید.

```json title="opencode.json"
{
  "$schema": "https://opencode.ai/config.json",
  "lsp": true
}
```

با تعریف یک شیء، می‌توانید در کنار سرورهای زبان داخلی فعال، تنظیمات را تغییر دهید یا سرور سفارشی بیفزایید.

```json title="opencode.json"
{
  "$schema": "https://opencode.ai/config.json",
  "lsp": {}
}
```

هر سرور زبان گزینه‌های زیر را می‌پذیرد.

تعیین `command` الزامی است، مگر اینکه فقط بخواهید یک سرور را غیرفعال کنید.

| ویژگی | نوع | توضیحات |
| ---------------- | -------- | ------------------------------------------------- |
| `disabled` | boolean | برای غیرفعال کردن سرور زبان، مقدار `true` را تعیین کنید. |
| `command` | string[] | فرمان راه‌اندازی سرور زبان |
| `extensions` | string[] | پسوند فایل‌هایی که این سرور پردازش می‌کند |
| `env` | object | متغیرهای محیطی هنگام راه‌اندازی سرور |
| `initialization` | object | گزینه‌های مقداردهی اولیه که برای سرور ارسال می‌شوند |

در ادامه چند نمونه می‌بینید.

---

### متغیرهای محیطی

با ویژگی `env` متغیرهای محیطی زمان راه‌اندازی سرور زبان را تعیین کنید.

```json title="opencode.json" {5-8}
{
  "$schema": "https://opencode.ai/config.json",
  "lsp": {
    "rust": {
      "command": ["rust-analyzer"],
      "env": {
        "RUST_LOG": "debug"
      }
    }
  }
}
```

---

### گزینه‌های مقداردهی اولیه

با ویژگی `initialization` گزینه‌های آغاز کار را به سرور زبان بدهید. این تنظیمات مخصوص هر سرورند و همراه درخواست `initialize` در پروتکل LSP فرستاده می‌شوند.

```json title="opencode.json" {5-13}
{
  "$schema": "https://opencode.ai/config.json",
  "lsp": {
    "custom-lsp": {
      "command": ["custom-lsp-server", "--stdio"],
      "extensions": [".custom"],
      "initialization": {
        "preferences": {
          "importModuleSpecifierPreference": "relative"
        }
      }
    }
  }
}
```

:::note
گزینه‌های قابل استفاده را در مستندات سرور زبان خود ببینید.
:::

---

### غیرفعال کردن سرورهای زبان

اگر `lsp` را تعیین نکنید، همهٔ سرورهای زبان غیرفعال‌اند. اگر پیکربندی دیگری آن‌ها را فعال کرده است، برای غیرفعال کردن همه، `lsp` را روی `false` بگذارید.

```json title="opencode.json" {3}
{
  "$schema": "https://opencode.ai/config.json",
  "lsp": false
}
```

برای غیرفعال کردن **یک سرور زبان مشخص**، `disabled` را روی `true` بگذارید.

```json title="opencode.json" {5}
{
  "$schema": "https://opencode.ai/config.json",
  "lsp": {
    "typescript": {
      "disabled": true
    }
  }
}
```

---

### سرورهای زبان سفارشی

برای افزودن سرور زبان سفارشی، فرمان اجرا و پسوند فایل‌های آن را مشخص کنید.

```json title="opencode.json" {4-7}
{
  "$schema": "https://opencode.ai/config.json",
  "lsp": {
    "custom-lsp": {
      "command": ["custom-lsp-server", "--stdio"],
      "extensions": [".custom"]
    }
  }
}
```

## اطلاعات بیشتر

### PHP Intelephense

برای فعال‌سازی امکانات پیشرفتهٔ PHP Intelephense، کلید مجوز لازم است. آن را در یک فایل متنی در مسیر زیر ذخیره کنید.

- در macOS یا لینوکس: `$HOME/intelephense/license.txt`
- در ویندوز: `%USERPROFILE%/intelephense/license.txt`

این فایل باید فقط حاوی کلید مجوز باشد.
