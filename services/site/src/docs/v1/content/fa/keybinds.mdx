  :::

## کلید پیشوند

OpenCode در بسیاری از میان‌برها از کلید پیشوند (`leader`) استفاده می‌کند تا با میان‌برهای ترمینال تداخل پیدا نکنند.

کلید پیشوند به‌طور پیش‌فرض `ctrl+x` است. در بسیاری از میان‌برها ابتدا پیشوند و سپس کلید عملیات را فشار می‌دهید. برای نمونه، برای شروع نشست تازه ابتدا `ctrl+x` و سپس `n` را بزنید.

استفاده از کلید پیشوند اختیاری است، اما آن را توصیه می‌کنیم.

برخی میان‌برهای جابه‌جایی عمداً بدون پیشوند تعریف شده‌اند. در نشست‌های زیرعامل، پیش‌فرض‌ها عبارت‌اند از `session_child_first` برابر `<leader>down`، `session_child_cycle` برابر `right`، `session_child_cycle_reverse` برابر `left` و `session_parent` برابر `up`.

گزینهٔ `leader_timeout` تعیین می‌کند OpenCode پس از فشردن پیشوند چقدر منتظر کلید بعدی بماند. پیش‌فرض آن `2000` میلی‌ثانیه است.

## مقادیر میان‌بر

می‌توانید یک میان‌بر یا چند میان‌بر جداشده با ویرگول لاتین را در یک رشته بنویسید. برای چند میان‌بر، آرایه نیز پذیرفته می‌شود.

برای تنظیمات پیشرفته، یک شیء با ویژگی‌های `key`، `event`، `preventDefault` یا `fallthrough` بنویسید.

```json title="tui.json"
{
  "$schema": "https://opencode.ai/tui.json",
  "keybinds": {
    "messages_copy": ["<leader>y", "ctrl+shift+c"],
    "input_paste": {
      "key": "ctrl+v",
      "preventDefault": false
    }
  }
}
```

## غیرفعال کردن میان‌بر

در `tui.json` برای کلید موردنظر مقدار `"none"` یا `false` تعیین کنید تا میان‌بر غیرفعال شود.

```json title="tui.json"
{
  "$schema": "https://opencode.ai/tui.json",
  "keybinds": {
    "session_compact": "none"
  }
}
```

## میان‌برهای کادر ورودی برنامهٔ دسکتاپ

کادر ورودی OpenCode در دسکتاپ از میان‌برهای رایج ویرایش متن به سبک Readline و Emacs پشتیبانی می‌کند. این میان‌برها داخلی‌اند و فعلاً از طریق `opencode.json` قابل تغییر نیستند.

| میان‌بر | عملیات |
| -------- | ---------------------------------------- |
| `ctrl+a` | رفتن به ابتدای خط جاری |
| `ctrl+e` | رفتن به انتهای خط جاری |
| `ctrl+b` | حرکت مکان‌نما به‌اندازهٔ یک نویسه به عقب |
| `ctrl+f` | حرکت مکان‌نما به‌اندازهٔ یک نویسه به جلو |
| `alt+b` | حرکت مکان‌نما به‌اندازهٔ یک کلمه به عقب |
| `alt+f` | حرکت مکان‌نما به‌اندازهٔ یک کلمه به جلو |
| `ctrl+d` | حذف نویسهٔ زیر مکان‌نما |
| `ctrl+k` | حذف از مکان‌نما تا انتهای خط |
| `ctrl+u` | حذف از مکان‌نما تا ابتدای خط |
| `ctrl+w` | حذف کلمهٔ قبلی |
| `alt+d` | حذف کلمهٔ بعدی |
| `ctrl+t` | جابه‌جا کردن دو نویسه |
| `ctrl+g` | بستن پنجره‌های بازشونده یا توقف پاسخ در حال تولید |

## Shift+Enter

در برخی ترمینال‌ها، فشردن Enter همراه کلیدهای کمکی به‌طور پیش‌فرض از Enter معمولی قابل تشخیص نیست. ممکن است لازم باشد ترمینال را برای ارسال `Shift+Enter` به شکل یک دنبالهٔ گریز تنظیم کنید.

### Windows Terminal

فایل `settings.json` را در مسیر زیر باز کنید.

```
%LOCALAPPDATA%\Packages\Microsoft.WindowsTerminal_8wekyb3d8bbwe\LocalState\settings.json
```

این مورد را به آرایهٔ `actions` در سطح بالای فایل اضافه کنید.

```json
"actions": [
  {
    "command": {
      "action": "sendInput",
      "input": "\u001b[13;2u"
    },
    "id": "User.sendInput.ShiftEnterCustom"
  }
]
```

این مورد را به آرایهٔ `keybindings` در سطح بالای فایل اضافه کنید.

```json
"keybindings": [
  {
    "keys": "shift+enter",
    "id": "User.sendInput.ShiftEnterCustom"
  }
]
```

فایل را ذخیره کنید و Windows Terminal را دوباره راه بیندازید یا یک زبانهٔ تازه باز کنید.
