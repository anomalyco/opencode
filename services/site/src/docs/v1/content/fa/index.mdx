:::note
OpenCode 1 و OpenCode 2 هر دو از فرمان `opencode` استفاده می‌کنند و با نام فرمان پیش‌فرض نمی‌توانید آن‌ها را در کنار هم نصب کنید.
برای مهاجرت، [مستندات OpenCode 2](https://opencode.ai/docs/) را ببینید.
:::

[**OpenCode**](/) یک عامل برنامه‌نویسی متن‌باز مبتنی بر هوش مصنوعی است. می‌توانید آن را در ترمینال، به‌صورت برنامهٔ دسکتاپ یا به‌عنوان افزونهٔ محیط توسعه به کار ببرید.

![رابط ترمینالی OpenCode با پوستهٔ opencode](../../../assets/lander/screenshot.png)

بیایید شروع کنیم.

---

#### پیش‌نیازها

برای اجرای OpenCode در ترمینال به این موارد نیاز دارید.

1. یک شبیه‌ساز ترمینال امروزی، مانند یکی از گزینه‌های زیر.
   - [WezTerm](https://wezterm.org)، چندسکویی
   - [Alacritty](https://alacritty.org)، چندسکویی
   - [Ghostty](https://ghostty.org)، لینوکس و macOS
   - [Kitty](https://sw.kovidgoyal.net/kitty/)، لینوکس و macOS

2. کلید API هر یک از ارائه‌دهندگان مدل زبانی بزرگ (LLM) که می‌خواهید از آن استفاده کنید.

---

## نصب

ساده‌ترین راه نصب OpenCode 1 استفاده از اسکریپت نصب است. این روش‌ها فایل اجرایی `opencode` را نصب می‌کنند و ممکن است با نصب OpenCode 2 تداخل داشته باشند یا جایگزین آن شوند.

```bash
curl -fsSL https://opencode.ai/install | bash
```

روش‌های زیر هم در دسترس‌اند.

- **نصب با Node.js**

  <Tabs>
    <TabItem label="npm">

    ```bash
    npm install -g opencode-ai
    ```

    </TabItem>
    <TabItem label="Bun">

    ```bash
    bun install -g opencode-ai
    ```

    </TabItem>
    <TabItem label="pnpm">

    ```bash
    pnpm install -g opencode-ai
    ```

    </TabItem>
    <TabItem label="Yarn">

    ```bash
    yarn global add opencode-ai
    ```

    </TabItem>
  </Tabs>

- **نصب با Homebrew در macOS و لینوکس**

  ```bash
  brew install anomalyco/tap/opencode
  ```

  > برای V1 از مخزن Homebrew بالا استفاده کنید. فرمان `brew install opencode` در حال حاضر V2 را نصب می‌کند. [مستندات V2](https://opencode.ai/docs/) را ببینید.

- **نصب در آرچ لینوکس**

  ```bash
  sudo pacman -S opencode           # Arch Linux (OpenCode 2)
  paru -S opencode-bin              # Arch Linux (OpenCode 1, from AUR)
  ```

  بستهٔ رسمی آرچ، OpenCode 2 را نصب می‌کند. برای OpenCode 1 از بستهٔ AUR استفاده کنید.

#### ویندوز

:::tip[در ویندوز از WSL استفاده کنید]
برای استفاده در ویندوز، [زیرسیستم ویندوز برای لینوکس (WSL)](/docs/windows-wsl) را پیشنهاد می‌کنیم. WSL عملکرد بهتری دارد و با همهٔ قابلیت‌های OpenCode سازگار است.
:::

- **نصب با Chocolatey**

  ```bash
  choco install opencode
  ```

- **نصب با Scoop**

  ```bash
  scoop install opencode
  ```

- **نصب با npm**

  ```bash
  npm install -g opencode-ai
  ```

- **نصب با Mise**

  ```bash
  mise use -g github:anomalyco/opencode
  ```

- **اجرا با Docker**

  ```bash
  docker run -it --rm ghcr.io/anomalyco/opencode
  ```

پشتیبانی از نصب با Bun در ویندوز هنوز در دست توسعه است.

می‌توانید فایل اجرایی را از صفحهٔ [انتشارها](https://github.com/anomalyco/opencode/releases) هم دریافت کنید.

## پیکربندی

برای استفاده از هر ارائه‌دهندهٔ مدل زبانی در OpenCode، کلید API آن را تنظیم کنید.

اگر تازه با ارائه‌دهندگان مدل زبانی آشنا شده‌اید، [OpenCode Models](https://opencode.ai/docs/console/) نقطهٔ شروع خوبی است. تیم OpenCode مدل‌های این فهرست را آزمایش و تأیید کرده است.

1. فرمان `/connect` را در رابط ترمینالی اجرا کنید، `opencode` را انتخاب کنید و به [opencode.ai/auth](https://opencode.ai/auth) بروید.

   ```txt
   /connect
   ```

2. وارد حساب شوید، اطلاعات پرداخت را وارد کنید و کلید API را کپی کنید.

3. کلید API را در رابط ترمینالی جای‌گذاری کنید.

   ```txt
   ┌ API key
   │
   │
   └ enter
   ```

اگر ترجیح می‌دهید از ارائه‌دهندهٔ دیگری استفاده کنید، [فهرست ارائه‌دهندگان](/docs/providers#directory) را ببینید.

## راه‌اندازی پروژه

بعد از پیکربندی ارائه‌دهنده، به پوشهٔ پروژه بروید.

```bash
cd /path/to/project
```

OpenCode را اجرا کنید.

```bash
opencode
```

در رابط ترمینالی، فرمان زیر را برای راه‌اندازی OpenCode در پروژه اجرا کنید.

```bash frame="none"
/init
```

OpenCode پروژه را بررسی می‌کند و فایل `AGENTS.md` را در ریشهٔ پروژه می‌سازد. این فایل به OpenCode کمک می‌کند ساختار پروژه و شیوهٔ کدنویسی آن را بشناسد.

:::tip
فایل `AGENTS.md` پروژه را در Git ثبت کنید.
:::

## استفاده

حالا می‌توانید روی پروژه کار کنید و هر سؤالی دارید از OpenCode بپرسید. اگر برای اولین بار با یک عامل برنامه‌نویسی کار می‌کنید، نمونه‌های زیر را امتحان کنید.

---

### پرسیدن دربارهٔ کد

می‌توانید از OpenCode بخواهید بخشی از کد را توضیح دهد.

:::tip
با کلید `@` می‌توانید نام فایل‌های پروژه را به‌صورت تقریبی جست‌وجو کنید.
:::

```txt frame="none" "@packages/functions/src/api/index.ts"
احراز هویت در @packages/functions/src/api/index.ts چطور انجام می‌شود؟
```

این روش برای شناخت بخش‌هایی از کد که خودتان روی آن‌ها کار نکرده‌اید مفید است.

---

### افزودن قابلیت

برای افزودن قابلیت تازه، بهتر است از OpenCode بخواهید اول برنامهٔ انجام کار را پیشنهاد کند.

1. **برنامهٔ انجام کار را تهیه کنید**

   در حالت برنامه‌ریزی (Plan)، OpenCode شیوهٔ پیاده‌سازی را پیشنهاد می‌کند و فایل‌های پروژه را تغییر نمی‌دهد. با کلید **Tab** به این حالت بروید. نشانگر حالت را در گوشهٔ پایینِ سمت راست می‌بینید.

   ```bash frame="none" title="رفتن به حالت برنامه‌ریزی"
   <TAB>
   ```

   سپس توضیح دهید چه رفتاری می‌خواهید.

   ```txt frame="none"
   وقتی کاربر یادداشتی را حذف می‌کند، آن را در پایگاه داده به‌عنوان حذف‌شده علامت بزن.
   سپس صفحه‌ای بساز که یادداشت‌های اخیراً حذف‌شده را نشان دهد. کاربر باید بتواند
   از همان صفحه یادداشت را بازیابی کند یا برای همیشه پاک کند.
   ```

   درخواستتان را با همان جزئیاتی توضیح دهید که به یک برنامه‌نویس تازه‌کار در تیم می‌گویید.

   :::tip
   مثال بزنید و زمینهٔ کافی بدهید تا OpenCode دقیقاً بداند چه می‌خواهید.
   :::

2. **برنامه را بازبینی کنید**

   اگر بخشی از برنامه نیاز به تغییر دارد، توضیح دهید چه چیز باید عوض شود. در صورت نیاز تصویر نمونه هم اضافه کنید.

   ```txt frame="none"
   می‌خواهم صفحهٔ جدید شبیه طرحی باشد که قبلاً استفاده کرده‌ام.
   [Image #1] طرح را بررسی کن و آن را مبنای چیدمان صفحه قرار بده.
   ```

   :::tip
   برای افزودن تصویر، آن را بکشید و در ترمینال رها کنید. OpenCode می‌تواند تصویر پیوست را بررسی کند.
   :::

3. **قابلیت را پیاده‌سازی کنید**

   وقتی از برنامه راضی بودید، با **Tab** به حالت پیاده‌سازی (Build) بروید.

   ```bash frame="none"
   <TAB>
   ```

   سپس از OpenCode بخواهید تغییرات را انجام دهد.

   ```txt frame="none"
   برنامه خوب است. تغییرات را انجام بده.
   ```

---

### تغییر مستقیم کد

برای تغییر ساده‌تر، می‌توانید مستقیم درخواست پیاده‌سازی بدهید.

```txt frame="none" "@packages/functions/src/settings.ts" "@packages/functions/src/notes.ts"
به مسیر /settings احراز هویت اضافه کن. شیوهٔ پیاده‌سازی مسیر /notes را
در @packages/functions/src/notes.ts بررسی کن و همان منطق را برای
@packages/functions/src/settings.ts به کار ببر.
```

جزئیات و نمونهٔ مرتبط کمک می‌کند OpenCode تغییر موردنظر را پیدا کند.

---

### برگرداندن تغییرات

فرض کنید از OpenCode خواسته‌اید تابعی را بازآرایی کند.

```txt frame="none" "@packages/functions/src/api/index.ts"
تابع موجود در @packages/functions/src/api/index.ts را بازآرایی کن.
```

اگر از نتیجه راضی نبودید، تغییرات را با `/undo` برگردانید.

```bash frame="none"
/undo
```

OpenCode تغییرات را برمی‌گرداند و پیام اولیهٔ شما را دوباره نشان می‌دهد.

```txt frame="none" "@packages/functions/src/api/index.ts"
تابع موجود در @packages/functions/src/api/index.ts را بازآرایی کن.
```

حالا می‌توانید درخواستتان را دقیق‌تر کنید و دوباره از OpenCode بخواهید تغییر را انجام دهد.

:::tip
برای برگشتن به تغییرات قبلی می‌توانید چند بار `/undo` را اجرا کنید.
:::

برای اعمال دوبارهٔ تغییر برگردانده‌شده، `/redo` را اجرا کنید.

```bash frame="none"
/redo
```
