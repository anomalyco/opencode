---
title: فرمان‌ها
description: ساخت فرمان‌های سفارشی برای کارهای تکراری.
---

برای هر فرمان سفارشی می‌توانید درخواستی بنویسید که هنگام اجرای آن فرمان در رابط ترمینالی به مدل فرستاده شود.

```bash frame="none"
/my-command
```

این فرمان‌ها در کنار فرمان‌های داخلی مانند `/init`، `/undo`، `/redo` و `/help` در دسترس‌اند. [دربارهٔ فرمان‌های داخلی بیشتر بخوانید](/docs/tui#commands).

---

## ساخت فایل فرمان

برای تعریف فرمان سفارشی، در پوشهٔ `commands/` یک فایل Markdown بسازید.

فایل `.opencode/commands/test.md` را بسازید.

```md title=".opencode/commands/test.md"
---
description: اجرای آزمون‌ها با گزارش پوشش
agent: build
model: anthropic/claude-sonnet-5-5
---

همهٔ آزمون‌ها را اجرا کن، گزارش پوشش را تهیه کن و آزمون‌های ناموفق را نشان بده.
علت شکست آزمون‌ها را بررسی کن و راه اصلاحشان را پیشنهاد بده.
```

ویژگی‌های فرمان در فرادادهٔ آغاز فایل و الگوی درخواست در متن آن قرار می‌گیرد.

برای اجرای فرمان، `/` و سپس نام آن را بنویسید.

```bash frame="none"
"/test"
```

---

## پیکربندی

فرمان سفارشی را می‌توانید در پیکربندی OpenCode یا در یک فایل Markdown در پوشهٔ `commands/` تعریف کنید.

---

### JSON

در [پیکربندی](/docs/config) OpenCode از گزینهٔ `command` استفاده کنید.

```json title="opencode.jsonc" {4-12}
{
  "$schema": "https://opencode.ai/config.json",
  "command": {
    // نام فرمان از این کلید گرفته می‌شود
    "test": {
      // این درخواست برای مدل زبانی فرستاده می‌شود
      "template": "همهٔ آزمون‌ها را اجرا کن، گزارش پوشش را تهیه کن و آزمون‌های ناموفق را نشان بده.\nعلت شکست آزمون‌ها را بررسی کن و راه اصلاحشان را پیشنهاد بده.",
      // این متن در رابط ترمینالی به‌عنوان توضیح فرمان نمایش داده می‌شود
      "description": "اجرای آزمون‌ها با گزارش پوشش",
      "agent": "build",
      "model": "anthropic/claude-sonnet-5-5"
    }
  }
}
```

اکنون می‌توانید فرمان را در رابط ترمینالی اجرا کنید.

```bash frame="none"
/test
```

---

### Markdown

برای تعریف فرمان در فایل Markdown، آن را در یکی از مسیرهای زیر قرار دهید.

- سراسری: `~/.config/opencode/commands/`
- ویژهٔ پروژه: `.opencode/commands/`

```markdown title="~/.config/opencode/commands/test.md"
---
description: اجرای آزمون‌ها با گزارش پوشش
agent: build
model: anthropic/claude-sonnet-5-5
---

همهٔ آزمون‌ها را اجرا کن، گزارش پوشش را تهیه کن و آزمون‌های ناموفق را نشان بده.
علت شکست آزمون‌ها را بررسی کن و راه اصلاحشان را پیشنهاد بده.
```

نام فایل Markdown نام فرمان را تعیین می‌کند. برای مثال، با فایل `test.md` می‌توانید فرمان زیر را اجرا کنید.

```bash frame="none"
/test
```

## تنظیم متن درخواست

متن درخواستِ فرمان‌های سفارشی از چند جای‌نگهدار و نشانهٔ ویژه پشتیبانی می‌کند.

---

### آرگومان‌ها

با جای‌نگهدار `$ARGUMENTS` آرگومان‌ها را به فرمان بدهید.

```md title=".opencode/commands/component.md"
---
description: ساخت مؤلفهٔ جدید
---

مؤلفه‌ای جدید برای React با نام $ARGUMENTS و پشتیبانی از TypeScript بساز.
نوع‌ها و ساختار اولیهٔ آن را تعریف کن.
```

فرمان را با آرگومان اجرا کنید.

```bash frame="none"
/component Button
```

در این مثال، `$ARGUMENTS` با `Button` جایگزین می‌شود.

با پارامترهای موقعیتی می‌توانید به هر آرگومان جداگانه دسترسی داشته باشید.

- `$1` آرگومان اول
- `$2` آرگومان دوم
- `$3` آرگومان سوم
- و به همین ترتیب برای آرگومان‌های بعدی.

برای مثال:

```md title=".opencode/commands/create-file.md"
---
description: ساخت فایل جدید با محتوای دلخواه
---

در پوشهٔ $2 فایلی به نام $1 بساز
و محتوای آن را برابر $3 قرار بده.
```

فرمان را اجرا کنید.

```bash frame="none"
/create-file config.json src "{ \"key\": \"value\" }"
```

در این نمونه، جایگزینی‌ها به این صورت‌اند.

- به‌جای `$1` مقدار `config.json` قرار می‌گیرد.
- به‌جای `$2` مقدار `src` قرار می‌گیرد.
- به‌جای `$3` مقدار `{ "key": "value" }` قرار می‌گیرد.

---

### خروجی پوسته

با _!`command`_ خروجی یک [فرمان پوسته](/docs/tui#shell-commands) را در متن درخواست قرار دهید.

برای نمونه، برای ساخت فرمانی که پوشش آزمون‌ها را تحلیل کند، چنین بنویسید.

```md title=".opencode/commands/analyze-coverage.md"
---
description: تحلیل پوشش آزمون‌ها
---

نتایج فعلی آزمون‌ها:
!`npm test`

با توجه به این نتایج، برای افزایش پوشش آزمون‌ها پیشنهاد بده.
```

برای مرور تغییرات اخیر هم می‌توانید بنویسید:

```md title=".opencode/commands/review-changes.md"
---
description: بازبینی تغییرات اخیر
---

کامیت‌های اخیر Git:
!`git log --oneline -10`

این تغییرات را بررسی کن و اگر راهی برای بهبودشان هست پیشنهاد بده.
```

فرمان‌ها در ریشهٔ پروژه اجرا می‌شوند و خروجی آن‌ها بخشی از متن درخواست خواهد بود.

---

### ارجاع به فایل

برای افزودن یک فایل به فرمان، `@` و سپس نام فایل را بنویسید.

```md title=".opencode/commands/review-component.md"
---
description: بازبینی مؤلفه
---

مؤلفهٔ موجود در @src/components/Button.tsx را بازبینی کن.
مشکلات عملکرد آن را پیدا کن و برای بهبود پیشنهاد بده.
```

محتوای فایل به‌طور خودکار به درخواست افزوده می‌شود.

## گزینه‌ها

گزینه‌های زیر رفتار فرمان را تعیین می‌کنند.

---

### الگو

گزینهٔ `template` متن درخواستی را تعیین می‌کند که هنگام اجرای فرمان به مدل زبانی ارسال می‌شود.

```json title="opencode.json"
{
  "command": {
    "test": {
      "template": "همهٔ آزمون‌ها را اجرا کن، گزارش پوشش را تهیه کن و آزمون‌های ناموفق را نشان بده.\nعلت شکست آزمون‌ها را بررسی کن و راه اصلاحشان را پیشنهاد بده."
    }
  }
}
```

تعیین این گزینه **الزامی** است.

---

### توضیحات

در `description` به‌اختصار بنویسید فرمان چه کاری انجام می‌دهد.

```json title="opencode.json"
{
  "command": {
    "test": {
      "description": "اجرای آزمون‌ها با گزارش پوشش"
    }
  }
}
```

هنگام تایپ فرمان در رابط ترمینالی، این متن به‌عنوان توضیح آن نمایش داده می‌شود.

---

### عامل

با گزینهٔ اختیاری `agent` تعیین کنید کدام [عامل](/docs/agents) فرمان را اجرا کند. اگر یک [زیرعامل](/docs/agents/#subagents) انتخاب کنید، فرمان به‌طور پیش‌فرض آن را فراخوانی می‌کند. برای غیرفعال کردن این رفتار، `subtask` را روی `false` بگذارید.

```json title="opencode.json"
{
  "command": {
    "review": {
      "agent": "plan"
    }
  }
}
```

تعیین این گزینه **اختیاری** است. پیش‌فرض آن عامل فعلی شماست.

---

### زیرکار

با گزینهٔ بولی `subtask` می‌توانید اجرای فرمان را به یک [زیرعامل](/docs/agents/#subagents) بسپارید تا محتوای کار وارد زمینهٔ اصلی نشود. حتی اگر در پیکربندی [عامل](/docs/agents)، مقدار `mode` برابر `primary` باشد، این گزینه آن را **ملزم** به اجرا در نقش زیرعامل می‌کند.

```json title="opencode.json"
{
  "command": {
    "analyze": {
      "subtask": true
    }
  }
}
```

تعیین این گزینه **اختیاری** است.

---

### مدل

با گزینهٔ `model` مدلی متفاوت با مدل پیش‌فرض برای این فرمان تعیین کنید.

```json title="opencode.json"
{
  "command": {
    "analyze": {
      "model": "anthropic/claude-sonnet-5-5"
    }
  }
}
```

تعیین این گزینه **اختیاری** است.

---

## فرمان‌های داخلی

OpenCode فرمان‌های داخلی متعددی از جمله `/init`، `/undo`، `/redo` و `/help` دارد. [راهنمای فرمان‌های داخلی](/docs/tui#commands) را ببینید.

:::note
فرمان سفارشی می‌تواند جای فرمان داخلی را بگیرد.
:::

اگر فرمانی سفارشی با نام یک فرمان داخلی تعریف کنید، فرمان سفارشی اجرا می‌شود.
