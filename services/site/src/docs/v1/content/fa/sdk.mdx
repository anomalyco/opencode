SDK جاوااسکریپت و تایپ‌اسکریپت OpenCode، یک کلاینت با بررسی نوع برای ارتباط با سرور فراهم می‌کند. با آن می‌توانید ابزارهای دیگر را به OpenCode متصل و آن را از برنامهٔ خود کنترل کنید.

[راهنمای سرور](/docs/server) و نمونهٔ [پروژه‌های ساخته‌شده توسط کاربران](/docs/ecosystem#projects) را ببینید.

---

## نصب

SDK را از npm نصب کنید.

```bash
npm install @opencode-ai/sdk
```

---

## ساخت کلاینت

یک نمونهٔ OpenCode بسازید.

```javascript
import { createOpencode } from "@opencode-ai/sdk"

const { client } = await createOpencode()
```

این کد هم سرور و هم کلاینت را راه‌اندازی می‌کند.

#### گزینه‌ها

| گزینه | نوع | توضیحات | پیش‌فرض |
| ---------- | ------------- | ------------------------------ | ----------- |
| `hostname` | `string` | نام میزبان سرور | `127.0.0.1` |
| `port` | `number` | پورت سرور | `4096` |
| `signal` | `AbortSignal` | سیگنال لغو عملیات | `undefined` |
| `timeout` | `number` | مهلت راه‌اندازی سرور به میلی‌ثانیه | `5000` |
| `config` | `Config` | شیء پیکربندی | `{}` |

---

## پیکربندی

برای تغییر رفتار، یک شیء پیکربندی بدهید. OpenCode همچنان `opencode.json` را می‌خواند، اما می‌توانید مستقیماً در کد گزینه‌ای اضافه کنید یا مقدار قبلی آن را تغییر دهید.

```javascript
import { createOpencode } from "@opencode-ai/sdk"

const opencode = await createOpencode({
  hostname: "127.0.0.1",
  port: 4096,
  config: {
    model: "anthropic/claude-sonnet-5-5",
  },
})

console.log(`Server running at ${opencode.server.url}`)

opencode.server.close()
```

## فقط کلاینت

اگر از قبل یک نمونهٔ OpenCode در حال اجراست، برای اتصال به آن فقط کلاینت را بسازید.

```javascript
import { createOpencodeClient } from "@opencode-ai/sdk"

const client = createOpencodeClient({
  baseUrl: "http://localhost:4096",
})
```

#### گزینه‌ها

| گزینه | نوع | توضیحات | پیش‌فرض |
| --------------- | ---------- | -------------------------------- | -------------------- |
| `baseUrl` | `string` | نشانی سرور | مقدار پیش‌فرض ندارد. صریحاً تعیین کنید. |
| `fetch` | `function` | پیاده‌سازی سفارشی fetch | `globalThis.fetch` |
| `parseAs` | `string` | روش تجزیهٔ پاسخ | `auto` |
| `responseStyle` | `string` | قالب خروجی: `data` یا `fields` | `fields` |
| `throwOnError` | `boolean` | پرتاب خطا به‌جای برگرداندن آن | `false` |

## نوع‌ها

SDK برای همهٔ نوع‌های API تعریف TypeScript دارد. می‌توانید آن‌ها را مستقیماً وارد کنید.

```typescript
import type { Session, Message, Part } from "@opencode-ai/sdk"
```

همهٔ نوع‌ها از مشخصات OpenAPI سرور تولید می‌شوند و در <a href={typesUrl}>فایل تعریف نوع‌ها</a> در دسترس‌اند.

## خطاها

به‌طور پیش‌فرض خطاهای HTTP در `result.error` برگردانده می‌شوند. برای پرتاب آن‌ها، `throwOnError: true` را تعیین کنید. خطاهای شبکه مستقل از این گزینه ممکن است پرتاب شوند.

```typescript
try {
  await client.session.get({ path: { id: "invalid-id" }, throwOnError: true })
} catch (error) {
  console.error("Failed to get session:", error)
}
```

## خروجی ساخت‌یافته

برای دریافت JSON ساخت‌یافته از مدل، یک `format` همراه با طرح‌وارهٔ JSON تعیین کنید. مدل با ابزار `StructuredOutput`، دادهٔ JSON اعتبارسنجی‌شده و منطبق با طرح‌وارهٔ شما را برمی‌گرداند.

خروجی ساخت‌یافته فقط در کلاینت صادرشده از `@opencode-ai/sdk/v2` در دسترس است. این کلاینت پارامترها را مستقیم و بدون اشیای `path` و `body` می‌گیرد.

### استفادهٔ پایه

```typescript
import { createOpencodeClient } from "@opencode-ai/sdk/v2"

const client = createOpencodeClient({ baseUrl: "http://localhost:4096" })

const result = await client.session.prompt(
  {
    sessionID: sessionId,
    parts: [{ type: "text", text: "دربارهٔ شرکت Anthropic تحقیق کن و اطلاعات آن را برگردان." }],
    format: {
      type: "json_schema",
      schema: {
        type: "object",
        properties: {
          company: { type: "string", description: "نام شرکت" },
          founded: { type: "number", description: "سال تأسیس" },
          products: {
            type: "array",
            items: { type: "string" },
            description: "محصولات اصلی",
          },
        },
        required: ["company", "founded"],
      },
    },
  },
  { throwOnError: true },
)

// Access the structured output
console.log(result.data.info.structured)
// { company: "Anthropic", founded: 2021, products: ["Claude", "Claude API"] }
```

### انواع قالب خروجی

| نوع | توضیحات |
| ------------- | ------------------------------------------------------ |
| `text` | پیش‌فرض. پاسخ متنی معمولی بدون ساختار مشخص |
| `json_schema` | JSON اعتبارسنجی‌شده و منطبق با طرح‌وارهٔ ورودی را برمی‌گرداند. |

### قالب طرح‌وارهٔ JSON

هنگام استفاده از `type: 'json_schema'`، فیلدهای زیر را تعیین کنید.

| فیلد | نوع | توضیحات |
| ------------ | --------------- | ---------------------------------------------------------- |
| `type` | `'json_schema'` | الزامی. حالت طرح‌وارهٔ JSON را مشخص می‌کند. |
| `schema` | `object` | الزامی. شیء JSON Schema که ساختار خروجی را تعریف می‌کند. |
| `retryCount` | `number` | اختیاری. تعداد تلاش‌های مجدد برای اعتبارسنجی (پیش‌فرض ۲). |

### مدیریت خطا

اگر مدل پس از همهٔ تلاش‌ها نتواند خروجی معتبر تولید کند، پاسخ حاوی `StructuredOutputError` خواهد بود.

```typescript
if (result.data.info.error?.name === "StructuredOutputError") {
  console.error("Failed to produce structured output:", result.data.info.error.data.message)
  console.error("Attempts:", result.data.info.error.data.retries)
}
```

### توصیه‌های کاربردی

1. **ویژگی‌های طرح‌واره را روشن توضیح دهید** تا مدل بداند چه داده‌ای استخراج کند.
2. **با `required`** فیلدهای الزامی را مشخص کنید.
3. **طرح‌واره را متمرکز نگه دارید.** ساختار پیچیده و تودرتو ممکن است پر کردن درست فیلدها را برای مدل دشوار کند.
4. **`retryCount` را متناسب انتخاب کنید.** برای طرح‌وارهٔ پیچیده آن را افزایش و برای طرح‌وارهٔ ساده کاهش دهید.

### نشست‌ها

| متد | توضیحات | نکات |
| ---------------------------------------------------------- | ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `session.list()` | فهرست نشست‌ها | خروجی: <a href={typesUrl}><code>Session[]</code></a> |
| `session.get({ path })` | دریافت نشست | خروجی: <a href={typesUrl}><code>Session</code></a> |
| `session.children({ path })` | فهرست نشست‌های فرزند | خروجی: <a href={typesUrl}><code>Session[]</code></a> |
| `session.create({ body })` | ساخت نشست | خروجی: <a href={typesUrl}><code>Session</code></a> |
| `session.delete({ path })` | حذف نشست | خروجی: `boolean` |
| `session.update({ path, body })` | به‌روزرسانی ویژگی‌های نشست | خروجی: <a href={typesUrl}><code>Session</code></a> |
| `session.init({ path, body })` | تحلیل برنامه و ساخت `AGENTS.md` | خروجی: `boolean` |
| `session.abort({ path })` | توقف نشست در حال اجرا | خروجی: `boolean` |
| `session.share({ path })` | اشتراک‌گذاری نشست | اشتراک‌گذاری متوقف شده است و این مسیر خطا برمی‌گرداند. |
| `session.unshare({ path })` | پاک کردن پیوند اشتراک‌گذاری ذخیره‌شده | خروجی: <a href={typesUrl}><code>Session</code></a> |
| `session.summarize({ path, body })` | خلاصه‌سازی نشست | خروجی: `boolean` |
| `session.messages({ path })` | فهرست پیام‌های یک نشست | خروجی: `{ info: `<a href={typesUrl}><code>Message</code></a>`, parts: `<a href={typesUrl}><code>Part[]</code></a>`}[]` |
| `session.message({ path })` | دریافت جزئیات پیام | خروجی: `{ info: `<a href={typesUrl}><code>Message</code></a>`, parts: `<a href={typesUrl}><code>Part[]</code></a>`}` |
| `session.prompt({ path, body })` | ارسال پیام درخواست | خروجی `{ info, parts }` است. با `body.noReply: true` اطلاعاتی به زمینه افزوده می‌شود، بدون اینکه مدل پاسخی تولید کند. برای خروجی ساخت‌یافته از [کلاینت `/v2`](#structured-output) استفاده کنید. |
| `session.command({ path, body })` | ارسال فرمان به نشست | خروجی: `{ info: `<a href={typesUrl}><code>AssistantMessage</code></a>`, parts: `<a href={typesUrl}><code>Part[]</code></a>`}` |
| `session.shell({ path, body })` | اجرای فرمان پوسته | خروجی: <a href={typesUrl}><code>AssistantMessage</code></a> |
| `session.revert({ path, body })` | برگرداندن یک پیام | خروجی: <a href={typesUrl}><code>Session</code></a> |
| `session.unrevert({ path })` | بازیابی پیام‌های برگردانده‌شده | خروجی: <a href={typesUrl}><code>Session</code></a> |
| `postSessionByIdPermissionsByPermissionId({ path, body })` | پاسخ به درخواست مجوز | خروجی: `boolean` |

---

#### مثال‌ها

```javascript
// Create and manage sessions
const session = await client.session.create({
  body: { title: "نشست من" },
  throwOnError: true,
})

const sessions = await client.session.list()

// Send a prompt message
const result = await client.session.prompt({
  path: { id: session.data.id },
  body: {
    model: { providerID: "anthropic", modelID: "claude-sonnet-5-5" },
    parts: [{ type: "text", text: "سلام!" }],
  },
})

// Inject context without triggering AI response (useful for plugins)
await client.session.prompt({
  path: { id: session.data.id },
  body: {
    noReply: true,
    parts: [{ type: "text", text: "تو دستیار کاربر هستی. به او در انجام کارش کمک کن." }],
  },
})
```

### فایل‌ها

| متد | توضیحات | پاسخ |
| ------------------------- | ---------------------------------- | ------------------------------------------------------------------------------------------- |
| `find.text({ query })` | جست‌وجوی متن در فایل‌ها | آرایهٔ نتیجه‌های منطبق، شامل `path`، `lines`، `line_number`، `absolute_offset` و `submatches` |
| `find.files({ query })` | یافتن فایل‌ها و پوشه‌ها براساس نام | `string[]` (مسیرها) |
| `find.symbols({ query })` | یافتن نمادهای فضای کاری | <a href={typesUrl}><code>Symbol[]</code></a> |
| `file.read({ query })` | خواندن فایل | <a href={typesUrl}><code>FileContent</code></a> |
| `file.status({ query? })` | دریافت وضعیت فایل‌های تحت پیگیری | <a href={typesUrl}><code>File[]</code></a> |

متد `find.files` در کلاینت اصلی این فیلدهای اختیاری پرس‌وجو را می‌پذیرد.

- `dirs`: مقدار `"false"` جست‌وجو را به فایل‌ها محدود می‌کند. در غیر این صورت، پوشه‌ها نیز در نتایج می‌آیند.
- `directory`: تعیین ریشه‌ای دیگر برای جست‌وجوی پروژه

کلاینت `/v2` همچنین پارامترهای مستقیم `type` (با مقدار `"file"` یا `"directory"`) و `limit` (از ۱ تا ۲۰۰) را می‌پذیرد.

---

#### مثال‌ها

```javascript
// Search and read files
const textResults = await client.find.text({
  query: { pattern: "function.*opencode" },
})

const files = await client.find.files({
  query: { query: ".ts", dirs: "false" },
})

const paths = await client.find.files({
  query: { query: "packages", dirs: "true" },
})

const content = await client.file.read({
  query: { path: "src/index.ts" },
})
```
