# Company logos

One-colour copies of each company's official logo for the home page logo row. Every file is drawn
in black with knockouts as transparent holes, and its `viewBox` is cropped to the ink, so it works
as a CSS mask. After you add or change a file, run `bun script/measure-logos.ts` from
`packages/console/app` to update `src/component/site/logo-metrics.ts`.
