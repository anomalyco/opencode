The [OpenCode Console](https://opencode.ai/console) is an optional service that provides additional benefits to
using OpenCode, on your own or as a team.

- [Workspaces](/console/workspaces) for sharing access with your [team](/console/members)
- [Inference](/console/models) for both proprietary and open source models
- [Providers](/console/providers) for connecting your own provider accounts through the Console gateway
- Usage tracking and [budget](/console/budgets) controls
- Deploy team wide policies to control OpenCode behavior
- [Web search](/console/websearch)
- [Harnesses](/console/harnesses) for using Console models from Claude Code, Codex, and other agents
- [OpenCode Go, Go Plus, and Go Teams](/console/go), $10, $40, and $20/member monthly subscriptions for open source model access

## Get started

You don't need a team to use the Console. Every account starts with a **Personal** workspace where you are the only
member.

1. Sign in to the [Console](https://opencode.ai/console).
2. Subscribe to [Go](/console/go), add [credits](/console/billing#add-credits), or connect a [provider](/console/providers).
3. Run `/connect` in OpenCode and choose the workspace.
4. Optionally, [invite](/console/members#invite-members) your team.

```text
/connect
```

## Policies

Providers and Tools rules from the Policies page apply to every OpenCode client
connected to the workspace. They are delivered as [policy](/policies#console)
statements that outrank the member's user and project configuration and take effect
within about a minute. Managed preferences and the system configuration file still
outrank the workspace; see [precedence](/policies#precedence).
