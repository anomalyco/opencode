Console works with coding agents other than OpenCode. Point a harness at the Console gateway with an API key, and usage
is billed to your workspace like any other request.

| Harness                                       | Pay-as-you-go | Go        | Models                    | MCP |
| --------------------------------------------- | ------------- | --------- | ------------------------- | --- |
| [Claude Code](/console/harnesses/claude-code) | Yes           | Yes       | Anthropic Messages models | Yes |
| [Codex](/console/harnesses/codex)             | Yes           | Yes       | OpenAI Responses models   | Yes |
| [Hermes](/console/harnesses/hermes)           | Built in      | Built in  | Paid and Go models        | Yes |
| [Pi](/console/harnesses/pi)                   | Built in      | Built in  | Paid and Go models        | Yes |
| [Raycast](/console/harnesses/raycast)         | Extension     | Extension | Paid and Go models        | Yes |

Free-tier chat models are only available from within OpenCode. Other harnesses receive HTTP `403` for those models,
even with a Console API key. Use paid models or a Go subscription.

## Get an API key

Harnesses authenticate with a Console API key. The quickest option is a
[personal API key](/console/api#personal-api-keys), which calls models as you.

1. Open **Account** from the account menu in the [Console](https://opencode.ai/console).
2. Under **Personal API keys**, click **Add API key**.
3. Choose the workspace, name the key, and click **Create**.
4. Copy the key. It is shown only once.

```text
oc_sk_1a2b3c4d5e6f_...
```

Usage counts toward your [member budget](/console/budgets#member-budgets). Use a key from a workspace with credits for
pay-as-you-go, or from a workspace subscribed to [Go](/console/go) for Go.

For shared machines or CI, owners and admins can create a [service account](/console/api#service-accounts) key instead,
so usage isn't tied to one person.

## Base URLs

Pay-as-you-go and Go are served from different base URLs. Use the one that matches your plan.

| Plan          | Base URL                           |
| ------------- | ---------------------------------- |
| Pay-as-you-go | `https://opencode.ai/inference`    |
| Go            | `https://opencode.ai/inference/go` |

Append the path for the API your harness speaks.

| API                     | Path                                            |
| ----------------------- | ----------------------------------------------- |
| OpenAI Responses        | `/openai/v1/responses`                          |
| OpenAI Chat Completions | `/openai/v1/chat/completions`                   |
| Anthropic Messages      | `/anthropic/v1/messages`                        |
| Gemini                  | `/google/v1beta/models/<model>:generateContent` |

```text
https://opencode.ai/inference/go/openai/v1/chat/completions
```

## Choose an API

A harness can only use the models that accept the API it speaks. Most models accept one API, and some accept several.
The endpoint column in the [Console](/console/models#endpoints) and [Go](/console/go#endpoints) tables lists one API per
model, so check the harness page for the full list.

Hermes, Pi, and the Raycast extension pick the right API for each paid or Go model. Claude Code and
Codex speak a single API and only reach part of the catalog.

| Harness     | API                | Models                                                           |
| ----------- | ------------------ | ---------------------------------------------------------------- |
| Claude Code | Anthropic Messages | Claude and Qwen, plus Kimi K3, DeepSeek V4, and MiniMax M3 on Go |
| Codex       | OpenAI Responses   | GPT, Grok, and Muse Spark, plus DeepSeek V4 on Go                |

<Callout>Support for every model in every harness is coming soon.</Callout>

## Sessions

Send a stable session ID with every request so Console can route a conversation consistently and reuse its prompt
cache. Go [requires it](/console/go#where-can-i-use-it).

```text
x-opencode-session: ses_...
```

Console also recognizes the native session headers sent by Claude Code, Codex, Hermes, and Pi, so they need no extra
configuration.

## Console MCP

Harnesses with MCP support can manage your workspace through the Console MCP server. It uses OAuth with dynamic client
registration, so you sign in from the browser instead of pasting a key.

```text
https://opencode.ai/console/mcp
```

Each harness page shows how to add it. OpenCode adds the server automatically as `opencode_console` when your workspace
enables it, and asks you to sign in from the browser the first time it uses it.
