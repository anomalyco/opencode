title: "Codex"
description: "Use Console and Go models from Codex."
---

Codex speaks the OpenAI Responses API, so it can use the models served through Responses, such as GPT, Grok, and Muse
Spark.

## Configure

Add Console as a model provider in `~/.codex/config.toml` and make it the default.

```toml title="~/.codex/config.toml"
model = "gpt-6.1-sol"
model_provider = "opencode"

[model_providers.opencode]
name = "OpenCode Console"
base_url = "https://opencode.ai/inference/openai/v1"
env_key = "OPENCODE_API_KEY"
wire_api = "responses"
```

Codex appends `/responses` to the base URL and reads the key from `env_key`. Create a
[personal API key](/console/harnesses#get-an-api-key), then export it.

```bash
export OPENCODE_API_KEY="oc_sk_..."
codex
```

<Callout>
  Codex only reads model providers from `~/.codex/config.toml`. A project's `.codex/config.toml` cannot set them.
</Callout>

## Go

Use the Go base URL and a key from a workspace with a [Go](/console/go) subscription.

```toml title="~/.codex/config.toml"
model = "gpt-6-luna"
model_provider = "opencode-go"

[model_providers.opencode-go]
name = "OpenCode Go"
base_url = "https://opencode.ai/inference/go/openai/v1"
env_key = "OPENCODE_API_KEY"
wire_api = "responses"
```

## Models

Set `model` to a model that accepts the Responses API. Override it for one run with `--model`.

| Plan          | Models                                 |
| ------------- | -------------------------------------- |
| Pay-as-you-go | GPT, Grok, and Muse Spark models       |
| Go            | GPT, Grok, Muse Spark, and DeepSeek V4 |

```bash
codex --model grok-4.7
```

Claude, Gemini, and most open models are not available in Codex yet. Use [Pi](/console/harnesses/pi) or
[Hermes](/console/harnesses/hermes) for them in the meantime.

<Callout>Support for every model in every harness is coming soon.</Callout>

Codex doesn't know the context window or reasoning settings of models outside its own catalog. It uses generic defaults
for them and prints a warning, which you can ignore.

## Profiles

Keep pay-as-you-go and Go side by side with a profile. Define both providers in `~/.codex/config.toml`, then add a
profile file that switches to Go.

```toml title="~/.codex/go.config.toml"
model = "gpt-6-luna"
model_provider = "opencode-go"
```

```bash
codex --profile go
```

## Console MCP

Add the [Console MCP](/console/harnesses#console-mcp) server and sign in from the browser.

```bash
codex mcp add opencode-console --url https://opencode.ai/console/mcp
```

If the sign-in doesn't start automatically, run it yourself.

```bash
codex mcp login opencode-console
```
