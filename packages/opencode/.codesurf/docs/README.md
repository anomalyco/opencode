# Development Session Documentation

This directory contains internal development session notes and documentation that were created during the development of CodeSurf/OpenCode. These files are kept for historical reference but are not part of the public-facing documentation.

## Contents

These documents track the evolution of various features and fixes:

- **Agent & Orchestration**: AGENT_TRACKING.md, ORCHESTRATION.md, ORCHESTRATOR_BUGS_FIXED.md
- **UI & Plugins**: PLUGIN_*.md, UI_*.md, MESSAGE_WIDGETS*.md, COLLAPSIBLE_SIDEBARS.md
- **Performance & Fixes**: PERFORMANCE_FIXES.md, BUGS_FIXED_SUMMARY.md, BEFORE_AFTER_FIX.md
- **Architecture**: WORKER_ARCHITECTURE.md, XML_RUNTIME_*.md
- **Integration**: INTEGRATION_COMPLETE.md, MIGRATION_IMPLEMENTATION_SUMMARY.md
- **Knowledge Base**: KB_RAID_*.md
- **Session Notes**: SESSION_COMPLETE.md, REALITY_CHECK.md, THE_SOLUTION.md, DEBUG_WORKERS.md

## Purpose

These files document:
- Feature implementation decisions
- Bug fixes and their solutions
- Architecture evolution
- Development session summaries
- Technical lessons learned

## Note

This directory is gitignored to keep these development notes local. They serve as historical context for the development team but are not needed for end users.
