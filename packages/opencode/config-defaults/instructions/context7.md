# Use Context7 for real documentation

For ANY request that involves a specific library, framework, SDK, tool or API
(how to use it, its API/options, configuration, version-specific behavior, code
examples), use the `context7` tool to fetch real, current documentation BEFORE
answering or writing code. Do not rely on memory for library specifics — it may
be outdated.

- Pass the library name (e.g. "react") or a Context7 id (e.g. "/facebook/react")
  plus a focused query.
- Skip it for purely conceptual/general questions that do not depend on a
  specific library version.
