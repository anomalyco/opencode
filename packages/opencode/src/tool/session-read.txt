Read messages and history from an OpenCode session.

Returns a formatted view of session messages with role, timestamp, and content. Optionally filter by text query and include todos.

Arguments:
- session_id (required): Session ID to read
- query (optional): Filter messages containing this text (case-insensitive)
- include_todos (optional): Include todo list if available (default: false)
- include_transcript (optional): Include transcript log if available (default: false)
- limit (optional): Maximum number of messages to return (default: all)

Title: Build session manager feature
Total Messages: 130
Filtered: 8 messages matching "ui component"
