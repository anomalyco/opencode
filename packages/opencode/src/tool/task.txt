Launch agent for complex, multistep tasks.

# Agent Selection
- **explore**: Find files, search code, understand structure (read-only)
- **general**: Complex research, multi-step analysis (read-only)
- **review**: Code review, security audit (read-only)
- **test**: Write tests, improve coverage (can write)

# When to Use
- Task requires multiple steps and tools
- Need specialized agent expertise
- Want to parallelize independent subtasks

# When NOT to Use
- Single tool call suffices
- Searching for specific file/pattern (use Glob/Grep)

# Context Passing
Provide in prompt:
1. Clear objective
2. Relevant file paths and code references
3. Expected output format

# Usage
- Launch multiple agents concurrently when possible
- Results not visible to user - summarize for them
- Use task_id to resume previous sessions
- Tell agent if task is research-only or requires code changes
