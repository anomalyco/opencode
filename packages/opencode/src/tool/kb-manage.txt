Manage the KB knowledge base - view statistics, list documents, get details, and delete documents.

This tool provides administrative functions for the KB knowledge base:

Actions:
- **stats**: Show knowledge base statistics (document counts, tokens, top keywords)
- **list**: List all documents with filters and pagination
- **get**: Get full details and content of a specific document
- **delete**: Delete a specific document by ID
- **clear**: Delete all documents (optionally filtered by source)

Examples:
- View stats: action=stats
- List all docs: action=list
- List project docs: action=list, source=project, limit=50
- Get document: action=get, documentId=abc123
- Delete document: action=delete, documentId=abc123
- Clear project KB: action=clear, source=project
- Clear all: action=clear

Use this for:
- Monitoring knowledge base size and growth
- Finding document IDs for targeted queries
- Reviewing ingested content
- Cleaning up outdated documents
- Managing project vs global knowledge bases separately
