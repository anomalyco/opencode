Execute Python code in a persistent REPL environment for Recursive Language Model (RLM) processing.

This tool enables you to interact with arbitrarily long contexts through code execution. The context is stored as a variable in the REPL environment, allowing you to programmatically examine, decompose, and process it.

## Environment Setup

When initialized with context, the REPL provides:
1. A `context` variable containing the input data (string or list of strings)
2. An `llm_query(prompt, context="")` function for recursive LLM sub-calls
3. Standard Python libraries and the ability to import more
4. Persistent state across code executions within the same session

## How to Use

Write Python code wrapped in triple backticks with 'repl' language identifier:

```repl
# Example: Examine the context
print(f"Context length: {len(context)} characters")
print(f"First 500 chars: {context[:500]}")
```

## Key Functions

### llm_query(prompt, context="")
Query a sub-LLM for semantic understanding. Use this for:
- Semantic transformations that can't be done with code
- Classifying or labeling data
- Summarizing sections of context
- Answering questions about specific content

```repl
# Example: Classify a chunk semantically
chunk = context[:10000]
classification = llm_query(f"Classify this text into categories: {chunk}")
print(classification)
```

## Strategies for Long Contexts

1. **Chunking and Iterating**: Split context into manageable pieces
```repl
chunks = context.split('\n')
for i, chunk in enumerate(chunks[:10]):
    result = llm_query(f"Summarize: {chunk}")
    print(f"Chunk {i}: {result}")
```

2. **Filtering with Code**: Use regex/string operations to narrow search
```repl
import re
relevant = [line for line in context.split('\n') if 'keyword' in line.lower()]
print(f"Found {len(relevant)} relevant lines")
```

3. **Building Answers Incrementally**: Store intermediate results
```repl
answers = []
for section in sections:
    answer = llm_query(f"Extract key facts: {section}")
    answers.append(answer)
final = llm_query(f"Combine these facts: {answers}")
```

## Providing Final Answers

When you have completed your analysis, you MUST wrap your answer in one of these tags:

- `FINAL(your answer here)` - Return a direct text answer
- `FINAL_VAR(variable_name)` - Return the contents of a variable

```repl
# Direct answer
print("FINAL(The answer is 42)")

# Or return a built-up variable
result = "Complex answer built from multiple sub-queries..."
print(f"FINAL_VAR(result)")
```

## Important Notes

- Output is truncated to prevent context overflow; use llm_query for analysis
- Sub-LLM calls can handle ~500K characters each
- Variables persist across code executions in the same session
- Always explicitly explore the context before answering queries
- Batch information into sub-LLM calls to minimize API costs
