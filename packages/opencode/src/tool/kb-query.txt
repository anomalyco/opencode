Query the KB knowledge base with AI-powered orchestration, intelligent shard routing, and answer fusion.

This is the main KB query interface that uses advanced RAG techniques:

1. **Document Discovery**: Searches knowledge base for relevant documents
2. **Smart Sharding**: Breaks large documents into overlapping chunks
3. **Intelligent Routing**: Uses AI to select the most relevant shards
4. **Parallel Querying**: Queries multiple shards concurrently
5. **Answer Fusion**: Synthesizes responses from multiple sources into a coherent answer

The orchestrator uses two models:
- Shard Model (RAID_SHARD_MODEL): Fast, efficient model for querying individual shards
- Orchestration Model (RAID_ORCH_MODEL): Powerful model for routing and fusion

Configuration:
- RAID_MAX_CONCURRENT: Max parallel shard queries (default: 5)
- RAID_MAX_TOKENS_PER_SHARD: Max tokens per shard (default: 4000)
- RAID_OVERLAP_TOKENS: Token overlap between shards (default: 200)

Examples:
- Ask about API endpoints: "What authentication endpoints are available?"
- Query implementation details: "How is rate limiting implemented?"
- Explore architecture: "Explain the database schema design"
- Find specific information: "What are the deployment requirements?"

Use this when:
- You need accurate answers from your knowledge base
- The answer requires information from multiple documents
- You want AI-synthesized responses rather than raw search results
