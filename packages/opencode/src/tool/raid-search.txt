Search the RAID knowledge base using full-text search with relevance ranking.

This tool performs fast, SQLite FTS5-powered searches across all ingested documents, with:
- BM25 relevance ranking
- Highlighted snippets
- Source filtering (project/global)
- Tag and content type filtering
- Configurable result limits

FTS Query Syntax:
- "exact phrase" - Match exact phrase
- word1 OR word2 - Match either word
- word1 AND word2 - Match both words
- word* - Prefix matching
- -word - Exclude word
- column:word - Search specific column (title, content, keywords, summary)

Examples:
- Search for authentication docs: "authentication"
- Find React hooks: "react" AND "hooks"
- Exclude deprecated docs: "api" -deprecated
- Find specific title: title:"getting started"

Use this for:
- Quick lookups in the knowledge base
- Finding relevant documents before querying
- Browsing available documentation
- Verifying ingested content
