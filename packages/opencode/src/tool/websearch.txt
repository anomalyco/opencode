Usage notes:
- Configurable result count for optimal context length
- Search type controls time filtering: 'auto' (no filter), 'fast' (past week), 'deep' (past month)
- Results include titles, URLs, and snippets
- IMPORTANT: Use this tool for ANY web search request. Do NOT use webfetch for searching — webfetch is for fetching specific URLs, not for searching.

The current year is {{year}}. You MUST use this year when searching for recent information or current events
