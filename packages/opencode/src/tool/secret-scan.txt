Advanced secret and credential detection tool for identifying hardcoded sensitive data in source code.

This tool scans files and directories for exposed secrets, API keys, passwords, tokens, certificates, and other sensitive data that should never be committed to version control.

## Detection Categories

- **API Keys**: AWS, GCP, Azure, Stripe, Twilio, SendGrid, Slack, GitHub, GitLab, Bitbucket, and 100+ more services
- **Private Keys**: RSA, DSA, EC, PGP, SSH private keys and certificates
- **Passwords & Credentials**: Hardcoded passwords, database connection strings, authentication tokens
- **OAuth Tokens**: Bearer tokens, refresh tokens, JWT secrets, OAuth client secrets
- **Cloud Credentials**: AWS access keys, GCP service account keys, Azure storage keys
- **Infrastructure Secrets**: Database URLs, SMTP credentials, Redis/MongoDB connection strings
- **Blockchain Keys**: Private keys for Ethereum, Bitcoin, and other cryptocurrency wallets
- **Internal URLs**: Internal/staging URLs, VPN configurations, internal service endpoints
- **Certificates**: TLS/SSL certificates, CA bundles, PKCS12 files

## Scan Modes

- `quick` - Scan for high-confidence patterns only (API keys, private keys)
- `thorough` - Full scan including entropy-based detection for unknown secret formats (default)
- `git-history` - Scan current files plus git history for previously committed secrets

## Features

- **Entropy Analysis**: Detects high-entropy strings that may be undiscovered secret formats
- **Context Awareness**: Reduces false positives by analyzing surrounding code context
- **Git Integration**: Can scan git history to find secrets that were committed and later removed
- **Allowlist Support**: Respects .secretscanignore files for known false positives
- **Severity Rating**: Classifies findings as Critical (active credentials), High (keys/tokens), Medium (potential secrets), Low (suspicious patterns)

Use this tool to audit codebases before committing to public repositories, during security reviews, or as part of CI/CD pipeline security checks.
