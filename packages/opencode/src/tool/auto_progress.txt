Use this tool to manage the auto-progress engine for a session. The auto-progress engine automatically advances todos through their lifecycle: it starts the next pending L1 todo, launches all its L2 children in parallel, and marks the L1 complete when all children finish.

## When to Use This Tool

Use this tool proactively in these scenarios:

1. Starting the engine — When you begin a multi-step task with a well-defined todo hierarchy and want the engine to automatically advance L1→L1 as each parent completes
2. Stopping the engine — When you want to take manual control of todo progression
3. Checking status — To see whether the engine is currently running for the active session

## When NOT to Use This Tool

Skip using this tool when:
1. There are no hierarchical todos (single-level flat list)
2. The task is trivial and doesn't need structured progression
3. The engine is already running and you don't need to change its state

## Behavior by Action

- `start`: Activates the engine for the given (or current) session. The engine listens for Todo.Updated events and automates L1→L1 transitions.
- `stop`: Deactivates the engine, returning control to manual todo management.
- `status`: Returns whether the engine is "running" or "idle" for the session.
