# セキュアコード マニュアル

このマニュアルは Acompany セキュアコード の **使い方** です。ユーザーが セキュアコード 本体の操作・設定・トラブル対応について質問したときに参照してください。アプリのコードを書く依頼や、コードベースに対するレビュー依頼などには使いません（その場合はこのスキルを呼ばないでください）。

## 章構成

このスキルには以下の章が **このスキル本文として** 含まれています (別ファイルを Read する必要はありません)。

| # | 章 | 主な内容 | こんな質問のときに読む |
|---|---|---|---|
| 01 | インストール | インストール方法、対応 OS、`install` スクリプトの挙動 | 「どうやって入れる？」「どの OS で動く？」 |
| 02 | クイックスタート | 初回起動、API キー設定、最初のプロンプトまで | 「最初に何すればいい？」「`Hello` が動かない」 |
| 03 | コマンド一覧 | `run` / `serve` / `attach` / `agent` / `models` / `session` / `mcp` / `upgrade` 等 | 「`securecode <何か>` ってどう使う？」「履歴を見たい」 |
| 04 | 設定ファイル | `securecode.json` / `tui.json` / `sandbox.json` の置き場所と書き方 | 「モデルを切り替えたい」「設定の場所はどこ？」 |
| 05 | サンドボックス | 2 層防御 (Permission + Sandbox) の挙動、許可ドメイン追加、AI から見えないファイル | 「外部通信できない」「`fetch` がブロックされる」 |
| 06 | トラブルシュート | 起動失敗・401/502・通信ブロック・upgrade 失敗・権限ダイアログ | 「エラーが出る」「動かない」 |
| 07 | FAQ | よくある質問・既知の制約・問い合わせ先 | 「データはどこに行く？」「オフラインで使える？」 |

## 推奨される使い方

1. ユーザーの質問内容を読んで、上の表から該当する章を 1〜2 個特定する
2. このスキル本文の該当章を根拠として回答する（**マニュアル本文に書かれていない事項は推測で穴埋めをせず、「マニュアルには明示されていない」と素直に言う**）
3. 質問が複数章にまたがる場合は、必要な章を全部読んでから回答を統合する

## このスキルを使わない場合

- ユーザーの依頼が「セキュアコード 自身」ではなく「ユーザーのアプリ・ライブラリ・コードベース」についてのコーディング依頼の場合
- `git` / `npm` / 他の CLI ツールの使い方を聞かれたとき
- 一般的なプログラミングの質問
