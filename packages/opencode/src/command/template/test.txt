Generate and run tests for the current file or module.

Task: Analyze the code in the current open file, generate appropriate tests, write them to a test file, and run them.

$ARGUMENTS

### Instructions

1. Identify the testing framework used by this project (check package.json for vitest, jest, mocha, etc.)
2. Analyze the source code's exports, classes, and functions
3. Generate comprehensive tests following the project's existing test patterns
4. Write tests to the appropriate test file (same directory in __tests__/ or with .test.ts suffix)
5. Run the tests and report results
6. If tests fail, fix the issues and retry (up to 2 iterations)

### Output
Report which tests were written, the test results, and any issues found.
