Generate and run tests for the current file or module.

Task: Analyze the code in the current open file, generate appropriate tests, write them to a test file, and run them.

$ARGUMENTS

### Instructions

1. Check if a testing framework is configured in the project settings. If configured, use that framework.
2. If no framework is configured, identify the testing framework used by this project (check package.json for vitest, jest, mocha, bun, etc.)
3. Analyze the source code's exports, classes, and functions
4. Generate comprehensive tests following the project's existing test patterns
5. Write tests to the appropriate test file (same directory in __tests__/ or with .test.ts suffix)
6. Run the tests using the configured test command, or auto-detect the correct command
7. Report results: which tests were written, test results, and any issues found
8. If tests fail, fix the issues and retry (up to configured max iterations, default 2)

### Output
Report which tests were written, the test results, and any issues found.
