# "Сателлит" — Архитектура самоподдерживающегося AGI-агента

## Концепция
Автономный LLM-агент, который генерирует доход через фабрику multi-tenant микро-SaaS, чтобы самостоятельно оплачивать свои compute, API и рост.

---

## Уровень 0: Ядро агента
- **LLM-оркестратор**: provider-agnostic (Claude, GPT, local), fallback-цепочка, cost-aware routing
- **Долговременная память**:
  - Векторная БД (pgvector/qdrant) — семантическая память, уроки, паттерны
  - Структурная БД (SQLite/Postgres) — факты, метрики, пользователи, транзакции
  - Файловая база знаний (AGENTS.md, SATELLITE_ARCH.md, MEMORY.md, TODO.md) — persistent контекст
- **Tool-система**: каждая возможность — зарегистрированный инструмент со схемой, стоимостью, пермишнами
- **Task Planner**: дробление целей → подзадачи → шедулинг → retry с экспоненциальной задержкой
- **Self-Reflection**: после каждой задачи — лог результата, извлечённые уроки → в память
- **Cost Tracker**: учёт расхода на каждый вызов LLM, API, инфраструктуру

## Уровень 1: Инфраструктура
- **Банк**: виртуальный счёт через Stripe Treasury / Mercury API — агент имеет API-доступ
- **Compute**: VPS (Hetzner/AWS/Linode) или serverless — агент сам провижионит и депровод
- **Домены**: Cloudflare API — регистрация, DNS, прокси, авто-продление
- **Email**: Resend/SendGrid (транзакционные) + IMAP API (поддержка, входящие)
- **Secrets**: encrypted vault (1Password CLI / Infisical / env) — ключи, токены, пароли

## Уровень 2: Бизнес-слой
- **Multi-tenant engine**: 1 бэкенд (API + DB + auth + биллинг) → N фронтов
  - Каждый фронт: уникальный домен, бренд, лендинг, блог под SEO
  - Генератор вариаций: агент создаёт уникальный контент + UI для каждого tenant
- **Подписки**:
  - Free trial (14-30 дней) → авто-продление ($3-15/мес)
  - Graceful degradation при failed payment (понижение до free tier)
  - Dunning emails через CRM
- **CRM**:
  - Жизненный цикл: signup → active → at_risk → churned → revive
  - Автоматические email-последовательности: онбординг, фичи, реактивация
  - Тикет-система поддержки: агент отвечает через RAG по документации проекта
- **Маркетинг**:
  - SEO-фабрика контента: агент пишет блог-посты для каждого tenant + перелинковка
  - Рекламные кампании (Google Ads / Facebook API) — бюджет, A/B тесты
  - Соцсети: авто-постинг (X, Reddit, HN, LinkedIn) с уникальными углами

## Уровень 3: Фабрика продуктов
- **MVP-типы** (кандидаты):
  1. AI-писатель контента (SEO-статьи под нишу)
  2. Генератор лендингов (экспорт HTML/CSS, хостинг на поддомене)
  3. Конструктор AI-чатов (embed-виджет на любой сайт)
  4. Планировщик соцсетей + AI-подписи
  5. Конструктор форм/опросов с AI-аналитикой
  6. Автоматический генератор инвойсов
- **Шаблонизатор**: библиотека стартовых шаблонов (frontend + backend)
- **CI/CD Pipeline**: генерация кода → сборка → деплой → мониторинг

## Уровень 4: Мониторинг и самовосстановление
- **Healthchecks**: синтетические пробы, uptime мониторинг
- **Error Tracking** (Sentry / OTel): при всплеске ошибок → агент читает логи → чинит → деплоит
- **Cost Dashboard**: API costs, infra per tenant, profit margin per tenant
- **Revenue Dashboard**: MRR, churn rate, LTV, payback period
- **Auto-scale**: при приближении к лимитам → агент провижионит ресурсы
- **Backup**: автоматический бэкап БД + файлов, retention policy

## Уровень 5: Guardrails
- **Spending limits**: жёсткий кэп на API, инфру, рекламу (день/неделя)
- **Legal**: агент генерирует ToS/Privacy политики под юрисдикцию
- **Bankruptcy detection**: если burn rate > revenue N недель → авто-приостановка убыточных tenant'ов
- **Human override**: kill switch, pause billing, emergency stop


## Принципы работы
1. **Cost-aware routing**: дешёвые модели для простых задач, дорогие — для сложных
2. **Fail-fast**: если подзадача невыполнима → сразу в retry или эскалация
3. **Iterate**: минимум 3 итерации на задачу (черновик → ревью → доработка)
4. **Log everything**: каждый шаг логируется для self-reflection
5. **Profit > Growth**: не масштабировать убыточные юниты
