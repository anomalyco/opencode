Focus View 设计:回合折叠 + 最新消息展示(交互版)

每个用户 prompt = 一个「回合」(turn),产生 多条 assistant 消息(共享 parentID)。 Focus view 把整个回合折叠为「最后一条 assistant 消息 + 一行工具摘要」,新消息到达时展示就地更新。 下方交互图可播放消息流动画、点击展开被折叠的工具轮。

①回合结构:一个 prompt → 多条 assistant 消息

②交互演示:Focus ON 回合折叠(点击展开/收起隐藏轮)

FOCUS OFF ⇄ ON 切换折叠;ON 状态下点击摘要行展开被隐藏的工具轮(模拟 claude 的 "toggle /focus to show")。

实现要点:(1) 按 parentID 分组消息为回合;(2) focus 模式下每个回合渲染单一折叠块; (3) 块内容 = last 消息的文本 + 全回合工具摘要 + hidden 计数; (4) 消息流追加时 last 变化,折叠块响应式更新为最新消息; (5) 点击摘要行展开被隐藏的工具轮(claude 的 "toggle /focus to show" 等价物)。
