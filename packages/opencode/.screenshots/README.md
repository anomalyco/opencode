# Screenshots Folder

Drop any screenshots here that you want to share with the AI.

Files in this folder are:
- ✅ Always accessible by the AI
- ✅ Inside the project directory
- ✅ Git-ignored by default

## Usage:

1. Take a screenshot (Cmd+Shift+4 on macOS)
2. Move/copy it to this folder
3. Reference it in chat

## Example:

```
User: "Check out .screenshots/context-bar.png"
AI: *can read the file directly*
```
