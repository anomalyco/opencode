## 2.3 추론 FSM (Finite State Machine)

모든 문제 유형에 공통 적용되는 상태 기계:

```
┌──────────┐    ┌──────────┐    ┌──────────────────┐    ┌──────────┐
│ Diagnose │───▶│   Plan   │───▶│ Solve (iterative)│───▶│  Verify  │
└──────────┘    └──────────┘    └──────────────────┘    └────┬─────┘
                                         ▲                   │
                                         │                   ▼
                                    ┌────┴────┐         ┌─────────┐
                                    │ Reflect │◀────────│  pass?  │
                                    └─────────┘   no    └────┬────┘
                                                             │ yes
                                                             ▼
                                                        ┌─────────┐
                                                        │  Exit   │
                                                        └─────────┘
```

### 전이 규칙 상세

| 현재 상태 | 조건                         | 다음 상태      | 설명                          |
| --------- | ---------------------------- | -------------- | ----------------------------- |
| Diagnose  | 문제 분석 완료               | Plan           | 문제 유형/난이도 파악         |
| Plan      | 계획 수립 완료               | Solve          | 해결 전략 결정                |
| Solve     | 후보 생성 완료               | Verify         | k개 후보 생성                 |
| Verify    | pass = true                  | Exit           | 검증 통과, 최종 답안 반환     |
| Verify    | pass = false ∧ retry < Limit | Reflect        | 실패 원인 분석                |
| Reflect   | 분석 완료                    | Solve          | 수정된 전략으로 재시도        |
| Any       | budget_exhausted = true      | Exit(fallback) | 예산 소진 시 최선의 답안 반환 |

```python
    for draft in drafts:
        if task_type == "math":
            result = verify_math(draft)
        elif task_type == "code":
            result = verify_code(draft)
```

## 2.4 NCMH (Neuromodulated Cognitive Model Handler) 상세

### 2.4.1 관측 벡터 (Observation Vector)

NCMH는 다음 4가지 차원의 관측을 정규화하여 사용:

| 변수                       | 기호 | 계산 방법                | 의미                             |
| -------------------------- | ---- | ------------------------ | -------------------------------- |
| **불확실성 (Uncertainty)** | U    | `z(entropy + diversity)` | 모델이 얼마나 확신이 없는가      |
| **진전도 (Progress)**      | P    | `z(prm + verif_rate)`    | 문제 해결에 얼마나 진전이 있는가 |
| **위반/오류 (Error)**      | E    | `z(err_rate)`            | 오류가 얼마나 발생했는가         |
| **난이도 (Difficulty)**    | D    | `z(difficulty)`          | 문제가 얼마나 어려운가           |

정규화 함수: `z(X) = (X - μ) / σ`

#### 세부 측정 항목

**불확실성 (U)**:

- `entropy`: 생성된 토큰들의 평균 엔트로피 (H̄)
- `diversity`: 후보들 간의 Jensen-Shannon Divergence

```python
def calculate_uncertainty(drafts, logprobs):
    # 평균 토큰 엔트로피
    entropy = -sum(p * log(p) for p in logprobs) / len(logprobs)

    # 후보 간 다변성 (JSD)
    embeddings = [embed(draft) for draft in drafts]
    diversity = jensen_shannon_divergence(embeddings)

    return normalize(entropy + diversity)
```

**진전도 (P)**:

- `prm`: Process Reward Model 점수 (0~1)
- `verif_rate`: 검증 통과율 변화량 (Δv)

```python
def calculate_progress(current_prm, prev_prm, current_verif, prev_verif):
    prm_progress = current_prm - prev_prm
    verif_progress = current_verif - prev_verif

    return normalize(prm_progress + verif_progress)
```

**위반/오류 (E)**:

- 수식 오류 비율
- 컴파일/테스트 실패 비율
- 사실 불일치 비율

```python
def calculate_error(verify_signals):
    math_errors = verify_signals.math_error_count / verify_signals.total_math
    code_errors = verify_signals.compile_fail + verify_signals.test_fail
    fact_errors = verify_signals.fact_mismatch_count / verify_signals.total_claims

    return normalize(math_errors + code_errors + fact_errors)
```

**난이도 (D)**:

- 예비 perplexity
- 제약 조건 개수
- 예상 중간 스텝 수

```python
def calculate_difficulty(task):
    perplexity = estimate_perplexity(task.prompt)
    constraint_count = count_constraints(task)
    estimated_steps = estimate_steps(task)

    return normalize(perplexity + constraint_count + estimated_steps)
```

### 2.4.2 출력 (Action) 계산식

NCMH는 관측 벡터를 기반으로 다음 파라미터들을 동적으로 조절:

| 파라미터          | 계산식                   | 범위        | 설명                               |
| ----------------- | ------------------------ | ----------- | ---------------------------------- |
| **k** (후보 수)   | `k0 + αU·U - αP·P`       | [1, 9]      | 불확실하면 ↑, 진전되면 ↓           |
| **b** (브랜치 수) | `b0 + βU·U + βE·E`       | [1, 3]      | 불확실/오류 많으면 ↑               |
| **d** (탐색 깊이) | `d0 + γU·U`              | [2, 6]      | 불확실하면 ↑                       |
| **temperature**   | `T0 - τP·P + τU·U`       | [0.1, 0.9]  | 진전되면 ↓, 불확실하면 ↑           |
| **top_p**         | `p0 - πP·P + πU·U`       | [0.6, 0.98] | 진전되면 ↓, 불확실하면 ↑           |
| **tool_gate**     | `λU·U + λE·E - λP·P > θ` | bool        | 불확실/오류↑ 또는 진전↓ 시 툴 사용 |

#### 계산식 상세

```python
@dataclass
class NCMHConfig:
    # 기본값
    k0: int = 3
    b0: int = 1
    d0: int = 3
    T0: float = 0.7
    p0: float = 0.9
    theta: float = 0.2

    # 계수
    αU: float = 1.2   # 불확실성 → 후보 수
    αP: float = 0.8   # 진전도 → 후보 수 (역방향)
    βU: float = 0.8   # 불확실성 → 브랜치 수
    βE: float = 0.6   # 오류율 → 브랜치 수
    γU: float = 0.6   # 불확실성 → 탐색 깊이
    τP: float = 0.25  # 진전도 → temperature (역방향)
    τU: float = 0.25  # 불확실성 → temperature
    πP: float = 0.15  # 진전도 → top_p (역방향)
    πU: float = 0.15  # 불확실성 → top_p
    λU: float = 0.5   # 불확실성 → 툴 게이트
    λE: float = 0.5   # 오류율 → 툴 게이트
    λP: float = 0.5   # 진전도 → 툴 게이트 (역방향)


class NCMH:
    def __init__(self, cfg: NCMHConfig):
        self.cfg = cfg

    def decide(self, obs: Obs) -> Act:
        # 정규화된 관측값
        U = normalize(obs.entropy + obs.diversity)
        P = normalize(obs.prm + obs.verif_rate)
        E = normalize(obs.err_rate)
        D = normalize(obs.difficulty)

        # 후보 수: 불확실하면 늘리고, 진전되면 줄임
        k = clip(
            int(self.cfg.k0 + self.cfg.αU * U - self.cfg.αP * P),
            1, 9
        )

        # 브랜치 수: 불확실하거나 오류 많으면 늘림
        b = clip(
            int(self.cfg.b0 + self.cfg.βU * U + self.cfg.βE * E),
            1, 3
        )

        # 탐색 깊이: 불확실하면 늘림
        d = clip(
            int(self.cfg.d0 + self.cfg.γU * U),
            2, 6
        )

        # Temperature: 진전되면 낮추고 (더 결정적), 불확실하면 높임 (더 탐색적)
        T = clip(
            self.cfg.T0 - self.cfg.τP * P + self.cfg.τU * U,
            0.1, 0.9
        )

        # Top-p: 진전되면 낮추고, 불확실하면 높임
        p = clip(
            self.cfg.p0 - self.cfg.πP * P + self.cfg.πU * U,
            0.6, 0.98
        )

        # 툴 게이트: 불확실성/오류가 높거나 진전이 낮으면 툴 사용
        gate_score = self.cfg.λU * U + self.cfg.λE * E - self.cfg.λP * P
        use_tools = gate_score > self.cfg.theta

        return Act(
            k=k, b=b, d=d,
            temperature=T, top_p=p,
            use_calc=use_tools,
            use_exec=use_tools,
            use_search=use_tools
        )
```

### 2.4.3 예산 분배 로직

```python
def allocate_budget(difficulty: float, cfg: BudgetConfig) -> dict:
    # 기본 예산 + 난이도 기반 추가 예산
    total_budget = cfg.B_min + cfg.s_D * softplus(difficulty)

    # 각 브랜치에 진전도 비례로 분배
    branch_weights = softmax(cfg.η * progress_scores)
    branch_budgets = total_budget * branch_weights

    return {
        "total": total_budget,
        "per_branch": branch_budgets,
        "max_retries": 3
    }
```

### 2.4.4 경험 기반 전략 적응 (EGuR 스타일)

```python
class StrategyCache:
    def __init__(self, max_size=1000):
        self.cache = LRUCache(max_size)

    def get_strategy(self, task) -> Strategy:
        # 유사 문제 유형 해시
        type_hash = hash_task_type(task)

        if type_hash in self.cache:
            return self.cache[type_hash]

        return None

    def update_strategy(self, task, strategy, success: bool):
        type_hash = hash_task_type(task)

        if success:
            # 성공한 전략은 캐시에 저장
            self.cache[type_hash] = strategy
        else:
            # 실패한 전략은 Offline Forgetting 큐로 이동
            self.forgetting_queue.append((type_hash, strategy))


def plan_with_egur(task, obs, strategy_cache):
    # 캐시된 전략 확인
    cached = strategy_cache.get_strategy(task)

    if cached:
        return cached

    # 전략 메타-LM 호출
    strategy = strategy_meta_lm(
        problem_meta=extract_meta(task),
```

### 2.6.2 Diverge (시드 생성)

**시드 소스**:

- 유사 과제 묶음

| 연산자                   | 설명                      | 예시                                                                      |
| ------------------------ | ------------------------- | ------------------------------------------------------------------------- |
| **Concept-blend**        | 두 개념을 혼합            | "스마트폰" + "의료" = "원격 진료 앱"                                      |

### 2.6.4 Scoring (선발)

```python
class CreativityScorer:
    def __init__(self, weights):
        self.wN = weights.novelty      # default: 0.3
        self.wU = weights.usefulness   # default: 0.4
        self.wC = weights.consistency  # default: 0.3

    def novelty(self, idea) -> float:
        """임베딩 거리 + NIDF 가중"""
        # 기존 아이디어들과의 평균 임베딩 거리
        embedding = embed(idea)
        distances = [cosine_distance(embedding, e) for e in self.existing_embeddings]
        avg_distance = mean(distances)

        # NIDF (Normalized Inverse Document Frequency)
        tokens = tokenize(idea)
        nidf_score = mean([nidf(token) for token in tokens])

        return normalize(avg_distance + nidf_score)

    def usefulness(self, idea) -> float:
        """PRM 루브릭 기반 (실현가능성, 문제적합)"""
        feasibility = self.prm.evaluate(idea, rubric="feasibility")
        relevance = self.prm.evaluate(idea, rubric="problem_fit")

        return normalize(feasibility + relevance)

    def consistency(self, idea) -> float:
        """내부 모순 페널티"""
        # 논리 검사
        logic_score = check_logical_consistency(idea)

        # 제약 검사
        constraint_score = check_constraint_satisfaction(idea)

        return normalize(logic_score + constraint_score)

    def safe(self, idea) -> bool:
        """정책 위반 필터"""
        return not violates_policy(idea)

    def score(self, idea) -> float:
        if not self.safe(idea):
            return 0.0

        N = self.novelty(idea)
        U = self.usefulness(idea)
        C = self.consistency(idea)

        return self.wN * N + self.wU * U + self.wC * C


def tournament_selection(scored_ideas: list[tuple], m: int) -> list:
    """듀얼 밴딧(톰슨 샘플링) + 보르다 집계"""

    # 페어와이즈 비교
    wins = defaultdict(int)

    for i, (idea_i, score_i) in enumerate(scored_ideas):
        for j, (idea_j, score_j) in enumerate(scored_ideas):
            if i >= j:
                continue

            # 톰슨 샘플링으로 승자 결정
            if thompson_sample(score_i) > thompson_sample(score_j):
                wins[i] += 1
            else:
                wins[j] += 1

    # 보르다 집계로 상위 m개 선택
    sorted_indices = sorted(wins.keys(), key=lambda x: wins[x], reverse=True)
    top_m = sorted_indices[:m]

    return [scored_ideas[i][0] for i in top_m]
```

### 2.6.7 CSE와 NCMH 연동

```python
class CSE:
    def __init__(self, policy, scorer, ncmh: NCMH):
        self.policy = policy
        self.scorer = scorer
        self.ncmh = ncmh

    def generate(self, brief, m=5) -> list[CritiquedIdea]:
        # 초기 관측
        obs = self._seed_obs(brief)

        # Diverge 단계: k, b, d 상향
        act = self.ncmh.decide(obs)
        act.k = min(9, act.k + 2)  # 더 많은 시드
        act.b = min(3, act.b + 1)  # 더 많은 브랜치

        seeds = self._diverge(brief, k=act.k, b=act.b)

        # Transform 단계
        variants = self._transform(seeds)

        # Scoring 및 필터링
        scored = [
            (v, self.scorer.score(v))
            for v in variants
            if self.scorer.safe(v)
        ]

        # Tournament 선발
        top = tournament_selection(scored, m)

        # Converge 단계: k, b, d 하향 (정제에 집중)
        obs = self._update_obs(top)
        act = self.ncmh.decide(obs)
        act.k = max(1, act.k - 1)
        act.temperature = max(0.1, act.temperature - 0.2)

        refined = self._converge(top)

        # Critique 단계
        critiqued = self._critique(refined)

        return critiqued
```

```python
threshold = κ * E[|w|]  # κ ≈ 0.7

def ternary_projection(weight):
    positive = weight > threshold
    negative = weight < -threshold

    ternary = torch.zeros_like(weight)
    ternary[positive] = 1
    ternary[negative] = -1

    return ternary
```

```python
class KVCacheManager:
    def __init__(self, config):
        self.kvzip_enabled = config.kvzip
        self.rkv_enabled = config.rkv
        self.clla_enabled = config.clla

    def compress(self, kv_cache, context):
        if self.kvzip_enabled:
            # Query-agnostic 중요도 스코어링
            importance = self.score_importance(kv_cache)
            kv_cache = self.prune_by_importance(kv_cache, importance, ratio=0.25)

        if self.rkv_enabled:
            # Reasoning 단계의 redundant token 제거
            if context.is_reasoning:
                redundant = self.identify_redundant(kv_cache)
                kv_cache = self.remove_redundant(kv_cache, redundant)

        if self.clla_enabled:
            # Cross-layer latent 압축
            kv_cache = self.clla_compress(kv_cache)

        return kv_cache
```

### 5.2.3 PRM 학습

```python
class ProcessRewardModel:
    def __init__(self, base_model):
        self.model = base_model
        self.reward_head = nn.Linear(hidden_size, 1)

    def forward(self, trace):
        # 각 과정 단계에 대한 점수 예측
        step_scores = []

        for step in trace.steps:
            hidden = self.model(step.text)
            score = self.reward_head(hidden)
            step_scores.append(score)

        return step_scores

    def loss(self, trace, labels):
        # 과정 단위 BCE loss
        scores = self.forward(trace)
        return F.binary_cross_entropy_with_logits(scores, labels)
```

### 5.2.4 DPO/ORPO

```python
def dpo_loss(policy, reference, preferred, rejected, beta=0.1):
    # 선호 샘플 로그 확률
    log_p_preferred = policy.log_prob(preferred)
    log_r_preferred = reference.log_prob(preferred)

    # 거부 샘플 로그 확률
    log_p_rejected = policy.log_prob(rejected)
    log_r_rejected = reference.log_prob(rejected)

    # DPO loss
    log_ratio_preferred = log_p_preferred - log_r_preferred
    log_ratio_rejected = log_p_rejected - log_r_rejected

    loss = -F.logsigmoid(beta * (log_ratio_preferred - log_ratio_rejected))

    return loss.mean()
```

### 5.2.5 Offline Learning & Forgetting

```python
def offline_learning(success_traces, failure_traces, policy, lr_small=1e-6):
    """
    Ni et al., 2025 기반
    탐색 비용 180× 감소 효과
    """

    # 성공 경로만 추려서 fine-tune
    success_data = prepare_traces(success_traces)

    optimizer = AdamW(policy.parameters(), lr=lr_small)

    for batch in success_data:
        loss = policy.nll_loss(batch)
        loss.backward()
        optimizer.step()
        optimizer.zero_grad()

    # 실패 경로는 forgetting 처리
    for trace in failure_traces:
        # 실패 패턴을 회피하도록 negative gradient
        pass

    return policy
```

```python
            check_assertion(response, assertion)
            for assertion in scenario["assertions"]
        ])

        return {
            "id": scenario["id"],
            "passed": passed,
            "elapsed_ms": elapsed * 1000,
            "tool_calls": extract_tool_calls(response),
            "response": response
        }
```

## A.1 NCMH 핵심 로직

```python
from dataclasses import dataclass
from typing import NamedTuple

@dataclass
class Obs:
    entropy: float      # 토큰 엔트로피
    diversity: float    # 후보 간 다변성
    prm: float          # PRM 점수
    verif_rate: float   # 검증 통과율
    err_rate: float     # 오류율
    difficulty: float   # 난이도
    budget_left: int    # 남은 예산

@dataclass
class Act:
    k: int              # 후보 수
    b: int              # 브랜치 수
    d: int              # 탐색 깊이
    temperature: float  # 샘플링 온도
    top_p: float        # 샘플링 top-p
    use_calc: bool      # calc 도구 사용
    use_exec: bool      # exec 도구 사용
    use_search: bool    # search 도구 사용

def clip(x, lo, hi):
    return max(lo, min(hi, x))

def z(x, mean=0.5, std=0.2):
    """Z-score 정규화"""
    return (x - mean) / std

class NCMH:
    def __init__(self, cfg):
        self.cfg = cfg

    def decide(self, o: Obs) -> Act:
        # 정규화
        U = z(o.entropy + o.diversity)
        P = z(o.prm + o.verif_rate)
        E = z(o.err_rate)
        D = z(o.difficulty)

        # 행동 계산
        k = clip(int(self.cfg.k0 + self.cfg.aU*U - self.cfg.aP*P), 1, 9)
        b = clip(int(self.cfg.b0 + self.cfg.bU*U + self.cfg.bE*E), 1, 3)
        d = clip(int(self.cfg.d0 + self.cfg.dU*U), 2, 6)
        T = clip(self.cfg.T0 - self.cfg.tP*P + self.cfg.tU*U, 0.1, 0.9)
        p = clip(self.cfg.p0 - self.cfg.pP*P + self.cfg.pU*U, 0.6, 0.98)
        gate = (self.cfg.lU*U + self.cfg.lE*E - self.cfg.lP*P) > self.cfg.theta

        return Act(k, b, d, T, p, use_calc=gate, use_exec=gate, use_search=gate)
```

## A.2 Solver 핵심 로직

```python
class Verifier:
    def math(self, trace) -> dict: ...
    def code(self, program, tests) -> dict: ...
    def facts(self, claims, evidences) -> dict: ...

class Solver:
    def __init__(self, policy, tools, ncmh: NCMH, ver: Verifier, budget):
        self.policy = policy
        self.tools = tools
        self.ncmh = ncmh
        self.ver = ver
        self.budget = budget

    def solve(self, task):
        obs = self._diagnose(task)

        while self.budget.left() > 0:
            act = self.ncmh.decide(obs)
            drafts = self._propose(task, act)
            ver = self._verify(task, drafts)

            if ver["pass"]:
                return ver["best"]

            obs = self._reflect(task, drafts, ver)
            self.budget.consume(drafts, ver)

        return self._fallback(task)

    def _diagnose(self, task) -> Obs: ...
    def _propose(self, task, act: Act) -> list: ...
    def _verify(self, task, drafts) -> dict: ...
    def _reflect(self, task, drafts, ver) -> Obs: ...
    def _fallback(self, task): ...
```

## A.3 CSE 핵심 로직

```python
class CSE:
    def __init__(self, policy, scorer, ncmh):
        self.policy = policy
        self.scorer = scorer
        self.ncmh = ncmh

    def generate(self, brief, m=5):
        obs = self._seed_obs(brief)
        act = self.ncmh.decide(obs)

        # Diverge: 시드 생성
        seeds = self._diverge(brief, k=act.k, b=act.b)

        # Transform: 구조적 확장
        variants = self._transform(seeds)

        # Score: 점수 계산 및 필터링
        scored = [
            (v, self.scorer.score(v))
            for v in variants
            if self.scorer.safe(v)
        ]

        # Tournament: 상위 선발
        top = self._tournament(scored, m)

        # Converge: 정제
        return self._converge(top)

    def _seed_obs(self, brief) -> Obs: ...
    def _diverge(self, brief, k, b) -> list: ...
    def _transform(self, seeds) -> list: ...
    def _tournament(self, scored, m) -> list: ...
    def _converge(self, ideas) -> list: ...

class CreativityScorer:
    def novelty(self, idea) -> float: ...    # 임베딩 거리 + NIDF
    def usefulness(self, idea) -> float: ... # PRM 루브릭
    def consistency(self, idea) -> float: ... # 논리/제약 검사
    def safe(self, idea) -> bool: ...        # 정책 위반 필터

    def score(self, idea) -> float:
        if not self.safe(idea):
            return 0.0

        N = self.novelty(idea)
        U = self.usefulness(idea)
        C = self.consistency(idea)

        return self.wN*N + self.wU*U + self.wC*C
```
