Bolt integrates with VS Code, Cursor, or any IDE that supports a terminal. Just run `opencode` in the terminal to get started.

---

## Usage

- **Quick Launch**: Use `Cmd+Esc` (Mac) or `Ctrl+Esc` (Windows/Linux) to open Bolt in a split terminal view, or focus an existing terminal session if one is already running.
- **New Session**: Use `Cmd+Shift+Esc` (Mac) or `Ctrl+Shift+Esc` (Windows/Linux) to start a new Bolt terminal session, even if one is already open. You can also click the Bolt button in the UI.
- **Context Awareness**: Automatically share your current selection or tab with Bolt.
- **File Reference Shortcuts**: Use `Cmd+Option+K` (Mac) or `Alt+Ctrl+K` (Linux/Windows) to insert file references. For example, `@File#L37-42`.

---

## Installation

To install Bolt on VS Code and popular forks like Cursor, Windsurf, VSCodium:

1. Open your IDE's Extension Marketplace.
2. Search for **OpenCode** and click **Install**.
3. Open the integrated terminal and run `opencode`.

If on the other hand you want to use your own IDE when you run `/editor` or `/export` from the TUI, you'll need to set `export EDITOR="code --wait"`. [Learn more](/docs/tui/#editor-setup).

---

### Manual Install

Search for **Bolt** in the Extension Marketplace and click **Install**.

---

### Troubleshooting

If the extension doesn't work after installation:

- Ensure you’re running `opencode` in the integrated terminal.
- Confirm that OpenCode is installed and enabled in your IDE's Extensions view.
- Restart the integrated terminal after installing the extension.
