Una raccolta di progetti della comunità costruiti su xcsh.

:::note
Vuoi aggiungere il tuo progetto legato a xcsh a questa lista? Apri una PR.
:::

Puoi anche dare un'occhiata a [awesome-xcsh](https://github.com/awesome-xcsh/awesome-xcsh) e [xcsh.cafe](https://xcsh.cafe), una comunità che aggrega ecosistema e community.
