مجموعه‌ای از پروژه‌های جامعه که بر پایه OpenCode ساخته شده‌اند.

:::note
می‌خواهید پروژه مرتبط با OpenCode خود را به این فهرست اضافه کنید؟ یک PR ارسال کنید.
:::

همچنین می‌توانید [awesome-opencode](https://github.com/awesome-opencode/awesome-opencode) و [opencode.cafe](https://opencode.cafe) را ببینید، جامعه‌ای که اکوسیستم و جامعه را گردآوری می‌کند.
