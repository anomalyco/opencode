مجموعه‌ای از پروژه‌های جامعه کاربری ساخته‌شده بر پایه OpenCode.

:::note
می‌خواهید پروژه مرتبط با OpenCode خود را به این فهرست اضافه کنید؟ یک PR ارسال کنید.
:::

همچنین می‌توانید [awesome-opencode](https://github.com/awesome-opencode/awesome-opencode) و [opencode.cafe](https://opencode.cafe) را بررسی کنید، جامعه‌ای که اکوسیستم و جامعه کاربری را گردآوری می‌کند.
