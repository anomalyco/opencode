OpenCode از [AI SDK](https://ai-sdk.dev/) و [Models.dev](https://models.dev) برای پشتیبانی از **بیش از ۷۵ ارائه‌دهنده‌ی LLM** استفاده می‌کند و از اجرای مدل‌های محلی نیز پشتیبانی می‌کند.

---

## ارائه‌دهنده‌ها

بیشتر ارائه‌دهنده‌های محبوب به‌صورت پیش‌فرض از پیش بارگذاری شده‌اند. اگر اعتبارنامه‌های یک ارائه‌دهنده را از طریق دستور `/connect` افزوده باشید، هنگام راه‌اندازی OpenCode در دسترس خواهند بود.

درباره‌ی [ارائه‌دهنده‌ها](/docs/providers) بیشتر بدانید.

---

## انتخاب یک مدل

پس از پیکربندی ارائه‌دهنده‌ی خود، می‌توانید مدل دلخواه را با تایپ‌کردن این عبارت انتخاب کنید:

```bash frame="none"
/models
```

---

## مدل‌های توصیه‌شده

مدل‌های زیادی وجود دارند و هر هفته مدل‌های جدیدی عرضه می‌شوند.

:::tip
استفاده از یکی از مدل‌هایی را که توصیه می‌کنیم در نظر بگیرید.
:::

با این حال، تنها تعداد کمی از آن‌ها هم در تولید کد و هم در فراخوانی ابزار خوب هستند.

در اینجا چند مدل آورده شده که با OpenCode به‌خوبی کار می‌کنند، بدون ترتیب خاص. (این نه یک فهرست جامع است و نه لزوماً به‌روز):

- GPT 5.2
- GPT 5.1 Codex
- Claude Opus 4.5
- Claude Sonnet 4.5
- Minimax M2.1
- Gemini 3 Pro

## تعیین یک پیش‌فرض

برای تعیین یکی از این‌ها به‌عنوان مدل پیش‌فرض، می‌توانید کلید `model` را در پیکربندی OpenCode خود تنظیم کنید.

```json title="opencode.json" {3}
{
  "$schema": "https://opencode.ai/config.json",
  "model": "lmstudio/google/gemma-3n-e4b"
}
```

در اینجا شناسه‌ی کامل `provider_id/model_id` است. برای مثال، اگر از [OpenCode Zen](/docs/zen) استفاده می‌کنید، برای GPT 5.1 Codex از `opencode/gpt-5.1-codex` استفاده خواهید کرد.

اگر یک [ارائه‌دهنده‌ی سفارشی](/docs/providers#custom) پیکربندی کرده باشید، `provider_id` کلیدی از بخش `provider` پیکربندی شما است و `model_id` کلیدی از `provider.models` است.

## پیکربندی مدل‌ها

می‌توانید گزینه‌های یک مدل را به‌صورت سراسری از طریق پیکربندی تنظیم کنید.

```jsonc title="opencode.jsonc" {7-12,19-24}
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "openai": {
      "models": {
        "gpt-5": {
          "options": {
            "reasoningEffort": "high",
            "textVerbosity": "low",
            "reasoningSummary": "auto",
            "include": ["reasoning.encrypted_content"],
          },
        },
      },
    },
    "anthropic": {
      "models": {
        "claude-sonnet-4-5-20250929": {
          "options": {
            "thinking": {
              "type": "enabled",
              "budgetTokens": 16000,
            },
          },
        },
      },
    },
  },
}
```

در اینجا تنظیمات سراسری را برای دو مدل داخلی پیکربندی می‌کنیم: `gpt-5` هنگام دسترسی از طریق ارائه‌دهنده‌ی `openai` و `claude-sonnet-4-20250514` هنگام دسترسی از طریق ارائه‌دهنده‌ی `anthropic`.
نام‌های ارائه‌دهنده و مدل داخلی را می‌توان در [Models.dev](https://models.dev) یافت.

همچنین می‌توانید این گزینه‌ها را برای هر عاملی که استفاده می‌کنید پیکربندی کنید. پیکربندی عامل هر گزینه‌ی سراسری اینجا را جایگزین می‌کند. [بیشتر بدانید](/docs/agents/#additional).

همچنین می‌توانید واریانت‌های سفارشی‌ای تعریف کنید که واریانت‌های داخلی را گسترش می‌دهند. واریانت‌ها به شما اجازه می‌دهند تنظیمات مختلفی را برای همان مدل بدون ساختن ورودی‌های تکراری پیکربندی کنید:

```jsonc title="opencode.jsonc" {6-21}
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "opencode": {
      "models": {
        "gpt-5": {
          "variants": {
            "high": {
              "reasoningEffort": "high",
              "textVerbosity": "low",
              "reasoningSummary": "auto",
            },
            "low": {
              "reasoningEffort": "low",
              "textVerbosity": "low",
              "reasoningSummary": "auto",
            },
          },
        },
      },
    },
  },
}
```

## واریانت‌ها

بسیاری از مدل‌ها از چند واریانت با پیکربندی‌های مختلف پشتیبانی می‌کنند. OpenCode با واریانت‌های پیش‌فرض داخلی برای ارائه‌دهنده‌های محبوب عرضه می‌شود.

### واریانت‌های داخلی

OpenCode با واریانت‌های پیش‌فرض برای بسیاری از ارائه‌دهنده‌ها عرضه می‌شود:

**Anthropic**:

- `high` - بودجه‌ی تفکر بالا (پیش‌فرض)
- `max` - حداکثر بودجه‌ی تفکر

**OpenAI**:

بسته به مدل متفاوت است، اما تقریباً:

- `none` - بدون استدلال
- `minimal` - حداقل تلاش استدلالی
- `low` - تلاش استدلالی کم
- `medium` - تلاش استدلالی متوسط
- `high` - تلاش استدلالی بالا
- `xhigh` - تلاش استدلالی بسیار بالا

**Google**:

- `low` - تلاش/بودجه‌ی توکن کمتر
- `high` - تلاش/بودجه‌ی توکن بیشتر

:::tip
این فهرست جامع نیست. بسیاری از ارائه‌دهنده‌های دیگر نیز پیش‌فرض‌های داخلی دارند.
:::

### واریانت‌های سفارشی

می‌توانید واریانت‌های موجود را جایگزین کنید یا واریانت‌های خود را اضافه کنید:

```jsonc title="opencode.jsonc" {7-18}
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "openai": {
      "models": {
        "gpt-5": {
          "variants": {
            "thinking": {
              "reasoningEffort": "high",
              "textVerbosity": "low",
            },
            "fast": {
              "disabled": true,
            },
          },
        },
      },
    },
  },
}
```

### چرخش بین واریانت‌ها

از کلید میان‌بُر `variant_cycle` برای جابه‌جایی سریع بین واریانت‌ها استفاده کنید. [بیشتر بدانید](/docs/keybinds).

## بارگذاری مدل‌ها

هنگامی که OpenCode راه‌اندازی می‌شود، مدل‌ها را به‌ترتیب اولویت زیر بررسی می‌کند:

1. فلگ خط فرمان `--model` یا `-m`. قالب آن همانند فایل پیکربندی است: `provider_id/model_id`.

2. فهرست مدل‌ها در پیکربندی OpenCode.

   ```json title="opencode.json"
   {
     "$schema": "https://opencode.ai/config.json",
     "model": "anthropic/claude-sonnet-4-20250514"
   }
   ```

   قالب در اینجا `provider/model` است.

3. آخرین مدل استفاده‌شده.

4. اولین مدل با استفاده از یک اولویت داخلی.
