OpenCode از [AI SDK](https://ai-sdk.dev/) و [Models.dev](https://models.dev) برای پشتیبانی از **۷۵+ ارائه‌دهنده LLM** استفاده می‌کند و اجرای مدل‌های محلی را نیز پشتیبانی می‌کند.

---

## ارائه‌دهنده‌ها

بیشتر ارائه‌دهنده‌های محبوب به طور پیش‌فرض از پیش بارگذاری شده‌اند. اگر اعتبارنامه‌های یک ارائه‌دهنده را از طریق دستور `/connect` افزوده‌اید، هنگام شروع OpenCode در دسترس خواهند بود.

درباره [ارائه‌دهنده‌ها](/docs/providers) بیشتر بیاموزید.

---

## انتخاب یک مدل

وقتی ارائه‌دهنده خود را پیکربندی کردید، می‌توانید مدل دلخواه را با تایپ کردن موارد زیر انتخاب کنید:

```bash frame="none"
/models
```

---

## مدل‌های پیشنهادی

مدل‌های زیادی در بیرون وجود دارند، و هر هفته مدل‌های جدیدی منتشر می‌شوند.

:::tip
استفاده از یکی از مدل‌هایی را که پیشنهاد می‌کنیم در نظر بگیرید.
:::

با این حال، فقط تعداد انگشت‌شماری از آن‌ها در هر دو کار تولید کد و فراخوانی ابزار (tool calling) خوب عمل می‌کنند.

در اینجا چند مدل که با OpenCode به خوبی کار می‌کنند آورده شده است، بدون ترتیب خاص. (این فهرست جامع نیست و لزوماً به‌روز نیست):

- GPT 5.2
- GPT 5.1 Codex
- Claude Opus 4.5
- Claude Sonnet 4.5
- Minimax M2.1
- Gemini 3 Pro

## تنظیم یک پیش‌فرض

برای تنظیم یکی از این مدل‌ها به عنوان مدل پیش‌فرض، می‌توانید کلید `model` را در پیکربندی OpenCode خود تنظیم کنید.

```json title="opencode.json" {3}
{
  "$schema": "https://opencode.ai/config.json",
  "model": "lmstudio/google/gemma-3n-e4b"
}
```

در اینجا شناسه کامل برابر است با `provider_id/model_id`. به عنوان مثال، اگر از [OpenCode Zen](/docs/zen) استفاده می‌کنید، برای GPT 5.1 Codex از `opencode/gpt-5.1-codex` استفاده می‌کنید.

اگر یک [ارائه‌دهنده سفارشی](/docs/providers#custom) پیکربندی کرده‌اید، `provider_id` کلید بخش `provider` در پیکربندی شماست، و `model_id` کلید بخش `provider.models` است.

## پیکربندی مدل‌ها

می‌توانید گزینه‌های یک مدل را به صورت سراسری از طریق پیکربندی تنظیم کنید.

```jsonc title="opencode.jsonc" {7-12,19-24}
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "openai": {
      "models": {
        "gpt-5": {
          "options": {
            "reasoningEffort": "high",
            "textVerbosity": "low",
            "reasoningSummary": "auto",
            "include": ["reasoning.encrypted_content"],
          },
        },
      },
    },
    "anthropic": {
      "models": {
        "claude-sonnet-4-5-20250929": {
          "options": {
            "thinking": {
              "type": "enabled",
              "budgetTokens": 16000,
            },
          },
        },
      },
    },
  },
}
```

در اینجا در حال پیکربندی تنظیمات سراسری برای دو مدل داخلی هستیم: `gpt-5` وقتی از طریق ارائه‌دهنده `openai` دسترسی پیدا می‌کند، و `claude-sonnet-4-20250514` وقتی از طریق ارائه‌دهنده `anthropic` دسترسی پیدا می‌کند.
نام‌های ارائه‌دهنده و مدل داخلی را می‌توانید در [Models.dev](https://models.dev) بیابید.

همچنین می‌توانید این گزینه‌ها را برای هر عاملی که استفاده می‌کنید پیکربندی کنید. پیکربندی عامل هر گزینه سراسری اینجا را بازنویسی می‌کند. [بیشتر بیاموزید](/docs/agents/#additional).

همچنین می‌توانید متغیرهای (variants) سفارشی تعریف کنید که موارد داخلی را توسعه می‌دهند. متغیرها به شما اجازه می‌دهند تنظیمات متفاوتی را برای یک مدل یکسان بدون ایجاد ورودی‌های تکراری پیکربندی کنید:

```jsonc title="opencode.jsonc" {6-21}
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "opencode": {
      "models": {
        "gpt-5": {
          "variants": {
            "high": {
              "reasoningEffort": "high",
              "textVerbosity": "low",
              "reasoningSummary": "auto",
            },
            "low": {
              "reasoningEffort": "low",
              "textVerbosity": "low",
              "reasoningSummary": "auto",
            },
          },
        },
      },
    },
  },
}
```

## متغیرها

بسیاری از مدل‌ها چندین متغیر با پیکربندی‌های متفاوت پشتیبانی می‌کنند. OpenCode متغیرهای پیش‌فرض داخلی را برای ارائه‌دهنده‌های محبوب عرضه می‌کند.

### متغیرهای داخلی

OpenCode متغیرهای پیش‌فرض را برای بسیاری از ارائه‌دهنده‌ها عرضه می‌کند:

**Anthropic**:

- `high` - سقف تفکر بالا (پیش‌فرض)
- `max` - حداکثر سقف تفکر

**OpenAI**:

بسته به مدل متفاوت است اما تقریباً:

- `none` - بدون استنتاج
- `minimal` - حداقل تلاش استنتاج
- `low` - تلاش استنتاج کم
- `medium` - تلاش استنتاج متوسط
- `high` - تلاش استنتاج بالا
- `xhigh` - تلاش استنتاج بسیار بالا

**Google**:

- `low` - سقف تلاش/توکن پایین
- `high` - سقف تلاش/توکن بالا

:::tip
این فهرست جامع نیست. بسیاری دیگر از ارائه‌دهنده‌ها نیز پیش‌فرض‌های داخلی دارند.
:::

### متغیرهای سفارشی

می‌توانید متغیرهای موجود را بازنویسی کنید یا متغیرهای خود را اضافه کنید:

```jsonc title="opencode.jsonc" {7-18}
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "openai": {
      "models": {
        "gpt-5": {
          "variants": {
            "thinking": {
              "reasoningEffort": "high",
              "textVerbosity": "low",
            },
            "fast": {
              "disabled": true,
            },
          },
        },
      },
    },
  },
}
```

### چرخش متغیرها

از کلید میانبر `variant_cycle` برای جابجایی سریع بین متغیرها استفاده کنید. [بیشتر بیاموزید](/docs/keybinds).

## بارگذاری مدل‌ها

وقتی OpenCode شروع می‌شود، مدل‌ها را به ترتیب اولویت زیر بررسی می‌کند:

1. پرچم خط فرمان `--model` یا `-m`. فرمت مشابه فایل پیکربندی است: `provider_id/model_id`.

2. فهرست مدل در پیکربندی OpenCode.

   ```json title="opencode.json"
   {
     "$schema": "https://opencode.ai/config.json",
     "model": "anthropic/claude-sonnet-4-20250514"
   }
   ```

   فرمت در اینجا برابر است با `provider/model`.

3. آخرین مدل استفاده‌شده.

4. اولین مدل با استفاده از یک اولویت داخلی.
