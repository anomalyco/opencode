OpenCode می‌تواند به‌عنوان یک برنامه‌ی وب در مرورگر شما اجرا شود و همان تجربه‌ی قدرتمند برنامه‌نویسی با هوش مصنوعی را بدون نیاز به ترمینال در اختیار شما بگذارد.

![OpenCode Web - جلسه جدید](../../../assets/web/web-homepage-new-session.png)

## شروع به کار

رابط وب را با اجرای دستور زیر آغاز کنید:

```bash
opencode web
```

این کار یک سرور محلی روی `127.0.0.1` با یک پورت تصادفی در دسترس راه‌اندازی می‌کند و OpenCode را به‌طور خودکار در مرورگر پیش‌فرض شما باز می‌کند.

:::caution
اگر `OPENCODE_SERVER_PASSWORD` تنظیم نشده باشد، سرور بدون محافظت خواهد بود. این برای استفاده‌ی محلی مناسب است، اما باید برای دسترسی شبکه‌ای تنظیم شود.
:::

:::tip[کاربران Windows]
برای بهترین تجربه، `opencode web` را از [WSL](/docs/windows-wsl) اجرا کنید نه از PowerShell. این کار دسترسی صحیح به سیستم فایل و یکپارچگی ترمینال را تضمین می‌کند.
:::

## پیکربندی

می‌توانید سرور وب را با استفاده از پرچم‌های خط فرمان یا در [فایل پیکربندی](/docs/config) خود پیکربندی کنید.

### پورت

به‌طور پیش‌فرض، OpenCode یک پورت در دسترس را انتخاب می‌کند. می‌توانید یک پورت مشخص کنید:

```bash
opencode web --port 4096
```

### نام میزبان

به‌طور پیش‌فرض، سرور به `127.0.0.1` (تنها localhost) متصل می‌شود. برای در دسترس قراردادن OpenCode روی شبکه‌ی خود:

```bash
opencode web --hostname 0.0.0.0
```

هنگام استفاده از `0.0.0.0`، OpenCode هم نشانی‌های محلی و هم نشانی‌های شبکه را نمایش می‌دهد:

```
  Local access:       http://localhost:4096
  Network access:     http://192.168.1.100:4096
```

### کشف mDNS

mDNS را فعال کنید تا سرور شما روی شبکه‌ی محلی قابل کشف شود:

```bash
opencode web --mdns
```

این کار به‌طور خودکار نام میزبان را روی `0.0.0.0` تنظیم می‌کند و سرور را با نام `opencode.local` معرفی می‌کند.

می‌توانید نام دامنه‌ی mDNS را سفارشی کنید تا چند نمونه را روی یک شبکه اجرا کنید:

```bash
opencode web --mdns --mdns-domain myproject.local
```

### CORS

برای مجازکردن دامنه‌های اضافی برای CORS (مفید برای فرانت‌اندهای سفارشی):

```bash
opencode web --cors https://example.com
```

### احراز هویت

برای محافظت از دسترسی، یک رمز عبور را با استفاده از متغیر محیطی `OPENCODE_SERVER_PASSWORD` تنظیم کنید:

```bash
OPENCODE_SERVER_PASSWORD=secret opencode web
```

نام کاربری به‌طور پیش‌فرض `opencode` است اما می‌توان آن را با `OPENCODE_SERVER_USERNAME` تغییر داد.

## استفاده از رابط وب

پس از راه‌اندازی، رابط وب دسترسی به جلسات OpenCode شما را فراهم می‌کند.

### جلسات

جلسات خود را از صفحه‌ی اصلی مشاهده و مدیریت کنید. می‌توانید جلسات فعال را ببینید و جلسات جدیدی را آغاز کنید.

![OpenCode Web - جلسه فعال](../../../assets/web/web-homepage-active-session.png)

### وضعیت سرور

روی "See Servers" کلیک کنید تا سرورهای متصل و وضعیت آن‌ها را ببینید.

![OpenCode Web - See Servers](../../../assets/web/web-homepage-see-servers.png)

## اتصال یک ترمینال

می‌توانید یک TUI ترمینال را به یک سرور وب در حال اجرا متصل کنید:

```bash
# سرور وب را راه‌اندازی کنید
opencode web --port 4096

# در ترمینالی دیگر، TUI را متصل کنید
opencode attach http://localhost:4096
```

این کار به شما اجازه می‌دهد هم‌زمان از رابط وب و ترمینال استفاده کنید، در حالی که همان جلسات و وضعیت را به اشتراک می‌گذارند.

## فایل پیکربندی

می‌توانید تنظیمات سرور را در فایل پیکربندی `opencode.json` خود نیز پیکربندی کنید:

```json
{
  "server": {
    "port": 4096,
    "hostname": "0.0.0.0",
    "mdns": true,
    "cors": ["https://example.com"]
  }
}
```

پرچم‌های خط فرمان بر تنظیمات فایل پیکربندی اولویت دارند.
