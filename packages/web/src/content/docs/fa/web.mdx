OpenCode می‌تواند به عنوان یک برنامه وب در مرورگر شما اجرا شود و همان تجربه کدنویسی قدرتمند هوش مصنوعی را بدون نیاز به ترمینال فراهم کند.

![OpenCode Web - New Session](../../../assets/web/web-homepage-new-session.png)

## شروع به کار

رابط وب را با اجرای دستور زیر شروع کنید:

```bash
opencode web
```

این کار یک سرور محلی روی `127.0.0.1` با یک درگاه (port) تصادفی در دسترس راه‌اندازی می‌کند و OpenCode را به طور خودکار در مرورگر پیش‌فرض شما باز می‌کند.

:::caution
اگر `OPENCODE_SERVER_PASSWORD` تنظیم نشده باشد، سرور بدون امنیت خواهد بود. این برای استفاده محلی مناسب است اما برای دسترسی شبکه‌ای باید تنظیم شود.
:::

:::tip[کاربران ویندوز]
برای بهترین تجربه، دستور `opencode web` را از [WSL](/docs/windows-wsl) اجرا کنید نه PowerShell. این دسترسی صحیح به سیستم پرونده و یکپارچگی ترمینال را تضمین می‌کند.
:::

## پیکربندی

می‌توانید سرور وب را با استفاده از پرچم‌های (flags) خط فرمان یا در [فایل پیکربندی](/docs/config) خود پیکربندی کنید.

### درگاه

به طور پیش‌فرض، OpenCode یک درگاه در دسترس را انتخاب می‌کند. می‌توانید یک درگاه را مشخص کنید:

```bash
opencode web --port 4096
```

### نام میزبان

به طور پیش‌فرض، سرور به `127.0.0.1` (فقط localhost) متصل می‌شود. برای در دسترس قرار دادن OpenCode روی شبکه خود:

```bash
opencode web --hostname 0.0.0.0
```

هنگام استفاده از `0.0.0.0`، OpenCode هر دو نشانی محلی و شبکه‌ای را نمایش می‌دهد:

```
  Local access:       http://localhost:4096
  Network access:     http://192.168.1.100:4096
```

### کشف mDNS

mDNS را فعال کنید تا سرور شما روی شبکه محلی قابل کشف شود:

```bash
opencode web --mdns
```

این کار به طور خودکار نام میزبان را روی `0.0.0.0` قرار می‌دهد و سرور را به عنوان `opencode.local` اعلان (advertise) می‌کند.

می‌توانید نام دامنه mDNS را سفارشی کنید تا چندین نمونه روی یک شبکه مشابه اجرا شوند:

```bash
opencode web --mdns --mdns-domain myproject.local
```

### CORS

برای اجازه دادن به دامنه‌های اضافی برای CORS (مفید برای فرانت‌اندهای سفارشی):

```bash
opencode web --cors https://example.com
```

### احراز هویت

برای محافظت از دسترسی، یک گذرواژه را با استفاده از متغیر محیطی `OPENCODE_SERVER_PASSWORD` تنظیم کنید:

```bash
OPENCODE_SERVER_PASSWORD=secret opencode web
```

نام کاربری پیش‌فرض `opencode` است اما می‌توان آن را با `OPENCODE_SERVER_USERNAME` تغییر داد.

## استفاده از رابط وب

پس از شروع، رابط وب دسترسی به نشست‌های (sessions) OpenCode شما را فراهم می‌کند.

### نشست‌ها

نشست‌های خود را از صفحه اصلی مشاهده و مدیریت کنید. می‌توانید نشست‌های فعال را ببینید و نشست‌های جدیدی شروع کنید.

![OpenCode Web - Active Session](../../../assets/web/web-homepage-active-session.png)

### وضعیت سرور

روی «See Servers» کلیک کنید تا سرورهای متصل و وضعیت آن‌ها را مشاهده کنید.

![OpenCode Web - See Servers](../../../assets/web/web-homepage-see-servers.png)

## اتصال یک ترمینال

می‌توانید یک ترمینال TUI را به یک سرور وب در حال اجرا متصل کنید:

```bash
# Start the web server
opencode web --port 4096

# In another terminal, attach the TUI
opencode attach http://localhost:4096
```

این به شما اجازه می‌دهد همزمان از رابط وب و ترمینال استفاده کنید و همان نشست‌ها و وضعیت را به اشتراک بگذارید.

## فایل پیکربندی

همچنین می‌توانید تنظیمات سرور را در فایل پیکربندی `opencode.json` خود پیکربندی کنید:

```json
{
  "server": {
    "port": 4096,
    "hostname": "0.0.0.0",
    "mdns": true,
    "cors": ["https://example.com"]
  }
}
```

پرچم‌های خط فرمان بر تنظیمات فایل پیکربندی اولویت دارند.
