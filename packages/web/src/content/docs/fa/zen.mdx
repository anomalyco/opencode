OpenCode Zen فهرستی از مدل‌های آزمایش‌شده و تأییدشده ارائه‌شده توسط تیم OpenCode است.

Zen دقیقاً مانند هر ارائه‌دهنده دیگری در OpenCode کار می‌کند. وارد OpenCode Zen می‌شوید و کلید API خود را دریافت می‌کنید. این گزینه **کاملاً اختیاری** است و برای استفاده از OpenCode نیازی به استفاده از آن ندارید.

---

## پیش‌زمینه

مدل‌های بسیار زیادی وجود دارد اما تنها تعداد کمی از این مدل‌ها به‌عنوان عامل کدنویسی به‌خوبی عمل می‌کنند. علاوه بر این، اکثر ارائه‌دهندگان پیکربندی بسیار متفاوتی دارند؛ بنابراین عملکرد و کیفیت بسیار متفاوتی دریافت می‌کنید.

:::tip
ما گروهی گزینش‌شده از مدل‌ها و ارائه‌دهندگانی را آزمایش کردیم که با OpenCode به‌خوبی کار می‌کنند.
:::

بنابراین اگر مدلی را از طریق چیزی مانند OpenRouter استفاده می‌کنید، هرگز نمی‌توانید مطمئن باشید که بهترین نسخه مدل مورد نظرتان را دریافت می‌کنید.

برای رفع این مشکل، ما چند کار انجام دادیم:

1. گروهی گزینش‌شده از مدل‌ها را آزمایش کردیم و با تیم‌هایشان درباره بهترین نحوه اجرای آن‌ها صحبت کردیم.
2. سپس با چند ارائه‌دهنده همکاری کردیم تا مطمئن شویم این مدل‌ها به‌درستی ارائه می‌شوند.
3. در نهایت، ترکیب مدل/ارائه‌دهنده را بنچمارک کردیم و به فهرستی رسیدیم که توصیه کردن آن را با خیال راحت انجام می‌دهیم.

OpenCode Zen یک درگاه هوش مصنوعی است که دسترسی شما به این مدل‌ها را فراهم می‌کند.

---

## نحوه کار

OpenCode Zen دقیقاً مانند هر ارائه‌دهنده دیگری در OpenCode کار می‌کند.

1. وارد **<a href={console}>OpenCode Zen</a>** می‌شوید، جزئیات صورت‌حساب خود را اضافه می‌کنید و کلید API خود را کپی می‌کنید.
2. دستور `/connect` را در TUI اجرا می‌کنید، OpenCode Zen را انتخاب می‌کنید و کلید API خود را جای‌می‌گذارید.
3. برای دیدن فهرست مدل‌هایی که توصیه می‌کنیم، `/models` را در TUI اجرا کنید.

هزینه به ازای هر درخواست از شما کسر می‌شود و می‌توانید اعتبار به حساب خود اضافه کنید.

### بارگذاری خودکار

اگر موجودی شما کمتر از ۵ دلار شود، Zen به‌طور خودکار ۲۰ دلار شارژ مجدد می‌کند.

می‌توانید مبلغ شارژ مجدد خودکار را تغییر دهید. همچنین می‌توانید شارژ مجدد خودکار را کاملاً غیرفعال کنید.

---

### محدودیت‌های ماهانه

همچنین می‌توانید یک محدودیت استفاده ماهانه برای کل فضای کاری و برای هر یک از
اعضای تیم خود تعیین کنید.

برای مثال، فرض کنید محدودیت استفاده ماهانه را ۲۰ دلار قرار داده‌اید، Zen در یک ماه
بیش از ۲۰ دلار استفاده نمی‌کند. اما اگر شارژ مجدد خودکار را فعال کرده باشید، Zen ممکن است
اگر موجودی شما کمتر از ۵ دلار شود، در نهایت بیش از ۲۰ دلار از شما هزینه کند.

## حریم خصوصی

تمام مدل‌های ما در ایالات متحده میزبانی می‌شوند. ارائه‌دهندگان ما سیاست عدم نگهداری (zero-retention) را دنبال می‌کنند و داده‌های شما را برای آموزش مدل استفاده نمی‌کنند، با استثناهای زیر:

- Big Pickle: در دوره رایگان آن، داده‌های جمع‌آوری‌شده ممکن است برای بهبود مدل استفاده شوند.
- DeepSeek V4 Flash Free: در دوره رایگان آن، داده‌های جمع‌آوری‌شده ممکن است برای بهبود مدل استفاده شوند.
- MiMo-V2.5 Free: در دوره رایگان آن، داده‌های جمع‌آوری‌شده ممکن است برای بهبود مدل استفاده شوند.
- North Mini Code Free: در دوره رایگان آن، داده‌ها ممکن است نگهداری و برای بهبود مدل استفاده شوند. اطلاعات شخصی یا محرمانه ارسال نکنید. [شرایط استفاده](https://cohere.com/terms-of-use) و [سیاست حریم خصوصی](https://cohere.com/privacy) ما را ببینید.
- Nemotron 3 Ultra Free (نقاط پایانی رایگان NVIDIA): فقط استفاده آزمایشی — اطلاعات شخصی یا محرمانه ارسال نکنید. استفاده شما برای اهداف امنیتی و بهبود محصولات و خدمات NVIDIA ثبت می‌شود. داده نشست ثبت‌شده برای بهبود، به هویت یا شناسه پایدار شما پیوند داده نمی‌شود. برای اطلاعات بیشتر درباره شیوه‌های پردازش داده ما، [سیاست حریم خصوصی](https://assets.ngc.nvidia.com/products/api-catalog/legal/NVIDIA%20API%20Trial%20Terms%20of%20Service.pdf) ما را ببینید. با تعامل با این نقطه پایانی، با جمع‌آوری، ضبط و استفاده ما از چنین اطلاعاتی و [شرایط خدمات آزمایشی API نVIDIA](https://assets.ngc.nvidia.com/products/api-catalog/legal/NVIDIA%20API%20Trial%20Terms%20of%20Service.pdf) موافقت می‌کنید.
- OpenAI APIs: درخواست‌ها طبق [سیاست‌های داده OpenAI](https://platform.openai.com/docs/guides/your-data) به مدت ۳۰ روز نگهداری می‌شوند.
- Anthropic APIs: درخواست‌ها طبق [سیاست‌های داده Anthropic](https://docs.anthropic.com/en/docs/claude-code/data-usage) به مدت ۳۰ روز نگهداری می‌شوند.

## برای تیم‌ها

Zen برای تیم‌ها نیز عالی عمل می‌کند. می‌توانید هم‌تیمی‌ها را دعوت کنید، نقش اختصاص دهید، مدل‌هایی که تیمتان استفاده می‌کند را انتخاب کنید و بیشتر.

:::note
فضاهای کاری در حال حاضر به عنوان بخشی از نسخه آزمایشی (beta) برای تیم‌ها رایگان است.
:::

مدیریت فضای کاری شما در حال حاضر به عنوان بخشی از نسخه آزمایشی برای تیم‌ها رایگان است. جزئیات بیشتری درباره قیمت‌گذاری را به‌زودی به اشتراک خواهیم گذاشت.

---

### نقش‌ها

می‌توانید هم‌تیمی‌ها را به فضای کاری خود دعوت کرده و نقش اختصاص دهید:

- **مدیر (Admin)**: مدیریت مدل‌ها، اعضا، کلیدهای API و صورت‌حساب
- **عضو (Member)**: مدیریت فقط کلیدهای API خودش

مدیران همچنین می‌توانند محدودیت هزینه ماهانه برای هر عضو تعیین کنند تا هزینه‌ها تحت کنترل بماند.

---

### دسترسی به مدل

مدیران می‌توانند مدل‌های خاصی را برای فضای کاری فعال یا غیرفعال کنند. درخواست‌های ارسالی به یک مدل غیرفعال با خطا مواجه می‌شوند.

این برای مواردی مفید است که می‌خواهید استفاده از مدلی که داده جمع‌آوری می‌کند را غیرفعال کنید.

---

### کلید خودتان را بیاورید

می‌توانید از کلیدهای API اختصاصی OpenAI یا Anthropic خود استفاده کنید، در حالی که همچنان به سایر مدل‌ها در Zen دسترسی دارید.

هنگامی که از کلیدهای خود استفاده می‌کنید، توکن‌ها مستقیماً توسط ارائه‌دهنده صورت‌حساب می‌شوند، نه توسط Zen.

برای مثال، سازمان شما ممکن است از قبل کلیدی برای OpenAI یا Anthropic داشته باشد و بخواهید به جای کلیدی که Zen ارائه می‌دهد از آن استفاده کنید.

---

## اهداف

ما OpenCode Zen را ایجاد کردیم تا:

1. **بنچمارک** بهترین مدل‌ها/ارائه‌دهندگان برای عامل‌های کدنویسی.
2. دسترسی به گزینه‌های **باکیفیت‌ترین** داشته باشیم و عملکرد را تنزل ندهیم یا به ارائه‌دهندگان ارزان‌تر مسیریابی نکنیم.
3. هرگونه **کاهش قیمت** را با فروش به قیمت تمام‌شده منتقل کنیم؛ بنابراین تنها افزایش قیمت برای پوشش هزینه‌های پردازش ماست.
4. **بدون قفل شدن** با اجازه دادن به استفاده از آن با هر عامل کدنویسی دیگری. و همیشه اجازه دهید با هر ارائه‌دهنده دیگری در OpenCode نیز استفاده کنید.
