دستور `opencode serve` یک سرور HTTP بدون واجهه (headless) اجرا می‌کند که یک نقطه پایانی OpenAPI را در دسترس قرار می‌دهد تا یک کلاینت opencode بتواند از آن استفاده کند.

---

### استفاده

```bash
opencode serve [--port <number>] [--hostname <string>] [--cors <origin>]
```

#### گزینه‌ها

| پرچم            | توضیحات                                | پیش‌فرض          |
| --------------- | -------------------------------------- | ---------------- |
| `--port`        | پورتی که روی آن گوش داده می‌شود         | `4096`           |
| `--hostname`    | نام میزبانی که روی آن گوش داده می‌شود   | `127.0.0.1`      |
| `--mdns`        | فعال‌سازی کشف mDNS                      | `false`          |
| `--mdns-domain` | نام دامنه سفارشی برای سرویس mDNS        | `opencode.local` |
| `--cors`        | مبدأهای مرورگر (Origins) اضافی مجاز     | `[]`             |

`--cors` را می‌توان چندین بار پاس داد:

```bash
opencode serve --cors http://localhost:5173 --cors https://app.example.com
```

---

### احراز هویت

برای محافظت از سرور با احراز هویت پایه HTTP، مقدار `OPENCODE_SERVER_PASSWORD` را تنظیم کنید. نام کاربری به‌طور پیش‌فرض `opencode` است، یا برای بازنویسی آن `OPENCODE_SERVER_USERNAME` را تنظیم کنید. این مورد هم برای `opencode serve` و هم برای `opencode web` اعمال می‌شود.

```bash
OPENCODE_SERVER_PASSWORD=your-password opencode serve
```

---

### چگونه کار می‌کند

وقتی `opencode` را اجرا می‌کنید، یک TUI و یک سرور را راه‌اندازی می‌کند. جایی که TUI همان کلاینتی است که با سرور صحبت می‌کند. سرور یک نقطه پایانی مشخصات OpenAPI 3.1 را در دسترس قرار می‌دهد. این نقطه پایانی برای تولید یک [SDK](/docs/sdk) نیز استفاده می‌شود.

:::tip
از سرور opencode برای تعامل برنامه‌نویسی‌شده (programmatic) با opencode استفاده کنید.
:::

این معماری به opencode اجازه می‌دهد از چندین کلاینت پشتیبانی کند و به شما امکان می‌دهد به‌صورت برنامه‌نویسی‌شده با opencode تعامل داشته باشید.

می‌توانید `opencode serve` را برای راه‌اندازی یک سرور مستقل اجرا کنید. اگر TUI ی opencode در حال اجرا باشد، `opencode serve` یک سرور جدید راه‌اندازی می‌کند.

---

#### اتصال به یک سرور موجود

وقتی TUI را راه‌اندازی می‌کنید، به‌طور تصادفی یک پورت و نام میزبان اختصاص می‌دهد. در عوض می‌توانید [پرچم‌های](/docs/cli) `--hostname` و `--port` را پاس دهید. سپس از آن‌ها برای اتصال به سرور آن استفاده کنید.

از نقطه پایانی [`/tui`](#tui) می‌توان برای هدایت TUI از طریق سرور استفاده کرد. برای مثال، می‌توانید یک پرامپت را از پیش پر کنید یا اجرا کنید. این تنظیمات توسط افزونه‌های [IDE](/docs/ide) ی OpenCode استفاده می‌شود.

## مشخصات (Spec)

سرور یک مشخصات OpenAPI 3.1 منتشر می‌کند که می‌توان آن را در آدرس زیر مشاهده کرد:

```
http://<hostname>:<port>/doc
```

برای مثال، `http://localhost:4096/doc`. از این مشخصات برای تولید کلاینت‌ها یا بازرسی انواع درخواست و پاسخ استفاده کنید. یا آن را در یک کاوشگر Swagger مشاهده کنید.

### فایل‌ها

| متد   | مسیر                     | توضیحات                              | پاسخ                                                                                         |
| ----- | ------------------------ | ------------------------------------ | ------------------------------------------------------------------------------------------- |
| `GET` | `/find?pattern=<pat>`    | جستجوی متن در فایل‌ها                 | آرایه‌ای از اشیاء تطبیق با `path`، `lines`، `line_number`، `absolute_offset`، `submatches`   |
| `GET` | `/find/file?query=<q>`   | یافتن فایل‌ها و دایرکتوری‌ها بر اساس نام | `string[]` (مسیرها)                                                                       |
| `GET` | `/find/symbol?query=<q>` | یافتن نمادهای فضای کاری               | <a href={typesUrl}><code>Symbol[]</code></a>                                                |
| `GET` | `/file?path=<path>`      | فهرست فایل‌ها و دایرکتوری‌ها          | <a href={typesUrl}><code>FileNode[]</code></a>                                              |
| `GET` | `/file/content?path=<p>` | خواندن یک فایل                        | <a href={typesUrl}><code>FileContent</code></a>                                             |
| `GET` | `/file/status`           | دریافت وضعیت فایل‌های ردیابی‌شده      | <a href={typesUrl}><code>File[]</code></a>                                                  |

#### پارامترهای کوئری `/find/file`

- `query` (الزامی) — رشته جستجو (تطبیق فازی)
- `type` (اختیاری) — محدود کردن نتایج به `"file"` یا `"directory"`
- `directory` (اختیاری) — بازنویسی ریشه پروژه برای جستجو
- `limit` (اختیاری) — حداکثر نتایج (۱ تا ۲۰۰)
- `dirs` (اختیاری) — پرچم قدیمی (`"false"` فقط فایل‌ها را برمی‌گرداند)
