اگرچه OpenCode می‌تواند مستقیماً روی ویندوز اجرا شود، ما برای بهترین تجربه استفاده از [زیرسیستم ویندوز برای لینوکس (WSL)](https://learn.microsoft.com/en-us/windows/wsl/install) را توصیه می‌کنیم. WSL محیط لینوکسی ارائه می‌دهد که به‌خوبی با ویژگی‌های OpenCode هماهنگ است.

:::tip[چرا WSL؟]
WSL عملکرد بهتر سیستم پرونده، پشتیبانی کامل از ترمینال و سازگاری با ابزارهای توسعه‌ای که OpenCode به آن‌ها متکی است را فراهم می‌کند.
:::

---

## راه‌اندازی

<Steps>

1. **نصب WSL**

   اگر هنوز نصب نکرده‌اید، [نصب WSL](https://learn.microsoft.com/en-us/windows/wsl/install) را با استفاده از راهنمای رسمی مایکروسافت انجام دهید.

2. **نصب OpenCode در WSL**

   پس از راه‌اندازی WSL، ترمینال WSL خود را باز کنید و OpenCode را با یکی از [روش‌های نصب](/docs/) نصب کنید.

   ```bash
   curl -fsSL https://opencode.ai/install | bash
   ```

3. **استفاده از OpenCode از طریق WSL**

   به فهرست پروژه خود بروید (دسترسی به پرونده‌های ویندوز از طریق `/mnt/c/`، `/mnt/d/` و غیره) و OpenCode را اجرا کنید.

   ```bash
   cd /mnt/c/Users/YourName/project
   opencode
   ```

</Steps>

## برنامه دسکتاپ + سرور WSL

اگر ترجیح می‌دهید از برنامه دسکتاپ OpenCode استفاده کنید اما می‌خواهید سرور در WSL اجرا شود:

1. **راه‌اندازی سرور در WSL** با `--hostname 0.0.0.0` برای اجازه دادن به اتصالات خارجی:

   ```bash
   opencode serve --hostname 0.0.0.0 --port 4096
   ```

2. **اتصال برنامه دسکتاپ** به `http://localhost:4096`

:::note
اگر `localhost` در تنظیمات شما کار نمی‌کند، از نشانی IP WSL به جای آن استفاده کنید (در WSL: `hostname -I`) و از `http://<wsl-ip>:4096` استفاده کنید.
:::

:::caution
هنگام استفاده از `--hostname 0.0.0.0`، برای ایمن کردن سرور `OPENCODE_SERVER_PASSWORD` را تنظیم کنید.
:::

```bash
OPENCODE_SERVER_PASSWORD=your-password opencode serve --hostname 0.0.0.0
```

## کلاینت وب + WSL

برای بهترین تجربه وب روی ویندوز:

1. **اجرای `opencode web` در ترمینال WSL** به جای PowerShell:

   ```bash
   opencode web --hostname 0.0.0.0
   ```

2. **دسترسی از مرورگر ویندوز خود** در `http://localhost:<port>` (OpenCode نشانی را چاپ می‌کند)

اجرای `opencode web` از طریق WSL دسترسی صحیح به سیستم پرونده و یکپارچگی ترمینال را تضمین می‌کند، در حالی که همچنان از مرورگر ویندوز قابل دسترسی است.

---

## دسترسی به پرونده‌های ویندوز

WSL می‌تواند به تمام پرونده‌های ویندوز شما از طریق فهرست `/mnt/` دسترسی داشته باشد:

- درایو `C:` → `/mnt/c/`
- درایو `D:` → `/mnt/d/`
- و غیره...

مثال:

```bash
cd /mnt/c/Users/YourName/Documents/project
opencode
```

:::tip
برای صاف‌ترین تجربه، در نظر بگیرید که مخزن خود را در سیستم پرونده WSL (برای مثال در `~/code/`) کلون/کپی کنید و OpenCode را در آنجا اجرا کنید.
:::

---

## نکات

- OpenCode را در WSL برای پروژه‌هایی که روی درایوهای ویندوز ذخیره شده‌اند در حال اجرا نگه دارید - دسترسی به پرونده‌ها یکپارچه است
- از [افزونه WSL](https://code.visualstudio.com/docs/remote/wsl) مربوط به VS Code در کنار OpenCode برای جریان کاری توسعه یکپارچه استفاده کنید
- پیکربندی و نشست‌های OpenCode شما در محیط WSL در مسیر `~/.local/share/opencode/` ذخیره می‌شوند
