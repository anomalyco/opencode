OpenCode با VS Code، Cursor یا هر محیط توسعه‌ای که از ترمینال پشتیبانی می‌کند یکپارچه است. کافی است برای شروع `opencode` را در ترمینال اجرا کنید.

---

## نحوه استفاده

- **راه‌اندازی سریع**: برای باز کردن OpenCode در نمای ترمینال تقسیم‌شده، از `Cmd+Esc` (مک) یا `Ctrl+Esc` (ویندوز/لینوکس) استفاده کنید، یا اگر نشست ترمینالی در حال اجرا وجود دارد، روی آن تمرکز کنید.
- **نشست جدید**: برای شروع یک نشست ترمینالی جدید OpenCode، حتی اگر یکی باز باشد، از `Cmd+Shift+Esc` (مک) یا `Ctrl+Shift+Esc` (ویندوز/لینوکس) استفاده کنید. همچنین می‌توانید روی دکمه OpenCode در رابط کاربری کلیک کنید.
- **آگاهی از بافتار**: انتخاب یا زبانه فعلی شما به‌طور خودکار با OpenCode به اشتراک گذاشته می‌شود.
- **میان‌برهای ارجاع به پرونده**: برای درج ارجاع پرونده‌ها از `Cmd+Option+K` (مک) یا `Alt+Ctrl+K` (لینوکس/ویندوز) استفاده کنید. برای مثال `@File#L37-42`.

---

## نصب

برای نصب OpenCode روی VS Code و انشعاب‌های محبوبی مانند Cursor، Windsurf، VSCodium:

1. VS Code را باز کنید
2. ترمینال داخلی را باز کنید
3. اجرای `opencode` - افزونه به‌طور خودکار نصب می‌شود

از سوی دیگر، اگر می‌خواهید هنگام اجرای `/editor` یا `/export` از TUI از محیط توسعه خودتان استفاده کنید، باید `export EDITOR="code --wait"` را تنظیم کنید. [اطلاعات بیشتر](/docs/tui/#editor-setup).

---

### نصب دستی

**OpenCode** را در فروشگاه افزونه‌ها جستجو کنید و روی **نصب** کلیک کنید.

---

### عیب‌یابی

اگر نصب افزونه به‌طور خودکار انجام نشد:

- مطمئن شوید که `opencode` را در ترمینال داخلی اجرا می‌کنید.
- تأیید کنید که CLI محیط توسعه شما نصب شده است:
  - برای VS Code: دستور `code`
  - برای Cursor: دستور `cursor`
  - برای Windsurf: دستور `windsurf`
  - برای VSCodium: دستور `codium`
  - در غیر این صورت، `Cmd+Shift+P` (مک) یا `Ctrl+Shift+P` (ویندوز/لینوکس) را اجرا کنید و عبارت "Shell Command: Install 'code' command in PATH" (یا معادل آن برای محیط توسعه شما) را جستجو کنید
- مطمئن شوید که VS Code اجازه نصب افزونه‌ها را دارد
