با OpenCode می‌توانید از میان چندین تم داخلی یکی را انتخاب کنید، از تمی که با تم ترمینال شما تطبیق می‌یابد استفاده کنید، یا تم سفارشی خود را تعریف کنید.

به‌طور پیش‌فرض، OpenCode از تم خودمان به نام `opencode` استفاده می‌کند.

---

## الزامات ترمینال

برای اینکه تم‌ها با پالت رنگ کامل خود به‌درستی نمایش داده شوند، ترمینال شما باید از **truecolor** (رنگ ۲۴ بیتی) پشتیبانی کند. بیشتر ترمینال‌های مدرن به‌طور پیش‌فرض از این قابلیت پشتیبانی می‌کنند، اما ممکن است لازم باشد آن را فعال کنید:

- **بررسی پشتیبانی**: دستور `echo $COLORTERM` را اجرا کنید - باید `truecolor` یا `24bit` را چاپ کند
- **فعال‌سازی truecolor**: متغیر محیطی `COLORTERM=truecolor` را در پروفایل shell خود تنظیم کنید
- **سازگاری ترمینال**: مطمئن شوید که شبیه‌ساز ترمینال شما از رنگ ۲۴ بیتی پشتیبانی می‌کند (بیشتر ترمینال‌های مدرن مانند iTerm2، Alacritty، Kitty، Windows Terminal و نسخه‌های اخیر GNOME Terminal این کار را می‌کنند)

بدون پشتیبانی از truecolor، ممکن است تم‌ها با دقت رنگ کمتری نمایش داده شوند یا به نزدیک‌ترین تقریب در میان ۲۵۶ رنگ بازگردند.

## تم سیستم

تم `system` طوری طراحی شده که به‌صورت خودکار با طرح رنگ ترمینال شما تطبیق یابد. برخلاف تم‌های سنتی که از رنگ‌های ثابت استفاده می‌کنند، تم _system_:

- **تولید مقیاس خاکستری**: یک مقیاس خاکستری سفارشی بر اساس رنگ پس‌زمینه ترمینال شما ایجاد می‌کند تا کنتراست بهینه تضمین شود.
- **استفاده از رنگ‌های ANSI**: از رنگ‌های استاندارد ANSI (۰ تا ۱۵) برای برجسته‌سازی سینتکس و عناصر واجهه استفاده می‌کند، که به پالت رنگ ترمینال شما احترام می‌گذارند.
- **حفظ پیش‌فرض‌های ترمینال**: از `none` برای رنگ‌های متن و پس‌زمینه استفاده می‌کند تا ظاهر بومی ترمینال شما حفظ شود.

تم سیستم برای کاربرانی است که:

- می‌خواهند OpenCode با ظاهر ترمینال آن‌ها مطابقت داشته باشد
- از طرح‌های رنگ سفارشی ترمینال استفاده می‌کنند
- ظاهری یکدست در همه اپلیکیشن‌های ترمینال را ترجیح می‌دهند

---

## استفاده از یک تم

می‌توانید با باز کردن انتخابگر تم از طریق دستور `/theme` یک تم را انتخاب کنید. یا می‌توانید آن را در `tui.json` مشخص کنید.

```json title="tui.json" {3}
{
  "$schema": "https://opencode.ai/tui.json",
  "theme": "tokyonight"
}
```

## تم‌های سفارشی

OpenCode از یک سیستم تم انعطاف‌پذیر مبتنی بر JSON پشتیبانی می‌کند که به کاربران اجازه می‌دهد به‌راحتی تم‌ها را ایجاد و سفارشی کنند.

---

### سلسله‌مراتب

تم‌ها از چندین دایرکتوری به ترتیب زیر بارگذاری می‌شوند، که در آن دایرکتوری‌های بعدی، دایرکتوری‌های قبلی را بازنویسی می‌کنند:

1. **تم‌های داخلی** - این‌ها در فایل اجرایی تعبیه شده‌اند
2. **دایرکتوری پیکربندی کاربر** - تعریف‌شده در `~/.config/opencode/themes/*.json` یا `$XDG_CONFIG_HOME/opencode/themes/*.json`
3. **دایرکتوری ریشه پروژه** - تعریف‌شده در `<project-root>/.opencode/themes/*.json`
4. **دایرکتوری کاری فعلی** - تعریف‌شده در `./.opencode/themes/*.json`

اگر چندین دایرکتوری شامل تمی با نام یکسان باشند، تم از دایرکتوری با اولویت بالاتر استفاده خواهد شد.

---

### ایجاد یک تم

برای ایجاد یک تم سفارشی، یک فایل JSON در یکی از دایرکتوری‌های تم ایجاد کنید.

برای تم‌های سطح کاربر:

```bash no-frame
mkdir -p ~/.config/opencode/themes
vim ~/.config/opencode/themes/my-theme.json
```

و برای تم‌های مخصوص پروژه.

```bash no-frame
mkdir -p .opencode/themes
vim .opencode/themes/my-theme.json
```

---

### فرمت JSON

تم‌ها از یک فرمت JSON انعطاف‌پذیر با پشتیبانی از موارد زیر استفاده می‌کنند:

- **رنگ‌های هگزادسیمال**: `"#ffffff"`
- **رنگ‌های ANSI**: `3` (۰ تا ۲۵۵)
- **ارجاع‌های رنگ**: `"primary"` یا تعریف‌های سفارشی
- **متغیرهای تیره/روشن**: `{"dark": "#000", "light": "#fff"}`
- **بدون رنگ**: `"none"` - از رنگ پیش‌فرض ترمینال استفاده می‌کند یا شفاف است

---

### تعریف‌های رنگ

بخش `defs` اختیاری است و به شما اجازه می‌دهد رنگ‌های قابل استفاده مجدد را تعریف کنید که می‌توانند در تم ارجاع داده شوند.

---

### پیش‌فرض‌های ترمینال

مقدار خاص `"none"` را می‌توان برای هر رنگی استفاده کرد تا رنگ پیش‌فرض ترمینال را به ارث ببرد. این به‌ویژه برای ایجاد تم‌هایی که به‌طور یکپارچه با طرح رنگ ترمینال شما ترکیب می‌شوند مفید است:

- `"text": "none"` - از رنگ پیش‌زمینه پیش‌فرض ترمینال استفاده می‌کند
- `"background": "none"` - از رنگ پس‌زمینه پیش‌فرض ترمینال استفاده می‌کند

---
