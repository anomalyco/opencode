---

می‌توانید ابزارهای خارجی را به OpenCode با استفاده از _Model Context Protocol_ یا MCP اضافه کنید. OpenCode از هر دو سرور محلی و از راه دور پشتیبانی می‌کند.

پس از افزودن، ابزارهای MCP به‌طور خودکار در کنار ابزارهای داخلی در دسترس LLM قرار می‌گیرند.

---

#### هشدارها

هنگام استفاده از یک سرور MCP، به متن (context) اضافه می‌شود. این می‌تواند به سرعت تجمع یابد اگر ابزارهای زیادی دارید. بنابراین توصیه می‌کنیم در انتخاب سرورهای MCP احتیاط کنید.

:::tip
سرورهای MCP به متن شما اضافه می‌شوند، بنابراین می‌خواهید در فعال کردن آن‌ها احتیاط کنید.
:::

برخی سرورهای MCP، مانند سرور GitHub MCP، تمایل دارند توکن‌های زیادی اضافه کنند و می‌توانند به سادگی از محدودیت متن فراتر روند.

---

## فعال‌سازی

می‌توانید سرورهای MCP را در [پیکربندی OpenCode](https://opencode.ai/docs/config/) زیر `mcp` تعریف کنید. هر MCP را با یک نام یکتا اضافه کنید. می‌توانید هنگام درخواست از LLM، به آن MCP با نام ارجاع دهید.

```jsonc title="opencode.jsonc" {6}
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "name-of-mcp-server": {
      // ...
      "enabled": true,
    },
    "name-of-other-mcp-server": {
      // ...
    },
  },
}
```

همچنین می‌توانید یک سرور را با قرار دادن `enabled` روی `false` غیرفعال کنید. این مفید است اگر می‌خواهید موقتاً یک سرور را بدون حذف از پیکربندی غیرفعال کنید.

---

### لغو پیش‌فرض‌های از راه دور

سازمان‌ها می‌توانند سرورهای MCP پیش‌فرض را از طریق نقطه پایانی `.well-known/opencode` خود ارائه دهند. این سرورها ممکن است به‌طور پیش‌فرض غیرفعال باشند و به کاربران اجازه می‌دهند مواردی را که نیاز دارند انتخاب کنند.

برای فعال کردن یک سرور خاص از پیکربندی از راه دور سازمان خود، آن را با `enabled: true` به پیکربندی محلی خود اضافه کنید:

```json title="opencode.json"
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "jira": {
      "type": "remote",
      "url": "https://jira.example.com/mcp",
      "enabled": true
    }
  }
}
```

مقادیر پیکربندی محلی شما پیش‌فرض‌های از راه دور را لغو می‌کنند. برای جزئیات بیشتر [اولویت پیکربندی](/docs/config#precedence-order) را ببینید.

---

## محلی

سرورهای MCP محلی را با استفاده از `type` برابر با `"local"` درون شیء MCP اضافه کنید.

```jsonc title="opencode.jsonc" {15}
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "my-local-mcp-server": {
      "type": "local",
      // Or ["bun", "x", "my-mcp-command"]
      "command": ["npx", "-y", "my-mcp-command"],
      "enabled": true,
      "environment": {
        "MY_ENV_VAR": "my_env_var_value",
      },
    },
  },
}
```

دستور نحوه شروع سرور MCP محلی است. همچنین می‌توانید یک لیست از متغیرهای محیطی را نیز پاس دهید.

به عنوان مثال، در اینجا نحوه افزودن سرور آزمایشی [`@modelcontextprotocol/server-everything`](https://www.npmjs.com/package/@modelcontextprotocol/server-everything) MCP آمده است.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "mcp_everything": {
      "type": "local",
      "command": ["npx", "-y", "@modelcontextprotocol/server-everything"],
    },
  },
}
```

و برای استفاده از آن می‌توانم `use the mcp_everything tool` را به درخواست‌های خود اضافه کنم.

```txt "mcp_everything"
use the mcp_everything tool to add the number 3 and 4
```

---

#### گزینه‌ها

در اینجا تمام گزینه‌ها برای پیکربندی یک سرور MCP محلی آمده است.

| گزینه         | نوع    | ضروری | توضیحات                                                                                |
| ------------- | ------ | ----- | -------------------------------------------------------------------------------------- |
| `type`        | String | بله   | نوع اتصال سرور MCP، باید `"local"` باشد.                                              |
| `command`     | Array  | بله   | دستور و آرگومان‌ها برای اجرای سرور MCP.                                               |
| `cwd`         | String |       | فهرست کاری برای فرآیند سرور MCP. مسیرهای نسبی از فضای کاری حل می‌شوند.                |
| `environment` | Object |       | متغیرهای محیطی برای تنظیم هنگام اجرای سرور.                                            |
| `enabled`     | Boolean|       | فعال یا غیرفعال کردن سرور MCP در هنگام راه‌اندازی.                                    |
| `timeout`     | Number |       | زمان انقضا به میلی‌ثانیه برای واکشی ابزارها از سرور MCP. پیش‌فرض 5000 (۵ ثانیه).      |

---

## از راه دور

سرورهای MCP از راه دور را با قرار دادن `type` برابر با `"remote"` اضافه کنید.

```json title="opencode.json"
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "my-remote-mcp": {
      "type": "remote",
      "url": "https://my-mcp-server.com",
      "enabled": true,
      "headers": {
        "Authorization": "Bearer MY_API_KEY"
      }
    }
  }
}
```

`url` نشانی URL سرور MCP از راه دور است و با گزینه `headers` می‌توانید یک لیست از هدرها را پاس دهید.

---

#### گزینه‌ها

| گزینه     | نوع    | ضروری | توضیحات                                                                         |
| --------- | ------ | ----- | ------------------------------------------------------------------------------- |
| `type`    | String | بله   | نوع اتصال سرور MCP، باید `"remote"` باشد.                                      |
| `url`     | String | بله   | نشانی URL سرور MCP از راه دور.                                                 |
| `enabled` | Boolean|       | فعال یا غیرفعال کردن سرور MCP در هنگام راه‌اندازی.                            |
| `headers` | Object |       | هدرهایی که با درخواست ارسال می‌شوند.                                           |
| `oauth`   | Object |       | پیکربندی احراز هویت OAuth. [بخش OAuth](#oauth) زیر را ببینید.                  |
| `timeout` | Number |       | زمان انقضا به میلی‌ثانیه برای واکشی ابزارها از سرور MCP. پیش‌فرض 5000 (۵ ثانیه). |

## OAuth

OpenCode به‌طور خودکار احراز هویت OAuth را برای سرورهای MCP از راه دور مدیریت می‌کند. هنگامی که یک سرور نیاز به احراز هویت دارد، OpenCode موارد زیر را انجام می‌دهد:

1. تشخیص پاسخ ۴۰۱ و آغاز جریان OAuth
2. استفاده از **ثبت پویای کلاینت (RFC 7591)** اگر توسط سرور پشتیبانی شود
3. ذخیره امن توکن‌ها برای درخواست‌های آینده

---

### خودکار

برای اکثر سرورهای MCP با قابلیت OAuth، پیکربندی خاصی لازم نیست. فقط سرور از راه دور را پیکربندی کنید:

```json title="opencode.json"
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "my-oauth-server": {
      "type": "remote",
      "url": "https://mcp.example.com/mcp"
    }
  }
}
```

اگر سرور نیاز به احراز هویت داشته باشد، OpenCode از شما می‌خواهد هنگام اولین تلاش برای استفاده، احراز هویت کنید. در غیر این صورت، می‌توانید [جریان را به‌صورت دستی فعال کنید](#authenticating) با `opencode mcp auth <server-name>`.

---

### از پیش ثبت‌شده

اگر اعتبارنامه‌های کلاینت را از ارائه‌دهنده سرور MCP دارید، می‌توانید آن‌ها را پیکربندی کنید:

```json title="opencode.json" {7-11}
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "my-oauth-server": {
      "type": "remote",
      "url": "https://mcp.example.com/mcp",
      "oauth": {
        "clientId": "{env:MY_MCP_CLIENT_ID}",
        "clientSecret": "{env:MY_MCP_CLIENT_SECRET}",
        "scope": "tools:read tools:execute"
      }
    }
  }
}
```

---

### احراز هویت

می‌توانید احراز هویت را به‌صورت دستی فعال کنید یا اعتبارنامه‌ها را مدیریت کنید.

احراز هویت با یک سرور MCP خاص:

```bash
opencode mcp auth my-oauth-server
```

فهرست کردن تمام سرورهای MCP و وضعیت احراز هویت آن‌ها:

```bash
opencode mcp list
```

حذف اعتبارنامه‌های ذخیره‌شده:

```bash
opencode mcp logout my-oauth-server
```

دستور `mcp auth` مرورگر شما را برای مجوز باز می‌کند. پس از مجوز دادن، OpenCode توکن‌ها را به‌طور امن در `~/.local/share/opencode/mcp-auth.json` ذخیره می‌کند.

---

#### غیرفعال کردن OAuth

اگر می‌خواهید OAuth خودکار را برای یک سرور غیرفعال کنید (مثلاً برای سرورهایی که به جای آن از کلیدهای API استفاده می‌کنند)، `oauth` را روی `false` قرار دهید:

```json title="opencode.json" {7}
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "my-api-key-server": {
      "type": "remote",
      "url": "https://mcp.example.com/mcp",
      "oauth": false,
      "headers": {
        "Authorization": "Bearer {env:MY_API_KEY}"
      }
    }
  }
}
```

---

#### گزینه‌های OAuth

| گزینه         | نوع             | توضیحات                                                                  |
| ------------- | --------------- | ------------------------------------------------------------------------ |
| `oauth`       | Object \| false | شیء پیکربندی OAuth، یا `false` برای غیرفعال کردن تشخیص خودکار OAuth.     |
| `clientId`    | String          | شناسه کلاینت OAuth. اگر ارائه نشود، ثبت پویای کلاینت تلاش می‌شود.        |
| `clientSecret`| String          | راز کلاینت OAuth، اگر توسط سرور مجوز نیاز باشد.                          |
| `scope`       | String          | دامنه‌های OAuth برای درخواست در طول مجوز.                                |

#### اشکال‌زدایی

اگر یک سرور MCP از راه دور در احراز هویت شکست می‌خورد، می‌توانید مشکلات را با موارد زیر تشخیص دهید:

```bash
# View auth status for all OAuth-capable servers
opencode mcp auth list

# Debug connection and OAuth flow for a specific server
opencode mcp debug my-oauth-server
```

دستور `mcp debug` وضعیت احراز هویت فعلی را نشان می‌دهد، اتصال HTTP را آزمایش می‌کند و جریان کشف OAuth را تلاش می‌کند.

## مدیریت

MCPهای شما در کنار ابزارهای داخلی به عنوان ابزار در OpenCode در دسترس هستند. بنابراین می‌توانید آن‌ها را از طریق پیکربندی OpenCode مانند هر ابزار دیگر مدیریت کنید.

---

### سراسری

این به این معناست که می‌توانید آن‌ها را به‌طور سراسری فعال یا غیرفعال کنید.

```json title="opencode.json" {14}
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "my-mcp-foo": {
      "type": "local",
      "command": ["bun", "x", "my-mcp-command-foo"]
    },
    "my-mcp-bar": {
      "type": "local",
      "command": ["bun", "x", "my-mcp-command-bar"]
    }
  },
  "tools": {
    "my-mcp-foo": false
  }
}
```

همچنین می‌توانیم از یک الگوی glob برای غیرفعال کردن تمام MCPهای مطابق استفاده کنیم.

```json title="opencode.json" {14}
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "my-mcp-foo": {
      "type": "local",
      "command": ["bun", "x", "my-mcp-command-foo"]
    },
    "my-mcp-bar": {
      "type": "local",
      "command": ["bun", "x", "my-mcp-command-bar"]
    }
  },
  "tools": {
    "my-mcp*": false
  }
}
```

در اینجا از الگوی glob `my-mcp*` برای غیرفعال کردن تمام MCPها استفاده می‌کنیم.

---

### به‌ازای عامل

اگر تعداد زیادی سرور MCP دارید، ممکن است بخواهید فقط آن‌ها را به‌ازای هر عامل فعال کنید و به‌طور سراسری غیرفعال کنید. برای انجام این کار:

1. آن را به عنوان یک ابزار به‌طور سراسری غیرفعال کنید.
2. در [پیکربندی عامل](/docs/agents#tools) خود، سرور MCP را به عنوان یک ابزار فعال کنید.

```json title="opencode.json" {11, 14-18}
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "my-mcp": {
      "type": "local",
      "command": ["bun", "x", "my-mcp-command"],
      "enabled": true
    }
  },
  "tools": {
    "my-mcp*": false
  },
  "agent": {
    "my-agent": {
      "tools": {
        "my-mcp*": true
      }
    }
  }
}
```

---

#### الگوهای glob

الگوی glob از الگوهای glob ساده regex استفاده می‌کند:

- `*` با صفر یا چند کاراکتر از هر نوع مطابقت می‌کند (مثلاً `"my-mcp*"` با `my-mcp_search`، `my-mcp_list` و غیره مطابقت می‌کند)
- `?` دقیقاً با یک کاراکتر مطابقت می‌کند
- تمام کاراکترهای دیگر به‌طور تحت‌اللفظی مطابقت می‌کنند

:::note
ابزارهای سرور MCP با نام سرور به عنوان پیشوند ثبت می‌شوند، بنابراین برای غیرفعال کردن تمام ابزارهای یک سرور به سادگی از موارد زیر استفاده کنید:

```
"mymcpservername_*": false
```

:::

## مثال‌ها

در زیر مثال‌هایی از برخی سرورهای MCP رایج آمده است. می‌توانید یک PR ارسال کنید اگر می‌خواهید سرورهای دیگر را مستند کنید.

---

### Sentry

[سرور Sentry MCP](https://mcp.sentry.dev) را برای تعامل با پروژه‌ها و مسائل Sentry خود اضافه کنید.

```json title="opencode.json" {4-8}
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "sentry": {
      "type": "remote",
      "url": "https://mcp.sentry.dev/mcp",
      "oauth": {}
    }
  }
}
```

پس از افزودن پیکربندی، با Sentry احراز هویت کنید:

```bash
opencode mcp auth sentry
```

این یک پنجره مرورگر را برای تکمیل جریان OAuth باز می‌کند و OpenCode را به حساب Sentry شما متصل می‌کند.

پس از احراز هویت، می‌توانید از ابزارهای Sentry در درخواست‌های خود برای پرس‌وجو درباره مسائل، پروژه‌ها و داده‌های خطا استفاده کنید.

```txt "use sentry"
Show me the latest unresolved issues in my project. use sentry
```

---

### Context7

[سرور Context7 MCP](https://github.com/upstash/context7) را برای جستجو در مستندات اضافه کنید.

```json title="opencode.json" {4-7}
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "context7": {
      "type": "remote",
      "url": "https://mcp.context7.com/mcp"
    }
  }
}
```

اگر برای یک حساب رایگان ثبت‌نام کرده‌اید، می‌توانید از کلید API خود استفاده کنید و محدودیت نرخ بالاتری دریافت کنید.

```json title="opencode.json" {7-9}
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "context7": {
      "type": "remote",
      "url": "https://mcp.context7.com/mcp",
      "headers": {
        "CONTEXT7_API_KEY": "{env:CONTEXT7_API_KEY}"
      }
    }
  }
}
```

در اینجا فرض می‌کنیم متغیر محیطی `CONTEXT7_API_KEY` را تنظیم کرده‌اید.

`use context7` را به درخواست‌های خود اضافه کنید تا از سرور Context7 MCP استفاده کنید.

```txt "use context7"
Configure a Cloudflare Worker script to cache JSON API responses for five minutes. use context7
```

همچنین می‌توانید چیزی شبیه این را به [AGENTS.md](/docs/rules/) خود اضافه کنید.

```md title="AGENTS.md"
When you need to search docs, use `context7` tools.
```

---

### Grep توسط Vercel

[سرور Grep توسط Vercel](https://grep.app) را برای جستجو در قطعات کد در GitHub اضافه کنید.

```json title="opencode.json" {4-7}
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "gh_grep": {
      "type": "remote",
      "url": "https://mcp.grep.app"
    }
  }
}
```

از آنجا که سرور MCP خود را `gh_grep` نامیدیم، می‌توانید `use the gh_grep tool` را به درخواست‌های خود اضافه کنید تا عامل از آن استفاده کند.

```txt "use the gh_grep tool"
What's the right way to set a custom domain in an SST Astro component? use the gh_grep tool
```

همچنین می‌توانید چیزی شبیه این را به [AGENTS.md](/docs/rules/) خود اضافه کنید.

```md title="AGENTS.md"
If you are unsure how to do something, use `gh_grep` to search code examples from GitHub.
```
