---

ویژگی اشتراک‌گذاری OpenCode به شما امکان می‌دهد لینک‌های عمومی برای گفتگوهای OpenCode خود ایجاد کنید تا بتوانید با هم‌تیمی‌ها همکاری کنید یا از دیگران کمک بگیرید.

:::note
گفتگوهای به‌اشتراک‌گذاشته‌شده برای هر کسی که لینک را داشته باشد به‌صورت عمومی قابل دسترسی هستند.
:::

---

## چگونه کار می‌کند

هنگامی که یک گفتگو را به اشتراک می‌گذارید، OpenCode:

1. یک URL عمومی منحصربه‌فرد برای جلسه شما ایجاد می‌کند
2. سابقه گفتگوی شما را با سرورهای ما همگام‌سازی می‌کند
3. گفتگو را از طریق لینک قابل اشتراک‌گذاری در دسترس قرار می‌دهد — `opncd.ai/s/<share-id>`

---

## اشتراک‌گذاری

OpenCode از سه حالت اشتراک‌گذاری پشتیبانی می‌کند که نحوه به‌اشتراک‌گذاری گفتگوها را کنترل می‌کنند:

---

### دستی (پیش‌فرض)

به‌صورت پیش‌فرض، OpenCode از حالت اشتراک‌گذاری دستی استفاده می‌کند. جلسات به‌صورت خودکار به اشتراک گذاشته نمی‌شوند، اما می‌توانید آن‌ها را به‌صورت دستی با استفاده از دستور `/share` به اشتراک بگذارید:

```
/share
```

این کار یک URL منحصربه‌فرد تولید می‌کند که در کلیپ‌بورد شما کپی خواهد شد.

برای تنظیم صریح حالت دستی در [فایل پیکربندی](/docs/config):

```json title="opencode.json"
{
  "$schema": "https://opencode.ai/config.json",
  "share": "manual"
}
```

---

### اشتراک‌گذاری خودکار

می‌توانید اشتراک‌گذاری خودکار را برای همه گفتگوهای جدید با تنظیم گزینه `share` روی `"auto"` در [فایل پیکربندی](/docs/config) فعال کنید:

```json title="opencode.json"
{
  "$schema": "https://opencode.ai/config.json",
  "share": "auto"
}
```

با فعال‌بودن اشتراک‌گذاری خودکار، هر گفتگوی جدید به‌صورت خودکار به اشتراک گذاشته می‌شود و یک لینک تولید خواهد شد.

---

### غیرفعال

می‌توانید اشتراک‌گذاری را به‌طور کامل با تنظیم گزینه `share` روی `"disabled"` در [فایل پیکربندی](/docs/config) غیرفعال کنید:

```json title="opencode.json"
{
  "$schema": "https://opencode.ai/config.json",
  "share": "disabled"
}
```

برای اعمال این مورد در سراسر تیم خود برای یک پروژه معین، آن را به فایل `opencode.json` در پروژه خود اضافه کنید و در Git ثبت (check in) کنید.

---

## لغو اشتراک‌گذاری

برای توقف اشتراک‌گذاری یک گفتگو و حذف آن از دسترسی عمومی:

```
/unshare
```

این کار لینک اشتراک‌گذاری را حذف می‌کند و داده‌های مرتبط با گفتگو را پاک می‌کند.

---

## حریم خصوصی

هنگام اشتراک‌گذاری یک گفتگو، چند نکته وجود دارد که باید در نظر داشته باشید.

---

### نگه‌داری داده‌ها

گفتگوهای به‌اشتراک‌گذاشته‌شده تا زمانی که به‌صراحت اشتراک آن‌ها را لغو نکنید، قابل دسترسی باقی می‌مانند. این شامل موارد زیر است:

- سابقه کامل گفتگو
- همه پیام‌ها و پاسخ‌ها
- فراداده (metadata) جلسه

---

### توصیه‌ها

- فقط گفتگوهایی را به اشتراک بگذارید که حاوی اطلاعات حساس نیستند.
- محتوای گفتگو را پیش از اشتراک‌گذاری بررسی کنید.
- پس از تکمیل همکاری، اشتراک گفتگوها را لغو کنید.
- از اشتراک‌گذاری گفتگوهای حاوی کد اختصاصی یا داده‌های محرمانه خودداری کنید.
- برای پروژه‌های حساس، اشتراک‌گذاری را به‌طور کامل غیرفعال کنید.

---

## برای سازمان‌ها

برای استقرارهای سازمانی، ویژگی اشتراک‌گذاری می‌تواند:

- برای انطباق امنیتی به‌طور کامل **غیرفعال** شود
- فقط به کاربران احراز هویت‌شده از طریق SSO **محدود** شود
- روی زیرساخت خودتان **میزبانی شخصی** شود

[بیشتر بدانید](/docs/enterprise) درباره استفاده از OpenCode در سازمان شما.
