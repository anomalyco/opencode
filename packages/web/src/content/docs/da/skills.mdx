---
title: "Agentfærdigheder"
description: "Definer genbrugbar adfærd via SKILL.md-definitioner"
---

Agentfærdigheder lader OpenCode opdage genbrugelige instruktioner fra repo- eller hjemmekatalogen din.
Færdigheder indlæses på forespørgsel via det oprindelige `skill`-værktøj – agenter ser tilgængelige færdigheder og kan indlæse hele indholdet, når det er nødvendigt.

---

## Placer filer

Opret én mappe per færdighedsnavn og tilføj en `SKILL.md` i den.
OpenCode søger efter disse steder:

- Projektkonfiguration: `.opencode/skills/<name>/SKILL.md`
- Global konfiguration: `~/.config/opencode/skills/<name>/SKILL.md`
- Projekt Claude-kompatibel: `.claude/skills/<name>/SKILL.md`
- Global Claude-kompatibel: `~/.claude/skills/<name>/SKILL.md`
- Projektagent-kompatibel: `.agents/skills/<name>/SKILL.md`
- Global agent-kompatibel: `~/.agents/skills/<name>/SKILL.md`

---

## Forstå opdagelsen

For projektlokale stier går OpenCode op fra din nuværende arbejdskatalog, indtil den når git-arbejdstree.
Den laster alle matchende `skills/*/SKILL.md` i `.opencode/` og alle matchende `.claude/skills/*/SKILL.md` eller `.agents/skills/*/SKILL.md` underveis.

Globale definitioner indlæses også fra `~/.config/opencode/skills/*/SKILL.md`, `~/.claude/skills/*/SKILL.md` og `~/.agents/skills/*/SKILL.md`.

---

## Skriv frontmatter

Hver `SKILL.md` må starte med YAML frontmatter.
Bare disse feltene gjenkjennes:

- `name` (påkrevd)
- `description` (påkrevd)
- `license` (valgfritt)
- `compatibility` (valgfritt)
- `metadata` (valgfritt, streng-til-streng kart)

Ukjente frontmatter-felter ignoreres.

---

## Bekræft navn

`name` må:

- Bestå av 1–64 tegn
- Vær alfanumerisk med små bokstaver med skilletegn med enkelt bindestrek
- Ikke begynne eller slutte med `-`
- Ikke inneholde påfølgende `--`
- Match katalognavnet som inneholder `SKILL.md`

Ekvivalent regulært uttrykk:

```text
^[a-z0-9]+(-[a-z0-9]+)*$
```

---

## Følg længdereglerne

`description` må bestå av 1-1024 tegn.
Hold det specifikt nok til at agenten kan vælge rigtigt.

---

## Brug et eksempel

Lav `.opencode/skills/git-release/SKILL.md` sådan:

```markdown
---
name: git-release
description: Create consistent releases and changelogs
license: MIT
compatibility: opencode
metadata:
  audience: maintainers
  workflow: github
---

## What I do

- Draft release notes from merged PRs
- Propose a version bump
- Provide a copy-pasteable `gh release create` command

## When to use me

Use this when you are preparing a tagged release.
Ask clarifying questions if the target versioning scheme is unclear.
```

## Genkend værktøjsbeskrivelsen

OpenCode viser tilgængelige færdigheder i `skill` værktøjsbeskrivelsen.
Hver post indeholder færdighedsnavnet og beskrivelsen:

```xml
<available_skills>
  <skill>
    <name>git-release</name>
    <description>Create consistent releases and changelogs</description>
  </skill>
</available_skills>
```

Agenten indlæser en færdighed ved at kalde værktøjet:

```
skill({ name: "git-release" })
```

## Konfigurer tilladelser

Kontroller hvilke færdigheder agenter har adgang til ved at bruge mønsterbaserede tilladelser i `opencode.json`:

```json
{
  "permission": {
    "skill": {
      "*": "allow",
      "pr-review": "allow",
      "internal-*": "deny",
      "experimental-*": "ask"
    }
  }
}
```

| Tilladelse | Adfærd                                     |
| ---------- | ------------------------------------------ |
| `allow`    | Færdigheder indlæses straks             |
| `deny`     | Færdighed skjult for agenten, adgang afvist |
| `ask`      | Bruger bedt om godkjenning før lasting     |

Mønstre støtter jokertegn: `internal-*` samsvarer med `internal-docs`, `internal-tools` osv.

---

## Tilsidesættelse pr. agent

Giv specifikke agenter andre tilladelser end de globale standardindstillinger.

**For egendefinerede agenter** (i agent frontmatter):

```yaml
---
permission:
  skill:
    "documents-*": "allow"
---
```

**For indbyggede agenter** (i `opencode.json`):

```json
{
  "agent": {
    "plan": {
      "permission": {
        "skill": {
          "internal-*": "allow"
        }
      }
    }
  }
}
```

---

## Deaktiver færdighedsværktøjet

Deaktiver færdigheder fuldstændigt for agenter, som ikke bør bruge dem:

**For egendefinerede agenter**:

```yaml
---
tools:
  skill: false
---
```

**For indbyggede agenter**:

```json
{
  "agent": {
    "plan": {
      "tools": {
        "skill": false
      }
    }
  }
}
```

Når den er deaktiveret, bliver `<available_skills>`-delen udeladt helt.

---

## Fejlfind indlæsning

Hvis en færdighed ikke vises:

1. Kontroller at `SKILL.md` er stavet med store bokstaver
2. Tjek at frontmatter inkluderer `name` og `description`
3. Sørg for at færdighedsnavnene er unikke på alle steder
4. Tjek tilladelser – færdigheder med `deny` er skjult for agenter
