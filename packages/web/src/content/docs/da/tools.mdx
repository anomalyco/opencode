title: Værktøjer
description: Administrer de værktøjer, en LLM kan bruge.
---

Værktøjer lader LLM udføre handlinger i din kodebase. OpenCode leveres med et sæt indbyggede værktøjer, men du kan udvide det med [egendefinerede værktøjer](/docs/custom-tools) eller [MCP-servere](/docs/mcp-servers).

Som standard er alle værktøjer **aktiveret** og har ikke brug for tilladelse for at køre. Du kan kontrollere værktøjets opførsel gennem [tilladelser](/docs/permissions).

---

## Konfiguration

Brug feltet `permission` for at kontrollere værktøjets opførsel. Du kan tillade, afvise eller kræve godkendelse for hvert værktøj.

```json title="opencode.json"
{
  "$schema": "https://opencode.ai/config.json",
  "permission": {
    "edit": "deny",
    "bash": "ask",
    "webfetch": "allow"
  }
}
```

Du kan også bruge jokertegn for at kontrollere flere værktøjer samtidig. For eksempel, for at kræve godkendelse for alle værktøjer fra en MCP-server:

```json title="opencode.json"
{
  "$schema": "https://opencode.ai/config.json",
  "permission": {
    "mymcp_*": "ask"
  }
}
```

[Læs mere](/docs/permissions) om konfigurering af tilladelser.

## Indbyggede

Her er alle de indbyggede værktøjer, der er tilgængelige i OpenCode.

---

### bash

Udfør shell-kommandoer i dit projektmiljø.

```json title="opencode.json" {4}
{
  "$schema": "https://opencode.ai/config.json",
  "permission": {
    "bash": "allow"
  }
}
```

Dette værktøj lader LLM køre terminalkommandoer som `npm install`, `git status` eller en hvilken som helst anden shell-kommando.

---

### edit

Endre eksisterende filer ved at bruge eksakte strengerstatninger.

```json title="opencode.json" {4}
{
  "$schema": "https://opencode.ai/config.json",
  "permission": {
    "edit": "allow"
  }
}
```

Dette værktøj udfører nøjagtige redigeringer af filer ved at erstatte nøjagtige tekstmatch. Det er den primære måde, LLM ændrer kode på.

---

### write

Opret nye filer eller overskriv eksisterende.

```json title="opencode.json" {4}
{
  "$schema": "https://opencode.ai/config.json",
  "permission": {
    "edit": "allow"
  }
}
```

Brug dette for at lade LLM oprette nye filer. Den vil overskrive eksisterende filer, hvis de allerede eksisterer.

:::note
`write`-værktøjet kontrolleres af tilladelsen `edit`, som dækker alle filændringer (`edit`, `write`, `patch`, `multiedit`).
:::

---

### read

Læs filindholdet fra din kodebase.

```json title="opencode.json" {4}
{
  "$schema": "https://opencode.ai/config.json",
  "permission": {
    "read": "allow"
  }
}
```

Dette værktøj læser filer og returnerer indholdet. Det understøtter læsning af specifikke linjeområder for store filer.

---

### grep

Søg i filindhold ved hjælp af regulære udtryk.

```json title="opencode.json" {4}
{
  "$schema": "https://opencode.ai/config.json",
  "permission": {
    "grep": "allow"
  }
}
```

Hurtig indholdssøgning på tværs af din kodebase. Understøtter fuld regex-syntaks og filmønsterfiltrering.

---

### glob

Find filer ved hjælp af mønstermatchning.

```json title="opencode.json" {4}
{
  "$schema": "https://opencode.ai/config.json",
  "permission": {
    "glob": "allow"
  }
}
```

Søg efter filer ved at bruge glob-mønstre som `**/*.js` eller `src/**/*.ts`. Returnerer matchende filstier sorteret efter ændringstid.

---

### list

List filer og mapper i en given sti.

```json title="opencode.json" {4}
{
  "$schema": "https://opencode.ai/config.json",
  "permission": {
    "list": "allow"
  }
}
```

Dette værktøj viser katalogindhold. Det accepterer glob-mønstre for at filtrere resultater.

---

### lsp (experimental)

Interagér med dine konfigurerede LSP-servere for at få kodeintelligensfunktioner som definitioner, referencer, hover-information og call hierarchy.

:::note
Dette værktøj er kun tilgængeligt når `OPENCODE_EXPERIMENTAL_LSP_TOOL=true` (eller `OPENCODE_EXPERIMENTAL=true`).
:::

```json title="opencode.json" {4}
{
  "$schema": "https://opencode.ai/config.json",
  "permission": {
    "lsp": "allow"
  }
}
```

Støttede operationer inkluderer `goToDefinition`, `findReferences`, `hover`, `documentSymbol`, `workspaceSymbol`, `goToImplementation`, `prepareCallHierarchy`, `incomingCalls` og `outgoingCalls`.

For at konfigurere, hvilke LSP-servere der er tilgængelige for dit projekt, se [LSP-servere](/docs/lsp).

---

### patch

Brug patcher på filer.

```json title="opencode.json" {4}
{
  "$schema": "https://opencode.ai/config.json",
  "permission": {
    "edit": "allow"
  }
}
```

Dette værktøj bruger opdateringsfiler til din kodebase. Nyttig til at anvende diffs og lapper fra forskellige kilder.

:::note
`patch`-værktøjet kontrolleres af tilladelsen `edit`, som dækker alle filændringer (`edit`, `write`, `patch`, `multiedit`).
:::

---

### skill

Last inn en [ferdighet](/docs/skills) (en `SKILL.md` fil) og returner innholdet i samtalen.

```json title="opencode.json" {4}
{
  "$schema": "https://opencode.ai/config.json",
  "permission": {
    "skill": "allow"
  }
}
```

---

### todowrite

Administrer to-doslister under kodingssessioner.

```json title="opencode.json" {4}
{
  "$schema": "https://opencode.ai/config.json",
  "permission": {
    "todowrite": "allow"
  }
}
```

Opretter og opdaterer opgavelister for at spore fremdrift under komplekse operationer. LLM bruger dette til at organisere flertrinsopgaver.

:::note
Dette værktøj er deaktiveret for subagenter som standard, men du kan aktivere det manuelt. [Læs mere](/docs/agents/#permissions)
:::

---

### webfetch

Hent netindhold.

```json title="opencode.json" {4}
{
  "$schema": "https://opencode.ai/config.json",
  "permission": {
    "webfetch": "allow"
  }
}
```

Lader LLM hente og læse websider. Nyttig for at slå op dokumentation eller forske i netressourcer.

---

### websearch

Søg på nettet efter information.

:::note
Dette værktøj er kun tilgængeligt, når du bruger OpenCode-leverandøren, eller når miljøvariablen `OPENCODE_ENABLE_EXA` er sat til sand (f.eks. `true` eller `1`).

Sådan aktiverer du det, når du starter OpenCode:

```bash
OPENCODE_ENABLE_EXA=1 opencode
```

:::

```json title="opencode.json" {4}
{
  "$schema": "https://opencode.ai/config.json",
  "permission": {
    "websearch": "allow"
  }
}
```

Udfører netsøgninger med Exa AI for at finde relevant information på nettet. Nyttigt til at undersøge emner, finde aktuelle begivenheder eller samle information ud over træningsdataafbrydelsen.

Ingen API-nøgle kræves — værktøjet kobles direkte til Exa AIs værtsbaserede MCP-tjeneste uden autentisering.

:::tip
Brug `websearch`, når du har brug for at finde information (opdagelse), og `webfetch`, når du har brug for at hente indhold fra en bestemt URL.
:::

---

### question

Still brugeren spørgsmål under udførelsen.

```json title="opencode.json" {4}
{
  "$schema": "https://opencode.ai/config.json",
  "permission": {
    "question": "allow"
  }
}
```

Dette værktøj lader LLM stille spørgsmål til brugeren under en opgave. Det er nyttigt til:

- Indsamle brugerpræferencer eller krav
- Afklare tvetydige instruktioner
- Tage beslutninger om gennemførelsesvalg
- Tilbyde valg om, hvilken retning du skal tage

Hvert spørgsmål inkluderer en overskrift, spørgsmålsteksten og en liste over alternativer. Brugere kan vælge fra de angivne alternativer eller skrive ind et brugerdefineret svar. Når det er flere spørgsmål, kan brugerne navigere mellem dem, før de sender alle svarene.

## Interne

Internt bruger værktøjer som `grep`, `glob` og `list` [ripgrep](https://github.com/BurntSushi/ripgrep) under panseret. Som standard respekterer ripgrep `.gitignore`-mønstre, hvilket betyder, at filer og mapper, der er opført i `.gitignore`, bliver ekskluderet fra søgninger og lister.

---

### Ignoreringsmønstre

For at inkludere filer, der normalt bliver ignoreret, opret en `.ignore`-fil i projektroden. Denne fil kan eksplicit tillade visse stier.

```text title=".ignore"
!node_modules/
!dist/
!build/
```

For eksempel lader denne `.ignore` fil ripgrep søge i `node_modules/`, `dist/` og `build/` kataloger, selv om de er opført i `.gitignore`.
