OpenCode provides a Nix flake for building the Tauri-based desktop application. This works on NixOS and macOS.

---

## Build

Build the desktop app using the Nix flake:

```bash
nix build .#desktop
```

The binary will be available at `./result/bin/opencode-desktop`.

---

## Run

Run the desktop app directly without installing:

```bash
nix run .#desktop
```

---

## Platforms

The flake supports the following systems:

- `aarch64-linux` - ARM64 Linux (NixOS)
- `x86_64-linux` - x86 Linux (NixOS)
- `aarch64-darwin` - Apple Silicon macOS
- `x86_64-darwin` - Intel macOS

:::note
Building on non-NixOS Linux distributions may require additional configuration. The flake is optimized for NixOS where system libraries are managed by Nix.
:::

---

## Prerequisites

You'll need Nix with flakes enabled. If you don't have it set up, add this to your Nix configuration:

```nix
{
  nix.settings.experimental-features = [ "nix-command" "flakes" ]
}
```

Or run commands with the experimental flag:

```bash
nix --experimental-features 'nix-command flakes' build .#desktop
```

---

## Development shell

The flake also provides a development shell with all the dependencies needed to work on OpenCode:

```bash
nix develop
```

This gives you access to Bun, Node.js, and other build tools.
