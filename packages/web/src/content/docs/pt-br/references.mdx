Referências dão ao opencode acesso a diretórios fora do projeto atual. Use-as para disponibilizar documentação, bibliotecas compartilhadas, exemplos ou outro repositório enquanto você trabalha.

Referências são configuradas por alias em `opencode.json` ou `opencode.jsonc`.

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "references": {
    "docs": {
      "path": "../product-docs",
      "description": "Use for product behavior and documentation conventions",
    },
    "sdk": {
      "repository": "anomalyco/opencode-sdk-js",
      "branch": "main",
      "description": "Use for JavaScript SDK implementation details",
    },
  },
}
```

---

## Diretórios locais

Use `path` para referenciar um diretório local.

```jsonc title="opencode.jsonc"
{
  "references": {
    "docs": {
      "path": "../docs",
    },
  },
}
```

Os caminhos podem ser:

- Relativos ao arquivo de configuração que define a referência.
- Absolutos, como `/home/user/docs`.
- Relativos ao seu diretório home, como `~/docs`.

Você também pode usar a forma abreviada como string:

```jsonc title="opencode.jsonc"
{
  "references": {
    "docs": "../docs",
  },
}
```

## Repositórios Git

Use `repository` para referenciar um repositório Git. O opencode materializa o repositório em seu cache local e disponibiliza o código como um diretório de referência.

```jsonc title="opencode.jsonc"
{
  "references": {
    "effect": {
      "repository": "Effect-TS/effect",
      "branch": "main",
    },
  },
}
```

`repository` aceita URLs Git, referências host/path e o formato abreviado `owner/repo` do GitHub. O campo opcional `branch` seleciona uma branch ou ref. Sem `branch`, o opencode usa a branch padrão do repositório.

Você pode usar a forma abreviada como string quando não precisar de branch, description ou outras opções:

```jsonc title="opencode.jsonc"
{
  "references": {
    "effect": "Effect-TS/effect",
  },
}
```

:::note
Referências Git são atualizadas de forma assíncrona. Um repositório recém-configurado pode levar um momento para terminar de clonar ou atualizar.
:::

## Descrever o uso

Adicione `description` para explicar quando um agente deve usar uma referência.

```jsonc title="opencode.jsonc"
{
  "references": {
    "design-system": {
      "path": "../design-system",
      "description": "Use when implementing UI components or design tokens",
    },
  },
}
```

O opencode inclui referências com descrições no contexto dos agentes. As descrições devem ser curtas e específicas o suficiente para distinguir referências com conteúdo semelhante. Referências sem descrição continuam disponíveis por meio do autocomplete e do uso direto, mas não são anunciadas aos agentes.

## Ocultar entradas do autocomplete

Defina `hidden` como `true` para omitir uma referência do autocomplete com `@` na TUI.

```jsonc title="opencode.jsonc"
{
  "references": {
    "internal": {
      "path": "../internal",
      "description": "Use for internal implementation details",
      "hidden": true,
    },
  },
}
```

`hidden` afeta apenas o autocomplete. Uma referência oculta com descrição continua incluída no contexto dos agentes.

## Usar referências

Referências configuradas aparecem no autocomplete com `@` da TUI. Digite `@alias` para anexar a raiz da referência ou `@alias/` para procurar arquivos dentro dela.

```text
Compare this implementation with @sdk/src/client.ts
```

Os agentes também recebem, em seu contexto de sistema, os caminhos resolvidos e as descrições das referências configuradas que têm descrição, para que possam inspecionar uma referência quando ela for relevante, sem que você precise anexá-la manualmente.

O opencode permite automaticamente diretórios de referência na sua fronteira de permissão de diretórios externos. As permissões normais de ferramentas continuam valendo; por exemplo, um agente que não pode editar arquivos não ganha acesso de edição porque um diretório está configurado como referência.

## Campos de configuração

| Campo         | Local | Git | Descrição                                          |
| ------------- | ----- | --- | -------------------------------------------------- |
| `path`        | Sim   | Não | Diretório de referência local                      |
| `repository`  | Não   | Sim | URL Git, host/path ou valor `owner/repo` do GitHub |
| `branch`      | Não   | Sim | Branch ou ref Git opcional                         |
| `description` | Sim   | Sim | Orientação descrevendo quando usar a referência    |
| `hidden`      | Sim   | Sim | Oculta a referência do autocomplete `@` da TUI     |

Aliases de referência não podem ser vazios nem conter `/`, espaços, crases ou vírgulas.
