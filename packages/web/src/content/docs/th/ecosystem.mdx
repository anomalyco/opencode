ชุดโครงการชุมชนที่สร้างขึ้นบน xcsh

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ xcsh ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-xcsh](https://github.com/awesome-xcsh/awesome-xcsh) และ [xcsh.cafe](https://xcsh.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
