ชุดโครงการชุมชนที่สร้างขึ้นบน CyberStrike

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ CyberStrike ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-cyberstrike](https://github.com/awesome-cyberstrike/awesome-cyberstrike) และ [cyberstrike.cafe](https://cyberstrike.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
