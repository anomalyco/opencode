---

פקודות מותאמות אישית מאפשרות לך לציין פרומפט שאתה רוצה להריץ כאשר הפקודה הזו מבוצעת ב-TUI.

```bash frame="none"
/my-command
```

פקודות מותאמות אישית הן בנוסף לפקודות המובנות כמו `/init`, `/undo`, `/redo`, `/share`, `/help`. [למד עוד](/docs/tui#commands).

---

## צור קבצי פקודות

צור קבצי markdown בספרייה `commands/` כדי להגדיר פקודות מותאמות אישית.

צור `.opencode/commands/test.md`:

```md title=".opencode/commands/test.md"
---
description: הרץ בדיקות עם כיסוי
agent: build
model: anthropic/claude-3-5-sonnet-20241022
---

הרץ את סוויטת הבדיקות המלאה עם דוח כיסוי והצג כל כישלונות.
התמקד בבדיקות שנכשלו והצע הצעות לתיקון.
```

ה-frontmatter מגדיר מאפיינים של הפקודה. התוכן הופך לתבנית.

השתמש בפקודה על ידי הקלדת `/` ולאחר מכן שם הפקודה.

```bash frame="none"
"/test"
```

## הגדר

אתה יכול להוסיף פקודות מותאמות אישית דרך הגדרות OpenCode או על ידי יצירת קבצי markdown בספרייה `commands/`.

---

### JSON

השתמש באפשרות `command` ב[הגדרות](/docs/config) OpenCode שלך:

```json title="opencode.jsonc" {4-12}
{
  "$schema": "https://opencode.ai/config.json",
  "command": {
    // זה הופך לשם הפקודה
    "test": {
      // זה הפרומפט שיישלח ל-LLM
      "template": "הרץ את סוויטת הבדיקות המלאה עם דוח כיסוי והצג כל כישלונות.\nהתמקד בבדיקות שנכשלו והצע הצעות לתיקון.",
      // זה מוצג כתיאור ב-TUI
      "description": "הרץ בדיקות עם כיסוי",
      "agent": "build",
      "model": "anthropic/claude-3-5-sonnet-20241022"
    }
  }
}
```

עכשיו אתה יכול להריץ את הפקודה הזו ב-TUI:

```bash frame="none"
/test
```

---

### Markdown

אתה יכול גם להגדיר פקודות באמצעות קבצי markdown. מקם אותם ב:

- גלובלי: `~/.config/opencode/commands/`
- לכל פרויקט: `.opencode/commands/`

```markdown title="~/.config/opencode/commands/test.md"
---
description: הרץ בדיקות עם כיסוי
agent: build
model: anthropic/claude-3-5-sonnet-20241022
---

הרץ את סוויטת הבדיקות המלאה עם דוח כיסוי והצג כל כישלונות.
התמקד בבדיקות שנכשלו והצע הצעות לתיקון.
```

שם קובץ ה-marketing הופך לשם הפקודה. לדוגמה, `test.md` מאפשר לך להריץ:

```bash frame="none"
/test
```

## הגדרת פרומפט

הפרומפטים עבור הפקודות המותאמות אישית תומכים בכמה מציינים מיוחדים ותחביר.

---

### ארגומנטים

העבר ארגומנטים לפקודות באמצעות המציין `$ARGUMENTS`.

```md title=".opencode/commands/component.md"
---
description: צור רכיב חדש
---

צור רכיב React חדש בשם $ARGUMENTS עם תמיכה ב-TypeScript.
כלול הקלדה נכונה ומבנה בסיסי.
```

הרץ את הפקודה עם ארגומנטים:

```bash frame="none"
/component Button
```

ו�-`$ARGUMENTS` יוחלף ב-`Button`.

אתה יכול גם לגשת לארגומנטים בודדים באמצעות פרמטרים מיקומיים:

- `$1` - ארגומנט ראשון
- `$2` - ארגומנט שני
- `$3` - ארגומנט שלישי
- וכן הלאה...

לדוגמה:

```md title=".opencode/commands/create-file.md"
---
description: צור קובץ חדש עם תוכן
---

צור קובץ בשם $1 בספרייה $2
עם התוכן הבא: $3
```

הרץ את הפקודה:

```bash frame="none"
/create-file config.json src "{ \"key\": \"value\" }"
```

זה מחליף:

- `$1` עם `config.json`
- `$2` עם `src`
- `$3` עם `{ "key": "value" }`

---

### פלט Shell

השתמש ב-_!`command`_ כדי להזריק פלט [פקודת bash](/docs/tui#bash-commands) לפרומפט שלך.

לדוגמה, כדי ליצור פקודה מותאמת אישית שמנתחת כיסוי בדיקות:

```md title=".opencode/commands/analyze-coverage.md"
---
description: נתח כיסוי בדיקות
---

הנה תוצאות הבדיקות הנוכחיות:
!`npm test`

בהתבסס על התוצאות הללו, הצע שיפורים כדי להגדיל את הכיסוי.
```

או כדי לסקור שינויים אחרונים:

```md title=".opencode/commands/review-changes.md"
---
description: סקור שינויים אחרונים
---

קומיטים git אחרונים:
!`git log --oneline -10`

סקור את השינויים הללו והצע שיפורים.
```

פקודות רצות בספריית השורש של הפרויקט שלך והפלט שלהם הופך לחלק מהפרומפט.

---

### הפניות קבצים

כלול קבצים בפקודה שלך באמצעות `@` ולאחר מכן שם הקובץ.

```md title=".opencode/commands/review-component.md"
---
description: סקור רכיב
---

סקור את הרכיב ב-@src/components/Button.tsx.
בדוק בעיות ביצוע והצע שיפורים.
```

התוכן של הקובץ משולב אוטומטית בפרומפט.

## אפשרויות

בוא נסתכל באפשרויות ההגדרה בפירוט.

---

### תבנית

אפשרות ה-`template` מגדיר את הפרומפט שיישלח ל-LLM כאשר הפקודה מבוצעת.

```json title="opencode.json"
{
  "command": {
    "test": {
      "template": "הרץ את סוויטת הבדיקות המלאה עם דוח כיסוי והצג כל כישלונות.\nהתמקד בבדיקות שנכשלו והצע הצעות לתיקון."
    }
  }
}
```

זה אפשרות הגדרה **חובה**.

---

### תיאור

השתמש באפשרות `description` כדי לספק תיאור קצר למה הפקודה עושה.

```json title="opencode.json"
{
  "command": {
    "test": {
      "description": "הרץ בדיקות עם כיסוי"
    }
  }
}
```

זה מוצג כתיאור ב-TUI כאשר אתה מקליד את הפקודה.

---

### סוכן

השתמש בהגדרת `agent` כדי לציין באופן איזה [סוכן](/docs/agents) צריך לבצע את הפקודה הזו.
אם זה [סוכן משנה](/docs/agents/#subagents) הפקודה תפעיל קריאה לסוכן משנה כברירת מחדל.
כדי לבטל התנהגות הזו, הגדר `subtask` ל-`false`.

```json title="opencode.json"
{
  "command": {
    "review": {
      "agent": "plan"
    }
  }
}
```

זה אפשרות הגדרה **אופציונלית**. אם לא צוין, ברירת המחדל היא הסוכן הנוכחי שלך.

---

### משימה משנה

השתמש בבוליאן `subtask` כדי לכפות על הפקודה להפעיל קריאה ל[סוכן משנה](/docs/agents/#subagents).
זה שימושי אם אתה רוצה שהפקודה לא תזהם את ההקשר הראשי שלך ותכפה על הסוכן לפעול כסוכן משנה,
גם אם `mode` מוגדר ל-`primary` ב[הגדרת הסוכן](/docs/agents).

```json title="opencode.json"
{
  "command": {
    "analyze": {
      "subtask": true
    }
  }
}
```

זה אפשרות הגדרה **אופציונלית**.

---

### מודל

השתמש בהגדרת `model` כדי לבטל את המודל ברירת המחדל עבור הפקודה הזו.

```json title="opencode.json"
{
  "command": {
    "analyze": {
      "model": "anthropic/claude-3-5-sonnet-20241022"
    }
  }
}
```

זה אפשרות הגדרה **אופציונלית**.

---

## מובנות

opencode כולל כמה פקודות מובנות כמו `/init`, `/undo`, `/redo`, `/share`, `/help`; [למד עוד](/docs/tui#commands).

:::note
פקודות מותאמות אישית יכולות לבטל פקודות מובנות.
:::

אם אתה מגדיר פקודה מותאמת אישית עם אותו שם, היא תבטל את הפקודה המובנית.
