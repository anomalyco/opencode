OpenCode може інтегруватися з серверами Language Server Protocol (LSP) для використання діагностики як зворотного зв'язку для агента.

---

LSP вимкнено за замовчуванням. Якщо увімкнено, сервери запускаються, коли виявляється одне з вищезазначених розширень файлів і виконуються вимоги.

:::note
Ви можете вимкнути автоматичне завантаження LSP серверів, встановивши змінну середовища `OPENCODE_DISABLE_LSP_DOWNLOAD` у `true`.
:::

## Як це працює

Коли LSP увімкнено і opencode відкриває файл, він:

1. Перевіряє розширення файлу на відповідність усім увімкненим LSP серверам.
2. Запускає відповідний LSP сервер, якщо він ще не запущений.

---

## Найкращі практики

LSP може допомогти агенту знаходити та виправляти проблеми, надаючи діагностику від мовних серверів. Це корисно в деяких проєктах, але не завжди є чистим позитивом.

Мовні сервери можуть виходити з синхронізації, використовувати значний обсяг пам'яті, відрізнятися за версією або проєктом та сповільнювати робочі процеси агента. У багатьох проєктах краще, щоб агент запускав інструменти лінту, типізації або інші діагностичні CLI інструменти безпосередньо, щоб помилки поверталися в цикл агента без цих компромісів. Документуйте ці команди у файлах інструкцій, таких як `AGENTS.md` або скіли, щоб агент знав, що запускати. Увімкніть LSP, коли ваш проєкт отримує користь від додаткового зворотного зв'язку від мовного сервера.

## Налаштування

Ви можете ввімкнути та налаштувати LSP сервери через секцію `lsp` у вашому конфігу opencode.

Щоб увімкнути всі вбудовані LSP сервери, встановіть `lsp` у `true`.

```json title="opencode.json"
{
  "$schema": "https://opencode.ai/config.json",
  "lsp": true
}
```

Використовуйте об'єкт, щоб залишити вбудовані увімкненими, налаштовуючи перевизначення або користувацькі сервери.

```json title="opencode.json"
{
  "$schema": "https://opencode.ai/config.json",
  "lsp": {}
}
```

Кожен налаштований запис LSP сервера підтримує наступне:

Записи сервера потребують `command`, якщо вони лише не вимикають сервер.

| Властивість     | Тип     | Опис                                       |
| ---------------- | -------- | ------------------------------------------------- |
| `disabled`       | boolean  | Встановіть `true`, щоб вимкнути LSP сервер      |
| `command`        | string[] | Команда для запуску LSP сервера               |
| `extensions`     | string[] | Розширення файлів, які має обробляти цей LSP сервер     |
| `env`            | object   | Змінні середовища для встановлення під час запуску сервера |
| `initialization` | object   | Опції ініціалізації для надсилання LSP серверу  |

Розглянемо кілька прикладів.

---

### Змінні середовища

Використовуйте властивість `env` для встановлення змінних середовища при запуску LSP сервера:

```json title="opencode.json" {5-8}
{
  "$schema": "https://opencode.ai/config.json",
  "lsp": {
    "rust": {
      "command": ["rust-analyzer"],
      "env": {
        "RUST_LOG": "debug"
      }
    }
  }
}
```

---

### Опції ініціалізації

Використовуйте властивість `initialization` для передачі опцій ініціалізації LSP серверу. Це налаштування, специфічні для сервера, які надсилаються під час LSP запиту `initialize`:

```json title="opencode.json" {5-13}
{
  "$schema": "https://opencode.ai/config.json",
  "lsp": {
    "custom-lsp": {
      "command": ["custom-lsp-server", "--stdio"],
      "extensions": [".custom"],
      "initialization": {
        "preferences": {
          "importModuleSpecifierPreference": "relative"
        }
      }
    }
  }
}
```

:::note
Опції ініціалізації відрізняються залежно від LSP сервера. Перевірте документацію вашого LSP сервера для доступних опцій.
:::

---

### Вимкнення LSP серверів

Якщо `lsp` пропущено, всі LSP сервери вимкнено. Щоб вимкнути всі LSP сервери після того, як інший конфіг їх увімкнув, встановіть `lsp` у `false`:

```json title="opencode.json" {3}
{
  "$schema": "https://opencode.ai/config.json",
  "lsp": false
}
```

Щоб вимкнути **конкретний** LSP сервер, встановіть `disabled` у `true`:

```json title="opencode.json" {5}
{
  "$schema": "https://opencode.ai/config.json",
  "lsp": {
    "typescript": {
      "disabled": true
    }
  }
}
```

---

### Користувацькі LSP сервери

Ви можете додати користувацькі LSP сервери, вказавши команду та розширення файлів:

```json title="opencode.json" {4-7}
{
  "$schema": "https://opencode.ai/config.json",
  "lsp": {
    "custom-lsp": {
      "command": ["custom-lsp-server", "--stdio"],
      "extensions": [".custom"]
    }
  }
}
```

## Додаткова інформація

### PHP Intelephense

PHP Intelephense пропонує преміум-функції через ліцензійний ключ. Ви можете надати ліцензійний ключ, розмістивши (лише) ключ у текстовому файлі за адресою:

- На macOS/Linux: `$HOME/intelephense/license.txt`
- На Windows: `%USERPROFILE%/intelephense/license.txt`

Файл повинен містити лише ліцензійний ключ без додаткового вмісту.
