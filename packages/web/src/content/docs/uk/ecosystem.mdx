Добірка проєктів спільноти, створених на основі OpenCode.

:::note
Хочете додати свій проєкт, пов'язаний з OpenCode, до цього списку? Надішліть PR.
:::

Ви також можете переглянути [awesome-opencode](https://github.com/awesome-opencode/awesome-opencode) та [opencode.cafe](https://opencode.cafe) — спільноту, яка агрегує екосистему та ком'юніті.
