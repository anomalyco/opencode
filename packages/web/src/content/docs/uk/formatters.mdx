---
title: Форматувальники
description: OpenCode використовує форматувальники для конкретних мов.
---

OpenCode може форматувати файли після їх запису або редагування за допомогою мовно-специфічних форматувальників. Форматувальники вимкнені за замовчуванням; увімкніть їх у вашому конфігу, перш ніж OpenCode почне їх запускати.

---

## Вбудовані

OpenCode постачається з кількома вбудованими форматувальниками для популярних мов та фреймворків. Нижче наведено список форматувальників, підтримуваних розширень файлів та необхідних команд або опцій конфігурації.

---

## Як це працює

Коли OpenCode записує або редагує файл і форматувальники увімкнено, він:

1. Перевіряє розширення файлу на відповідність усім увімкненим форматувальникам.
2. Запускає відповідну команду форматувальника на файлі.
3. Застосовує зміни форматування.

Цей процес відбувається у фоновому режимі для увімкнених форматувальників.

---

## Налаштування

Ви можете ввімкнути та налаштувати форматувальники через секцію `formatter` у вашому конфігу OpenCode.

Щоб увімкнути всі вбудовані форматувальники, встановіть `formatter` у `true`.

```json title="opencode.json"
{
  "$schema": "https://opencode.ai/config.json",
  "formatter": true
}
```

Використовуйте об'єкт, щоб залишити вбудовані увімкненими, налаштовуючи перевизначення або користувацькі форматувальники.

```json title="opencode.json"
{
  "$schema": "https://opencode.ai/config.json",
  "formatter": {}
}
```

Кожна конфігурація форматувальника підтримує наступне:

| Властивість  | Тип     | Опис                                                                                |
| ------------- | -------- | ------------------------------------------------------------------------------------------ |
| `disabled`    | boolean  | Встановіть `true`, щоб вимкнути форматувальник                                                |
| `command`     | string[] | Команда для запуску форматування. Обов'язково для користувацьких форматувальників; опціонально для вбудованих. |
| `environment` | object   | Змінні середовища для встановлення під час запуску форматувальника                                    |
| `extensions`  | string[] | Розширення файлів, які має обробляти цей форматувальник                                               |

Розглянемо кілька прикладів.

---

### Вимкнення форматувальників

Якщо `formatter` пропущено, всі форматувальники вимкнено. Щоб вимкнути всі форматувальники після того, як інший конфіг їх увімкнув, встановіть `formatter` у `false`:

```json title="opencode.json" {3}
{
  "$schema": "https://opencode.ai/config.json",
  "formatter": false
}
```

Щоб вимкнути **конкретний** форматувальник, встановіть `disabled` у `true`:

```json title="opencode.json" {5}
{
  "$schema": "https://opencode.ai/config.json",
  "formatter": {
    "prettier": {
      "disabled": true
    }
  }
}
```

---

### Користувацькі форматувальники

Ви можете налаштувати вбудовані форматувальники з опціями, як `environment` або `extensions`. Щоб додати користувацький форматувальник, вкажіть `command` та `extensions`:

```json title="opencode.json" {4-14}
{
  "$schema": "https://opencode.ai/config.json",
  "formatter": {
    "prettier": {
      "command": ["npx", "prettier", "--write", "$FILE"],
      "environment": {
        "NODE_ENV": "development"
      },
      "extensions": [".js", ".ts", ".jsx", ".tsx"]
    },
    "custom-markdown-formatter": {
      "command": ["deno", "fmt", "$FILE"],
      "extensions": [".md"]
    }
  }
}
```

**Плейсхолдер `$FILE`** у команді буде замінено на шлях до файлу, який форматується.
