[**OpenCode**](/) — це відкритий AI-агент для програмування. Він доступний як термінальний інтерфейс, десктопний застосунок або розширення для IDE.

![OpenCode TUI з темою opencode](../../../assets/lander/screenshot.png)

Почнімо.

---

#### Передумови

Щоб використовувати OpenCode у терміналі, вам знадобиться:

1. Сучасний емулятор термінала, наприклад:
   - [WezTerm](https://wezterm.org), кросплатформний
   - [Alacritty](https://alacritty.org), кросплатформний
   - [Ghostty](https://ghostty.org), Linux та macOS
   - [Kitty](https://sw.kovidgoyal.net/kitty/), Linux та macOS

2. Ключі API для провайдерів LLM, які ви плануєте використовувати.

---

## Встановлення

Найпростіший спосіб встановити OpenCode — через скрипт встановлення.

```bash
curl -fsSL https://opencode.ai/install | bash
```

Ви також можете встановити його за допомогою наступних команд:

- **Використовуючи Node.js**

        <Tabs>

      <TabItem label="npm">
      ```bash
      npm install -g opencode-ai
      ```

          </TabItem>

        <TabItem label="Bun">
        ```bash
        bun install -g opencode-ai
        ```

          </TabItem>

        <TabItem label="pnpm">
        ```bash
        pnpm install -g opencode-ai
        ```

          </TabItem>

        <TabItem label="Yarn">
        ```bash
        yarn global add opencode-ai
        ```

      </TabItem>

  </Tabs>

- **Використовуючи Homebrew на macOS та Linux**

  ```bash
  brew install anomalyco/tap/opencode
  ```

  > Ми рекомендуємо використовувати tap OpenCode для найсвіжіших релізів. Офіційний `brew install opencode` підтримується командою Homebrew та оновлюється рідше.

- **Встановлення на Arch Linux**

  ```bash
  sudo pacman -S opencode           # Arch Linux (Стабільна)
  paru -S opencode-bin              # Arch Linux (Найновіша з AUR)
  ```

#### Windows

:::tip[Рекомендація: Використовуйте WSL]
Для найкращого досвіду на Windows ми рекомендуємо використовувати [Підсистему Windows для Linux (WSL)](/docs/windows-wsl). Вона забезпечує кращу продуктивність та повну сумісність з функціями OpenCode.
:::

- **Використовуючи Chocolatey**

  ```bash
  choco install opencode
  ```

- **Використовуючи Scoop**

  ```bash
  scoop install opencode
  ```

- **Використовуючи NPM**

  ```bash
  npm install -g opencode-ai
  ```

- **Використовуючи Mise**

  ```bash
  mise use -g github:anomalyco/opencode
  ```

- **Використовуючи Docker**

  ```bash
  docker run -it --rm ghcr.io/anomalyco/opencode
  ```

Підтримка встановлення OpenCode на Windows за допомогою Bun наразі в процесі розробки.

Ви також можете завантажити бінарний файл зі [сторінки релізів](https://github.com/anomalyco/opencode/releases).

## Налаштування

З OpenCode ви можете використовувати будь-якого LLM-провайдера, налаштувавши їхні ключі API.

Якщо ви новачок у використанні LLM-провайдерів, ми рекомендуємо [OpenCode Zen](/docs/zen).
Це добірка моделей, які були протестовані та перевірені командою OpenCode.

1. Виконайте команду `/connect` у TUI, виберіть opencode та перейдіть на [opencode.ai/auth](https://opencode.ai/auth).

   ```txt
   /connect
   ```

2. Увійдіть, додайте платіжні дані та скопіюйте ваш ключ API.

3. Вставте ваш ключ API.

   ```txt
   ┌ API key
   │
   │
   └ enter
   ```

Або ви можете вибрати одного з інших провайдерів. [Дізнатися більше](/docs/providers#directory).

## Ініціалізація

Тепер, коли ви налаштували провайдера, перейдіть до проєкту,
над яким хочете працювати.

```bash
cd /path/to/project
```

Запустіть OpenCode.

```bash
opencode
```

Далі ініціалізуйте OpenCode для проєкту, виконавши наступну команду.

```bash frame="none"
/init
```

Це змусить OpenCode проаналізувати ваш проєкт і створити файл `AGENTS.md`
в корені проєкту.

:::tip
Ви повинні закомітити файл `AGENTS.md` вашого проєкту до Git.
:::

Це допомагає OpenCode зрозуміти структуру проєкту та патерни
кодування, що використовуються.

## Використання

Тепер ви готові використовувати OpenCode для роботи над вашим проєктом. Не соромтеся питати його
про що завгодно!

Якщо ви новачок у використанні AI-агента для програмування, ось кілька прикладів, які можуть
допомогти.

---

### Запитання

Ви можете попросити OpenCode пояснити вам кодову базу.

:::tip
Використовуйте клавішу `@` для нечіткого пошуку файлів у проєкті.
:::

```txt frame="none" "@packages/functions/src/api/index.ts"
Як реалізована аутентифікація в @packages/functions/src/api/index.ts
```

Це корисно, якщо є частина кодової бази, над якою ви не працювали.

---

### Додавання функцій

Ви можете попросити OpenCode додати нові функції до вашого проєкту. Однак ми рекомендуємо спочатку попросити його створити план.

1. **Створіть план**

   OpenCode має _Режим планування_, який вимикає можливість вносити зміни,
   а натомість пропонує _як_ він реалізує функцію.

   Перемкніться на нього за допомогою клавіші **Tab**. Ви побачите індикатор цього в нижньому правому куті.

   ```bash frame="none" title="Перемикання в режим планування"
   <TAB>
   ```

   Тепер опишіть, що ви хочете, щоб він зробив.

   ```txt frame="none"
   Коли користувач видаляє нотатку, ми хочемо позначити її як видалену в базі даних.
   Потім створіть екран, що показує всі нещодавно видалені нотатки.
   З цього екрана користувач може відновити нотатку або назавжди її видалити.
   ```

   Дайте OpenCode достатньо деталей, щоб він зрозумів, що ви хочете. Корисно
   розмовляти з ним, як з молодшим розробником у вашій команді.

   :::tip
   Давайте OpenCode достатньо контексту та прикладів, щоб допомогти йому зрозуміти, що ви
   хочете.
   :::

2. **Доопрацюйте план**

   Як тільки він надасть план, ви можете дати зворотний зв'язок або додати більше деталей.

   ```txt frame="none"
   Ми хотіли б розробити цей новий екран, використовуючи дизайн, який я використовував раніше.
   [Image #1] Подивіться на це зображення та використайте його як зразок.
   ```

   :::tip
   Перетягуйте зображення в термінал, щоб додавати їх до запиту.
   :::

   OpenCode може сканувати будь-які зображення, які ви йому даєте, та додавати їх до запиту. Ви можете
   зробити це, перетягнувши зображення в термінал.

3. **Реалізуйте функцію**

   Коли ви будете задоволені планом, перемкніться назад у _Режим розробки_,
   натиснувши клавішу **Tab** знову.

   ```bash frame="none"
   <TAB>
   ```

   І попросіть його внести зміни.

   ```bash frame="none"
   Звучить добре! Вперед, внось зміни.
   ```

---

### Внесення змін

Для більш простих змін ви можете попросити OpenCode одразу реалізувати їх,
без попереднього перегляду плану.

```txt frame="none" "@packages/functions/src/settings.ts" "@packages/functions/src/notes.ts"
Нам потрібно додати аутентифікацію до маршруту /settings. Подивіться, як це
реалізовано в маршруті /notes у @packages/functions/src/notes.ts та реалізуйте
ту саму логіку в @packages/functions/src/settings.ts
```

Переконайтеся, що ви надаєте достатньо деталей, щоб OpenCode вніс правильні
зміни.

---

### Скасування змін

Припустимо, ви попросили OpenCode внести деякі зміни.

```txt frame="none" "@packages/functions/src/api/index.ts"
Можеш рефакторити функцію в @packages/functions/src/api/index.ts?
```

Але ви розумієте, що це не те, що ви хотіли. Ви **можете скасувати** зміни
за допомогою команди `/undo`.

```bash frame="none"
/undo
```

OpenCode скасує внесені зміни та покаже ваше оригінальне повідомлення
знову.

```txt frame="none" "@packages/functions/src/api/index.ts"
Можеш рефакторити функцію в @packages/functions/src/api/index.ts?
```

Звідси ви можете змінити запит і попросити OpenCode спробувати знову.

:::tip
Ви можете виконати `/undo` кілька разів, щоб скасувати кілька змін.
:::

Або ви **можете повернути** зміни за допомогою команди `/redo`.

```bash frame="none"
/redo
```

## Поширення

Розмови, які ви ведете з OpenCode, можна [поширювати серед вашої
команди](/docs/share).

```bash frame="none"
/share
```

Це створить посилання на поточну розмову та скопіює його в буфер обміну.

:::note
Розмови не поширюються за замовчуванням.
:::

Ось [приклад розмови](https://opencode.ai/s/4XP1fce5) з OpenCode.
