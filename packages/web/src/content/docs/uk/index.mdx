[**OpenCode**](/) — це AI-агент для програмування з відкритим кодом. Він доступний у вигляді інтерфейсу для термінала, десктопного застосунку або розширення для IDE.

![OpenCode TUI з темою opencode](../../../assets/lander/screenshot.png)

Давайте розпочнемо.

---

#### Системні вимоги

Щоб використовувати OpenCode у своєму терміналі, вам знадобляться:

1. Сучасний емулятор термінала, наприклад:
   - [WezTerm](https://wezterm.org), кросплатформний
   - [Alacritty](https://alacritty.org), кроссплатформний
   - [Ghostty](https://ghostty.org), Linux та macOS
   - [Kitty](https://sw.kovidgoyal.net/kitty/), Linux та macOS

2. Ключі API для провайдерів LLM, які ви плануєте використовувати.

## Встановлення

Найпростіший спосіб встановити OpenCode — через скрипт встановлення.

```bash
curl -fsSL https://opencode.ai/install | bash
```

Ви також можете встановити його за допомогою таких команд:

- **Використовуючи Node.js**

        <Tabs>

      <TabItem label="npm">
      ```bash
      npm install -g opencode-ai
      ```

          </TabItem>

        <TabItem label="Bun">
         ```bash
         bun install -g opencode-ai
         ```

          </TabItem>

        <TabItem label="pnpm">
         ```bash
         pnpm install -g opencode-ai
         ```

          </TabItem>

        <TabItem label="Yarn">
         ```bash
         yarn global add opencode-ai
         ```

      </TabItem>

  </Tabs>

- **Використовуючи Homebrew на macOS та Linux**

  ```bash
  brew install anomalyco/tap/opencode
  ```

  > Ми рекомендуємо використовувати tap OpenCode, щоб завжди отримувати найактуальніші релізи. Офіційна формула `brew install opencode` підтримується командою Homebrew і оновлюється рідше.

- **Встановлення на Arch Linux**

  ```bash
  sudo pacman -S opencode           # Arch Linux (Stable)
  paru -S opencode-bin              # Arch Linux (Остання версія з AUR)
  ```

#### Windows

:::tip[Рекомендовано: використовуйте WSL]
Для найкращого досвіду роботи на Windows ми рекомендуємо використовувати [підсистему Windows для Linux (WSL)](/docs/windows-wsl). Вона забезпечує кращу продуктивність та повну сумісність із функціями OpenCode.
:::

- **Використовуючи Chocolatey**

  ```bash
  choco install opencode
  ```

- **Використовуючи Scoop**

  ```bash
  scoop install opencode
  ```

- **Використовуючи NPM**

  ```bash
  npm install -g opencode-ai
  ```

- **Використовуючи Mise**

  ```bash
  mise use -g github:anomalyco/opencode
  ```

- **Використовуючи Docker**

  ```bash
  docker run -it --rm ghcr.io/anomalyco/opencode
  ```

Наразі триває робота над підтримкою встановлення OpenCode на Windows за допомогою Bun.

Ви також можете завантажити бінарні файли безпосередньо зі сторінки [Релізів (Releases)](https://github.com/anomalyco/opencode/releases).

## Налаштування

З OpenCode ви можете використовувати будь-якого провайдера LLM, налаштувавши їхні ключі API.

Якщо ви раніше не користувалися провайдерами LLM, ми рекомендуємо спробувати [OpenCode Zen](/docs/zen).
Це відібраний список моделей, які були перевірені та протестовані командою OpenCode.

1. Запустіть команду `/connect` у TUI, виберіть OpenCode та перейдіть на сторінку [opencode.ai/auth](https://opencode.ai/auth).

   ```txt
   /connect
   ```

2. Увійдіть у свій обліковий запис, додайте платіжні реквізити та скопіюйте свій ключ API.

3. Вставте свій ключ API.

   ```txt
   ┌ API key
   │
   │
   └ enter
   ```

Крім того, ви можете вибрати будь-якого іншого провайдера. [Дізнатися більше](/docs/providers#directory).

## Ініціалізація

Тепер, коли ви налаштували провайдера, ви можете перейти до каталогу проєкту, над яким хочете працювати.

```bash
cd /path/to/project
```

Та запустити OpenCode.

```bash
opencode
```

Далі ініціалізуйте OpenCode для вашого проєкту, виконавши таку команду.

```bash frame="none"
/init
```

Це дозволить OpenCode проаналізувати ваш проєкт та створити файл `AGENTS.md` у його корені.

:::tip
Рекомендується зберегти файл проєкту `AGENTS.md` у Git.
:::

Це допомагає OpenCode розуміти структуру проєкту та використані шаблони кодування.

## Використання

Тепер ви готові використовувати OpenCode для роботи над вашим проєктом. Не соромтеся запитувати його про що завгодно!

Якщо ви вперше використовуєте AI-агента для програмування, ось кілька прикладів, які можуть допомогти.

---

### Ставити запитання

Ви можете попросити OpenCode пояснити вам структуру кодової бази.

:::tip
Використовуйте клавішу `@`, щоб здійснювати нечіткий пошук файлів у проєкті.
:::

```txt frame="none" "@packages/functions/src/api/index.ts"
Як реалізовано автентифікацію в @packages/functions/src/api/index.ts
```

Це особливо корисно, якщо ви працюєте над частиною кодової бази, яку писали не ви.

---

### Додавання функцій

Ви можете попросити OpenCode додати нові функції у ваш проєкт. Проте спочатку рекомендується попросити його створити план.

1. **Створення плану**

   OpenCode має спеціальний _режим планування (Plan mode)_, який вимикає можливість вносити зміни, натомість агент пропонує, _як саме_ він реалізує нову функцію.

   Перемкніться на нього за допомогою клавіші **Tab**. Ви побачите відповідний індикатор у правому нижньому кутку.

   ```bash frame="none" title="Перемкнутися в режим планування"
   <TAB>
   ```

   Тепер опишемо, що саме потрібно зробити:

   ```txt frame="none"
   Коли користувач видаляє нотатку, ми хочемо позначити її як видалену в базі даних.
   Потім створити екран, який показує всі нещодавно видалені нотатки.
   На цьому екрані користувач може відновити нотатку або видалити її назавжди.
   ```

   Надайте OpenCode достатньо деталей для розуміння завдання. Спілкуйтеся з ним так, ніби ви пояснюєте завдання молодшому розробнику (junior) у вашій команді.

   :::tip
   Надавайте OpenCode якомога більше контексту та прикладів, щоб допомогти йому зрозуміти ваші вимоги.
   :::

2. **Оновлення та ітерація плану**

   Коли агент запропонує вам план, ви можете надати свій відгук або додати нові вимоги.

   ```txt frame="none"
   Ми хочемо розробити цей новий екран, використовуючи дизайн, який я застосовував раніше.
   [Зображення #1] Подивися на це зображення та використай його як референс.
   ```

   :::tip
   Перетягуйте зображення в термінал, щоб додати їх до вашого запиту.
   :::

   OpenCode може сканувати будь-які надіслані зображення та додавати їх до запиту. Для цього просто перетягніть файл зображення у вікно термінала.

3. **Створення функції**

   Коли ви погодитеся з планом, перемкніться назад у _режим розробки (Build mode)_, знову натиснувши клавішу **Tab**.

   ```bash frame="none"
   <TAB>
   ```

   І попросіть агента внести зміни.

   ```bash frame="none"
   Чудово! Починай вносити зміни.
   ```

---

### Швидкі зміни

Для простіших змін ви можете попросити OpenCode відразу внести зміни без попереднього створення плану.

```txt frame="none" "@packages/functions/src/settings.ts" "@packages/functions/src/notes.ts"
Нам потрібно додати автентифікацію для маршруту /settings. Подивися, як це зроблено в маршруті /notes у @packages/functions/src/notes.ts, та реалізуй таку ж логіку в @packages/functions/src/settings.ts
```

Намагайтеся надавати достатньо деталей, щоб OpenCode міг внести точні зміни.

---

### Скасування змін

Уявімо, що ви попросили OpenCode виконати деякі зміни.

```txt frame="none" "@packages/functions/src/api/index.ts"
Чи можеш ти зробити рефакторинг функції в @packages/functions/src/api/index.ts?
```

Але потім ви зрозуміли, що це не зовсім те, що вам потрібно. Ви **можете скасувати** ці зміни за допомогою команди `/undo`.

```bash frame="none"
/undo
```

OpenCode поверне стан файлів до початкового та знову покаже ваше вихідне повідомлення.

```txt frame="none" "@packages/functions/src/api/index.ts"
Чи можеш ти зробити рефакторинг функції в @packages/functions/src/api/index.ts?
```

Тут ви можете змінити ваш запит та попросити OpenCode спробувати ще раз.

:::tip
Ви можете виконати команду `/undo` кілька разів, щоб скасувати декілька останніх змін поспіль.
:::

Також ви **можете повернути** скасовані зміни за допомогою команди `/redo`.

```bash frame="none"
/redo
```

## Обмін сесіями

Історією вашого діалогу з OpenCode можна [поділитися з вашою командою](/docs/share).

```bash frame="none"
/share
```

Це створить публічне посилання на поточну сесію та скопіює його у ваш буфер обміну.

:::note
Діалоги не поширюються публічно за замовчуванням.
:::

Ось [приклад поширеної сесії](https://opencode.ai/s/4XP1fce5) з OpenCode.
