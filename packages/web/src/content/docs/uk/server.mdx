Команда `opencode serve` запускає безголовий HTTP-сервер, який надає кінцеву точку OpenAPI, яку може використовувати клієнт opencode.

---

### Використання

```bash
opencode serve [--port <number>] [--hostname <string>] [--cors <origin>]
```

#### Параметри

| Прапор          | Опис                                 | За замовчуванням |
| --------------- | ------------------------------------ | ---------------- |
| `--port`        | Порт для прослуховування             | `4096`           |
| `--hostname`    | Ім'я хоста для прослуховування       | `127.0.0.1`      |
| `--mdns`        | Увімкнути mDNS-виявлення             | `false`          |
| `--mdns-domain` | Власне доменне ім'я для mDNS-сервісу | `opencode.local` |
| `--cors`        | Додаткові джерела браузера           | `[]`             |

`--cors` можна передавати кілька разів:

```bash
opencode serve --cors http://localhost:5173 --cors https://app.example.com
```

---

### Автентифікація

Встановіть `OPENCODE_SERVER_PASSWORD` для захисту сервера за допомогою HTTP basic auth. Ім'я користувача за замовчуванням — `opencode`, або встановіть `OPENCODE_SERVER_USERNAME` для його зміни. Це стосується як `opencode serve`, так і `opencode web`.

```bash
OPENCODE_SERVER_PASSWORD=your-password opencode serve
```

---

### Як це працює

Коли ви запускаєте `opencode`, він запускає TUI та сервер. TUI є
клієнтом, який спілкується з сервером. Сервер надає кінцеву точку зі специфікацією OpenAPI 3.1.
Ця кінцева точка також використовується для генерації [SDK](/docs/sdk).

:::tip
Використовуйте сервер opencode для програмної взаємодії з opencode.
:::

Така архітектура дозволяє opencode підтримувати кількох клієнтів і дає вам змогу взаємодіяти з opencode програмно.

Ви можете запустити `opencode serve`, щоб запустити окремий сервер. Якщо у вас
запущено TUI opencode, `opencode serve` запустить новий сервер.

---

#### Підключення до існуючого сервера

Коли ви запускаєте TUI, він випадковим чином призначає порт та ім'я хоста. Натомість ви можете передати прапорці `--hostname` та `--port` [flags](/docs/cli). Потім використовуйте це для підключення до його сервера.

Кінцева точка [`/tui`](#tui) може використовуватися для керування TUI через сервер. Наприклад, ви можете попередньо заповнити або запустити запит. Це налаштування використовується плагінами OpenCode [IDE](/docs/ide).

---

## Специфікація

Сервер публікує специфікацію OpenAPI 3.1, яку можна переглянути за адресою:

```
http://<hostname>:<port>/doc
```

Наприклад, `http://localhost:4096/doc`. Використовуйте специфікацію для генерації клієнтів або перегляду типів запитів і відповідей. Або перегляньте її в оглядачі Swagger.

### Files

| Метод  | Шлях                      | Опис                               | Відповідь                                                                                   |
| ------ | ------------------------- | ---------------------------------- | ------------------------------------------------------------------------------------------- |
| `GET`  | `/find?pattern=<pat>`     | Пошук тексту у файлах              | Масив об'єктів збігів з `path`, `lines`, `line_number`, `absolute_offset`, `submatches`    |
| `GET`  | `/find/file?query=<q>`    | Пошук файлів і каталогів за назвою | `string[]` (шляхи)                                                                          |
| `GET`  | `/find/symbol?query=<q>`  | Пошук символів робочої області     | <a href={typesUrl}><code>Symbol[]</code></a>                                               |
| `GET`  | `/file?path=<path>`       | Список файлів і каталогів          | <a href={typesUrl}><code>FileNode[]</code></a>                                             |
| `GET`  | `/file/content?path=<p>`  | Читання файлу                      | <a href={typesUrl}><code>FileContent</code></a>                                            |
| `GET`  | `/file/status`            | Статус відстежуваних файлів        | <a href={typesUrl}><code>File[]</code></a>                                                 |

#### Параметри запиту `/find/file`

- `query` (обов'язкове) — рядок пошуку (нечіткий збіг)
- `type` (необов'язкове) — обмежити результати до `"file"` або `"directory"`
- `directory` (необов'язкове) — перевизначити корінь проєкту для пошуку
- `limit` (необов'язкове) — максимальна кількість результатів (1–200)
- `dirs` (необов'язкове) — застарілий прапорець (`"false"` повертає лише файли)
