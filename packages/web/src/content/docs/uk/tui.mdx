OpenCode надає інтерактивний термінальний інтерфейс (TUI) для роботи над вашими проєктами з LLM.

Запуск OpenCode запускає TUI для поточного каталогу.

```bash
opencode
```

Або ви можете запустити його для конкретного робочого каталогу.

```bash
opencode /path/to/project
```

Опинившись у TUI, ви можете дати йому запит.

```text
Надай короткий підсумок кодової бази.
```

---

## Посилання на файли

Ви можете посилатися на файли у ваших повідомленнях за допомогою `@`. Це виконує нечіткий пошук файлів у поточному робочому каталозі.

:::tip
Ви також можете використовувати `@` для посилання на файли у ваших повідомленнях.
:::

```text "@packages/functions/src/api/index.ts"
Як реалізована аутентифікація в @packages/functions/src/api/index.ts?
```

Вміст файлу додається до розмови автоматично.

Налаштовані [посилання](/docs/references) також з'являються в автодоповненні `@`. Введіть `@alias`, щоб додати корінь посилання як контекст, або введіть `@alias/`, щоб автодоповнити файли всередині цього посилання.

```text "@docs/README.md"
Порівняйте наше налаштування з @docs/README.md
```

## Команди Bash

Почніть повідомлення з `!`, щоб виконати команду оболонки.

```bash frame="none"
!ls -la
```

Вивід команди додається до розмови як результат інструмента.

---

## Команди

При використанні TUI OpenCode ви можете ввести `/` після назви команди, щоб швидко виконати дії. Наприклад:

```bash frame="none"
/help
```

Більшість команд також мають комбінації клавіш, використовуючи `ctrl+x` як клавішу-лідер за замовчуванням. [Дізнатися більше](/docs/keybinds).

Ось усі доступні слеш-команди:

---

### connect

Додати провайдера до OpenCode. Дозволяє вибрати з доступних провайдерів та додати їхні ключі API.

```bash frame="none"
/connect
```

---

### compact

Ущільнити поточну сесію. _Псевдонім_: `/summarize`

```bash frame="none"
/compact
```

**Комбінація клавіш:** `ctrl+x c`

---

### details

Перемкнути деталі виконання інструментів.

```bash frame="none"
/details
```

---

### editor

Відкрити зовнішній редактор для написання повідомлень. Використовує редактор, встановлений у вашій змінній середовища `EDITOR`. [Дізнатися більше](#налаштування-редактора).

```bash frame="none"
/editor
```

**Комбінація клавіш:** `ctrl+x e`

---

### exit

Вийти з OpenCode. _Псевдоніми_: `/quit`, `/q`

```bash frame="none"
/exit
```

**Комбінація клавіш:** `ctrl+x q`

---

### export

Експортувати поточну розмову в Markdown та відкрити у вашому редакторі за замовчуванням. Використовує редактор, встановлений у вашій змінній середовища `EDITOR`. [Дізнатися більше](#налаштування-редактора).

```bash frame="none"
/export
```

**Комбінація клавіш:** `ctrl+x x`

---

### help

Показати довідкове діалогове вікно.

```bash frame="none"
/help
```

---

### init

Покрокове налаштування для створення або оновлення `AGENTS.md`. [Дізнатися більше](/docs/rules).

```bash frame="none"
/init
```

---

### models

Список доступних моделей.

```bash frame="none"
/models
```

**Комбінація клавіш:** `ctrl+x m`

---

### new

Почати нову сесію. _Псевдонім_: `/clear`

```bash frame="none"
/new
```

**Комбінація клавіш:** `ctrl+x n`

---

### redo

Повернути раніше скасоване повідомлення. Доступно лише після використання `/undo`.

:::tip
Будь-які зміни файлів також будуть відновлені.
:::

Внутрішньо це використовує Git для керування змінами файлів. Тому ваш проєкт **має
бути Git-репозиторієм**.

```bash frame="none"
/redo
```

**Комбінація клавіш:** `ctrl+x r`

---

### sessions

Список сесій та перемикання між ними. _Псевдоніми_: `/resume`, `/continue`

```bash frame="none"
/sessions
```

**Комбінація клавіш:** `ctrl+x l`

---

### share

Поширити поточну сесію. [Дізнатися більше](/docs/share).

```bash frame="none"
/share
```

---

### themes

Список доступних тем.

```bash frame="none"
/themes
```

**Комбінація клавіш:** `ctrl+x t`

---

### thinking

Перемкнути видимість блоків міркувань/роздумів у розмові. Якщо ввімкнено, ви можете бачити процес міркування моделі для моделей, що підтримують розширене мислення.

:::note
Ця команда контролює лише чи **відображаються** блоки міркувань — вона не вмикає та не вимикає здатність моделі до міркування. Щоб перемкнути фактичні можливості міркування, використовуйте `ctrl+t` для циклічного перегляду варіантів моделі.
:::

```bash frame="none"
/thinking
```

---

### undo

Скасувати останнє повідомлення в розмові. Видаляє найновіше повідомлення користувача, всі наступні відповіді та будь-які зміни файлів.

:::tip
Будь-які зміни файлів також будуть скасовані.
:::

Внутрішньо це використовує Git для керування змінами файлів. Тому ваш проєкт **має
бути Git-репозиторієм**.

```bash frame="none"
/undo
```

**Комбінація клавіш:** `ctrl+x u`

---

### unshare

Припинити поширення поточної сесії. [Дізнатися більше](/docs/share#un-sharing).

```bash frame="none"
/unshare
```

## Налаштування редактора

Команди `/editor` та `/export` використовують редактор, вказаний у вашій змінній середовища `EDITOR`.

<Tabs>
  <TabItem label="Linux/macOS">
    ```bash
    # Приклад для nano або vim
    export EDITOR=nano
    export EDITOR=vim

    # Для графічних редакторів: VS Code, Cursor, VSCodium, Windsurf, Zed тощо.
    # додайте --wait
    export EDITOR="code --wait"
    ```

    Щоб зробити це постійним, додайте це до вашого профілю оболонки;
    `~/.bashrc`, `~/.zshrc` тощо.

  </TabItem>

  <TabItem label="Windows (CMD)">
    ```bash
    set EDITOR=notepad

    # Для графічних редакторів: VS Code, Cursor, VSCodium, Windsurf, Zed тощо.
    # додайте --wait
    set EDITOR=code --wait
    ```

    Щоб зробити це постійним, використовуйте **Системні властивості** > **Змінні
    середовища**.

  </TabItem>

  <TabItem label="Windows (PowerShell)">
    ```powershell
    $env:EDITOR = "notepad"

    # Для графічних редакторів: VS Code, Cursor, VSCodium, Windsurf, Zed тощо.
    # додайте --wait
    $env:EDITOR = "code --wait"
    ```

    Щоб зробити це постійним, додайте це до вашого профілю PowerShell.

  </TabItem>
</Tabs>

Популярні варіанти редакторів:

- `code` - Visual Studio Code
- `cursor` - Cursor
- `windsurf` - Windsurf
- `nvim` - Редактор Neovim
- `vim` - Редактор Vim
- `nano` - Редактор Nano
- `notepad` - Блокнот Windows
- `subl` - Sublime Text

:::note
Деякі редактори, як-от VS Code, потрібно запускати з прапорцем `--wait`.
:::

Деякі редактори потребують аргументів командного рядка для роботи в режимі блокування. Прапорець `--wait` змушує редактор блокувати роботу до закриття.

## Налаштування

Ви можете налаштувати поведінку TUI через `tui.json` (або `tui.jsonc`).

```json title="tui.json"
{
  "$schema": "https://opencode.ai/tui.json",
  "theme": "opencode",
  "leader_timeout": 2000,
  "keybinds": {
    "leader": "ctrl+x",
    "command_list": "ctrl+p"
  },
  "scroll_speed": 3,
  "scroll_acceleration": {
    "enabled": false
  },
  "diff_style": "auto",
  "mouse": true,
  "attention": {
    "enabled": true,
    "notifications": true,
    "sound": true,
    "volume": 0.4,
    "sound_pack": "opencode.default",
    "sounds": {
      "error": "./sounds/error.mp3"
    }
  }
}
```

Це окремо від `opencode.json`, який налаштовує поведінку сервера/середовища виконання.

`keybinds` об'єднується з вбудованими стандартними налаштуваннями, тому вам потрібно налаштовувати лише ті комбінації, які ви хочете змінити.

### Параметри

- `theme` — Встановлює тему UI. [Дізнатися більше](/docs/themes).
- `keybinds` — Налаштовує комбінації клавіш. [Дізнатися більше](/docs/keybinds).
- `leader_timeout` — Контролює, як довго OpenCode чекає після клавіші-лідера. Стандартне значення: `2000`.
- `scroll_acceleration.enabled` — Увімкнути прискорення прокрутки в стилі macOS для плавної, природної прокрутки. Якщо ввімкнено, швидкість прокрутки збільшується при швидких жестах прокрутки та залишається точною для повільних рухів. **Цей параметр має перевагу над `scroll_speed` та перевизначає його, коли ввімкнено.**
- `scroll_speed` — Контролює швидкість прокрутки TUI при використанні команд прокрутки (мінімум: `0.001`, підтримує десяткові значення). Стандартне значення: `3`. **Примітка: ігнорується, якщо `scroll_acceleration.enabled` встановлено в `true`.**
- `diff_style` — Контролює відображення diff. `"auto"` адаптується до ширини термінала, `"stacked"` завжди показує одноколонковий макет.
- `mouse` — Увімкнути або вимкнути захоплення миші в TUI (стандартно: `true`). Якщо вимкнено, зберігається рідна поведінка вибору/прокрутки миші термінала.
- `attention` — Налаштовує сповіщення робочого столу та звуки TUI. Вимкнено за замовчуванням.

Використовуйте `OPENCODE_TUI_CONFIG`, щоб завантажити власний шлях до конфігурації TUI.

### Увага

TUI може запитувати увагу для запитань, дозволів, помилок сесії та завершених сесій. Увімкніть за допомогою `attention.enabled`; вбудовані події відтворюють звуки при спрацьовуванні, а події, що не є подіями субагента, запитують сповіщення робочого столу лише коли термінал не в фокусі.

- `enabled` — Увімкнути всі сповіщення уваги та звуки. Стандартно: `false`.
- `notifications` — Дозволити сповіщення робочого столу через термінал, коли увагу ввімкнено. Стандартно: `true`.
- `sound` — Дозволити звуки уваги, коли увагу ввімкнено. Стандартно: `true`.
- `volume` — Стандартна гучність звуку від `0` до `1`. Стандартно: `0.4`.
- `sound_pack` — ID звукового пакунка. Стандартно: `opencode.default`.
- `sounds` — Перевизначити звукові файли для `default`, `question`, `permission`, `error`, `done` або `subagent_done`. Шляхи можуть бути абсолютними, `file://` URL або відносними до `tui.json`.

## Налаштування

Ви можете налаштувати різні аспекти вигляду TUI за допомогою палітри команд (`ctrl+p`). Ці налаштування зберігаються після перезапуску.

---

#### Відображення імені користувача

Перемкнути, чи відображається ваше ім'я користувача в повідомленнях чату. Доступ через:

- Палітру команд: знайдіть "username" або "hide username"
- Налаштування зберігається автоматично та запам'ятовується між сесіями TUI
