OpenCode може працювати як веб-застосунок у вашому браузері, надаючи той самий потужний AI-досвід програмування без необхідності у терміналі.

![OpenCode Web - Нова сесія](../../../assets/web/web-homepage-new-session.png)

## Початок роботи

Запустіть веб-інтерфейс, виконавши:

```bash
opencode web
```

Це запускає локальний сервер на `127.0.0.1` з випадковим доступним портом та автоматично відкриває OpenCode у вашому браузері за замовчуванням.

:::caution
Якщо `OPENCODE_SERVER_PASSWORD` не встановлено, сервер буде незахищеним. Це нормально для локального використання, але слід встановити для мережевого доступу.
:::

:::tip[Користувачам Windows]
Для найкращого досвіду запускайте `opencode web` з [WSL](/docs/windows-wsl), а не з PowerShell. Це забезпечує належний доступ до файлової системи та інтеграцію термінала.
:::

## Налаштування

Ви можете налаштувати веб-сервер за допомогою прапорців командного рядка або у вашому [файлі конфігурації](/docs/config).

### Порт

За замовчуванням OpenCode обирає доступний порт. Ви можете вказати порт:

```bash
opencode web --port 4096
```

### Ім'я хоста

За замовчуванням сервер прив'язується до `127.0.0.1` (тільки localhost). Щоб зробити OpenCode доступним у вашій мережі:

```bash
opencode web --hostname 0.0.0.0
```

При використанні `0.0.0.0` OpenCode покаже як локальні, так і мережеві адреси:

```
  Локальний доступ:       http://localhost:4096
  Мережевий доступ:       http://192.168.1.100:4096
```

### mDNS Виявлення

Увімкніть mDNS, щоб зробити ваш сервер видимим у локальній мережі:

```bash
opencode web --mdns
```

Це автоматично встановлює ім'я хоста на `0.0.0.0` та анонсує сервер як `opencode.local`.

Ви можете налаштувати доменне ім'я mDNS для запуску кількох екземплярів в одній мережі:

```bash
opencode web --mdns --mdns-domain myproject.local
```

### CORS

Щоб дозволити додаткові домени для CORS (корисно для власних інтерфейсів):

```bash
opencode web --cors https://example.com
```

### Аутентифікація

Щоб захистити доступ, встановіть пароль за допомогою змінної середовища `OPENCODE_SERVER_PASSWORD`:

```bash
OPENCODE_SERVER_PASSWORD=secret opencode web
```

Ім'я користувача за замовчуванням — `opencode`, але його можна змінити за допомогою `OPENCODE_SERVER_USERNAME`.

## Використання веб-інтерфейсу

Після запуску веб-інтерфейс надає доступ до ваших сесій OpenCode.

### Сесії

Переглядайте та керуйте своїми сесіями з головної сторінки. Ви можете бачити активні сесії та починати нові.

![OpenCode Web - Активна сесія](../../../assets/web/web-homepage-active-session.png)

### Статус сервера

Натисніть "See Servers", щоб переглянути підключені сервери та їхній статус.

![OpenCode Web - See Servers](../../../assets/web/web-homepage-see-servers.png)

## Підключення термінала

Ви можете підключити термінальний TUI до запущеного веб-сервера:

```bash
# Запустіть веб-сервер
opencode web --port 4096

# В іншому терміналі підключіть TUI
opencode attach http://localhost:4096
```

Це дозволяє використовувати як веб-інтерфейс, так і термінал одночасно, спільно використовуючи одні й ті самі сесії та стан.

---

## Файл конфігурації

Ви також можете налаштувати параметри сервера у вашому файлі конфігурації `opencode.json`:

```json
{
  "server": {
    "port": 4096,
    "hostname": "0.0.0.0",
    "mdns": true,
    "cors": ["https://example.com"]
  }
}
```

Прапорці командного рядка мають перевагу над налаштуваннями файлу конфігурації.
