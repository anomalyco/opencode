OpenCode інтегрується з VS Code, Cursor або будь-якою IDE, що підтримує термінал. Просто запустіть `opencode` в терміналі, щоб почати роботу.

---

## Використання

- **Швидкий запуск**: Використовуйте `Cmd+Esc` (Mac) або `Ctrl+Esc` (Windows/Linux), щоб відкрити OpenCode у розділеному терміналі або перемкнути фокус на існуючу сесію терміналу, якщо вона вже запущена.
- **Нова сесія**: Використовуйте `Cmd+Shift+Esc` (Mac) або `Ctrl+Shift+Esc` (Windows/Linux), щоб запустити нову сесію терміналу OpenCode, навіть якщо одна вже відкрита. Ви також можете натиснути кнопку OpenCode в інтерфейсі.
- **Контекстна обізнаність**: Автоматично діліться поточним виділенням або вкладкою з OpenCode.
- **Швидкі посилання на файли**: Використовуйте `Cmd+Option+K` (Mac) або `Alt+Ctrl+K` (Linux/Windows), щоб вставити посилання на файли. Наприклад, `@File#L37-42`.

---

## Встановлення

Щоб встановити OpenCode у VS Code та популярні форки, як-от Cursor, Windsurf, VSCodium:

1. Відкрийте VS Code
2. Відкрийте вбудований термінал
3. Запустіть `opencode` — розширення встановиться автоматично

Якщо ж ви хочете використовувати власну IDE, коли запускаєте `/editor` або `/export` з TUI, вам потрібно встановити `export EDITOR="code --wait"`. [Дізнатися більше](/docs/tui/#editor-setup).

---

### Ручне встановлення

Знайдіть **OpenCode** у Маркетплейсі розширень та натисніть **Встановити**.

---

### Вирішення проблем

Якщо розширення не встановлюється автоматично:

- Переконайтеся, що ви запускаєте `opencode` у вбудованому терміналі.
- Переконайтеся, що CLI для вашої IDE встановлено:
  - Для VS Code: команда `code`
  - Для Cursor: команда `cursor`
  - Для Windsurf: команда `windsurf`
  - Для VSCodium: команда `codium`
  - Якщо ні, натисніть `Cmd+Shift+P` (Mac) або `Ctrl+Shift+P` (Windows/Linux) і знайдіть "Shell Command: Install 'code' command in PATH" (або аналог для вашої IDE)
- Переконайтеся, що VS Code має дозвіл на встановлення розширень
