JS/TS SDK від opencode надає типобезпечний клієнт для взаємодії з сервером.
Використовуйте його для створення інтеграцій та програмного керування opencode.

[Дізнайтеся більше](/docs/server) про те, як працює сервер. Приклади дивіться у [проєктах](/docs/ecosystem#projects), створених спільнотою.

---

## Встановлення

Встановіть SDK з npm:

```bash
npm install @opencode-ai/sdk
```

---

## Створення клієнта

Створіть екземпляр opencode:

```javascript
import { createOpencode } from "@opencode-ai/sdk"

const { client } = await createOpencode()
```

Це запускає і сервер, і клієнт

#### Параметри

| Параметр    | Тип           | Опис                        | За замовчуванням |
| ----------- | ------------- | --------------------------- | ---------------- |
| `hostname`  | `string`      | Ім'я хоста сервера          | `127.0.0.1`      |
| `port`      | `number`      | Порт сервера                | `4096`           |
| `signal`    | `AbortSignal` | Сигнал для скасування       | `undefined`      |
| `timeout`   | `number`      | Тайм-аут у мс для запуску   | `5000`           |
| `config`    | `Config`      | Об'єкт конфігурації         | `{}`             |

---

## Конфігурація

Ви можете передати об'єкт конфігурації для налаштування поведінки. Екземпляр все одно зчитує ваш `opencode.json`, але ви можете перевизначити або додати конфігурацію безпосередньо:

```javascript
import { createOpencode } from "@opencode-ai/sdk"

const opencode = await createOpencode({
  hostname: "127.0.0.1",
  port: 4096,
  config: {
    model: "anthropic/claude-3-5-sonnet-20241022",
  },
})

console.log(`Сервер запущено за адресою ${opencode.server.url}`)

opencode.server.close()
```

## Тільки клієнт

Якщо у вас вже запущено екземпляр opencode, ви можете створити клієнтський екземпляр для підключення до нього:

```javascript
import { createOpencodeClient } from "@opencode-ai/sdk"

const client = createOpencodeClient({
  baseUrl: "http://localhost:4096",
})
```

#### Параметри

| Параметр        | Тип        | Опис                               | За замовчуванням        |
| --------------- | ---------- | ---------------------------------- | ----------------------- |
| `baseUrl`       | `string`   | URL сервера                        | `http://localhost:4096` |
| `fetch`         | `function` | Власна реалізація fetch            | `globalThis.fetch`      |
| `parseAs`       | `string`   | Метод парсингу відповіді           | `auto`                  |
| `responseStyle` | `string`   | Стиль повернення: `data` або `fields` | `fields`             |
| `throwOnError`  | `boolean`  | Викидати помилки замість повернення | `false`                 |

## Типи

SDK включає визначення TypeScript для всіх типів API. Імпортуйте їх безпосередньо:

```typescript
import type { Session, Message, Part } from "@opencode-ai/sdk"
```

Усі типи генеруються зі специфікації OpenAPI сервера та доступні у <a href={typesUrl}>файлі типів</a>.

## Помилки

SDK може викидати помилки, які ви можете перехоплювати та обробляти:

```typescript
try {
  await client.session.get({ path: { id: "invalid-id" } })
} catch (error) {
  console.error("Не вдалося отримати сесію:", (error as Error).message)
}
```

## Структурований вивід

Ви можете запитати структурований JSON-вивід від моделі, вказавши `format` з JSON-схемою. Модель використовуватиме інструмент `StructuredOutput` для повернення валідованого JSON, що відповідає вашій схемі.

### Базове використання

```typescript
const result = await client.session.prompt({
  path: { id: sessionId },
  body: {
    parts: [{ type: "text", text: "Досліди Anthropic та надай інформацію про компанію" }],
    format: {
      type: "json_schema",
      schema: {
        type: "object",
        properties: {
          company: { type: "string", description: "Назва компанії" },
          founded: { type: "number", description: "Рік заснування" },
          products: {
            type: "array",
            items: { type: "string" },
            description: "Основні продукти",
          },
        },
        required: ["company", "founded"],
      },
    },
  },
})

// Доступ до структурованого виводу
console.log(result.data.info.structured_output)
// { company: "Anthropic", founded: 2021, products: ["Claude", "Claude API"] }
```

### Типи форматів виводу

| Тип           | Опис                                                         |
| ------------- | ------------------------------------------------------------ |
| `text`        | За замовчуванням. Стандартна текстова відповідь (без структурованого виводу) |
| `json_schema` | Повертає валідований JSON, що відповідає наданій схемі       |

### Формат JSON Schema

При використанні `type: 'json_schema'` вкажіть:

| Поле         | Тип             | Опис                                                       |
| ------------ | --------------- | ---------------------------------------------------------- |
| `type`       | `'json_schema'` | Обов'язкове. Вказує режим JSON-схеми                       |
| `schema`     | `object`        | Обов'язкове. Об'єкт JSON Schema, що визначає структуру виводу |
| `retryCount` | `number`        | Необов'язкове. Кількість повторів валідації (за замовчуванням: 2) |

### Обробка помилок

Якщо моделі не вдається створити правильний структурований вивід після всіх повторів, відповідь міститиме `StructuredOutputError`:

```typescript
if (result.data.info.error?.name === "StructuredOutputError") {
  console.error("Не вдалося створити структурований вивід:", result.data.info.error.message)
  console.error("Спроби:", result.data.info.error.retries)
}
```

### Рекомендації

1. **Надавайте чіткі описи** у властивостях схеми, щоб допомогти моделі зрозуміти, які дані витягувати
2. **Використовуйте `required`** для вказівки обов'язкових полів
3. **Тримайте схеми сфокусованими** — складні вкладені схеми можуть бути складнішими для правильного заповнення моделлю
4. **Встановлюйте відповідний `retryCount`** — збільшуйте для складних схем, зменшуйте для простих

#### Приклади

```javascript
// Створення та керування сесіями
const session = await client.session.create({
  body: { title: "Моя сесія" },
})

const sessions = await client.session.list()

// Надіслати повідомлення-запит
const result = await client.session.prompt({
  path: { id: session.id },
  body: {
    model: { providerID: "anthropic", modelID: "claude-3-5-sonnet-20241022" },
    parts: [{ type: "text", text: "Привіт!" }],
  },
})

// Вставити контекст без відповіді AI (корисно для плагінів)
await client.session.prompt({
  path: { id: session.id },
  body: {
    noReply: true,
    parts: [{ type: "text", text: "Ви — корисний помічник." }],
  },
})
```

### Files

| Метод                       | Опис                           | Відповідь                                                                                   |
| --------------------------- | ------------------------------ | ------------------------------------------------------------------------------------------- |
| `find.text({ query })`      | Пошук тексту у файлах          | Масив об'єктів збігів з `path`, `lines`, `line_number`, `absolute_offset`, `submatches`     |
| `find.files({ query })`     | Пошук файлів і каталогів за назвою | `string[]` (шляхи)                                                                          |
| `find.symbols({ query })`   | Пошук символів робочої області | <a href={typesUrl}><code>Symbol[]</code></a>                                                |
| `file.read({ query })`      | Читання файлу                   | `{ type: "raw" \| "patch", content: string }`                                                |
| `file.status({ query? })`   | Статус відстежуваних файлів     | <a href={typesUrl}><code>File[]</code></a>                                                  |

`find.files` підтримує кілька необов'язкових полів запиту:

- `type`: `"file"` або `"directory"`
- `directory`: перевизначити корінь проєкту для пошуку
- `limit`: максимальна кількість результатів (1–200)

---

#### Приклади

```javascript
// Пошук та читання файлів
const textResults = await client.find.text({
  query: { pattern: "function.*opencode" },
})

const files = await client.find.files({
  query: { query: "*.ts", type: "file" },
})

const directories = await client.find.files({
  query: { query: "packages", type: "directory", limit: 20 },
})

const content = await client.file.read({
  query: { path: "src/index.ts" },
})
```
