CLI OpenCode за замовчуванням запускає [TUI](/docs/tui), коли виконується без аргументів.

```bash
opencode
```

Але він також приймає команди, як описано на цій сторінці. Це дозволяє вам взаємодіяти з OpenCode програмно.

```bash
opencode run "Поясни, як працюють замикання в JavaScript"
```

---

### tui

Запустити термінальний інтерфейс користувача OpenCode.

```bash

```

## Команди

CLI OpenCode також має наступні команди.

---

### agent

Керування агентами для OpenCode.

```bash
opencode agent [command]
```

---

#### create

Створити нового агента з користувацькою конфігурацією.

```bash
opencode agent create
```

Ця команда проведе вас через створення нового агента з користувацьким системним запитом та конфігурацією дозволів. Все, що ви не дозволите, буде заборонено у фронтматері згенерованого агента.

#### Прапорці

| Прапорець                                    | Скорочення | Опис                                                                                                                                                                                                                               |
| -------------------------------------------- | ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| <nobr><code>{"--path"}</code></nobr>         |            | Каталог для запису файлу агента (за замовчуванням глобальний або `.opencode/agent` залежно від запиту)                                                                                                                              |
| <nobr><code>{"--description"}</code></nobr>  |            | Що агент повинен робити                                                                                                                                                                                                            |
| <nobr><code>{"--mode"}</code></nobr>         |            | Режим агента: `all`, `primary` або `subagent`                                                                                                                                                                                      |
| <nobr><code>{"--permissions"}</code></nobr>  |            | Розділений комами список дозволів (за замовчуванням: усі). Доступні: `bash`, `read`, `edit`, `glob`, `grep`, `webfetch`, `task`, `todowrite`, `websearch`, `lsp`, `skill`. Все, що пропущено, заборонено. Псевдонім: `--tools`      |
| <nobr><code>{"--model"}</code></nobr>        | `-m`       | Модель для використання у форматі `provider/model`                                                                                                                                                                                 |

Передача всіх `--path`, `--description`, `--mode` та `--permissions` запускає команду в неінтерактивному режимі.

### attach

Підключити термінал до запущеного бекенд-сервера OpenCode, запущеного за допомогою команд `serve` або `web`.

```bash
opencode attach [url]
```

Це дозволяє використовувати TUI з віддаленим бекендом OpenCode. Наприклад:

```bash
# Запустіть бекенд-сервер для веб/мобільного доступу
opencode web --port 4096 --hostname 0.0.0.0

# В іншому терміналі підключіть TUI до запущеного бекенда
opencode attach http://10.20.30.40:4096
```

#### Прапорці

| Прапорець                                  | Скорочення | Опис                                                                                 |
| ------------------------------------------ | ---------- | ------------------------------------------------------------------------------------ |
| <nobr><code>{"--dir"}</code></nobr>        |            | Робочий каталог для запуску TUI                                                      |
| <nobr><code>{"--continue"}</code></nobr>   | `-c`       | Продовжити останню сесію                                                             |
| <nobr><code>{"--session"}</code></nobr>    | `-s`       | ID сесії для продовження                                                             |
| <nobr><code>{"--fork"}</code></nobr>       |            | Форкнути сесію при продовженні (використовуйте з `--continue` або `--session`)       |
| <nobr><code>{"--password"}</code></nobr>   | `-p`       | Пароль базової аутентифікації (за замовчуванням `OPENCODE_SERVER_PASSWORD`)          |
| <nobr><code>{"--username"}</code></nobr>   | `-u`       | Ім'я користувача базової аутентифікації (за замовчуванням `OPENCODE_SERVER_USERNAME` або `opencode`) |

### auth

Команда для керування обліковими даними та входом для провайдерів.

```bash
opencode auth [command]
```

---

#### login

OpenCode працює на основі списку провайдерів з [Models.dev](https://models.dev), тому ви можете використовувати `opencode auth login` для налаштування ключів API для будь-якого провайдера, який ви бажаєте використовувати. Це зберігається в `~/.local/share/opencode/auth.json`.

```bash
opencode auth login
```

При запуску OpenCode завантажує провайдерів з файлу облікових даних. А також якщо є ключі, визначені у вашому середовищі або у файлі `.env` у вашому проєкті.

##### Прапорці

| Прапорець                                  | Скорочення | Опис                                                     |
| ------------------------------------------ | ---------- | -------------------------------------------------------- |
| <nobr><code>{"--provider"}</code></nobr>   | `-p`       | ID або назва провайдера для входу                        |
| <nobr><code>{"--method"}</code></nobr>     | `-m`       | Мітка методу входу, пропускаючи вибір методу             |

---

#### list

Список усіх автентифікованих провайдерів, що зберігаються у файлі облікових даних.

```bash

```

Або коротка версія.

```bash
opencode auth ls
```

### models

Список усіх доступних моделей від налаштованих провайдерів.

```bash
opencode models [provider]
```

Ця команда показує всі моделі, доступні через налаштованих провайдерів, у форматі `provider/model`.

Це корисно для визначення точної назви моделі для використання у [вашій конфігурації](/docs/config/).

Ви можете додатково передати ID провайдера, щоб відфільтрувати моделі за цим провайдером.

```bash
opencode models anthropic
```

#### Прапорці

| Прапорець                                 | Опис                                                                    |
| ----------------------------------------- | ----------------------------------------------------------------------- |
| <nobr><code>{"--refresh"}</code></nobr>   | Оновити кеш моделей з models.dev                                        |
| <nobr><code>{"--verbose"}</code></nobr>   | Детальніший вивід моделей (включає метадані, як-от вартість)            |

Використовуйте прапорець `--refresh`, щоб оновити кешований список моделей. Це корисно, коли до провайдера додано нові моделі, і ви хочете бачити їх у OpenCode.

```bash
opencode models --refresh
```

### run

Запустити opencode у неінтерактивному режимі, передаючи запит безпосередньо.

```bash
opencode run [message..]
```

Це корисно для скриптів, автоматизації або коли ви хочете отримати швидку відповідь без запуску повного TUI. Наприклад:

```bash "opencode run"
opencode run Поясни використання context у Go
```

Ви також можете підключитися до запущеного екземпляра `opencode serve`, щоб уникнути холодного запуску MCP-сервера при кожному запуску:

```bash
# Запустіть безголовий сервер в одному терміналі
opencode serve

# В іншому терміналі запускайте команди, які підключаються до нього
opencode run --attach http://localhost:4096 "Поясни async/await у JavaScript"
```

| <nobr><code>{"--fork"}</code></nobr>       |            | Форкнути сесію при продовженні (використовуйте з `--continue` або `--session`)       |
| <nobr><code>{"--share"}</code></nobr>      |            | Поширити сесію                                                                       |
| <nobr><code>{"--model"}</code></nobr>      | `-m`       | Модель для використання у форматі provider/model                                     |
| <nobr><code>{"--agent"}</code></nobr>      |            | Агент для використання                                                               |
| <nobr><code>{"--file"}</code></nobr>       | `-f`       | Файл(и) для прикріплення до повідомлення                                             |

### serve

Запустити безголовий сервер OpenCode для доступу через API. Перегляньте [документацію сервера](/docs/server) для повного HTTP-інтерфейсу.

```bash
opencode serve
```

Це запускає HTTP-сервер, який надає доступ до функціональності opencode через API без інтерфейсу TUI. Встановіть `OPENCODE_SERVER_PASSWORD`, щоб увімкнути базову HTTP-аутентифікацію (ім'я користувача за замовчуванням — `opencode`).

#### Прапорці

| Прапорець                                     | Опис                                                  |
| --------------------------------------------- | ----------------------------------------------------- |
| <nobr><code>{"--port"}</code></nobr>          | Порт для прослуховування                              |
| <nobr><code>{"--hostname"}</code></nobr>      | Ім'я хоста для прослуховування                        |
| <nobr><code>{"--mdns"}</code></nobr>          | Увімкнути mDNS виявлення                              |
| <nobr><code>{"--mdns-domain"}</code></nobr>   | Користувацьке доменне ім'я mDNS                       |
| <nobr><code>{"--cors"}</code></nobr>          | Додаткові джерела браузера для дозволу CORS           |

Вивести шлях до бази даних.

```bash
opencode db path
```

### debug

Інструменти налагодження та вирішення проблем.

```bash
opencode debug [command]
```

---

### uninstall

Видалити OpenCode та всі пов'язані файли.

```bash
opencode uninstall
```

#### Прапорці

| Прапорець                                     | Скорочення | Опис                                                |
| --------------------------------------------- | ---------- | --------------------------------------------------- |
| <nobr><code>{"--keep-config"}</code></nobr>   | `-c`       | Зберегти файли конфігурації                         |
| <nobr><code>{"--keep-data"}</code></nobr>     | `-d`       | Зберегти дані сесій та знімки                       |
| <nobr><code>{"--dry-run"}</code></nobr>       |            | Показати, що буде видалено, без фактичного видалення |
| <nobr><code>{"--force"}</code></nobr>         | `-f`       | Пропустити запити підтвердження                     |

---

### upgrade

Оновлює opencode до останньої версії або конкретної версії.

```bash
opencode upgrade [target]
```

Щоб оновити до останньої версії.

```bash
opencode upgrade
```

Щоб оновити до конкретної версії.

```bash
opencode upgrade v0.1.48
```

#### Прапорці

| Прапорець                                | Скорочення | Опис                                                                  |
| ---------------------------------------- | ---------- | --------------------------------------------------------------------- |
| <nobr><code>{"--method"}</code></nobr>   | `-m`       | Метод встановлення, який використовувався; curl, npm, pnpm, bun, brew |

## Глобальні прапорці

CLI opencode приймає наступні глобальні прапорці.

| Прапорець                                    | Скорочення | Опис                                      |

| <nobr><code>{"--print-logs"}</code></nobr>   |            | Вивести журнали в stderr                  |
| <nobr><code>{"--log-level"}</code></nobr>    |            | Рівень журналювання (DEBUG, INFO, WARN, ERROR) |
| <nobr><code>{"--pure"}</code></nobr>         |            | Запустити без зовнішніх плагінів          |

## Змінні середовища

OpenCode можна налаштовувати за допомогою змінних середовища.

| Змінна                              | Тип     | Опис                                                    |
| ----------------------------------- | ------- | ------------------------------------------------------- |
| `OPENCODE_AUTO_SHARE`               | boolean | Автоматично поширювати сесії                            |
| `OPENCODE_GIT_BASH_PATH`            | string  | Шлях до Git Bash на Windows                             |
| `OPENCODE_CONFIG`                   | string  | Шлях до файлу конфігурації                              |
| `OPENCODE_TUI_CONFIG`               | string  | Шлях до файлу конфігурації TUI                          |
| `OPENCODE_CONFIG_DIR`               | string  | Шлях до каталогу конфігурації                           |
| `OPENCODE_CONFIG_CONTENT`           | string  | Вбудований вміст json конфігурації                      |
| `OPENCODE_DISABLE_AUTOUPDATE`       | boolean | Вимкнути автоматичну перевірку оновлень                  |
| `OPENCODE_DISABLE_PRUNE`            | boolean | Вимкнути очищення старих даних                          |
| `OPENCODE_DISABLE_TERMINAL_TITLE`   | boolean | Вимкнути автоматичне оновлення заголовка термінала      |
| `OPENCODE_PERMISSION`               | string  | Вбудована конфігурація дозволів у форматі json           |
| `OPENCODE_DISABLE_DEFAULT_PLUGINS`  | boolean | Вимкнути стандартні плагіни                             |
| `OPENCODE_DISABLE_LSP_DOWNLOAD`     | boolean | Вимкнути автоматичне завантаження LSP-серверів           |
| `OPENCODE_ENABLE_EXPERIMENTAL_MODELS`| boolean | Увімкнути експериментальні моделі                       |
| `OPENCODE_DISABLE_AUTOCOMPACT`      | boolean | Вимкнути автоматичне ущільнення контексту                |
| `OPENCODE_DISABLE_CLAUDE_CODE`      | boolean | Вимкнути читання з `.claude` (підказка + навички)       |
| `OPENCODE_DISABLE_CLAUDE_CODE_PROMPT`| boolean | Вимкнути читання `~/.claude/CLAUDE.md`                  |
| `OPENCODE_DISABLE_CLAUDE_CODE_SKILLS`| boolean | Вимкнути завантаження `.claude/skills`                  |
| `OPENCODE_DISABLE_MODELS_FETCH`     | boolean | Вимкнути отримання моделей з віддалених джерел           |
| `OPENCODE_DISABLE_MOUSE`            | boolean | Вимкнути захоплення миші в TUI                          |
| `OPENCODE_FAKE_VCS`                 | string  | Фальшивий VCS-провайдер для тестування                  |
| `OPENCODE_CLIENT`                   | string  | Ідентифікатор клієнта (за замовчуванням `cli`)         |
| `OPENCODE_ENABLE_EXA`               | boolean | Увімкнути інструменти веб-пошуку Exa                     |
| `OPENCODE_SERVER_PASSWORD`          | string  | Увімкнути базову аутентифікацію для `serve`/`web`       |
| `OPENCODE_SERVER_USERNAME`          | string  | Змінити ім'я користувача базової аутентифікації (за замовчуванням `opencode`) |
| `OPENCODE_MODELS_URL`               | string  | Користувацький URL для отримання конфігурації моделей    |

| `OPENCODE_EXPERIMENTAL_BASH_DEFAULT_TIMEOUT_MS`  | number  | Стандартний таймаут для команд bash у мс            |
| `OPENCODE_EXPERIMENTAL_OUTPUT_TOKEN_MAX`         | number  | Максимальна кількість вихідних токенів для LLM      |
| `OPENCODE_EXPERIMENTAL_FILEWATCHER`              | boolean | Увімкнути спостерігач файлів для всього каталогу    |
| `OPENCODE_EXPERIMENTAL_OXFMT`                    | boolean | Увімкнути форматер oxfmt                            |
| `OPENCODE_EXPERIMENTAL_LSP_TOOL`                 | boolean | Увімкнути експериментальний LSP-інструмент          |
| `OPENCODE_EXPERIMENTAL_DISABLE_FILEWATCHER`      | boolean | Вимкнути спостерігач файлів                         |
| `OPENCODE_EXPERIMENTAL_EXA`                      | boolean | Увімкнути експериментальні функції Exa              |
| `OPENCODE_EXPERIMENTAL_LSP_TY`                   | boolean | Увімкнути TY LSP для Python файлів                  |
| `OPENCODE_EXPERIMENTAL_PLAN_MODE`                | boolean | Увімкнути режим планування                          |
| `OPENCODE_EXPERIMENTAL_BACKGROUND_SUBAGENTS`     | boolean | Увімкнути фонові завдання субагентів                |
| `OPENCODE_EXPERIMENTAL_EVENT_SYSTEM`             | boolean | Увімкнути експериментальну систему подій            |
| `OPENCODE_EXPERIMENTAL_NATIVE_LLM`               | boolean | Увімкнути рідний шлях LLM-запитів                   |
| `OPENCODE_EXPERIMENTAL_PARALLEL`                 | boolean | Увімкнути паралельне виконання веб-пошуку           |
| `OPENCODE_EXPERIMENTAL_SCOUT`                    | boolean | Увімкнути субагента Scout                            |
| `OPENCODE_EXPERIMENTAL_WORKSPACES`               | boolean | Увімкнути підтримку робочих просторів               |
