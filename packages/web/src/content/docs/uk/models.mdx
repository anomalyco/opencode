OpenCode використовує [AI SDK](https://ai-sdk.dev/) та [Models.dev](https://models.dev) для підтримки **75+ LLM провайдерів** і підтримує запуск локальних моделей.

---

## Провайдери

Більшість популярних провайдерів попередньо завантажені за замовчуванням. Якщо ви додали облікові дані для провайдера через команду `/connect`, вони будуть доступні під час запуску OpenCode.

Дізнайтеся більше про [провайдерів](/docs/providers).

---

## Вибір моделі

Після налаштування провайдера ви можете вибрати потрібну модель, ввівши:

```bash frame="none"
/models
```

## Встановлення за замовчуванням

Щоб встановити одну з них як модель за замовчуванням, ви можете встановити ключ `model` у вашому
конфігу OpenCode.

```json title="opencode.json" {3}
{
  "$schema": "https://opencode.ai/config.json",
  "model": "lmstudio/google/gemma-3n-e4b"
}
```

Тут повний ID — `provider_id/model_id`. Наприклад, якщо ви використовуєте [OpenCode Zen](/docs/zen), ви б використали `opencode/gpt-5.1-codex` для GPT 5.1 Codex.

Якщо ви налаштували [користувацького провайдера](/docs/providers#custom), `provider_id` — це ключ з частини `provider` вашого конфігу, а `model_id` — це ключ з `provider.models`.

## Налаштування моделей

Ви можете глобально налаштувати опції моделі через конфіг.

```jsonc title="opencode.jsonc" {7-12,19-24}
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "openai": {
      "models": {
        "gpt-5": {
          "options": {
            "reasoningEffort": "high",
            "textVerbosity": "low",
            "reasoningSummary": "auto",
            "include": ["reasoning.encrypted_content"],
          },
        },
      },
    },
    "anthropic": {
      "models": {
        "claude-sonnet-4-5-20250929": {
          "options": {
            "thinking": {
              "type": "enabled",
              "budgetTokens": 16000,
            },
          },
        },
      },
    },
  },
}
```

Тут ми налаштовуємо глобальні налаштування для двох вбудованих моделей: `gpt-5` при доступі через провайдера `openai`, та `claude-sonnet-4-20250514` при доступі через провайдера `anthropic`.
Назви вбудованих провайдерів та моделей можна знайти на [Models.dev](https://models.dev).

Ви також можете налаштувати ці опції для будь-яких агентів, яких використовуєте. Конфігурація агента перевизначає будь-які глобальні опції тут. [Дізнатися більше](/docs/agents/#additional).

Ви також можете визначати користувацькі варіанти, які розширюють вбудовані. Варіанти дозволяють налаштовувати різні параметри для тієї самої моделі без створення дублікатів записів:

```jsonc title="opencode.jsonc" {6-21}
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "opencode": {
      "models": {
        "gpt-5": {
          "variants": {
            "high": {
              "reasoningEffort": "high",
              "textVerbosity": "low",
              "reasoningSummary": "auto",
            },
            "low": {
              "reasoningEffort": "low",
              "textVerbosity": "low",
              "reasoningSummary": "auto",
            },
          },
        },
      },
    },
  },
}
```

## Варіанти

Багато моделей підтримують кілька варіантів з різними конфігураціями. OpenCode постачається з вбудованими варіантами за замовчуванням для популярних провайдерів.

### Вбудовані варіанти

OpenCode постачається з варіантами за замовчуванням для багатьох провайдерів:

**Anthropic**:

- `high` — Високий бюджет міркування (за замовчуванням)
- `max` — Максимальний бюджет міркування

**OpenAI**:

Варіюється залежно від моделі, але приблизно:

- `none` — Без міркування
- `minimal` — Мінімальне зусилля міркування
- `low` — Низьке зусилля міркування
- `medium` — Середнє зусилля міркування
- `high` — Високе зусилля міркування
- `xhigh` — Надвисоке зусилля міркування

**Google**:

- `low` — Нижчий бюджет зусиль/токенів
- `high` — Вищий бюджет зусиль/токенів

:::tip
Цей список не є вичерпним. Багато інших провайдерів також мають вбудовані значення за замовчуванням.
:::

### Користувацькі варіанти

Ви можете перевизначати існуючі варіанти або додавати власні:

```jsonc title="opencode.jsonc" {7-18}
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "openai": {
      "models": {
        "gpt-5": {
          "variants": {
            "thinking": {
              "reasoningEffort": "high",
              "textVerbosity": "low",
            },
            "fast": {
              "disabled": true,
            },
          },
        },
      },
    },
  },
}
```

### Цикл варіантів

Використовуйте комбінацію клавіш `variant_cycle`, щоб швидко перемикатися між варіантами. [Дізнатися більше](/docs/keybinds).

## Завантаження моделей

Коли OpenCode запускається, він перевіряє моделі в наступному порядку пріоритету:

1. Прапорець командного рядка `--model` або `-m`. Формат такий самий, як у файлі конфігурації: `provider_id/model_id`.

2. Список моделей у конфігурації OpenCode.

   ```json title="opencode.json"
   {
     "$schema": "https://opencode.ai/config.json",
     "model": "anthropic/claude-sonnet-4-20250514"
   }
   ```

   Формат тут — `provider/model`.

3. Остання використана модель.

4. Перша модель з використанням внутрішнього пріоритету.
