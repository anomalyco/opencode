---
title: Поширення
description: Поширюйте свої розмови в OpenCode.
---

Функція поширення OpenCode дозволяє створювати публічні посилання на ваші розмови в OpenCode, щоб ви могли співпрацювати з членами команди або отримувати допомогу від інших.

:::note
Поширені розмови є загальнодоступними для всіх, хто має посилання.
:::

---

## Як це працює

Коли ви поширюєте розмову, OpenCode:

1. Створює унікальну публічну URL-адресу для вашої сесії
2. Синхронізує історію вашої розмови з нашими серверами
3. Робить розмову доступною через посилання для поширення — `opncd.ai/s/<share-id>`

---

## Поширення

OpenCode підтримує три режими поширення, які контролюють, як поширюються розмови:

---

### Ручний (за замовчуванням)

За замовчуванням OpenCode використовує ручний режим поширення. Сесії не поширюються автоматично, але ви можете вручну поширити їх за допомогою команди `/share`:

```
/share
```

Це згенерує унікальну URL-адресу, яка буде скопійована в буфер обміну.

Щоб явно встановити ручний режим у [файлі конфігурації](/docs/config):

```json title="opencode.json"
{
  "$schema": "https://opencode.ai/config.json",
  "share": "manual"
}
```

---

### Автоматичне поширення

Ви можете ввімкнути автоматичне поширення всіх нових розмов, встановивши опцію `share` у значення `"auto"` у вашому [файлі конфігурації](/docs/config):

```json title="opencode.json"
{
  "$schema": "https://opencode.ai/config.json",
  "share": "auto"
}
```

З увімкненим автоматичним поширенням кожна нова розмова автоматично поширюватиметься, і буде згенеровано посилання.

---

### Вимкнено

Ви можете повністю вимкнути поширення, встановивши опцію `share` у значення `"disabled"` у вашому [файлі конфігурації](/docs/config):

```json title="opencode.json"
{
  "$schema": "https://opencode.ai/config.json",
  "share": "disabled"
}
```

Щоб застосувати це до всієї команди для певного проєкту, додайте це до `opencode.json` у вашому проєкті та закомітьте в Git.

---

## Скасування поширення

Щоб припинити поширення розмови та видалити її з публічного доступу:

```
/unshare
```

Це видалить посилання для поширення та дані, пов'язані з розмовою.

---

## Приватність

Є кілька речей, про які слід пам'ятати під час поширення розмови.

---

### Зберігання даних

Поширені розмови залишаються доступними, доки ви явно не скасуєте їх поширення. Це
включає:

- Повну історію розмови
- Всі повідомлення та відповіді
- Метадані сесії

---

### Рекомендації

- Поширюйте лише ті розмови, які не містять конфіденційної інформації.
- Перевіряйте вміст розмови перед поширенням.
- Скасовуйте поширення, коли співпрацю завершено.
- Уникайте поширення розмов із власницьким кодом або конфіденційними даними.
- Для чутливих проєктів повністю вимкніть поширення.

---

## Для підприємств

Для корпоративних розгортань функція поширення може бути:

- **Вимкнена** повністю для відповідності вимогам безпеки
- **Обмежена** лише для користувачів, автентифікованих через SSO
- **Самостійно розміщена** на власній інфраструктурі

[Дізнатися більше](/docs/enterprise) про використання OpenCode у вашій організації.
