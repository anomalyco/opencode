OpenCode se integruje s vaším pracovním postupem GitLab prostřednictvím vašeho potrubí GitLab CI/CD nebo pomocí GitLab Duo.

V obou případech poběží OpenCode na vašich běžcích GitLab.

---

## GitLab CI

OpenCode funguje v běžném potrubí GitLab. Můžete jej zabudovat do potrubí jako [komponent CI](https://docs.gitlab.com/ee/ci/components/)

Zde používáme komunitou vytvořenou komponentu CI/CD pro OpenCode — [nagyv/gitlab-opencode](https://gitlab.com/nagyv/gitlab-opencode).

---

### Funkce

- **Použít vlastní konfiguraci pro každou úlohu**: Nakonfigurujte OpenCode pomocí vlastního konfiguračního adresáře, například `./config/#custom-directory`, abyste povolili nebo zakázali funkčnost podle vyvolání OpenCode.
- **Minimální nastavení**: Komponenta CI nastavuje OpenCode na pozadí, stačí vytvořit konfiguraci OpenCode a úvodní výzvu.
- **Flexibilní**: Komponenta CI podporuje několik vstupů pro přizpůsobení jejího chování

---

### Nastavení

1. Uložte své ověření OpenCode JSON jako proměnné prostředí CI typu File pod **Nastavení** > **CI/CD** > **Proměnné**. Nezapomeňte je označit jako „Maskované a skryté“.
2. Přidejte následující do souboru `.gitlab-ci.yml`.

   ```yaml title=".gitlab-ci.yml"
   include:
     - component: $CI_SERVER_FQDN/nagyv/gitlab-opencode/opencode@2
       inputs:
         config_dir: ${CI_PROJECT_DIR}/opencode-config
         auth_json: $OPENCODE_AUTH_JSON # The variable name for your OpenCode authentication JSON
         command: optional-custom-command
         message: "Your prompt here"
   ```

Další vstupy a případy použití [prohlédněte si dokumenty](https://gitlab.com/explore/catalog/nagyv/gitlab-opencode) pro tuto komponentu.

## GitLab Duo

OpenCode se integruje s vaším pracovním postupem GitLab.
Zmiňte `@opencode` v komentáři a OpenCode bude provádět úkoly v rámci vašeho kanálu GitLab CI.

---

### Funkce

- **Problémy s tříděním**: Požádejte OpenCode, aby se na problém podíval a vysvětlil vám ho.
- **Opravit a implementovat**: Požádejte OpenCode o vyřešení problému nebo implementaci funkce.
  Vytvoří novou větev a vyvolá žádost o sloučení se změnami.
- **Secure**: OpenCode běží na vašich běžcích GitLab.

---

### Nastavení

OpenCode běží ve vašem potrubí GitLab CI/CD, zde je to, co budete potřebovat k jeho nastavení:

:::tip
Aktuální pokyny naleznete v [**GitLab docs**](https://docs.gitlab.com/user/duo_agent_platform/agent_assistant/).
:::

1. Nakonfigurujte své prostředí GitLab
2. Nastavte CI/CD
3. Získejte klíč API poskytovatele modelu AI
4. Vytvořte servisní účet
5. Nakonfigurujte proměnné CI/CD
6. Vytvořte konfigurační soubor toku, zde je příklad:

        <details>

    <summary>Konfigurace flow</summary>

    ```yaml
    image: node:22-slim
    commands:
      - echo "Installing opencode"
      - npm install --global opencode-ai
      - echo "Installing glab"
      - export GITLAB_TOKEN=$GITLAB_TOKEN_OPENCODE
      - apt-get update --quiet && apt-get install --yes curl wget gpg git && rm --recursive --force /var/lib/apt/lists/*
      - curl --silent --show-error --location "https://raw.githubusercontent.com/upciti/wakemeops/main/assets/install_repository" | bash
      - apt-get install --yes glab
      - echo "Configuring glab"
      - echo $GITLAB_HOST
      - echo "Creating OpenCode auth configuration"
      - mkdir --parents ~/.local/share/opencode
      - |
        cat > ~/.local/share/opencode/auth.json << EOF
        {
          "anthropic": {
            "type": "api",
            "key": "$ANTHROPIC_API_KEY"
          }
        }
        EOF
      - echo "Configuring git"
      - git config --global user.email "opencode@gitlab.com"
      - git config --global user.name "OpenCode"
      - echo "Testing glab"
      - glab issue list
      - echo "Running OpenCode"
      - |
        opencode run "
        You are an AI assistant helping with GitLab operations.

        Context: $AI_FLOW_CONTEXT
        Task: $AI_FLOW_INPUT
        Event: $AI_FLOW_EVENT

        Please execute the requested task using the available GitLab tools.
        Be thorough in your analysis and provide clear explanations.

        <important>
        Please use the glab CLI to access data from GitLab. The glab CLI has already been authenticated. You can run the corresponding commands.

        If you are asked to summarize an MR or issue or asked to provide more information then please post back a note to the MR/Issue so that the user can see it.
        You don't need to commit or push up changes, those will be done automatically based on the file changes you make.
        </important>
        "
      - git checkout --branch $CI_WORKLOAD_REF origin/$CI_WORKLOAD_REF
      - echo "Checking for git changes and pushing if any exist"
      - |
        if ! git diff --quiet || ! git diff --cached --quiet || [ --not --zero "$(git ls-files --others --exclude-standard)" ]; then
          echo "Git changes detected, adding and pushing..."
          git add .
          if git diff --cached --quiet; then
            echo "No staged changes to commit"
          else
            echo "Committing changes to branch: $CI_WORKLOAD_REF"
            git commit --message "Codex changes"
            echo "Pushing changes up to $CI_WORKLOAD_REF"
            git push https://gitlab-ci-token:$GITLAB_TOKEN@$GITLAB_HOST/gl-demo-ultimate-dev-ai-epic-17570/test-java-project.git $CI_WORKLOAD_REF
            echo "Changes successfully pushed"
          fi
        else
          echo "No git changes detected, skipping push"
        fi
    variables:
      - ANTHROPIC_API_KEY
      - GITLAB_TOKEN_OPENCODE
      - GITLAB_HOST
    ```

### Příklady

Zde je několik příkladů, jak můžete použít OpenCode v GitLabu.

:::tip
Můžete nakonfigurovat použití jiné spouštěcí fráze než `@opencode`.
:::

- **Vysvětlete problém**

Přidejte tento komentář do vydání GitLab.

  ```
  @opencode explain this issue
  ```

OpenCode si problém přečte a odpoví jasným vysvětlením.

- **Opravit problém**

V čísle GitLab řekněte:

  ```
  @opencode fix this
  ```

OpenCode vytvoří novou větev, implementuje změny a otevře žádost o sloučení se změnami.

- **Zkontrolujte žádosti o sloučení**

Zanechte následující komentář k žádosti o sloučení GitLab.

  ```
  @opencode review this merge request
  ```

OpenCode žádost o sloučení zkontroluje a poskytne zpětnou vazbu.
