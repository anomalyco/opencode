OpenCode automaticky formátuje soubory poté, co jsou zapsány nebo upraveny pomocí formátovačů specifických pro daný jazyk. Tím zajistíte, že vygenerovaný kód bude odpovídat stylům kódu vašeho projektu.

---

## Vestavěný

OpenCode přichází s několika vestavěnými formátovači pro oblíbené jazyky a rámce. Níže je uveden seznam potřebných formátovačů, podporovaných přípon souborů a příkazů nebo možností konfigurace.

---

## Jak to funguje

Když OpenCode zapisuje nebo upravuje soubor,:

1. Zkontroluje příponu souboru proti všem povoleným formátovačům.
2. Spustí příslušný příkaz formátovače na souboru.
3. Automaticky použije změny formátování.

Tento proces probíhá na pozadí a zajišťuje, že vaše styly kódu budou zachovány bez jakýchkoli ručních kroků.

## Konfigurace

Formátovače si můžete přizpůsobit prostřednictvím sekce `formatter` v konfiguraci OpenCode.

```json title="opencode.json"
{
  "$schema": "https://opencode.ai/config.json",
  "formatter": {}
}
```

Každá konfigurace formátovače podporuje následující:

| Nemovitost | Typ | Popis |
| -------------- | -------- | -------------------------------------------------------- |
| `disabled` | booleovský | Nastavením na `true` deaktivujete formátovač |
| `command` | řetězec[] | Příkaz ke spuštění pro formátování |
| `environment` | objekt | Proměnné prostředí, které se mají nastavit při spuštění formátovače |
| `extensions` | řetězec[] | Přípony souborů by měl tento formátovač zvládnout |

Podívejme se na některé příklady.

---

### Zakázání formátovačů

Chcete-li globálně zakázat **všechny** formátovače, nastavte `formatter` na `false`:

```json title="opencode.json" {3}
{
  "$schema": "https://opencode.ai/config.json",
  "formatter": false
}
```

Chcete-li deaktivovat **konkrétní** formátovač, nastavte `disabled` na `true`:

```json title="opencode.json" {5}
{
  "$schema": "https://opencode.ai/config.json",
  "formatter": {
    "prettier": {
      "disabled": true
    }
  }
}
```

---

### Vlastní formátovače

Vestavěné formátovače můžete přepsat nebo přidat nové zadáním příkazu, proměnných prostředí a přípon souborů:

```json title="opencode.json" {4-14}
{
  "$schema": "https://opencode.ai/config.json",
  "formatter": {
    "prettier": {
      "command": ["npx", "prettier", "--write", "$FILE"],
      "environment": {
        "NODE_ENV": "development"
      },
      "extensions": [".js", ".ts", ".jsx", ".tsx"]
    },
    "custom-markdown-formatter": {
      "command": ["deno", "fmt", "$FILE"],
      "extensions": [".md"]
    }
  }
}
```

Zástupný symbol **`$FILE`** v příkazu bude nahrazen cestou k formátovanému souboru.
