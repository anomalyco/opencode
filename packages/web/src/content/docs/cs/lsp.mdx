OpenCode se integruje s vaším protokolem Language Server Protocol (LSP), aby pomohl LLM interagovat s vaší kódovou základnou. K poskytování zpětné vazby LLM využívá diagnostiku.

---

:::note
Automatické stahování serveru LSP můžete zakázat nastavením proměnné prostředí `OPENCODE_DISABLE_LSP_DOWNLOAD` na `true`.
:::

## Jak to funguje

Když opencode otevře soubor, bude:

1. Zkontroluje příponu souboru proti všem povoleným serverům LSP.
2. Spustí příslušný server LSP, pokud již není spuštěn.

---

## Konfigurace

Servery LSP můžete přizpůsobit prostřednictvím sekce `lsp` ve vaší konfiguraci opencode.

```json title="opencode.json"
{
  "$schema": "https://opencode.ai/config.json",
  "lsp": {}
}
```

Každý server LSP podporuje následující:

| Nemovitost | Typ | Popis |
| ----------------- | -------- | -------------------------------------------------- |
| `disabled` | booleovský | Nastavením na `true` deaktivujete server LSP |
| `command` | řetězec[] | Příkaz ke spuštění serveru LSP |
| `extensions` | řetězec[] | Přípony souborů by měl tento server LSP zvládnout |
| `env` | objekt | Proměnné prostředí pro nastavení při spouštění serveru |
| `initialization` | objekt | Možnosti inicializace pro odeslání na server LSP |

Podívejme se na některé příklady.

---

### Proměnné prostředí

Použijte vlastnost `env` k nastavení proměnných prostředí při spouštění serveru LSP:

```json title="opencode.json" {5-7}
{
  "$schema": "https://opencode.ai/config.json",
  "lsp": {
    "rust": {
      "env": {
        "RUST_LOG": "debug"
      }
    }
  }
}
```

---

### Možnosti inicializace

Pomocí vlastnosti `initialization` předejte možnosti inicializace serveru LSP. Toto jsou nastavení specifická pro server odeslaná během požadavku LSP `initialize`:

```json title="opencode.json" {5-9}
{
  "$schema": "https://opencode.ai/config.json",
  "lsp": {
    "typescript": {
      "initialization": {
        "preferences": {
          "importModuleSpecifierPreference": "relative"
        }
      }
    }
  }
}
```

:::note
Možnosti inicializace se liší podle serveru LSP. Dostupné možnosti naleznete v dokumentaci k serveru LSP.
:::

---

### Deaktivace serverů LSP

Chcete-li globálně zakázat **všechny** servery LSP, nastavte `lsp` na `false`:

```json title="opencode.json" {3}
{
  "$schema": "https://opencode.ai/config.json",
  "lsp": false
}
```

Chcete-li zakázat **konkrétní** server LSP, nastavte `disabled` na `true`:

```json title="opencode.json" {5}
{
  "$schema": "https://opencode.ai/config.json",
  "lsp": {
    "typescript": {
      "disabled": true
    }
  }
}
```

---

### Vlastní servery LSP

Vlastní servery LSP můžete přidat zadáním příkazu a přípon souborů:

```json title="opencode.json" {4-7}
{
  "$schema": "https://opencode.ai/config.json",
  "lsp": {
    "custom-lsp": {
      "command": ["custom-lsp-server", "--stdio"],
      "extensions": [".custom"]
    }
  }
}
```

## Další informace

### Intelephense PHP

PHP Intelephense nabízí prémiové funkce prostřednictvím licenčního klíče. Licenční klíč můžete poskytnout umístěním (pouze) klíče do textového souboru na adrese:

- V systému macOS/Linux: `$HOME/intelephense/license.txt`
- Na Windows: `%USERPROFILE%/intelephense/license.txt`

Soubor by měl obsahovat pouze licenční klíč bez dalšího obsahu.
