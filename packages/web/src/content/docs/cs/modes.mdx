title: Režimy
description: Různé režimy pro různé případy použití.
---

:::caution
Režimy se nyní konfigurují pomocí možnosti `agent` v konfiguraci OpenCode.
Možnost `mode` je zastaralá. [Další informace](/docs/cs/agents).
:::

Režimy v OpenCode vám umožňují přizpůsobit chování, nástroje a prompty pro různé případy použití.

OpenCode obsahuje dva vestavěné režimy: **build** a **plan**. Můžete je upravit
nebo si nakonfigurovat vlastní pomocí konfigurace OpenCode.

Během relace můžete přepínat mezi režimy nebo je nakonfigurovat v konfiguračním souboru.

---

## Vestavěný

OpenCode obsahuje dva vestavěné režimy.

---

### Build

Build je **výchozí** režim se všemi povolenými nástroji. Toto je standardní režim pro vývojovou práci, kde potřebujete plný přístup k operacím se soubory a systémovým příkazům.

---

### Plán

Omezený režim určený pro plánování a analýzu. V režimu plánu jsou ve výchozím nastavení zakázány následující nástroje:

- `write` - Nelze vytvářet nové soubory
- `edit` - Nelze upravit existující soubory, s výjimkou souborů umístěných na `.opencode/plans/*.md` pro podrobný popis samotného plánu
- `patch` - Nelze aplikovat záplaty
- `bash` - Nelze provádět příkazy shellu

Tento režim je užitečný, když chcete, aby AI analyzoval kód, navrhoval změny nebo vytvářel plány bez jakýchkoli skutečných úprav vaší kódové základny.

---

## Přepínání

Během relace můžete přepínat mezi režimy pomocí klávesy _Tab_. Nebo vaše nakonfigurovaná klávesnice `switch_mode`.

Viz také: [Formatters](/docs/cs/formatters) pro informace o konfiguraci formátování kódu.

---

## Konfigurace

Můžete si přizpůsobit vestavěné režimy nebo si vytvořit svůj vlastní prostřednictvím konfigurace. Režimy lze konfigurovat dvěma způsoby:

### Konfigurace JSON

Nakonfigurujte režimy v konfiguračním souboru `opencode.json`:

```json title="opencode.json"
{
  "$schema": "https://opencode.ai/config.json",
  "mode": {
    "build": {
      "model": "anthropic/claude-sonnet-4-20250514",
      "prompt": "{file:./prompts/build.txt}",
      "tools": {
        "write": true,
        "edit": true,
        "bash": true
      }
    },
    "plan": {
      "model": "anthropic/claude-haiku-4-20250514",
      "tools": {
        "write": false,
        "edit": false,
        "bash": false
      }
    }
  }
}
```

### Konfigurace Markdown

Můžete také definovat režimy pomocí souborů markdown. Umístěte je do:

- Globální: `~/.config/opencode/modes/`
- Projekt: `.opencode/modes/`

```markdown title="~/.config/opencode/modes/review.md"
---
model: anthropic/claude-sonnet-4-20250514
temperature: 0.1
tools:
  write: false
  edit: false
  bash: false
---

You are in code review mode. Focus on:

- Code quality and best practices
- Potential bugs and edge cases
- Performance implications
- Security considerations

Provide constructive feedback without making direct changes.
```

Název souboru markdown se stane názvem režimu (např. `review.md` vytvoří režim `review`).

Podívejme se na tyto možnosti konfigurace podrobně.

---

### Model

Použijte konfiguraci `model` k přepsání výchozího modelu pro tento režim. Užitečné pro použití různých modelů optimalizovaných pro různé úkoly. Například rychlejší model pro plánování, schopnější model pro implementaci.

```json title="opencode.json"
{
  "mode": {
    "plan": {
      "model": "anthropic/claude-haiku-4-20250514"
    }
  }
}
```

---

### Teplota

Ovládejte náhodnost a kreativitu odpovědí AI pomocí konfigurace `temperature`. Nižší hodnoty činí odpovědi cílenější a determinističtější, zatímco vyšší hodnoty zvyšují kreativitu a variabilitu.

```json title="opencode.json"
{
  "mode": {
    "plan": {
      "temperature": 0.1
    },
    "creative": {
      "temperature": 0.8
    }
  }
}
```

Hodnoty teploty se obvykle pohybují od 0,0 do 1,0:

- **0,0-0,2**: Velmi soustředěné a deterministické reakce, ideální pro analýzu a plánování kódu
- **0,3-0,5**: Vyvážené odpovědi s trochou kreativity, dobré pro obecné rozvojové úkoly
– **0,6–1,0**: Kreativnější a rozmanitější odpovědi, užitečné pro brainstorming a průzkum

```json title="opencode.json"
{
  "mode": {
    "analyze": {
      "temperature": 0.1,
      "prompt": "{file:./prompts/analysis.txt}"
    },
    "build": {
      "temperature": 0.3
    },
    "brainstorm": {
      "temperature": 0.7,
      "prompt": "{file:./prompts/creative.txt}"
    }
  }
}
```

Pokud není specifikována žádná teplota, opencode použije výchozí hodnoty specifické pro daný model (obvykle 0 pro většinu modelů, 0,55 pro modely Qwen).

---

### Výzva

S konfigurací `prompt` určete vlastní soubor systémových výzev pro tento režim. Soubor s výzvou by měl obsahovat pokyny specifické pro účel režimu.

```json title="opencode.json"
{
  "mode": {
    "review": {
      "prompt": "{file:./prompts/code-review.txt}"
    }
  }
}
```

Tato cesta je relativní vzhledem k umístění konfiguračního souboru. Takže tohle funguje
jak globální konfiguraci opencode, tak konfiguraci specifickou pro projekt.

---

### Nástroje

Pomocí konfigurace `tools` můžete ovládat, které nástroje jsou v tomto režimu dostupné. Konkrétní nástroje můžete povolit nebo zakázat jejich nastavením na `true` nebo `false`.

```json
{
  "mode": {
    "readonly": {
      "tools": {
        "write": false,
        "edit": false,
        "bash": false,
        "read": true,
        "grep": true,
        "glob": true
      }
    }
  }
}
```

Pokud nejsou zadány žádné nástroje, všechny nástroje jsou ve výchozím nastavení povoleny.

---

#### Dostupné nástroje

Zde jsou všechny nástroje, které lze ovládat pomocí konfigurace režimu.

| Nástroj | Popis |
| ----------- | ----------------------- |
| `bash` | Provádět příkazy shellu |
| `edit` | Upravit existující soubory |
| `write` | Vytvořit nové soubory |
| `read` | Číst obsah souboru |
| `grep` | Prohledat obsah souboru |
| `glob` | Najít soubory podle vzoru |
| `patch` | Použít záplaty na soubory |
| `todowrite` | Spravovat seznamy úkolů |
| `webfetch` | Načítání webového obsahu |

## Vlastní režimy

Můžete si vytvořit své vlastní vlastní režimy jejich přidáním do konfigurace. Zde jsou příklady použití obou přístupů:

### Použití konfigurace JSON

```json title="opencode.json" {4-14}
{
  "$schema": "https://opencode.ai/config.json",
  "mode": {
    "docs": {
      "prompt": "{file:./prompts/documentation.txt}",
      "tools": {
        "write": true,
        "edit": true,
        "bash": false,
        "read": true,
        "grep": true,
        "glob": true
      }
    }
  }
}
```

### Používání souborů markdown

Vytvořte soubory režimů v `.opencode/modes/` pro režimy specifické pro projekt nebo `~/.config/opencode/modes/` pro globální režimy:

```markdown title=".opencode/modes/debug.md"
---
temperature: 0.1
tools:
  bash: true
  read: true
  grep: true
  write: false
  edit: false
---

You are in debug mode. Your primary goal is to help investigate and diagnose issues.

Focus on:

- Understanding the problem through careful analysis
- Using bash commands to inspect system state
- Reading relevant files and logs
- Searching for patterns and anomalies
- Providing clear explanations of findings

Do not make any changes to files. Only investigate and report.
```

```markdown title="~/.config/opencode/modes/refactor.md"
---
model: anthropic/claude-sonnet-4-20250514
temperature: 0.2
tools:
  edit: true
  read: true
  grep: true
  glob: true
---

You are in refactoring mode. Focus on improving code quality without changing functionality.

Priorities:

- Improve code readability and maintainability
- Apply consistent naming conventions
- Reduce code duplication
- Optimize performance where appropriate
- Ensure all tests continue to pass
```

---

### Případy použití

Zde jsou některé běžné případy použití pro různé režimy.

- **Režim sestavení**: Úplná vývojová práce se všemi povolenými nástroji
- **Režim plánu**: Analýza a plánování bez provádění změn
- **Režim kontroly**: Kontrola kódu s přístupem pouze pro čtení plus dokumentační nástroje
- **Režim ladění**: Zaměřeno na vyšetřování s aktivovanými nástroji bash a čtení
- **Režim Dokumentů**: Psaní dokumentace pomocí operací se soubory, ale bez systémových příkazů

Můžete také zjistit, že různé modely jsou dobré pro různé případy použití.
