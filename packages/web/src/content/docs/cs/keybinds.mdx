## Klíč vůdce

OpenCode používá pro většinu klávesnic klíč `leader`. Vyhnete se tak konfliktům ve vašem terminálu.

Ve výchozím nastavení je klávesa odkazu `ctrl+x` a většina akcí vyžaduje, abyste nejprve stiskli klávesu odkazu a poté klávesovou zkratku. Chcete-li například zahájit novou relaci, nejprve stiskněte `ctrl+x` a poté stiskněte `n`.

Pro své klávesové zkratky nemusíte používat vodicí klíč, ale doporučujeme tak učinit.

Některé navigační klávesy ve výchozím nastavení záměrně nepoužívají hlavní klávesu. Pro relace subagenta jsou výchozí hodnoty `session_child_first` = `\<leader>down`, `session_child_cycle` = `right`, `session_child_cycle_reverse` = `left` a `session_parent` = `up`.

## Zakázat vázání klávesnice

Klávesnici můžete deaktivovat přidáním klíče do `tui.json` s hodnotou „none“.

```json title="tui.json"
{
  "$schema": "https://opencode.ai/tui.json",
  "keybinds": {
    "session_compact": "none"
  }
}
```

## Klávesové zkratky na ploše

Zadání příkazového řádku OpenCode desktopové aplikace podporuje běžné klávesové zkratky ve stylu Readline/Emacs pro úpravu textu. Ty jsou vestavěné a v současnosti je nelze konfigurovat pomocí `opencode.json`.

| Zkratka | Akce |
| -------- | ----------------------------------------- |
| `ctrl+a` | Přesunout na začátek aktuálního řádku |
| `ctrl+e` | Přesunout na konec aktuálního řádku |
| `ctrl+b` | Posuňte kurzor zpět o jeden znak |
| `ctrl+f` | Posuňte kurzor o jeden znak dopředu |
| `alt+b` | Posuňte kurzor zpět o jedno slovo |
| `alt+f` | Posuňte kurzor o jedno slovo dopředu |
| `ctrl+d` | Smazat znak pod kurzorem |
| `ctrl+k` | Zabít do konce řádku |
| `ctrl+u` | Zabít na začátek řádku |
| `ctrl+w` | Zabijte předchozí slovo |
| `alt+d` | Zabijte další slovo |
| `ctrl+t` | Transponovat znaky |
| `ctrl+g` | Zrušit vyskakovací okna / přerušit běžící odpověď |

## Shift+Enter

Některé terminály ve výchozím nastavení neposílají modifikační klíče s Enterem. Možná budete muset nakonfigurovat svůj terminál tak, aby odesílal `Shift+Enter` jako únikovou sekvenci.

### Terminál Windows

Otevřete svůj `settings.json` na:

```
%LOCALAPPDATA%\Packages\Microsoft.WindowsTerminal_8wekyb3d8bbwe\LocalState\settings.json
```

Přidejte toto do kořenového pole `actions`:

```json
"actions": [
  {
    "command": {
      "action": "sendInput",
      "input": "\u001b[13;2u"
    },
    "id": "User.sendInput.ShiftEnterCustom"
  }
]
```

Přidejte toto do kořenového pole `keybindings`:

```json
"keybindings": [
  {
    "keys": "shift+enter",
    "id": "User.sendInput.ShiftEnterCustom"
  }
]
```

Uložte soubor a restartujte Windows Terminal nebo otevřete novou kartu.
