OpenCode poskytuje interaktivní terminálové rozhraní nebo TUI pro práci na vašich projektech s LLM.

Spuštěním OpenCode se spustí TUI pro aktuální adresář.

```bash
opencode
```

Nebo jej můžete spustit pro konkrétní pracovní adresář.

```bash
opencode /path/to/project
```

Jakmile jste v TUI, můžete jej vyzvat zprávou.

```text
Give me a quick summary of the codebase.
```

---

## Referenční soubor

Na soubory ve zprávách můžete odkazovat pomocí `@`. To provede fuzzy hledání souborů v aktuálním pracovním adresáři.

:::tip
`@` můžete také použít k odkazování na soubory ve zprávách.
:::

```text "@packages/functions/src/api/index.ts"
How is auth handled in @packages/functions/src/api/index.ts?
```

Obsah souboru se do konverzace přidá automaticky.

## Bash příkazy

Spusťte zprávu pomocí `!` a spusťte příkaz shellu.

```bash frame="none"
!ls -la
```

Výstup příkazu je přidán do konverzace jako výsledek nástroje.

## Příkazy

Při použití OpenCode TUI můžete zadat `/` následovaný názvem příkazu pro rychlé provedení akcí. Například:

```bash frame="none"
/help
```

Většina příkazů má také klávesovou vazbu pomocí `ctrl+x` jako hlavní klávesy, kde `ctrl+x` je výchozí klávesa odkazu. [Další informace](/docs/cs/keybinds).

Zde jsou všechny dostupné příkazy lomítka:

---

### připojit

Přidejte poskytovatele do OpenCode. Umožňuje vybrat z dostupných poskytovatelů a přidat jejich klíče API.

```bash frame="none"
/connect
```

---

### kompaktní

Zkomprimujte aktuální relaci. _Alias_: `/summarize`

```bash frame="none"
/compact
```

**Klávesa:** `ctrl+x c`

---

### podrobnosti

Přepnout podrobnosti provádění nástroje.

```bash frame="none"
/details
```

**Klávesa:** `ctrl+x d`

---

### editor

Otevřete externí editor pro psaní zpráv. Používá editor nastavený ve vaší proměnné prostředí `EDITOR`. [Další informace](#nastavení-editoru).

```bash frame="none"
/editor
```

**Klávesa:** `ctrl+x e`

---

### odchod

Ukončete OpenCode. _Aliasy_: `/quit`, `/q`

```bash frame="none"
/exit
```

**Klávesa:** `ctrl+x q`

---

### exportovat

Exportujte aktuální konverzaci do Markdown a otevřete ji ve výchozím editoru. Používá editor nastavený ve vaší proměnné prostředí `EDITOR`. [Další informace](#nastavení-editoru).

```bash frame="none"
/export
```

**Klávesa:** `ctrl+x x`

---

### pomoc

Zobrazit dialogové okno nápovědy.

```bash frame="none"
/help
```

**Klávesa:** `ctrl+x h`

---

### init

Průvodce nastavením pro vytvoření nebo aktualizaci `AGENTS.md`. [Další informace](/docs/cs/rules).

```bash frame="none"
/init
```

**Klávesa:** `ctrl+x i`

---

### modely

Seznam dostupných modelů.

```bash frame="none"
/models
```

**Klávesa:** `ctrl+x m`

---

### nové

Začněte novou relaci. _Alias_: `/clear`

```bash frame="none"
/new
```

**Klávesa:** `ctrl+x n`

---

### znovu

Opakujte dříve vrácenou zprávu. Dostupné pouze po použití `/undo`.

:::tip
Všechny změny souboru budou také obnoveny.
:::

Interně to používá Git ke správě změn souborů. Takže váš projekt **musí
být úložiště Git**.

```bash frame="none"
/redo
```

**Klávesa:** `ctrl+x r`

---

### relace

Seznam relací a přepínání mezi nimi. _Aliasy_: `/resume`, `/continue`

```bash frame="none"
/sessions
```

**Klávesa:** `ctrl+x l`

---

### sdílet

Sdílet aktuální relaci. [Další informace](/docs/cs/share).

```bash frame="none"
/share
```

**Klávesa:** `ctrl+x s`

---

### motivů

Seznam dostupných témat.

```bash frame="none"
/themes
```

**Klávesa:** `ctrl+x t`

---

### přemýšlet

Přepínání viditelnosti bloků myšlení/uvažování v konverzaci. Je-li povoleno, můžete vidět proces uvažování modelu pro modely, které podporují rozšířené myšlení.

:::note
Tento příkaz pouze řídí, zda se **zobrazují** bloky myšlení – nepovoluje ani nezakazuje možnosti uvažování modelu. Chcete-li přepínat skutečné možnosti uvažování, použijte `ctrl+t` k procházení variant modelu.
:::

```bash frame="none"
/thinking
```

---

### vrátit zpět

Vrátit zpět poslední zprávu v konverzaci. Odstraní nejnovější uživatelskou zprávu, všechny následné odpovědi a všechny změny souborů.

:::tip
Všechny provedené změny souboru budou také vráceny.
:::

Interně to používá Git ke správě změn souborů. Takže váš projekt **musí
být úložiště Git**.

```bash frame="none"
/undo
```

**Klávesa:** `ctrl+x u`

---

### zrušit sdílení

Zrušit sdílení aktuální relace. [Další informace](/docs/cs/share/#zrušení-sdílení).

```bash frame="none"
/unshare
```

## Nastavení editoru

Příkazy `/editor` i `/export` používají editor zadaný ve vaší proměnné prostředí `EDITOR`.

<Tabs>
  <TabItem label="Linux/macOS">
    ```bash
    # Example for nano or vim
    export EDITOR=nano
    export EDITOR=vim

    # For GUI editors, VS Code, Cursor, VSCodium, Windsurf, Zed, etc.
    # include --wait
    export EDITOR="code --wait"
    ```

Aby to bylo trvalé, přidejte to do svého profilu shellu;
    `~/.bashrc`, `~/.zshrc` atd.

  </TabItem>

  <TabItem label="Windows (CMD)">
    ```bash
    set EDITOR=notepad

    # For GUI editors, VS Code, Cursor, VSCodium, Windsurf, Zed, etc.
    # include --wait
    set EDITOR=code --wait
    ```

Chcete-li, aby byl trvalý, použijte **Vlastnosti systému** > **Prostředí
    Proměnné**.

  </TabItem>

  <TabItem label="Windows (PowerShell)">
    ```powershell
    $env:EDITOR = "notepad"

    # For GUI editors, VS Code, Cursor, VSCodium, Windsurf, Zed, etc.
    # include --wait
    $env:EDITOR = "code --wait"
    ```

Aby to bylo trvalé, přidejte to do svého profilu PowerShell.

  </TabItem>
</Tabs>

Mezi oblíbené možnosti editoru patří:

- `code` - Visual Studio Code
- `cursor` - Kurzor
- `windsurf` - Windsurf
- `nvim` - Editor Neovim
- `vim` - Editor Vim
- `nano` - Nano editor
- `notepad` - Windows Poznámkový blok
- `subl` - Vznešený text

:::note
Některé editory jako VS Code je třeba spustit s příznakem `--wait`.
:::

Některé editory potřebují ke spuštění v režimu blokování argumenty příkazového řádku. Příznak `--wait` zablokuje proces editoru až do uzavření.

## Konfigurace

Chování TUI můžete přizpůsobit pomocí `tui.json` (nebo `tui.jsonc`).

```json title="tui.json"
{
  "$schema": "https://opencode.ai/tui.json",
  "theme": "opencode",
  "keybinds": {
    "leader": "ctrl+x"
  },
  "scroll_speed": 3,
  "scroll_acceleration": {
    "enabled": true
  },
  "diff_style": "auto",
  "mouse": true
}
```

Toto je oddělené od `opencode.json`, který konfiguruje chování serveru/běhu.

### Možnosti

- `theme` - Nastaví váš motiv UI. [Další informace](/docs/cs/themes).
- `keybinds` - Přizpůsobuje klávesové zkratky. [Další informace](/docs/cs/keybinds).
- `scroll_acceleration.enabled` - Povolte zrychlení posouvání ve stylu macOS pro plynulé a přirozené posouvání. Je-li povoleno, rychlost posouvání se zvyšuje pomocí rychlých gest posouvání a zůstává přesná i pro pomalejší pohyby. **Toto nastavení má přednost před `scroll_speed` a přepíše ho, když je povoleno.**
- `scroll_speed` - Řídí, jak rychle se TUI posouvá při použití povelů posouvání (minimum: `0.001`, podporuje desetinné hodnoty). Výchozí hodnota je `3`. **Poznámka: Toto se ignoruje, pokud je `scroll_acceleration.enabled` nastaveno na `true`.**
- `diff_style` - Ovládá vykreslování rozdílů. `"auto"` se přizpůsobí šířce terminálu, `"stacked"` vždy zobrazuje jednosloupcové rozložení.
- `mouse` - Povolí nebo zakáže zachycení myši v TUI (výchozí: `true`). Je-li zakázáno, zachová se nativní chování terminálu při výběru/posouvání myší.

Pomocí `OPENCODE_TUI_CONFIG` načtěte vlastní konfigurační cestu TUI.

## Přizpůsobení

Různé aspekty pohledu TUI můžete přizpůsobit pomocí palety příkazů (`ctrl+x h` nebo `/help`). Tato nastavení přetrvávají po restartování.

---

#### Zobrazení uživatelského jména

Přepněte, zda se vaše uživatelské jméno zobrazuje ve zprávách chatu. Přístup k tomu přes:

- Paleta příkazů: Vyhledejte „uživatelské jméno“ nebo „skrýt uživatelské jméno“
- Nastavení automaticky přetrvává a bude si zapamatováno během relací TUI
