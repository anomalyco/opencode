---
title: 引用
description: 将本地目录和 Git 仓库添加为项目引用。
---

引用使 OpenCode 能够访问当前项目之外的目录。使用它们可在工作时提供文档、共享库、示例或其他仓库。

引用通过别名在 `opencode.json` 或 `opencode.jsonc` 中配置。

```jsonc title="opencode.jsonc"
{
  "$schema": "https://opencode.ai/config.json",
  "references": {
    "docs": {
      "path": "../product-docs",
      "description": "用于产品行为和文档约定",
    },
    "sdk": {
      "repository": "anomalyco/opencode-sdk-js",
      "branch": "main",
      "description": "用于 JavaScript SDK 实现细节",
    },
  },
}
```

---

## 本地目录

使用 `path` 引用一个本地目录。

```jsonc title="opencode.jsonc"
{
  "references": {
    "docs": {
      "path": "../docs",
    },
  },
}
```

路径可以是：

- 相对于定义该引用的配置文件
- 绝对路径，例如 `/home/user/docs`
- 相对于你的主目录，例如 `~/docs`

你也可以使用字符串简写形式：

```jsonc title="opencode.jsonc"
{
  "references": {
    "docs": "../docs",
  },
}
```

## Git 仓库

使用 `repository` 引用一个 Git 仓库。OpenCode 会在其本地仓库缓存中具体化该仓库，并将检出的源代码作为引用目录提供。

```jsonc title="opencode.jsonc"
{
  "references": {
    "effect": {
      "repository": "Effect-TS/effect",
      "branch": "main",
    },
  },
}
```

`repository` 接受 Git URL、主机/路径引用以及 GitHub `owner/repo` 简写形式。可选的 `branch` 字段用于选择分支或引用。若不指定 `branch`，OpenCode 将使用仓库的默认分支。

当你不需要分支、描述或其他选项时，可以使用字符串简写形式：

```jsonc title="opencode.jsonc"
{
  "references": {
    "effect": "Effect-TS/effect",
  },
}
```

:::note
Git 引用是异步刷新的。新配置的仓库可能需要一些时间来完成克隆或更新。
:::

## 描述用途

添加 `description` 以说明代理何时应使用引用。

```jsonc title="opencode.jsonc"
{
  "references": {
    "design-system": {
      "path": "../design-system",
      "description": "在实现 UI 组件或设计令牌时使用",
    },
  },
}
```

OpenCode 会将带有描述的引用包含在代理上下文中。描述应简短且具体，足以区分内容相似的引用。没有描述的引用仍然可以通过自动补全和直接使用来访问，但不会主动告知代理。

## 隐藏自动补全条目

将 `hidden` 设置为 `true` 可在 TUI 的 `@` 自动补全中省略引用。

```jsonc title="opencode.jsonc"
{
  "references": {
    "internal": {
      "path": "../internal",
      "description": "用于内部实现细节",
      "hidden": true,
    },
  },
}
```

`hidden` 仅影响自动补全。带有描述的隐藏引用仍会包含在代理上下文中。

## 使用引用

配置的引用会出现在 TUI 的 `@` 自动补全中。键入 `@别名` 可附加引用根目录，或键入 `@别名/` 来搜索其中的文件。

```text
将此实现与 @sdk/src/client.ts 进行比较
```

代理还会在其系统上下文中接收到已配置引用的解析路径和描述（带有描述的引用），因此它们可以在相关时检查引用，而无需你手动附加。

OpenCode 会自动允许引用目录通过其外部目录权限边界。常规工具权限仍然适用；例如，无法编辑文件的代理不会因为某个目录被配置为引用而获得编辑权限。

## 配置字段

| 字段           | 本地 | Git | 描述                                          |
| -------------- | ---- | --- | --------------------------------------------- |
| `path`         | 是   | 否  | 本地引用目录                                  |
| `repository`   | 否   | 是  | Git URL、主机/路径或 GitHub `owner/repo` 值  |
| `branch`       | 否   | 是  | 可选的 Git 分支或引用                         |
| `description`  | 是   | 是  | 说明何时使用该引用的指导                      |
| `hidden`       | 是   | 是  | 从 TUI `@` 自动补全中隐藏引用                 |

引用别名不能为空，也不能包含 `/`、空格、反引号或逗号。
