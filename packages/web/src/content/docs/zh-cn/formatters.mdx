OpenCode 会在写入或编辑文件后，使用语言特定的 formatter 自动格式化。这确保生成的代码符合你的项目代码风格。

---

## 工作方式

当 OpenCode 写入或编辑文件时，它会：

1. 将文件扩展名与所有启用的 formatter 进行匹配。
2. 对文件运行对应的 formatter 命令。
3. 自动应用格式化更改。

该流程在后台执行，确保你的代码风格在无需手动操作的情况下保持一致。

---

## 配置

你可以通过 OpenCode 配置中的 `formatter` 部分自定义 formatter。

```json title="opencode.json"
{
  "$schema": "https://opencode.ai/config.json",
  "formatter": {}
}
```

每个 formatter 配置支持以下字段：

| Property      | Type     | Description                     |
| ------------- | -------- | ------------------------------- |
| `disabled`    | boolean  | 设为 `true` 可禁用该 formatter  |
| `command`     | string[] | 格式化时运行的命令              |
| `environment` | object   | 运行 formatter 时设置的环境变量 |
| `extensions`  | string[] | 该 formatter 处理的文件扩展名   |

下面是一些示例。

---

### 禁用 formatter

要全局禁用 **所有** formatter，将 `formatter` 设为 `false`：

```json title="opencode.json" {3}
{
  "$schema": "https://opencode.ai/config.json",
  "formatter": false
}
```

要禁用 **特定** formatter，将 `disabled` 设为 `true`：

```json title="opencode.json" {5}
{
  "$schema": "https://opencode.ai/config.json",
  "formatter": {
    "prettier": {
      "disabled": true
    }
  }
}
```

---

### 自定义 formatter

你可以通过指定命令、环境变量与文件扩展名来覆盖内置 formatter 或新增 formatter：

```json title="opencode.json" {4-14}
{
  "$schema": "https://opencode.ai/config.json",
  "formatter": {
    "prettier": {
      "command": ["npx", "prettier", "--write", "$FILE"],
      "environment": {
        "NODE_ENV": "development"
      },
      "extensions": [".js", ".ts", ".jsx", ".tsx"]
    },
    "custom-markdown-formatter": {
      "command": ["deno", "fmt", "$FILE"],
      "extensions": [".md"]
    }
  }
}
```

命令中的 **`$FILE` 占位符** 会被替换为正在格式化的文件路径。
