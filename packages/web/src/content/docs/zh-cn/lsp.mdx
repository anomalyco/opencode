OpenCode 与 Language Server Protocol (LSP) 集成，帮助 LLM 与代码库交互。它使用 diagnostics 向 LLM 提供反馈。

---

:::note
你可以将 `OPENCODE_DISABLE_LSP_DOWNLOAD` 环境变量设为 `true` 来禁用 LSP server 自动下载。
:::

## 工作方式

当 opencode 打开文件时，它会：

1. 将文件扩展名与所有已启用的 LSP servers 进行匹配。
2. 如有需要，启动对应的 LSP server。

---

## 配置

你可以通过 opencode 配置中的 `lsp` 部分自定义 LSP servers。

```json title="opencode.json"
{
  "$schema": "https://opencode.ai/config.json",
  "lsp": {}
}
```

每个 LSP server 支持以下字段：

| Property         | Type     | Description                    |
| ---------------- | -------- | ------------------------------ |
| `disabled`       | boolean  | 设为 `true` 禁用该 LSP server  |
| `command`        | string[] | 启动 LSP server 的命令         |
| `extensions`     | string[] | 该 LSP server 处理的文件扩展名 |
| `env`            | object   | 启动 server 时设置的环境变量   |
| `initialization` | object   | 发送给 LSP server 的初始化选项 |

下面是一些示例。

---

### 禁用 LSP servers

要全局禁用 **所有** LSP servers，将 `lsp` 设为 `false`：

```json title="opencode.json" {3}
{
  "$schema": "https://opencode.ai/config.json",
  "lsp": false
}
```

要禁用 **特定** LSP server，将 `disabled` 设为 `true`：

```json title="opencode.json" {5}
{
  "$schema": "https://opencode.ai/config.json",
  "lsp": {
    "typescript": {
      "disabled": true
    }
  }
}
```

---

### 自定义 LSP servers

你可以通过指定命令与扩展名来添加自定义 LSP servers：

```json title="opencode.json" {4-7}
{
  "$schema": "https://opencode.ai/config.json",
  "lsp": {
    "custom-lsp": {
      "command": ["custom-lsp-server", "--stdio"],
      "extensions": [".custom"]
    }
  }
}
```

## 其他信息

### PHP Intelephense

PHP Intelephense 提供需要 license key 的高级功能。你可以将（仅）license key 放入以下文本文件：

- macOS/Linux：`$HOME/intelephense/licence.txt`
- Windows：`%USERPROFILE%/intelephense/licence.txt`

该文件仅应包含 license key，不应包含其他内容。
