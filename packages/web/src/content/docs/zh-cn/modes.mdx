opencode 中的 Mode 允许你针对不同用例自定义行为、tools 与 prompts。

它内置两个 Mode：**build** 与 **plan**。你可以自定义它们，或在 opencode 配置中创建自己的 Mode。

你可以在会话中切换 Mode，或在配置文件中设置它们。

---

## 内置

opencode 内置两个 Mode。

---

### Build

Build 是 **默认** Mode，启用所有 tools。这是开发工作的标准 Mode，需要完整的文件操作与系统命令访问。

---

### Plan

一个用于规划与分析的受限 Mode。在 plan Mode 下，以下 tools 默认禁用：

- `write` - 不能创建新文件
- `edit` - 不能修改已有文件，除非是 `.opencode/plans/*.md` 用于描述计划本身
- `patch` - 不能应用补丁
- `bash` - 不能执行 shell 命令

当你希望 AI 分析代码、提出建议或制定计划，但不对代码库做实际改动时，这个 Mode 很有用。

---

## 切换

你可以在会话中使用 _Tab_ 键切换 Mode，或使用你配置的 `switch_mode` keybind。

另请参阅：[Formatters](/docs/formatters) 了解代码格式化配置。

---

## 配置

你可以通过配置自定义内置 Mode 或创建自己的 Mode。Mode 有两种配置方式：

### JSON Configuration

在 `opencode.json` 中配置 Mode：

```json title="opencode.json"
{
  "$schema": "https://opencode.ai/config.json",
  "mode": {
    "build": {
      "model": "anthropic/claude-sonnet-4-20250514",
      "prompt": "{file:./prompts/build.txt}",
      "tools": {
        "write": true,
        "edit": true,
        "bash": true
      }
    },
    "plan": {
      "model": "anthropic/claude-haiku-4-20250514",
      "tools": {
        "write": false,
        "edit": false,
        "bash": false
      }
    }
  }
}
```

### Markdown Configuration

你也可以使用 markdown 文件定义 Mode。将文件放在：

- 全局：`~/.config/opencode/modes/`
- 项目：`.opencode/modes/`

```markdown title="~/.config/opencode/modes/review.md"
---
model: anthropic/claude-sonnet-4-20250514
temperature: 0.1
tools:
  write: false
  edit: false
  bash: false
---

You are in code review mode. Focus on:

- Code quality and best practices
- Potential bugs and edge cases
- Performance implications
- Security considerations

Provide constructive feedback without making direct changes.
```

markdown 文件名即为 Mode 名称（例如 `review.md` 创建 `review` Mode）。

我们来详细看看这些配置选项。

---

### Model

使用 `model` 配置覆盖该 Mode 的默认模型。适用于为不同任务选择不同模型，例如用于规划的更快模型或用于实现的更强模型。

```json title="opencode.json"
{
  "mode": {
    "plan": {
      "model": "anthropic/claude-haiku-4-20250514"
    }
  }
}
```

---

### Temperature

使用 `temperature` 配置控制 AI 回复的随机性与创造力。较低的值使回复更聚焦、更确定；较高的值会增加创造力与变化度。

```json title="opencode.json"
{
  "mode": {
    "plan": {
      "temperature": 0.1
    },
    "creative": {
      "temperature": 0.8
    }
  }
}
```

Temperature 常见范围为 0.0 到 1.0：

- **0.0-0.2**：非常聚焦且确定，适合代码分析与规划
- **0.3-0.5**：平衡且有一定创造力，适合一般开发任务
- **0.6-1.0**：更有创造力与变化性，适合头脑风暴与探索

```json title="opencode.json"
{
  "mode": {
    "analyze": {
      "temperature": 0.1,
      "prompt": "{file:./prompts/analysis.txt}"
    },
    "build": {
      "temperature": 0.3
    },
    "brainstorm": {
      "temperature": 0.7,
      "prompt": "{file:./prompts/creative.txt}"
    }
  }
}
```

如果未指定 temperature，opencode 使用模型默认值（多数模型为 0，Qwen 模型为 0.55）。

---

### Prompt

使用 `prompt` 为该 Mode 指定自定义 system prompt 文件。该 prompt 文件应包含与 Mode 目的相关的指令。

```json title="opencode.json"
{
  "mode": {
    "review": {
      "prompt": "{file:./prompts/code-review.txt}"
    }
  }
}
```

该路径相对于配置文件所在位置，因此既适用于全局 opencode 配置，也适用于项目配置。

---

### Tools

使用 `tools` 配置控制该 Mode 可用的 tools。你可以通过设置 `true` 或 `false` 来启用或禁用特定 tools。

```json
{
  "mode": {
    "readonly": {
      "tools": {
        "write": false,
        "edit": false,
        "bash": false,
        "read": true,
        "grep": true,
        "glob": true
      }
    }
  }
}
```

如果未指定 tools，默认启用所有 tools。

---

#### 可用 tools

以下是可在 Mode 配置中控制的所有 tools。

| Tool        | Description             |
| ----------- | ----------------------- |
| `bash`      | Execute shell commands  |
| `edit`      | Modify existing files   |
| `write`     | Create new files        |
| `read`      | Read file contents      |
| `grep`      | Search file contents    |
| `glob`      | Find files by pattern   |
| `list`      | List directory contents |
| `patch`     | Apply patches to files  |
| `todowrite` | Manage todo lists       |
| `todoread`  | Read todo lists         |
| `webfetch`  | Fetch web content       |

## 自定义 Mode

你可以通过配置添加自定义 Mode。下面是两种方式的示例：

### 使用 JSON 配置

```json title="opencode.json" {4-14}
{
  "$schema": "https://opencode.ai/config.json",
  "mode": {
    "docs": {
      "prompt": "{file:./prompts/documentation.txt}",
      "tools": {
        "write": true,
        "edit": true,
        "bash": false,
        "read": true,
        "grep": true,
        "glob": true
      }
    }
  }
}
```

### 使用 markdown 文件

在 `.opencode/modes/` 创建项目级 Mode，或在 `~/.config/opencode/modes/` 创建全局 Mode：

```markdown title=".opencode/modes/debug.md"
---
temperature: 0.1
tools:
  bash: true
  read: true
  grep: true
  write: false
  edit: false
---

You are in debug mode. Your primary goal is to help investigate and diagnose issues.

Focus on:

- Understanding the problem through careful analysis
- Using bash commands to inspect system state
- Reading relevant files and logs
- Searching for patterns and anomalies
- Providing clear explanations of findings

Do not make any changes to files. Only investigate and report.
```

```markdown title="~/.config/opencode/modes/refactor.md"
---
model: anthropic/claude-sonnet-4-20250514
temperature: 0.2
tools:
  edit: true
  read: true
  grep: true
  glob: true
---

You are in refactoring mode. Focus on improving code quality without changing functionality.

Priorities:

- Improve code readability and maintainability
- Apply consistent naming conventions
- Reduce code duplication
- Optimize performance where appropriate
- Ensure all tests continue to pass
```

---

### Use cases

以下是不同 Mode 的常见用例。

- **Build mode**：启用所有 tools 的完整开发
- **Plan mode**：仅分析与规划，不做改动
- **Review mode**：只读代码审查 + 文档 tools
- **Debug mode**：专注排查，启用 bash 与 read tools
- **Docs mode**：文档编写，允许文件操作但不允许系统命令

你可能也会发现，不同 models 适合不同用例。
