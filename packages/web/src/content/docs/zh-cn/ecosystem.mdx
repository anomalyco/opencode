你也可以看看 [awesome-opencode](https://github.com/awesome-opencode/awesome-opencode) 和 [opencode.cafe](https://opencode.cafe)，这是聚合生态与社区的站点。

## Plugins

| 名称                                                                                               | 描述                                                                       |
| -------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| [opencode-helicone-session](https://github.com/H2Shami/opencode-helicone-session)                  | 自动注入 Helicone 会话头，用于请求分组                                     |
| [opencode-type-inject](https://github.com/nick-vi/opencode-type-inject)                            | 通过查找工具将 TypeScript/Svelte 类型自动注入到文件读取中                  |
| [opencode-openai-codex-auth](https://github.com/numman-ali/opencode-openai-codex-auth)             | 使用你的 ChatGPT Plus/Pro 订阅而不是 API 额度                              |
| [opencode-gemini-auth](https://github.com/jenslys/opencode-gemini-auth)                            | 使用你已有的 Gemini 计划而不是 API 计费                                    |
| [opencode-antigravity-auth](https://github.com/NoeFabris/opencode-antigravity-auth)                | 使用 Antigravity 的免费模型而不是 API 计费                                 |
| [opencode-devcontainers](https://github.com/athal7/opencode-devcontainers)                         | 使用浅克隆与自动分配端口的多分支 devcontainer 隔离                         |
| [opencode-google-antigravity-auth](https://github.com/shekohex/opencode-google-antigravity-auth)   | Google Antigravity OAuth Plugin，支持 Google Search，以及更稳健的 API 处理 |
| [opencode-dynamic-context-pruning](https://github.com/Tarquinen/opencode-dynamic-context-pruning)  | 通过剪枝过时的工具输出来优化 token 使用                                    |
| [opencode-websearch-cited](https://github.com/ghoulr/opencode-websearch-cited.git)                 | 为支持的 provider 添加原生 websearch，并采用 Google grounded 风格          |
| [opencode-pty](https://github.com/shekohex/opencode-pty.git)                                       | 允许 AI Agent 在 PTY 中运行后台进程，并向其发送交互输入                    |
| [opencode-shell-strategy](https://github.com/JRedeker/opencode-shell-strategy)                     | 针对非交互式 shell 命令的指引，避免依赖 TTY 的操作导致挂起                 |
| [opencode-wakatime](https://github.com/angristan/opencode-wakatime)                                | 使用 Wakatime 跟踪 OpenCode 使用情况                                       |
| [opencode-md-table-formatter](https://github.com/franlol/opencode-md-table-formatter/tree/main)    | 清理由 LLM 生成的 markdown 表格                                            |
| [opencode-morph-fast-apply](https://github.com/JRedeker/opencode-morph-fast-apply)                 | 使用 Morph Fast Apply API 与惰性编辑标记实现 10 倍更快的代码编辑           |
| [oh-my-opencode](https://github.com/code-yeongyu/oh-my-opencode)                                   | 后台 Agent、预置 LSP/AST/MCP 工具、精选 Agent、兼容 Claude Code            |
| [opencode-notificator](https://github.com/panta82/opencode-notificator)                            | OpenCode 会话的桌面通知与声音提醒                                          |
| [opencode-notifier](https://github.com/mohak34/opencode-notifier)                                  | 针对权限、完成与错误事件的桌面通知与声音提醒                               |
| [opencode-zellij-namer](https://github.com/24601/opencode-zellij-namer)                            | 基于 OpenCode 上下文的 AI 自动 Zellij 会话命名                             |
| [opencode-skillful](https://github.com/zenobi-us/opencode-skillful)                                | 允许 OpenCode Agent 按需懒加载 prompt，并注入 skill 发现机制               |
| [opencode-supermemory](https://github.com/supermemoryai/opencode-supermemory)                      | 通过 Supermemory 实现跨会话的持久记忆                                      |
| [@plannotator/opencode](https://github.com/backnotprop/plannotator/tree/main/apps/opencode-plugin) | 带可视化标注与私有/离线分享的交互式计划审阅                                |
| [@openspoon/subtask2](https://github.com/spoons-and-mirrors/subtask2)                              | 将 opencode /commands 扩展为强大的编排系统，提供细粒度流程控制             |
| [opencode-scheduler](https://github.com/different-ai/opencode-scheduler)                           | 使用 launchd（Mac）或 systemd（Linux）与 cron 语法调度定时任务             |
| [micode](https://github.com/vtemian/micode)                                                        | 结构化 Brainstorm → Plan → Implement 工作流，支持会话连续性                |
| [octto](https://github.com/vtemian/octto)                                                          | 面向 AI 头脑风暴的交互式浏览器 UI，支持多问题表单                          |
