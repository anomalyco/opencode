OpenCode Zen 是由 OpenCode 团队测试并验证的模型列表。

:::note
OpenCode Zen 目前处于 beta 阶段。
:::

Zen 的使用方式与 OpenCode 中的其他 provider 一样。你登录 OpenCode Zen 并获取 API key。它是**完全可选的**，不使用它也能使用 OpenCode。

---

## 背景

市面上模型众多，但只有少数适合作为 coding agent 使用。此外，大多数 provider 的配置差异很大，因此性能与质量表现各不相同。

:::tip
我们测试了一组与 OpenCode 配合良好的模型和 provider。
:::

因此，如果你通过 OpenRouter 等方式使用模型，就无法确定自己是否得到了想要的最佳版本。

为了解决这个问题，我们做了几件事：

1. 我们测试了一组精选模型，并与其团队讨论如何最佳运行它们。
2. 我们与部分 provider 合作，确保这些模型被正确提供。
3. 最后，我们对模型与 provider 的组合进行基准测试，整理出我们觉得值得推荐的列表。

OpenCode Zen 是一个 AI gateway，让你能够访问这些模型。

---

## 工作方式

OpenCode Zen 的工作方式与 OpenCode 中的其他 provider 一样。

1. 登录 **<a href={console}>OpenCode Zen</a>**，添加账单信息并复制 API key。
2. 在 TUI 中运行 `/connect`，选择 OpenCode Zen，并粘贴 API key。
3. 在 TUI 中运行 `/models` 查看我们推荐的模型列表。

你按请求计费，可以为账户充值。

### 自动续费

当你的余额低于 $5 时，Zen 会自动充值 $20。

你可以更改自动充值金额，也可以完全关闭自动续费。

---

### 月度额度

你还可以为整个 workspace 以及每位团队成员设置月度使用上限。

例如，你将月度上限设置为 $20，那么 Zen 每月不会使用超过 $20。但如果启用了自动续费，当余额低于 $5 时，Zen 可能会扣费超过 $20。

## 隐私

所有模型均托管在美国。我们的 provider 遵循零保留政策，不会使用你的数据进行模型训练，但以下情况除外：

- Grok Code Fast 1：在免费期间，收集的数据可能用于改进 Grok Code。
- GLM 4.7：在免费期间，收集的数据可能用于改进模型。
- MiniMax M2.1：在免费期间，收集的数据可能用于改进模型。
- Big Pickle：在免费期间，收集的数据可能用于改进模型。
- OpenAI APIs：请求会保留 30 天，符合 [OpenAI's Data Policies](https://platform.openai.com/docs/guides/your-data)。
- Anthropic APIs：请求会保留 30 天，符合 [Anthropic's Data Policies](https://docs.anthropic.com/en/docs/claude-code/data-usage)。

Zen 也非常适合团队使用。你可以邀请成员、分配角色、管理团队可用模型等。

:::note
目前，workspace 在 beta 期间对团队免费。
:::

管理 workspace 目前在 beta 期间对团队免费。我们会很快分享更多定价细节。

### 角色

你可以邀请成员加入 workspace 并分配角色：

- **Admin**: 管理模型、成员、API key 与账单
- **Member**: 仅管理自己的 API key

Admin 还可以为每位成员设置月度支出上限，控制成本。

---

### 模型访问

Admin 可以为 workspace 启用或禁用指定模型。对已禁用模型的请求会返回错误。

这适用于你想禁用某些会收集数据的模型。

---

### 自带 key

你可以使用自己的 OpenAI 或 Anthropic API key，同时继续使用 Zen 中的其他模型。

使用自有 key 时，token 费用直接由 provider 计费，而不是由 Zen 计费。

例如，你的组织可能已经拥有 OpenAI 或 Anthropic key，你希望使用该 key 而不是 Zen 提供的。

---

## 目标

我们创建 OpenCode Zen 的目标是：

1. **Benchmark** 适合 coding agent 的最佳模型与 provider。
2. 提供**最高质量**选项，不降低性能或转向更便宜的 provider。
3. 以成本价转售，**价格下调**全部传递；唯一的加成仅用于覆盖手续费。
4. **无锁定**，允许你与任意 coding agent 一起使用，并始终允许你在 OpenCode 中使用其他 provider。
