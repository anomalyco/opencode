`opencode serve` 命令运行一个无界面 HTTP server，并暴露 OpenAPI 端点供 opencode client 使用。

---

### Usage

```bash
opencode serve [--port <number>] [--hostname <string>] [--cors <origin>]
```

#### Options

| Flag         | Description             | Default     |
| ------------ | ----------------------- | ----------- |
| `--port`     | 监听端口                | `4096`      |
| `--hostname` | 监听 hostname           | `127.0.0.1` |
| `--mdns`     | 启用 mDNS discovery     | `false`     |
| `--cors`     | 允许的额外浏览器 origin | `[]`        |

`--cors` 可多次传入：

```bash
opencode serve --cors http://localhost:5173 --cors https://app.example.com
```

---

### Authentication

设置 `OPENCODE_SERVER_PASSWORD` 以启用 HTTP basic auth。用户名默认 `opencode`，或设置 `OPENCODE_SERVER_USERNAME` 覆盖。该设置同时适用于 `opencode serve` 与 `opencode web`。

```bash
OPENCODE_SERVER_PASSWORD=your-password opencode serve
```

---

### 工作方式

运行 `opencode` 时会启动 TUI 与 server，TUI 是与 server 通信的 client。server 暴露 OpenAPI 3.1 spec 端点，该端点也用于生成 [SDK](/docs/sdk)。

:::tip
使用 opencode server 以编程方式与 opencode 交互。
:::

这种架构让 opencode 支持多客户端，并支持编程式交互。

你可以运行 `opencode serve` 启动独立 server。如果已有 opencode TUI 运行，`opencode serve` 会启动新的 server。

---

#### 连接到已有 server

TUI 启动时会随机分配端口与 hostname。你也可以传入 `--hostname` 与 `--port` [flags](/docs/cli)。随后可用这些信息连接到 server。

[`/tui`](#tui) 端点可通过 server 驱动 TUI，例如预填或运行 prompt。OpenCode [IDE](/docs/ide) plugins 就使用了该设置。

---

## Spec

server 发布 OpenAPI 3.1 spec，可在以下地址查看：

```
http://<hostname>:<port>/doc
```

例如 `http://localhost:4096/doc`。你可以用它生成 client 或查看请求/响应类型，也可在 Swagger 中浏览。

### Files

| Method | Path                     | Description         | Response                                                                           |
| ------ | ------------------------ | ------------------- | ---------------------------------------------------------------------------------- |
| `GET`  | `/find?pattern=<pat>`    | 在文件中搜索文本    | 匹配对象数组，包含 `path`、`lines`、`line_number`、`absolute_offset`、`submatches` |
| `GET`  | `/find/file?query=<q>`   | 按名称查找文件/目录 | `string[]`（路径）                                                                 |
| `GET`  | `/find/symbol?query=<q>` | 查找工作区 symbols  | <a href={typesUrl}><code>Symbol[]</code></a>                                       |
| `GET`  | `/file?path=<path>`      | 列出文件与目录      | <a href={typesUrl}><code>FileNode[]</code></a>                                     |
| `GET`  | `/file/content?path=<p>` | 读取文件            | <a href={typesUrl}><code>FileContent</code></a>                                    |
| `GET`  | `/file/status`           | 获取跟踪文件状态    | <a href={typesUrl}><code>File[]</code></a>                                         |

#### `/find/file` 查询参数

- `query`（必填）— 搜索字符串（模糊匹配）
- `type`（可选）— 限制结果为 `"file"` 或 `"directory"`
- `directory`（可选）— 覆盖项目根目录
- `limit`（可选）— 最大结果数量（1–200）
- `dirs`（可选）— 旧标志（`"false"` 仅返回文件）
