A collection of community projects built on xcsh.

:::note
Want to add your xcsh related project to this list? Submit a PR.
:::

You can also check out [awesome-xcsh](https://github.com/awesome-xcsh/awesome-xcsh) and [xcsh.cafe](https://xcsh.cafe), a community that aggregates the ecosystem and community.
