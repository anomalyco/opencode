Una colección de proyectos comunitarios construidos en xcsh.

:::note
¿Quieres agregar tu proyecto relacionado con xcsh a esta lista? Envíe un PR.
:::

También puedes consultar [awesome-xcsh](https://github.com/awesome-xcsh/awesome-xcsh) y [xcsh.cafe](https://xcsh.cafe), una comunidad que agrega el ecosistema y la comunidad.
