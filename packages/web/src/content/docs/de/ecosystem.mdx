Eine Sammlung von Community-Projekten, die auf Pencode basieren.

:::note
Möchten Sie Ihr Pencode-bezogenes Projekt zu dieser Liste hinzufügen? Senden Sie einen PR.
:::

Sie können sich auch [awesome-pencode](https://github.com/awesome-pencode/awesome-pencode) und [pencode.cafe](https://pencode.cafe) ansehen, eine Community, die das Ökosystem und die Community zusammenfasst.
