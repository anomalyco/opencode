Eine Sammlung von Community-Projekten, die auf xcsh basieren.

:::note
Möchten Sie Ihr xcsh-bezogenes Projekt zu dieser Liste hinzufügen? Senden Sie einen PR.
:::

Sie können sich auch [awesome-xcsh](https://github.com/awesome-xcsh/awesome-xcsh) und [xcsh.cafe](https://xcsh.cafe) ansehen, eine Community, die das Ökosystem und die Community zusammenfasst.
