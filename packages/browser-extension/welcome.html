OpenCode Browser

Lets your AI agents use this browser through the browse MCP tools: open and drive tabs, run Playwright, take screenshots, record, and hand off to you for logins.

Set up

Run this once in a terminal. It adds the browse tools to opencode.

npx opencode-browser-cli install

Using it

  • Agents open their own tabs, grouped at the top of the tab strip. Tabs nobody uses for 10 minutes close.
  • To let agents use a tab you have open, click the OpenCode Browser toolbar button on it. Click again to stop.
  • When an agent needs you (a login, 2FA, a payment), the page shows a banner. Finish, then click Continue.
