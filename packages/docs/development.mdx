<Info>**Prerequisites**: Node.js 19+ and a docs workspace with `packages/docs/docs.json`.</Info>

This folder uses Mintlify for a lightweight preview of OpenCode documentation and the API reference. The production docs at https://opencode.ai/docs are sourced from `packages/web/src/content/docs`.

<Steps>
<Step title="Install the Mintlify CLI">

```bash
npm i -g mint
```

</Step>

<Step title="Run the local docs preview">

From `packages/docs`, run:

```bash
mint dev
```

The preview is available at `http://localhost:3000`.

</Step>
</Steps>

## Custom ports

Use the `--port` flag when you need a different port:

```bash
mint dev --port 3333
```

If the default port is in use, Mintlify will pick the next available port and print a message like:

```md
Port 3000 is already in use. Trying 3001 instead.
```

## Mintlify versions

If the local preview doesn’t align with production, update the CLI:

```bash
npm i -g mint@latest
```

## Code formatting

For MDX syntax highlighting and formatting in VS Code, install:

- [MDX VSCode extension](https://marketplace.visualstudio.com/items?itemName=unifiedjs.vscode-mdx)
- [Prettier](https://marketplace.visualstudio.com/items?itemName=esbenp.prettier-vscode)

## Validating links

Check for broken links before opening a PR:

```bash
mint broken-links
```

## Troubleshooting

<AccordionGroup>
	<Accordion title='Error: Could not load the "sharp" module using the darwin-arm64 runtime'>

		This may be due to an outdated version of Node. Try the following:
		1. Remove the currently-installed CLI: `npm remove -g mint`
		2. Upgrade to Node v19 or higher.
		3. Reinstall the CLI: `npm i -g mint`

	</Accordion>

	<Accordion title="Issue: Encountering an unknown error">

		Solution: Delete the `~/.mintlify` folder and run `mint dev` again.
	</Accordion>

</AccordionGroup>

If the preview still fails to boot, remove the Mintlify cache and retry:

```bash
rm -rf ~/.mintlify
mint dev
```
