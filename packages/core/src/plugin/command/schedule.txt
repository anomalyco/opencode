Manage scheduled prompts for this session.

Request: $ARGUMENTS

Use the schedule tools in the `opencode` namespace. They only see this session's schedules.

- To schedule something, call `schedule_create`. Choose `when`: `{"in": "20 minutes"}`, `{"at": "2026-10-27T09:00"}`, `{"every": "1 hour"}` or `{"cron": "0 9 * * 1-5"}`. With `until`, the default is every 30 seconds.
- Use `until` to wake once and stop (24h default timeout, matches immediately if already true), or `if` to check each recurring slot without a model call (the initial check sets state without waking). Pass `{"run": command}` for a shell check or `{"code": program}` for a Python check. Python checks must call tools by static path, e.g. `return await tools.example.ready()`. No `fetch`; caps are 30 seconds, 20 calls, and 32 KB. Return a bool or a dictionary with `wake` and optional `state` and `message`. Checks run once at creation with `state = None`; an exception fails `schedule_create`.
- To stop a repeating schedule, add `ends`: `{"after": "8 hours"}`, `{"at": timestamp}`, or `{"times": 3}`. Write `prompt` as the instruction you will receive when it wakes, with enough context to act without this conversation.
- To pause, resume or delete one, find its id with `schedule_list`, then call `schedule_pause`, `schedule_resume` or `schedule_delete`.
- If the request is empty, call `schedule_list` and show this session's schedules: name, when, status and next run.

Reply in one line: what changed and when it next fires.
