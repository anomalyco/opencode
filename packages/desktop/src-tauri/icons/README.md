# Icons

This directory should contain the application icons in various formats.

For now, you can generate these using:
```bash
bun tauri icon path/to/icon.png
```

Required formats:
- 32x32.png
- 128x128.png
- 128x128@2x.png
- icon.icns (macOS)
- icon.ico (Windows)
- icon.png

Temporary: Using fallback configurations until proper icons are added.
