# @opencode-ai/sdk (Python)

Python SDK for the [opencode](https://opencode.ai) HTTP API. Mirrors the
JavaScript SDK in `packages/sdk/js`. The client is generated from the same
OpenAPI document used by the JS SDK (`packages/sdk/openapi.json`) so the two
stay in lockstep.

## Install

```bash
pip install opencode-ai
```

Requires Python 3.10+. The runtime depends only on `httpx`, `attrs`, and
`python-dateutil`.

## Quick start

```python
from opencode_ai import Client, ServerOptions, create_opencode_server
from opencode_ai.api.default import global_health, session_create, session_prompt

# Spawn a local opencode server (or skip this and connect to an existing one).
with create_opencode_server(ServerOptions(port=4096)) as server:
    client = Client(base_url=server.url)

    health = global_health.sync(client=client)
    print(health.version)

    session = session_create.sync(client=client).id
    session_prompt.sync(client=client, id=session, body=...)
```

The generated client follows the standard
[`openapi-python-client`](https://github.com/openapi-generators/openapi-python-client)
convention: every operation lives in its own module under
`opencode_ai.api.<tag>` (most operations live under `default`) and exposes
four entry points:

| function          | result                                |
| ----------------- | ------------------------------------- |
| `sync`            | parsed model on success, `None` on 4xx with `raise_on_unexpected_status=False` |
| `sync_detailed`   | full `Response[...]` with status, headers, raw bytes |
| `asyncio`         | coroutine variant of `sync`           |
| `asyncio_detailed`| coroutine variant of `sync_detailed`  |

## Server helper

`create_opencode_server` spawns the local `opencode serve` process, blocks
until it prints its listen URL, and returns a context manager that shuts the
process down cleanly on exit. The async sibling
`AsyncServerHandle.create()` provides the same behavior for asyncio code.

```python
import asyncio
from opencode_ai import AsyncServerHandle, ServerOptions
from opencode_ai.api.default import global_health

async def main():
    async with await AsyncServerHandle.create(ServerOptions(port=0)) as server:
        # ... use server.url
        pass

asyncio.run(main())
```

## Authentication

For deployments that require an auth token, pass it via the
`AuthenticatedClient` re-export:

```python
from opencode_ai import AuthenticatedClient

client = AuthenticatedClient(base_url=..., token="...")
```

## Regeneration

The package source is generated by `openapi-python-client` from
`packages/sdk/openapi.json`. Hand-written files (`__init__.py`, `server.py`)
are layered on top from `scripts/_overlay/`.

```bash
# Regenerate in place after editing the overlay or the OpenAPI spec.
python packages/sdk/python/scripts/generate.py

# CI runs this in --check mode and fails if the result differs from disk.
python packages/sdk/python/scripts/generate.py --check
```

## Testing

```bash
pip install -e packages/sdk/python[dev]
pytest packages/sdk/python/tests
```

The smoke suite under `tests/test_smoke.py` is skipped unless an `opencode`
binary is on `$PATH`. CI provides the binary by building the monorepo.
