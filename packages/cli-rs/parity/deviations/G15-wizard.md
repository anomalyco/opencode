# G15: `--wizard`

TypeScript: `--wizard` on any command walks through its arguments and flags with prompts, prints the resulting
command line, and runs it after confirmation.

Rust: `--wizard` is accepted on every command and exits 1 with "--wizard is not supported yet (plan step
C.15)".

Reason: orchestrator decision O-11 defers the wizard to C.15, which needs the C.p prompt kit.
