# Senior Backend Engineer

## Role
- Company: Northline Analytics (fictional)
- Team: Data Platform
- Level: IC4 / Senior
- Location: Remote (US time zones) · hybrid SF optional

## Must-haves
- 5+ years building production backend services
- Strong TypeScript or Go in production (both a plus)
- Experience with Postgres at scale (indexing, migrations, query plans)
- Designed or operated event-driven systems (Kafka, SQS, or equivalent)
- Comfortable owning on-call for services you ship

## Nice-to-haves
- Prior data-platform or analytics-engineering adjacency
- OpenTelemetry / metrics-first debugging
- Mentoring mid-level engineers

## Deal-breakers
- No production backend ownership (pure frontend or pure research only)
- Unable to work overlapping 10:00–14:00 PT core hours

## Scorecard
Score each dimension 1–5. Hire bar: no dimension below 3; average ≥ 3.5 for "yes".

| Dimension | 1 | 3 | 5 |
|-----------|---|---|---|
| Backend ownership | Assisted only | Owned services end-to-end | Led multi-service or platform slice |
| Languages (TS/Go) | Exposure only | Production in one | Production depth in one + working other |
| Data stores | CRUD apps | Postgres tuning/migrations | Scale + failure modes |
| Events / async | None | Queues or pub/sub in prod | Designed consumers, retries, DLQ |
| Reliability / on-call | None | Participated | Drove incident quality + prevention |
| Communication | Unclear | Clear with probes | Crisp written + verbal signal |

- **Strong yes:** avg ≥ 4.0, no dim < 3, clear ownership stories
- **Yes:** avg ≥ 3.5, gaps coachable
- **Mixed:** avg 3.0–3.4 or one dim at 2 with compensating strengths
- **No:** any must-have dim at 1, or deal-breaker present

## Process
- Stages: sourced → screen → phone → onsite → offer → hire
- Loop: recruiter screen (30m) → technical screen (system design lite + debugging, 60m) → onsite (deep system design, coding, values) → hiring manager + team match
- Comp: $185k–$220k base · 0.15%–0.25% equity · standard benefits
