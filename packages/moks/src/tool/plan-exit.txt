Use this tool when you have completed the hiring strategy planning phase and are ready to exit plan agent.

This tool will ask the user if they want to switch to the recruit agent to execute the hiring plan (score / outreach drafts / commit dispositions as planned).

Call this tool:
- After you have written a complete hiring plan to the plan file
- After you have clarified any questions with the user
- When you are confident the plan is ready for recruit to execute

Do NOT call this tool:
- Before you have created or finalized the plan
- If you still have unanswered questions about the hiring approach
- If the user has indicated they want to continue planning
