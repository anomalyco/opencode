OpenCode Console gives you access to coding models tested and verified by the OpenCode team. Use the
[console](https://console.opencode.ai) to manage your API keys, billing, and usage.

Choose how you want to access models:

- **Pay as you go** gives you access to [curated models](/console/models). Add credits to your balance and pay for what you use.
- **Go** is a [low cost subscription](/console/go) for popular open coding models, with included usage limits.

Both work like any other provider in OpenCode and are completely optional. You can also connect directly to
[other providers](/providers).

## Get started

1. Sign in to the [console](https://console.opencode.ai), add credits or subscribe to Go, and copy your API key.
2. Run `/connect` in the TUI, choose the OpenCode provider for your plan, and paste your API key.

   ```text
   /connect
   ```

3. Run `/models` to choose a model from your connected provider.

   ```text
   /models
   ```
