# Autoloop

An **agentic evolutionary optimization loop** for GitHub, inspired by
AlphaEvolve / OpenEvolve and built on
[GitHub Agentic Workflows (`gh aw`)](https://github.com/githubnext/gh-aw).

Autoloop takes a *program* — a goal, a target metric, and a machine-checkable
evaluator — and iteratively rewrites the program's code to maximize the score,
with no human in the loop between iterations. Accepted improvements land as a
pull request.

## How it works

```
autoloop/
├── workflows/
│   ├── autoloop.md            # the agentic workflow (compiled by `gh aw`)
│   └── shared/
│       └── reporting.md       # the run-report format
├── .autoloop/
│   └── programs/              # example programs
│       ├── function_minimization/
│       ├── signal_processing/
│       ├── circle_packing/
│       └── autoresearch/
└── .github/
    ├── ISSUE_TEMPLATE/
    │   └── autoloop-program.md
    └── workflows/             # compiled *.lock.yml (generated by gh aw)
```

Each program directory contains:

- `program.md` — the **goal**, **target metric**, and **evaluation contract**.
- `code/` — the source under optimization. `code/evaluate.py` is the entrypoint
  and prints one JSON line: `{"score": <float>, "valid": <bool>, "metrics": {...}}`.
  Higher `score` is better; `valid: false` rejects the candidate.

The loop, defined in `workflows/autoloop.md`, repeats:
**baseline → hypothesize → mutate `code/` → evaluate → keep-or-revert**,
then opens a PR with the accepted diffs and a run report.

## Example programs

| Program | Goal | Metric | Baseline | Target |
|---|---|---|---|---|
| `function_minimization` | Minimize the 2D Rastrigin function | `-best_value` | ~ -1.75 | `>= -1e-3` |
| `signal_processing` | Denoise a noisy signal | SNR (dB) | ~ 8.5 dB | `>= 20 dB` |
| `circle_packing` | Pack 26 circles in the unit square | sum of radii | ~ 2.17 | `>= 2.6` |
| `autoresearch` | Rank relevant documents | Mean Avg Precision | ~ 0.78 | `>= 0.85` |

## Run a program locally (sanity check)

```bash
cd .autoloop/programs/function_minimization
python code/evaluate.py
```

## Trigger a run on GitHub

1. Install the CLI extension: `gh extension install githubnext/gh-aw`.
2. Compile the workflow: `gh aw compile` (generates
   `.github/workflows/autoloop.lock.yml`).
3. Trigger it via **Actions → Autoloop → Run workflow**, choosing a `program`
   and `iterations`; or open an issue from the **Autoloop program** template and
   apply the `autoloop-program` label.

## Adding your own program

1. Create `.autoloop/programs/<name>/` with a `program.md` and a `code/`
   directory.
2. Make `code/evaluate.py` print the JSON contract line and be the sole judge of
   quality. Provide a weak-but-valid baseline in the file(s) the loop may edit.
3. Never let the loop edit the evaluator — that is the anti-cheating boundary.
