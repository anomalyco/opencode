# Claxedo example (60s launch video)

Assumptions: 60s, 16:9, VO + captions, CTA = Download.

## Message map

| Field | Content |
| --- | --- |
| Audience | Developers using AI coding agents daily |
| Pain | Switching tools, babysitting runs, losing context across sessions |
| Promise | One desktop app to run and manage multiple coding agents efficiently |
| Proof | Built on top of OpenCode; designed for parallel workflows |
| Differentiators | 1) Run OpenCode + other CLI agents 2) Notifications when done 3) Sessions/workspace tabs for control |
| CTA | Download Claxedo |

## Beat sheet

| Time | On-screen headline | What we show | VO |
| --- | --- | --- | --- |
| 0:00–0:04 | `Run agents. Don’t babysit.` | 3 “agent lanes” running → toast “Done” | “Run coding agents in parallel — without babysitting.” |
| 0:04–0:10 | `One place for every run` | Claxedo window with clean tabs/workspaces | “Claxedo is a desktop wrapper around OpenCode — and it can run your other CLI coding agents too.” |
| 0:10–0:22 | `Start multiple agents` | Pick agent → click “Run” → lanes appear | “Kick off multiple sessions at once. Each one gets its own workspace and status.” |
| 0:22–0:35 | `Switch sessions instantly` | Tab hop across sessions; quick previews | “Jump between sessions with workspace tabs, keep context, and stay organized.” |
| 0:35–0:48 | `Get notified when it’s done` | Toast appears; click → result summary (diff/tests/output) | “When an agent finishes, Claxedo notifies you — click to open the results.” |
| 0:48–0:55 | `Works with your tools` | Icons/labels: OpenCode + “Other CLI agents” | “Use the agent you prefer. Claxedo helps you run them efficiently.” |
| 0:55–1:00 | `Download Claxedo` | End card + URL | “Download Claxedo and ship with less friction.” |
