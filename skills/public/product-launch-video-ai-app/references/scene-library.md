# Scene library (AI dev-tool launch videos)

Use 3–5 motifs repeatedly; do not invent new motion every beat.

## Hook patterns (0–4s)

1) **Result-first**
- Visual: “Before/After” split or a finished artifact (diff, tests passing, shipped output)
- Text: 3–5 words (“Ship faster. Stay sane.”)

2) **Parallel proof**
- Visual: lanes/cards duplicating to imply “many agents”
- Text: “Run multiple agents. Cleanly.”

## Transitions (keep consistent)

- **Swipe + blur** for moving between “workspaces”
- **Tab morph** for switching sessions
- **Scale-in toast** for completion notifications

## UI emphasis toolkit

- Cursor spotlight (soft circle around cursor)
- Click ripple (single ring)
- Region highlight (rounded rect + subtle shadow)
- Background defocus (5–10px blur) for focus moments

## Demo beats that sell AI coding apps

### A) Orchestrate work (parallelization)
- Show: “Start agent” → choose agent type → N lanes appear
- Overlay labels: “Agent 1…Agent N”
- Avoid: long scrolling logs; show compact status + key output

### B) Manage sessions (tabs/workspaces)
- Show: top tab bar with 3–6 sessions
- Motion: quick “tab hop” (300–500ms) + title change
- Add: tiny breadcrumbs or “workspace name” lower third

### C) Completion loop (notifications)
- Show: toast “Done” + click → jumps to results
- Reinforce: “You don’t babysit the run”

## Motion heuristics (easy, modern)

- Prefer easing: fast-in, slow-out (avoid bouncy unless brand is playful)
- Cut every 1.5–3.5s during demo section
- Use zoom sparingly: at most 2–3 “camera moves” per 60s
- Keep text large enough for phone view (even in 16:9)
