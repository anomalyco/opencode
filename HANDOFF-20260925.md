## 5. Environment traps that cost real time

- `Stop-ScheduledTask` does not kill the process tree → use `taskkill /PID <pid> /T /F`.
- `git rev-parse --git-dir` returns a **relative** path; use `--absolute-git-dir`.
- `squeez` swallows stdout on long output → redirect to a file and read the file.
- Git Bash quoting eats `$` inside single quotes → write a `.sh` file and run the file.
- `opencode models` is the **authoritative** model resolver (259 entries). The provider
  `/v1/models` endpoints **under-report** — both Meridian's and ChatGPT's misled me badly today.
- `registry.json` is read **once at gateway startup** — config changes need a restart.
- Windows: `SetEnvironmentVariable('X','User')` needs `WM_SETTINGCHANGE` broadcast + a fresh
  process tree.
