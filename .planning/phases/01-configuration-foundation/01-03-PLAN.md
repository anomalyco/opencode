```typescript
// Validate PAM service file exists when auth is enabled
if (result.auth?.enabled) {
  const pamService = result.auth.pam?.service ?? "opencode"
  const pamPath = `/etc/pam.d/${pamService}`
  const pamExists = await Filesystem.exists(pamPath)
  if (!pamExists) {
    throw new PamServiceNotFoundError({
      service: pamService,
      path: pamPath,
    })
  }
  log.info("PAM service file validated", { service: pamService, path: pamPath })
}
```

3. This validation:
   - Only runs when auth.enabled is true
   - Uses the configured service name or defaults to "opencode"
   - Throws PamServiceNotFoundError (defined in Plan 02) if file is missing
   - Logs successful validation for debugging

NOTE: Per CONTEXT.md decision, this is startup-only validation. The file might be deleted later, but that's handled at auth time in future phases.

IMPORTANT: This validation must come AFTER all config merging, so we're validating the final merged config.
