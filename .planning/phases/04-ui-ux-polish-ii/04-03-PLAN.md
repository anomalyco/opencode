<objective>
Replace the abrupt TUI update flow (confirm -> download -> exit) with a non-disruptive background download + persistent badge + install-on-quit pattern.

Purpose: Currently the update flow interrupts the user's work — a dialog appears, and if they accept, the app downloads and then force-exits. This is hostile UX. Instead: download silently in background, show a badge, and apply on next natural quit.
Output: Modified app.tsx with background update, persistent "Update ready" signal, and exit hook.

    Step 1 — Add a pendingUpdate signal near the top of the App function (after line 219, near other signal declarations):
    ```tsx

    ```

    Step 2 — Replace the entire "installation.update-available" event handler (lines 741-786) with:
    ```tsx
    sdk.event.on("installation.update-available", async (evt) => {
      const version = evt.properties.version

      const skipped = kv.get("skipped_version")
      if (skipped && !semver.gt(version, skipped)) return

      // Download in background — no dialog, no interruption
      toast.show({
        variant: "info",
        message: `Downloading update v${version}...`,
        duration: 5000,
      })

      const result = await sdk.client.global.upgrade({ target: version })

      if (result.error || !result.data?.success) {
        toast.show({
          variant: "warning",
          title: "Update failed",
          message: `Could not download v${version}. Will retry next launch.`,
          duration: 8000,
        })
        return
      }

      // Mark update as ready — badge will appear
      setPendingUpdate(result.data.version)
      toast.show({
        variant: "info",
        message: `Update v${result.data.version} ready — restart to apply`,
        duration: 10000,
      })
    })
    ```

    Step 3 — Add a persistent update badge to the App component's root box. Inside the `<box>` that wraps the Switch (lines 788-812), add a Show block BEFORE the Switch:
    ```tsx
    <Show when={pendingUpdate()}>
      <box
        flexDirection="row"
        justifyContent="center"
        paddingTop={0}
        paddingBottom={0}
        flexShrink={0}
      >
        <text fg={theme.primary}>
          {"  Update v"}{pendingUpdate()}{" ready — restart to apply  "}
        </text>
      </box>
    </Show>
    ```

    This renders a single centered line at the top of the app area. It uses theme.primary (the accent color) so it's noticeable but not alarming.

    Step 4 — NO exit hook needed. The upgrade has already been applied by `sdk.client.global.upgrade()` — it runs the package manager install command. The new version will be active on next launch. The old flow called exit() to force a restart; we simply remove that and let the user quit naturally.

    IMPORTANT: Do NOT remove the `semver` import or the `DialogConfirm` import (other code may use them). Do NOT modify any other event handler. The `DialogAlert` import can stay too — it's used by the error component.
