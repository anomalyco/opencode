<task type="auto">
  <name>Task 1: Create SSH key storage + install helpers</name>
  <files>packages/opencode/src/ssh/keys.ts</files>
  <action>
Create a new `SshKey` namespace that owns SSH key records and installation behavior:
- Define Zod schemas for key input (name, publicKey, privateKey, hosts) and stored info (id, fingerprint, created/updated timestamps, installed paths).
- Store per-user records with `Storage` keyed by username (e.g., ["ssh-keys", username, id]) and list helpers for that namespace.
- Compute a SHA256 fingerprint from the public key body using built-in `crypto` (no new dependencies, no `ssh-keygen`).
- Resolve the install target using `session.home` when available, falling back to `Global.Path.home`.
- Ensure `~/.ssh` exists with 0700 permissions, write private key (0600) and public key (0644), and return the paths.
- Update `~/.ssh/config` using a managed block (e.g., `# opencode:begin` / `# opencode:end`) and write `Host` entries for each key's host patterns with `IdentityFile` pointing at the installed key.
- Implement delete flow that removes key files and strips the managed config entries for that key id.
- Avoid logging key material or the raw private key contents.
  </action>
  <verify>Run `bun run typecheck` in `packages/opencode`.</verify>
  <done>SSH keys can be stored, installed into ~/.ssh with secure permissions, and removed cleanly.</done>
</task>
