## 引言

## WU2Compressor核心算法解析

WU2Compressor的核心算法基于Claude Code的官方实现，通过一系列函数和策略实现智能压缩。其主要功能包括token计算、压缩触发检查、压缩执行和质量验证。

### VE/HY5/zY5 Token计算算法

WU2Compressor实现了Claude Code的精确token计算三件套：

- **VE函数**: 反向遍历算法，从最新消息开始查找token使用信息
- **HY5函数**: 过滤助手消息，只从有效消息中提取usage数据
- **zY5函数**: 计算包含缓存的完整token使用量

```javascript
// VE函数 - 反向遍历优化
VE(messages) {
  let index = messages.length - 1;
  while (index >= 0) {
    const message = messages[index];
    const usage = this.HY5(message);
    if (usage) {
      return this.zY5(usage);
    }
    index--;
  }
  return 0;
}
```

### yW5压缩触发检查

yW5函数用于检查是否达到92%阈值触发压缩。该函数结合g11函数检查自动压缩是否启用，并使用m11函数评估警告状态。

```javascript
// yW5函数 - 92%阈值检查
async yW5(messages) {
  if (!this.g11()) return false;

  const currentTokens = this.VE(messages);
  const { isAboveAutoCompactThreshold } = this.m11(
    currentTokens,
    CLAUDE_CONSTANTS.AUTO_COMPACT_THRESHOLD
  );

  return isAboveAutoCompactThreshold;
}
```

## 8段式结构化压缩指令

WU2Compressor采用8段式结构化压缩指令，确保压缩后的摘要包含所有关键信息。这8个部分包括：

1. **主要请求和意图**: 用户的核心目标
2. **关键技术概念**: 对话中涉及的框架、算法、库等
3. **文件和代码片段**: 所有被提及或修改过的代码和文件路径
4. **错误和修复**: 记录遇到的错误信息和最终的解决方案
5. **问题解决过程**: 解决问题的完整思路和决策路径
6. **所有用户消息**: 保留用户的关键指令和反馈
7. **待处理任务**: 未完成的工作项，形成待办清单
8. **当前工作状态**: 明确记录当前对话中断时的进度

## 质量验证与保真度评估

WU2Compressor通过多维度的质量验证机制确保压缩后的摘要具有高保真度。验证过程包括段落完整性检查、关键信息保留情况验证、上下文连续性验证和压缩比例验证。

### 段落完整性检查

验证所有8个段落是否完整存在，确保摘要的结构完整性。

```javascript
validateSectionCompleteness(summary) {
  const foundSections = this.requiredSections.filter(section =>
    summary.toLowerCase().includes(section.toLowerCase()) ||
    this.findSectionByKeywords(summary, section)
  );

  const completeness = foundSections.length / this.requiredSections.length;

  return {
    score: completeness * 100,
    missingCount: this.requiredSections.length - foundSections.length,
    missingSections: this.requiredSections.filter(s => !foundSections.includes(s)),
    isValid: completeness >= this.config.minSectionCoverage
  };
}
```

### 关键信息保留情况验证

检查摘要中保留的关键信息比例，包括文件名、错误信息、用户命令和技术术语。

```javascript
validateKeyInformationPreservation(summary, originalMessages) {
  const keyInfo = this.extractKeyInformation(originalMessages);
  const preservedInfo = {
    fileNames: this.checkFileNamePreservation(summary, keyInfo.fileNames),
    errorMessages: this.checkErrorMessagePreservation(summary, keyInfo.errorMessages),
    userCommands: this.checkUserCommandPreservation(summary, keyInfo.userCommands),
    technicalTerms: this.checkTechnicalTermPreservation(summary, keyInfo.technicalTerms)
  };

  const overallPreservation = Object.values(preservedInfo)
    .reduce((sum, item) => sum + item.preservationRate, 0) / 4;

  return {
    score: overallPreservation * 100,
    details: preservedInfo,
    isValid: overallPreservation >= (1 - this.config.maxKeywordLoss)
  };
}
```

## 优雅降级策略

### 自适应重压缩

调整压缩策略，增加关键信息保留权重，重新进行压缩。

```javascript
async adaptiveRecompression(messages, validationResult) {
  const adjustedConfig = {
    ...this.config,
    maxCompressionRatio: this.config.maxCompressionRatio * 1.2,
    minFidelityScore: Math.max(70, this.config.minFidelityScore - 10)
  };

  const retryCompressor = new WU2Compressor(adjustedConfig);
  return await retryCompressor.compress(messages);
}
```

## 与ClaudeContextManager的集成

WU2Compressor与ClaudeContextManager紧密集成，共同实现高效的上下文管理。ClaudeContextManager负责管理消息存储、文件操作跟踪和状态跟踪，而WU2Compressor负责执行压缩任务。

### 初始化核心组件

在ClaudeContextManager的构造函数中，初始化WU2Compressor和其他核心组件。

```javascript
initializeComponents() {
  this.wu2Compressor = new WU2Compressor({
    llmProvider: this.config.llmProvider,
    apiKey: this.config.apiKey,
    model: this.config.llmModel,
    autoCompactEnabled: this.config.enableAutoCompact
  });

  this.tw5FileRestorer = new TW5FileRestorer({
    maxFiles: this.config.maxFilesToRestore,
    maxTokensPerFile: this.config.maxTokensPerFile,
    maxTotalTokens: this.config.maxTotalRestoreTokens
  });

  this.warningSystem = new ProgressiveWarningSystem({
    contextLimit: this.config.maxTokens,
    enableAutoCompact: this.config.enableAutoCompact

  this.setupEventListeners();

```

## 配置参数与调优建议

WU2Compressor提供了丰富的配置参数，允许用户根据具体需求进行调优。

### 核心配置参数

- **minFidelityScore**: 最低信息保真度，建议设置为80%
- **maxCompressionRatio**: 最大压缩比，建议设置为0.15
- **minSectionCoverage**: 最低段落覆盖度，建议设置为0.875
- **maxKeywordLoss**: 最大关键词丢失率，建议设置为0.20
- **maxRetries**: 最大重试次数，建议设置为3
- **enableQualityValidation**: 是否启用质量验证，建议设置为true

### 调优建议

1. **平衡压缩比和信息保真度**: 根据项目需求调整`maxCompressionRatio`和`minFidelityScore`，在压缩效率和信息保留之间找到最佳平衡点。
2. **优化质量验证**: 根据具体应用场景调整`minSectionCoverage`和`maxKeywordLoss`，确保关键信息不被遗漏。
3. **启用优雅降级**: 在高风险场景下启用`enableQualityValidation`，确保在压缩失败时仍能提供可用的摘要。

## 常见问题与解决方案

### 压缩质量验证失败

**问题描述**: 压缩后的摘要未能通过质量验证，导致信息丢失。

**解决方案**: 
1. 检查`minFidelityScore`和`maxCompressionRatio`设置是否合理。
2. 启用优雅降级策略，确保在极端情况下仍能提供可用的摘要。
3. 调整`minSectionCoverage`和`maxKeywordLoss`，确保关键信息不被遗漏。

### 压缩耗时过长

**问题描述**: 压缩过程耗时过长，影响用户体验。

**解决方案**:
1. 优化LLM调用，减少网络延迟。
2. 调整`maxRetries`，减少重试次数。
3. 使用更高效的token计算算法，减少计算开销。
