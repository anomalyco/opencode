## 概述

Claude Code处理大型项目和大文件的核心策略包括：
- **分层架构理解**：使用PROJECT_INDEX.json和CLAUDE.md文件
- **智能文件加载**：选择性加载相关文件
- **并行代理处理**：使用多个子代理并行搜索
- **语义搜索增强**：集成MCP服务器进行语义搜索
- **上下文工程**：优化上下文窗口管理

## 项目架构索引策略

### PROJECT_INDEX.json 系统

PROJECT_INDEX.json是Claude Code在大项目中的核心导航工具，它提供了项目的整体架构概览。

#### 生成项目索引
```bash
# 生成项目索引
claude-code -i "为这个项目生成架构索引"

# 更新项目索引
claude-code -i "更新PROJECT_INDEX.json，包含最新的项目结构"
```

#### PROJECT_INDEX.json 结构示例
```json
{
  "project_name": "your-project",
  "architecture": {
    "overview": "项目整体架构描述",
    "key_components": ["用户认证系统", "订单处理系统", "支付网关"],
    "dependencies": {
      "react": "^18.0.0",
      "express": "^4.18.0",
      "mongoose": "^7.0.0"
    },
    "data_flow": "客户端 → API网关 → 微服务 → 数据库"
  },
  "directory_structure": {
    "src/": "源代码目录",
    "tests/": "测试目录",
    "docs/": "文档目录",
    "config/": "配置文件目录"
  },
  "important_files": {
    "src/main.js": "应用入口点",
    "src/config/database.js": "数据库配置",
    "src/middleware/auth.js": "认证中间件"
  },
  "key_modules": {
    "authentication": "用户认证相关模块",
    "payment": "支付处理模块",
    "notification": "通知系统模块"
  }
}
```

### CLAUDE.md 文件层次结构

建立分层的CLAUDE.md文件系统可以帮助Claude Code更好地理解项目结构。

```
project-root/
├── CLAUDE.md              # 项目级别说明
├── src/
│   ├── CLAUDE.md          # 源代码级别说明
│   ├── components/
│   │   ├── CLAUDE.md      # 组件级别说明
│   │   └── utils/
│   │       └── CLAUDE.md  # 工具类级别说明
│   └── services/
│       └── CLAUDE.md      # 服务级别说明
├── tests/
│   └── CLAUDE.md          # 测试级别说明
└── docs/
    └── CLAUDE.md          # 文档级别说明
```

#### 项目级别CLAUDE.md示例
```markdown
# 项目：电商系统

## 项目概述
这是一个基于React + Node.js的电商系统，包含用户管理、商品管理、订单处理和支付功能。

## 技术栈
- 前端：React 18, TypeScript, Tailwind CSS
- 后端：Node.js, Express, MongoDB
- 认证：JWT, Passport.js
- 支付：Stripe API

## 核心模块
1. 用户认证模块 (src/auth/)
2. 商品管理模块 (src/products/)
3. 订单处理模块 (src/orders/)
4. 支付模块 (src/payment/)

## 重要文件
- src/app.js - 应用主入口
- src/config/database.js - 数据库配置
- src/middleware/auth.js - 认证中间件
```

## 并行搜索技术

### 多代理并行搜索

并行搜索是处理大型项目的关键技术，可以显著提高搜索效率。

```bash
# 使用多个子代理并行搜索不同目录
claude-code "使用5个子代理并行搜索以下目录中的相关代码：
- src/components/
- src/services/
- src/utils/
- src/api/
- src/middleware/

每个代理专注于一个目录，查找与用户认证相关的代码"
```

#### 并行搜索配置示例
```bash
# 按功能模块并行搜索
claude-code "创建4个并行搜索任务：
任务1：搜索用户认证相关代码 (src/auth/, src/middleware/auth.js)
任务2：搜索数据库操作代码 (src/models/, src/database/)
任务3：搜索API路由代码 (src/routes/, src/api/)
任务4：搜索前端组件代码 (src/components/)

汇总所有搜索结果，提供完整的代码位置和功能说明"
```

### 任务分解策略

```bash
# 分解复杂搜索任务
claude-code "将这个搜索任务分解：
1. 查找所有数据库模型定义
2. 找到所有API路由
3. 识别所有中间件
4. 搜索测试文件
5. 查找配置文件

每个任务由独立的代理处理，最后汇总结果"
```

#### 任务分解模板
```bash
# 功能导向的任务分解
claude-code "为'订单处理功能'创建完整的代码地图：
任务1：搜索订单模型和数据库相关代码
任务2：查找订单API端点和路由
任务3：识别订单状态管理代码
任务4：搜索订单相关的工具函数
任务5：查找订单处理的测试文件

提供每个文件的路径、主要功能和与其他模块的关联"
```

## 语义搜索增强

### MCP服务器集成

集成语义搜索MCP服务器可以大幅提升在大项目中查找相关代码的能力。

#### 安装和配置
```bash
# 安装语义搜索MCP服务器
git clone https://github.com/zilliztech/claude-context
cd claude-context
npm install

# 配置MCP服务器
claude-code --mcp ./claude-context/dist/index.js
```

#### 自定义MCP服务器配置
```json
{
  "mcpServers": {
    "code-search": {
      "command": "node",
      "args": ["./claude-context/dist/index.js"],
      "env": {
        "CODE_SEARCH_PATH": "./src",
        "INDEX_FILE": "./code-index.json"
      }
    }
  }
}
```

### 向量搜索功能

```bash
# 使用语义搜索查找相关代码
claude-code "使用语义搜索找到所有与'用户认证'相关的代码文件"

# 基于功能描述搜索
claude-code "搜索实现'购物车功能'的所有相关文件和代码"

# 概念相关性搜索
```
