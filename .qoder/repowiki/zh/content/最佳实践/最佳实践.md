## 上下文优化技巧
### 如何编写能被有效压缩的提示词
编写高效的提示词是确保上下文管理成功的关键。根据`上下文工程管理实践-第4部分-最佳实践.md`中的建议，提示词应遵循以下原则：

1. **明确性**：确保提示词清晰地表达用户的需求和意图，避免模糊或含糊不清的描述。
2. **结构化**：使用结构化的格式来组织提示词，例如分点列出需求、目标和约束条件。
3. **优先级标记**：在提示词中明确指出哪些任务是高优先级的，以便系统能够优先处理。

例如，在电商网站开发项目中，可以这样编写提示词：
```
- 高优先级：
  1. 当前工作和下一步（最关键）
  2. 用户的明确请求和反馈
  3. 关键决策和架构选择
- 中优先级：
  4. 代码片段和文件修改
  5. 错误解决和问题排查
  6. 工具使用及其结果
- 低优先级：
  7. 背景信息和初始设置
  8. 一般性讨论和探索
```

### 管理大型项目的上下文以避免性能下降
管理大型项目的上下文需要采用多层次的策略。根据`07-context-compaction.md`中的描述，系统实现了智能的上下文管理和压缩策略，包括：

1. **自动压缩触发**：当上下文超过模型限制时自动触发压缩。
2. **智能摘要生成**：使用AI生成会话摘要，保留重要上下文。
3. **增量压缩**：只压缩必要的部分，保持对话连续性。

具体实现如下：
```typescript
// packages/opencode/src/session/compaction.ts
export function isOverflow(input: { 
  tokens: MessageV2.Assistant["tokens"]; 
  model: ModelsDev.Model 
}) {
  if (Flag.OPENCODE_DISABLE_AUTOCOMPACT) return false
  const context = input.model.limit.context
  if (context === 0) return false
  const count = input.tokens.input + input.tokens.cache.read + input.tokens.output
  const output = Math.min(input.model.limit.output, SessionPrompt.OUTPUT_TOKEN_MAX) || SessionPrompt.OUTPUT_TOKEN_MAX
  const usable = context - output
  return count > usable
}
```
