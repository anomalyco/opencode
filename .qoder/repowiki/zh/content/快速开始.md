## 简介
OpenCode 是一个为终端设计的 AI 编程代理工具，支持多种前端界面（CLI、桌面应用、Web 界面），并兼容多种 LLM 提供商（如 Anthropic、OpenAI、Google 等）。本指南将帮助新用户在本地环境中快速安装和运行 OpenCode，无论您使用的是 Bun、Node.js 还是 Docker。

## 安装选项
OpenCode 提供了多种安装方式，适用于不同操作系统和包管理器。

### 使用安装脚本（推荐）
```bash
curl -fsSL https://opencode.ai/install | bash
```

### 使用包管理器
```bash
# npm / bun / pnpm / yarn
npm i -g opencode-ai@latest

# macOS 和 Linux（Homebrew）
brew install sst/tap/opencode

# Arch Linux（AUR）
paru -S opencode-bin
```

### 自定义安装路径
安装脚本支持通过环境变量指定安装目录，优先级如下：
1. `$OPENCODE_INSTALL_DIR` - 自定义安装目录
2. `$XDG_BIN_DIR` - 符合 XDG Base Directory 规范的路径
3. `$HOME/bin` - 标准用户二进制目录（如果存在或可创建）
4. `$HOME/.opencode/bin` - 默认备选路径

示例：
```bash
OPENCODE_INSTALL_DIR=/usr/local/bin curl -fsSL https://opencode.ai/install | bash
```

## 依赖安装与环境配置
### 开发环境依赖
要本地运行 OpenCode，需要以下依赖：
- **Bun**（推荐）
- **Golang 1.24.x**

### 安装项目依赖
进入项目根目录后，执行以下命令安装依赖：

```bash
bun install
```

该命令会根据 `package.json` 文件安装所有必要的依赖项。

### 构建与启动开发服务器
```bash
bun dev
```

此命令将启动 OpenCode 的开发服务器，自动监听代码变更并重新加载。

## 启动命令与访问方式
OpenCode 支持三种主要界面：CLI、桌面应用和 Web 界面。

### CLI（命令行界面）
CLI 是 OpenCode 的核心入口，安装后可直接使用 `opencode` 命令：

```bash
opencode
```

### 桌面应用
进入 `packages/desktop` 目录并启动开发服务器：

```bash
cd packages/desktop
npm install
npm run dev
```

访问地址：[http://localhost:3000](http://localhost:3000)

### Web 界面
进入 `packages/web` 目录并启动开发服务器：

```bash
cd packages/web
npm install
npm run dev
```

访问地址：[http://localhost:4321](http://localhost:4321)

## 配置文件说明
OpenCode 使用 `opencode.json` 作为主配置文件，位于项目根目录。

### 基本结构
```json
{
  "$schema": "https://opencode.ai/config.json"
}
```

### 关键设置
- **`$schema`**：指向配置文件的 JSON Schema，用于编辑器自动补全和验证。
- 可扩展字段：可根据需要添加模型提供商配置、快捷方式、工具集成等。

该配置文件支持自动补全和类型检查，建议使用支持 JSON Schema 的编辑器（如 VS Code）进行编辑。

## 常见问题排查
### 端口冲突
当 Web 或桌面应用启动时出现端口占用错误：

**解决方案**：
- 更改默认端口：
  - Web 界面：修改 `astro.config.mjs` 中的 `server.port`
  - 桌面应用：修改 `vite.config.ts` 中的 `server.port`
- 使用命令行参数指定端口：
  ```bash
  npm run dev -- --port 5000
  ```

### 依赖安装失败
**问题**：`bun install` 或 `npm install` 失败

**解决方案**：
1. 确保网络连接正常，必要时配置代理
2. 清除缓存后重试：
   ```bash
   bun install --clean-cache
   ```
3. 检查 Bun 版本是否兼容：
   ```bash
   bun --version
   ```

### 权限问题
**问题**：安装脚本无法写入目标目录

**解决方案**：
- 使用 `sudo`（不推荐）
- 或设置自定义安装目录：
  ```bash
  OPENCODE_INSTALL_DIR=$HOME/.local/bin curl -fsSL https://opencode.ai/install | bash
  ```

### 环境变量未生效
确保安装目录已添加到 `PATH` 环境变量中：
```bash
export PATH="$HOME/.local/bin:$PATH"
```
