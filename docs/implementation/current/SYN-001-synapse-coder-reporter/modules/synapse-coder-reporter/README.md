# Module: synapse-coder-reporter

**Parent:** [SYN-001-synapse-coder-reporter](../../README.md)
**Type:** opencode v1 plugin
**Status:** Planning

A v1 opencode plugin that detects code corrections during opencode sessions (LSP diagnostics after edits, permission rejections with feedback) and reports them to Synapse Coder's `coder_report_correction` learning loop.

See the parent [requirements](../../requirements.md), [technical design](../../technical-design.md), [acceptance criteria](../../acceptance-criteria.md), and [checklist](../../checklist.md) for full details.
