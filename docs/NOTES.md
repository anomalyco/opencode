# ئەسكەرتىشلەر

## 2026-11-15

- ئۇيغۇرچە: ئامبار ئوچۇق كودلۇق OpenCode فورك نۇسخىسى، شۇڭا MIT لىتسېنزىيە ئەسكەرتىشى ساقلىنىشى كېرەك.
- ئۇيغۇرچە: ئىچكى پاكېت نامى `@opencode/*` نى ئالماشتۇرۇش بەك خەتەرلىك (ئىمپورتلار بۇزۇلىدۇ)، شۇڭا پەقەت ئىشلەتكۈچىگە كۆرۈنىدىغان نامغا تېگىمىز.
- ئۇيغۇرچە: ئەسلى `README.md` نىڭ ئېنگلىزچىسى `README.en.md` دا.
- ئۇيغۇرچە: ئاپتوماتىك يېڭىلاشنى سۈكۈتتە تاقاش سەۋەبى: ئۇ `opencode.ai` غا نۇسخا ئۇچۇرى يوللايتتى ھەم فوركنى ئەسلى OpenCode بىلەن ئالماشتۇرۇشى مۇمكىن ئىدى.
- ئۇيغۇرچە: `bun` بۇ كومپيۇتېردا ئورنىتىلمىغان، شۇڭا ھېچقانداق typecheck ياكى سىناق ئىجرا قىلىنمىدى.

## خىتاي تەمىنلىگۈچىلىرىنى چەكلەش (2026-11-15)

- ئۇيغۇرچە: Muhlis (beatapi) تاللىشى ئېلىۋېتىلدى، چۈنكى beatapi كۆپ ھېسابات ئىشلىتىشنى «abuse» دەپ ھېساباتنى توسىۋەتتى ھەمدە GLM / DeepSeek / Hunyuan خىتاي مودېللىرى ئىدى. `~/.muhliscode/keys.json` ئۆچۈرۈلدى.
- ئۇيغۇرچە: ئامباردىكى `policies` (`provider.use` = deny) ئارقىلىق خىتاي تەمىنلىگۈچىلىرى ۋە `opencode` ھەقسىز تىزىملىكى چەكلەندى.
- ئۇيغۇرچە: خىتاي تەمىنلىگۈچى كودلىرىنى `packages/ai` تىن ئۆچۈرۈش ئايرىم چوڭ ئىش، تېخى قىلىنمىدى.
