## 引言

欢迎使用 **DeskFox**(以下简称"本软件")。本软件是一款**个人开发的开源桌面工具**,由个人开发者**笑南**独立维护,帮你在本地电脑上读文件、写文件、和各类 AI 模型对话。本协议告诉你**我们如何处理你的数据**,以及你拥有哪些权利。

> **本软件性质说明**:本软件由笑南作为**个人开发者**以业余时间开发并免费开源,不构成商业服务,不存在企业级 SLA 承诺。请你在使用前充分理解本软件的"个人开源"性质 — 这意味着维护节奏、bug 响应速度、功能迭代均**不可预期**,你应当评估这一点是否适合你的使用场景(尤其商业场景)。详见第八节免责声明。

### 为什么你可以信任这份协议

本软件**完全开源**,源码托管在两个公开仓库:
- GitHub:https://github.com/yuesoue/opencode-for-office-deskfox
- Gitee:https://gitee.com/zoulukuang/opencode-for-office-deskfox

**你可以亲自审计**本软件的所有代码,验证我们在协议里说的话是否属实 — 无论是收什么数据、不收什么数据,还是数据怎么发出去。这是比任何法律承诺都更强的隐私担保。

本软件遵循 [**MIT 开源协议**](../../LICENSE)(与上游 [sst/opencode](https://github.com/sst/opencode) 一致),你可以自由使用、修改、分发,但需保留版权与许可证文本。

### 我们的核心承诺

**笑南 不会读取或存储你的聊天内容、文件内容、API key**。我们最多收集的是**匿名的总体用量统计**和**更新检查所需的最少信息**(如软件版本、平台),且**全部可在设置中关闭**。

本协议适用于你下载、安装、使用 DeskFox 桌面应用的全过程。

## 一、整体数据流(请先理解架构)

```
你的电脑                              
┌────────────────┐    
│  DeskFox.exe   │ ──┬─→ 你选的 AI 模型方(Claude / GPT / GetBot / ...)
│  (本地运行)   │   │  传:聊天文本、加入上下文的文件内容、API 请求
│                │   │  ※ 笑南 不在中间,看不到
│  本地文件      │   │
│  聊天历史      │   ├─→ 笑南 使用统计端点(自未来版本 v[待定] 起)
│  API key       │   │  传:匿名设备 UUID + 软件版本 + OS + 国家地区
│  配置          │   │  ※ 不含聊天 / 文件 / API key 任何内容
│                │   │  ※ 设置里一键关闭(详见第四节)
│                │   │
│                │   └─→ 笑南 更新检查端点(自未来版本 v[待定] 起)
│                │      传:当前软件版本 + 平台
│                │      ※ 仅查询是否有新版本,不静默下载,不静默安装
│                │      ※ 设置里一键关闭(详见第四节)
└────────────────┘
```

理解四条数据通道:

| 通道 | 走向 | 谁能看到 | 你的控制 |
|---|---|---|---|
| **聊天 / 文件上下文** | 你电脑 → 你选的模型方 | 模型方(由模型方隐私政策约束),**笑南 看不到** | 不接入模型 = 完全不发 |
| **本地数据** | 留你电脑 | 只有能登录你电脑账号的人(包括你) | 卸载 + 删除本地目录 = 完全清除 |
| **使用统计**(未来版本) | 你电脑 → 笑南 统计端点 | 笑南,**仅聚合层级**,不识别个人 | 设置一键关闭 |
| **更新检查**(未来版本) | 你电脑 → 笑南 更新端点 | 笑南,**仅版本号 + 平台** | 设置一键关闭 |

## 二、我们如何处理你的数据

### 2.1 留在你电脑上的(我们看不到)

| 数据类型 | 存储位置 | 是否离开你电脑 |
|---|---|---|
| 你打开 / 编辑的文件 | 你电脑的原路径 | ❌ 不离开(除非你"加聊天"主动发给模型) |
| 聊天历史 | DeskFox 用户配置目录(本地数据库) | ❌ 不离开 |
| 模型 API key | 本地配置文件 | ❌ 不离开(发请求时直接打到模型方,不过任何中转) |
| DeskFox 偏好设置 | 本地配置文件 | ❌ 不离开 |
| 文件树状态 / 最近打开 | 本地配置文件 | ❌ 不离开 |

### 2.2 发给第三方模型方的(由你的选择决定)

当你**主动**做以下操作时,数据会从你电脑发到你选的模型方:
- 在聊天框输入并发送消息
- 用"右键 → 加到聊天"把文件内容加入对话上下文
- 让模型 Edit / Write 你的文件(模型读 / 写文件需要先取到内容)
- 行评论 review 路径

**发给模型方的**:你的提问文本、被加入上下文的文件内容、你提供的 system prompt、agent 配置等。

**重要**:这些请求由 DeskFox 在你本机直接发起,**完全不经过 笑南 的服务器**。模型方收到什么、保留多久、怎么用,**由各模型方的隐私政策决定**(常见模型方政策见附录 A)。我们建议你在选择模型方前阅读对应的隐私政策。

### 2.3 我们**永远不会**收集的数据(无论现在或将来)

- ❌ **聊天内容**:任何与模型对话的内容,我们不收
- ❌ **文件内容 / 文件名 / 文件路径**:你打开或编辑的任何文件,我们不收
- ❌ **API key**:不收
- ❌ **细粒度行为日志**:不记录你点了什么按钮、用了哪个功能多久
- ❌ **真实 IP 地址**:仅用于推算粗略地区(国家/省级别),推算后**立即丢弃 IP**,不入库
- ❌ **能识别你身份的信息**:姓名、邮箱、手机、账号、生物特征等
- ❌ **崩溃报告含真实数据**:本机崩溃日志默认仅留本地;若未来加入崩溃上报,会单独征求你同意,且只上传脱敏堆栈
- ❌ **广告 / 监测 / 数据出售**:从来不做

## 三、与 笑南 服务器的通信

DeskFox 与 笑南 服务器的通信**仅限以下两类**,且数据范围严格受限:

### 3.1 使用统计(自未来版本 v[待定] 起)

**目的**:了解软件总体用户规模、地区分布、版本分布,用于判断维护投入和本地化优先级。

#### 收集内容

| 数据点 | 例子 | 用途 |
|---|---|---|
| 匿名设备 UUID | `b4c7e2a1-...`(本机生成的随机 ID,首次启动产生) | 区分独立设备数,**无法关联到你的真实身份**(我们没有任何映射表把 UUID 还原到人) |
| 软件版本号 | `2026.4.29.2` | 版本分布统计 |
| 操作系统大类 | `Windows` / `macOS` | OS 分布统计(不收具体小版本) |
| 国家 / 地区 | `CN-华东` / `US-CA` 之类粗粒度 | 由请求 IP 推算后**立即丢弃 IP**,只留地区码 |
| 心跳事件 | "首次启动" / "今日活跃" | 用户量统计 |

#### 频率
首次启动发送一次,之后**每日 1 次心跳**(同一天多次启动只算 1 次)。

#### 默认开关
**默认开启,但首次启动弹窗告知**,你可以:
- 在弹窗直接选"不发送统计"→ 永久关闭
- 之后随时通过 `设置 → 隐私 → 使用统计` 一键开关
(此项 笑南 可改为"默认关闭 + 用户主动开启",详见文末待办清单)

#### 存储与保留

| 数据形态 | 保留期 | 存储位置 |
|---|---|---|
| 原始心跳记录 | 30 天后销毁 | [待 笑南 收口:中国境内 / 海外] |
| 聚合统计(日活、月活、地区分布) | 12 个月 | 同上 |
| 聚合后的趋势图 | 永久 | 同上 |

### 3.2 更新检查(自未来版本 v[待定] 起)

**目的**:告知你有新版本可用,你**自行决定**是否下载和更新。

#### 收集内容

| 数据点 | 例子 | 用途 |
|---|---|---|
| 当前软件版本号 | `2026.4.29.2` | 服务器据此判断有无更新 |
| 平台 | `windows-x64` / `macos-arm64` | 服务器返回对应平台的更新信息 |

**不收**:设备 UUID、地区、IP(IP 只用于服务器返回响应,不入库)、其它任何信息。

#### 行为边界(重要)

- ✅ 仅**查询**有无新版本
- ✅ 若有新版本,弹窗或菜单提示,**由你点击**才会跳转下载
- ❌ **不静默下载**新版本
- ❌ **不静默安装** / 不强制升级 / 不在你不知情时替换文件
- ❌ **不收集你的更新行为**(你看到提示后是否更新,我们不知道)

#### 频率
启动时检查一次(同一天多次启动最多 1 次)。

#### 默认开关
**默认开启**,可在 `设置 → 隐私 → 更新检查` 一键关闭。

#### 与上游 sst/opencode 的差异

DeskFox **已禁用上游 sst/opencode 的官方自动升级通道**(详见 [`改动日志.md`](../../改动日志.md) "禁自动升级"条目),原因是上游通道会用上游版本覆盖 DeskFox。本节的更新检查是 笑南 自有通道,**只用来通知 DeskFox 自己的版本更新**,与上游通道无关。

## 四、第三方组件与依赖

### 4.1 微软 WebView2

DeskFox 使用 WebView2 渲染界面,这是 Windows 系统组件,由微软维护。WebView2 自身的数据收集行为受**微软隐私声明**约束,我们无法干预。如有疑问,请查阅 https://learn.microsoft.com/microsoft-edge/webview2/concepts/distribution#privacy。

### 4.2 上游开源依赖

DeskFox 基于开源项目 [sst/opencode](https://github.com/sst/opencode) fork 而成(MIT 协议),并依赖一系列前端 / Rust 第三方库。这些库**作为代码运行在你本机内**,不会单独向外传输你的数据。完整依赖清单见源码 `package.json` 与 `Cargo.toml`。

### 4.3 你选用的 AI 模型方

你在 DeskFox 中接入的任何模型方(Anthropic Claude / OpenAI / GetBot / Google Gemini / 自部署模型 / 其它)**各自独立处理你的请求数据**,各自有独立的隐私政策。**笑南 对模型方的数据处理行为不承担责任**,但建议你优先选择**有明确隐私政策、提供数据不留存选项**的模型方。

你随时可以做以下操作来管理你的数据:

| 你想做的 | 怎么做 |
|---|---|
| 关闭使用统计 | 设置 → 隐私 → 使用统计 → 关闭(未来版本) |
| 关闭更新检查 | 设置 → 隐私 → 更新检查 → 关闭(未来版本) |
| 删除聊天历史 | 在 DeskFox 内删除对应会话,或直接删除本地数据库文件 |
| 撤销 / 替换某模型的 API key | 在 DeskFox 设置 → 模型 中删除/编辑,或编辑本地配置文件 |
| 不再使用某模型 | 在模型选择器中切换 / 移除 |
| 完全清除所有 DeskFox 数据 | 卸载 DeskFox + 手动删除本地配置目录(具体路径见附录 B) |
| 重置匿名设备 UUID | 删除本地配置目录(附录 B)后重启,即生成新 UUID,与历史统计断开关联 |
| 完全离线使用 | 不接入任何模型方 + 关闭使用统计 + 关闭更新检查,DeskFox 退化为完全本地工具 |

## 七、安全限制(请务必阅读)

DeskFox 当前版本存在以下**已知安全限制**,请你在使用前充分知悉:

1. **installer 不带数字签名**:出于成本考虑,本软件 installer 不进行代码签名(详见 [`docs/governance/数字签名问题.md`](../governance/数字签名问题.md))。Windows / macOS 在首次运行时可能弹出"未知发布者 / 来源不明"警告。**仅当你从上述 GitHub / Gitee 官方仓库的 Release 页下载时,可以选择继续运行**。来源不明的 installer **不要运行**,可能是仿冒。
2. **本地数据未加密**:聊天历史、API key、配置文件以**本机用户可读形式**存储。任何能登录你电脑这个用户账号的人(或恶意程序)都能读取。**请保护好你的电脑账号密码**,共享电脑用户尤其注意。
3. **API key 是你的资产**:被泄露的 API key 可能被恶意调用产生费用。如果怀疑泄露,请**立刻去模型方控制台撤销** key,然后在 DeskFox 中替换新 key。

本协议可能随软件版本更新而修订。**重大修订**(例如改变数据流向、新增收集项目、改变默认开关、修改免责条款)**必须**:
- 在新版本 installer 发布说明([`docs/installer-versions.md`](../installer-versions.md))中明确标注
- 修订后的协议版本号在本文件头部更新
- 用户首次运行新版本时**强制弹窗告知并需重新确认**

非重大修订(例如错别字、链接更新、措辞优化)可直接更新本文件,不另行通知。

历次修订留痕保存在源码仓库的 git 历史中,任何人可通过 `git log docs/legal/隐私协议.md` 查看完整历史。

## 十一、适用法律

本协议的解释、执行、纠纷处理,适用 **中华人民共和国** 法律(不含港澳台地区法律)。具体涉及但不限于:
- 《中华人民共和国民法典》
- 《中华人民共和国个人信息保护法》(PIPL)
- 《中华人民共和国数据安全法》
- 《中华人民共和国网络安全法》
- 《中华人民共和国消费者权益保护法》(虽然本软件免费,但如适用)

**MIT 开源协议本身**(LICENSE 英文文本)则按其原文及国际开源社区惯例解释,不因本协议被替换或修改。

如果适用法律的某个条款使本协议某条款无效,**仅该条款无效**,其余条款继续有效。

如就本协议产生纠纷且协商不成,任一方可向**笑南所在地有管辖权的人民法院**提起诉讼。
