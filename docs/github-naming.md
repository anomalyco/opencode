# 命名约定

| 层面 | 名称 | 说明 |
|------|------|------|
| GitHub 仓库 | `xujian519/yunpat-ts` | 克隆地址、CI、Release 资产 |
| npm 根包 / 产品 | `yunpat` | [package.json](../package.json) `name` |
| 工作区包 | `@yunpat/*` | app、ui、desktop、sdk 等 |
| CLI 目录 | `packages/opencode` | 引擎包目录名暂保留，命令仍可为 `opencode` |
| 本地目录 | 任意 | 推荐 `~/projects/yunpat-ts` 与仓库一致 |

旧仓库 `xujian519/yunpat`（专利框架）与 `xujian519/opencode`（已改名为 `yunpat-ts`）是不同远程，请勿混淆 remote。
