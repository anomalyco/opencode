Installation

Get Jarvis running on your machine in minutes. Windows, macOS and Linux are supported.

System requirements

  • Windows 10 or later (64-bit)
  • macOS 12 or later (Intel & Apple Silicon)
  • Linux Ubuntu 20.04 / Debian 11 or later (x64)
  • 4 GB RAM recommended

Download

Grab the installer for your platform from the latest release:

⬇ Windows (.exe) 🖥 macOS (.dmg) 🐧 Linux (.deb)

Windows

  1. Run the .exe installer you downloaded.
  2. Allow the setup to finish and click Finish.
  3. Launch Jarvis from the Start menu.

macOS

  1. Open the .dmg file.
  2. Drag Jarvis into your Applications folder.
  3. Launch it from Launchpad. On first open you may need to right-click the app and select Open to bypass Gatekeeper.

Linux

  1. Install the .deb package: 
    sudo apt install ./jarvis_*.deb
  2. Launch Jarvis from your application menu.
Auto-updates: Jarvis checks for updates automatically and restarts to install them with one click. No manual updates needed.

First run

On first launch Jarvis will ask you to sign in. Bring your own API keys, or use the free models available inside the app.
