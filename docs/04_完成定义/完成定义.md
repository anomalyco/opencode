# 完成定义 (Definition of Done)

> 定义一个用户故事被视为"完成"的标准

---

## 代码质量标准

- [ ] 代码已提交并通过代码检查
  - Python 项目：`ruff check . && ruff format .`
  - Node.js 项目：`eslint . && prettier --write .`
  - Rust 项目：`cargo clippy && cargo fmt`
- [ ] 代码文件不超过 400 行
- [ ] 单行代码不超过 120 字符
- [ ] 无重复代码
- [ ] 所有函数有显式类型签名
- [ ] 所有函数有显式 return/pass 语句

---

## 测试标准

- [ ] 单元测试覆盖核心逻辑
- [ ] 所有测试通过
- [ ] 测试使用 `conftest.py` 管理数据库连接
- [ ] 测试环境与生产环境隔离
- [ ] 覆盖生产配置验证（禁止 mock 生产配置）

---

## 文档标准

- [ ] 相关文档已更新
- [ ] 如有架构决策，已创建 ADR
- [ ] Sprint 记录已更新

---

## 验收标准

- [ ] 用户故事验收标准全部满足
- [ ] 用户验收通过
- [ ] 功能可演示

---

## 代码自查清单

- [ ] 无 `as any`、`@ts-ignore`、`@ts-expect-error`
- [ ] 无空 catch 块
- [ ] 无硬编码路径
- [ ] 使用异步 IO（Python: `aiofiles`）
- [ ] 使用 `config.key` 直接访问配置，无安全访问
