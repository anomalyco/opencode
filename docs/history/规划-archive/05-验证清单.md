# 05 — 验证清单

## Phase 0(独立 prototype)

- [ ] CodeMirror EditorView 在 SolidJS 里 mount/unmount 不漏 DOM(Chrome DevTools Memory tab,反复 mount/unmount 100 次后 detached node 数稳定)
- [ ] `.md` 文件加载有 markdown 语法高亮
- [ ] `.ts` `.js` 文件加载有 JS 高亮
- [ ] 编辑后调 `write_text_file` 写入 → 关闭 → 重启加载,内容一致
- [ ] 大文件(5MB markdown)滚动流畅,无明显卡顿
- [ ] 中文输入法(微软 / 搜狗)候选词正常,无吞字

## Phase 1(fork 跑起来)

- [ ] `bun install` 通过(**重点验证 @pierre/diffs**)
- [ ] `bun run dev` 启动 Tauri dev,开 opencode 能登录
- [ ] 打开任意项目,能看到文件树 + AI 聊天 + 右侧 review tab,跟官方版行为一致
- [ ] `bun run tauri build` 打出 exe,装上能跑

## Phase 2-3(改完核心功能)

### 基本功能
- [ ] 打开 `.md` 文件,右侧 tab 顶部出现"编辑"按钮
- [ ] 点编辑 → CodeMirror 视图出现,内容跟之前一致,markdown 高亮正常
- [ ] 编辑态行评论叠层消失
- [ ] 改一行 → "保存"按钮变可点 + 出现 dirty 圆点
- [ ] 点保存 → 切回查看态 → 内容已变
- [ ] 关闭 opencode → 用 PowerShell `Get-Content` 看磁盘内容确实变了

### 各文件类型
- [ ] `.md` markdown 高亮
- [ ] `.ts` `.tsx` `.js` JavaScript/TypeScript 高亮
- [ ] `.json` JSON 高亮
- [ ] `.txt` 纯文本可编辑(无高亮)
- [ ] `.png` `.jpg` 图片文件 — **编辑按钮应禁用**
- [ ] 100MB+ 大文件 — **编辑按钮应禁用**(防卡死)

### 互不影响验证
- [ ] 切到"审查"tab,diff 视图仍是只读且渲染正常(确认没破坏 review 路径)
- [ ] 行评论功能在查看态仍可用
- [ ] AI 聊天区域不受影响

### 边界场景
- [ ] 编辑 dirty 状态下切到另一个 file tab → 弹未保存提示(放弃 / 保存 / 取消)
- [ ] 编辑 dirty 状态下关闭整个 tab → 弹未保存提示
- [ ] 编辑 dirty 状态下关 opencode 程序 → 弹未保存提示
- [ ] 编辑期间在外部用 PowerShell 改了同一文件 → 保存时弹 mtime 冲突提示
- [ ] 编辑期间让 AI 用 Write 工具改同一文件 → 保存时弹冲突提示
- [ ] 没有写权限的文件(只读属性)→ 保存失败有清晰错误提示,编辑内容不丢

### 性能
- [ ] 频繁切编辑 / 查看模式 10 次,内存增长 < 50MB
- [ ] 编辑大型文件(2MB)输入字符时无可感知延迟

## Phase 4(打包分发)

- [ ] 出包 size 跟官方相比无明显膨胀(>30% 算异常)
- [ ] 装在干净的 Win11 虚拟机上能跑(无开发环境)
- [ ] 签名后 SmartScreen 无红色警告
- [ ] 自动更新机制能拉到 fork 自己的 update server,不会被官方版覆盖
- [ ] 替换 / 卸载干净,不残留垃圾文件

## 跨平台(如果分发不只 Windows)

- [ ] macOS arm64 / x64 打包通过
- [ ] Linux AppImage / deb 打包通过
- [ ] 各平台文件路径分隔符处理正确(Tauri command 用 `PathBuf` 而非字符串拼接)

## 回归测试矩阵

| 操作 | 查看态 | 编辑态 |
|---|---|---|
| 加载文件 | ✓ | ✓ |
| 切 tab | ✓ | ✓(dirty 拦截) |
| 关闭 tab | ✓ | ✓(dirty 拦截) |
| 加行评论 | ✓ | ✗(隐藏) |
| 看已有评论 | ✓ | ✗(隐藏,保存后回查看态再显示) |
