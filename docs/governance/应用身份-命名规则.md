# 应用身份命名规则(macOS Bundle ID / Windows AppId)

> 应用身份在两个平台上都决定:数据目录归属 / URL Scheme handler / 系统是否识别为同一应用(决定升级是替换还是共存)。
> 改身份 = 系统视为全新应用(权限重置、数据目录易主、旧版变孤儿)。**改动须谨慎,merge 上游时勿误覆盖**。

## 设计原则(Mac / Win 共通)

1. **三档身份独立 → 同一台机器可共存安装**
   - Mac:三档全部已落地
   - Win:三档待落地(`feat/win-tri-env-appid`)

2. **prod 身份一旦发布,任何情况禁止改**
   - Mac:`ai.deskfox.app` 锁死(改了 = 系统识别成新 app,旧用户数据/权限丢)
   - Win:`{F9F6F6C5-D865-468C-BCE5-BF0ECA24A763}` 锁死(改了 = installer 视为新 app,已装用户的版本不会自动升级,会变成"装两份")

3. **base 配置不动,override 全在 fork-only 文件**
   - Mac:`tauri.conf.json` 不动(上游 contract),`packages/branding/tauri-overrides/*.json` override
   - Win:`packages/branding/installer/DeskFox.iss` 是 fork-only(本身不存在上游),用 `#ifdef` / ISCC `/D` 切档,不另立文件

4. **reverse-DNS 与域名对齐(仅 Mac)**:`ai.deskfox.app` ↔ user 持有的 `deskfox.ai` 域名。未来做 URL Scheme handler / Universal Link / OAuth callback 时,Apple 要求 `apple-app-site-association` 校验 reverse-DNS 与域名所有权一致;现在对齐 = 未来 0 迁移成本。Win 端 GUID 与 DNS 无关,无此要求。

5. **完全切断 sst/opencode 命名空间共享(Mac)**:不用 `ai.opencode.*` 前缀(那是上游)。用户即使同 Mac 装两个软件,TCC / 数据目录 / URL Scheme 完全独立。

6. **`ai.` 前缀不用 `com.`(Mac)**:符合 AI / agent 类工具命名习惯(对照 `ai.cursor.app`、上游 `ai.opencode.*` 都用此前缀)。

## 维护规则

### Mac

- **merge upstream/dev 时**:base `tauri.conf.json` 的 `identifier` 字段会回到上游(`ai.opencode.desktop.dev`),**这是预期行为,接受 theirs**;三档 override 在 `packages/branding/tauri-overrides/` 里,跟上游 0 路径冲突,自动保留
- **扩新档**(如未来加 `nightly`):新建 `packages/branding/tauri-overrides/nightly.json`,`identifier` 用 `ai.deskfox.app.nightly` 形式延续 reverse-DNS 树
- **绝不在 base `tauri.conf.json` 里改 identifier**:违反 P1 隔离,merge upstream 必冲突
- **绝不用回 `ai.opencode.*` 前缀**:那是上游命名空间,共享会出 4 类问题(详见 [`docs/features/bundle-id-debrand/3-changelog.md`](../features/bundle-id-debrand/3-changelog.md) 触发原因段)
- **改 Bundle ID 须重打安装包并通知 user 重装**:旧 ID 的 `/Applications/<App>.app` 不会自动清(macOS 按 ID 识别),TCC 权限重置一次(实测 macOS 14+ 自动放行用户目录,无干预)

### Windows

- **prod GUID `{F9F6F6C5-D865-468C-BCE5-BF0ECA24A763}` 锁死,任何情况禁止改** — 改了等于"重新发布一款新软件",已装用户的版本不会自动升级,会变成"装两份",必须先卸载旧版
- **dev / beta GUID 落地后也不应该改**(原则同上,虽然实际影响仅限开发者本地)
- **扩新档**(如未来加 `nightly`):`DeskFox.iss` 加新 `#elif AppEnv == "nightly"` 分支 + 新 GUID,同时 `pack-installer.ps1` 加 `-Env nightly` 选项
- **Inno Setup `#ifdef` 用法注意**:Inno Setup 预处理器不支持 `else if`,要用 `#elif`;或者由 ISCC `/D AppEnv=...` 命令行注入参数,在 `.iss` 内部 `#ifdef AppEnv` + `#elif AppEnv == "..."` 链式判断
