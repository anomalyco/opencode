# 版本号与发布渠道规范(3-tier 体系)

> **状态**:活规则,2026-05-21 起生效
> **适用范围**:DeskFox 安装包 / 发布物的命名、版本号、分发渠道规则
> **关联文档**:[`应用身份-命名规则.md`](./应用身份-命名规则.md)(Mac Bundle ID / Win AppId 三档身份)+ [`installer-versions.md`](../installer-versions.md)(版本号历史日志)

---

## 一、3-tier 体系总览

| Tier | 对外名 | 内部代号 | 做什么的 | 谁用 |
|---|---|---|---|---|
| **1** | **稳定版**(Stable)| `prod` | 主推的发布物,所有功能测过 | 99% 普通用户 |
| **2** | **预览版**(Preview)| `dev` | 公开但标"开发版"的发布物,新功能预览 | 主动 opt-in 早鸟用户 / 内部测试 |
| **3** | **本地测试版** | `dev`(同代号)+ `--no-bundle` | 不打包,raw exe 自测 | Claude / 开发者本机 |

> **关于 `beta` 内部代号**:Win/Mac AppId 三档独立 GUID 都已落地(详 [`应用身份-命名规则.md`](./应用身份-命名规则.md)),`beta` 作为 RC 候选发布渠道**储备**,日常不主动 ship。未来某次 prod ship 风险高时(如大重构)可启用 beta 走"候选发布"。本规范不展开 beta。

## 二、命名空间分离

**两个独立命名空间,token 不撞**:

| 命名空间 | token | 含义 |
|---|---|---|
| Git 分支 | `main` | 本仓主分支(2026-05-21 由 `dev` 重命名)|
| Git 分支 | `feat/<name>` | feat 分支(合 main 即销毁)|
| Git 分支 | `upstream/dev` | 上游 anomalyco/opencode 主分支(他们仍叫 dev)|
| Installer channel | `prod` | Tier 1 稳定版 |
| Installer channel | `beta` | RC 储备(日常不用)|
| Installer channel | `dev` | Tier 2 预览版 / Tier 3 本地测试 共用代号 |

**为什么 Tier 2 / 3 共用 `dev` 代号**:
- Tier 3 不打包(`build-deskfox.ps1 -Env dev -NoBundle` 只出 raw exe),不分配版本号
- Tier 2 才走 installer 流程(`pack-installer.ps1 -Env dev`),版本号带 `-dev` 后缀
- 同一份 raw exe build 出来后,既可以"Tier 3 直接跑"也可以"Tier 2 用 Inno Setup 包成 installer 发预览版" — 区别在**走没走 pack-installer**,不在 build 阶段

## 三、版本号规则(2026-05-21 B2 口径)

### 3.1 格式

```
YYYY.M.D.N[-env-suffix]
```

| 部分 | 含义 |
|---|---|
| `YYYY.M.D` | 年.月.日(去掉前导零,`2026.5.21` 非 `2026.05.21`)|
| `.N` | 当天第 N 个版本(N 从 1 开始)|
| `-env-suffix` | env 后缀,**仅非 prod 时加**:`-dev` / `-beta` |

**例子**:
- Tier 1 稳定版:`2026.5.21.1`、`2026.5.21.2`(无后缀)
- Tier 2 预览版:`2026.5.21.1-dev`、`2026.5.21.2-dev`
- RC 储备:`2026.5.21.1-beta`(暂未用)

### 3.2 N 序列双维度独立

**平台 × env 两维都独立计数**:

| 同一天打包顺序 | 版本号 |
|---|---|
| Windows prod 第 1 笔 | `2026.5.21.1` |
| Windows prod 第 2 笔 | `2026.5.21.2` |
| Windows dev 第 1 笔 | `2026.5.21.1-dev`(N 跟 prod 完全独立)|
| Windows dev 第 2 笔 | `2026.5.21.2-dev` |
| macOS prod 第 1 笔 | `2026.5.21.1`(平台跟 Windows 独立)|
| macOS dev 第 1 笔 | `2026.5.21.1-dev` |

**实现机制**:`bump-installer-version.ps1/sh` regex 加 env suffix 字面量 + trailing space anchor,匹配 `docs/installer-versions.md` 里同 env 历史 entry。详 [`feat: installer-version-env-suffix`](../features/installer-version-env-suffix/3-changelog.md)。

### 3.3 `VersionInfoVersion` strip 后缀

Windows installer PE header `VersionInfoVersion` 必须 `N.N.N.N` 数字格式。`AppVersion = "2026.5.21.1-dev"` 含后缀会破规则。

`DeskFox.iss` ISPP preprocessor 自动 strip:
```iss
#if Pos("-", AppVersion) > 0
  #define NumericAppVersion Copy(AppVersion, 1, Pos("-", AppVersion) - 1)
#else
  #define NumericAppVersion AppVersion
#endif

[Setup]
AppVersion={#AppVersion}                  # 人类可读:2026.5.21.1-dev
VersionInfoVersion={#NumericAppVersion}   # 数字 only:2026.5.21.1
```

user 看到的两个版本号:
- 控制面板"已安装应用" → AppVersion `2026.5.21.1-dev`
- exe 文件 properties → 文件版本 `2026.5.21.1`(数字 only)

### 3.4 installer 文件名规则(2026-05-21 起,`installer-naming-cleanup`)

`DeskFox.iss` `OutputBaseFilename` 模板用 **NumericAppVersion**(strip env suffix 的纯数字)而非 AppVersion,避免 `OutputBase` 已经标了 env 时双重 suffix 冗余。

```iss
OutputBaseFilename={#OutputBase}-{#NumericAppVersion}-setup
```

| Tier | OutputBase | NumericAppVersion | 产物文件名 |
|---|---|---|---|
| 1 prod | `DeskFox` | `2026.5.21.1` | `DeskFox-2026.5.21.1-setup.exe` |
| 2 dev | `DeskFox-Dev` | `2026.5.21.1`(strip `-dev`)| `DeskFox-Dev-2026.5.21.1-setup.exe` |
| beta 储备 | `DeskFox-Beta` | `2026.5.21.1`(strip `-beta`)| `DeskFox-Beta-2026.5.21.1-setup.exe` |
| 3 raw exe | — | — | `target/release/DeskFox.exe`(不打包,无版本号)|

env 信息只通过 **OutputBase 前缀**(`-Dev` / `-Beta`)体现,版本号本身保持纯数字。**控制面板显示的 AppVersion 仍带 env 后缀**(`2026.5.21.1-dev`),这是 user 可见的"开发版" 标识。

## 四、各 tier 详细规则

### 4.1 Tier 1 — 稳定版(prod)

| 项 | 规则 |
|---|---|
| 操作命令 | `pack-installer.ps1 -Env prod`(默认,Mac 端 `pack-installer.sh --env prod`)|
| 版本号 | 每次 ship 必 bump 到当天最新 N(无后缀)|
| Inno Setup AppId | `{F9F6F6C5-D865-468C-BCE5-BF0ECA24A763}`(锁死)|
| 安装目录 | `Program Files\DeskFox` |
| 系统显示名 | `DeskFox` |
| Output 文件名 | `DeskFox-<NumericVer>-setup.exe` / `DeskFox-<NumericVer>_aarch64.dmg`(prod NumericVer == AppVersion 即纯数字)|
| Git tag | `ship-prod-<版本>`(例 `ship-prod-2026.5.21.1`)|
| Ship 路径 | **本地 pack-installer + 手动 gh release create + 手动 mirror-asset-to-gitee**(2026-05-21 起官方流程;原 `release-deskfox.yml` workflow 已永久废止)|
| 分发去向 | GitHub Release **latest** 标 + Gitee Release(本地脚本镜像)+ 官网"下载"主按钮 |
| UI 左下角版本牌 | `DeskFox v2026.5.21.1` |

### 4.2 Tier 2 — 预览版(dev,可对外)

| 项 | 规则 |
|---|---|
| 操作命令 | `pack-installer.ps1 -Env dev`(Mac 端 `pack-installer.sh --env dev`)|
| 版本号 | 每次 ship 必 bump 到当天最新 N(`-dev` 后缀)|
| Inno Setup AppId | `{4C5D29F2-3BBB-49A2-B248-B74B716F8EA1}`(独立,跟 prod 同机共存)|
| 安装目录 | `Program Files\DeskFox Dev` |
| 系统显示名 | `DeskFox Dev` |
| Output 文件名 | `DeskFox-Dev-<NumericVer>-setup.exe`(NumericVer 是 strip 掉 `-dev` 后缀的纯数字,避免 `-Dev-...-dev-` 双重冗余)|
| Git tag | `ship-dev-<版本>`(例 `ship-dev-2026.5.21.1-dev`)|
| Ship 路径 | **本地 pack-installer + 手动 gh release create --prerelease + 手动 mirror-asset-to-gitee**(跟 Tier 1 同流程,只是 --prerelease 标 + Gitee 元数据 API 手动建)|
| 分发去向 | GitHub Release **prerelease** 标 + Gitee Release(本地脚本镜像)+ 官网"预览版"独立入口(**官网入口待补,follow-up**)|
| UI 左下角版本牌 | `DeskFox Dev v2026.5.21.1-dev` |

### 4.3 Tier 3 — 本地测试版(raw exe,**不发布**)

| 项 | 规则 |
|---|---|
| 操作命令 | `build-deskfox.ps1 -Env dev -NoBundle`(Mac 端 `build-deskfox.sh -Env dev --no-bundle`)|
| 版本号 | **不分配新版本号**,沿用 `installer-versions.json` 里上次 ship 时的值 |
| 是否 bump | ❌ 不 bump,不动 `.iss` / `installer-versions.json` / `installer-versions.md` |
| 是否 commit | ❌ git 不留痕 |
| 是否 push | ❌ 不发布 |
| Output | `packages/desktop/src-tauri/target/release/DeskFox.exe`(raw exe,不进 installer)|
| UI 左下角版本牌 | 显示上次 ship 时的版本号(用谁就是谁,无区分)|
| 谁会用 | Claude 跑测试 / 开发者本机自测 |

**重要规则**:Tier 3 build 完后**不要把** `.iss` / `installer-versions.json` 的 bump artifacts commit 进 git。如果不小心改了,git stash drop / git checkout 撤回即可。

## 五、操作 SOP

> **2026-05-21 起 ship 流程全本地化**:user 决议放弃 GitHub Actions cloud build,3 个 release workflow yml 永久废止(`release-deskfox.yml` / `release-mac-deskfox.yml` / `release-mirror-gitee-deskfox.yml`)。原因:Win runner 撞 sidecar deadlock + Gitee mirror silent fail 双坑,本地 ship 流程已实战跑顺。

### 5.1 出 Tier 1 稳定版(每次必 bump,要发布)

```powershell
# 1. 本地 pack(bump + build + ISCC pack 一条龙)
.\packages\branding\scripts\pack-installer.ps1 -Env prod    # Windows
bash packages/branding/scripts/pack-installer.sh --env prod  # Mac

# 2. 提交 bump artifacts
git add packages/branding/installer/DeskFox.iss packages/branding/installer-versions.json docs/installer-versions.md
git commit -m "chore(ship): bump prod 2026.5.21.1 — <一句话总结> [feat: <相关-feat-id>]"
git push origin main

# 3. 推 tag
git tag ship-prod-2026.5.21.1   # Mac 端用 ship-mac-prod-<版本>
git push origin ship-prod-2026.5.21.1

# 4. 创建 GitHub Release(本地手动,Tier 1 用 latest 标)
gh release create ship-prod-2026.5.21.1 \
  packages/branding/installer/Output/DeskFox-2026.5.21.1-setup.exe \
  --title "DeskFox 2026.5.21.1" \
  --notes "<release notes>"

# 5. 镜像 Gitee — 元数据 + 附件
$body = @{
  access_token = $env:GITEE_TOKEN
  tag_name = "ship-prod-2026.5.21.1"
  name = "DeskFox 2026.5.21.1"
  body = "<同 GitHub Release body>"
  target_commitish = "main"
} | ConvertTo-Json
Invoke-RestMethod -Uri "https://gitee.com/api/v5/repos/zoulukuang/deskfox/releases" -Method POST -Body $body -ContentType "application/json;charset=UTF-8"

.\packages\branding\scripts\mirror-asset-to-gitee.ps1 -Tag ship-prod-2026.5.21.1
```

### 5.2 出 Tier 2 预览版(每次必 bump,要发布)

跟 Tier 1 几乎相同,差别只在:
- `pack-installer.ps1 -Env dev`(dev env)
- `gh release create ... --prerelease`(prerelease 标)
- Gitee API body 加 `prerelease = $true`
- tag 用 `ship-dev-<版本>-dev`(含 B2 后缀)

```powershell
# 1. 本地 pack
.\packages\branding\scripts\pack-installer.ps1 -Env dev

# 2. 提交 bump + push
git add packages/branding/installer/DeskFox.iss packages/branding/installer-versions.json docs/installer-versions.md
git commit -m "chore(ship-dev): bump dev 2026.5.21.1-dev — <一句话总结> [feat: <相关-feat-id>]"
git push origin main
git tag ship-dev-2026.5.21.1-dev
git push origin ship-dev-2026.5.21.1-dev

# 3. GitHub Release(prerelease)
gh release create ship-dev-2026.5.21.1-dev \
  packages/branding/installer/Output/DeskFox-Dev-2026.5.21.1-setup.exe \
  --prerelease \
  --title "DeskFox Dev 2026.5.21.1-dev (预览版)" \
  --notes "<release notes>"

# 4. Gitee 元数据 + 附件
$body = @{
  access_token = $env:GITEE_TOKEN
  tag_name = "ship-dev-2026.5.21.1-dev"
  name = "DeskFox Dev 2026.5.21.1-dev (预览版)"
  body = "<同 GitHub Release body>"
  prerelease = $true
  target_commitish = "main"
} | ConvertTo-Json
Invoke-RestMethod -Uri "https://gitee.com/api/v5/repos/zoulukuang/deskfox/releases" -Method POST -Body $body -ContentType "application/json;charset=UTF-8"

.\packages\branding\scripts\mirror-asset-to-gitee.ps1 -Tag ship-dev-2026.5.21.1-dev
```

### 5.3 出 Tier 3 本地测试版(不 bump,不发布)

```powershell
# Windows
.\packages\branding\scripts\build-deskfox.ps1 -Env dev -NoBundle
# Mac
bash packages/branding/scripts/build-deskfox.sh -Env dev --no-bundle

# 用法:直接跑 target/release/DeskFox.exe 自测,不 commit 任何东西
# 如果 .iss / installer-versions.json 不小心被改了:git checkout 撤回
```
