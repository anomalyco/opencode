# Design Resources for Developers

Use this skill when selecting design assets, UI libraries, visual tools, templates, fonts, icons, animation libraries, or other resources for a web project.

## Process

1. Clarify the project type, framework, visual goal, licensing needs, budget, and accessibility or performance constraints.
2. Search the local `readme.md` catalog by resource category.
3. Prefer resources that match the project stack and constraints rather than recommending a large undifferentiated list.
4. Explain what each resource provides and call out license, attribution, hosting, dependency, and maintenance considerations.
5. Favor accessible, performant, and actively maintained options.
6. Verify current availability, pricing, licenses, and framework compatibility before adopting a resource.

## Reference material

The `readme.md` file is the upstream categorized catalog covering graphics, fonts, colors, icons, media, templates, CSS and JavaScript libraries, UI kits, design systems, tools, and inspiration.
