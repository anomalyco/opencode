# Professional Programming

Use this skill when the user asks for engineering learning resources, best practices, references for a technical topic, or a structured path to improve professional programming skills.

## Process

1. Clarify the topic, experience level, practical goal, and preferred format.
2. Search the local `README.md` by topic and select a small set of relevant resources.
3. Prefer foundational and primary sources, then add focused practical references.
4. Explain why each recommendation fits and distinguish opinion from established practice.
5. Turn recommendations into an actionable reading, exercise, or implementation sequence.
6. Avoid presenting the catalog as exhaustive or treating every linked resource as an endorsement.
7. Verify external links and current tooling details before relying on them.

## Reference material

The `README.md` file is the main categorized catalog. Additional Markdown files under `antipatterns/`, `cheatsheets/`, `list-of-links/`, and `training/` provide focused supporting material.
