# Command Playbook

## Standard Session

```bash
/import <book.md>
/chapters
/select <range>
/analyze
/status
/export obsidian
/check
```

## Analyze Filters

```bash
/analyze --only people
/analyze --only events
/analyze --only clues
/analyze --only foreshadows
/analyze --only threads
/analyze --only hypotheses
```

## Allowed Commands

`/import`, `/chapters`, `/select`, `/selected`, `/analyze`, `/export`, `/check`, `/graphs`, `/status`, `/help`, `/quit`
