# Build Your Own X

Use this skill when the user wants to learn how a technology works, implement a simplified version from scratch, or choose a hands-on learning path for a language, protocol, database, compiler, operating system, or other system.

## Process

1. Clarify the target technology, learning goal, preferred language, and desired depth.
2. Select the closest tutorial from the local `README.md` catalog.
3. Break the tutorial into small milestones with an executable result at each step.
4. Explain the core concepts before introducing implementation details.
5. Prefer a minimal, correct implementation over production-scale completeness.
6. Add focused tests or manual verification for each milestone.
7. Identify what the tutorial omits and point to production concerns separately.

## Reference material

The `README.md` file is the upstream catalog of build-from-scratch tutorials. Use its links to locate the relevant guide, and verify external tutorial details before relying on them.
