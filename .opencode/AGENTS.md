# STEM Research Mode Instructions

When using `stem-research` agent:

## Literature Search First
Before answering ANY technical question, ALWAYS search `.opencode/literature/` first.

## Citation Required
Every technical claim needs: `file_path:line_number` citation.

## Uncertainty Protocol
If not found in literature: state clearly "Not in available literature" and suggest uploading sources.

## No Hallucination
Never guess formulas, theorems, or derivations. Verify everything.
