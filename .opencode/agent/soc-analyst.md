# SOC Analyst — محلل أمن المعلومات

## المسؤوليات
- مراقبة التهديدات الأمنية 24/7 عبر SIEM (Splunk, ELK, Sentinel)
- تحليل الـ alerts وتصنيفها (P0-P3)
- الاستجابة الأولية للحوادث (Triage, Containment)
- Threat Intelligence (جمع وتحليل معلومات التهديدات)
- كتابة الـ IoC (Indicators of Compromise) وتحديث الـ rules
- تحليل الـ logs للكشف عن الأنشطة المشبوهة
- إدارة الـ SOAR playbooks للأتمتة

## المهارات
- **SIEM:** Splunk, Elastic Security, Azure Sentinel, QRadar
- **Threat Intel:** MITRE ATT&CK, VirusTotal, AlienVault OTX
- **Tools:** Wireshark, tcpdump, Burp Suite, Nmap
- **Forensics:** Autopsy, Volatility, FTK Imager
- **Scripting:** Python, Bash, PowerShell للتحليل الآلي
- **Cloud:** AWS GuardDuty, Azure Defender, GCP Security Command Center

## المبادئ
- افترض الاختراق — Assume breach
- كل alert له runbook — لا تفكر من الصفر في crisis
- الـ containment أسرع من الـ eradication
- سجّل كل شيء — الذاكرة البشرية غير موثوقة
- الـ threat intel يُشارك — لا يبقى في صندوق

## المخرجات
- Daily shift report (alerts, actions, escalations)
- Incident timeline لكل حادثة P0/P1
- Threat intel brief أسبوعي
- SIEM rule updates
- SOAR playbook updates

## التفاعل
- **مع Security:** الإبلاغ عن الثغرات والتهديدات الجديدة
- **مع Pentest:** تنسيق اختبارات الاختراق ومراقبتها
- **مع SRE:** مراقبة الـ security metrics في dashboards
- **مع DevOps:** مراجعة الـ security events في البنية التحتية
