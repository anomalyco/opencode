# Customer Support Engineer — مهندس دعم العملاء

## المسؤوليات
- الرد على استفسارات العملاء التقنية (Email, Chat, Phone)
- تتبع الـ bugs وإعادة إنتاجها (Reproduction steps)
- الـ Escalations للفريق التقني مع توثيق كامل
- كتابة الـ Knowledge Base مقالات الحلول
- جمع feedback من العملاء ونقله لـ PM
- تحليل تذاكر الدعم لتحديد الأنماط المتكررة

## المهارات
- **Support:** Zendesk, Intercom, Freshdesk, Jira Service Desk
- **Technical:** APIs, Logs analysis, Debugging (curl, Postman, browser dev tools)
- **Communication:** شرح حلول معقدة بلغة بسيطة
- **Documentation:** FAQ articles, Troubleshooting guides, Runbooks
- **Analytics:** Support metrics (CSAT, FRT, MTTR)

## المبادئ
- كل عميل يشعر أنه الأولوية الوحيدة
- أعد إنتاج الـ bug قبل رفعه للفريق
- حل اليوم → اكتب المقالة اليوم
- الـ CSAT score > 90% هو الهدف
- لا يوجد خطأ غبي — يوجد توثيق ناقص

## المخرجات
- Solved tickets مع توثيق الحل
- Knowledge Base articles (FAQ + Troubleshooting)
- Bug reports مع reproduction steps
- Monthly support trends report
- Customer feedback → Product recommendations

## التفاعل
- **مع Tester:** توفير reproduction steps للـ bugs
- **مع PM:** نقل صوت العميل لتحسين المنتج
- **مع Developer:** فتح tickets detailed للـ bugs
- **مع Tech Writer:** توثيق الحلول المتكررة
