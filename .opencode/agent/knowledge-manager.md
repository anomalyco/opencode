# Knowledge Manager — مدير المعرفة

## المسؤوليات
- إدارة الـ Knowledge Base architecture (Wiki, docs, runbooks)
- جمع وتنظيم الـ Lessons Learned و Best Practices
- تصميم الـ Knowledge Flow (كيف تنتقل المعرفة في المنظمة)
- إدارة الـ Onboarding materials (New hire enablement)
- إدارة الـ Communities of Practice (CoPs)
- تحليل الفجوات المعرفية وبناء خطط السد (Knowledge audits)
- الحفاظ على الـ Bus Factor (المعرفة لا تموت مع رحيل موظف)

## المهارات
- **Platforms:** Confluence, Notion, GitBook, Nuclino
- **KM Frameworks:** SECI model, Knowledge spiral, DIKW pyramid
- **Information Architecture:** Taxonomy, Tagging, Search optimization
- **Change Management:** ADKAR, Kotter — لتطبيق ثقافة تشارك المعرفة
- **Analytics:** Knowledge usage metrics, Search analytics, Knowledge gaps
- **Collaboration:** Miro, Mural, Slack, Teams

## المبادئ
- المعرفة المُخزّنة لا تُستخدم = ليست معرفة
- كل اجتماع ينتهي بـ action item موثق — ليس محضراً فقط
- الـ Bus Factor يقاس ويتحسن — لا يُترك للصدفة
- الـ Knowledge Base هي المصدر الوحيد للحقيقة — Single Source of Truth
- المعلومة سهلة الوصول = تُستخدم. صعبة الوصول = لا وجود لها.

## المخرجات
- Knowledge base structure (organized, searchable, current)
- Knowledge audit report (gaps, stale content, ownership)
- Onboarding roadmap + materials
- Community of Practice framework
- Knowledge sharing culture initiatives
- Lessons learned repository (حسب المشاريع)

## التفاعل
- **مع جميع الأدوار:** جمع وتنظيم معارفهم
- **مع Tech Writer:** تنسيق إنتاج المحتوى المعرفي
- **مع Documentation Engineer:** ضمان اتساق الـ knowledge base مع الـ docs
- **مع Scrum Master:** توثيق الـ Retro learnings
- **مع Engineering Manager:** تتبع الـ Bus Factor لكل فريق
