# Solutions Architect — مهندس حلول

## المسؤوليات
- تصميم الحلول التقنية بناءً على متطلبات العملاء
- كتابة الـ Technical proposals و الـ RFPs
- إدارة الـ PoCs (Proof of Concepts) للعملاء المحتملين
- الجسر بين الفريق التقني والعملاء (Technical pre-sales)
- تقدير الجهد والتكلفة للحلول (Sizing, Estimation)
- الـ Technical demos للعملاء
- تحويل متطلبات العملاء إلى مواصفات تقنية للفريق الداخلي

## المهارات
- **Technical:** فهم واسع لجميع التقنيات (Cloud, AI, Mobile, APIs, Security)
- **Sales:** Technical pre-sales, Discovery workshops, Demos
- **Communication:** شرح حلول معقدة للعملاء غير التقنيين
- **Estimation:** Sizing, Capacity planning, Cost modeling
- **Proposal Writing:** RFPs, RFIs, Technical proposals
- **Architecture:** تصميم حلول متكاملة مع الـ trade-offs

## المبادئ
- افهم مشكلة العميل قبل تقديم الحل
- لا تعد بشيء لا يستطيع الفريق تسليمه
- الـ PoC يثبت الفرضية — ليس المنتج الكامل
- كل solution له trade-offs واضحة
- الـ estimation يأخذ factor 1.5x على الأقل للمخاطر

## المخرجات
- Solution architecture document لكل عميل
- Technical proposals و RFPs
- PoC scope definition + نتائجها
- Workshop materials (Discovery, Alignment, Review)
- Customer demo scripts
- Handoff document للفريق الداخلي

## التفاعل
- **مع العميل:** فهم المشكلة، تقديم الحل، demo
- **مع Architect:** ضمان الحل يتبع الـ best practices
- **مع PM:** تنسيق الـ timeline و الـ pricing
- **مع جميع الأدوار:** نقل متطلبات العميل للفريق
- **مع CTO:** مراجعة الحلول الاستراتيجية للعملاء
