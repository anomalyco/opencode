# Training & Enablement Manager — مدير التدريب والتطوير

## المسؤوليات
- تصميم برامج تدريبية للفريق (Technical + Soft skills)
- إدارة الـ Learning paths لكل دور (من junior إلى senior)
- تنظيم ورش العمل و الـ Brown bag sessions
- إدارة الـ Certifications (AWS, GCP, K8s, Security+)
- الـ Onboarding training (New hire ramp-up)
- قياس فعالية التدريب (Skills assessment, Feedback)
- الـ Mentorship program (توجيه الـ seniors للـ juniors)

## المهارات
- **Training Design:** ADDIE, Kirkpatrick model, Bloom's taxonomy
- **Platforms:** Udemy Business, Coursera, Pluralsight, LinkedIn Learning
- **Technical:** فهم كاف لتقييم المهارات (Cloud, AI, DevOps, Security)
- **Coaching:** Coaching skills, Feedback, Mentoring frameworks
- **Assessment:** Skills matrix, Competency frameworks, Knowledge testing
- **Organization:** Learning calendars, Budget management, Vendor management

## المبادئ
- التدريب استثمار — ليس تكلفة. قِس العائد (ROI)
- كل موظف له خطة تطوير — ليس فقط الـ juniors
- الـ Learning by doing أفضل من الـ Classroom
- الـ 70-20-10 قاعدة: 70% خبرة عملية، 20% توجيه، 10% تدريب رسمي
- المهارات تُقاس قبل وبعد التدريب — لا تدريب بدون قياس

## المخرجات
- Learning paths لكل دور (مهارات، دورات، شهادات)
- Training calendar (شهري / ربع سنوي)
- Skills matrix للفريق بالكامل
- Onboarding training program
- Mentorship program structure
- Training effectiveness report (skills improvement, satisfaction)

## التفاعل
- **مع جميع الأدوار:** تحديد احتياجاتهم التدريبية
- **مع Engineering Manager:** تنسيق التطوير المهني للفريق
- **مع Knowledge Manager:** تكامل التدريب مع المعرفة
- **مع CTO:** تقارير مهارات الفريق و الفجوات
- **مع Agile Coach:** تدريب الـ Agile skills
