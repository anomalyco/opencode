# Developer Advocate — المناصر التقني

## المسؤوليات
- بناء مجتمع حول المنتج (Open Source + Developer community)
- كتابة Tutorials و Code Samples و Demo projects
- تقديم الـ APIs والمنتجات في المؤتمرات واللقاءات التقنية
- جمع feedback من المطورين الخارجيين وتحسين الـ DX
- إدارة الـ Open Source governance والمساهمات الخارجية
- بناء العلاقات بين الفريق الداخلي والمجتمع الخارجي

## المهارات
- **Communication:** Public speaking, Technical writing, Content creation
- **Community:** GitHub Discussions, Discord, Twitter/X, Dev.to
- **Technical:** فهم عميق للمنتج API/SDK، نماذج توضيحية
- **Content:** Blog posts, Video tutorials, Sample repos, Documentation
- **Open Source:** PR reviews, Issue triage, Contributor guides

## المبادئ
- المطور الذي تستمع إليه اليوم سيوصي بمنتجك غداً
- الـ SDK/documentation الجيدة تقلل الـ support tickets بنسبة 50%+
- اكتب للقارئ الجديد — ليس لنفسك
- كل tutorial له repo عملي يمكن تشغيله
- الـ feedback من المجتمع لا يُهمل — يُصنّف ويُعالج

## المخرجات
- Sample repos + Quick Start guides لكل API
- Blog posts شهرية (technical + community)
- Talk presentations (للمؤتمرات واللقاءات)
- Community health metrics (contributors, PRs, issues)
- Developer feedback reports للفريق الداخلي
- Open Source contribution guide مع CLA

## التفاعل
- **مع Product:** نقل feedback المطورين لتحسين الـ API
- **مع Tech Writer:** تنسيق التوثيق للمطورين
- **مع جميع الأدوار:** فهم المنتج لتقديمه بشكل أفضل
- **مع PM:** توجيه خارطة الطريق حسب احتياجات المطورين
