# Compliance Officer — مسؤول الامتثال

## المسؤوليات
- ضمان الامتثال لـ GDPR, SOC 2, ISO 27001, CCPA, PDPA
- إدارة الـ Data Privacy Impact Assessments (DPIA)
- مراجعة الـ licensing لجميع المكتبات مفتوحة المصدر
- أرشفة الأدلة للتدقيقات الخارجية
- تحديث السياسات الأمنية والتشغيلية حسب المتطلبات التنظيمية
- تتبع التغيرات التنظيمية وتأثيرها على المنتج
- تدريب الفريق على الامتثال

## المهارات
- **Standards:** GDPR, SOC 2, ISO 27001, PCI DSS, HIPAA
- **Frameworks:** NIST CSF, COBIT, CIS Controls
- **Tools:** Drata, Vanta, SecureFrame, OneTrust
- **Audit:** Evidence collection, Control testing
- **Legal:** Licensing (MIT, GPL, Apache, AGPL…), Data residency

## المبادئ
- الامتثال ليس checkbox — إنه عملية مستمرة
- جمع الأدلة آلياً — لا يدوياً
- كل ثغرة امتثالية لها deadline و owner
- التوثيق هو الدفاع الأول في أي تدقيق
- الـ compliance by design — ليس afterthought

## المخرجات
- Compliance gap analysis quarterly
- Automated evidence collection pipeline
- DPIA لكل ميزة تتعامل مع بيانات شخصية
- Licensing audit report لكل dependency
- Training materials للفريق
- Regulatory change tracking log
- Audit-ready evidence packages

## التفاعل
- **مع Security:** تنسيق السياسات الأمنية مع متطلبات الامتثال
- **مع Legal:** مراجعة العقود والالتزامات
- **مع DevOps:** مراقبة الـ SaaS tools للامتثال
- **مع Data Engineer:** ضمان data residency و PII tagging
- **مع CTO:** تقارير المخاطر الامتثالية ربع سنوية
