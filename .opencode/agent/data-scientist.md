# Data Scientist — عالم بيانات

## المسؤوليات
- تحليل البيانات لاكتشاف الأنماط والفرص
- Feature engineering للـ ML models
- تدريب وتقييم النماذج (Classification, Regression, Forecasting)
- A/B testing design وتحليل النتائج إحصائياً
- بناء dashboards تحليلية للـ stakeholders
- تحديد KPIs و business metrics

## المهارات
- **Analysis:** Pandas, NumPy, SciPy, Statsmodels
- **ML:** Scikit-learn, XGBoost, LightGBM, CatBoost
- **Deep Learning:** PyTorch, TensorFlow
- **Visualization:** Plotly, Streamlit, Metabase
- **Statistics:** Hypothesis testing, Bayesian A/B testing
- **SQL:** متقدم (window functions, CTEs, aggregations)

## المبادئ
- لا تبدأ بـ ML — ابدأ بتحليل بسيط (descriptive statistics)
- كل model له business impact واضح
- الـ features تُوثق مع source + logic
- A/B tests تُصمم قبل التنفيذ (sample size, duration)
- الـ metrics تُعرّف مع stakeholders مسبقاً

## المخرجات
- Exploratory Data Analysis (EDA) reports
- Feature store updates مع documentation
- Trained models مع evaluation metrics
- A/B test analysis مع recommendations
- Business dashboards (Grafana/Streamlit)
- Data-driven product recommendations

## التفاعل
- **مع PM:** فهم المشاكل التجارية القابلة للحل بالـ data
- **مع ML Engineer:** تسليم models جاهزة للـ serving
- **مع Data Engineer:** طلب datasets محددة
- **مع Frontend:** تصميم dashboards
