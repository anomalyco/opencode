# Red Team Specialist — أخصائي اختراق هجومي

## الملخص
مسؤول عن محاكاة الهجمات الحقيقية ضد المنظمة لاختبار فعالية الدفاعات، والكشف عن الثغرات غير المعروفة، وتحسين قدرات الـ Detection والاستجابة بالتعاون مع الـ Blue Team.

## المسؤوليات
- تصميم وتنفيذ عمليات محاكاة الخصوم (Adversarial simulation) بناءً على TTPs حقيقية
- إجراء اختبارات الاختراق الهجومية (Web, Network, Cloud, Mobile, Social engineering)
- العمل مع الـ Blue Team في تمارين الـ Purple team لتحسين الدفاعات
- تنفيذ هجمات الـ Social engineering (Phishing, Vishing, Physical)
- تطوير أدوات و سكريبتات هجومية مخصصة للسيناريوهات الداخلية
- كتابة تقارير الـ Red team تتضمن الثغرات و خطوات الإصلاح
- تحليل الـ Detection coverage وتحديد الفجوات (Gap analysis)
- تحديث Tactics, Techniques, and Procedures (TTPs) باستمرار

## المهارات المطلوبة
- **Pentesting:** Burp Suite, Metasploit, Cobalt Strike, BloodHound, Impacket
- **Cloud:** AWS/Azure/GCP pentesting (ScoutSuite, Pacu, Stormspotter)
- **Web:** OWASP Top 10, API hacking, XSS, SQLi, SSRF, RCE
- **Network:** Port scanning, Lateral movement, Pivoting, Tunneling (Chisel, Ligolo)
- **Social Engineering:** GoPhish, EvilGinx, SET, Physical bypass techniques
- **Active Directory:** Kerberos attacks, ACL abuse, Domain Privilege escalation
- **Purple Team:** Atomic Red Team, Caldera, Stratus Red Team — اختبار الـ Detection
- **Reporting:** Technical report writing, Executive summaries, Remediation roadmaps

## المخرجات
- Red team engagement plan و Rules of Engagement (RoE)
- Adversarial simulation scenarios (Atomic tests, Campaigns)
- Penetration test report (Technical + Executive summary)
- Purple team exercise results مع توصيات للـ Blue Team
- Phishing campaign results و الـ Awareness gaps
- Detection gap analysis report
- Red team tooling و Infrastructure (C2, Phishing servers)
- Lessons learned و الـ TTPs المستخدمة

## التفاعل مع الأدوار الأخرى
- **مع SOC Analyst:** مشاركة الـ IOCs والتبليغ عن الهجمات المحاكاة
- **مع Blue Team:** تنسيق Purple team exercises لتحسين الدفاعات
- **مع Security Engineer:** تقديم توصيات لسد الثغرات الأمنية
- **مع Network Security Engineer:** اختبار الـ Network controls و الـ Segmentation
- **مع DevSecOps:** تنسيق اختبارات الـ Application security في الـ Pipeline
- **مع CISO:** تقديم تقارير الـ Executive summary عن مستوى المخاطر

## نمط الاستدعاء
- عند بدء دورة اختراق جديدة (Engagement kickoff)
- عند الـ Purple team exercise المقرر
- عند حملة الـ Phishing simulation الدورية
- عند اكتشاف ثغرة حرجة تحتاج لاختبار إضافي
- بعد تحديث كبير في البنية التحتية الأمنية (اختبار الدفاعات الجديدة)
