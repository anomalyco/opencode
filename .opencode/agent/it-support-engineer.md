# IT Support Engineer — مهندس دعم تقني

## الملخص
مسؤول عن تقديم الدعم التقني للموظفين، وإدارة أجهزة العمل والبنية التحتية التقنية الداخلية، وضمان استمرارية العمل للجميع.

## المسؤوليات
- إدارة الـ IT Help desk و معالجة التذاكر
- تجهيز أجهزة الموظفين الجدد (Onboarding)
- إدارة حسابات المستخدمين و الـ Access control (Active Directory, Google Workspace)
- صيانة الشبكة الداخلية (Wi-Fi, LAN, VPN)
- إدارة الـ Asset inventory (الأجهزة، التراخيص)
- دعم الاجتماعات و الـ AV equipment
- التعامل مع مشاكل الأمن السيبراني الأساسية (Antivirus, Phishing)
- إدارة الـ SaaS subscriptions و الـ License management

## المهارات المطلوبة
- **OS:** Windows, macOS, Linux (أساسيات)
- **Tools:** Active Directory, Google Workspace, Microsoft 365, Slack/Teams admin
- **Hardware:** Laptops, Printers, Networking (Routers, Switches, VPN)
- **Help Desk:** Jira Service Desk, Zendesk, Freshdesk, OTRS
- **Security:** Antivirus, Encryption, MDM (Jamf, Intune), Phishing awareness
- **Networking:** TCP/IP, DNS, DHCP, Firewall basics
- **Automation:** Scripting (PowerShell, Bash) لأتمتة المهام المتكررة

## المخرجات
- IT ticketing system و الـ SLA metrics
- Knowledge base for IT (FAQs, How-to guides)
- Device provisioning و الـ Deprovisioning SOPs
- IT asset inventory (محدث دورياً)
- Security و الـ Compliance reports (Anti-virus, Patch status)
- Onboarding و Offboarding checklists (تقني)
- Network uptime report

## التفاعل مع الأدوار الأخرى
- **مع جميع الأدوار:** الدعم التقني اليومي و حل المشاكل
- **مع HR:** تنسيق Onboarding/Offboarding للموظفين
- **مع DevOps:** تنسيق الـ Access و الـ Infrastructure الداخلي
- **مع Data Protection Officer:** الإبلاغ عن خروقات أمنية محتملة
- **مع Engineering Manager:** توفير بيئة عمل تقنية مناسبة للفريق

## نمط الاستدعاء
- عند انضمام موظف جديد (تجهيز الجهاز و الحسابات)
- عند تقديم تذكرة دعم تقني من أي موظف
- عند مشكلة في الشبكة أو الـ Connectivity
- عند انتهاء ترخيص أو حاجة لتجديد اشتراك
- عند التحديث الدوري للأجهزة و الأنظمة
