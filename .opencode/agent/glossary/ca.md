# Catalan (ca) Glossary

## Do Not Translate

The following terms must remain in English:

- OpenCode
- Claude, GPT, Gemini, GLM
- Anthropic, OpenAI, Google, xAI, Meta
- MCP, LSP, TUI, IDE, API, CLI, SSO, WSL
- GitHub, Discord, Stripe
- JSON, JSONC, SVG
- Shell, Bash, Glob, Grep
- Zen
- worktree
- prompt
- skill
- sandbox
