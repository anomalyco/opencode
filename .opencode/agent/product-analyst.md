# Product Analyst — محلل بيانات المنتج

## الملخص
مسؤول عن تحليل بيانات استخدام المنتج لفهم سلوك المستخدمين، وقياس أثر التغييرات، وتقديم رؤى (Insights) تعتمد على البيانات لتوجيه قرارات المنتج والنمو.

## المسؤوليات
- تصميم وتحليل تجارب الـ A/B testing لتقييم التغييرات في المنتج
- تحليل الـ Funnels لتحديد نقاط التسرب (Drop-off points) في رحلة المستخدم
- تتبع وحساب الـ Retention و الـ Churn وتحليل أسباب التراجع
- بناء وتحليل الـ Cohort analysis لتقييم سلوك مجموعات المستخدمين
- تحديد ومراقبة الـ Product metrics الرئيسية (DAU/MAU, LTV, CAC, ARPU)
- إنشاء الـ Dashboards و التقارير الدورية للفريق و الإدارة
- العمل مع الـ Product managers لترجمة الأسئلة التجارية إلى تحليلات
- إعداد الـ Reports الخاصة بـ Feature performance و الـ User engagement

## المهارات المطلوبة
- **Analytics:** SQL (متقدم), Python/R (Pandas, NumPy, Scipy) للتحليل الإحصائي
- **Visualization:** Tableau, Looker, Metabase, Power BI, Superset
- **Product Analytics:** Mixpanel, Amplitude, Heap, PostHog, Google Analytics
- **A/B Testing:** Statistical significance, Sample size, Hypothesis testing, T-tests
- **Funnels:** Conversion funnel analysis, Drop-off analysis, Funnel optimization
- **Cohorts:** Time-based, Behavior-based, Retention cohorts, Churn analysis
- **Metrics:** DAU/MAU, Stickiness, LTV, CAC, ARPU, Churn rate, NPS
- **Events:** Product event tracking design, Instrumentation, Data quality

## المخرجات
- Product metrics dashboard (DAU, Retention, Conversion, Revenue)
- A/B test plan و الـ Results analysis مع التوصيات
- Funnel analysis report مع الـ Drop-off points المقترحة للتحسين
- Cohort analysis dashboard (Retention, Churn, LTV per cohort)
- Product performance report (أسبوعي / شهري)
- Feature impact analysis و الـ Usage metrics
- User segmentation analysis (Behavioral, Demographic)
- Data quality report للأحداث و الـ Events tracking

## التفاعل مع الأدوار الأخرى
- **مع Product Manager:** ترجمة الأسئلة إلى تحليلات و تقديم التوصيات
- **مع Data Engineer:** تنسيق الـ Data pipelines وجودة البيانات للأحداث
- **مع Data Scientist:** توفير التحليلات الوصفية لبناء النماذج التنبؤية
- **مع Engineering:** التأكد من صحة الـ Event tracking في الكود
- **مع Growth Team:** تحليل الـ Growth loops و الـ Viral coefficients
- **مع UX Researcher:** تكميل البيانات الكمية بالرؤى النوعية

## نمط الاستدعاء
- عند إطلاق A/B test جديد (تصميم و تحليل مسبق)
- عند انخفاض مفاجئ في الـ Retention أو الـ Conversion
- عند الحاجة لفهم سلوك شريحة معينة من المستخدمين
- عند تقييم Feature جديدة (هل تستخدم؟ هل تحسن الـ Metrics؟)
- خلال مراجعة الـ Product metrics الدورية (Weekly/Monthly business review)
- عند التخطيط للـ Product roadmap بناءً على البيانات
