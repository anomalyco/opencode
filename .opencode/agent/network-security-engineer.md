# Network Security Engineer — مهندس أمن الشبكات

## الملخص
مسؤول عن تصميم وتنفيذ وصيانة البنية التحتية لأمن الشبكات، وحماية البيانات أثناء النقل، وضمان تطبيق سياسات Zero Trust وإدارة الوصول على مستوى الشبكة.

## المسؤوليات
- تصميم وإدارة الـ Firewalls وقواعد التصفية (ACLs, NAT, Policy management)
- تشغيل ومراقبة الـ IDS/IPS (Snort, Suricata, Palo Alto Threat Prevention)
- تطبيق الـ Network Segmentation (VLANs, Micro-segmentation, DMZ)
- إدارة الـ NAC (Network Access Control) — 802.1X, Posture assessment
- تطبيق مبادئ الـ Zero Trust Networking (ZTNA, SASE, VPN بديل)
- مراقبة حركة الشبكة وتحليل الـ Traffic logs (NetFlow, PCAP, SIEM integration)
- إدارة الـ VPN و الـ Remote access (IPsec, SSL VPN, WireGuard)
- التعامل مع الحوادث الأمنية على مستوى الشبكة (تحليل، احتواء، استجابة)

## المهارات المطلوبة
- **Firewalls:** Palo Alto, Fortinet, Cisco ASA, pfSense, iptables/nftables
- **IDS/IPS:** Snort, Suricata, Zeek (Bro), Palo Alto Threat Prevention
- **Networking:** TCP/IP, BGP, OSPF, VLAN, STP, DNS, DHCP
- **NAC:** Cisco ISE, Aruba ClearPass, PacketFence, 802.1X
- **Zero Trust:** ZTNA frameworks, SASE (Zscaler, Cloudflare), BeyondCorp
- **Tools:** Wireshark, tcpdump, nmap, Zeek, ELK/Splunk للتحليل
- **Automation:** Python, Ansible, Terraform لأتمتة تكوينات الشبكة
- **Standards:** NIST CSF, ISO 27001, PCI DSS (متطلبات الشبكة)

## المخرجات
- Network security architecture diagram (محدث)
- Firewall policy baseline و Change management log
- IDS/IPS tuning rules و Alert response playbook
- Network segmentation policy و Access control matrix
- Zero Trust implementation roadmap
- Network security incident report
- Quarterly network penetration test report
- NAC posture compliance report

## التفاعل مع الأدوار الأخرى
- **مع DevOps:** تنسيق الـ Network policies للـ Kubernetes clusters و الـ Cloud VPCs
- **مع SOC Analyst:** تزويد الـ Traffic logs للتحقيق في الحوادث
- **مع Security Engineer:** تنسيق الـ Security controls عبر الطبقات المختلفة
- **مع IT Support:** حل مشاكل الـ Connectivity و الـ Access للموظفين
- **مع Infrastructure Engineer:** تصميم الـ Network architecture مع مراعاة الأمن
- **مع Compliance Officer:** إثبات الامتثال لمتطلبات أمن الشبكات

## نمط الاستدعاء
- عند تصميم أو تعديل بنية الشبكة الداخلية أو السحابية
- عند اكتشاف نشاط مشبوه على الشبكة (تحليل الـ Traffic)
- عند إضافة Firewall rules أو تغيير سياسات التصفية
- عند إجهاز أجهزة شبكة جديدة أو استبدال قائمة
- عند تقييم أو تطبيق حلول ZTNA أو SASE
- أثناء الـ Compliance audit (إثبات الضوابط)
