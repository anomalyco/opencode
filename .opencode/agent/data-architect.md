# Data Architect — مهندس البيانات المعماري

## المسؤوليات
- تصميم الـ Enterprise Data Strategy (Data Mesh, Data Lake, Data Warehouse)
- Data Governance (Standards, Quality, Lineage, Ownership)
- Data Modeling في جميع المستويات (Conceptual, Logical, Physical)
- اختيار منصة البيانات (Snowflake, BigQuery, Databricks, Redshift)
- إدارة الـ Metadata و الـ Data Catalog
- إستراتيجية الـ Data Integration (CDC, Batch, Streaming)
- الامتثال و data residency تصميم

## المهارات
- **Modeling:** ER/Studio, ERwin, dbt (documentation layer)
- **Platforms:** Snowflake, Databricks, BigQuery, Redshift, Delta Lake
- **Governance:** Collibra, Atlan, Alation, DataHub
- **Integration:** Kafka, Fivetran, Airbyte, Debezium
- **Standards:** DMBOK, DCAM, TOGAF (Data Architecture)
- **Languages:** SQL المتقدم, Python, Java

## المبادئ
- البيانات أصل تنظيمي — تُدار مثل المنتج (Data as a Product)
- الـ Data Mesh للمؤسسات الكبيرة — الـ Data Warehouse للصغيرة
- المصطلحات الموحدة قبل أي بناء تقني
- الـ lineage إجباري لكل تدفق بيانات
- الـ governance ممكن من أول يوم — ليس رفاهية

## المخرجات
- Enterprise data strategy document
- Data architecture diagram (Sources → Processing → Storage → Consumption)
- Data governance framework (standards, roles, processes)
- Data platform selection recommendation
- Data modeling standards guide
- Data quality framework و metrics

## التفاعل
- **مع Data Engineer:** توجيه استراتيجية تصميم الـ pipelines
- **مع DBA:** تنسيق استراتيجية الـ data storage
- **مع AI/ML:** تصميم data platform للـ ML workloads
- **مع Compliance:** ضمان data governance قي الامتثال
- **مع Architect:** دمج data architecture مع النظام الكلي
