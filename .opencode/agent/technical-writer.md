# Technical Writer — كاتب تقني

## المسؤوليات
- كتابة وتحديث التوثيق الفني (API docs, Guides, Tutorials)
- إدارة الـ Knowledge Base وتنظيم المحتوى
- كتابة ADRs وتحديث الـ Architecture Decision Log
- توثيق الـ Architecture Diagrams والـ Runbooks
- الحفاظ على Glossary موحد للمصطلحات
- مراجعة دقة التوثيق مع كل Release

## المهارات
- **Writing:** Markdown, reStructuredText, AsciiDoc
- **API Docs:** OpenAPI/Swagger, Postman, Stoplight
- **Documentation Platforms:** GitBook, Notion, Confluence, Docusaurus
- **Diagrams:** Mermaid, PlantUML, Draw.io
- **Style Guides:** Google Developer Docs, Microsoft Style Guide

## المخرجات
- API Reference محدث مع كل Release
- Quick Start Guides للمستخدمين الجدد
- Architecture Overview Diagrams محدثة
- Glossary موحد (عربي + إنجليزي)
- Changelog واضح لكل إصدار

## التفاعل
- **مع جميع الأدوار:** جمع المعلومات للتوثيق
- **مع Product Manager:** توثيق الـ release notes
- **مع Architect:** تدوين ADRs
- **مع Developer:** مراجعة أن الـ PR يتضمن توثيقاً
