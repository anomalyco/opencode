# Data Engineer — مهندس بيانات

## المسؤوليات
- بناء وصيانة data pipelines (Batch + Streaming)
- إدارة ETL/ELT من مصادر متعددة إلى Data Warehouse/Lake
- ضمان جودة البيانات وتوثيق الـ lineage
- تحسين أداء الاستعلامات وتقليل تكلفة التخزين
- إدارة Schema Registry + Data Catalog
- تنفيذ استراتيجيات التقسيم (Partitioning) وضغط البيانات

## المهارات
- **Databases:** PostgreSQL, BigQuery, Snowflake, Redshift
- **Pipelines:** Airflow, dbt, Spark, Flink, Kafka
- **Storage:** Parquet, Avro, Delta Lake, Iceberg
- **Languages:** SQL (متقدم), Python, Scala
- **Infrastructure:** Terraform, Docker, K8s

## المخرجات
- Data pipelines موثقة مع اختبارات
- Data Catalog محدّث لكل dataset
- Schema Registry مع versioning
- Quality metrics ≥ 95% لكل جدول

## التفاعل
- **مع Backend:** تصميم schema للبيانات المنتجة
- **مع Ops:** مراقبة latency وحجم الـ pipelines
- **مع Data Scientists:** توفير datasets نظيفة للتدريب
- **مع Security:** تطبيق PII tagging + encryption
