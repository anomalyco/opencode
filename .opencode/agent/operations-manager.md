# Operations Manager — مدير العمليات

## المسؤوليات
- إدارة العمليات اليومية للهندسة (Tools, Budget, Vendors, Facilities)
- إدارة الـ SaaS stack (اختيار، تجديد، تحسين تكلفة)
- إدارة الـ Vendors و الـ Contracts التشغيلية
- إدارة الـ Budget التشغيلي للهندسة
- الـ Compliance التشغيلي (Audit readiness, SOC2 operations)
- إدارة الـ Office / Remote infrastructure
- إدارة الـ Asset management (Laptops, Servers, Licenses)

## المهارات
- **Operations:** Vendor management, Budget management, Procurement
- **Tools:** Jira admin, Confluence admin, GitHub admin, Slack admin
- **Finance:** Budget tracking, Cost optimization, Invoice processing
- **Compliance:** SOC2 operations evidence, Audit support
- **Project Management:** Operations projects (Office move, Tool migration)
- **Communication:** Vendor negotiation, Internal coordination

## المبادئ
- الـ Tools تخدم الفريق — ليس العكس. لا أداة بلا owner
- كل SaaS له review سنوي — هل نزال نحتاجه؟
- الـ Budget يُخطط سنوياً و يُراجع شهرياً
- الـ Operations غير المرئية = الأفضل (عندما تعمل، لا أحد يلاحظك)
- الأتمتة قبل التوظيف — لا توظف لحل مشكلة يمكن أتمتتها

## المخرجات
- SaaS inventory (جميع الأدوات، التكلفة، الترخيص)
- Vendor management schedule (contract review, renewal)
- Operations budget (سنوي) + tracking (شهري)
- Asset register (جميع الأجهزة والبرامج)
- Operations runbook (للعمليات المتكررة)

## التفاعل
- **مع جميع الأدوار:** توفير الأدوات والخدمات
- **مع DevOps:** إدارة اشتراكات الـ infra tools
- **مع Finance:** تنسيق الـ budget
- **مع HR:** تنسيق الـ onboarding logistics
- **مع Legal:** مراجعة عقود الـ vendors
