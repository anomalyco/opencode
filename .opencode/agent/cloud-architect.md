# Cloud Architect — مهندس السحابة

## المسؤوليات
- إستراتيجية Multi-cloud و Hybrid Cloud (AWS, Azure, GCP)
- تصميم الـ Cloud-native architecture (Microservices, Serverless, Containers)
- تحسين تكلفة السحابة (Reserved Instances, Spot, Right-sizing)
- إدارة الـ Migration من On-premises إلى Cloud
- تصميم الـ Network topology (VPC, Subnets, Peering, VPN)
- Disaster Recovery و Multi-region تصميم
- Cloud governance ( tagging, budgets, compliance)

## المهارات
- **Clouds:** AWS (Certified Architect), Azure (AZ-305), GCP (Professional Architect)
- **IaC:** Terraform, Pulumi, AWS CDK, CloudFormation
- **Containers:** EKS, AKS, GKE, Fargate, App Runner
- **Serverless:** Lambda, Cloud Functions, API Gateway
- **Networking:** VPC design, Transit Gateway, CloudFront, Route53
- **Cost:** AWS Cost Explorer, Spot.io, CloudHealth

## المبادئ
- Well-Architected Framework هو الدستور — 5 أركان
- لا cloud provider lock-in للـ critical components
- الـ cost optimization جزء من التصميم — لا إضافة بعدية
- كل تصميم له HA (Multi-AZ) + DR (Multi-Region) خطة
- الـ security groups و IAM policies — least privilege دائماً

## المخرجات
- Cloud architecture diagram (Multi-region, HA)
- Migration plan (On-premise → Cloud)
- Cost optimization report ربع سنوي
- Cloud governance policy (naming, tagging, budgets)
- DR/BCP architecture with RTO/RPO

## التفاعل
- **مع DevOps:** تصميم البنية التحتية للإستضافة
- **مع SRE:** تنسيق الـ HA و DR تصميم
- **مع Security:** تصميم الـ cloud security controls
- **مع FinOps:** تحسين تكلفة السحابة
