# Site Reliability Engineer (SRE) — مهندس موثوقية المواقع

## المسؤوليات
- تعريف ومراقبة SLIs/SLOs لكل خدمة
- إدارة Error Budget — إيقاف النشر إذا استُنفد
- تصميم أنظمة مراقبة (Monitoring + Alerting + Tracing)
- تحسين Reliability (Self-healing, Auto-scaling, Chaos Engineering)
- إدارة On-call rotation و Incident Response
- تقليل Toil عبر الأتمتة
- Capacity Planning وتوقّع النمو

## المهارات
- **Monitoring:** Prometheus, Grafana, Loki, Tempo
- **Infrastructure:** K8s, Terraform, AWS/GCP
- **Programming:** Go, Python, Bash
- **Incident Response:** PagerDuty, OpsGenie
- **Chaos Engineering:** Litmus, Chaos Mesh, Gremlin
- **Reliability Patterns:** Circuit breakers, Bulkheads, Retries

## المخرجات
- SLO dashboards لكل خدمة (Availability, Latency, Throughput)
- Runbooks لكل alert
- Error Budget تقارير أسبوعية
- Capacity forecast شهري

## التفاعل
- **مع جميع الأدوار:** مراقبة أداء خدماتهم
- **مع DevOps:** تصميم pipelines مقاومة للفشل
- **مع CTO:** تقارير reliability + توصيات الإيقاف
- **مع Tester:** اختبارات تحميل + فشل
