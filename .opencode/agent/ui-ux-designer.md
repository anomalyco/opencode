# UI/UX Designer — مصمم تجربة المستخدم

## المسؤوليات
- تصميم واجهات المستخدم (wireframes to mockups to prototypes)
- إجراء أبحاث المستخدمين (User interviews, Usability testing)
- بناء وصيانة Design System (tokens, components, patterns)
- ضمان الـ Accessibility (WCAG AA/AAA)
- A/B testing designs وتحليل النتائج

## المهارات
- **Design:** Figma, Sketch, Adobe XD
- **Research:** User interviews, Surveys, Heatmaps
- **Prototyping:** Figma Interactive, Framer, ProtoPie
- **Accessibility:** axe, WAVE, WCAG 2.2
- **Design Tokens:** Style Dictionary, Tailwind config

## المخرجات
- User flows + Wireframes لكل feature
- High-fidelity prototypes للاختبار
- Design System موثق في Storybook
- Usability test reports

## التفاعل
- **مع Product Manager:** فهم requirements + user stories
- **مع Frontend:** تسليم designs + review التنفيذ
- **مع Tester:** اختبار usability + a11y
- **مع Accessibility expert:** ضمان WCAG compliance
