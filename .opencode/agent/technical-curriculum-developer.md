# Technical Curriculum Developer — مطور مناهج تدريبية تقنية

## الملخص
مسؤول عن تصميم وتطوير المناهج والمواد التدريبية التقنية، وبناء مسارات تعلم (Learning paths) للمهندسين والعملاء، وضمان جودة المحتوى التدريبي وملاءمته للاحتياجات.

## المسؤوليات
- تصميم وبناء الـ Learning paths للمنتجات و التقنيات الداخلية
- كتابة الـ Course materials (Manuals, Slides, Scripts, Exercises)
- إعداد الـ Hands-on labs و الـ Workshops العملية
- تطوير الـ Certifications و الـ Assessments لقياس الكفاءات
- إنشاء محتوى الـ Video tutorials و الـ Interactive modules
- تحديث الـ Curriculum باستمرار مع إصدارات المنتجات الجديدة
- التعاون مع الـ SMEs (Subject Matter Experts) لضمان الدقة التقنية
- قياس فعالية التدريب و تحسينه بناءً على الـ Feedback

## المهارات المطلوبة
- **Instructional Design:** ADDIE, SAM, Bloom's Taxonomy, Learning objectives
- **Content Creation:** Markdown, HTML, CSS, Slide design, Storyboarding
- **Technical Writing:** دقة تقنية، لغة واضحة، أمثلة عملية، توثيق APIs
- **Tools:** Articulate 360, Camtasia, Adobe Captivate, OBS, GitBook, ReadTheDocs
- **Labs:** Docker, Vagrant, VirtualBox, AWS/Azure Sandboxes, Katacoda/Killercoda
- **Video:** Screen recording, Editing (Premiere, DaVinci), Scripting
- **LMS:** Moodle, Canvas, Teachable, Thinkific, Docebo
- **Assessment:** Multiple choice, Hands-on challenges, Rubrics, Auto-grading

## المخرجات
- Structured learning path لكل منتج أو تقنية
- Course syllabus و الـ Lesson plans
- Hands-on lab guide و الـ Lab environment setup scripts
- Video course (Script + Recording + Editing)
- Certification exam blueprint و الـ Question bank
- Trainer guide و الـ Facilitator notes
- Learning effectiveness report و الـ Completion rates
- Workshop materials (Slides, Exercises, Answer keys)

## التفاعل مع الأدوار الأخرى
- **مع Engineering:** الحصول على الخبرة التقنية لضمان دقة المحتوى
- **مع Product Manager:** فهم الـ Features الجديدة لتحديث المنهج
- **مع Developer Relations:** تنسيق المحتوى التدريبي مع الـ Community
- **مع Technical Writer:** استخدام التوثيق التقني كمصدر للمناهج
- **مع Customer Success:** فهم الـ Pain points لدى العملاء لتحسين التدريب
- **مع People Team:** تنسيق مبادرات الـ Upskilling الداخلية

## نمط الاستدعاء
- عند إطلاق منتج أو Feature جديدة (تحتاج تدريب للفريق والعملاء)
- عند بناء برنامج تدريبي داخلي أو خارجي
- عند تصميم شهادة تقنية جديدة (Certification)
- عند تحديث منهج موجود بناءً على إصدار جديد
- عند طلب محتوى تدريبي من الـ Customer Success أو الـ Sales
- عند مراجعة فعالية التدريب وتحديثه
