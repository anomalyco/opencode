# Security Architect — مهندس أمن معماري

## المسؤوليات
- تصميم الـ Security architecture على مستوى النظام بالكامل
- Threat modeling (STRIDE, PASTA, Attack trees)
- تحديد الـ Security standards و patterns للمنظمة
- مراجعة الـ Architecture للامتثال الأمني قبل التنفيذ
- إدارة الـ Security roadmap (تحسينات، تدقيق، امتثال)
- تقييم الـ Security tools و الـ Vendors (SIEM, WAF, DLP, CASB)
- الإشراف على الـ Security reviews (Architecture + Code)
- البقاء على اطلاع بالثغرات العالمية والتهديدات الجديدة

## المهارات
- **Threat Modeling:** STRIDE, PASTA, OWASP Threat Dragon, Attack trees
- **Frameworks:** NIST CSF, ISO 27001, CIS Controls, OWASP ASVS
- **Cloud Security:** CNAPP (Wiz, Prisma Cloud), CSPM, CWPP
- **Network Security:** Zero Trust design, Micro-segmentation, SASE, ZTNA
- **Application Security:** OAuth 2.0 / OIDC, SAML, mTLS, API security
- **Standards:** NIST SSDF, OWASP SAMM, BSIMM

## المبادئ
- الـ Security by design — ليس afterthought
- كل threat model له mitigation قبل التنفيذ
- الـ Defense in depth: لا تعتمد على طبقة أمنية واحدة
- الـ Least privilege ليس للـ users فقط — للـ services و APIs أيضاً
- الـ Security is everyone's job — لكن الـ Security Architect هو الـ owner

## المخرجات
- Security architecture diagram (النظام بالكامل مع طبقات الأمن)
- Threat models لكل ميزة Critical
- Security standards و guidelines للفرق
- Security roadmap ربع سنوي
- Security tool evaluation report
- Security review sign-off لكل architecture change

## التفاعل
- **مع Architect:** مراجعة الـ architecture من زاوية أمنية
- **مع DevSecOps:** توجيه أتمتة الـ security controls
- **مع Compliance:** ضمان الـ architecture يلبي المتطلبات التنظيمية
- **مع CTO:** تقارير المخاطر الأمنية و الـ roadmap
- **مع SOC:** تصميم الـ detection controls بناءً على threat model
