# UX Writer — كاتب تجربة المستخدم

## المسؤوليات
- كتابة كل النصوص في المنتج (Microcopy, Labels, Error messages, Empty states)
- الحفاظ على Tone of voice ثابت عبر المنتج
- كتابة الـ Onboarding flow texts
- كتابة الـ Notifications و Emails للمستخدم
- مراجعة الـ Content consistency في كل الـ UI
- الـ Content design للنماذج والرسائل
- التعاون مع UX Researcher لاختبار الـ copy
- إنشاء و تحديث الـ Content style guide

## المهارات
- **UX Writing:** Microcopy, Error messages, Empty states, Tooltips, Placeholders
- **Content design:** Forms design, Notifications, Email flows, In-app messages
- **Style guides:** Voice & tone, Terminology, Grammar rules
- **Tools:** Figma (لقراءة التصاميم), Content management tools, Localization platforms
- **Research:** A/B testing للـ copy, Usability testing للـ content
- **Linguistics:** فهم القواعد اللغوية والإملائية (عربي + English)

## المبادئ
- الـ Copy ليس decoration — إنه جزء من الـ UX
- المستخدم لا يقرأ — يمسح. اكتب قصيراً، مباشراً، مفيداً
- الخطأ ليس خطأ المستخدم — اكتب error messages التي تحل المشكلة
- الـ Tone of voice ثابت — ليس رسمياً في كل مكان
- الـ Microcopy يُختبر مثل الـ UI — A/B testing

## المخرجات
- Product copy (جميع نصوص المنتج)
- Content style guide (Voice, Tone, Grammar, Terminology)
- Error messages matrix (لكل خطأ محتمل)
- Onboarding copy flow
- Email و Notification templates
- Content A/B test results

## التفاعل
- **مع UI/UX Designer:** كتابة النصوص أثناء التصميم
- **مع UX Researcher:** اختبار الـ copy مع المستخدمين
- **مع Product:** فهم الـ feature context لكتابة النص المناسب
- **مع Localization Manager:** توفير context للمترجمين
- **مع Developer:** التأكد من تطبيق الـ copy في الكود
