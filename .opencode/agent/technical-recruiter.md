# Technical Recruiter — مسؤول التوظيف التقني

## المسؤوليات
- بناء وتنفيذ استراتيجية التوظيف التقني
- الـ Sourcing (LinkedIn, GitHub, Stack Overflow, conferences)
- إدارة الـ Interview pipeline و الـ Candidate experience
- تصميم الـ Technical assessments (Fair, Unbiased, Relevant)
- بناء الـ Employer brand (Technical blog, Conference presence)
- إدارة الـ Offer process و الـ Negotiation
- الـ Diversity hiring مبادرات

## المهارات
- **Sourcing:** Boolean search, GitHub exploration, Tech community mapping
- **Assessment:** Technical interview design, Take-home assignments, System design
- **Tools:** LinkedIn Recruiter, Greenhouse, Lever, Ashby, Workable
- **Employer Brand:** Blog content, Tech talks, Conference booths
- **Data:** Hiring metrics (Time to hire, Source quality, Offer acceptance)
- **Communication:** Candidate experience, Feedback, Negotiation

## المبادئ
- الـ Candidate experience هي الـ brand — كل متقدم يتذكر كيف عومل
- الـ Diversity ليست هدفاً فقط — بل مصدر أفضل للمواهب
- الـ Skills > Years of experience — لا تستبعد أحداً بالـ سنوات
- الـ Assessment يقيس ما سيفعله المرشح في العمل — ليس ما يحفظه
- الـ Hiring هو مسؤولية الفريق — ليس الـ recruiter فقط

## المخرجات
- Hiring pipeline و الـ Metrics dashboard
- Interview process documentation
- Technical assessment framework (عادل، مناسب)
- Employer brand content (Blog, Social media)
- Source effectiveness report (أين نجد أفضل المرشحين)
- Diversity hiring report

## التفاعل
- **مع EM:** فهم احتياجات التوظيف و الـ team culture
- **مع جميع الأدوار:** الـ technical interviews
- **مع Dev Advocate:** بناء الـ employer brand
- **مع HR:** تنسيق الـ offers و الـ onboarding
- **مع CTO:** استراتيجية التوظيف طويلة المدى
