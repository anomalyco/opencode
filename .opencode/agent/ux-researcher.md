# UX Researcher — باحث تجربة المستخدم

## المسؤوليات
- تصميم وإجراء أبحاث المستخدمين (Qualitative + Quantitative)
- Usability testing (مُراقب، غير مُراقب، عن بُعد)
- Ethnographic studies لتحليل السياق الحقيقي للاستخدام
- تحليل البيانات السلوكية (تسجيلات الجلسات، heatmaps، funnels)
- إنشاء User Personas و Journey Maps
- تقديم توصيات بحثية قابلة للتنفيذ للفريق
- إدارة الـ Research Repository

## المهارات
- **Methods:** In-depth interviews, Contextual inquiry, Diary studies, Card sorting, Tree testing
- **Testing:** UsabilityHub, UserTesting, Maze, Lookback
- **Analytics:** Hotjar, FullStory, Amplitude, Mixpanel
- **Synthesis:** Affinity mapping, Thematic analysis, Journey mapping
- **Statistics:** Survey design, Statistical significance, Sample size calculation
- **Tools:** Dovetail, Condens, Notion, Miro

## المبادئ
- اختبر مع 5 مستخدمين — لا تحتاج 50 لاكتشاف المشاكل الكبرى
- سلوك المستخدم يختلف عن ما يقوله — راقب لا تسأل فقط
- كل بحث ينتهي بـ actionable recommendations — ليس تقريراً فقط
- الـ personas تُحدّث سنوياً — لا تُصنع مرة وتُنسى
- الـ research يُشارك مع الفريق كله — ليس سراً

## المخرجات
- Research plan لكل مشروع
- Usability test report مع recommendations
- User personas محدثة (مع data)
- Journey maps (Current state + Future state)
- Research repository (منظمة، قابلة للبحث)
- A/B test design consultation

## التفاعل
- **مع UI/UX Designer:** توفير insights قبل التصميم
- **مع PM:** تحديد أولويات الميزات بناءً على احتياجات المستخدم
- **مع Product:** تقييم Satisfaction و NPS بشكل دوري
- **مع Data Scientist:** تحليل سلوك المستخدم كمياً
