# Site Reliability Manager — مدير موثوقية المواقع

## المسؤوليات
- إدارة استراتيجية الـ Reliability على مستوى المنظمة
- تعريف ومراقبة الـ SLOs/SLIs لجميع الخدمات
- إدارة الـ Error Budget governance (متى نوقف النشر)
- تصميم وإدارة الـ On-call rotations
- قيادة الـ Incident Command أثناء الحوادث الكبرى
- إدارة الـ Postmortem culture و الـ follow-through
- تقارير الـ Reliability للـ CTO و الـ Stakeholders
- الموازنة بين الـ Feature velocity و الـ Reliability

## المهارات
- **SRE:** SLO/SLI/Error Budget deeply, Toil automation, Burn rate
- **Incident Management:** Incident Command, Crisis management, Communication
- **Monitoring:** Prometheus, Grafana, Datadog, PagerDuty
- **Leadership:** Team management, Blameless culture, Technical leadership
- **Metrics:** DORA metrics, SLIs definition, Reliability scorecards
- **Budgeting:** Error budget policy, Release governance, Cost of reliability

## المبادئ
- الـ Reliability مسؤولية المنتج — ليست مجرد SRE team
- كل 9 أخرى من الـ uptime تكعّب التكلفة — اختر SLO بعناية
- الـ Error budget ليس ترخيصاً للفشل — إنه أداة للقرار
- الـ On-call تُوزع بشكل عادل — لا تحرق فريقاً واحداً
- الـ Postmortem بدون action items = مجرد اجتماع

## المخرجات
- Service Level (SLOs, Error Budgets لكل خدمة)
- Reliability roadmap ربع سنوي
- On-call schedule policy (عادل، مستدام)
- Incident Command structure
- Reliability report شهري للـ CTO
- Error budget policy (متى نوقف النشر)

## التفاعل
- **مع SRE:** توجيه استراتيجي وتحسين العمليات
- **مع DevOps:** تنسيق الـ release governance مع error budget
- **مع CTO:** تقارير reliability و توصيات
- **مع TPM:** برمجة تحسينات الـ reliability
- **مع جميع الأدوار:** نشر ثقافة reliability
