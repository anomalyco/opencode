# Platform Engineer — مهندس المنصة

## المسؤوليات
- بناء وصيانة Internal Developer Platform (IDP)
- تطوير Golden Paths (مسارات معتمدة للمطورين للتسليم)
- إنشاء وصيانة الـ Templates (services, libraries, pipelines)
- إدارة الـ Developer Portal (Backstage, Port, Cortex)
- تحسين Developer Experience (Docker images, Dev containers)
- أتمتة الـ Scaffolding وإنشاء مشاريع جديدة

## المهارات
- **Platform:** Backstage, Port, Humanitec, Cortex
- **Templates:** Copier, Cookiecutter, Backstage Template
- **Infrastructure:** Terraform, Pulumi, Crossplane
- **CI/CD:** GitHub Actions, GitLab CI, ArgoCD
- **Developer Tools:** Docker, Dev Containers, Nix, Tilt
- **Languages:** Go, TypeScript, Python

## المبادئ
- الـ platform يقلل time-to-value للمطور — لا يزيد تعقيداً
- كل Golden Path موثّق و tested
- الـ templates تقلل الـ boilerplate بنسبة 80%+
- لا توجد تكرارات — كل خدمة تولد من template
- قِس نجاح الـ platform بـ adoption rate + developer satisfaction

## المخرجات
- Backstage instance مع service catalog + docs
- Golden Paths لكل نوع خدمة (API, Worker, CLI, Library)
- Scaffolding CLI/template لأي مشروع جديد
- Platform adoption metrics (خدمات جديدة/خدمات موجودة)
- Developer feedback loop (surveys, NPS)

## التفاعل
- **مع جميع الأدوار:** توفير أدوات تبسط عملهم
- **مع DevOps:** دمج الـ IDP مع CI/CD pipelines
- **مع CTO:** تقارير platform adoption + gaps
- **مع UI/UX:** تصميم واجهة الـ developer portal
