## Do Not Translate (Locale Additions)

- `OpenCode` (preserve casing in prose, docs, and UI copy)
- Keep lowercase `opencode` in commands, package names, paths, URLs, and other exact identifiers
- `<TAB>` stays the literal key token in code blocks; use `Tab` for the nearby explanatory label in prose
- Commands, flags, file paths, and code literals (keep exactly as written)

## Preferred Terms

These are wording preferences and may evolve.

| English / Context         | Preferred                                  | Notes                                                         |
| ------------------------- | ------------------------------------------ | ------------------------------------------------------------- |
| available in beta         | `beta olaraq mövcuddur`                    | Prefer this over `beta versiyası mövcuddur`                  |
| privacy-first             | `Məxfilik önə alınaraq hazırlanıb`         | Prefer this over `Əvvəlcə məxfilik üçün hazırlanıb`          |
| connect your local models | `yerli modellərinizi qoşa bilərsiniz`      | Use the fuller, more direct action phrase                     |
| `<TAB>` key label         | `Tab`                                      | Use `Tab` in prose; keep `<TAB>` in literal UI or code blocks |
| cross-platform            | `cross-platform (bütün platformlarda)`     | Keep the English term, add a short clarification when helpful |
| workspace                 | `iş sahəsi`                                | Prefer this over `işçi sahə` or `iş yeri`                    |
| provider                  | `provayder`                                | Keep the loanword for consistency with technical context       |
| billing                   | `ödəniş`                                   | Prefer this over `faktura` or `hesablaşma`                    |
| subscription              | `abunəlik`                                 | Prefer this over `üzvlük`                                     |

## Guidance

- Prefer natural Azerbaijani phrasing over literal translation
- Merge broken sentence fragments into one clear sentence when the source is a single thought
- Keep product naming consistent: `OpenCode` in prose, `opencode` only for exact technical identifiers
- When an English technical term is intentionally kept, add a short Azerbaijani clarification only if it improves readability

## Avoid

- Avoid `beta versiyası mövcuddur` when `beta olaraq mövcuddur` fits
- Avoid `Əvvəlcə məxfilik üçün hazırlanıb`; use the more natural reviewed wording instead
- Avoid changing `opencode` to `OpenCode` inside commands, URLs, package names, or code literals
- Avoid overly formal or literary Azerbaijani; prefer conversational clarity
