# sv Glossary

## Do Not Translate

- `OpenCode` (behåll versalerna; använd `opencode` endast i kommandon, paketnamn, sökvägar eller kod)
- `OpenCode CLI`
- `CLI`, `TUI`, `MCP`, `OAuth`
- Kommandon, flaggor, filsökvägar och kodliteraler (behåll exakt som de är)

## Preferred Terms

- agent → agent
- build → build (agentnamn)
- plan → plan (agentnamn)
- desktop app → desktop-app
- pull request → pull request
- session → session
- workspace → arbetsyta
- file tree → filträd

## Guidance

- Skriv naturlig, tydlig svenska i UI-etiketter och dokumentation.
- Använd imperativ i knappar och korta verbfraser där engelskan gör det.
- Behåll tekniska identifierare, platshållare, kommandon, URL:er och modellnamn exakt.
