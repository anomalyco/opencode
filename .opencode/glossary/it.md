## Do Not Translate (Locale Additions)

- `OpenCode` (preserve casing in prose; keep `opencode` only in commands, package names, paths, or code)
- `OpenCode CLI`, `OpenCode Desktop`, `OpenCode Go`, `OpenCode Zen`, `OpenCode Black`
- `CLI`, `TUI`, `MCP`, `LSP`, `OAuth`, `API`, `SSO`, `WSL`
- Commands, flags, file paths, and code literals (keep exactly as written)
- Model IDs: `Claude`, `GPT`, `Gemini`, `GLM`, `Kimi`, `MiMo`, `Qwen`, `DeepSeek`, `MiniMax`
- Provider names: `Anthropic`, `OpenAI`, `Google`, `xAI`, `Meta`, `OpenRouter`, `Vercel`
- `VS Code`, `Cursor`, `Zed`, `TextMate`, `iTerm2`, `Ghostty`, `Warp`, `Xcode`, `Sublime Text`

## Guidance

- Preferire la forma italiana naturale rispetto alla traduzione letterale
- Mantenere tono chiaro e diretto nelle etichette UI e nei testi
- Preservare invariati gli artefatti tecnici: comandi, flag, percorsi, URL, ID modello
- Usare il "tu" come forma di cortesia (coerente con lo standard UI italiano)
- Per le variabili con `{{count}}`, rispettare le forme singolare/plurale con `.one` / `.other`
- I nomi dei suoni (Alert 01, Bip-bop 01, ecc.) NON vanno tradotti

## Avoid

- Evitare di tradurre nomi di prodotto e protocollo che sono identificatori fissi
- Evitare di mescolare più termini italiani per la stessa azione UI ricorrente
- Evitare calchi dall'inglese quando esiste un equivalente italiano chiaro (es. preferire "caricamento" a "loading")
