# it Glossary

## Sources

- Initial Italian locale bootstrap in this repository

## Do Not Translate (Locale Additions)

- `OpenCode` (preserve casing)
- `Agent`
- `MCP`
- `LSP`
- `Shell`
- `Prompt`
- `Glob`
- `Grep`
- `Patch`

## Preferred Terms

| English | Preferred | Notes |
| ------- | --------- | ----- |
| session | sessione | Use in UI and docs prose |
| workspace | workspace | Keep the repo term in UI/docs |
| provider | provider | Keep the product/config term |
| model | modello | Preferred in UI |
| settings | impostazioni | Preferred in UI |

## Guidance

- Prefer natural Italian phrasing over literal translation
- Keep product names, commands, file paths, config keys, and code exactly as written
- Use native language names in language pickers, including `Italiano`
- Keep technical repo terms in English when translating them would sound unnatural in developer UI

## Avoid

- Avoid translating `workspace` as `spazio di lavoro` in product UI unless the English source explicitly needs prose wording
- Avoid translating tool names like `Glob`, `Grep`, or `Patch` in code-oriented UI
